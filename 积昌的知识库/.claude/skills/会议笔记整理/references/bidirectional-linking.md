# 双向链接建立指南

在完成笔记整理后，必须在 vault 内搜索相关笔记并建立双向链接。

## 1. 提取核心关键词

从刚完成的笔记内容中提取 **3-5 个核心关键词**：

| 笔记主题 | 关键词示例 |
|---------|-----------|
| Codex 配置 | `Codex`、`DeepSeek`、`API配置`、`模型` |
| 面试技巧 | `面试`、`求职`、`简历`、`JD拆解` |
| Claude Code | `ClaudeCode`、`AI编程`、`MCP`、`子Agent` |

**提取规则**：
- 优先使用笔记 tags 中的关键词
- 从各章节标题中提取核心名词
- 选择 vault 中可能存在的关联主题词

## 2. 使用 Grep 搜索相关笔记

```bash
# 搜索范围：总结好的大纲以及笔记/ 目录下的所有 .md 文件
Grep pattern="关键词1|关键词2|关键词3" path="总结好的大纲以及笔记/" glob="*.md" output_mode="files_with_matches"
```

### 2.1 搜索范围说明

- **限定目录**：`总结好的大纲以及笔记/` 及其所有子目录
- **文件类型**：仅 `.md` 文件（不搜索 PDF/图片）
- **排除当前笔记**：过滤掉当前正在创建的笔记本身

### 2.2 排序与筛选

1. 匹配关键词**数量最多**的笔记优先
2. 同一**主题领域**的笔记优先
3. 排除明显不相关的笔记（关键词仅出现在标签中而无实质内容相关）
4. 选取 **3-5 篇**最相关的笔记

## 3. 添加正向链接

在笔记末尾的 `## 🔗 相关笔记` 部分添加链接：

```markdown
## 🔗 相关笔记

- [[找到的笔记1]]
- [[找到的笔记2]]
- [[找到的笔记3]]
```

### 3.1 链接格式规则

- 使用 Obsidian wikilink 格式：`[[笔记名]]`
- 如果是子文件夹内的笔记：`[[文件夹/笔记名]]`
- 如果笔记名包含特殊字符，使用完整文件名（含扩展名）

## 4. 添加反向链接

### 4.1 核心逻辑

在**每篇找到的相关笔记**末尾追加一行反向链接，指向当前笔记。

### 4.2 操作方式

使用 Edit 工具追加：

```
在 [[找到的笔记1]] 末尾追加：
- [[当前笔记名]]
```

### 4.3 追加规则

| 情况 | 操作 |
|------|------|
| 相关笔记已有 `## 🔗 相关笔记` 章节 | 在列表末尾追加一行 `- [[当前笔记名]]` |
| 相关笔记没有该章节 | 在文件末尾创建 `## 🔗 相关笔记` 章节并添加链接 |
| 该笔记已引用了当前笔记 | 跳过（避免重复） |
| 相关笔记是 PDF 或其他非 .md 文件 | 不追加反向链接 |

### 4.4 查找现有章节的方法

通过 Grep 检查相关笔记中是否已有 `## 🔗 相关笔记`：

```bash
Grep pattern="## 🔗 相关笔记" path="总结好的大纲以及笔记/{{文件夹}}/{{笔记}}.md" output_mode="content" -n
```

如果找到，在该章节下方追加；如果没找到，在文件末尾创建。

## 5. 未找到相关笔记时的处理

- 跳过反向链接步骤
- 在当前笔记中保留空 `## 🔗 相关笔记` 章节
- 可添加注释说明"暂未发现相关笔记"

## 6. 验证检查

完成后验证：
- [ ] 当前笔记是否有 3-5 个正向链接？
- [ ] 相关笔记是否都追加了反向链接？
- [ ] 是否有重复链接？
- [ ] 是否排除了当前笔记自身？
