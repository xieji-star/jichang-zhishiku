# AI 语音转写字幕识别错误修正对照表

当处理 Chinese speech-to-text 转录内容时，常见的识别错误模式及修正对照。

## 通用错误模式

| 原文（错误） | 修正后（正确） | 说明 |
|-------------|---------------|------|
| `Y`（大量出现在句尾） | `了` | 最常见语气词错误，`Y` 几乎永远是 `了` |
| `的 Y` | `的了` | 组合错误 |
| `可以上 / 科上` | `科学上网` / `VPN` | 网络环境术语 |
| `白品` | `白屏` | 应用启动状态 |
| `神装` | `生效` / `成功` | 状态描述 |
| `开的` | `开票` → `配置` | 操作描述 |
| `开票` | `配置` | 操作描述 |

## 修正原则

1. **优先自动修正**：根据上下文能确定的直接修正
2. **标记存疑**：不确定的用 `> [!QUESTION]` 标注
3. **保留专有名词**：品牌名、工具名保留原名
4. **Y→了 几乎总是成立**：中文语音转写中，"了"被识别为"Y"是最常见的错误
