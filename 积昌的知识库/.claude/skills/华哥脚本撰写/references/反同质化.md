# 反同质化：创新与延伸规则 / Anti-Homogenization: Innovation & Extension Rules

> 为什么重要（用户硬性要求）：账号主战场是抖音。除了"与历史内容重复"会被限流，**"同质化"（结构/立意/句式/叙事套路千篇一律）会让账号被判低质、粉丝流失**——"发来发去都是那些内容"，观众一眼就划走。创作必须**创新 + 延伸**：结构与立意换着来，素材向深处挖，每一篇都要让老粉觉得"这条不一样"。
>
> 历史教训：0802 系列 8 篇作品已暴露出完整同质化清单（见下"同质化症状清单"）——全部是"三步法"、全部是"我有个学员"+半夜发消息、金句反复用"审稿人不怕X怕Y""问题不在X在于Y"、结尾全是"好了这条就到这儿+170多篇+私信"。**这些套路在登记前都禁止原样复用**。

## 二、结构轮换：给出指导环节不得连用同型 / Structure Rotation

"给出指导"是正文主干，**连续两条作品不得用同一种指导结构**；交稿前登记结构类型到选题库「已覆盖主题清单」：

- **三步法**（第一步…第二步…第三步…）——最常用，**隔 3 条以上才可用**
- **四步法**（四步拆解，适合流程型主题）
- **一坑一解**（只讲一个最深的坑 + 对应解法，深度打透）
- **对比式**（做A vs 不做A / 新做法 vs 老做法，两栏对照讲）
- **清单式**（5 件小事/3 个信号/4 个信号，平行枚举）
- **漏斗式**（先宽后窄：先讲大方向，再逐步收窄到关键一步）
- **时间线式**（按过程推进：头三天…一周后…月底…）
- **问答式**（连问连答：审稿人会问什么？你答什么）

递进句式同步轮换，不只用"首先…然后…最关键的是…"：可用"第一关…第二关…第三关…""头一步…再一步…收尾一步…""先说最要命的…再说最省事的…"等。**原则：骨架变，才叫创新；光换词，还是同质**。

### 二·B 表达形式轮换（硬性，2026-08-24 用户点名）/ Expression Form Rotation

> 用户点名的核心问题：**结构类型在轮换，但表面的表达形式一模一样**——0805 五条脚本中间全是"第一道保险/第二道保险""第一刀/第二刀/第三刀""第一看/第二看/第三看""一证/二证/三证"式**裸编号列举**。观众连刷十条视频，感觉是同一条换了个壳，账号被判低质。
>
> **铁律**：**结构可以相同（黄金三秒的时机、结尾钩子的写法等），但表达形式禁止每一条都相同。** 连续两条作品不得用同一种表达形式；同一种表达形式至少隔 3 条才可再用。

**表达形式轮换库**（中间干货部分的组织方式，每篇选一种，与历史错开）：

| 表达形式 | 形态特征 | 示例 |
|---------|---------|------|
| **裸编号列举** ⚠️（黑名单） | "第一X/第二X/第三X"直接数数，表面零修饰 | "第一道保险/第二道保险"——0805 五连用，已禁 |
| **优先级递进式** | 按重要/紧急程度排，强调"最关键的" | "这三件事里，最要命的是第二条…其次…最后…" |
| **对比式** | 做A vs 不做A / 新做法 vs 老做法，两栏对照 | "多数人写引言是这么写的…你换个顺序…" |
| **问答推进式** | 连问连答，一句提问引出一个解答 | "审稿人第一个会问什么？答：…那第二个呢？…" |
| **场景串讲式** | 跟着一个具体画面/时间轴走 | "从你打开论文那刻起：先…接着…等稿回来…" |
| **清单平行式** | 平行并列若干项，项内带小修饰 | "三个信号，中一个就该重写：信号一…信号二…" |
| **时间线式** | 按过程推进 | "头三天…一周后…月底…" |
| **漏斗收窄式** | 先宽后窄，逐步聚焦到关键一步 | "大方向先定对，再收到实验设计，最后就差一个动作…" |
| **分情况式** | 按人群/场景分叉 | "博一这么做…在职的换个做法…临毕业的只做一条…" |
| **反例正例式** | 先演示错误示范，再演示正确示范 | "这么写，审稿人直接划走；你改成这样，他停下来…" |
| **数字盘点式** | 用具体数字/比例组织，盘点性质 | "90% 的返修都栽在这一步，剩下 10% 输在…" |

**轮换执行规则**：
- 动手前先看最近 5 条作品的表达形式（各日期合集文档里查），**不得与最近 1 条相同，同形式至少隔 3 条**；
- **洗稿时保留爆款的表达形式**（爆款的"威力"就在它的表达形式，借形式不借内容）；**借构自创时必须选一个与最近作品不同的表达形式**；
- **裸编号列举"第一X/第二X/第三X"进黑名单**——除非隔 3 条以上且确实无更优形式，否则不碰；同类并列点数 >3 时优先改用清单平行式或数字盘点式；
- 表达形式与结构类型是两个维度：**结构**管"主干怎么搭"（三步法/漏斗式…见第二节），**表达形式**管"这一步一句话怎么说出口"。两者都要轮换，互相独立。

## 三、立意新鲜度：换汤必须换药 / Fresh Thesis

每篇作品必须携带**信息增量**（四选一，交稿前确认）：
1. **新角度**——同一个卡点，讲历史没讲过的切入面（如"数据问题"已讲过量/多样性/标注，新作改讲"算力观"）；
2. **新素材细节**——用历史没出现过的学员故事细节（回读学员感悟原文挖）；
3. **新结论**——给一句历史没有的金句/结论；
4. **新比喻**——用一个历史没用过的生活化比喻。

**核心立意查重（硬性）**：立意 = 用一句话概括"这篇讲的核心道理"。交稿前把立意与「已覆盖主题清单」逐条比对，**核心道理相同即使案例/用词全换也是重复**（推文3 教训：案例素材全换仍与脚本2 立意雷同）。交付时在选题库登记**立意**，供下次比对。

**金句骨架黑名单（硬性）**：以下骨架已用烂，**骨架级禁用**（换主语换词都不算翻新）：
- "审稿人不怕X，怕Y"
- "问题不在X，在于Y"
- "不是X，是Y"式反转
- "结果决定下限，XX决定上限"
- "XX不是YY，是ZZ"
- "这行字/这句话是你论文里性价比最高的XX"
自检方法：把正文里任何一句"金句"的主语换掉——**还能装进别的历史脚本，就是骨架雷同，重写**。

## 四、句式与细节轮换库 / Phrase & Detail Rotation

案例引入句（**连续两条不同**）：我有个学员 / 带过一个学生 / 之前接手过一个 / 有个博士来找我 / 上个月一个研二的学生 / 有个学员卡在XX / 前几天一个学员 / 她一开始…

时间细节（**同一细节至少隔 3 条**）：半夜发消息（已用5次，近期禁用）/ 白天开会时 / 群里吐槽 / 电话里 / 周末 / 答辩前一周 / 第一次组会 / 出实验结果那天

反应细节（**同一细节至少隔 3 条**）：愣住了 / 长舒一口气 / 眼睛都亮了 / 沉默半分钟 / 当场没说话 / 手都在抖 / 半天憋出一句 / 直接弹起来

导师原话引入（**轮换**）："我说：…" / "老师当时就回了一句：…" / "他只说了一句：…" / "我回他：…" / "他当时说：…"

细节分布原则：**一条作品里，同一类细节不超过 1 个**（不能既半夜发消息又当场愣住又眼睛亮）。

## 五、营销类-韩玲文档：类型学参考，不是模板（用户点名）/ Positioning of Marketing Doc

用户明确指出该文档**内容同质化严重**（12 条选题全是"XX怎么办/怎么做/怎么选"式），把它当模板直接套用 = 产出同质内容。定位改为：

- ✅ **只取"类型学"**：有哪些选题类型（技术卡点/方向选择/学术策略）、钩子类型（10 钩子）、收法类型（8 收法）、内容线（四条）——用类型清单来对照"我这条属于哪类、轮换到哪类了"，仅此而已。
- ❌ **禁止**：照搬其示例句式、话术原句、选题原文；"从三张表里挑一条"（挑出来必同质）。
- **选题延伸法（替代直接挑题）**：
  1. **素材反推法**（首选）：回读学员感悟/案例文件，从学员的真实卡点反推选题——素材是无限的，选题就跟着无限；
  2. **卡点×场景×人群组合法**：把通用卡点（写不出/被拒/没算力/选刊错…）与具体场景（换数据集/加模块/答辩前/申博季…）和具体人群（跨专业/在职/博一…）组合出新选题；
  3. **追问延伸法**：把已覆盖主题往深处追问一步（"先查数据"→"数据从哪来/标注怎么管"；"选方向"→"被导师按头定方向怎么办"）。
- 选题库 12 条只作**查重基准与类型示例**，不作唯一选题来源。

## 六、素材复用登记 / Material Reuse Registry

- **同一学员素材至少隔 3 条才能复用**（姜姜素材曾被 3 篇连续使用，是教训）；
- 复用必须**换角度**：同一学员的不同信息点（如姜姜：数据三步 / 服务器算力观 / 报错处理），登记时写清本次用哪个角度；
- 素材登记到选题库「已覆盖主题清单」：条目格式 `主题（学员名·角度）`。

## 七、反同质化自查（交稿前必做）/ Anti-Homogenization Self-Check

- [ ] 结构类型与上一条不同（三步法隔 3 条以上才可用），已登记
- [ ] **表达形式与最近 1 条不同、同形式至少隔 3 条**（不是裸编号列举"第一X/第二X/第三X"；优先级递进/对比/问答推进/场景串讲/清单平行/时间线/漏斗收窄/分情况/反例正例/数字盘点任选其一，见第二节·B）
- [ ] **开头三步曲骨架与最近 3 条不同**（痛点句式 + IP 亮牌句式不能同构——"你研二+痛点+我是华哥170背书"三步曲是 0828脚本1~2 的教训：洗稿同账号多条爆款时，原爆款的开头公式会整段重复，必须逐条轮换开头钩子：场景式/设问式/选择题/倒计时/假设式/数据数字式……IP 亮牌句式同步变体，见结构方法论第六节）
- [ ] **洗稿结尾对标原爆款收法，不套自由创作结尾三段式**（2026-08-28 用户点名规则：洗稿时结尾直接对标原爆款收法——保留"资料钩子→咨询钩子→IP升华"的先后次序与句式节奏，只换资料名/扣词/话术；**不套**收束确认+资料钩子+咨询钩子三段式、**不受**结尾收法 8 类轮换约束。自由创作的结构表只用于自创脚本，洗稿场景以爆款原稿为准，见 SKILL.md「爆款脚本洗稿与借构创作」红线）
- [ ] 立意与全部历史作品不重复（对照已登记立意），有信息增量（新角度/新素材细节/新结论/新比喻之一）
- [ ] 金句无黑名单骨架（"审稿人不怕X怕Y""问题不在X在于Y""不是X是Y"等），换主语装不进别的历史脚本
- [ ] 案例引入句、时间/反应细节与最近 3 条不同，同条作品内同类细节 ≤1 个
- [ ] 叙事骨架（成功翻盘/反转警示/对比/时间线/悬念倒推/教训型）与上一条不同
- [ ] 素材复用间隔 ≥3 条且换角度（如适用）
- [ ] 结尾过渡句、IP 句结构（不只用词）与最近版本不同
- [ ] **结尾三段式不命中结尾句式黑名单**（"做科研最怕XX/你要把它做成闭环/评论区打XX华哥安排/顶会顶刊导师一对一诊断"0805 五连用句式——三段式是骨架，句式/措辞/过渡词各换一处）
- [ ] **科研论文锚定（脱题红线）**：把"论文/科研/实验/投稿/导师/审稿人/方向/数据/毕业"换成"工作/领导/同事/老板"后内容不再成立（0805脚本5 脱题教训已规避）
- [ ] 选题不是直接从营销类-韩玲 12 条里挑的（用了素材反推/组合/追问延伸）
