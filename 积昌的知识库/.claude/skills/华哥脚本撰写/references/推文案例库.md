# 推文案例库 / Written-Post Case Library

> 本库是**招生推文类**（服务说明型）的标准案例与拆解。注意：**推文的主力形态是"知识分享类/案例解释类"**——与视频脚本完全同构（华哥口吻 + 7 步结构 + 案例叙事），素材直接使用本地脚本素材库（学员感悟/案例文件/结构模板/受众报告/选题库），写法见 SKILL.md「推文脚本撰写」章节，与视频无结构差异，只是篇幅（600~800 字）与语言（书面精练、术语同样通俗化）不同；**不要照搬本库案例的写法**，按华哥的方式讲自己的案例。
>
> 本库标准案例为其他账号（"佛系接指导"）的高转化招生推文，仅用于**招生推文类**题材。华哥账号推文必须套用华哥人设（170 多篇学员论文、AI 方向论文、咨询信息点=方向+学历+卡点），并继承黑名单红线（原文个别用词如"手把手"要改写）。

```

1.之前有带过基础差的本科生比如说xx学院，在努力下也发了ccf
2.当然也有很多资质不错的学生，例如南开，中科院，复旦，清华，北邮，nyu
```

约 550 字正文 + 11 个标签，口语少、书面精练（注意：标准案例术语偏多，华哥推文按新规则**术语通俗化**改写，不照抄）。

## 二、8 段式逐段拆解 / 8-Section Breakdown

| 段 | 作用 | 案例原文 | 要点 |
|----|------|----------|------|
| 1 人设钩子 | 抓眼球 | "今年带出十几篇A会已累死🫠" | 结果数字 + 情绪化表达，第一句就立"有战绩的老师"人设 |
| 2 服务承诺+风险预期管理 | 讲清边界 | "从选题到idea到实验到写作…初稿改个十几遍；顶会有随机性，只能保证文章质量" | **主动说清不确定性反而可信**（信息对称）——这是高端产品信任的核心写法 |
| 3 团队背书 | 证据堆叠 | "16篇CCFA，8篇CCF B…今年中稿ICCV2025、ICLR2025、CVPR2025…cs圈内co-author组建专业team" | 数据 + 具体会议名 + 团队构成，全部可验证，不空喊 |
| 4 分层案例 | 两档对照覆盖全部用户 | "基础差的本科生xx学院也发了ccf / 资质好的南开、中科院、复旦、清华、北邮…保研top2、CMU交换、CS前30博士" | **名校点名、普通院校"xx学院"打码**；基础差→兜底安全感，资质好→更上层楼想象，两类用户都能对上号 |
| 5 初衷情怀 | 立真诚人设 | "被导师耽误的学生特别能共情…帮被导师坑的学生完成0-1的转变" | 直击目标用户最痛场景（导师坑/被耽误），不是空谈情怀 |
| 6 能力清单 | 展示专业纵深 | "可带方向：llm、mllm、ml、cv、具身智能、diffusion、自动驾驶、ai4science；有现成idea，算力可协调使用" | 方向清单覆盖目标用户全画像；**资源实打实**（idea+算力） |
| 7 目标承诺 | 落成可预期动作 | "target会议：暑假AAAI，10月ICLR、11月CVPR" | 把"带你发论文"变成具体时间表，服务可预期 |
| 8 标签 | 承接搜索流量 | "#计算机申博 #llm #留学 #sci论文辅导 #ai #nips2024 #aaai2025 #iclr2025 #icml2024 #顶会论文 #机器学习" | 11 个：人群词 + 领域词 + 会议词，承接精准搜索 |

**规律**：每个承诺后面紧跟证据；每个段落都是"卖点 + 证据"成对出现——没有一句空头自夸。这是推文信任的底层逻辑（信任 = 信息对称）。

## 三、可复用句式库 / Reusable Sentence Patterns

> 句式可复用，用词按华哥账号红线调整（黑名单词改写），不得整句照抄：

- **预期管理句**：顶会有随机性，我们也只能保证文章质量这块，以及你努力配合的情况下。
- **承诺句**：从选题到 idea 到实验到写作全程跟，初稿能给你改十几遍。
- **分层案例句**：之前带过基础差的本科生（xx学院），努力下来也发了 CCF；也有资质很好的学生，比如清华、中科院、北邮…保研 top2、CMU 交换。
- **初衷句**：被导师耽误过的学生，特别能共情；初衷就是帮被导师坑的学生完成 0-1 的转变。
- **能力清单句**：可带方向：llm、mllm、ml、cv、具身智能、diffusion、自动驾驶、ai4science；有现成且成熟的 idea，算力可协调使用。
- **目标句**：目前 target 会议：暑假 AAAI，10 月 ICLR、11 月 CVPR。
- **标签公式**：人群词（#计算机申博 #留学 #sci论文辅导）+ 领域词（#llm #机器学习 #ai）+ 会议词（#aaai2025 #iclr2025 #nips2024）+ 泛流量词（#顶会论文）。标准案例原文 11 个；**华哥推文栏目固定 7 个标签（格式与视频脚本一致）**，按此公式从候选里精选 7 个。

## 四、推文 vs 视频要点对照 / Post vs Video

| 维度 | 视频脚本 | 推文脚本 |
|------|----------|----------|
| 篇幅 | **650 字左右**（600~700，不含空格标点） | 600~800 字（不含标签与空格标点） |
| 语言 | 口语化多、语气词多、短句多 | 口语化少、书面精练、**废话少**、信息密度高 |
| 术语 | 通俗化（显卡/陪跑的位置） | **同样通俗化**：简单易懂不堆术语，只是比视频更精练 |
| 案例 | 虚拟组合形象，不点名院校 | 名校点名、普通院校"xx学院"打码 |
| 服务身份 | 只能暗线（人设+结尾转化） | 可直接明线（招生推文本质） |
| 结构 | 7 步结构 + 口播节奏 | 8 段式 + 换行留白节奏 |

## 五、使用注意事项 / Usage Notes

1. **案例来源**：标准案例是其他账号原文，结构可仿、原文不抄；华哥推文用华哥的数据（170 多篇学员论文、AI 方向、真实案例文件）与红线。
2. **黑名单改写**：原文"手把手教"在华哥推文中改写（如"从选题到写作全程跟""每个环节都有人带"）；"包带会"同样落黑名单（包中稿类），改写为"文章质量我们把关"。
3. **分层背书**：点名名校须有真实依据（来自案例文件/学员素材），普通院校一律"xx学院"打码，不消费弱势院校。
4. **禁止空头承诺**：每条承诺必须有可验证证据，否则删掉或改写（这是标准案例的底层逻辑）。
5. **查重（硬性）**：账号主战场是抖音，平台对重复内容限流，**重复率必须低**——推文与全部历史视频脚本/推文（含优化版）均不得重复：主题/选题、开头句式、结尾收法、关键句式/话术、标签组合逐项核对（见 SKILL.md「推文查重」章节）；交付后把主题登记到选题库「已覆盖主题清单」（标注"推文"）。句式库仅作结构参考，**用词必须翻新**，不整句照抄。
6. **语言精练但通俗（用户硬性要求）**：废话少、信息密度高（有限篇幅讲全知识点/信息点），但术语同样要通俗化——不能通篇专业术词，观众看一眼就划走；专业概念换大白话或带一句简短解释。
