## 一、使用规则（硬性）/ Usage Rules

1. **虚拟组合形象**：把不同学员的真实细节组合成一个虚拟学员，不出现真实网名（薯饼、小黄鸭等）和机构名（图灵学术等）。对外口径只有"我有个学员/我带过一个学生"。
2. **技术事实必须自洽**：显存、参数量、训练时间、涨点数字、会议名称不能有逻辑错误（可参考素材里的真实数据）。
3. **PASS 原则**（浩源课程）：每个案例细节尽量四要素齐备——**地点**（深夜的实验室/宿舍）、**动作**（发消息、盯着曲线、翻实验记录）、**话术**（学员说了什么/老师回了什么）、**内心所想**（"心里发虚""长舒了一口气"）。心理活动是让观众觉得"这就是我"的关键。
4. 案例中老师的形象：有经验的领路人，一两句点睛的话（"没事""牛，省一半工作量""你先停"），不神话。

## 四、叙事模板 / Narrative Templates

**"三步讲法"模板**（0802脚本2 用过，已验证）：定动机 → 定证据 → 定身份
**"反转"模板**（0802脚本3 方向）：先写最绝望/最卡的一刻（学员原话）→ 老师一句话点破 → 行动 → 结果

通用案例弧线：**卡壳（具体到动作和数字）→ 老师干预（一句话）→ 执行（细节）→ 结果（时间+成果）→ 学员心理变化**。心理细节放在卡壳和结果两处，观众代入感最强。
