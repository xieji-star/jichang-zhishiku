# 实战案例：0804脚本1 完整创作工作流 / Real Worked Case

> 本案例完整记录一次从零到交付的创作流程（技术痛点型·图表横坐标逻辑），含**字数压缩与审视教训**。**创作前通读一遍找感觉**——看真实作品如何把本 skill 的查重、轮换、人设、压缩规则落成一篇 650 字左右的成品；**做长度压缩时必须对照第五节**。

## 一、任务背景与内容线确认

- 用户要求 1 条脚本（数量 < 10）→ 按内容线分配硬性规则**先询问**内容线 → 用户选**技术痛点型（40%）** → 才开始选题与动笔。
- 日期 2026-08-04，产出 `0804脚本1`，按日期合集模式保存为 `创作好的脚本/0804脚本/0804脚本合集.md`。

## 二、查重与选题（第 0 步）

- 读全部历史合集（0802/0803 脚本 37 篇 + 0802 推文 8 篇）与 `references/选题库.md`「已覆盖主题清单」，视频与推文跨类型互查。
- 选题 = **追问延伸法**：历史 transcripts 只泛泛覆盖过"图表"主题 → 往深处追问一步"图表的**逻辑漏洞**（坐标系）"，信息增量 = 新角度。
- 素材 = **素材反推法**：回读学员感悟，取芭乐章节（顶刊、横坐标 iteration→攻击比例、300dpi 等图表细节）；0802推文3 已用过芭乐"基线公平性"角度，本次换"图表坐标系"角度，复用间隔 30+ 条 ✓。
- 立意一句话："图表是替论文说真话的证人，横坐标选错整张图都在误导审稿人"——与已登记立意逐条比对不重复。

## 三、结构轮换（第 2 步 + 第 6 步）

| 维度 | 本次选择 | 轮换依据 |
|------|----------|----------|
| 指导结构 | **对比式**（你眼里的图 vs 审稿人眼里的图） | 上一条（0803脚本31）是三步法，不连用；对比式间隔 20+ 条 |
| 递进句式 | "第一版…第二版…" | 替代"首先…然后…最关键的是…" |
| 开头钩子 | **好奇悬念**（同一份数据，两张图，一张点头一张皱眉） | 最近 5 版用过代入场景×2/互动提问/借势热点/逆向反转 |
| 结尾收法 | **行动启发 + 资料钩子**（扣"横轴"领图表自查清单） | 最近 5 版全是私信咨询钩子，需轮换；主钩二选一 |
| 案例引入句 | "去年我带过一个做网络攻击方向的学员" | 避开"我有个学员"（历史 6 次） |

## 四、案例叙事（第 3 步）

- PASS 要素：对话（"你每批打的节点数，一样吗？"）+ 动作（第二天重画一版）+ 心理（"还挺满意"/"那次才明白"）。
- 虚拟组合形象：不出现真实网名（芭乐）与机构名；技术事实自洽（攻击比例、迭代次数、高清大图 300dpi 均为真实素材细节）。
- 人设点明句在案例引入处完成（"我带过一个…学员"），结尾 IP 句变体（"这半年，170多个学员的稿子从我这儿出去，每一张图，都先过我这一关"）。

## 五、字数压缩与审视教训（第 5 步·⭐核心）

**事件经过**：第一版 983 字 → 用户要求 600~700 字 → 压缩出 698 字精简版 → **用户复核发现重要干货被误删** → 补回后 699 字定稿。

**用户复核发现的问题**：压缩时把"图表规范清单"（坐标轴名字统一简写、纵轴范围卡紧、拼高清大图、白边裁干净）**整段删掉了**。这段是：

1. **技术痛点型的干货落点**——观众看完横坐标逻辑后能直接拿走的具体操作清单，是"让被卡住的人觉得你真懂"的信息密度所在；
2. **结尾资料钩子的正文依据**——钩子承诺"我把图表自查清单发你"，正文却没有任何清单内容铺垫，钩子悬空、像空话；
3. **金句的垫脚石**——"画图是给数据上法庭作证"正因为前面有"收拾规范"的动作铺垫才立得住。

**压缩守则（沉淀为硬规则）**：

1. **压缩 ≠ 删干货**。技术痛点型的"干货落点"（可操作清单/方法步骤）必须保留，删它是成本最低的错误——观众学不到东西，信任立不住，转化无从谈起。
2. **压缩顺序**：先删过渡句（"咱们把两版图摆一起看"）→ 再删次要心理细节（"线是线、点是点"）→ 再压缩表达（"记录→记""回答→答""套个模板就完事→套个模板完事"）→ **最后才轮到干货句**。
3. **压缩后必须回读审视**：对照原版逐句比对，每处删除都要能说出理由；删不动的就换一种表达腾字数，而不是删下一句干货。
4. 字数口径不变：600~700 同样按"去空格去标点"统计（中文按字计，英文/数字按连续串计）；用脚本 `len(去标点文本)` 数一遍再交稿。

**压缩前后对照（节选）**：

| 原版 | 压缩后 | 处理 |
|------|--------|------|
| 咱们把两版图摆在一起看，差别一下就出来了。 | （删除） | 过渡句，删 |
| 线是线、点是点，颜色也统一 | （删除） | 次要画面细节，删 |
| 他按我给的清单把图一张张收拾过：坐标轴名字统一成规范简写，纵轴范围卡紧不留大片空白，图片拼成高清大图，白边裁干净 | 我让他把图再收拾一遍：坐标名字统一简写、纵轴范围卡紧、拼高清大图、白边裁干净 | **干货落点，压缩表达但保留** |
| 记录的是我跑了几轮；回答的是达到同样的破坏效果 | 记的是我跑了几轮；答的是达到同样的破坏效果 | 口语压缩 |
