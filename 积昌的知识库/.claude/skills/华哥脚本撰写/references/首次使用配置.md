# 首次使用配置 / First-Use Configuration

> 本文是「华哥脚本撰写」skill 的**首次使用配置**完整规格。SKILL.md 的「🔗 首次使用配置」章节是入口，这里给出**流程细节**与**config 字段说明**。
> 本 skill 是被**分享出去的通用版**，**不绑定任何特定飞书账号 / 文档**。绑定动作在**第一次调用**时完成，并把结果写入本 skill 目录下的 `config/config.json`。

---

## 0. 检测

- 看本 skill 目录下是否存在 `config/config.json`。
  - **存在** → 直接复用其中的**飞书账号（`feishu`）+ 三个功能的默认文档（`docs`）+ 素材库根（`paths`）**，**不再询问**。
    - 例外：用户**明确说**"我要换账号 / 换文档 / 改默认文档" → 重新走下面的流程，改完**再确认一次**、更新 `config.json`。
  - **不存在** → 执行下面「A → B → C（→D 确认）」流程。

---

## 1. A. 绑定飞书账号（优先 bot）

1. 问用户："你有飞书开放平台应用（bot）吗？优先用 bot。"
2. **有** → 让用户提供这个 bot（Claude 负责用 `lark-cli` 配置、授权、验证）。
3. **没有** → **由 Claude 代为创建**一个飞书开放平台应用 bot：
   - 创建应用、配置权限、发布版本等全部由 Claude 完成；
   - **只有"扫码登录 / 授权"这一步由用户本人完成**，其余全程由 Claude 操作，做到最精简。
4. 绑定成功 → 记录：
   - `feishu.as_flag`：`"bot"` 或 `"user"`（优先 bot）
   - `feishu.account_name`：该账号名
5. 该账号名下的飞书文档一并归到该账号下（后续访问都用这个账号）。

> 交换条件/说明：bot 有开放的文档读写权限；若 bot 权限不足或确有需要以个人身份维护同一文档，才改用 `--as user`（个人账号）。

---

## 2. B. 映射三个功能的文档

本 skill 有三个功能，**各对应一个飞书文档**（「记录」的文档可与「洗稿 / 创作」不同）：

| 功能 | 说明 | config 字段 |
|------|------|-------------|
| **① 爆款脚本的记录** | 记录 / 归档采集到的爆款脚本 | `docs.记录` |
| **② 爆款脚本的洗稿** | 基于爆款改写 | `docs.洗稿` |
| **③ 脚本的创作** | 创作新的华哥脚本 | `docs.创作` |

**逐个功能询问**（每个功能问两件事）：

1. **写到哪个飞书文档**：让用户给出文档标题或链接（`docs.<功能>.title` / `docs.<功能>.url`）；"有关飞书文档"若同名多个，**取时间戳最新的那个**。
2. **是否设为默认文档**（`docs.<功能>.is_default`，true / false）：
   - 设为默认 → 以后调用该功能，只要用户没点名"直接改哪个文档"，就默认写进这个文档。

> 说明：三个功能**独立设默认**；「记录」与「洗稿/创作」通常各用各的文档，分开问。若某个功能用不到飞书，也允许设为 `null` / 不设置（调用时再按需询问）。

---

## 3. C. 操作红线：只增查改、禁止删除（硬性）

- 对绑定文档**只能增、查、改**，**禁止删除**。
- **任何删除动作**（删块、删日期、删内容、清空文档）**必须先询问用户、得到明确同意后**才执行，**绝不擅自删除**。

---

## 4. D. 确认（唯一一次）

把收集到的 **账号 + 三个功能的文档 + 各自是否设为默认** 汇总成清单，**问用户一次"是否确认？"**：

- **确认** → 写入 `<skill目录>/config/config.json`（如不存在则创建），此后正常创作，**不再重复询问**。
- **不确认 / 要改** → 重新问，直到确认。

---

## 5. 后续更新

- 之后**默认用已设置的账号与默认文档**，不再询问。
- 仅当用户**明确提出要改**（"我要换操作的文档""帮我换回账号""把默认文档改成 XX"）→ **重新走 A→B 询问**，改完**再确认一次**、更新 `config/config.json`。
- 判断逻辑：以「用户是否明确点了要改」为准；未点则一律走默认，避免反复打扰。

---

## 6. `config/config.json` 字段说明

参考 `config/config.example.json`（字段模板），字段含义如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | int | 配置版本号，当前 `1` |
| `created_at` | string | 首次绑定日期（`YYYY-MM-DD`） |
| `feishu.as_flag` | string | 写入飞书的账号标识：`"bot"`（优先）或 `"user"` |
| `feishu.account_name` | string | 绑定的飞书账号名 |
| `feishu.server_dir` | string | 飞书智能助手服务所在目录（含 `server.py`），启动服务用 |
| `docs.<功能>.title` | string | 该功能绑定文档的标题 |
| `docs.<功能>.url` | string | 文档 wiki 链接（或搜索定位关键词） |
| `docs.<功能>.is_default` | bool | 是否设为该功能的默认文档 |
| `paths.base_dir` | string | 素材库根目录（打包分享版默认 = 包内 `绑定的资料/`） |

---

## 7. 依赖说明（让 skill 功能齐全）

本 skill 正常运行依赖以下能力（打包已尽量自带；缺失时在首次配置里向用户确认）：

- **飞书能力**：`lark-cli` + `飞书智能助手` 服务（`feishu.server_dir`）。这是读写飞书文档的基础；**换设备后必须把 `server_dir` 指向新设备上的飞书智能助手**。
- **设计辅助**：`/前端设计` skill（转 HTML 时用）。
- **排版 / 提示词优化**：`/文档转换+排版`、`/提示词优化专家`（可选）。
- **素材库**：`paths.base_dir`（绑定的资料 / 参考的资料 / 创作好的脚本 / 创作好的推文 / 爆款库）。
