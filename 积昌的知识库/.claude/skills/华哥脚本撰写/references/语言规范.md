# 语言规范：去 AI 味 / De-AI Language Guide

> 为什么重要：口播脚本是"一个人对着镜头说话"，观众 3 秒内要能听懂。书面化、术语堆砌、长句会直接触发划走。目标状态：**像华哥坐在你对面聊天**。

## 一、AI 味自检清单 / AI-Flavor Checklist

写完后逐条检查，命中任何一条都要改：

1. **术语无解释**：任何专业词第一次出现必须带一句通俗解释，或直接用大白话替换。
2. **连接词书面化**：避免"首先/其次/最后""综上所述""总而言之""值得注意的是""不难发现""让我们""随着××的发展"等 AI 套话。
   - 例外：7 步结构里"举例佐证"步骤的"首先…然后…最关键的是…"是**方法论要求的递进句式**，保留。
3. **长句**：一句话超过 20 字就拆。宁可多几个句号，不要一口气读不完。
4. **排比堆砌**：连续三个以上同结构句式（"是××，是××，也是××"）像演讲稿不像聊天。
5. **书面用词**：把"在此""予以""进行""较为""从而""亦可"这类词删掉，换成口语。
6. **没有语气词**：通篇没有一个"啊/呢/吧/其实"，基本可以判定 AI 味重。
7. **情绪缺位**：全程陈述句、没有反问和感叹，听起来像念文档。
8. **数字与例证僵硬**："0.4 个点""3 倍显存"这种精确数字在口播里要么换算成大白话（"零点几个百分点"），要么配一个生活化比喻。

## 二、术语通俗化对照表 / Term Plain-Language Table

| 术语 | 通俗说法 |
|------|----------|
| 全参微调 / Full fine-tuning | 把模型从头到尾全都重新训练一遍 |
| LoRA / 低秩适配 | 只训练模型一小部分的轻量方法 |
| Baseline / 基线实验 | 陪跑的位置 / 拿来对比的基准 |
| 显存 | 显卡 |
| 0.4 个点 / 0.4个百分点 | 零点几个百分点 |
| 3 倍显存、4 倍时间 | 显卡要多用三倍，时间要多花四倍 |
| ICME / ICASSP / 顶会 | 一个挺权威的国际会议 / 顶级的国际学术会议 |
| Ablation study / 消融实验 | 把模块拆掉一个，看效果掉了多少的实验 |
| 泛化性 | 换个数据集、换个场景还行不行 |
| Transformer | 现在大模型都在用的那种网络结构 |
| 参数 / 参数量 | 模型的"记忆容量" |
| 训练轮次 | 把数据反复喂给模型学的次数 |
| 收敛 | 模型学得差不多了，指标不再明显涨 |
| 多模态 | 同时处理文字、图片、声音多种信息 |

规则：**对照表没有的词，也用同样的思路处理**——先判断观众（硕士/博士/职场人，懂"论文"但未必懂"门控激活分布"）听到这个词会不会懵；会懵就换成大白话或加一句括号式口语解释。

## 三、语气词库 / Colloquial Particles

自然插入，不要每句都加：啊 / 呢 / 吧 / 嘛 / 其实 / 说白了 / 你猜怎么着 / 翻来覆去 / 愣是 / 还真 / 到头来 / 说白了 / 说真的 / 我跟你说 / 结果呢 / 然后呢 / 你说气不气人。

## 四、短句化示例 / Sentence-Splitting Examples

**长句（AI 味）**："当科研人员面对海量计算资源时，常常面临一个关键抉择，即选择 LoRA 方法还是全参数微调方法，这直接关系到训练成本与最终效果。"
**拆成短句（人味）**："显卡就那么点大，模型又那么大。全参，装不下。LoRA，省得多。怎么选？这就是今天要聊的事。"

**长句**："全参数微调需要对模型的全部参数进行更新训练，这要求巨大的显存资源与漫长的训练时间。"
**拆成短句**："全参微调是什么？把模型从头到尾，全都重新训练一遍。显卡要多用三倍，时间要多花四倍。普通人，扛不住。"

## 五、正反例对照 / Before-After Examples

**反面（AI 味）**：
> 首先，全参数微调需要对模型全部参数进行训练，这要求巨大的计算资源。其次，LoRA 方法仅对部分参数进行训练，显著降低了资源需求。最后，科研人员应当根据自身情况做出合理选择。综上所述，……（这段全是套话，观众 3 秒划走）

**正面（人味）**：
> 你猜怎么着？全参效果确实好一点，但只高了零点几个百分点，代价是显卡要多用三倍、时间要多花四倍。这笔账，谁都会算。

**反面**："该方法在资源受限场景下具有显著优势，能够有效降低训练成本并提升部署效率。"
**正面**："一张普通显卡就能复现，实验室同学照着跑，也能跑出来。"

## 六、口播节奏参考 / Rhythm Notes

- 每段 1~3 句就换行（脚本排版留呼吸感）。
- 关键句独立成段（如"就是这三个字，把你的论文从录用拉到退稿"）。
- 数字、时间点（"两周""0.4 个点""一个月后"）是可信度锚点，保留但要口语化。

## 七、去营销味 / De-Marketing Guide

> 为什么重要：观众对广告味极其敏感。结尾一冒推销腔，前面建立的信任全垮——用户明确要求**去除营销味**。

1. **转化动作不堆叠**：一条脚本结尾只保留 **1 个主转化钩子**（评论区扣词 / 私信 / 关注，三选一，轮换使用），最多再加一句轻引导（"评论区聊聊""想看的吱一声"）。"扣词+私信+关注+进群"全家桶 = 营销味，直接毙。
2. **强推销词黑名单**（出现即改）：赶紧 / 名额 / 错过 / 上车 / 免费领 / 限时 / 包中稿 / 手把手带你 / 一对一陪跑 / 错过再等半年。
3. **咨询钩子铺垫自然**：不用"想不想……""你是不是也想……"推销句式；用"拿不准的，可以私信我看看""这种情况，发我，我帮你把把脉""数据没跑稳的，曲线截图发我，我帮你看偏在哪一步"——像帮忙，不像卖课。
4. **自然过渡收尾**：结尾前加一句"好了，这条就到这儿""行，今天就聊到这儿"，像下课聊天，不像广告结束。
5. **IP 句变体**：锚点信息（华哥身份 + 170 学员）每次换表达，禁止逐字重复"我是华哥，专做 AI 方向论文，这半年，170 多个学员中稿"；变体库见 `结构方法论.md` 第六节。
6. **利他话术优先**：结尾先给观众能拿走的东西（动作/观点/资料），再谈引导；顺序反了就是广告。

## 八、平台违禁词对照表 / Platform Banned Words

> 为什么重要：脚本与推文的**文字稿会被平台审核**，命中违禁词直接打标签限流，账号权重受损。这是硬性红线——视频正文、推文正文、标题、标签、封面文字全要查。

### 1. 绝对禁词（出现即删/换）

| 类别 | 禁词示例 |
|------|----------|
| 脏话辱骂 | 妈的、卧槽、操、傻逼、傻X、去死、滚、你大爷、神经病 |
| 死亡暴力 | 死、杀、自杀、杀人、打死、该死、判死刑、死定了、想死、寻死 |
| 其他敏感 | 政治敏感、色情低俗、赌博毒品类词汇一律不写（拿不准就删） |

### 2. 口语替换表（情绪表达不用禁词）

| 想表达的意思 | 禁词说法（禁用） | 替换说法（可用） |
|--------------|------------------|------------------|
| 极度震惊/无语 | 卧槽 | 我的天 / 你猜怎么着 / 我真服了 |
| 情绪崩溃 | 想死的心都有了 | 心态崩了 / 天塌了 / 整个人都不好了 |
| 否定判决 | 判死刑 / 死定了 | 别急着下结论 / 凉凉了 / 没戏了 |
| 强烈不信 | 打死我都不信 | 谁信啊 / 骗谁呢 |
| 语气助词（口癖） | 妈的、操 | 气死我了→气炸了 / 删掉口癖 |
| 恶劣结果 | 死磕到底 | 硬磕到底 / 死磕→硬磕 |

### 3. 教育广告合规词（硬性·高危）/ Education-Ad Compliance Words

教育/学术类目平台严打"结果承诺"与"保证性表述"，**命中直接限流/违规**。**出现即删/换，正文、标题、标签、封面、评论关键词全查**：

| 违禁/高危 | 替换说法 |
|-----------|----------|
| 保过 / 包过 / 保中 / 包中 | 客观描述流程与陪伴（"全程跟到出结果"） |
| 保证中稿 / 保证录用 | 不承诺结果，讲过程价值 |
| **保你毕业 / 保证毕业** | 乐观的口头预期 / 落地保障 / 客观核验 |
| 稳上 / 必过 / 内定 / 100% 通过 | 讲概率与现实（"概率摆在那儿，别赌特例"） |
| 承诺 XX / 一定 XX / 肯定 XX | 期许 / 预期 / 落地动作 |

> ⚠️ 教育类目对"保证毕业""包中稿"类结果承诺是**红线**——0805脚本5 的"保你毕业"即教训，一律用"预期/期许/落地保障/客观核验"等中性词替代。

### 4. 高危情绪表达替换表（降质 + 易限流）/ High-Risk Emotional Expressions

情绪化、口语化、夸张的表达会让账号显得低质，部分还可能被平台误伤。**换中性客观的说法**：

| 高危表达（禁用/慎用） | 中性替换 |
|----------------------|----------|
| 画饼（含"饼能不能吃""这张饼"） | 口头预期 / 口头期许 / 口头表达 |
| 拍着胸脯 | 口头 / 嘴上说 |
| 感动得一塌糊涂 / 一塌糊涂 | 直接删掉 / 心里没底 |
| 当场就清醒了 | 心里有数了 / 看清了现实 |
| 两手空空 | 陷入被动 / 没着落 |
| 承诺（指导师口头） | 期许 / 预期 / 口头表达 |
| 心凉 / 心凉半截 | 心里没底 / 心里打鼓 |

> ⚠️ **评论关键词也不能用高危词**：0805脚本5 评论区扣"画饼"→ 改进版扣"核验"（见 `对标案例.md`）。

### 5. 自查流程（交稿前必做）

1. 通读全文，逐字扫标题、正文、标签、封面文字、评论关键词；
2. 重点扫"死/杀/骂/操/逼"等字根，以及"保/包/保证/承诺/稳/必/一定"等结果承诺字眼；
3. 扫"画饼/拍着胸脯/一塌糊涂/两手空空"等高危情绪表达，换中性词；
4. 情绪强烈的口语优先换用"崩/完蛋/天塌/踩雷/没戏/硬磕"等替代词；
5. **拿不准的词宁可换掉**——平台审核不看语境，只看字。
