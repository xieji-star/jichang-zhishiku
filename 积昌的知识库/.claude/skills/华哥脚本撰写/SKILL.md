## 🔗 首次使用配置：绑定飞书账号与功能文档（前置步骤 / 只有第一次走）

> 本 skill 是**可分享**的，**不绑定任何特定的飞书账号或文档**。**第一次调用**时（检测到本 skill 目录下没有 `config/config.json`）**必须先完成下面配置**，做完并确认后才进入正常创作流程。

### 检测规则
- **有** `config/config.json` → 直接复用其中记录的**飞书账号 + 各功能默认文档**，**不再询问**，除非用户明确说"我要换账号 / 换文档 / 改默认文档"。
- **没有** → 依次走「**A. 绑定账号 → B. 映射功能文档 → C. 确认**」，全部问清楚后**再问一次"是否确认"**，确认后写入 `config/config.json`。

### A. 绑定飞书账号（优先 bot，其余由 Claude 完成）
1. 问用户："你有飞书开放平台应用（bot）吗？优先用 bot。"
2. **有** → 用这个 bot；**没有** → **由 Claude 代为创建**一个飞书开放平台应用 bot（创建应用 / 配权限 / 发布版本），**只有"扫码登录 / 授权"这一步由用户本人完成**，其余全部由 Claude 完成，全程做到最精简。
3. 绑定成功 → 把账号的 `as_flag`（`bot` / `user`）与账号名记录进配置。
4. 与该账号对应的飞书文档也一并归到该账号下。

### B. 映射三个功能的文档（逐功能询问）
本 skill 有三个功能，**各自对应一个飞书文档**（其中「记录」所用文档可与「洗稿 / 创作」不同）：

| 功能 | 用途 | 文档 |
|------|------|------|
| **① 爆款脚本的记录** | 记录 / 归档采集到的爆款脚本 | 待定 |
| **② 爆款脚本的洗稿** | 基于爆款改写 | 待定 |
| **③ 脚本的创作** | 创作新的华哥脚本 | 待定 |

**逐个功能询问**（每个功能问两件事）：
1. 该功能写到**哪个飞书文档**（让用户给文档标题或链接；同名取时间戳最新）；
2. **是否把这个文档设为该功能的默认文档**（是 / 否）。
   - 设为默认 → 以后调用该功能，只要用户没点名"直接改哪个文档"，就**默认用这个文档**。

> 说明：「记录」的文档与「洗稿 / 创作」的文档通常**不一样**，**分开问**；三个功能可以各自独立设默认。

### C. 操作红线（增查改不删，硬性）
- 对飞书文档**只能增、查、改**，**禁止删除**。
- **任何删除动作**（删块、删日期、删内容、清空文档）**必须先询问用户、得到明确同意后才能执行**，**绝不擅自删除**。

### D. 确认（唯一一次）
把上面收集到的 **飞书账号 + 三个功能的文档 + 各自是否设为默认** 汇总成清单，**问用户一次"是否确认？"**：
- **确认** → 写入 `config/config.json` 作为默认配置，此后正常创作，**不再重复询问**。
- **不确认 / 要改** → 重新询问，直到确认。

### 后续更新
- 之后**默认用已设置的账号与默认文档**，不再询问。
- 仅当用户**明确提出要改**（如"我要换操作的文档""帮我换回账号""把默认文档改成 XX"）时，**重新走 A→B 询问**，改完**再确认一次**、更新 `config/config.json`。
- 配置文件路径：`<skill目录>/config/config.json`（与 skill 同目录）。字段说明与完整流程见 **`references/首次使用配置.md`**。

# 🎬 华哥脚本撰写 — 短视频口播脚本创作与优化 / Short-video Script Writing Workflow

## 目标 / Goal

为高端产品（客单 5~65w）矩阵账号写出**让观众产生信任、愿意私信咨询**的口播脚本。核心逻辑：**信任 = 信息对称**。高端产品走**人设型**路线——用"往期学员培训案例"叙事建立信任，把知识点穿插进案例里讲，而不是干讲知识、硬广产品。

### 创作理念（三把刀）

每个脚本必须同时运用以下三把刀中的**至少两把**：
- **流量刀**：选题吸引目标人群（研究生/科研人员）。既可用**靶向选题**（精细方向，直击精准用户），也可用**泛内容/流量选题**（宏观科研·论文热点，拉曝光养账号权重，见「内容形态：泛内容 vs 靶向内容」）
- **干货刀**：内容有实际价值，看完能学到东西
- **人设刀**：华哥人设贯穿始终（见"华哥人设要素"）

> ⚠️ **科研论文锚定红线（脱题红线，硬性·最优先）**：无论哪条内容线、无论泛内容还是靶向内容，**每条脚本必须锚定"科研/论文"主线**——正文的干货落点、案例走向、结尾钩子都要指向论文写作 / 科研方法 / 科研生涯决策（选方向、选导师、投稿、复现、消融、申博……），不能漂移到与科研、论文无关的通用话题（职场人际、纯心理鸡汤、泛泛的生活建议）。
>
> **脱题自测（一换便知）**：把脚本里所有"论文/科研/实验/投稿/导师/审稿人/方向/数据/毕业"等科研词，全部替换成"工作/领导/同事/老板/升职"，**内容还能 100% 成立吗？能 → 脱题了，重写**。反面案例：0805脚本5（见「脱题红线」小节）。

## 🧑‍🏫 华哥人设要素

撰写脚本时必须严格遵守以下人设框架：

| 人设要素 | 要求 |
|---------|------|
| **身份亮牌** | 出现「我是华哥」身份词即可（人设锚点，位置自然即可）。⚠️ **教学成果背书（"170 学员"）不强制、不默认每条出现**——「我是华哥，这半年带了170多个学员」这类固定句**禁止逐条复用**（2026-08-29 用户点名：非必要内容，同质化严重）。要立人设/带案例时，可用其他方式（"我带过一个学生……""从审稿视角帮学员看稿""带了几百个学员后发现……"），或仅在真正需要时变体出现一次 |
| **中英夹杂** | 适当使用学术术语英文：Major Revision, Response Letter, Baseline, SCI, Transformer, Ablation Study 等 |
| **结构化教学** | 主体结构清晰、递进有层次，但**表达形式必须轮换**——禁止每篇都用「第一步/第二步/第三步」或「第一招/第二招/第三招」式裸编号列举（0805 五连用"第一道/第一刀/第一看/一证"教训）；可用优先级递进/对比/问答推进/场景串讲/清单平行/时间线/漏斗收窄/分情况/反例正例/数字盘点等轮换（见「🔥 爆款脚本洗稿与借构创作」第四节） |
| **解决方案导向** | 每个问题都必须给出具体可操作的方法，空谈概念不可接受 |
| **评论区转化** | 结尾设计低门槛互动，话术每篇必须不同（见"互动方式设计"章节） |
| **人称** | 全文围绕「你」展开——你的论文、你的审稿意见、你的导师 |
| **背书数据** | ⚠️ **非必须、不强制每条出现**（2026-08-29 用户点名）。是否用"170 学员"数据、放开头还是结尾，**视脚本需要决定**；如用必须变体、且与最近几条错开，**禁止每条脚本都出现同一句 170 数据**；不带 170、只点"我是华哥"也完全成立 |
| **叙事真实性** | ⚠️ **红线规则！** 见下方"叙事真实性红线" |

### ⚠️ 红线规则：叙事真实性（最优先）

华哥的人设定位是"有实战经验的论文辅导老师"，不是"学术大神"或"业界大牛"。身份亮牌必须立足于**教学成果**（带了多少学员、帮多少人中了稿），而不是**个人学术成就**（发了多少论文、有多少头衔）。

**❌ 禁止出现的叙事（红线）：**
- ❌ 自称发了大量顶会顶刊——如"在AI领域发了上百篇顶会顶刊"（全国一年顶会论文就这么多，明显虚假）
- ❌ 自称培养了大牛学生——如"带过的博士生已经是大厂首席科学家"
- ❌ 自称行业第一/唯一——如"XXX领域第一人"、"全国唯一"、"最懂XX的人"
- ❌ 夸大个人学术地位——如"学术界公认的XX专家"、"顶刊审稿人XXX篇"等无法验证的泛化表述
- ❌ 用不切实际的数字堆砌人设——如"指导过上千篇论文"、"审过几万篇稿件"

**✅ 允许的叙事方式：**
- ✅ 基于具体教学成果——「我是华哥，最近半年我们带了超过170个学员成功中稿」
- ✅ 基于教学经验——「带了几百个学员之后我发现……」
- ✅ 基于常见问题观察——「我带的学员里面，超过一半的人都卡在这个问题上」
- ✅ 保持真实感——数据具体（170 vs "几百个"）、时间范围明确（"最近半年" vs "多年来"）
- ✅ 身份定位为"有经验的辅导老师"而非"学术大牛"

> 💡 **核心原则**：人设刀不是靠吹嘘个人成就建立的，而是靠**持续输出有价值的干货**积累的信任感。一句「我带了170个学员成功中稿」比「我发了上百篇顶刊」更有说服力，因为它具体、可验证、符合常理。

### 飞书脚本落盘（写完自动写入飞书文档）/ Feishu Script Upload

> 写完脚本后，把当天作品**自动写入绑定好的飞书文档**（**文档在哪、用哪个账号，都取自 `config/config.json`**——见「首次使用配置」）。三个功能各对应一个文档：**① 爆款脚本的记录** → `config.docs.记录`；**② 爆款脚本的洗稿** → `config.docs.洗稿`；**③ 脚本的创作** → `config.docs.创作`。定位文档用 lark-cli 搜索；"有关飞书文档"若同名多个，**取时间戳最新的那个**。写入前先启动飞书服务（见「飞书素材获取」）。

> **通用落盘规则（硬性）**：以下规则对**所有绑定文档一律适用**——
> - **写入账号 = 配置里的默认账号**：用 `config.feishu.as_flag` 指定的账号（**优先 bot，`--as bot`**；若绑定的是个人账号则 `--as user`）。**一律按 `config/config.json` 记录为准**，不写死任何特定账号；仅当该账号权限异常时，才考虑切换到另一身份。
> - **文字颜色 = 黑色**：写入文档的文字**一律黑色**，**禁止加任何彩色/高亮/背景色**（不要写 `<span text-color=...>` / `background-color` 之类的彩色 span）。正文、标题、标签、封面标题、脚本正文全部用普通黑色文本，保证文档观感统一、纯净。
> - **置顶：日期新的就在最上面**：每次新增当天脚本/爆款，**最新日期块必须顶到文档最上面**，旧日期块依次下移。实现用 `block_insert_after` + `block_move_after`（详见下方 ①② 各自的置顶步骤）。**落盘后必须抓 docs outline 复核**——确认新日期块在最上、内容完整、无错位。
> - **只增查改、禁止删除（红线）**：对绑定文档**只能增、查、改**，**绝不删除**。任何删除动作（删块 / 删日期 / 删内容 / 清空）**必须先询问用户、得到明确同意后**才执行。

## 工作流 / Workflow

### 内容线分配规则（硬性规则）/ Content-Line Allocation Rule

**先定内容线，再选题动笔**——这是每次创建脚本的第一步，由用户一次要求的脚本数量决定是否需要询问：

- **数量 < 10 条**（如"创建 1 条""创建 4 条""创建 5 条"）：**必须先逐条详细询问**用户每条脚本按四条内容线中的哪一类创作：
  - 技术痛点型（40%，主力转化）/ 方向判断型（25%，战略眼光）/ 案例故事型（20%，建立信任）/ 筛选劝退型（15%，精准过滤）
  - 另有一种**泛内容/流量型**（宏观科研·论文热点，拉曝光养权重，见下节「内容形态」）——用户可点名某条做泛内容；未点名时默认在四条线中选。
  - 询问方式示例："这条按哪条内容线写？技术痛点型（40%）、方向判断型（25%）、案例故事型（20%）、筛选劝退型（15%），还是做一条泛内容/流量型（宏观科研热点）？"——逐条问，逐条得到明确答复后才能开始选题与动笔，**不得自行猜测内容线**。若用户回复含糊（如"你看着办"），按当前内容线配比缺口最多的一条分配并告知。
  - 询问内容线属于"怎么做"类问题（CLAUDE.md 允许的提问范围），不是权限请求，放心问。
- **数量 ≥ 10 条**：**不再询问**内容线类型，由 Claude 直接按四条内容线的明确配比（40/25/20/15）自动分配条数，四舍五入凑整（如 10 条 → 技术痛点 4 / 方向判断 2~3 / 案例故事 2 / 筛选劝退 1~2），并按「已覆盖主题清单」选题，保证同一内容线内部及各内容线之间的选题互不重复。其中可安排 **约 10~15% 为泛内容/流量型**（宏观科研·论文热点），其余按 40/25/20/15 分配。

### 内容形态：泛内容（流量破圈）vs 靶向内容（精准转化）/ Content Forms

> 账号是两条腿走路，**不是每一条视频都要高度精细化**。这是账号运营层面的战略（2026-08-06 用户明确口径，补充「精准用户 > 泛观众」：转化靠靶向内容，但账号权重靠泛内容喂）。

| 维度 | 泛内容 / 流量型 | 靶向内容（四条内容线） |
|------|----------------|----------------------|
| **目的** | 拉曝光、养账号权重、为出爆款打基础 | 精准吸引目标用户、快速筛选、开单 |
| **选题** | 宏观科研/论文大方向、热点事件、趋势话题（借势热点 + 时效性） | 精细方向：Transformer/CV 架构/LoRA/消融/复现/投稿…… |
| **精度** | 可以很泛，不追求高精度 | 高精度、直击卡点 |
| **转化** | 一般不直接开单 | 直接筛选高意向用户 |
| **平台算法** | 泛内容流量大，喂高账号权重，利于后续视频数据与爆款 | 流量相对小，但私信质量高 |
| **占比建议** | 约 10~15%（按内容线分配规则执行） | 40/25/20/15 |

- **泛内容选题示例**（全部仍锚定科研/论文）："SCI 到底值多少钱" "大模型时代，读研还值不值" "某学生几十篇 SCI 上热搜，真的假的" "高校论文 AI 造假上新闻，跟你有什么关系" "读博还是工作，2026 该怎么选" ——**讲的是大的、有热点的方向，而不是精细技术**。
- **泛内容素材来源（浩源三把刀·流量选题）**：打开抖音热榜，找跟"大学生/研究生/科研/论文/AI 教育"相关的热点话题去讲；注意**时效性**——热点过期再发等于白做（参考 `浩源自媒体课1.0第二节.md`——位于 `<base_dir>/`，打包分享版自带；本知识库中原位于 `总结好的大纲以及笔记/浪尖训练营/自媒体训练营/浩源自媒体课1.0/浩源自媒体课1.0第二节/`；三把刀与时效性章节）。
- **两条腿都必须锚定科研/论文（硬性·脱题红线）**：泛内容再泛，也必须是"科研/论文相关的大话题"，**禁止泛到与科研、论文完全无关**（0805脚本5 教训：讲"导师画饼三证"，换成职场/领导场景 100% 成立，与论文毫无关联，判脱题）。
- **三条内容来源可并用**：①四条内容线（靶向）；②知识库自媒体课程文档（浩源三把刀·流量/干货/人设，泛内容与结构优化来源）；③受众报告画像与痛点。创作脚本时优先从学员真实卡点（素材反推）选题。

### 选题禁忌（硬性规则·反面案例）/ Topic Taboos (Hard Rule)

**选题永远从学员的实际学术卡点出发，禁止以"论文辅导/辅导服务"本身为话题**。观众点进来是学论文知识的、是来找共鸣的，不是来看"辅导机构的经营理念"的。服务身份只作为**人设暗线**（学员案例 + 结尾转化），不能成为选题和正文主线。

- **反面案例（0802脚本5）**：《论文辅导前，先问自己三个问题——答不上来，别找我》（筛选劝退型）。错误点：
  - 选题与正文通篇围绕"论文辅导"展开（"来找我之前先自测""该不该找辅导""别急着找我"）——观众一眼看穿是辅导机构广告；哪怕是劝退话术，本质仍是"欲擒故纵"式自我标榜，评论区极易被喷"装清高""不就是卖课的"；
  - 内容零干货：全片没有给观众任何论文写作/科研的实质方法，观众学不到东西，信任立不住，转化无从谈起。
- **禁止类选题句式（出现即换）**："论文辅导前先XX""该不该找论文辅导""论文辅导避坑""找辅导被坑的N种方式""论文辅导值不值"——凡把"辅导/找老师/课程/机构"当选题主语的，一律禁止。
- **正确写法（筛选劝退型同样适用）**：选题从卡点出发，如"实验没跑通就发愁？先做这三件事"——正文给足干货（怎么做），学员案例自然穿插立人设，结尾再带筛选动作（"做完还卡住，你再来找我"）。全片不得出现"我们是专门做论文辅导的"类自述；"辅导/找老师"在选题中零出现、正文中低频出现。
- **自检测试（选题立没立住，一换便知）**：把脚本里所有"老师/辅导"换成"学长"，内容还成立吗？成立 → 选题立住了（讲的是论文方法论）；不成立 → 内容全在讲辅导关系，选题错了，重选。

### 脱题红线（硬性·反面案例）/ Off-Topic Red Line

**选题可以宏观、可以泛，但绝不能脱科研/论文**。所有内容线（含泛内容/流量型）的正文都必须落到"论文写作 / 科研方法 / 科研生涯决策"上，不能变成通用的职场、人际、心理建议。

- **反面案例（0805脚本5）**：《导师画的饼能吃吗？三证验出来，两分钟够用》（筛选劝退型）。错误点：
  - **干货与科研无关**：三证（成文记录 / 毕业数据 / 落实动作）是"验证一句口头承诺靠不靠谱"的通用建议，换成职场场景（领导画饼、老板许诺升职）100% 成立——全片没有一句论文写作、科研方法、实验、投稿的实质内容，**与科研、论文辅导严重脱节**；
  - **选题跑偏**：从"导师口头承诺"切入，讲的是信任与证据，不是学术卡点；观众进来学不到科研方法，信任立不住，转化悬空；
  - **高危表达集中**："画饼""保你毕业""拍着胸脯""感动得一塌糊涂""两手空空"——既有教育广告违禁词（保你毕业），又有情绪化高危表达（见「平台违禁词」）。
- **正确写法（同样题材怎么救回来）**：把"验证口头预期"落回科研主线——案例必须走向"调整科研策略→完成论文"、落点必须是"科研主动权"，全片围绕"毕业这件事能不能用论文/科研动作闭环兜住"，让观众记住的是科研方法而不是泛泛的"别信口头话"。改进版对照全文见 `references/对标案例.md`。
- **脱题自测（一换便知）**：把脚本里所有"论文/科研/实验/投稿/导师/审稿人/方向/数据/毕业"等科研词替换成"工作/领导/同事/老板/升职"，**内容还能 100% 成立吗？能 → 脱题，重写**。成立不了 → 锚定住了（讲的是科研/论文）。
- **禁止类选题方向（出现即换）**：纯职场人际（"怎么判断领导画饼"）、纯心态鸡汤（"别内耗，行动起来"）、纯生活建议（"研究生三年怎么过"）——只要正文不含科研/论文方法或科研决策的实质内容，一律重写。

### 平台违禁词（硬性规则）/ Platform Banned Words

**脚本与推文一律禁止写出平台违禁词**——文字稿会被平台审核，命中违禁词直接被打标签限流，账号权重受损，作品白做。**视频与推文一视同仁**（正文、标题、标签、封面文字全要查）。

- **绝对禁词（出现即删/换）**：
  - 脏话辱骂类：妈的、卧槽、操、傻逼、去死、滚、你大爷……
  - 死亡暴力类：死、杀、自杀、杀人、打死、该死、判死刑、死定了……
  - 政治敏感、色情低俗、赌博毒品等其他平台敏感词一律不写。
- **口语里的"死"也要避开**："想死的心都有了"→"心态崩了"；"判死刑"→"别急着下结论"；"打死我都不信"→"谁信啊"；"送命题"类边缘词也慎用，拿不准就换。
- **教育广告合规词（硬性，高危）**：教育/学术类目平台严打"结果承诺"——**保过 / 包过 / 保证中稿 / 保你毕业 / 稳上 / 必过 / 内定 / 100% 通过 / 承诺 XX**，出现即删/换。"包中稿"已在强推销词黑名单；"保你毕业"这类"保"字结果承诺是 0805脚本5 的教训，一律换客观表述（"乐观的口头预期"→ 用"落地保障""客观核验"等中性词）。
- **高危情绪表达（降质 + 易限流，换中性词）**：**画饼 / 拍着胸脯 / 一塌糊涂 / 感动得不行 / 当场清醒 / 两手空空 / 心凉 / 凉凉（慎）** 等情绪化、口语化的夸张表达，换成中性客观的说法（画饼→口头预期/期许；拍着胸脯→口头；一塌糊涂→直接删掉或改"心里没底"；两手空空→陷入被动）。**连评论区扣词也不能用高危词**（0805脚本5 扣"画饼"→ 改进版扣"核验"）。
- **自查时机（交稿前必做）**：通读一遍，逐字扫标题、正文、标签、封面文字；**拿不准的词宁可换掉**——情绪强烈时用"崩/完蛋/天塌/踩雷/没戏"等替代。
- 完整对照表与替换词：`references/语言规范.md` 第八节。

### 第 1 步：判断视频风格 / Style Decision（人设/干货/流量）

- 视频分三种：**人设型**（建立信任）/ **干货型**（拉关注）/ **流量型**（破圈）。
- 判断依据是**产品价位**：高端产品（5~65w）→ **人设型**。人设型 = 学员案例叙事为主、知识点穿插、让观众觉得"这老师真的带出了学生"。

### 第 2 步：7 步结构搭骨架 / 7-Step Structure

严格按结构表的七步：**抓人眼球 → 呈现结果（塑造1）→ 制造反差（分割线）→ 塑造价值（塑造2）→ 给出指导（结构轮换，见下）→ 举例佐证（递进句式轮换，见下）→ 临门一脚（信息/观点/行动启发）**。

- 开头（抓人眼球）用**黄金三秒 10 种钩子**之一：好奇悬念/痛点需求/价值承诺/逆向反转/挑战极限/借势热点/数据数字/盘点列表/代入场景/互动提问。
- **黄金三秒硬性三要素（2026-08-06 起，补对标案例开头三步曲）**——前三句内必须同时出现：
  1. **"你"**（浩源：所有开头都离不开"你"，一旦脱离"你"就完蛋）——开头第一句主语指向观众；
  2. **价值承诺或痛点**——让观众 3 秒内知道"这条跟我有关 / 能给我什么"（"两分钟用三项依据核验，避免后续被动！"式），**价值必须在前三句亮出**；
  3. **科研/论文元素**——锚定脱题红线，开场即点出论文/科研/实验/投稿/方向等科研语境词。
- **场景细节最多 1 句，禁止整句铺情绪**（0805脚本5 教训："导师拍着胸脯…感动得一塌糊涂…转头又熬了三个通宵"——三句都在铺与干货无关的情绪，第 4 句才出"停！"，观众早划走了）。要铺场景就用**一句带科研细节的场景**（"对着空白文档憋了一个月连个引言都写不出来？"），第二句立刻否定错误做法，第三句亮价值/反转。
- **开头三步曲效率版**：① 一句科研痛点场景（带时间/结果细节）→ ② 否定错误做法（别再/千万别）→ ③ 价值承诺或反转结论（"90% 的研究生都死在主次不分上"→ 换"大多数人都卡在主次不分上"规避"死"字）。
- **"给出指导"结构必须轮换（硬性，防同质化核心）**："三个关键步骤"三步法已被 8 篇作品连续复用，**禁止连用**——连续两条作品不得用同一种指导结构，三步法**隔 3 条以上才可用**。可用结构：四步法/一坑一解/对比式/清单式/漏斗式/时间线式/问答式（完整定义与轮换规则见 `references/反同质化.md` 第二节）。递进句式同步轮换（"第一关…第二关…"、"先说最要命的…再说最省事的…"），**骨架变才叫创新，光换词还是同质**。
- **表达形式必须轮换（硬性，2026-08-24 用户点名）**：结构轮换只保证"骨架不同"，**表达形式轮换才保证"看着不一样"**——中间干货部分怎么组织（裸编号列举/优先级递进/对比/问答推进/场景串讲/清单平行/时间线/漏斗收窄/分情况/反例正例/数字盘点）连续两条作品不得相同，同形式至少隔 3 条。**裸编号列举"第一X/第二X/第三X"已进黑名单**（0805 五连用"第一道保险/第一刀/第一看/一证"的教训）。轮换库见「🔥 爆款脚本洗稿与借构创作」第四节。
- 每一步的写法要点与结构表案例的参考写法：`references/结构方法论.md`。

### 第 3 步：案例叙事（人设型的灵魂）/ Case Narrative

- 用**往期学员培训案例**讲故事：知识点穿插进案例，不干讲知识点；导师一句话、学员一个动作、一段心理，比十句道理有用。
- 素材来源两层：
  - **学员感悟.md**（学员视角）：心理活动、卡壳细节、深夜发消息、面对空白文档发呆、长舒一口气……（PASS 原则：地点+动作+话术+内心所想）
  - **案例文件（老师视角）**（指导视角）：从卡壳到中稿的完整过程与数据。
- **硬性规则**：虚拟组合形象——不出现真实网名（薯饼/小黄鸭等）和机构名（图灵学术等）；技术事实必须自洽（显存、参数量、训练时间、涨点数字不能有逻辑错误）。
- **案例引入硬要求**：进入学员叙事前，必须先用"我有个学员""带过一个学生""这个学员"类**人设点明句**把"我是带出过学生的老师"立起来，再展开故事——不能一上来就用"他"指代，观众不知道这个"他"是谁、与博主什么关系，信任就立不住。整条脚本从头到尾都要让观众能对上号：这个学员是"我的学员"。
- **引入句/细节/叙事骨架轮换（硬性，防同质化）**："我有个学员"已被 6 篇使用、"半夜发消息"被 5 篇使用——案例引入句、时间细节、反应细节、导师原话引入都按 `references/反同质化.md` 第四节的轮换库换着用（连续两条不同，同一细节至少隔 3 条；同一条作品内同类细节不超过 1 个）。叙事骨架（学员卡壳→老师点拨→中稿直线）也要轮换：成功翻盘/反转警示/对比/时间线/悬念倒推/教训型换着来。
- 素材速查：`references/案例素材库.md`；轮换规则：`references/反同质化.md` 第四、六节。

### 第 5 步：长度控制 / Length Control

- **正文 650 字左右（600~700 字区间，约 2~2.5 分钟口播）**。这是用户明确的硬指标（2026-08-04 更新：原 900~1000 字调整为 650 字左右）。⚠️ **豁免：洗稿场景不受此条约束**（2026-08-30 用户点名，见「🔥 爆款脚本洗稿与借构创作」洗稿工作流「洗稿不设字数约束」红线）——洗稿只做内容转换，字数多或少都保留，不做 650 字删补。
- 太短（<550 字）像预告片、营销味重、说服力不足；太长（>750 字）没人看完。
- **字数口径（必须遵守）**：650 左右指**去掉空格与标点后的字数**（中文按字计，英文/数字按连续串计），约等于含标点的 750~800 字体量。**交稿前必须按此口径自己数一遍**，不能凭"口播时长"估算。
- **压缩守则（0804脚本1 教训，硬性）**：压缩 ≠ 删干货。压缩顺序：先删过渡句 → 再删次要心理细节 → 再压缩表达（"记录→记""回答→答"）→ **最后才轮到干货句**。技术痛点型的"干货落点"（观众能直接拿走的具体操作清单/方法步骤）**必须保留**——它既是内容价值，也是结尾资料钩子（"我把XX清单发你"）的正文依据，删掉后钩子悬空、信任立不住。压缩后必须对照原版逐句回读审视，每处删除都要能说出理由；删不动的就换一种表达腾字数。完整案例见 `references/实战案例.md` 第五节。
- 与"结尾收法轮换"配合：篇幅是质量底线，结尾是新鲜度。

### 第 6 步：开头结尾轮换 + 去营销味 / Fresh Openings, Endings & De-Marketing

- **每个新脚本（或每次优化）的开头、结尾结构必须与之前不同**。这是用户明确强调的硬要求。
- 轮换库：开头 9 句式（高价值/打赌/代入场景/同情反思/明明知道但还是/正案例提问/选择题/倒计时/假设）+ **结尾收法 8 类**（信息启发/观点启发/行动启发/资料钩子/IP 强化/夸观众/悬念预告/筛选劝退），完整库、示例与轮换机制见 `references/结构方法论.md`。
- 动手前先看 `创作好的脚本/` 与 `创作好的推文/` 各日期文件夹的**合集文档**（`MMDD脚本合集.md` / `MMDD推文合集.md`）里**最近 5 版**的开头结尾：结尾收法类型不得与最近版本重复（同类型至少隔 3 条再出现），开头 9 句式也不重复。
- **IP 句必须变体**：结尾的"我是谁 + 我的价值在哪"不得逐字重复固定锚点句"我是华哥，专做 AI 方向论文，这半年，170 多个学员中稿"。170 学员/价值信息每次换一种说法（变体库见 `references/结构方法论.md` 第六节），"我是华哥"身份词可保留。⚠️ **IP 句不要求每次必须带 170 学员**（2026-08-29 用户点名）——价值点可用"帮你看清论文卡在哪""陪你把论文发出去"等不带数字的表达，不带 170 也完全成立；170 只在真正需要立人设时变体带一次。
- **金句骨架黑名单（硬性，防同质化）**：以下金句骨架已被用烂，**骨架级禁用**——"审稿人不怕X，怕Y"、"问题不在X，在于Y"、"不是X，是Y"式反转、"结果决定下限，XX决定上限"、"XX不是YY，是ZZ"、"这行字是你论文里性价比最高的XX"。自检方法：把正文里任何一句"金句"的主语换掉，**还能装进别的历史脚本，就是骨架雷同，必须重写**（完整黑名单与自检见 `references/反同质化.md` 第三节）。
- **立意新鲜度（硬性）**：每篇作品必须携带**信息增量**（四选一：新角度/新素材细节/新结论/新比喻），核心立意与「已覆盖主题清单」逐条比对——**核心道理相同即使案例用词全换也是重复**（推文3 教训：案例素材全换仍与脚本2 立意雷同被判废稿）。交稿时登记立意到选题库供下次比对。
- 结尾强化 IP 公式：**我是谁 + 我的价值在哪 + 引导动作**；不直接要三连、不夸观众过头、不用"想要的在公屏打出XX，华哥发你"这种重复句式。
- **咨询钩子话术也要变体**："私信我【方向+学历+卡在哪个环节】"这类带【】的固定句式禁止逐字复用——信息点（方向/学历/卡点）固定，但每次换一种说法自然带出（变体库见 `references/结构方法论.md` 第六节）。这是用户明确点名的重复问题。
- **结尾钩子三段式（硬要求，仿结构表第七步"临门一脚"）**：结尾不能只是收束，必须能跟观众互动。三段式：①**收束确认句**（"你看，逻辑就是这么简单""你细品一下这套逻辑"式，像跟朋友聊天）→ ②**启发点破**（点难点或升华价值）→ ③**条件式互动指令**——给理由 + 给动作 + 给具体东西（"如果你听完，不知道怎么操作，那就去评论区找我要XXX"式；动作 = 评论区扣词/找我要/私信发我；东西 = 文档/清单/对照表/书/诊断等具体交付物）。禁止只有抽象引导（光一句"私信我"或光一个"关注我"都不算钩子）；筛选劝退类收法劝退完必须给入口，不能只有拒绝没有邀请。模板与结构表原句见 `references/结构方法论.md` 第六节。
- **开头三步曲（对标案例 2026-08-05 硬性标准，替代"共鸣提问式"开头）**：① 具体痛点场景（含时间/结果细节："对着空白文档憋了一个月连个引言都写不出来？"）→ ② 否定错误做法（"别再傻傻坐在电脑前硬憋了！"/"千万别一上来就硬啃代码"）→ ③ 反转承诺或数据结论（"论文根本不是'写'出来的，而是按顺序'填'出来的！"/"90% 的研究生都死在主次不分上"）。黄金三秒制造冲突，不建立共鸣铺垫。
- **方法命名化（硬性）**：每个方法步骤必须有名字——动词+名词（填空法/找空位）、对仗短句（话要软，证据要硬）、比喻词（文献地图/宝藏论文）、热词（做题家）、主题词（问心态/问思维/问问题/问出口）。禁止只有功能描述没有名字。
- **"别人vs你"对比画面**：正文至少 1 处差距感画面（"别人的实验还在报错装包，你的代码已经跑起来了！"）。
- **结尾三段式模板 = 骨架，不是填空模板（2026-08-06 起重要修正）**：① 闭环总结句 → ② 资料钩子 → ③ 咨询钩子，三级漏斗（扣词 1 秒 → 资料包 → 私信咨询）的**结构**保留，但**句式禁止原样套用**。0805 五条脚本逐字复用同一套模板句式，已构成新的"结尾高度重复"（用户点名）。⚠️ 以下模板句式已进**结尾句式黑名单（骨架级禁用，换词不算翻新）**：
  - ❌ "做科研XX，最怕XX。你要把它（写/做）成一个闭环：A怎么X，B怎么X，C怎么X，D怎么X。"
  - ❌ "如果你也卡在XX，我整理好了XX清单/方案包，想要的，评论区打'XX'，华哥安排！"
  - ❌ "或者你想更快拿下自己的论文成果，我们这边也有现成课题，顶会顶刊导师一对一科研诊断…让你少走弯路！"
  - **必须翻新**：闭环总结句换句式（"做科研，最怕XX"→"科研这条路上，最容易翻车的不是XX"）；资料钩子换引导词（"评论区打'XX'华哥安排"→"评论区留个'XX'，我把清单单独发你"等互动话术变体）；咨询钩子换措辞与服务名目。**三段式的三个信息点（闭环价值 / 资料交付物 / 咨询入口）保留，但每段的句式、措辞、过渡词至少各换一处，与最近 5 版结尾逐句比对不雷同**。
  - 结尾句式黑名单同时登记进 `references/反同质化.md` 症状清单。
- **案例压缩四要素（650字版）**：人物身份 + 一个关键动作 + 导师一句话 + 可核验结果 + 时间；长度 70~100 字；删学员原话/心理细节/对话过程——案例是证明工具不是叙事主角。
- **背书场景化**：170 学员数据与本期主题绑定（"其中一多半被放养的学生，都是靠这种'填空法'把论文跑通的！"），而非固定锚点句。
- **去营销味（每条脚本必查）**：
  - 转化动作不堆叠：结尾只保留 **1 个主转化钩子**（资料钩子"评论区扣词" 或 咨询钩子"私信" 二选一，轮换使用），最多再加一句轻引导；"扣词+私信+关注"全家桶 = 营销味。
  - 强推销词黑名单：赶紧/名额/错过/上车/免费领/限时/包中稿/手把手带你，出现即改。
  - 结尾前加一句自然过渡（"好了，这条就到这儿"），让结尾像下课聊天，不像广告结束。
- 示例（人设型结尾 + IP 句变体）："行，这条就到这儿。我是华哥，这半年，手机里 170 多封学员的中稿通知，一篇篇都是真的。数据没跑稳的，拿不准的，私信我，我帮你看。"

### 第 7 步：钩子漏斗 / Hook Funnel（临门一脚强化）

三级漏斗：**内容钩子**（拉留存）→ **资料钩子**（进资料粉，评论区扣关键词领资料）→ **咨询钩子**（进精准咨询粉）。

- 内容钩子（拉留存，主体中穿插使用，至少 2-3 种）：**与你有关**（"你论文里的图表"）/ **省时省力**（"花最少的时间找到你的修改"）/ **焦虑驱动**（"审稿人没有耐心在你的图里找结论"）/ **好奇心**（"今天我把内部方法拆给你看"）/ **过来人经验**（"170 个学员的数据告诉我们"）/ **权威背书**（"标准做法是……"）。
- 咨询钩子 9 种子类型：诊断导向/方案导向/解惑导向/规划导向/对症下药/时间VS机会成本/1v1拆解/目标差距评估/导师价值预告。
- **信息点固定，话术必须变体**：咨询钩子要收集【研究方向 + 学历 + 卡在哪个环节】三个信息点，但表达话术每次换一种说法（变体库见 `references/结构方法论.md`），**禁止带【】的固定句式逐字复用**（"私信我【方向+学历+卡在哪个环节】"类句子不得出现）。
- 9 种话术方向与变体库：`references/结构方法论.md`。

### 互动方式设计（评论区扣词形态细化）/ Interaction Design

> **核心原则**：每篇脚本的互动话术必须不同 + 互动门槛必须极低。与"结尾收法轮换""反同质化"规则联动——互动形态、关键词、引导措辞三项中至少两项与历史不同。

**为什么不能重复使用同一句互动话术？** 抖音算法会识别内容同质化程度。同一个账号连续多条视频用一模一样的结尾话术，系统会判定内容重复度高，影响推流。同时观众刷到相似结尾也会产生审美疲劳，降低互动意愿。**所以每篇脚本的结尾互动，都要让观众感觉是新的、是为这篇内容专门设计的。**

#### 互动方式设计四步法

| 步骤 | 操作 | 示例 |
|:---:|------|------|
| **① 查重** | 查阅历史脚本的"互动方式"记录清单，排除已用过的互动形态 | 上篇用了"扣1"，这篇就换"表情打卡" |
| **② 选题关联** | 互动方式与脚本主题挂钩，让互动看起来自然 | 选刊主题→"扣1"；英文写作主题→"打个😂" |
| **③ 定关键词** | 确定评论关键词，必须是2字中文短词或更简单的方式 | ✅"敲门" ✅"选刊" ✅😂 ✅"111" ❌"Cover Letter" |
| **④ 写话术** | 把互动自然嵌入结尾总结之后 | "觉得有用点个赞，我看看多少人需要这个" |

#### 10 种互动形态详解

| 形态 | 适用 | 话术示例 | 门槛 |
|------|------|----------|:---:|
| **扣1/扣2** | 干货型脚本，多个方法让用户选择 | 「觉得第一招有用的扣1，第二招有用的扣2，想看全流程的扣3」 | ⭐⭐（打2个键） |
| **表情打卡** | 痛点型、共鸣型内容 | 「被导师这样拖过的评论区打个😂」 | ⭐（一键发送） |
| **点赞统计** | 通用型，任何脚本都能用 | 「觉得有用点个赞，我看看还有多少人在这个问题上卡着」 | ⭐（双击屏幕） |
| **投票选择** | 争议性话题或 AB 选择 | 「你觉得是方法问题还是心态问题？评论区告诉我」 | ⭐⭐（打1-2个字） |
| **对号入座** | 群体标签类内容 | 「导师亲自改的扣1，导师放养的扣2，导师不管的扣3」 | ⭐⭐（打1个数字） |
| **数字接龙** | 步骤型、流程型内容 | 「已经改完第一步的打个1，改完第二步的打个2」 | ⭐⭐（打1个数字） |
| **AB选择** | 对比型内容 | 「你站A方法还是B方法？评论区告诉我」 | ⭐⭐（打1-2个字） |
| **赞藏引导** | 信息密度高的干货型内容 | 「信息量比较大，先点赞收藏免得划走找不到」 | ⭐（双击+收藏） |
| **提问引导** | 互动型内容，后续可做答疑视频 | 「你写论文最卡的是哪一步？评论区告诉我，下期我专门讲」 | ⭐⭐（需打字） |
| **填空互动** | 轻松话题 | 「你的论文到哪一步了——预审稿中了评论区告诉我」 | ⭐⭐（打2-4个字） |

#### 关键词设计铁律

| 规则 | 说明 |
|:----|------|
| **最长 2 个中文字** | 如"敲门"、"选刊"、"标题"、"润色"、"图表" |
| **禁止英文长词** | ❌ Cover Letter、Response Letter、Supplementary Material |
| **禁止超过 4 字** | ❌ "论文返修模板"、"图表设计方法" |
| **可使用数字** | "111"、"666"、"888" |
| **可使用表情** | 😂、👍、❤️、🔥 |
| **必须 2 键内完成** | 用户在评论区打出关键词的操作不超过 2 次点击 |

#### 互动话术创新示例库（"评论打关键词"形态的变体）

```
变体1：「模板我都整理好了，评论区打「关键词」，我直接发你。」
变体2：「需要模板的，评论区打「关键词」，私信发你。」
变体3：「评论区打「关键词」，我把资料包单独发你。」
变体4：「想要完整版的，评论区写「关键词」，我一个个私。」
变体5：「拿模板很简单，评论区打「关键词」，马上发你。」
变体6：「评论区回「关键词」，我直接把整理好的资料发给你。」
变体7：「评论区留个「关键词」，我挨个给你们发资料包。」

```

使用原则：不仅换关键词，换引导措辞，也换互动形态。多条视频可以用多种完全不同的互动方式。

新脚本固定栏目格式（与历史脚本一致）：

- **保存位置（日期合集文档模式，硬性）**：相同日期的脚本统一存放在一个日期文件夹 `总结好的大纲以及笔记/实习就业/创业黑马——数智科技部门/工作文件/脚本&推文撰写/脚本资料库/创作好的脚本/MMDD脚本/`（如 `0802脚本/`）下，**当天所有脚本合并为一个合集文档 `MMDD脚本合集.md`**（如 `0802脚本/0802脚本合集.md`），每篇脚本作为合集内的一个 `## MMDD脚本N` 章节（含完整栏目与正文）；日期不同就新建对应日期文件夹（`0803脚本/`、`0804脚本/`……）。**当天创作的新脚本直接并入当天合集文档（无合集先创建，追加章节 + 更新索引），不再生成单篇散文件**——日期文件夹内最终只有合集文档 + 用户放的封面图等素材（素材与脚本同目录管理）。N 递增：0802脚本1 → 0802脚本2 → 0802脚本3。若历史遗留有单篇散文件，整理时将其并入合集文档后删除散文件（内容无损，互链改锚点）。合集文档结构见下方「合集文档结构（视频与推文通用）」。
- **优化版追加在文档末尾，旧版本不删除**，每版用小标题标注版本名（如"优化版（按7步结构）"、"第三版（融合学员感悟·真实案例心理细节版）"）。

**合集文档结构（视频与推文通用，硬性）**：日期文件夹内以 `MMDD脚本合集.md` / `MMDD推文合集.md` 一个文档呈现当天全部作品：

## 推文脚本撰写（文字平台）/ Written-Post Script

> 用于**抖音图文**/小红书/微博/朋友圈/公众号等**文字平台**的文案。**推文与视频脚本本质相同，只是篇幅与语言不同**——写法参照视频脚本（华哥口吻 + 7 步结构 + 案例叙事），素材直接使用本地脚本素材库（学员感悟/案例文件/结构模板/受众报告/选题库），结构、规则与视频无差异。推文分两类题材：**①知识分享类/案例解释类**（主力形态，与视频选题同构：从选题库选未覆盖主题，走视频 7 步结构）；**②招生推文类**（服务说明型，走 8 段式，见 `references/推文案例库.md`）。账号主战场是抖音，创作前必须查重防重复。

### 推文 vs 视频差异（用户明确标准）

| 维度 | 视频脚本 | 推文脚本 |
|------|----------|----------|
| 篇幅 | **650 字左右**（600~700，不含空格标点） | **600~800 字**（不含标签与空格标点） |
| 语言 | 口语化多、语气词多、短句多 | 口语化少、**书面精练**、**废话少**、信息密度高（知识点/信息点全面） |
| 术语 | 专业术语要通俗化（显卡/陪跑的位置） | **同样通俗化**——简单易懂，不能通篇专业术词（观众看一眼就划走）；只是比视频更精练 |
| 案例 | 虚拟组合形象，不点名真实院校 | **可点名名校分层背书**（清华/中科院/北邮），普通院校打码"xx学院" |
| 受众 | 泛流量池，易被喷，服务身份只能暗线 | 精准用户池（主动搜索而来），**可直接讲服务能力** |
| 节奏 | 靠声音与口播节奏 | 靠**换行分段留白**，段落即节奏 |

### 推文结构：与视频同构 + 8 段式（仅招生推文）

**知识分享类/案例解释类推文**（主力形态）：与视频脚本**完全同构**——从 `references/选题库.md` 挑未覆盖主题（查重），直接套用视频工作流的 7 步结构（第 2 步）与全部方法论：10 种开头钩子、案例叙事（PASS）、语言打磨（去 AI 味）、开头结尾轮换、IP 句变体、去营销味、结尾钩子三段式——**只是篇幅（600~800 字）与语言（书面精练、术语同样通俗化）不同**。素材直接用本地脚本素材（学员感悟/案例文件），案例细节回读原文。此类推文适用内容线分配规则（<10 条逐条询问内容线，≥10 条自动按 40/25/20/15 分配）。

**招生推文类**（服务说明型，不适用选题禁忌红线）用 8 段式：

1. **人设钩子**：第一句带结果数字 + 情绪化表达（"今年带出十几篇A会"），立人设抓眼球
2. **服务承诺 + 风险预期管理**：讲清服务范围，同时主动说清不确定性（"顶会有随机性，我们也只能保证文章质量这块"）——**信息对称，反而可信**
3. **团队背书**：数据数字 + 中稿战绩 + 团队构成（"16篇CCFA，8篇CCF B""今年中稿 ICCV2025、ICLR2025、CVPR2025"）
4. **分层案例**：两档对照——基础差学员也能带出成绩（"xx学院也发了CCF"）/ 资质好学员更上层楼（"南开、中科院、复旦、清华、北邮…保研top2、CMU交换、CS排名前30博士"）；**名校点名、普通院校打码**
5. **初衷情怀**：为什么做这件事（"被导师耽误的学生""0-1的转变"），立真诚人设
6. **能力清单**：可带方向 + 资源（"llm、mllm、ml、cv、具身智能、diffusion、自动驾驶、ai4science…有现成idea，算力可协调使用"）
7. **目标承诺**：具体时间表（"target会议：暑假AAAI、10月ICLR、11月CVPR"），把服务落成可预期动作
8. **标签**：7~11 个高流量标签（#计算机申博 #llm #sci论文辅导 #顶会论文 等）

**合并规则**：段落间**不写过渡句**，留白即节奏；8 段可按篇幅合并（如 2+3、6+7），但 1 人设钩子、4 分层案例、8 标签一般保留。

### 推文写作规则

- **写法参照视频脚本**：华哥口吻、7 步结构、案例叙事，与视频完全同构——不要"照搬别人的推文"，按华哥的方式讲自己的案例和方法论。
- **素材与视频完全共用**：学员案例直接用本地脚本素材库——`学员感悟.md` / `案例文件（老师视角）` / 结构模板 / `受众报告` / `选题库`；案例细节写前回读原文，数据真实、技术自洽、不编造；同一案例视频用过，推文可换角度复用。
- **内容线适用**：知识分享类/案例解释类推文同样适用内容线分配规则（见工作流顶部：<10 条逐条询问，≥10 条按 40/25/20/15 自动分配，其中可含约 10~15% 泛内容/流量型）；同样受脱题红线约束（一律锚定科研/论文）。
- **复用视频方法论**：开头用 10 钩子之一、结尾用 8 收法之一且与最近版本错开、咨询钩子信息点自然带出、IP 句变体（不逐字重复"我是华哥，专做 AI 方向论文，这半年，170 多个学员中稿"锚点句）。
- **语言精练但通俗（用户硬性要求）**：**废话要少**——有限篇幅里把知识点、信息点尽量讲全（每句都有信息量，删掉所有废话连接词）；但**术语同样要通俗化**（同视频：全参微调→"把模型全部重新训练一遍"，baseline→"对比的基准"），不能通篇专业术词——观众一眼看不懂就划走了。写法：专业概念换大白话或首次出现带一句简短解释，但解释要精练，不啰嗦。
- **少口语、零废话**：删语气词，每句都要有信息量；用换行分段代替口头节奏。
- **分层背书规则**（招生推文类用）：名校直接点名（清华/中科院/复旦等），普通院校用"xx学院"打码——真实可信，不消费弱势院校。
- **红线继承（硬性）**：强推销词黑名单（赶紧/名额/错过/上车/免费领/限时/包中稿/手把手带你）、选题禁忌、平台违禁词全部继承——标准案例中的"手把手"是原文用词，华哥推文要改写（如"从选题到写作全程跟"）；**不空头承诺，每个承诺配证据**（数据/案例/团队/资源）。

### 推文查重（硬性规则）/ Anti-Duplication

**重复率必须低，这是硬性要求**——与视频脚本同理。账号主战场是**抖音**，平台对重复/搬运内容限流，推文若与历史已发布内容重复，权重会被压低、转化归零。**每次创作前必须查重，创作时不查重 = 废稿**。

1. **查重范围**：**视频脚本**在 `总结好的大纲以及笔记/实习就业/创业黑马——数智科技部门/工作文件/脚本&推文撰写/脚本资料库/创作好的脚本/`（按日期文件夹 `MMDD脚本/` 聚合）、**推文**在 `总结好的大纲以及笔记/实习就业/创业黑马——数智科技部门/工作文件/脚本&推文撰写/脚本资料库/创作好的推文/`（按日期文件夹 `MMDD推文/` 聚合）——两处**全部历史内容**（含各版本）都要扫，不止最近几版，**视频与推文跨类型互查**。
2. **查重对象**（逐项核对，任一重复即换）：
   - **主题/选题**：对照 `references/选题库.md`「已覆盖主题清单」+ 扫描全部脚本标题，不得与任何历史视频脚本或推文主题重复；
   - **核心立意**（防同质化关键维度）：立意 = 一句话概括"这篇讲的核心道理"，与「已覆盖主题清单」登记立意逐条比对——**核心道理相同即使案例/用词全换也是重复**（推文3 教训）；每篇必须有信息增量（新角度/新素材细节/新结论/新比喻之一，见 `references/反同质化.md` 第三节）；
   - **给出指导结构**：不得与最近一条作品同型（三步法隔 3 条以上，结构轮换见 `references/反同质化.md` 第二节）；
   - **开头句式**：不得与历史推文/视频的开头结构重复（10 钩子轮换）；
   - **结尾收法**：不得与最近版本重复（8 类轮换，同类型至少隔 3 条）；
   - **关键句式/话术**：承诺句、预期管理句、案例句式、钩子话术不得整句或近义雷同——句式库只能作结构参考，**用词必须翻新**；金句不得命中黑名单骨架（见 `references/反同质化.md` 第三节）；
   - **标签组合**：不得与历史推文标签完全一致（会议词/领域词可复用，但组合要变）；
   - **案例素材**：同一学员案例不重复使用（视频用过的案例，推文换案例或换角度）；复用间隔 ≥3 条且换角度（见 `references/反同质化.md` 第六节）。
3. **登记机制**：每条推文交付后，将主题登记到 `references/选题库.md`「已覆盖主题清单」（标注"推文"），保持查重闭环。

推文栏目格式与视频脚本**完全一致**（同构模板），只把"脚本"二字换成"推文"：

- **保存位置（日期合集文档模式，硬性，与视频脚本同理）**：相同日期的推文统一存放在一个日期文件夹 `总结好的大纲以及笔记/实习就业/创业黑马——数智科技部门/工作文件/脚本&推文撰写/脚本资料库/创作好的推文/MMDD推文/`（如 `0802推文/`）下，**当天所有推文合并为一个合集文档 `MMDD推文合集.md`**（如 `0802推文/0802推文合集.md`），每篇推文作为合集内的一个 `## MMDD推文N` 章节（含完整栏目与正文）；日期不同就新建对应日期文件夹（`0803推文/`、`0804推文/`……）。**当天创作的新推文直接并入当天合集文档（无合集先创建，追加章节 + 更新索引），不再生成单篇散文件**——日期文件夹内最终只有合集文档 + **用户放的图片等素材**（封面图、案例截图、数据图表，与推文同目录管理，素材嵌入用 `![[图片.png]]` 或相对路径）；没有素材时文件夹内只有合集文档。N 递增：0802推文1 → 0802推文2。若历史遗留有单篇散文件，整理时并入合集文档后删除散文件。合集文档结构见「合集文档结构（视频与推文通用）」。
- **优化版追加在文档末尾，旧版本不删除**；交付文件只放栏目与正文，过程产物不写入（同视频规则）。

## 🔥 爆款脚本洗稿与借构创作（2026-08-24 新增）/ Viral Script Adaptation & Borrowed-Structure Creation

> 背景（用户明确要求）：**脚本内容必须经常更新**——抖音的爆款随时期变化，每个时期有属于它的爆款脚本。用户会不定期爬取近一周的爆款脚本供本 skill 吸收更新。拿到爆款脚本后，按「洗稿」或「借构创作」两条路径使用。
>
> **核心约束（用户点名）**：**脚本结构可以相同（黄金三秒什么时候出现、结尾钩子怎么写等），但表达形式禁止每一条都一样**——0805 五条脚本中间全是"第一道保险/第一刀/第一看/一证"式裸编号列举、结尾五连用同一套三段式，结构类型明明在轮换，观众看十条却像看同一条。**结构轮换 ≠ 表达形式轮换**，两条都要守。

> **核心分界：洗稿 ≠ 原创，两套方案互不套用（2026-08-30 用户点名，硬性·总纲）**：**洗稿与原创是两种不同的内容形态，对应的方案也完全不一样**——
> - **洗稿**（拿爆款改编）只走「洗稿工作流」：保留爆款骨架/表达形式/语言风格/开头结尾（对标原爆款），**不设字数约束、不做去 AI 味/术语通俗化改造**（见下方洗稿工作流各红线）；
> - **原创**（自由创作/自创脚本）走「7 步创作流程」：字数 650 左右、去 AI 味、结构/表达形式/开头/结尾轮换、案例叙事、黄金三秒三要素等全套原创要求。
> **两条路径的规则互不越界**：**洗稿时不要采用原创的要求**（不用 650 字数口径、不用去 AI 味/术语通俗化、不用套 7 步结构表/开头三步曲/结尾三段式/轮换规则验收洗稿稿）；**原创时不要采取洗稿的要求**（不能拿"保留爆款骨架/语言风格/对标原爆款"来要求原创稿，原创稿必须自己搭结构、轮换表达形式、控制字数）。
> **判定走哪条路径**：拿到的是爆款素材要求改编 → 洗稿（或借构）；无爆款素材、自主选题创作 → 原创。借构创作界于两者之间：骨架借爆款、内容全部自创，**写作要求按原创执行**（字数/去 AI 味/轮换照原创）。

### 一、爆款脚本拆解模板（拿到爆款先拆，再决定怎么用）

拆解近一周爆款脚本时，按以下 6 项记录：

1. **黄金三秒**：前 3 秒怎么抓人（用了 10 钩子里的哪一种？具体句式？）
2. **内容线**：技术痛点 / 方向判断 / 案例故事 / 筛选劝退 / 泛内容（对照受众报告四条线）
3. **表达形式**：中间干货部分是怎么组织的（优先级递进/对比/问答推进/场景串讲/清单平行/时间线/漏斗收窄/分情况/反例正例/数字盘点/裸编号列举……见第四节轮换库）——**这是洗稿时重点保留、自创时重点轮换的部分**
4. **结构类型**：三步法 / 四步法 / 一坑一解 / 对比式 / 清单式 / 漏斗式 / 时间线式 / 问答式
5. **案例写法**：有没有案例？怎么引入的？案例里有什么细节（PASS）？
6. **结尾钩子**：怎么收尾的（资料钩子 / 咨询钩子 / 启发式？句式是什么？）

拆解结果登记到 `参考的资料/爆款库/MMDD爆款.md`（见第五节归档）。

### 二、洗稿工作流（近一周爆款直接用）/ Rewriting Workflow

**适用场景**：近一周的爆款脚本，结构/钩子/表达形式确实强（被市场验证过），直接把它的"威力"保留下来，把内容换成本账号（华哥聊论文/科研/论文方向）的。**洗稿只走本工作流的洗稿要求，不套原创要求**（见章节顶部「核心分界：洗稿 ≠ 原创」总纲）。

洗稿 = 保留爆款的「骨架与表达形式」，替换「内容主体」。具体五步：

1. **判定可承接性**：这个爆款讲的主题，能不能换成科研/论文主题？用脱题红线自测——换完能不能锚定科研？**不能承接的爆款不硬洗**（如纯职场/纯生活爆款，除非能完美落回科研，否则跳过）。
2. **换内容主体（5 换）**：
   - 换**人设**：爆款是谁在讲 → 换成华哥（"我是华哥"身份词；**教学成果背书"170 学员"按需、可选，不强制每条都加**——见「人设要素」背书数据规则）；**⚠️ 人设必须真正变换，禁止硬套爆款人设（2026-08-30 用户点名，硬性）**：爆款讲述者的人设通常与华哥不同（"与审稿人交流""发过几十篇顶刊的大牛""实验室 PI""亲历投稿的作者"等），洗稿时必须把**讲述者的身份与行为整体换成华哥能成立的样子**（辅导老师：带学员、帮学员改被拒的稿子、从退稿信与审稿意见里读门道、复盘学员被拒原因），**不能把爆款原人设的行为生搬硬套进华哥身上**——反面：把爆款"我和主编副主编交流"改成华哥"我也请教过期刊里的老师"，行为没换、还是审稿人人设，必须删掉这段，换成华哥视角的等价行为"帮学员看的被拒稿子多了，从审稿意见里读出编辑那把尺子"。**自查：把洗稿稿里的叙述者身份抽出来，若仍是爆款原人设的行为逻辑（跟编辑交流/亲自审稿/亲历投稿被拒），就是没换干净，重写**；
   - 换**卡点**：爆款讲的通用痛点 → 换成目标人群的学术卡点（复现/消融/选导师/首投/画饼……从学员感悟/案例文件里取真实卡点）；
   - 换**案例**：爆款的故事/证据 → 换成往期学员案例（学员感悟 PASS 细节 + 老师视角过程数据，虚拟组合形象、技术自洽）；**若爆款以第一人称讲作者亲身经历，须把主角从"我"转成"我带过的一个学生"**（见下方「洗稿叙事视角」规则）；
   - **语言风格保留**：原爆款怎么说话，洗稿版就怎么说话——**口语程度、术语用词、句式长短、语气词、情感浓度一律照原爆款来，不做改动**；不套华哥大白话/术语通俗化/去 AI 味改造（见下方「洗稿保留原语言风格」红线）。内容换掉的部分（案例/卡点/转化物）也用原爆款同样的语气续写；**⚠️ 语气词完整保留 + 分句与原版一致（2026-08-30 用户点名，硬性）**：原爆款里的**大量语气词（啊/呃/吧/嘛/所以啊/反正/那/呢）完整保留**、一个都不要删；**分句方式跟原版走**——别人怎么断句、怎么用逗号串成长句，洗稿就怎么断、怎么串，**不套原创的"尽量用短句"规则**去把长句拆短；
   - 换**结尾钩子**：爆款的转化方式 → 换成华哥的转化内容（资料名/扣词/话术），但**保留爆款结尾的收法与次序**（资料钩子 → 咨询钩子 → IP 升华的先后顺序与句式节奏照爆款来）——**洗稿结尾不套自由创作的结尾三段式**（见下方红线）。
3. **过红线**：平台违禁词 / 教育合规词 / 高危情绪表达 / 选题禁忌 / 脱题红线——全部按 SKILL.md 硬性规则过一遍。
4. **双格式输出**：按标准栏目格式输出（标题/描述/标签/封面/正文），并入当天 `MMDD脚本合集.md`（或推文合集）。
5. **登记**：主题、结构类型、表达形式、立意登记到选题库「已覆盖主题清单」，标注"洗稿自 [来源账号/链接] + 日期"。

> ⚠️ **洗稿不设字数约束（2026-08-30 用户点名，硬性）**：洗稿**豁免本 skill 的「正文 650 字左右（600~700）」字数口径**（第 5 步长度控制）——只做内容转换（5 换），忠实保留爆款的骨架、表达形式与详略节奏，**字数多或少都不用管、不刻意删补**。原爆款长，洗稿版就跟着长；原爆款短，洗稿版就跟着短。字数口径只约束自由创作/自创脚本，不约束洗稿产物；洗稿稿的优化也不做长度拉齐。

> ⚠️ **洗稿保留原语言风格（2026-08-30 用户点名，硬性）**：洗稿时**语言风格采用原版的语言风格、完整保留、不做改动**——不要按本 skill「自由创作/原创」的写作要求（去 AI 味、术语通俗化、华哥大白话、短句化、语气词库等第 4 步规则）去改爆款脚本的语言。**语言风格要"抄就抄完整的"**：原爆款的口语化程度、语气词密度、长句流水账节奏、情感浓度这些**风格特征**整段保留，原爆款怎么说话，洗稿就怎么说话；只把内容主体（人设锚点/卡点/案例/结尾转化物）换成华哥的，换上去的内容也用原爆款同样的语气续写。⚠️ 注意：**"保留语言风格"保留的是风格特征，不等于逐字照抄原句**——字句层必须"换个说法"（见下方「洗稿 ≠ 内容照搬 · 相似度红线」）。

> ⚠️ **洗稿 ≠ 内容照搬 · 相似度红线（2026-08-30 用户点名强化，硬性）**：洗稿 = **保留原语言风格的前提下换个说法**——禁止把爆款原文的句子整段逐字复制（内容主体与字句层都要换）。**抖音平台判定：文案相同部分超过 30% 且字数大于 100 字即判"文案抄袭/重复度过高"，机器消重直接命中、限流扣分**（量化口径参考 总结好的大纲以及笔记/技能/自媒体/抖音重复度过高的定义.md，非官方统一明文，作为本 skill 红线执行）。洗稿后与原爆款的重复部分**必须 ≤30% 且 ≤100 字**，宁换说法换到"用词神似、字句全非"，也不要整句照抄。
>
> **"保留语言风格"与"换个说法"的分工**：保留的是**风格层**——语气词密度、口语化程度、长句流水账节奏、情感浓度、标志性口语比喻（如"海底捞"）；换掉的是**字句层**——同样的意思用**不同的词、不同的语序、不同的细节**重新说一遍（如"编辑越来越倾向于拒稿"→"编辑那边拒稿的劲头，是越来越足了"；"即使审稿人在努力的海底捞"→"为什么审稿人那边明明在努力海底捞，编辑一拍板，照样没戏"）。**保留"海底捞"不等于保留整句——口语词可以原样用，但前后文必须重组**。
>
> **自查方法**：洗稿完成后把洗稿稿与原爆款**逐句比对**，标出连续相同 ≥8 字的片段；累计重复字数 ÷ 全文字数 ≤30%、且单处连续重复 ≤100 字。超了就把该句重写（换主谓宾、换比喻、换语序、增删细节）。洗稿输出前必做此步。

> ⚠️ **洗稿开头/结尾：对标原爆款，不套自由创作模板（2026-08-28 用户点名）**：洗稿时**开头和结尾直接对标原爆款的开头/结尾结构来写**，**不再参考本 skill「自由创作」的结构表**——不套短视频内容结构+钩子结构表（7 步结构）、不套开头三步曲、不套结尾钩子三段式（收束确认+资料钩子+咨询钩子）、不受结尾收法 8 类轮换约束。做法：保留爆款"开头怎么抓人、结尾怎么收"（开头钩子类型 + 结尾资料钩子/咨询钩子/IP 升华的先后次序与句式节奏照爆款来），只换内容主体（华哥人设、卡点、话术、案例、资料名/扣词）。自由创作的结构表只用于自创脚本；洗稿场景以爆款原稿为准。⚠️ 同账号洗稿多条爆款时，若各原爆款的开头/结尾公式相同（如同来自阿彭讲SCI），仍需在话术层逐条错开，避免同账号内开头/结尾连看雷同（0828脚本1~2 教训）。

> ⚠️ **洗稿结尾钩子：有则沿用、无则自创（2026-08-29 用户点名，硬性）**：结尾钩子按爆款本身的情况分两种处理——
> - **爆款本身有结尾钩子**（资料钩子/咨询钩子/IP 升华/提问启发等）→ **直接采用该爆款钩子的结构与收法，不做变换**——保留它的先后次序与句式节奏，只把内容主体换成华哥的（资料名/扣词/话术）。爆款怎么收，你就怎么收。
> - **爆款本身没有结尾钩子**（如爆款停在反问句/观点句上，没有明显的转化动作）→ 则**自己创作**一个结尾钩子，但**必须变体、不重复、不同质化**——**不要每次都用"评论区留下XX"这类重复句式**（这是已用烂的资料钩子套路），要换收法（如咨询钩子主收法/提问启发/筛选劝退等），并对照最近 5 条作品的结尾收法错开。**核心：有钩子照搬钩子，没钩子自创且不同质。**

> ⚠️ **洗稿叙事视角：第一人称经历 → 学生视角（2026-08-29 用户点名，硬性）**：爆款若以**第一人称**讲述作者亲身经历（如"我当时大修三轮又被拒""后来我发现做法是这样的"），**洗稿时不能把它留在华哥自己的第一人称上直述**——华哥的人设是"带学生的辅导老师"（见上方「叙事真实性红线」），不是亲历这些学术起伏的作者。应把这段经历**转换为华哥学生的视角来讲述**：**"我带过的一个学生……当时大修三轮又被拒……"**，再落到华哥点拨、学生中稿的案例叙事上。**核心：爆款里"我"的亲身经历 → 换成"我带过的一个学生"的经历；主角从作者转为学生，叙事骨架由"作者亲历"转为"学员卡壳 → 老师点拨 → 结果"**。这同时满足案例叙事硬要求：进入学员叙事前，须先立"我是带出过学生的老师"人设再展开。**例外**：爆款第一人称若只是"引子/观点带入"（如"最近投稿是不是越来越难？"这种泛指提问），不属于"亲身经历叙事"，无需转换，保留原句式即可。

### 三、借构创作工作流（借鉴结构自创脚本）/ Borrowed-Structure Creation Workflow

**适用场景**：爆款的**结构**值得借鉴，但**内容/表达形式**要自创——避免本账号所有脚本结构撞车。

借构创作 = 借「骨架」不借「内容」，且表达形式必须轮换。具体四步：

1. **拆解爆款骨架**：用第一节拆解模板，抽出「结构类型 + 表达形式 + 钩子安排」（如：开头代入场景 → 中间对比式两栏对照 → 结尾资料钩子）。
2. **选题自创**：依托知识库已有方法论选题——素材反推法（回读学员感悟/案例文件，从学员真实卡点反推）/ 卡点×场景×人群组合法 / 追问延伸法（见 `references/反同质化.md` 第五节）。**不直接照搬爆款的选题**。
3. **借结构不借内容**：把爆款的「骨架」套到新选题上，但正文干货、案例、话术、金句全部重新写；**表达形式必须与最近 5 条作品轮换错开**（见第四节轮换库）——借了结构，表达形式就更要换，否则两个维度一起撞 = 双重同质化。
4. **过红线 + 查重 + 登记**：同洗稿工作流第 3~5 步；表达形式一并登记到选题库。

### 四、表达形式轮换（硬性，2026-08-24 用户点名）/ Expression Form Rotation

> **用户点名的核心问题**：之前创作的脚本表达形式高度同质化——中间干货部分全是"第一道保险/第二道保险/第三道保险""第一刀/第二刀/第三刀""第一看/第二看/第三看""一证/二证/三证"这种**裸编号列举**。结构类型虽然在轮换（四步法/漏斗式/三步法/一坑一解），但**表面的表达形式一模一样**，观众看十条视频感觉是同一条。
>
> **铁律**：**结构可以相同（黄金三秒的时机、结尾钩子的写法等），但表达形式禁止每一条都相同。** 连续两条作品不得用同一种表达形式；同一种表达形式至少隔 3 条才可再用。

**表达形式轮换库**（中间干货部分的组织方式，每篇选一种，与历史错开）：

| 表达形式 | 特征 | 示例 |
|---------|------|------|
| **裸编号列举** ⚠️ | 第一X/第二X/第三X | "第一道保险锁环境，第二道保险锁种子……"（**已用烂，近期禁用**） |
| **优先级递进式** | 按重要性从高到低，只说"最要命的/最省事的" | "先说最要命的锁环境，再说最省事的锁种子" |
| **对比式** | 两栏对照：做A vs 不做A / 别人 vs 你 | "别人的环境靠记性，你的环境靠清单" |
| **问答推进式** | 连续自问自答推进 | "审稿人凭什么信你？凭你砍了一刀，效果掉了。" |
| **场景串讲式** | 用一个完整场景把几个点串起来讲 | "你从新电脑开机讲起：装环境…跑种子…对数据…" |
| **清单平行式** | 并列盘点，无编号 | "环境、种子、数据、一键脚本——四样东西，一样都不能少。" |
| **时间线式** | 按时间推进 | "头三天锁环境，一周内定种子，月底对完数据" |
| **漏斗收窄式** | 从大范围逐步收窄到关键一步 | "先别管模型，先管环境；环境定了再看种子" |
| **分情况式** | 按人群/场景分情况给解法 | "你刚入门，先锁环境；你已经跑通了，锁数据版本" |
| **反例正例式** | 先讲错误做法，再讲正确做法 | "别靠记性——记性三个月就失效。要用清单，十分钟还原" |
| **数字盘点式** | 用数字统领 | "四道保险，四句话，一次讲完" |

**轮换执行规则**：
- 动手前先看最近 5 条作品的表达形式（各日期合集文档里查），**不得与最近 1 条相同，同形式至少隔 3 条**；
- 洗稿时**保留爆款的表达形式**（这正是爆款的"威力"所在）；自创时**必须选一个与最近作品不同的表达形式**；
- **裸编号列举"第一X/第二X/第三X"进黑名单**——除非隔 3 条以上且确实无更优形式，否则不碰；同类并列点数超过 3 个点以上时，优先改用清单平行式或数字盘点式。

## 🖥️ 脚本转 HTML 演示网页 / Script-to-HTML Presentation（扩展功能，2026-09-02 新增）

把一条华哥口播脚本转成**可翻页、逐块显现的 16:9 单文件 HTML 演示网页**，供录制视频素材使用。

> **触发条件（硬性闸门）**：仅当用户**明确要求**"生成 HTML 演示网页 / 做 PPT 式 HTML / 做一版可翻页的网页 / 把脚本做成画面"等表述时才触发。**其余任何调用本 skill 创作/优化脚本、写推文、判断风格等情况，一律不触发本功能**，正常走脚本创作流程。

**默认 5 页**（除非用户明确指定其它页数）：①封面（主题）＋ ②~④ 内容页（一点一页，脚本未明确分点则整理成 3 点，有特殊分点要求按用户要求）＋ ⑤结尾回顾页（3 个分点集中列出，**每个分点标题严格 ≤ 7 字**）。

**质量底线**：每页排版必须不同（版式异构，给观众新鲜感）；**跨网页也要去同质化**——相邻两份 HTML 的整体版式骨架不重复（见下方「跨网页版式去同质化」）；**每页要有层次感**——主标题／副标签／正文逐级缩放、主次分明，禁止每页都套同一种"标签＋大标题＋副题＋内容块"；语言去 AI 味（无套话/评述/口水）；配色去廉价塑料感（低饱和、克制、留白充分）。

**设计辅助**：制作时必须**调用 `/前端设计` skill** 辅助完成风格与排版。

**风格前置询问（硬性闸门）**：每次制作 HTML **必须先问清楚用户要用哪种风格**，得到答复后才开始制作。两种风格：
- **真实风**：质感偏向真实。到 Pexels（https://www.pexels.com/zh-cn/ ）检索并**下载与脚本主题相关的图片素材**，转 **base64 内联**（`data:image/jpeg;base64,...`）嵌入网页，让整体质感/风格更真实；配色与气质从真实照片提取。仍保持**单文件、无外部依赖**。
- **默认**：即目前的抽象/图形风格（数据卡、三栏、对比卡、网格盘点等版式元素）。**不插入真实照片**，靠低饱和配色、版式分层与克制装饰表达气质。

**跨网页版式去同质化（硬性）**：不同网页之间也要多样，避免"每次都是那几页"。实现方法——内置 **≥6 套可互换的版式骨架**（封面居中 / 左文右图 / 三栏网格 / 左右对比卡 / 数字盘点 / 时间线 / 卡片堆叠 / 上下分层 等），每份网页按主题组合选取且**每页异构**；**相邻两份网页所用骨架的重合度 ≤50%**，整体气质、配色、装饰也随主题变化，禁止照搬前一份的版式。详见 `references/脚本转HTML网页.md`「二·排版要求」与「三点五·风格自定义」。

**风格自定义（硬性决策流程）**：网页视觉风格（配色/字体/装饰/气质）**不能随意选取**，在上方「风格前置询问」确定的**真实风 / 默认**基础上，再按以下优先级细化视觉方向——
① **用户明确指定了风格参照**（典型：上传一张图片并说"按这张图设计"）→ 提取该图的**核心元素 / 配色方案 / 整体气质**，落实到设计令牌（`:root` CSS 变量）与版面装饰，使网页风格与参照图**高度一致**；
② **用户未指定参照** → 从**脚本主题内容反推风格**（如脚本讲医学 → 相关克制冷调、素雅留白、专业气质）。**参考图来源首选 Pexels**（https://www.pexels.com/zh-cn/ ）——到 Pexels 按主题关键词检索并采图，借其确立配色与气质（**采集方法见 `references/脚本转HTML网页.md`「2.5 Pexels 采集风格素材」**），让风格"为内容服务"。
> **真实风 vs 默认的区别**：①、② 两步确定的是视觉方向（配色/气质/构图）；在此基础上——**真实风**还要把下载的 Pexels 主题图**转 base64 内联**真正嵌进网页（`data:image/jpeg;base64,...`），**默认风**则**只取色/气质/构图、不嵌入真实照片**。两者都保持单文件、无外部依赖；最终都必须符合上方**去 AI 味 / 去廉价塑料感**底线。

**播放过渡动画（沉浸感，硬性）**：播放/翻页**必须有过渡动画，禁止生硬瞬间切换**——用淡入淡出、位移、缩放等缓动过渡（`transition`/`animation`）；动画的节奏、方向、风格与脚本主题相适应（商务/医疗/科技/情感），避免千篇一律；页面内内容仍按"自上而下、自左而右"逐块淡入，与翻页过渡**协同**，让观众更快融入视频氛围。

完整执行细则（触发/页数/分点判定/排版/风格自定义/播放动效/自检清单）见 `references/脚本转HTML网页.md`；可直接套用的自适应骨架模板见 **`assets/脚本转HTML网页模板.html`**（把占位文案替换成脚本内容、按 `/前端设计` 调整风格与每页版式即可）。
