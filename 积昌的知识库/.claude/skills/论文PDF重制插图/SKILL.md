# 论文 PDF 重制插图

## 0. 定位：本 skill 与「文档转换+排版」的关系

本 skill 是 `文档转换+排版` skill 的**专属子 skill**，专门负责一件事：**把讲义截图里的"带手写批注的论文页"，用论文 PDF 源文件重制成一张干净的替换图**。

- **主 skill**（`文档转换+排版`）只在"功能六：附件型纪要整理"里保留**一段简短入口指引**，不再展开重制细节——这样主 skill 不会继续膨胀、日常调用省上下文。
- **需要重制插图时**，才加载本 skill。
- 本 skill 处理的是**插图本身**；插图重制完之后的**笔记图注怎么写、双向链接怎么建**，仍回到主 skill 的功能四/功能六执行。

> 一句话：**主 skill 管"笔记"，本 skill 管"图"。**

---

## 1. 何时使用 / 触发条件

满足以下**任一**即走本 skill：

- 用户明确要求："用**论文 PDF 源文件**重制插图""按 PDF **重置图片**""按照原版的图片**原封不动地抄下来**""把**手写批注改成印刷体**""重制某某期的插图"。
- 素材形态吻合：原图是**论文页 / 讲义页的截图**，页面上有**荧光笔分块、红圈、手写旁批**等批注，而**同一篇论文的 PDF 就在知识库里**（可作底稿重新渲染）。
- 主 skill 的"功能六"整理流程中，触发了"重制插图"分支。

**不适用**（不要用本 skill）：

- 底稿是**白板手写 / 平板手绘**（整幅手绘）→ 那是 Excalidraw 的地盘，走主 skill 功能六第 9 节，**不是**本 skill。
- 用户没要求重制 → **直接用原附件**整理，不做任何重绘（主 skill 功能六第 9 节"显式开关·默认关闭"）。

### ⚠️ 与 Excalidraw 的分界（一句话判据）

> **看底是什么——底是"空白纸/白板"→ Excalidraw 重绘；底是"印刷体论文页"→ 本 skill（PDF 重制插图）。**

## 4. 核心原则：保真复刻（六条硬性规则）

> 重制**只允许做一件事**——把**手写字换成印刷体**。除此之外，原图长什么样，重制图就长什么样。

1. **位置不漂移（最关键）** —— 批注的**位置本身就是信息**：它指向论文的哪一行，决定了这条批注在说什么。
   - 原图在**正文旁边的文字批注**，其**首行必须与它所批注的正文/色块的起始行齐平**——**不是居中、不是垂直等距**。
   - ❌ 反面案例（003 图 5）：把五条旁批改到"每块色带的**垂直中点**"并排成**等间距**，用户反馈——"**需要将其原封不动地标注回原来的地方，不要漂移，不然我不知道这个批注对应原论文在哪个位置**"。
   - ⚠️ **"原封不动"≠ 照搬像素坐标**：原图与重制图尺寸不同（如 1440×1080 对 1986×1401），直接搬坐标毫无意义。要复刻的是**相对论文正文的同一位置**（首行对齐所批注行）。
2. **不自加装饰** —— 原图没有的**色卡、小方块、边框、序号、箭头**，一律**不加**。"我觉得加个色卡更清楚"是**创作者的主观加法**，与"原封不动"的口径相反。
3. **断行照抄** —— 原图一条批注折了几行、每行到哪个字断，**照抄**；不要因为重制版面更宽就并成一行。
4. **不用文本框顶替有信息量的批注** —— **荧光笔分块**（颜色分区本身就是信息：一眼数出"分成几块"）、**红笔整体圈划**、**红圈关键词**、**绿色荧光标记**、**手写数字/公式**，**逐一还原**；**绝不能用"一个红框 + 右侧一张功能清单文本框"顶替**。
5. **手写→印刷体（唯一允许的改动）** —— 手写字统一换成**印刷体**（要求"文字批注清晰"），字号、位置、断行照原图。
6. **看不清就停** —— 手写无法辨认、或批注**遮挡**了原图关键内容 → **立即停下向用户汇报**（说清哪几张图、什么内容辨认不了、当前进度），**绝不猜测、绝不编造**（与主 skill 功能六第 4 节一致）。

## 5. 工作流（八步）

### 第 0 步：确认对象与边界

- 确认要重制**哪几期、哪几张图**（用户可能指定单张，也可能整期批量）。
- 备齐第 2 节的**三份素材**；缺哪份先补哪份，找不到就停下问用户。
- **明确"这张图对应 PDF 的哪一页"**——靠页眉、图表号、正文内容定位。

### 第 1 步：逐张提取原图信息（做一张"临摹清单"）

**先把原截图读一遍**，为**每一张**图建立一张清单，重制时对表逐项勾对：

- **图面**：第几页、什么章节、有哪些图（如图号 `Fig. 2`）。
- **批注清单**（逐条记录，含**坐标**）：
  - **荧光笔分块**：几块、各什么颜色、各覆盖哪几行文字、块的**上下边界**在哪；
  - **红笔整体圈划 / 红圈 / 红椭圆**：圈住了什么，位置在哪；
  - **手写旁批**：文字内容、**首行位置**、**每行断在哪**、共几行；
  - **大号批注框**（如论文页角落的 `CLIP + DCD`）：位置、字号。
- **字幕条**：底部字幕的**原文**（供判断"留/删"，见第 5·7 步）。

> 💡 清单就是"施工图"。**没有清单就动手，必漏批注。**

### 第 2 步：渲染 PDF 源页

- 找到原图对应的 PDF 页，用 **PyMuPDF** 渲染（整页或**只渲染需要的区域**，减小体积）。见 6.1。
- 输出宽度对齐原图观感（003 案例最终成品 ≈ **1986 × 1401 px**；原截图 1440×1080）。
- **不要**在原截图上"涂改"——重制是在**干净的 PDF 渲染图**上叠加。

### 第 3 步：叠加批注（按类型复刻）

按第 1 步的清单**逐条**落笔：

| 批注类型 | 复刻方式 | 技术 |
|---------|---------|------|
| 荧光笔分块 | **multiply 混合**半透明色块（白底变淡彩、黑字仍是黑字） | 见 6.3；块边界取**文本行框的中线** |
| 红圈 / 红椭圆 | **矢量描边**（不填充） | 见 6.4 |
| 手写旁批 | 换**印刷体**，**首行墨迹顶对齐**所批注的正文/色块起始行，**断行照抄** | 见 6.5 |
| 大号批注框 | 印刷体，位置与字号照原图 | 见 6.5 |
| 底纹 / 页码 / 页眉 | 直接用 PDF 渲染结果，不动 | — |

### 第 4 步：字体与坐标校准

- **字体**：`C:/Windows/Fonts/msyh.ttc`（微软雅黑）。
- **墨迹校准**：msyh.ttc 在 `size=31` 时——**墨迹高 ≈ 30 px**；**墨迹顶相对绘制原点的偏移 ≈ 7 px**（即 `draw.text` 的 y 要写成 `目标墨迹顶 − 7`）。参见 6.5。
- **行距**：按原图比例（003 图 5 案例 ≈ **41 px**）。
- **对齐**：把原图批注的**首行行区间**换算到目标画布，作为该条批注的**首行墨迹顶**（见 6.6 的量取法）。

### 第 5 步：并排比对自检（硬性，不可跳过）

把**重制图**与**原图**（至少**右栏**）**并排**，逐项勾对：

- [ ] 原图**每一处**批注都复刻了吗？（对照第 1 步清单逐条勾）
- [ ] **荧光笔**：颜色、**块数**、块边界都对吗？
- [ ] **旁批**：首行与所批注行**齐平**吗？**断行**一致吗？**条数**一致吗？（无漂移、无并成一行）
- [ ] 有没有**多画**？（色卡、边框、序号、箭头——原图没有的都不能有）
- [ ] **字幕条**：按第 5·7 步规则处理了吗？（空话删、承载内容的留）
- [ ] 有没有**漏画**？（宁可多画一笔，不可少画一笔）

> 🔴 **没有并排比对 = 没有自检。** 用户投诉的"漂移""自加装饰"都是**跳过这一步**造成的。

### 第 6 步：安装替换

- 用重制图**覆盖** `附件/N.png`。
- 原截图备份**保持不动**（仍在 `中间文件/附件原始备份/<期号>/`）。

### 第 7 步：更新笔记图注

- 图注**按纪要上下文写**（主 skill §10"纪要为主、附件为辅"）；**图注禁止引用视频原始字幕**（主 skill 功能六第 6 节）。
- **字幕条处理规则（2026-09-18 更新 · 一律抹掉）**：**底面视频字幕条一律删除，不再"看内容决定留删"。**
  - **为什么**：字幕是**逐帧抓拍**截下来的，极易是**"片面的真相"**——脱离上下文的半句（用户原话："避免图片的字幕出现了前面那些片面性真相这种低级错误"）。而且图注**已按纪要上下文书写**，字幕**不再需要充当"定位路标"**——留在图上只会误导读者。
  - **怎么做**：用**白色矩形填充**字幕条所在区域（`ImageDraw.rectangle([x0,y0,x1,y1], fill=(255,255,255))`）。
  - ⚠️ **只抹字幕条那一条区域**——若同高度处还有批注框/图例/正文，**不能整条裁掉**，只抹字幕条本身。抹之前先确认该区域确实只有字幕条。
  - ⚠️ 旧规则"空话删、承载内容的留"**已作废**——承载内容的信息由**图注**（按纪要写）承担，不再靠图上的字幕。
- ⚠️ **同步改图注描述**：若图注里原本写了"右侧色卡小方块""同色小方块"等**重制后已不存在**的元素，**必须同步删掉**这些描述，否则图与注对不上（003 案例踩过）。

### 第 8 步：清理中间文件

- 删除本次产生的**临时脚本**与**中间图**（如 `_z003/`、`_003png/`、`patch5.py` 等——这些不匹配 hook 的自动清理模式，**必须手动删**），**只保留**最终的 `附件/N.png`。
- 参考主 skill 的临时文件清理规则。

## 6. 技术参考（代码骨架）

> 所有脚本用 `PYTHONIOENCODING=utf-8 python xxx.py` 运行，兼容中文路径。

### 6.1 PyMuPDF 渲染 PDF 页

```python
import fitz  # PyMuPDF

doc = fitz.open(pdf_path)
page = doc[pno]                       # pno 从 0 开始

# 整页渲染
pix = page.get_pixmap(matrix=fitz.Matrix(scale, scale))
pix.save("page.png")

# 只渲染某个区域（减小体积）：PDF 坐标单位为 pt，原点在左上
clip = fitz.Rect(x0, y0, x1, y1)
pix = page.get_pixmap(matrix=fitz.Matrix(scale, scale), clip=clip)
pix.save("crop.png")
```

- `scale` 取值使输出宽度符合观感（003 案例 ≈ 1986 px 宽）。
- 一次渲染**尽量只覆盖需要的区域**，避免整页大图。

### 6.2 取文本行框（用于定位荧光笔色块）

```python
d = page.get_text("dict")
for block in d["blocks"]:
    for line in block.get("lines", []):
        bbox = line["bbox"]        # (x0, y0, x1, y1)，单位 pt
        text = "".join(s["text"] for s in line["spans"])
```

- **色块的上下边界取"相邻两行行框的中线"**——这样色块必然贴合文字、不会错位。

### 6.3 荧光笔 multiply 混合

```python
from PIL import Image
import numpy as np

base = Image.open("page.png").convert("RGB")
arr = np.asarray(base).astype(np.float32)

color = np.array([r, g, b], dtype=np.float32)   # 该块荧光笔的颜色
y0, y1, x0, x1 = band                            # 该块的矩形范围
region = arr[y0:y1, x0:x1]
arr[y0:y1, x0:x1] = region * (color / 255.0)     # multiply：结果 = 底色 × 颜色/255

out = Image.fromarray(arr.clip(0, 255).astype(np.uint8))
out.save("with_highlight.png")
```

**原理**：白底 `255 × 颜色/255 = 颜色`（淡彩）；黑字 `0 × 颜色/255 = 0`（仍是黑字）。这正是荧光笔的半透明质感。

### 6.4 矢量描边（红圈 / 红椭圆）

```python
from PIL import ImageDraw

d = ImageDraw.Draw(img)
d.ellipse([x0, y0, x1, y1], outline=(220, 40, 40), width=4)   # 只描边、不填充
# 整体圈划同理，用 rectangle 或 polygon
```

### 6.5 印刷体文字 + 字体校准

```python
from PIL import ImageFont, ImageDraw

FONT = "C:/Windows/Fonts/msyh.ttc"
font = ImageFont.truetype(FONT, 31)     # size=31 → 墨迹高 ≈ 30 px
INK_TOP_OFFSET = 7                       # 墨迹顶相对绘制原点 ≈ −7px
d.text((x, y_top - INK_TOP_OFFSET), "文字内容", font=font, fill=(24, 24, 24))
```

**校准墨迹 bbox 时注意**：PIL 在 `mode="L"` 下 `getbbox()` 统计的是**非零像素**——测**墨迹**必须用**黑底(0) + 白字(255)**：

```python
img = Image.new("L", (w, h), 0)          # 黑底
ImageDraw.Draw(img).text((0, 0), "字", font=font, fill=255)   # 白字
bbox = img.getbbox()                      # 墨迹范围 (x0, y0, x1, y1)
```

（白底黑字会得到整图 bbox，是错的。）

### 6.6 列扫描量取原图批注位置

```python
import numpy as np
from PIL import Image

g = np.asarray(Image.open(orig).convert("L"))
W = g.shape[1]

margin = g[:, int(0.76 * W):]              # 取右侧批注区（比例按图调）
dark_rows = (margin < 128).any(axis=1)     # 该行是否有暗像素

# 找"连续暗行段" → 每条批注的行区间
runs, start = [], None
for y, v in enumerate(dark_rows):
    if v and start is None:
        start = y
    elif not v and start is not None:
        runs.append((start, y - 1)); start = None
```

- 再按列扫描**正文区**，得到**高亮色带的上下边界**。
- **对齐关系**：计算每条批注**首行**与它对应**色带顶边**的差值——003 图 5 案例平均 ≈ **−11 px**（首行基本与色带顶边齐平）。

## 7. 实战示例：003 期 图 5（论文摘要页）

**背景**：003《摘要如何阅读》的图 5 是论文摘要页——原截图用水导的**五种荧光笔**把摘要切成五块，并在**右侧空白处逐块手写了五条功能批注**（① 背景介绍，先前的工作 → ⑤ 实验效果怎么怎么样）。首版重制把五条批注放到了**每块色带的垂直中点**、排成**等间距**、还**自加了同色小方块**——用户投诉"**漂移**"。

**原图（1440×1080）量取结果**（右侧批注区，列扫描）：

| 批注 | 文字（断行照抄） | 原图行区间(px) |
|:--:|------|:--:|
| L1 | `背景介绍，先前` / `的工作` | 155–221 |
| L2 | `现有的工作是怎么做` / `的，然后和先前的工作` / `对比` | 244–349 |
| L3 | `以前的方法和现有` / `的方法具体有什么` / `区别` | 378–483 |
| L4 | `基于上述发现，自己` / `的论文是怎么做的` | 521–587 |
| L5 | `实验效果怎么怎么样` | 626–654 |

**重制图（1986×1401）落笔参数**：

- 摘要五块荧光笔色的**顶边**：🟦 334（蓝） / 🟪 484（紫） / 🟨 632（黄） / 🟧 773（橙） / 🟥 931（粉）。

## 8. 常见坑（踩过的，务必避免）

| # | 坑 | 症状 | 防复发 |
|:-:|----|------|--------|
| 1 | **批注位置漂移** | 用户："我不知道这个批注对应原论文在哪个位置" | 旁批**首行对齐**所批注正文/色块起始行；**不用**中点、**不用**等距 |

| 4 | **用文本框顶替荧光笔分块** | 用户："原本荧光笔分块批注，你却简简单单画个文本框" | 荧光笔用 **multiply 混合**逐块还原，**块数/颜色**一个不少 |
| 5 | **字体墨迹测量测错** | bbox 返回整图 | 必用**黑底白字**测墨迹（见 6.5） |
| 6 | **跨尺寸照搬绝对坐标** | 坐标对不上 | 复刻的是**相对论文正文的位置**，不是像素坐标 |
| 7 | **临时目录没删** | `_z003/`、`_003png/` 残留 | 这些**不匹配** hook 自动清理，**手动删** |
| 8 | **图注还在说"色卡"** | 图与注对不上 | 删掉装饰后，**同步改图注描述**（第 5·7 步） |
