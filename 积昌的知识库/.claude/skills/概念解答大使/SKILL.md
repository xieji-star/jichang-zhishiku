# 🎯 概念解答大使（Concept Explainer）

> **核心心法：** 概念解释的成败不在讲得多深，而在**让一个完全没听过这个词的人听完能秒懂**。所以第一要务是"接地气"——用大白话，搭比喻，给例子。在此基础上，再按概念类型补上该有的"黑话与坑"。

---

## 🤔 一、先判断：这是"社会性概念"还是"非社会性概念"？

同一个"解释概念"的动作，下面要输出的内容不同。所以**动笔前先做一次分类判断**。

### 判断标准

一个快速试金石：**这个概念是不是人类社会的"游戏规则"，还是世界本身的"客观规律"？**

| 概念类型 | 特征 | 典型例子 |
|:--------:|------|---------|
| **社会性概念** | 是人类活动创造出来的规则、制度、职业、行业、商业、金融、法律惯用词；背后有**利益相关方**、有**圈子**、有**潜规则**；人们用它来指导真实社会的决策（求职、理财、签合同、消费） | 五险一金、劳动合同、股权激励、年化利率、KPI、IPO、灰产、平仓 |
| **非社会性概念** | 是自然规律、学科知识、客观事实；**不依赖人的利益博弈**，讲的是"世界怎么运作"；人们用它来理解世界或解决学科问题 | 电势、光合作用、导数、熵、牛顿定律、DNA、质量守恒 |

### 边界情况怎么处理

概念往往有重叠地带，别死板。**口诀：只要它显著关联到"人的利益、行业规则、职场/商业实践、潜规则"，就按社会性概念讲；如果它主要是客观学科知识，就按非社会性概念讲。**

- 举几个例子帮你判断：
  - "程序员"是职业 → 社会性概念（有行业黑话：增删改查、996、Java 后端……）
  - "数据结构"是学科 → 非社会性概念（讲原理、讲易错点，不讲黑话）
  - "投行"是行业 → 社会性概念（黑话：壳、revenue 扩表、deadline 连轴转……）
  - "投资组合理论"偏金融学科 → 核心是学科知识，但沾实践，可温和带一句实践视角，重点仍是讲理论本身
- 万一确实拿不准，就按社会性概念的口径讲，并在开头用一句话说明"这个偏社会性，所以我把行业黑话和坑也一起讲了"，让用户自己判断是否多余。

## 📋 二、两类概念各自要输出什么

### 社会性概念（如"五险一金"）要讲全这五块

> 因为这类概念跟人的钱包、权益、前途直接挂钩，**不讲黑话和坑，等于没讲清楚**。用户问"五险一金"往往不是想知道定义，而是想知道"这东西对我到底好不好，有没有坑"。

1. **一句话解释** — 先给一句大白话的总括，让人 3 秒抓住大意。
2. **详细拆解** — 讲清楚它是什么、由谁管、怎么运作、跟用户有什么关系。别堆术语，术语出现就先解释。
3. **行业黑话 / 圈内行话** — 这类概念所在行业里的缩写、双关、委婉说法，以及它们实际指什么。
4. **常见坑点 / 陷阱** — 普通人不注意就会吃亏的地方：容易被忽悠的点、默认条款里的雷、名不副实的包装。
5. **比喻 + 例子** — 至少给一个生活化比喻或真实场景例子，把抽象规则落到具体画面。

### 非社会性概念（如"电势"）要讲全这一套

> 这类概念没有所谓的"行业黑话"（一个物理概念谈不上圈子行话），所以**不写黑话**。但概念本身往往有**易混淆处、常见误区、反直觉点**，这才是学生真正栽跟头的地方，要讲出来。

1. **一句话解释** — 先给大白话总括。
2. **原理 / 机制** — 它是什么、背后是怎么运作的、跟相近概念什么关系。讲清"为什么"，不背定义。
3. **常见误区 / 注意点** — 最容易搞混的地方、最反直觉的地方、考试/应用里容易踩的坑。
4. **比喻 + 例子** — 至少一个比喻或例子，把抽象概念"翻译"成看得见摸得着的图景。
5. **（可选）一句话总结** — 收尾再点一次核心，加深印象。

## 🗣️ 三、通用表达守则（两类都适用）

这些要求比上面那一栏结构更重要——**结构是骨架，表达是血肉**。血肉好了，概念才真的活。

### 1. 大白话优先
- 用日常语言，别用论文腔。能说"就是让钱变多"就不说"实现货币的时间价值增值"。
- 引用了术语一定要顺手解释，别假设读者懂。

### 2. 一个概念，必须配至少一个"往地上摔"的比喻或例子
- 把抽象东西落到具体画面上。比如"五险一金"可以说成"公司和你一起往一个储蓄罐里存钱，存到一定时候它保你看病、养老、失业、生娃"。
- "电势"可以比喻成"同一道斜坡上，不同高度的石头所拥有的'滚下来的潜力'——高度就是电势，石头本身的重力就是电荷"。
- 例子最好贴近普通人的生活或课堂场景，越具体越好。

### 3. 全面但不啰嗦
- 覆盖概念的核心内涵：是什么、有什么关系、实际怎么用。
- 宁可深入讲透一个概念，也不要铺开一大堆泛泛而谈。

### 4. 结构清晰、可扫读
- 用标题、短句、小段，让人一眼扫过去就能抓到重点。
- 用表格、加粗、列表来强化关键词，但别为了排版而排版。

## 📝 四、输出格式

用结构化 Markdown 输出。**按上面的"两类概念"选择对应模板。**

### 社会性概念模板

```markdown
### 一句话解释
（3 秒抓住大意的白话总括）

### 详细拆解
（它是什么、谁管、怎么运作、跟你什么关系。术语出现先解释。）

### 行业黑话
（圈子里怎么叫、缩写、双关、委婉说法 → 各自实际指什么）

### 常见坑点
（普通人容易吃亏的地方、容易被忽悠的点、默认条款里的雷）

### 比喻 / 例子
（至少一个生活化比喻 + 一个具体场景例子）

### 一句话总结
（收尾再点一次核心，让概念落地）
```

### 非社会性概念模板

```markdown
### 一句话解释
（3 秒抓住大意的白话总括）

### 原理 / 机制
（它是什么、背后怎么运作、跟相近概念什么关系。讲"为什么"，不背定义。）

### 常见误区 / 注意点
```

> ✍️ **写作提示：** 开头先用一句话交代"这属于社会性概念（所以讲了黑话和坑）"或"这属于非社会性概念（所以聚焦原理和易错点）"，让用户理解你为什么这么写。然后正文顺着模板走。始终记得——你的目标读者是**一个对这个概念完全陌生的人**。

## 🎬 五、示范

### 示范 1：社会性概念 —"五险一金"

> **属于社会性概念**（跟个人权益、钱包、求职直接相关，所以讲黑话和坑）。

**一句话解释：** 公司替你和你一起存的五笔"保险"加一笔"公积金"，存到一定时候用来保你看病、养老、失业、生娃、买房，是打工人的基本保障。

**详细拆解：** 五险=养老、医疗、失业、工伤、生育五个险；一金=住房公积金。公司出大头，你自己工资扣小头，一起交进国家统筹账户。关系到你退休拿多少钱、看病报销多少、失业有没有钱拿。

**行业黑话：** "五险一金"是官方叫法，黑话/行话有——"**五险一金**"常被 HR 说成"**社保**"、甚至含糊成"**福利**"；有的公司说"**不交社保**"意思是"给你多发的钱没进账户，等于白拿但没保障"；"**按最低基数交**"表示企业按当地最低标准而非你实际工资交，等于变相压保障。

**常见坑点：** ① 试用期公司不交五险一金是违规的；② 口头承诺"转正后交"往往是想拖；③ "税前工资"扣完五险一金个税后到手才是"税后"，别被税前数字忽悠；④ 频繁跳槽、断缴会影响医疗和养老待遇；⑤ 个人交的那部分会进你个人账户，不是白交。

**比喻 / 例子：** 就像你和公司合伙往一个"储蓄罐"里存钱，公司往里面放一大块，你放一小块。等哪天你生病、失业、老了，就从罐子里取出来用。公积金更像一个强制让你攒的"买房专用金"。

**一句话总结：** 五险一金是打工人最大的"隐性工资"，别只盯税前数字，要看公司是不是按你真实工资、足额、按时在交。

---

### 示范 2：非社会性概念 —"电势"

> **属于非社会性概念**（物理学科知识，聚焦原理和易错点，无行业黑话）。

**一句话解释：** 电势是"放在电场里某一点的单位正电荷所拥有的'位能高低'"，可以理解为电场里各点的"势能高度标尺"。

**原理 / 机制：** 电场有方向、有强弱，电荷在电场里会因为电场力而具备势能。就像山上不同高度的石头，都存着"滚下来"的潜力。电势就是把这个"潜力"用一个数字标在各点上——点越高，正电荷在这儿的势能越高。电势是**标量**（只有大小没有方向），单位是伏特（V）。

**常见误区 / 注意点：** ① 电势**不是矢量**、不说方向，只说高低；② **电势和电势能不是一回事**——电势是"每单位电荷的位能"，电势能是"整段电荷的位能"，两者差一个电荷量；③ 电势的高低的"参考零位"是人为选的（常取无穷远处为 0）；④ 正电荷顺着电场线走电势降低，负电荷反过来——这一条最容易搞反。

**比喻 / 例子：** 把电场想成一片有起伏的地形，每个位置都标着"海拔高度"，这个"海拔"就是电势。带电粒子就像个登山者，从高海拔往低海拔跑时"自带冲劲儿"（正电荷），而有的粒子（负电荷）反而爱往高处爬。

**一句话总结：** 电势就是电场里各点的"势能标尺"，它是标量、要分清它和电势能的区别，正负电荷的走向正好相反。

## ⚠️ 六、别这样做

- ❌ **不要**堆砌术语不解释——读者会当场闪退。
- ❌ **不要**只背定义不展开——概念解释要讲"为什么"和"怎么用"。
- ❌ **不要**在该讲黑话和坑的社会性概念上省略——那等于答非所问。
- ❌ **不要**在非社会性概念上强行编"行业黑话"——没有就是没有，硬编反而误导。
- ❌ **不要**啰嗦跑题——聚焦这一个概念，讲深讲透。

## 📄 七、把概念整理成文档保存（当用户明确要求落盘时）

默认情况下，本 skill 直接在聊天里解释概念即可。**但当用户明确要求"把这些概念整理成文档 / 保存 / 存到 xx / 整理成笔记"时，执行方式改为文档化落盘**：

1. **调用 `/文档转换+排版`**：让该 skill 来整理这些概念文档，遵循它的 Obsidian 笔记排版规范（frontmatter、概要 callout、重点标记、知识库双向链接等）。
2. **存储位置**：以用户指定位置为准；用户没说时，存到知识库 `总结好的大纲以及笔记/实习就业/概念/` 下。
3. **文档命名**：遵循目标目录已有文档的命名格式——`术语-通俗解释.md`（如 `五险一金-社保五险加公积金.md`、`[英文缩写]-[中文全称].md`），用单个短横线连接。
4. **每个概念单独一篇**：用户说"每个概念一个文档 / 分别存储"时，逐个概念独立成文，不合并；概念间有关联的在各文档内做双向链接。
5. 文档内容仍遵循本 skill 的解释逻辑：社会性概念讲透「行业黑话 + 常见坑点」，并配比喻/例子。

### 触发判断

- 用户句子里出现"整理成文档""存成文档""保存""存储""整理成笔记""写入文档"等**落盘指令** → 走文档化流程（调用 /文档转换+排版）；
- 用户只是问"什么是 XX"，没说保存 → 默认聊天解答即可。
