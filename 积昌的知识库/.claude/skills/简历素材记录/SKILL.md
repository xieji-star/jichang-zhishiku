# 📋 简历素材记录 Skill

将用户的新的工作/实习/项目经历，按照「谢积昌简历素材库」的统一格式记录到对应的素材库文档中。

## 核心工作流

### Step 1：确认工作内容信息

在开始写入之前，必须先理解用户的新经历。用户可能已经提供了完整信息，也可能需要你追问。**需要确认以下字段**：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 公司/项目名称 | ✅ | 实习的公司名称或项目名称 |
| 所属部门/业务线 | ❌ | 如：数智科技部门·图灵学术 |
| 岗位/角色 | ✅ | 如：矩阵账号运营实习生 |
| 时间 | ✅ | 如：2026.07 — 至今 |
| 工作内容 | ✅ | 具体做了什么，分点描述 |
| 产出/成绩 | ✅ | 量化的结果数据 |
| 创始人/产品形态 | ❌ | 如有，可补充 |

> 💡 **用户可能已提供完整信息**：如果用户一次性说清楚了以上所有信息，则直接进入 Step 2，无需逐一追问。只有当信息明显缺失时才针对性追问。

### Step 2：读取现有的简历素材库

读取 `总结好的大纲以及笔记/浪尖训练营/实习训练营/课程里面的其他东西/简历素材库/谢积昌简历素材库.md`，理解：

- **文档结构**：YAML 头部 → 更新说明 → 基本信息 → 校内经历 → 校外经历 → 证书资质 → 技能清单 → 其他亮点 → 经历与岗位匹配速查表
- **经历编号规则**：目前最大编号，新经历编号 = 当前最大编号 + 1
- **表格格式**：固定使用 `| 项目 | 内容 |` 两列表格
- **包装方向格式**：使用 `> **🎯 可以往哪方面包装：**` 引用块，每行用 `- **方向名**：说明`

### Step 3：判断经历归属类型

根据经历类型，判断插入位置：

| 类型 | 插入位置 | 说明 |
|------|---------|------|
| **实习经历** | 校外经历 → 1. 实习经历 | 在公司/单位工作 |
| **校园大使/社会实践** | 校外经历 → 2. 校园大使/社会实践 | 短期项目或校园大使 |
| **竞赛/比赛** | 校外经历 → 3. 竞赛/比赛 | 比赛相关经历 |
| **创业/项目经历** | 校外经历 → 4. 创业/项目经历 | 自己创业或合伙项目 |
| **其他校外经历** | 校外经历 → 5. 其他校外经历 | 无法归类的校外经历 |
| **校内经历** | 校内经历 → 各子分类 | 学生会、班级、校内项目 |

### Step 4：写入新经历

按以下模板格式插入新经历：

```markdown
#### 经历{N}：{经历名称} ← 新增

| 项目 | 内容 |
|------|------|
| **公司** | {公司全称} |
| **岗位** | {岗位名称} |
| **时间** | {开始时间} — {结束时间/至今} |
| **工作内容** | {分点描述做了什么} |
| **产出/成绩** | {量化结果数据} |

> **🎯 可以往哪方面包装：**
> - **{方向1}**：{包装说明}
> - **{方向2}**：{包装说明}
```

**格式要点：**
- 表格使用 `| **字段名**` 加粗格式
- 时间格式统一为 `YYYY.MM — YYYY.MM` 或 `YYYY.MM — 至今`
- 工作内容中的分点用中文分号 `；` 或 `；` 分隔，**不要使用 Markdown 列表**（保持表格内单行文本）
- 包装方向使用 `> **🎯 可以往哪方面包装：**` 引用块
- 每个包装方向用 `- **方向名**：` 格式
- 在每个新经历的标题后添加 `← 新增` 标记（仅第一次写入时，后续迭代不再标记）

### Step 5：更新文档头部元数据

更新以下头部字段：

```yaml
最后更新: {当前日期 YYYY-MM-DD}
标签: #简历素材 #求职准备 #经历包装 #新经历相关标签...
```

在「更新说明」中追加记录：
```
{当前日期} 新增经历{编号}：{公司/项目名 — 岗位}实习经历。
```

### Step 6：更新「经历与岗位匹配速查表」

在 `## 七、经历与岗位匹配速查表` 中，根据新经历的属性，在对应的岗位方向中添加引用：

| 匹配类型 | 修改方式 |
|---------|---------|
| 高度匹配的岗位方向 | 在「最匹配的经历」列末尾添加 `**㉒新经历名**` |
| 辅助匹配的岗位方向 | 在「辅助经历」列末尾添加 `**㉒新经历名**` |

同时在表格后追加的 `> 💡 **新增说明**` 中简要说明新增内容。

### Step 7：更新「其他亮点」中的相关部分

如果新经历有可展示的链接、作品或新增的技能，更新以下部分：
- `### 作品/链接` — 添加作品链接
- `### 个人优势/特点` — 如果衍生出新优势可补充
- `### 技能清单` — 如果涉及新工具/技能可补充

### Step 8：确认结果

写入完成后，向用户简要说明已完成的操作：
- 新增经历编号和名称
- 插入位置
- 更新了哪些关联部分

## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 用户信息不完整 | 针对性追问缺失字段，不全部重问 |
| 已有同类经历 | 按编号顺序追加，不覆盖已有内容 |
| 更新已有经历 | 使用「编辑」而非「新建」，并在更新说明中注明 |
| 素材库文件不存在 | 报错提示路径错误，不自动创建新文件 |
