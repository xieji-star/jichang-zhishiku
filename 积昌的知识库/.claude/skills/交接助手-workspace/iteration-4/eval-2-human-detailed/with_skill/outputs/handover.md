## 2. 项目总览（大白话）

- **这个项目是做什么的**：公司是做考研培训的（主攻"在职考研"人群）。以前获客全靠销售打电话、发传单，又贵又累。今年 6 月公司决定做小红书——因为目标用户（在职想考研的上班族）就泡在小红书上。于是开了这个官方账号，专门发"考研怎么复习、怎么选专业、怎么避开培训机构坑"这类干货笔记，把感兴趣的人引流到公司微信，再转给销售跟进。**简单说：用内容帮公司"捡"客户，而且是免费的。**
- **为谁做、解决什么问题**：为公司解决"获客成本高、渠道单一"的问题；用户看到有用内容 → 关注账号 → 私信/评论区咨询 → 加销售微信 → 买课。
- **一句话讲清项目价值**：这是一个低成本的获客入口，公司指望它长期带来稳定的咨询量。你做得好不好，直接关系到销售那边每个月有多少"新线索"。
- **整体完成度估算**：**约 80%**。
  - 判断依据：账号搭建 ✅、定位 ✅、内容生产体系 ✅、首期导流活动 ✅、数据周报 ✅（这五块都做完了）；还没做完的是：选题库剩余稿件、二期导流活动、话术库、月度复盘、投放方案（这五块见第 7 节）。
  - 也就是说：**"地基"和"日常运转"已经就绪，剩下的是"补全弹药"和"扩大战果"。**

## 3. 背景与来去脉

### 3.1 项目怎么来的

- 今年年初，公司销售部门反馈"电销获客成本越来越高，一个有效线索要花 400~500 元"。市场部调研发现：目标用户（25~35 岁在职人群）刷小红书的比例很高，而且**小红书官方现在是"搜索型"平台，用户会主动搜"考研 在职 备考"这类关键词**，内容做得好能持续白嫖自然流量。
- 于是 6 月初立项，由市场部主管（王姐，见第 11 节）牵头，招了我这个实习生专门负责落地。**这个项目本质上是公司的一次"低成本获客实验"**，所以公司给的钱很少、人也很少，大部分工作靠我一个人 + 设计师偶尔支援。

### 3.2 关键约束和前置信息（这些决定了很多决策）

| 约束/背景 | 说明 |
|----------|------|
| 账号是**企业号**（蓝V） | 能挂官网链接、能投广告，但比个人号更容易被判定"营销"，**发广告词有讲究**（见第 10 节踩坑记录） |
| 团队只有我一个人全职做内容 | 设计是借调的，产出速度有限；所以内容设计成"模板化批量生产" |
| 公司给的 KPI | 月均"有效咨询线索 ≥ 60 条"（即加到销售微信、且是真实考研意向用户） |
| 内容红线 | 不能承诺"保过""包上岸"，不能编造学员成绩（教育广告法规+平台规则） |
| 每周固定动作 | 每周三、五、日各发 1 篇笔记（周更 3 篇），每周一写上周数据周报 |

### 3.3 和公司其他事情的关系

- 内容方向要配合公司课程产品节奏：比如公司 9 月要开"秋季考研强化班"，对应内容就要提前 2~3 周铺垫。
- 获客链路：**小红书笔记 → 评论区/私信 → 加企业微信 → 销售跟进**。销售那边每周一看我发的数据周报，所以周报不能断。

## 10. 关键决策与踩坑记录（给你最值钱的部分）

### 10.1 关键决策

| 决策 | 为什么这么选（大白话） |
|------|----------------------|
| 定位选"在职考研信息差"，而不是"泛考研" | 泛考研（大学生考研）竞争惨烈，全是机构在发；在职人群内容少、需求强、决策重（愿意付费），更稀缺、更好起号 |
| 周更 3 篇而不是日更 | 只有我一个人全职，日更质量会崩；**稳定比量大更重要**，3 篇是保证质量下的可持续频率 |
| 图文为主（22 图 : 6 视频） | 图文制作快、模板化程度高，一个人能撑住；视频留作后续精力富余时的增量 |
| 封面模板化 | 一个人做内容，必须把"重复劳动"标准化，才能腾出时间做选题和导流 |
| 用"免费资料"做导流钩子 | 在职用户"想要实用资料"的心理最强，资料类钩子加微转化率最高（第一期 39.7%） |
| 数据口径统一在周报里 | 销售、王姐、我都说同一套数字，避免扯皮；你接手后**必须沿用同一口径**，不要自创 |

### 10.2 踩过的坑（现象 → 根因 → 怎么避开）

1. **笔记被限流**：7 月中旬一篇笔记曝光从正常 3000+ 掉到 200。
   - 根因：正文里写了"最全""第一"这种违禁词 + 标题带了"免费"（营销嫌疑）。
   - 怎么避开：发布前用第 12 节的"敏感词检查清单"自查一遍；"免费"改说"有需要的我发你"。
2. **封面字体侵权**：Canva 里有个字体是付费商用字体，用了几次后收到平台提醒。
   - 根因：没注意 Canva 模板字体的"商用授权"标记。
   - 怎么避开：只用模板库里已标注"可商用"的字体/模板；不确定就换系统默认字体。
3. **评论区回复口径不一**：同一期活动，我回"私你哦"，另一个帮忙的同事回"加这个微信"，用户困惑。
   - 根因：没有统一话术，临时手写。
   - 怎么避开：这就是接力棒 #3（话术库）存在的原因，你接手后务必补上并坚持使用。
4. **导流话术踩敏感词**：第一期活动正文写了"加微信"，被平台判定营销限流，活动首日曝光极低。
   - 根因：小红书对"微信号"字样很敏感。
   - 怎么避开：正文永远不出现"微信/加V/私聊"字眼，用"评论区扣1/私信我"这种平台内引导。
5. **数据对不上**：有次周报我写"线索 12 条"，销售说只收到 8 条。
   - 根因：我把"加了微但没留意向"的人也算了线索。
   - 怎么避开：**线索口径 = 加微 + 有明确考研意向**，两者缺一不算；新实习生沿用此定义，别自己改。

### 10.3 试错过、但放弃的方案

- **做"考研名师拆解"系列**：试了 2 篇，互动不错但容易触及讲师个人权益，怕惹麻烦，放弃了。可以留着以后公司愿意做再捡起来。
- **日更 + 多开一个小号**：试了一周，一个人撑不住质量，果断砍掉，回到"精做一主号 + 周更 3 篇"。
