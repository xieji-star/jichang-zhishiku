## 3. 术语表

> 这些词在群里、文档里、mentor 口中高频出现。**看到不懂的回来翻这一节。**

| 术语 | 大白话解释 |
|---|---|
| **矩阵号 / 矩阵账号** | 公司同时运营的一批抖音账号（同一人设"华哥"拆成多个号），互相配合引流。本组叫"华哥系列"，共 4 个号 |
| **脚本** | 视频/图文的"口播文字稿"，先写稿再配音、配画面。**所有内容的源头** |
| **口播稿** | 就是"念出来的文案"。数字人口播视频里，AI 念的就是口播稿 |
| **图文** | 抖音的"图文模式"（图片+文字，不是视频）。制作比视频简单 |
| **私域** | 抖音（公域）以外的、能直接联系到用户的地方，主要指微信/企业微信。把用户从公域引到微信，就叫"引流到私域" |
| **线索** | 一条"潜在客户信息"= 用户的论文区位 + 研究方向 + 研几 + 微信号/手机号 |
| **灯塔系统** | 公司内部的客户线索登记平台（网址 `dengta.tulingxueshu.com`），**只能用飞书账号登录**。你录进去，后面的销售/导师才能接上 |
| **SCI** | 国际核心期刊检索体系，分一区到四区，一区最牛，分区越高辅导越贵 |
| **CCF** | 中国计算机学会的论文评级，A / B / C 三类，A 类最权威 |
| **EI** | 工程领域论文索引，分"期刊"和"会议"两种 |
| **保发** | "保证论文被录用发表"——公司敢卖高价的底气 |
| **引荐价** | 通过推荐/引荐渠道购买的价格，相当于"渠道优惠价" |
| **分步结账** | 分期付款。因为客单价高（3万~68万），客户又是学生，所以分阶段交钱 |
| **数字人 / HeyGen** | 用 AI 生成一个"真人形象"来念稿的视频。HeyGen 是生成数字人的网站 |
| **TTS** | 文字转语音（Text-To-Speech）。把脚本变成 MP3 音频 |
| **MiniMax** | 公司用来生成 AI 语音的平台（共享账号） |
| **剪映** | 剪辑软件（桌面端），用来剪视频、做封面、加字幕 |
| **内容线** | 脚本选题的四种风格分类（见第 7 节 7.3）：技术痛点 40% / 方向判断 25% / 案例故事 20% / 筛选劝退 15% |
| **查重** | 写新脚本前，先检查这个选题以前有没有写过、跟竞品像不像，避免被抖音判"内容重复"限流 |
| **脱题** | 内容跑偏，跟"论文/科研"没关系了。**红线，绝对不能脱题** |
| **DOU+** | 抖音的付费推广工具，花钱买播放量 |
| **置顶三件套** | 账号主页置顶的三条内容：人设 + 筛选 + 信任（见 7.3） |
| **MediaCrawler** | 一套开源的抖音爬虫程序（在你电脑 D 盘），用来自动采集视频数据 |
| **妙搭（Miaoda）** | 托管前端网页的平台（`ncn5iae3ocvu.feishuapp.com/app/app_17bkk0a8pt8`），爬虫工具的数据看板托管在上面 |
| **SQLite** | 一种本地数据库文件，爬虫工具的数据都存在 `D:\全自动爬取短视频、推文爆款程序\data\radar.sqlite3` |
| **CDP** | 让程序控制 Edge/Chrome 浏览器的技术。爬虫工具靠它用"你的抖音登录态"去采集 |
| **ASR / 转录** | 语音识别转文字。把视频里的话提取成文字稿，就是"口播稿转录" |

## 4. 背景与来龙去脉

### 4.1 为什么会有这个岗位

图灵学术靠"论文辅导"赚钱，获客方式是**新媒体引流**（抖音为主）。所有业务线的获客套路都一样：**内容获客 → 私域 → 转化**。本岗位就是这条链路最前端——**内容获客 + 初步筛选**。

前端引流整体由 **4 个小组、20+ 个矩阵号**构成：

| 齐发发组 | 长沙 | 真人实拍出镜为主 |
| 敏敏子组 | 北京 | 鱼哥系列矩阵号 |
| **韩玲组（你所在）** | **北京** | **华哥系列 4 个号** |
| 小七组 | 北京 | 七哥系列矩阵号 |

### A. 入职第一周（立刻做，照着顺序来）

1. **上班第一件事：打开飞书**，看 mentor 韩玲的消息和脚本反馈。
2. **把本组历史内容翻一遍**：打开文件夹
   `总结好的大纲以及笔记/实习就业/工作文件/脚本&推文撰写/脚本资料库/创作好的脚本` 和 `创作好的推文`，
   看看之前的号发过什么选题、什么风格。**这一步决定你写新脚本会不会和旧内容撞车。**
3. **读《受众报告》**：`脚本资料库/参考的资料/受众报告/受众报告.md`，了解你的目标用户是谁、四条内容线怎么分。
4. **确定当天选题**（先查重再动笔）：
   - 对照「已覆盖主题清单」+ 历史脚本库 + 竞品爆款库（`参考的资料/对标案例/脚本改良对标分析.md`）。
   - 选题必须和**论文/科研**相关，不能脱题。
5. **写脚本**：按「黄金三秒开头 → 中间七步信息点 → 结尾钩子」结构写（模板见 `参考的资料/案例文件/脚本结构与目前的案例/短视频内容结构+钩子结构表.xlsx`）。
6. **发飞书给 mentor 审核** → 按反馈改到定稿。
7. **制作视频**（全流程）：
   - 内部优化工具优化关键词（部门自研网页工具）；
   - **TTS 纠错工具**做发音预处理（本地 HTML：`lark-resources/数字人口播脚本发音处理.html`）——**每次配音前必做**，否则 SCI/C刊 会被 AI 读错；
   - **MiniMax** 生成 AI 语音（`minimax.io/audio`，共享账号，**别改密码**）；
   - **HeyGen** 生成数字人视频（首次登录找 mentor 协助）；

## 8. 关键决策与踩坑记录（前人经验，最值钱的部分）

### 8.1 日常运营

1. **内容好坏看"私信质量"，不看播放量**。播放量高但来的人不精准 = 白干。这是 mentor 反复强调的核心标准。
2. **脚本必须查重**：曾有一条 1 万+ 播放的视频被抖音判"内容重复"直接限流。4 个矩阵号月初统一生成的脚本最容易互相重复，写之前务必对照历史库。
3. **选题绝不脱题**：曾有一篇稿子内容变成"怎么防导师画饼"，被 mentor 判定严重脱题。判断口诀：**话题泛可以，方向不能偏**——把稿子里"华哥/学员"换成任意职场博主，如果内容照样成立，就是脱题了。
4. **配音前必过 TTS 纠错**：否则"SCI"会被 AI 读成字母串。
5. **抖音监管红线**：评论区/私信**禁止直接说"微信"**（会触发限流），用"卫星"或"\/"。陌生人私信一小时内最多回约 50 条，多了会发不出去——多号轮换 + 分段回复应对。
6. **线索宁缺毋滥**：只有"真需要论文辅导、有较大意向"的人才录灯塔；白嫖领资料的录了也转化不了，浪费销售团队精力。
7. **私信话术别用死**：话术里的课题名称（如"网安"）要根据当前脚本内容换，不能一直不变。
8. **剪辑全自己来**：已不用外包，所有视频自己用剪映剪，提前排好时间。

### 8.2 爬虫工具（踩过的技术坑，供维护时参考）

1. **正式代码在 D 盘，F 盘只放文档**——F 盘写入慢。
2. **pyvideotrans 只认本地文件，必须 Python 3.10**——不能直接喂 URL，要先下载到本地任务目录，用独立 `.venv-stt` 环境。
3. **"先写库再删临时文件"**：口播稿写进数据库成功后才允许删视频/WAV/SRT，防止转录丢失。
4. **播放量拿不到就老老实实存空值，绝不伪造 0**。
5. **MediaCrawler 许可**：只允许"非商业学习"，公司商用前要先联系作者拿授权。
6. **抖音风控（Argus/验证码）是合法人工介入点**——系统绝不尝试绕过验证码，遇验证码要人工处理。
7. **临时文件自动清理**：成功任务产物应自动删除，不要手动留一堆 490MB 的 job 目录。
