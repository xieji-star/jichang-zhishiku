## 7. 关键决策与踩坑记录

### 7.1 关键决策（为什么这么做）

| 决策 | 原因 |
|------|------|
| **A 线从"接收脚本"升级为"全流程独立创作"**（7-30） | mt 要求运营全链路独立，提升岗位价值；脚本创作是获客质量的第一道关卡 |
| **脚本先查重再动笔 + 去同质化**（8-04） | 一条 1 万+ 播放视频被抖音以"内容重复"贴标签限流——高播放不保险，原创是硬指标；4 矩阵号月初统一生成脚本同质化风险最高 |
| **四条内容线配比 40/25/20/15 + 私信质量 > 播放量**（8-04） | 5 万级客单价必须精准获客，泛流量无转化价值 |
| **选题不脱题红线**（8-06） | 曾有一篇稿件主体变成"验证导师口头承诺/防画饼"，被 mt 判定严重脱题；"话题泛可以，方向不能偏" |
| **B 线放弃付费抖音 API，改用 MediaCrawler** | 按次收费偏高、延迟不稳、部分需美元充值、批量获取能力不确定；开源采集器零按次成本 |
| **代码从 F 盘迁到 D 盘** | F 盘写入慢，Node/Python/Git 高频小文件操作卡顿；F 盘只留知识库文档 |
| **线上平台托管飞书妙搭** | 解决"无需个人电脑暴露端口 + 多人访问 + 登录鉴权 + 数据库"；早期 `chatgpt.site` 临时隧道被 Cloudflare 拦截 |
| **用稳定 UUID 做 accountId，不用账号名** | 显示名称会重名/改名，不能做主键；否则新增达人、分页、导出全串号 |
| **数据库先 Expand → Backfill → Contract 三阶段迁移** | 妙搭 dev→online 只同步 Schema 不同步 DML；先扩字段上线 → 幂等回填验零 → 再收紧 NOT NULL/外键，避免旧接口在窗口期写失败 |
| **B 线对抗组件启用（2026-08-16 用户决策）** | 用户明确拍板"突破合规红线、①类组件全部投入使用、风险自担"；原"隐身/指纹/代理轮换禁用"红线作废 |
| **删除 NopeCHA/代理池/nodriver**（8-16） | 用户要求删"要花钱或无法稳定投产"的组件，释放硬盘；免费的熔断/错峰/curl_cffi/mss/patchright 等保留投产 |

### 7.2 踩过的坑（现象 → 根因 → 规避）

1. **高播放视频被限流**：1 万+ 播放 → 被抖音贴"内容重复"标签 → 脚本创作前必须查重、去同质化。
2. **抖音封禁"微信"关键词**：私信/评论区直接说"微信"会被屏蔽或限流 → 改说"卫星 / \/"、引导进粉丝群扫码、多账号轮换 + 分段回复（陌生人私信 50 条上限）。
3. **口播稿曾跑偏自研 STT**：为省依赖自建 `radar_stt.py` 调 faster-whisper → 已删除，拉回 pyvideotrans 官方 `cli.py --task stt`，避免"引擎名与实现不一致"。
4. **转录环境 Python 版本冲突**：pyvideotrans 要 3.10，根环境是 3.12 → 独立 `.venv-stt`（Python 3.10.19）隔离运行，释放约 8GB 冗余依赖。
5. **下载被 SSRF 保护误拦**：本机代理 Fake-IP（198.18.0.0/15）被当成私网拦截 → 只特判该网段 + 阿里 DoH 校验真实公网地址，真实私网仍拒绝，**不扩大放行范围**。
6. **"全部视频"加载 0 条/卡死**：旧前端一次加载全量再 slice(0,100) → 改服务端分页 + 精确总数。
7. **线上 UI 没变化（以为缓存问题）**：实为功能分支没合并发布 → 开发要形成闭环：分支 → 测试 → 构建 → 发布 → 线上回读。
8. **云端"账号页查看视频固定指向同一达人"**：组件重挂载 + 旧初始化无条件全选 → 初始化优先级改为 URL 指定 > 当前选择 > 全选兜底，且达人 ID 大小写不敏感匹配。
9. **抖音 Argus/人机验证导致部分账号采集失败**：属平台风控，程序不绕过 → 预算+重试+监控应对（实测 argus=1 仍 20/20 完成）；需人工时会在已打开的 Edge 窗口完成验证。
10. **数据被伪装成 0**：早期页面把"未知/未采集"显示成 0 → 页面区分 none/partial/complete，缺失值显式标注，不造假 0。

## 8. 风险与待确认项

> [!warning] 需要你接手后重点盯防的地方

- ❓ **抖音账号风控/封禁风险**（B 线对抗组件已全量启用，用户自担）：持续观察账号级熔断器统计，出现连续风控信号（403/429/argus/验证码/封锁）及时冷却或回退开关。**合规责任归属请与用户确认**。
- ❓ **B 线运行前提**：采集需要个人电脑/服务器保持开机 + 抖音登录态；临时文件"成功后即删"是设计，**不要误删模型与可复用环境**（`pyvideotrans/models/` 与 `.venv-stt` 属长期资源）。
- ❓ **线上数据真实性**：云端真实采集尚未跑满 12 账号，线上看到的 0 不能被解释为真实业务指标；需等云采集/字段同步完整后再验收。
- ❓ **灯塔线索录入标准**：只录"有较大辅导意向"的用户；三大必填（联系方式/微信昵称/专业方向）缺一即不合格。拿不准是否该录 → 先记飞书表格、问 mentor。
- ❓ **脚本原创性**：每一条都先查重；与往期/竞品高度重合会被平台打标，影响整个矩阵权重。
- ❓ **脱敏提醒**：交接文档里的共享账号（MiniMax 等）是工作必需，请勿外传；爬虫项目的 API Key / Cookie / 浏览器 Profile 不得写进代码仓库或公开文档。
- ❓ **业务成果预期**：A 线短期 GMV 不会突然很高，属正常；以"私信质量 > 播放量"为标准向 mentor 汇报，不要为数据造假。
