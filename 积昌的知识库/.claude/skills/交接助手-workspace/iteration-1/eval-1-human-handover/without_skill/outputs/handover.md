## 四、日常核心工作全流程（我每天做什么）

完整操作细节全部在 **《矩阵账号日常运营SOP》** 和 **《灯塔平台线索录入SOP》** 里（位置见「七、资料与工具索引」），这里给流程骨架 + 关键点。

### 4.1 主流程一：视频制作与发布（数字人流水线）

```
① 脚本独立创作 → ② 内部工具优化关键词 → ③ TTS纠错工具（发音预处理）
    → ④ MiniMax AI 语音生成（下载 MP3）
    → ⑤ Heygen 数字人视频生成
    → ⑥ 剪映制作封面 + ⑦ 自己剪辑（字幕/特效画中画/BGM/黑板贴纸/结尾钩子）
    → ⑧ 抖音发布（定时或立即）→ ⑨ 携带高热度标签
```

**各环节要点：**
- **① 脚本创作（最关键，耗时长）**：
  - 创作前**必须查重**：对照「已覆盖主题清单」+ 历史脚本库 + 竞品爆款库，杜绝重复/同质化。
  - 遵循《短视频内容结构+钩子结构表》：**黄金三秒开头钩子（10 类模板）→ 中间七步信息点 → 结尾钩子（内容/资料/咨询三类）**。
  - 按**四条内容线配比**选题：技术痛点 40% / 方向判断 25% / 案例故事 20% / 筛选劝退 15%。
  - **选题必须与论文/科研相关，不得脱题**（见 5.4 红线）。
  - 创作完在飞书发 mentor 韩玲审核，按反馈修改定稿。
- **③ TTS 纠错工具**：每次 MiniMax 语音生成前**必须先用**，否则 AI 会把专业术语读错（"C刊"读成"C 刊"、"SCI"读成"S C I"等）。
- **⑦ 剪辑**：2026-07-30 起**不再用外包**，全部自己用剪映剪（字幕→特效/画中画→BGM（音量 10%-20%）→黑板贴纸→结尾钩子）。

### 4.2 主流程二：推文（图文）制作与发布

比视频简单：**脚本创作 → 内部工具优化关键词 → 制作图文内容（配图+文字）→ 抖音图文模式发布 → 携带标签**。无需数字人和视频剪辑。

### 4.3 主流程三：发布后运营

1. **评论区置顶**：按脚本确定关键词（常为"投稿"），发布并置顶引导评论。
2. **弹幕区发布 3 条固定信息**：点赞接 Accept / 听说第一秒点赞的都发顶会了 / 进群领取资料。
3. **评论区巡查**：约每小时 1 次，回复互动。
4. **私信转化**：用话术引导用户留下「想发表的论文区位 + 研究方向 + 目前研几 + 微信号/手机号」。
5. **粉丝群运营**：新成员进群发资料，群人数增加时重复发。

### 4.4 辅助流程：灯塔线索录入

- 从评论/私信获取意向用户线索 → 初步筛选 → 录入**灯塔平台**（https://dengta.tulingxueshu.com/，**仅支持飞书登录**）。
- **只录高意向用户**：真实需要论文/科研辅导的才录；单纯领资料的用户**不录**。
- **线索合格线（三大必填缺一不可）**：联系方式（微信号/手机号）+ 微信昵称 + 专业方向与研几。备注选填（学员当前问题，便于销售针对性话术）。
- **线索流转链路（2026-08-05 确认）**：小组间线索**先统一记录到飞书表格**（不直接录入灯塔），由 **mentor 判断筛选**后正式录入灯塔。这个流程以 mentor 实际要求为准。

### 4.5 每日例行沟通

- **每天上班先看飞书**，确认 mentor 是否有新安排或脚本反馈。
- 脚本通过飞书发给 mentor 韩玲审核。

### 5.3 辅助项目：全自动爬取短视频/推文爆款程序

> 这是我实习期间主导开发的辅助项目（Vibe Coding 方式：我给需求，Codex 写代码），为矩阵账号运营提供爆款数据支撑。文档都在 `总结好的大纲以及笔记/实习就业/全自动爬取短视频、推文爆款程序/`。

**项目简介**：
- **目标**：自动采集公司 13 个抖音矩阵号的视频数据 → 识别爆款（S/A/B/C 分级）→ 提取口播稿件 → 同步飞书供团队查看。
- **技术栈**：Python + MediaCrawler（浏览器采集）+ GPU-ASR（faster-whisper/CUDA 12.8, RTX 5060）+ SQLite + 飞书 API + 自研风控组件（熔断器/随机错峰/全局限速/指数退避/curl_cffi TLS 指纹/mss 截图/patchright 无检测浏览器）。
- **项目根目录**：`D:\全自动爬取短视频、推文爆款程序`（在 vault 外）。
- **主链路**：字幕直取 → 接口级 → 浏览器（MediaCrawler）三线路降级架构。

**当前进度（截至 8 月 17 日，详见开发日志 0809-0817）**：
- 风控组件已全部接线进生产链路（0816 十轮测试全绿，十轮真实采集零账号封锁）。
- 0817 完成速度专项优化（转录并行度 +50%、单账号采集耗时 542s→约 480s）、Edge 窗口清理、云端账号页 BUG 修复并部署。
- 数据库已补建 28 个对标账号映射。

### 5.4 我踩过的坑（红线，务必记住）

1. **抖音"内容重复"限流**：8 月初一条 1 万+ 播放视频被官方以"内容重复"**贴标签限流**。之后脚本创作必须**先查重再动笔**，4 个矩阵号月初统一生成脚本时同质化风险最高。
2. **选题脱题被批**：曾有稿件内容主体变成"如何验证导师口头承诺/防导师画饼"，被 mt 判定**严重脱题**。红线：**无论大选题（流量型）还是小选题（干货型），都必须与论文/科研相关，一律不得脱题**。口诀：**话题泛可以，方向不能偏**。把"华哥/学员"换成任意职场博主内容依然成立 = 已脱题。
3. **抖音监管规避**：公共区域（评论区/私信）**禁止直接说"微信"**，用 **"卫星" 或 "\/"** 替代；陌生人私信回复有 **50 条上限**，超过发不出去，应对：多账号轮换回复 + 分段间隔回复。
4. **线索不要滥录**：只录高意向用户，单纯领资料的"白嫖"用户不录，否则销售团队难以转化。
