## 2. 项目总览（大白话）

- **这个项目是做什么的**：公司有两个短视频账号——**抖音号**（主打技术干货，面向程序员/技术从业者）和**视频号**（主打职场求职干货，面向大学生和刚入职场的年轻人）。这两个账号每周都要发 3 条短视频。账号本身不是用来直接卖货的，而是用来**给公司引流获客**——把看视频的人吸引到公司的付费课程和咨询服务上。
- **项目里具体干什么**：一共四块活——
  1. **选题**：决定每周发什么主题（比如"转行程序员值不值""简历怎么写才不被筛"）；
  2. **写脚本**：把主题写成 60～90 秒的口播稿（说话用的稿子），交给出镜的人照着念；
  3. **排期发布**：把写好的脚本排进发布日历，按节奏发出去，配好标题、封面、话题标签；
  4. **数据复盘**：发完后看播放量、完播率、互动量，总结什么内容有效、什么没效，指导下一轮选题。
- **为谁做、解决什么问题**：为公司市场获客团队服务，解决"内容不知道发什么、发了没人看、看了不转化"的问题。
- **项目价值（为什么要做）**：短视频是目前获客成本最低的渠道之一。这套项目跑通后，公司可以稳定地靠内容获客，减少对广告投放的依赖。
- **整体完成度估算**：约 **70%**。流水线已经能跑通（选题→脚本→发布→复盘都有产出），但**还没有跑成"标准化的可复制流程"**——很多环节还靠前任（我）的个人经验撑着，脚本资料库没填满、SOP 没定稿、复盘机制还比较粗。这就是你接下来要补完的部分。

## 3. 背景与来去脉

- **项目怎么来的**：2026 年 5 月底，公司市场部决定做"内容获客"，但一开始既没专人也没流程。当时运营部只有一位运营同事（华哥）在管账号，忙不过来。6 月初我入职实习，任务就是把"发视频"从"想到什么发什么"变成"有计划地生产内容"。
- **为什么选了短视频**：老板判断公司目标客户（想转行/想提升的职场人）主要在抖音和微信视频号上刷短视频，比图文更触达年轻人；而且公司没有预算投大量广告，内容是性价比最高的入口。
- **组织关系**（谁是谁，方便你找人）：
  - **华哥**：运营部正式员工，是我的直接上级，管着两个账号的最终发布权。脚本写完后要经他确认才进排期。他目前人在公司，是主要求助对象。
  - **雷勤**：市场部领导，决定项目大方向（比如"下季度主攻求职方向"），不参与日常执行。
  - **出镜人（小马）**：负责在镜头前念稿，你只负责写稿和排期，不用出镜。
- **关键约束与偏好**（踩出来的规矩，务必遵守）：
  - **选题方向**：公司要求内容必须"干货优先、不蹭娱乐热点"，宁可不发也不发和业务无关的搞笑内容；
  - **口吻**：账号人设是"专业但不说教"，脚本里禁止出现"家人们""老铁"等词；
  - **时长**：每条 60～90 秒，超过 90 秒完播率会明显下降；
  - **审核**：任何脚本在排期前都必须经华哥过目，**不要自己直接发布**；
  - **数据口径**：内部统一用"完播率 > 25%、点赞率 > 2%"作为"内容及格线"，低于及格线的选题类型下次要少做。
- **和团队其他事的关系**：这套脚本生产的成果会同步给销售团队做转化素材（例如把高播放的脚本改编成销售朋友圈文案）；也跟公司正在搭的 CRM（客户管理系统）对接——视频号挂载的"报名表单"会把线索直接进 CRM。你暂时不用碰 CRM，知道有这层关系即可。

## 4. 术语表

> 项目里出现过的专业词、缩写、内部黑话，逐条大白话解释。**哪怕你觉得很基础，也写出来了——因为每个词你迟早会碰到。**

| 术语 | 大白话解释 |
|------|-----------|
| **口播脚本** | 出镜人照着念的说话稿，一般按 60～90 秒的语速写成 300～450 字 |
| **选题** | 决定"这条视频讲什么主题"，是生产线的第一步 |
| **内容线** | 给选题分类的框架。本项目按受众报告分四类：**技术痛点型**（占40%，讲技术难题）、**方向判断型**（占25%，讲要不要转行/怎么选）、**案例故事型**（占20%，讲真实经历）、**筛选劝退型**（占15%，帮用户避坑、劝退不适合的人）。比例来自受众报告，写脚本时要按这个比例分配条数 |
| **受众报告** | 一份说明"看我们视频的人是谁、他们愁什么"的报告。是全项目选题的"宪法"，先读它再定选题 |
| **脚本资料库** | 存放所有已写完脚本的文件夹，按内容线分类，写新脚本前先来这查重、找灵感 |
| **黄金 3 秒 / 开头钩子** | 视频前 3 秒留住人的话术。前 3 秒留不住人，后面都是白拍。每篇脚本开头必须有钩子 |
| **完播率** | 看完整条视频的人 / 看到这条视频的人。这是本项目最重要的指标，及格线 25% |
| **点赞率 / 互动率** | 点赞数/播放数、评论+收藏+转发/播放数。互动率及格线 2% |
| **CTR（点击率）** | 标题和封面让多少人点进来看。平台不给直接数据时，用"播放量/曝光量"估算 |
| **封面** | 视频的封面图+大标题，决定用户刷到时点不点进来 |
| **排期表 / 内容日历** | 一张写着"哪天发哪条"的表格，保证发布节奏稳定 |
| **话题标签** | 发视频时带的 #标签，帮助平台把视频推荐给对的人 |
| **对标账号** | 同行业做得好的账号，用来学习选题和写法（本项目对标了 3 个） |
| **SOP（标准作业流程）** | 把一件事写成"照做就行"的固定步骤文档。本项目要给"写脚本"这件事做一份 SOP |
| **数据复盘** | 视频发布 3～7 天后，拉数据看哪些内容有效，写一份简短总结 |
| **飞书** | 公司用的办公协作软件（聊天+文档+表格）。项目的排期表、复盘都放在飞书文档里 |
| **多维表格** | 飞书里像 Excel 但更强的表格工具，本项目用它管"选题池"和"脚本台账" |
| **AI 辅助写作** | 用 Claude 这类大模型帮忙写脚本初稿、查资料、改稿。注意：AI 只是助手，**每篇稿必须自己润色，不能直接发** |
| **蓝V账号** | 抖音的企业认证账号，有认证标识、可挂载官方信息（本项目抖音号已是蓝V） |
| **挂载 / 报名表单** | 视频上挂一个报名入口，观众点击可填表留下联系方式（本项目视频号挂了报名表单） |
| **BGM（背景音乐）** | 视频的背景音乐，运营同事负责配，你不用管 |
| **评论区置顶** | 发布后把自己写的一条引导评论置顶，引导观众互动，这属于你要做的运营动作 |

## 10. 关键决策与踩坑记录

> 这是前任踩出来的经验，**最值钱的部分**，你接手前必读。

### 10.1 关键决策（为什么这么选）

| 决策 | 为什么这么选（大白话） |
|------|----------------------|
| 两条账号内容方向分开（抖音偏技术、视频号偏求职） | 两个平台人群不同：抖音泛流量大、技术人群多；视频号偏职场、年纪稍大。分开写更精准 |
| 用四条内容线按比例分配选题 | 来自受众报告，避免"只做爱做的、不做有用的"；比例能保证内容结构健康 |
| 脚本控制在 300～450 字 / 60～90 秒 | 实测超过 90 秒完播率掉得很快，短而密是这套账号的最优解 |
| 每条脚本必须过华哥审核 | 出镜口径和合规（不夸大宣传、不承诺包就业）需要把关，前任曾被提醒过一次，宁可多审不可少审 |
| 用 AI 辅助写初稿、但必须人工润色 | AI 初稿能省 2/3 时间，但 AI 会编造案例和数据，必须人工核对事实 |
| 复盘固定在发布后 3～7 天做 | 3 天内数据没稳定、7 天后再看又太晚，这个窗口最准 |

### 10.2 踩坑记录（现象 → 根因 → 怎么避开）

| # | 现象 | 根因 | 怎么避开 |

| 3 | AI 初稿里编造了一个学员案例 | 给 AI 的提示词没限定"只能用真实素材" | 提示词里加"禁止编造案例，只使用我提供的素材" |
| 4 | 某条脚本华哥打回 3 次 | 稿子提到"转行包就业"，涉嫌夸大承诺 | 凡涉及"承诺结果"的表述一律避开，改用"提升概率/助力" |
| 5 | 排期表出现空位导致当天没内容发 | 脚本审核周期比预计长，排期没留缓冲 | 排期时每个发布位预留 3 天审核缓冲，库存不足 2 篇不排期 |
| 6 | 评论区"怎么报名"拖了 3 天没回，线索丢了 | 没有固定时间看评论 | 每天上午固定 15 分钟处理评论，当天必清 |

### 10.3 试错过但放弃的方案

| 放弃的方案 | 为什么放弃 |
|-----------|-----------|
| 日更（每天发 1 条） | 脚本产能跟不上，且审核质量下降；改为每账号每周 1 条 |
| 蹭热点追娱乐新闻 | 与账号"干货人设"冲突，老板否决 |
| 纯 AI 生成不润色直接发 | AI 出稿有明显 AI 味，且事实错误风险高，用户评论区会指出 |
