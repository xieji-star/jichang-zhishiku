## 2. 项目总览（大白话）

### 2.1 我们是做什么的

我们的业务线叫 **「图灵学术」**，卖的是**论文辅导 / 科研辅导服务**（帮研究生、博士改论文、做选题、冲 SCI/顶会等），客单价很高（¥3 万 到 ¥68.8 万）。母公司 **创业黑马** 是 A 股上市公司（股票代码 300688），是科研教育行业里唯一一家 A 股上市公司，这是重要的品牌背书。

**我们怎么赚钱（盈利模式 = 私域转化）**：

```
做抖音内容获客 → 用户评论区留言/私信 → 引导用户加微信（私域）→ 1对1 聊需求 → 卖出论文辅导服务 → 导师团队交付
```

- 一句话：**内容获客 → 私域引流 → 1对1 转化 → 论文辅导交付**。
- 你的岗位在**最前端（引流获客）**：你负责让更多人看到我们的抖音号，并把"有意向买论文辅导"的人筛选出来、录进系统。真正成交由后端的销售/导师团队负责，**不归你管**。

我们管它叫 **"矩阵号"**（Matrix Accounts），也就是一堆账号一起运营。你负责的是 **华哥组 4 个账号**（抖音号）：
1. **搞科研的华哥**

（注：整个部门还有"七哥组""鱼哥组"的账号，分别由其他同事负责，你只管华哥组。）

## 10. 关键决策与踩坑记录（最值钱的部分）

> 这些是我踩过的坑，你遇到类似问题直接避雷。

### 10.1 业务/运营层面的坑

| 坑 | 现象 | 根因 | 怎么避开 |
|----|------|------|---------|
| **内容重复被限流** | 一条播放 1万+ 的视频被抖音官方贴"内容重复"标签限流 | 4 个矩阵号月初统一生成脚本，同质化高；或与历史/竞品内容重复 | **先查重再动笔**；同一选题不在多账号用相近结构/话术重复发 |
| **选题脱题** | 稿件主体变成"验证导师口头承诺/防导师画饼"，被 mt 判定严重脱题 | 内容偏离"论文、科研"主题 | 话题泛可以，**方向不能偏**；写前用六项自查 |
| **大号播放低** | 「科研华哥」粉丝最多但播放低 | 疑似被平台限流；内容/服化道需调整 | 对标竞品调整；用"私信质量 > 播放量"来评估，别只盯播放 |
| **抖音说"微信"被屏蔽** | 私信/评论提到"微信"被平台屏蔽 | 平台监管私域引流 | 一律用"卫星"/"/"；引导进粉丝群扫码 |
| **陌生人私信回复超 50 条失败** | 消息发不出去 | 抖音对陌生人回复有数量限制 | 切换多个账号轮换回；分时段回 |

### 10.2 程序/技术层面的坑

| 坑 | 现象 | 根因 | 怎么避开 |
|----|------|------|---------|
| **第三方 API 贵且不稳** | 单次调用价格高、美元充值、延迟高 | 抖音数据高风控，第三方成本高 | 改用开源的 MediaCrawler（¥0） |
| **链接从哪来（设计死结）** | 原方案依赖"每日视频链接列表"，列表永远是空的 | 没人手动喂链接 | 改用 **creator 模式**：录入账号主页 URL，采集器自己发现全部新作品 |
| **F 盘写入慢** | 依赖安装、构建、小文件写入慢 | F 盘介质/挂载性能差 | 代码统一迁移到 **D 盘**（`D:\全自动爬取短视频、推文爆款程序`），F 盘只存文档 |
| **pyvideotrans 不能读 URL** | 把视频链接直接传给 pyvideotrans 报"文件不存在" | CLI 只接受本地文件路径 | 先**下载到临时文件**再转录，转录成功后删临时媒体 |
| **Python 版本冲突** | pyvideotrans 要求 3.10，项目其他环境是 3.12 | 依赖互斥 | 给 pyvideotrans 建**独立 Python 3.10 环境**（`.venv-stt`） |
| **线上数据全是 0** | 页面显示记录但互动数据为 0 | 采集没闭环/字段映射不全/页面默认值把缺失伪装成 0 | 页面不能把"未知"显示成 0；采集状态和失败原因必须可见 |
| **账号名不能做主键** | 新增达人后名称重复/改名导致串号 | 显示名称不是稳定身份 | 引入稳定 UUID `accountId`，名称只做显示 |
| **抖音验证码（Argus）** | 采集被拦截在验证码 | 平台风控，不能也不应自动绕过 | 人工在 Edge 完成验证；控制采集频率 |
| **临时文件膨胀** | 视频/音频堆积 | 转录后没清理 | 成功入库即删；失败按窗口保留后清理 |
| **云 IP/临时域名被拦截** | chatgpt.site 被 Cloudflare 拦截 | 临时隧道不适合 | 改用妙搭托管 |

### 10.3 我做过但放弃/删除的方案（别重蹈）

- **第三方付费抖音 API**（ApiZero 等）：贵 + 不稳 + 设计死结 → 弃用。
- **NopeCHA 自动验证码打码**（付费）：无 API Key、有反噬风险 → 8/16 已删除卸载。
- **代理池**：缺 HTTPS 代理源无法真正投产 → 已停用并清理运行时（源码目录保留，重启即恢复）。
- **nodriver 旁路**：未接线、无用 → 已删除。
- **自建 radar_stt.py 转录**：不是官方 CLI → 已删除，改用 pyvideotrans 官方 `cli.py --task stt`。
