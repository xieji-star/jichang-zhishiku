### 4.3 ③ 调度未接全自动

现在采集要手动跑，未接全自动。Windows 下用计划任务（schtasks）接：

```powershell
# 示例：注册每天 2 点的采集任务（确认入口脚本后再改命令）
schtasks /Create /TN "VideoCollector" /TR "python D:\全自动爬取短视频、推文爆款程序\main.py" /SC DAILY /ST 02:00 /F
```

> 先确认根目录到底哪个脚本是入口（`main.py`？`run.py`？看 §2 目录再定），别照抄上面命令里的文件名。

### 4.4 ④ 根目录无 git

项目根目录**没有 git 仓库**。接力动手前先建仓存档，防写坏：


## 7. 踩坑记录

- **无 git**：动手前先 `git init` + 首提交（§4.4），否则改坏没有后悔药
