## 3. 背景与来龙去脉

### 3.1 为什么会有这个岗位

论文辅导是高客单价的生意，获客方式靠**新媒体引流**（抖音为主）。整条业务线的获客套路都是同一套：**内容获客 → 私域沉淀 → 销售转化**。本岗位就是这条链路最前端——**用内容把精准用户吸引进来**。

前端引流不是一个人单打独斗，而是用**一批抖音账号**同时发内容，互相配合、扩大覆盖面——这批账号就叫"**矩阵号**"。

> ⚠️ **重要**：你入职后到底负责哪几个抖音账号，**以 mentor 韩玲的实际安排为准**，不要按我实习时的情况硬套。

## 4. 术语表

> 这些词在群里、文档里、mentor 口中高频出现。**看到不懂的，回来翻这一节。**

| 术语 | 大白话解释 |
|---|---|
| **矩阵号 / 矩阵账号** | 公司同时运营的一批抖音账号，互相配合引流。一批账号合起来叫"矩阵"，单个号叫"矩阵号" |
| **脚本** | 视频的"口播文字稿"。先写稿，再配音、配画面。**所有内容的源头** |
| **图文** | 抖音的"图文模式"（图片+文字，不是视频），制作比视频简单 |
| **私域** | 抖音（公域）以外、能直接联系到用户的地方，主要指微信/企业微信。把用户从抖音引到微信，就叫"引流到私域" |
| **线索** | 一条"潜在客户信息"，通常包含：用户的论文区位 + 研究方向 + 研几（硕士/博士几年级）+ 微信号/手机号。录进系统后，后面的销售才能跟进 |
| **灯塔系统** | 公司内部的客户线索登记平台，**只能用公司飞书账号登录**。你录进去，销售团队才能接上 |
| **SCI** | 国际核心期刊检索体系，分一区到四区，一区最牛；分区越高，辅导收费越贵 |
| **CCF** | 中国计算机学会的论文评级，分 A/B/C 三类，A 类最权威 |
| **EI** | 工程领域论文索引，分"期刊"和"会议"两种 |
| **DOU+** | 抖音的付费推广工具，花钱买播放量/曝光 |
| **CDP** | Chrome DevTools Protocol（Chrome 开发者工具协议）的缩写——让程序能"控制"浏览器。爬虫工具靠它用你的抖音登录态去采集数据 |
| **ASR** | 自动语音识别（Automatic Speech Recognition），把视频里的人声转成文字。爬虫工具用 ASR 把爆款视频的"口播稿"转录出来，方便你看内容 |
| **口播稿转录** | 把视频里说的话提取成文字稿，就是"ASR 转录" |
| **脱题** | 内容跑偏，跟"论文/科研"没关系了。**红线，绝对不能脱题** |
| **查重** | 写新脚本前，先检查这个选题以前有没有写过、跟竞品像不像，避免被抖音判"内容重复"限流 |
| **内容线** | 选题的风格分类，用来控制内容配比（比如技术痛点型、方向判断型等，见第 9 节） |
| **对标账号 / 对标达人** | 同领域做得好的账号，用来观察他们发什么内容、什么数据好，作为选题参考 |
| **限流** | 抖音不给你的视频推荐流量，播放量很低。违规内容、重复内容都可能被限流 |
| **风控（Argus/验证码）** | 抖音识别机器操作的安全机制。遇到验证码要**人工处理**，系统绝不能尝试绕过 |

## 10. 关键决策与踩坑记录（前人经验，最值钱的部分）

### 10.1 日常运营

1. **内容好坏看"私信质量"，不看播放量**。播放量高但来的人不精准 = 白干。这是 mentor 反复强调的核心标准。
2. **脚本必须查重**：曾有一条 1 万+ 播放的视频被抖音判"内容重复"直接限流。多账号同时生成的脚本最容易互相重复，写之前务必对照历史库。
3. **选题绝不脱题**：判断口诀——**话题泛可以，方向不能偏**。把稿子里的人设换成任意职场博主，如果内容照样成立，就是脱题了。
4. **配音前必做发音预处理（TTS 纠错）**：否则"SCI"会被 AI 读成字母串。
5. **抖音监管红线**：评论区/私信**禁止直接说"微信"**（会触发限流），用"卫星"或"\/"。陌生私信一小时内回太多会发不出去——多号轮换 + 分段回复。
6. **线索宁缺毋滥**：只有"真需要论文辅导、有较大意向"的人才录灯塔；白嫖领资料的录了也转化不了。
7. **私信话术别用死**：话术里的课题名称要根据当前脚本内容换，不能一直不变。

### 10.2 爬虫工具（踩过的技术坑，供维护参考）

1. **播放量拿不到就老老实实存空值，绝不伪造 0**。
2. **遇到验证码要人工处理**：抖音风控（Argus/验证码）是合法的人工介入点，系统绝不尝试绕过验证码。
3. **先写库再删临时文件**：口播稿写进数据库成功后才允许删临时视频/音频/字幕文件，防止转录丢失。
4. **临时文件要自动清理**：不要手动留一堆很大的任务目录。
5. **MediaCrawler 许可**：只允许"非商业学习"，公司商用前要先联系作者拿授权。
