## 一、项目全景：我们到底在做什么

### 1.1 一句话说清项目

我们运营一批**抖音账号（矩阵号）**，发布**学术论文辅导类**内容（教人写论文、发 SCI 等），把刷到视频、感兴趣的粉丝，从抖音**引导到微信**，再在微信里深度沟通、把有意向的人**记进"灯塔"线索系统**，最终交给销售/导师团队去转化成交。

### 1.2 完整的业务链路（核心逻辑，务必看懂）

整个业务是一条"流量 → 私域 → 线索 → 成交"的转化漏斗，你要记住每一步：

```
① 做内容（选题 + 拍摄/剪辑 + 文案）
        ↓
② 发抖音（矩阵号铺量）
        ↓
③ 聊到微信（私域，核心变现环节）
        ↓
④ 记线索（灯塔系统，CRM）
        ↓
⑤ 跟进转化（销售/导师团队）
```

**运营实习生负责的是 ① → ④**（内容生产、发布、引流、线索录入）。第 ⑤ 步由其他团队负责，但你的录入质量直接影响他们能不能成交。

### 1.3 为什么用"矩阵号"而不是一个号

- **分散风险**：单号违规限流、封号不影响全部业务；
- **放大流量**：同一选题多个号发，总曝光更大，总有人刷到；
- **测试效率**：不同号可以测试不同封面/文案/人设，跑出哪个好用再铺量。

### 1.4 学术论文辅导是个什么生意（理解背景用）

- **目标用户**：研究生、准研究生、有发论文需求的科研人员（硕博为主）；
- **需求点**：论文写不出来、不知道怎么发、想发 SCI/CCF/EI 等高水平论文；
- **我们提供的价值**：辅导写作、期刊投稿指导等；
- **获客逻辑**：用户刷到干货视频 → 觉得你有用 → 加微信 → 咨询 → 成单。所以**内容的专业度和真实感非常重要**，这也是"脱题红线"（见 7.2）严抓的原因。

## 三、专业术语速查表（新人必读，遇词即查）

按对你工作的重要性排序。**标 ★ 的是你必须烂熟于心的词。**

| 术语 | 含义 | 为什么你要知道 |
|------|------|----------------|
| **★ 矩阵号** | 同一个业务下运营的一批抖音账号，配合发布内容互相导流、放大曝光 | 你就是"管矩阵号"的人，多号发布是你的日常工作 |
| **★ 私域** | 指你能直接触达用户的渠道（典型就是微信好友/微信群），区别于抖音这类"公域"（流量归平台分配） | 业务的变现核心就是把公域粉丝导进私域 |
| **★ 线索** | 一个"有潜在成交可能的客户信息"，比如一个加了微信、咨询过论文辅导的人 | 你的 KPI 之一就是"线索量"，线索要记进灯塔 |
| **★ 灯塔系统** | 公司用的 CRM（客户关系管理）系统，用来记录、跟进、分配客户线索 | 你每天要把新加的微信客户录进去，录不准会影响转化 |
| **★ 脱题** | 内容偏离了我们"学术论文辅导"这个主题方向 | 选题红线之一，脱题内容不给发（见 7.2） |
| **SCI** | 科学引文索引（Science Citation Index），国际认可度最高的学术论文检索数据库之一，能在上面被检索的期刊俗称"SCI 期刊" | 目标用户最关心的"发高水平论文"主要指发 SCI |
| **CCF** | 中国计算机学会（China Computer Federation），会推荐计算机领域的重要期刊/会议目录（CCF A/B/C 类） | 计算机方向用户关注"CCF 推荐"的期刊会议，是选题常客 |
| **EI** | 工程索引（Engineering Index），另一个重要的学术检索数据库，覆盖工程技术类文献 | 与 SCI/CCF 并列，是用户常提的"论文检索/发表"目标 |
| **DOU+** | 抖音官方的付费推广工具，给视频花钱买曝光量 | 需要判断要不要投、投哪条视频，涉及运营决策 |
| **CDP** | 客户数据平台（Customer Data Platform），把各渠道客户数据汇总统一 | 理解"灯塔/线索数据从哪来、往哪汇总"用得上，报表可能涉及 |
| **ASR** | 自动语音识别（Automatic Speech Recognition），把语音转成文字的技术 | 视频转写文案、提取口播内容时会用到（爬虫/剪辑流水线里常见） |
| **日报/周报** | 每天/每周的数据汇报文档，记录发布条数、线索数、播放量等 | 你的例行产出，且当前存在口径不一致问题（见 4.3、6.3） |

> 补充：**"爬爆款"** 不是术语，是咱们内部对"自动爬取爆款视频"这个工具的简称，见 4.2。

### 6.2 🔥 爬虫工具端到端收尾（约 8 项）

下面是我记忆中的 8 项收尾点，**请你逐条核对哪些已完成、哪些还差**（以实际代码/运行为准），做完一项划掉一项：

5. **定时/增量更新**：能否按计划增量抓新爆款，而不是每次全量；

### 6.3 🔥 数据口径核对（周报 33 条 vs 日报 11 条）

这是最可能让你困惑的问题，处理思路如下：

1. **先别慌**：数字差大通常不是坏事，多半是口径不同；
2. **列出两边的定义**：
   - 周报的 33 条：统计的是哪个时间段？是否含非抖音来源？是否算上"加了微信但未咨询"的人？
   - 日报的 11 条：是否只统计了某一天？是否只统计了"有效线索"？
3. **逐一比对**：把周报每天的明细和日报每天对起来，找出 33 和 11 差在哪（去重规则？来源维度？时间范围？）；
4. **形成结论**：跟韩玲确认**统一口径**，并在日报/周报模板里写明"线索定义：XXX"；
5. **落成文档**：把结论写进你的周报备注，避免下个实习生再踩一遍。

> 交付标准：以后任何人问"我们这周多少线索"，都能给出同一个数，且能说清为什么。

### 6.4 🔥 部分发布运营自动化

目前发布/部分运营动作还是人工。优先自动化收益最大的环节，建议从以下选：

- **定时发布**：把人工定时发，改成工具定时批量发（多号）；
- **发布记录自动汇总**：发布后自动收集链接/时间，减少手抄；
- **数据自动抓取**：播放/互动数据自动拉取，直接进日报模板；
- **私信/评论话术模板化**：高频回复做成模板，减少重复劳动。

> 注意：**自动化不能碰红线**（见第 7 章）。特别是**任何自动化都不能代替你去公共区发"微信"字样**，宁可人工也不违规。

## 七、踩坑红线（绝对不能犯）

这两条红线是**高压线**，违反轻则限流、重则封号，直接损害业务。**宁可少做，不要犯错。**

### 7.1 🚫 红线一：抖音公共区不能出现"微信"

- **背景**：抖音平台严查导流，在**公开场景**（视频文案、标题、评论区、私信开头等可被平台检测到的地方）直接说"微信""加我微信"会被判定违规引流，导致限流/封号；
- **正确做法**：通过**合规话术**引导（比如"私信领取资料""主页有联系方式"等，具体话术以团队给定的为准），在**平台检测不到的私密环节**再引导到微信；
- **特别注意**：任何工具/自动化脚本都**不得**在公共区自动发"微信"字样（见 6.4 的提醒）。

### 7.2 🚫 红线二：选题脱题

- **背景**：我们只做**学术论文辅导**方向，靠"专业、垂直"打动目标用户；
- **什么是脱题**：发了与论文/学术无关的内容（如生活、娱乐、其他领域），粉丝不精准，浪费账号权重，也稀释专业感；
- **正确做法**：每条选题先问一句"目标用户（要发论文的人）会关心吗？"不会 → 不选；
- **拿不准怎么办**：先问韩玲，不要自己拍板发脱题内容。

### 7.3 其他注意点

- 客户隐私：微信里客户的**信息不能乱传、不能外泄**，录入灯塔按规范填；
- 账号安全：矩阵号登录/密码管理按团队规范，不要随意更换绑定。
