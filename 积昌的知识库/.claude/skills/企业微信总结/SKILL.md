# 企业微信内容处理工作流

> 本 skill 是企业微信文件处理的编排层，实际内容处理委托给 `会议笔记整理` skill。

## 核心原则

1. **只编排，不处理内容** —— 实际的内容总结、结构化由 `会议笔记整理` skill 完成
2. **简洁优先** —— 企业微信消息有长度限制，回复控制在 100-200 字
3. **直接行动** —— 无需 Step 0 的三问题询问（路径和信息已在 prompt 中提供），直接执行

---

## 工作流程

### Step 1：识别来源

确认消息来源是企业微信，且包含需要处理的文件（PDF、图片、文档等）。

企业微信自动化任务的特征：
- prompt 以 "🔴 自动化任务 — 来自企业微信" 开头
- 文件存放在 `wecom-resources/` 目录
- prompt 中已指定目标路径和文件名

### Step 2：获取文件

从 `wecom-resources/` 目录读取文件。

```bash
# 查看资源目录
ls "F:\积昌的知识库 - 副本\wecom-resources/"
```

### Step 3：处理文件

调用 `会议笔记整理` skill 处理文件：

> 将 `[文件名]` 发送给 会议笔记整理 skill 进行内容整理

如果文件是 PDF，先提取文本内容再处理。

### Step 4：保存结果

按 prompt 中指定的路径和名称，将处理结果写入磁盘（使用 `Write` 工具）。

保存目录规范：
- 课堂笔记 → `总结好的大纲以及笔记/课程学习/`
- 会议记录 → `总结好的大纲以及笔记/会议记录/`
- 备忘录/其他 → `总结好的大纲以及笔记/`

### Step 5：回复确认

回复格式（控制 100-200 字）：
- 处理结果简要说明
- 文件保存路径
- 如有异常需说明

---

## 注意事项

1. **禁止飞书操作**：企业微信任务与飞书完全无关，禁止执行任何 lark 相关操作
2. **文件清理**：处理完成后不需要清理 wecom-resources/ 目录中的源文件（用户可能后续使用）
3. **路径规范**：使用 vault 相对路径（相对于 `F:\积昌的知识库 - 副本\`）
4. **写入确认**：写入磁盘后回应结果，完整内容在 Vault 中
