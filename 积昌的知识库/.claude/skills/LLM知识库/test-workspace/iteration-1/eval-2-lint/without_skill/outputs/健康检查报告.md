## 二、问题清单

### 问题 1：来源引用名称与实际文件不匹配（矛盾）

- **文件**：`wiki/HTTP错误概述.md`
- **描述**：该页面的 YAML frontmatter 中 `source: "[[sources/HTTP 400 错误详解.md]]"`，但实际文件名为 `sources/HTTP 403 错误详解.md`。引用的文件 `sources/HTTP 400 错误详解.md` **不存在**。
- **严重程度**：高
- **建议**：将 frontmatter 中的 `source` 修正为 `[[sources/HTTP 403 错误详解.md]]`。

### 问题 2：Wiki 页面内容与来源内容不一致（矛盾）

- **文件**：`wiki/HTTP错误概述.md`
- **描述**：Wiki 页面声称汇总 "HTTP 400 和 502 错误"，但实际存在的来源文件 `sources/HTTP 403 错误详解.md` 讨论的是 HTTP 403 Forbidden 错误。页面内容与来源文件内容完全不一致。
- **严重程度**：高
- **建议**：要么更新页面内容使其与来源文件一致（改为讨论 403），要么补充 400/502 的真实来源文件。

### 问题 3：来源文件缺失 — `sources/面试课.md`（缺失页面）

- **文件**：`wiki/面试技巧.md`
- **描述**：该页面的 YAML frontmatter 中 `source: "[[sources/面试课.md]]"`，但文件 `sources/面试课.md` **不存在**。这是一个断链。
- **严重程度**：高
- **建议**：创建 `sources/面试课.md` 文件作为原始来源，或移除该引用。`index.md` 声称其来源数为 3，但没有任何一个来源文件实际存在。

### 问题 4：孤立来源文件 — `sources/HTTP 403 错误详解.md`（孤立页面）

- **文件**：`sources/HTTP 403 错误详解.md`
- **描述**：该文件在 `sources/` 目录中存在，但没有被任何 Wiki 页面通过 `source` 字段或内容链接引用。这是一个孤立文件。
- **严重程度**：中
- **建议**：将其链接到 `wiki/HTTP错误概述.md`（修正来源引用后），或将其内容提取为新的 Wiki 页面。

### 问题 5：缺失反向交叉引用（缺失交叉引用）

- **文件**：`wiki/HTTP错误概述.md`
- **描述**：`wiki/HTTP错误概述.md` 的 "关联页面" 节写着 "（暂无）"，但实际上 `wiki/面试技巧.md` 已经在 "关联页面" 中链接到了它。反向引用缺失。
- **严重程度**：中
- **建议**：在 `wiki/HTTP错误概述.md` 的 "关联页面" 中添加 `[[wiki/面试技巧.md]]`。

### 问题 6：索引页面描述不准确（过时 / 矛盾）

- **文件**：`index.md`
- **描述**：索引中 `wiki/HTTP错误概述.md` 的摘要为 "HTTP 400/502 错误详解"，但页面实际内容也是 400/502，而唯一可用的来源文件是 403。索引的描述与底层数据状态矛盾。
- **严重程度**：低
- **建议**：在修正来源引用后，同步更新索引中的摘要描述。

### 问题 7：数据缺口 — 已有来源但未利用（数据缺口）

- **文件**：`wiki/HTTP错误概述.md`
- **描述**：该页面的 "待深入" 清单包含 "[ ] HTTP 403/404/500 等其他常见错误码"。但实际上 `sources/HTTP 403 错误详解.md` 已经对 403 错误做了详细说明，可以直接引用补充。
- **严重程度**：中
- **建议**：将 `sources/HTTP 403 错误详解.md` 的内容整合到 `wiki/HTTP错误概述.md` 中并标记该 TODO 为已完成。
