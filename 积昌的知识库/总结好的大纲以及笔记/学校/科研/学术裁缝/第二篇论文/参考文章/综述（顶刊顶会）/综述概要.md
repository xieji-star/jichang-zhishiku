## 一、这份笔记按什么读法写：水导的"读一区"口径

- 水导 001 讲过：**一区文献"必须看"**，但看的目的**不是"读懂"**——"你根本看不懂（不是让你们仔仔细细地看懂）"，看的是**<span style="color:#e74c3c">别人的写作手法、别人怎么吹牛皮（编故事）</span>**。
- 看不懂一区时的退路也很实在：**<span style="color:#e67e22">"看论文的挂名作者"</span>**——先搞清楚"这篇是谁做的"，也能看清门道。所以本文**第二节先讲"谁在做"**。
- 水导 002 又讲了论文的**六块与"看不看"**：论文分 **摘要 → 引言 → 相关工作 → 方法 → 实验与分析 → 总结**；读的时候**只看摘要、引言、方法、总结**，相关工作与实验**不看**（"都是瞎扯的"）。
- **综述（review）没有严格的"方法章"**，因此本文按同样的精神，把综述拆成四块去读：
  1. **摘要** —— 这篇综述"是什么 + 讲了什么"；
  2. **引言** —— 它**怎么立"问题"**（这是编故事的主战场）；
  3. **方法（综述的"分类骨架"）** —— 它**把领域分成了哪几类**（相当于综述的"方法"）；
  4. **总结 / 展望** —— 它**留下的空白**（= 你的机会）。
- 水导 005 的三条铁律，本文也照着执行：**形式架构照搬 · 替换参考文献（本文改为"换成同类综述"）· 模块从同领域找**。

> 💡 **<span style="color:#2980b9">一句话：读这 3 篇的目的不是"懂材料学"，而是（1）搞清谁在做、（2）挖出公版的"基准模型 A"、（3）收集别人加过的"那一小块"当 b′/c′、（4）偷学一区怎么写故事。</span>**

## 三、综述一 · 可降解吸水树脂的"田间落差"批判性综述

> 📎 全文：`1.s13593-026-01125-7.pdf` ｜ *Agronomy for Sustainable Development*（2026）46:51 ｜ DOI `10.1007/s13593-026-01125-7`

**① 摘要（它是什么）**
- **类型**：**批判性系统综述（critical scoping review）**，走 **PRISMA 2020** 流程（PRISMA = 系统综述的报告规范），从 800+ 条记录筛出 **34 篇**同行评审文献（2010–2025）。

**② 引言（它怎么立"问题"）**
- 它的问题意识是：**以往的综述"大多只描述"、而且只在"盆栽 / 温室"里做**，这些场景"简化了土壤结构、水分动态、微生物互作"，于是**系统性地高估了水凝胶的真实效果**。
- 所以它给自己定了一个空位：**"此前缺的，是一次面向田间尺度的、批判性的评估。"**

**③ 骨架（它把领域分成哪几类）**
- 它把可降解吸水树脂（**BSAH，biodegradable superabsorbent hydrogel**）拆成**五个域**做综合：
  1. **材料组成** 2. **溶胀性能** 3. **生物降解** 4. **田间应用** 5. **经济可行性**
- 全文的核心立论是一个**悖论（paradox）**：

> 💡 **<span style="color:#e74c3c">性能–可持续性悖论（performance–sustainability paradox）</span>**
> 提高溶胀稳定性 / 耐久性的配方，**往往牺牲可降解性**；而环保配方**又不持久、田间效果差**。两头不可兼得。

**④ 关键数据（都是它给的硬数字）**
- **<span style="color:#e67e22">蒸馏水里溶胀 500–700 g/g，真实土壤里很少超过 80–100 g/g</span>**——差 5–10 倍。
- 它做的对比表（实验室蒸馏水 vs 土壤）：
  - **淀粉基**：实验室 200–420% → 土壤 93.11%（壤砂土）/ 20.2% / 120%
  - **纤维素基**：实验室 604% → 土壤 57% / 94.7%
  - **树胶基**：实验室 980% → 土壤 54% / 32%
- **>85% 的研究停留在实验室 / 小试；<15% 有多季田间试验**。
- 成本是传统土壤改良剂的 **3–5 倍**。
- 生命周期评估（LCA）：温室气体平均降 **45%**，但淡水富营养化 **+369%**。

**它给出的"四个田间约束机制"**（这是它最精华的一段，也是你写引言"提出问题"的好素材）：
1. **物理围压与土壤结构**——水凝胶膨胀要推开土壤，围压 / 压实会限制它；
2. **化学与渗透限制**——土壤里的 Ca²⁺/Mg²⁺ 提前"锁死"阴离子网络；盐土渗透压抑制吸水；
3. **反复干湿循环**——造成网络疲劳，溶胀能力逐次下降；
4. **空间异质性与施用不均**——撒施导致颗粒分布稀疏，根系"遇到"水凝胶的概率低。

**⑤ 总结 / 展望（它留的空白 = 你的机会）**
- 它点名要三样东西：**标准化的"农业气候"测试、同位素示踪 + 宏基因组监测降解、机械化施用 + 全生命周期评估**。
- ⚠️ **注意：它反复强调"田间效果差"，这对你是一把双刃剑**——既是"公认空白"（你的论文有故事可讲），也提醒你**别只做实验室数据，要带一点盆栽 / 田间的对比**，否则站不住。

## 四、综述二 · 农业废弃物路线全景

> 📎 全文：`2.jf4c04970.pdf` ｜ *J. Agric. Food Chem.* 2024, 72, 22399−22419 ｜ DOI `10.1021/acs.jafc.4c04970`

**① 摘要（它是什么）**
- **类型**：**原料–工艺–应用全景综述**。主线是"**农业废弃物 → 高吸水树脂（AW-SAHs）**"，并特别强调"**以原始废弃物为起点**"（区别于以往"先提纯出纤维素、再用纤维素"的路线）。

**② 引言（它怎么立"问题"）**
- 它的问题意识是：**提取聚合物要用酸碱，本身就"不环保"**；而且**现有综述没有系统讲过"直接用原始废料"这条更绿的路线**。
- 言下之意：**"别人都在先提纯、我是直接从废料起步"**——（水导 005 说的"他不是第一个，但我可以说我是第一个"的学术 trick。）

**③ 骨架（它把领域分成哪几类）**
- **第一块 · 农业废弃物的化学与利用策略**：核心是**纤维素 / 半纤维素 / 木质素**三种天然高分子；逐个废料讲怎么处理：
  - **麦秸 / 稻草 / 稻壳**：稻草≈40% 纤维素、18% 半纤维素、5.5% 木质素；稻壳≈32.9 / 23.6 / 26.2
  - **树枝**：桑枝≈37 / 27 / 20；桃枝做纳米纤维增强剂；沙棘枝涂多巴胺后接枝 PAA
  - **玉米秸秆 / 芯**：秸秆 25–40 / 20–30 / 10–20；芯 30–45 / 25–35 / 15–20
  - **果皮**：菠萝皮 20–25% 纤维素；柠檬皮 >20%；香蕉皮≈50%
  - **甘蔗渣**：30–45 / 20–35 / 15–35
- **第二块 · 合成方法**（本节是全文最"干货"的部分，也是你 A 的配方书）：
  - **物理交联**：溶解-再生（离子液体 / LiCl-DMAc / NMMO）、**冻融循环**（freeze–thawing）
  - **化学交联**：直接交联（**环氧氯丙烷 ECH**、**戊二醛 GA**、**柠檬酸**、异氰酸酯等；ECH 与 GA 会开环 / 成缩醛桥接上生物质的 -OH）
  - **接枝聚合（核心路线）**：**自由基接枝共聚**（热引发 / 光引发 / 氧化还原引发）、**微波辅助聚合**、**γ 辐射接枝**
  - **机理三步**（背下来就能写方法章）：
    1. **引发**——引发剂（APS / KPS）产自由基 → 生物质的 -OH 被夺氢成大分子自由基；
    2. **增长**——大分子自由基进攻乙烯基单体（AA、AAm）；
    3. **终止**——交联剂（MBA）把链桥成 3D 网络。
- **第三块 · 农业应用**：
  - **缓释肥（SRF）三种做法**：**溶液混合法**（水凝胶泡肥液再烘干）/ **原位聚合法**（单体 + 肥料一起聚合，最省步骤）/ **包覆法**（固体肥料外面包一层水凝胶）
  - **土壤调理剂**：看溶胀倍率、持水、机械强度、可降解性
  - **促进植物生长**：玉米、小麦、叶菜、黄瓜、豆类都做过

**④ 关键数据**
- 木质素-PVA（ECH 交联）：木质素从 0% → 5%，溶胀由 **92 → 456 g/g**。
- 羟乙基纤维素 / PVA / 木质素体系：溶胀达 **1220 g/g**（碱性水溶液）。
- 全纤维素包覆磷酸一铵（MAP）：水中 12 h、**土中 19–20 天**缓释；涂层 24 天失重 63.15%。
- 玉米秸秆纤维 / 偏岭土基地质聚合物 SRF：45 天缓释 **60.6%** 养分，提升氮利用率、促玉米生长。
- **本组（NUS）豆渣-P(AA-AAm)**：2% 掺量、播种后不浇水，**12 天 100% 存活**（无凝胶者 9 天全死）；水分受限下生物量 / 叶面积 **+80% 以上**；0.2%(w/v) 田间使菜心、白菜增产 **35–60%**、水分利用效率 **+30–60%**。

> 💡 **<span style="color:#2980b9">一句话定位：这是你确定"基准模型 A 的配方"最直接的一篇——它把"骨架 + AA + AAm + MBA + 引发剂 + 水浴接枝"这条主线写得最全。</span>**

## 五、综述三 · 智能响应水凝胶前瞻

> 📎 全文：`3.EcoMat - 2025 - Park - Smart Hydrogels for Sustainable Agriculture.pdf` ｜ *EcoMat* 2025;7:e70011 ｜ DOI `10.1002/eom2.70011`

**① 摘要（它是什么）**
- **类型**：**Perspective（观点展望）**——比"正经综述"轻，偏"我看好这个方向"。
- 主线：把水凝胶从"**保水**"升级为"**智能**"——**养分控释 + 农药控释 + 自灌溉 + 传感**四大功能。

**② 引言（它怎么立"问题"）**
- 问题意识是三个"环境代价"：世界人口 2050 年将超 **97 亿**、粮食需求涨 35–56%、近半人口面临严重缺水；而**氮肥利用率 <30%**、**农药浪费约 90%**。
- 于是它把水凝胶抬到"**一材多能**"的高度：**既能存水、又能控释、还能当传感器**。

**③ 骨架（它把领域分成哪几类）**
- **核心性质**：**溶胀（swelling）**、**网孔尺寸（mesh size, r_mesh）**、**刺激响应**（pH / 温度 / 离子强度 / 酶 / 光 / 氧化还原）。
- 四大功能与代表工作：

| 功能 | 代表做法与关键数据 |
|:---|:---|
| **养分控释** | 镁基生物炭-PAA 水凝胶：吸水 **1395 g/g**，30 天释氮 **62.1%**；双层包覆（天然橡胶 / PAA-g-NR）：30 天释氮 54.35%、磷 51.18%、钾 44.37%；三层包覆（PVA / 交联壳聚糖 / 共聚物）：30 天释氮 83.9%、磷 62.3%、钾 36.2%；PVA/淀粉 + Fe₃O₄ + 生物炭：氮淋失 31.03%→**24.99%** |
| **农药控释** | pH 响应：凹凸棒石（ATP）+ 聚多巴胺，毒死蜱 pH 5.5 释 **60%** → pH 8.5 释 **92%**；草甘膦 pH 8.5 24 h 释 60%（中性 / 酸性仅 20%）；多刺激（pH+温度+酶）：45℃ 80%/120 h vs 25℃ 200 h |
| **自灌溉** | **SMAG**（Zhou 等 2019）：大气集水，14 天不浇水、萌发率 **95%**；**SISRH**（Park 等 2024）：自灌溉 + 缓释肥，节水 **~40%**；太阳能吸湿凝胶：节水 **~44.9%** |
| **传感** | **PEDOT:PSS** 水凝胶当"电磁阀"控灌溉；**PVA/PAM/LiCl** 离子水凝胶（叶水含量监测，功率密度 1.9 W/m³）；**TENG** 摩擦电（424 mW/m²，60 s 内检出 8.62 ppm 氨，叶长 +35%）；**g-C₃N₄/PVA** 检测除草剂莠去津（ATZ，检出限 0.002 ng/mL，回收率 93–109%） |

**④ 总结 / 展望**
- 它主张做一个"**all-in-one（多合一）**"水凝胶：把"控释 + 传感"集成到同一个网络里。
- 它坦白了一个内在矛盾：**功能之间会打架**——"**增强控释能力，可能牺牲传感性能**"；包覆层越厚，缓释越好、但传感越迟钝。

> 💡 **<span style="color:#2980b9">一句话定位：它是一份"模块 b′/c′ 的菜单"——你想给水凝胶加"响应 / 缓释 / 传感"哪种功能，它就把别人怎么加的、加了之后什么效果，列给你看。</span>**

## 六、领域共通点：三篇都绕不开的"基准模型 A"

> [!important] 🧩 三篇综述的共同内核 = 学术裁缝的"领域共通点"
> 水导说，一区和四区"**用的都是学术裁缝的做法 A + b + c**"。把三篇综述并排看，那条"公版"的 A 就浮出来了：

> 🔥 **<span style="color:#e74c3c">基准模型 A（候选）= 生物质基接枝聚（丙烯酸-co-丙烯酰胺）高吸水树脂</span>**
> 英文：**bio-based graft poly(acrylic acid-co-acrylamide) superabsorbent polymer**，记作 **生物质-g-P(AA-co-AAm)**。

**它是怎么"做"的（标准配方，综述二 §3.2.2 写得最全）：**

1. **骨架（生物质）**：淀粉 / 纤维素 / 羧甲基纤维素 CMC / 果胶 / 木质素 / 各类农业废弃物（秸秆、稻壳、甘蔗渣、果皮、豆渣……）
2. **单体**：**AA**（丙烯酸）+ **AAm**（丙烯酰胺）
3. **交联剂**：**MBA**（N,N′-亚甲基双丙烯酰胺）
4. **引发剂**：**APS**（过硫酸铵）或 **KPS**（过硫酸钾）
5. **聚合**：水浴加热（约 **70°C**）或**微波辅助**（3–4.5 min）的**自由基接枝共聚**
6. **后处理**：中和 → 干燥 → 粉碎

> 💡 **<span style="color:#2980b9">为什么说这套是"公版"？因为它在本文件夹的三篇综述里反复出现，在综述一（材料组成域）、综述二（接枝聚合章）里都是"默认做法"。按水导 005 的话——它"已经被用烂了"，所以裁缝可以直接把它当 A 拿来用。</span>**

**已经有谁在用它（= 你可以直接抄的对象）：**

- **秸秆 / 稻草类**：小麦秸秆-g-PAA、稻秆纤维素-g-PAA
- **果皮类**：菠萝皮 CMC-g-P(AA-co-AAm)（+ 凹凸棒土 / 氧化石墨烯）
- **农业废弃物类**：甘蔗渣/P(AA-co-AAm)、甘蔗渣-g-PAA
- **玉米 / 稻壳类**：稻壳灰-P(AA-co-AAm)、玉米秸秆-PAA
- **淀粉类**：玉米淀粉基可降解 SAP（Kathi 2021）

> ⚠️ **骨架的优先级建议（越靠前越"好缝"）**：**玉米淀粉 → CMC / 纤维素 → 甘蔗渣 / 稻壳**。理由：淀粉基文献最多、工艺最成熟、**"被用烂"程度最高**，抄起来最省事；农业废弃物基则多一层"循环经济"的故事壳。

## 七、各家差异：模块 b′/c′ 的素材库

> [!important] 🎛️ A 不变，各家的差异就在"多加的那一小块"
> 水导把论文拆成 **A + b′ + c′**：A 是公版基准，**b′、c′ 是你后来加的两小块模块化改造**。三篇综述里"别人各加的"那块，就是现成的 b′/c′ 素材。

| 方向 | 别人加的"那一小块" | 加了之后的效果 / 出处 |
|:---|:---|:---|
| **增强骨架** | 凹凸棒土 / 蒙脱石 / 纳米 CaCO₃ / 氧化石墨烯 / 沸石 / 高岭土 | 提高凝胶强度、溶胀（Dai 2017；Kenawy 2018） |
| **换交联剂（更绿）** | 用**柠檬酸 / 单宁 / genipin** 替代 MBA | 解决"合成交联剂不环保"的痛点（综述一 §3.1） |
| **加生物炭** | 水凝胶 + 生物炭复合 | 吸水 + 缓释双升（Das 2025；Wen 等） |
| **缓释肥** | 载入**尿素 / KNO₃ / NPK**（混合 / 原位 / 包覆三种） | 缓释、提高氮利用率（综述二 §4.1） |
| **温敏自灌溉** | PNIPAM + 吸湿盐（CaCl₂ / LiCl） | 夜里吸水、白天放水（SMAG 2019；SISRH 2024） |
| **传感** | PEDOT:PSS / TENG / g-C₃N₄ | 实时监测土壤 / 作物（综述三 §4.4） |
| **种子包衣** | 用水凝胶包覆种子 | 提高发芽率与早期长势（综述一 §3.5） |

> 💡 **<span style="color:#e67e22">操作建议：从表里挑 1–2 个"最好写、最好出数据"的当 b′/c′。</span>** 按"缝起来最省事"排序，本文推荐——
> 1. **加生物炭**（数据好写：吸水倍率 + 缓释曲线），
> 2. **换绿色交联剂（柠檬酸）**（对比实验简单：MBA vs 柠檬酸），
> 3. **加缓释肥（尿素原位聚合）**（灌溉导师那边好对接）。
>
> ⚠️ 这三条都**不需要你重新发明 A**，只在 A 上"加一小块"——这正是水导说的"改一行公式也叫改进"。

## 八、写作手法：一区综述是怎么"编故事"的

> [!important] ✍️ 读一区的真正目的（水导 001 / 002）
> 水导 002 讲得最直白：**故事编在"引言、摘要、总结"，方法只做客观事实的陈述**。所以读一区，**看的就是它怎么"编"这三处**。

**三篇综述，三种"故事"讲法——同一个内核（都是生物质水凝胶），包装各不相同：**

| 综述 | 它的"故事"手法 | 具体怎么做 |
|:---|:---|:---|
| **一** | **制造悖论**（performance–sustainability paradox） | 把"大家都做得不错"重新框成"**其实没解决**"——用"实验室 500–700 vs 田间 80–100 g/g"这个 **5–10 倍落差**当武器。**（学它的"提出问题"，这是引言第一段的模板）** |
| **二** | **换个故事壳** | A 根本没变，只是把"石油基"换成"**农业废弃物基**"，套上"**循环经济 / 碳中和 / 废弃物资源化**"的外衣。**（学它怎么把"换个原料"讲成"新范式"）** |
| **三** | **功能升级** | 把"保水"这一个卖点，升级成"**控释 + 自灌溉 + 传感**"三个卖点。**（学它怎么用"多功能集成"把小事讲大）** |

> 🔥 **<span style="color:#e74c3c">扒开三层的包装，内核是同一套 A + b + c——这正是水导 001 说的："一区会让你看得云里雾里（因为包装重），四区就是明摆着给你看的。"</span>**

**三个可以直接偷的"编故事"句式：**
1. **立缺口式**（综述一）："以往的综述大多是描述性的、且局限于盆栽 / 温室——**此前缺的，是一次面向田间尺度的批判性评估。**"
2. **换壳式**（综述二）："传统路线（石油基 / 先提纯）存在 X 问题；**本路线从原始废料起步，规避了这些苛刻条件。**"
3. **升级式**（综述三）："以往的（水凝胶）只强调（保水）；**本方向把（保水）与（控释、传感）集成于一体。**"
