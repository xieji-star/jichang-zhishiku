# 发论文路线规划

> [!summary] 概要
> 本人为**大二本科生**（机械专业），论文定位 **"机械 + 材料"**，目标 **SCI 二区**，**无大小论文要求**——只要**发出去一篇**即可。本文把「学术裁缝」（水导·水论文的程序猿）两大方法论文集里**硕博用的打法**，**裁剪成本科生能直接照做的最简路线**。
>
> 全篇只坚持一条主线：**论文 = A（基准模型）+ b′（模块）+ c′（模块）**，<span style="color:#e74c3c">**a、b、c 全是别人的、全抄**</span>，你只做**小幅改动 + 缝合 + 做实验**，再**编故事**包装成"你的创新"。本科生<span style="color:#e67e22">**只需"1 个工作量 = 2 个模块"**</span>（= 小论文标准），**不碰大论文（4 模块）**。
>
> 🔥 **最关键的路线判断**：走 **"机械 + 材料"的器件-力学路线**——<span style="color:#e74c3c">**不碰计算机 / 深度学习 / 开源代码**</span>，写的就是**机械能真实介入的"器件力学"**（方向已定为 **电致发光器件（EL device / OLED）的力学与可靠性**）。**机械端**（力学 / 疲劳 / 封装 / 结构仿真）出你能独立做出的真贡献，**材料端**（发光层 / 封装阻隔 / 叠层材料）出"材料论文"的成分；"缝合"依旧是把别人的 **A**（主流器件 / 叠层方案）+ 别人的 **b′/c′**（中性层调控 / 封装结构 / 弯折测试小模块）拼起来，用**对比与实验数据**证明缝法有效——**天然顺应水导的 A+B+C 套路**。导师**仍主推许辉**，且<span style="color:#e67e22">**这次方向完全对口**（他做的正是电致发光器件）</span>——他署名是**名正言顺**，不是硬挂。

## 1. 先把坐标钉死（本科生的特殊前提）

本路线与硕博打法的**唯一区别**就在这里——先把四条前提分清，后面的动作才不会跑偏：

| 前提 | 内容 | 与硕博的不同 |
|------|------|:---:|
| **身份** | **大二本科生**，机械专业 | 硕博要兼顾大小论文、组会、毕设；**本科生只看"发出去"** |
| **目标** | **SCI 二区**（一篇即可） | 硕博有分区+篇数硬指标；**本科生只要命中一次分区** |
| **方向** | **机械 + 材料**（跨专业） | 硕博在单一方向深耕；**本科生靠"跨"来借大牛的势** |
| **导师** | 意向已定：**首选许辉、备选付宏刚**（见 [[总结好的大纲以及笔记/学校/科研/学术裁缝/第一篇论文/导师/最佳人选]]） | 硕博导师是分配；**本科生是主动去"挂名站队"** |

🔥 **"本科生无大小论文要求"意味着什么？** 按 [[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/2.6模块与工作量.md]] 的口径，**小论文 = 1 个工作量 = 2 个模块**、**大论文 = 2 个工作量 = 4 个模块**。你**只做小论文的规格**：

> [!important] 本科生的目标规格（比硕博还低一档）
> - **工作量 = 1 个**（不是 2 个）；
> - **模块 = 2 个**（b′ + c′，大论文才要 4 个）；
> - **基准 A = 1 个**（写得清、可复现）；
> - **产出 = 1 篇 SCI 二区**（不是"大小论文一套"）。
>
> 💡 <span style="color:#2980b9">**把这条钉死，你整条路线的工作量就砍掉了一半。**</span>

⚠️ **关于"二区是不是好发"的一个澄清**：充电视频 [[总结好的大纲以及笔记/学校/科研/学术裁缝/充电视频——写论文从入门到精通/001，阅读哪类论文/001，阅读哪类论文.md]] 说"**二区最没意义、最为鸡肋**"——那是**站在"读论文学东西"的角度**讲的（二区学不到手法）。它与**"二区能不能发"是两个问题**。而 [[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/补充：SCI2区的论文是怎么水的/补充：SCI2区的论文是怎么水的.md]] 已经**用真实案例证明：SCI 二区 top 也可以按"裁缝"流程水出来**。**发二区，能发。**

## 2. 核心判断：走「机械 + 材料」的器件-力学路线

> [!important] 🔥 本文最重要的一个判断
> <span style="color:#e74c3c">**你这条线，不走"计算机 / 深度学习 / 开源代码"的计算型路线，而走"机械 + 材料"的器件-力学路线。**</span>
> 一句话概括你的论文 = **拿领域里的主流方案当基准 A（别人的器件 / 叠层 / 结构），缝两个从别人论文里抠来的小模块当 b′ / c′（中性层调控 / 封装结构 / 弯折疲劳测试），用对比与实验数据证明"缝法有效"，把结果包装成"面向某机械问题的器件力学优化"。**

### 2.1 为什么是这条（"偏应用"是底线，"结合 AI"对你用不上）

[[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/2.9理工科假想.md]] 给理工科列的方向里，<span style="color:#e74c3c">**"尽量和 AI 结合"这一条对你的场景不适用**</span>——你写的是**机械领域的材料**，**不是计算机论文，没有也不需要有代码**。所以本路线只保留它的"两条底线"，并补上你自己的两条硬要求：

| 要求 | 本路线怎么满足 |
|:---|:---|
| ❌ **避雷纯理论** | 不推公式、不做纯数学；走**应用**（解决某个器件力学 / 可靠性的具体问题） |
| ✅ **偏器件 / 结构** | 落在**电致发光器件（OLED 叠层 / 封装）**这类"机械 + 材料"的实体对象上，内容天然充实、好写 |
| ✅ **够机械**（硬要求） | 力学 / 疲劳 / 封装 / 有限元仿真全是机械的看家本领，你能独立出成果 |
| ✅ **材料成分足**（硬要求） | 发光层 / 封装阻隔材料 / PI 基板 / 叠层材料都是材料内容，**能写成材料论文**（好挂名） |

### 2.2 为什么"最简"

> [!tip] 💡 "器件-力学"路线比"从零做起"少的三个坑
> 1. **不必"养数据"**——证据主要来自**文献里现成的结构 / 性能数据** + **你自己的对比实验**，省掉从零搭台的时间；
> 2. **不依赖昂贵设备**——优先选**结构分析 / 仿真 / 文献对比**就能支撑的切入点，**能不进的实验室就不进**；
> 3. **天然符合水导 A+B+C**——"主流器件 / 材料方案当 A、结构或封装小模块当 b′/c′"就是标准的裁缝打法，**开源代码与否都不是门槛**。

### 2.3 为什么"机械材料"方向就够（材料成分自带，署名靠对口）

⚠️ 器件力学方向**自带材料成分**（发光层、封装阻隔材料、PI 基板、叠层材料都是材料内容），<span style="color:#2980b9">**写成材料 / 器件论文毫无问题**</span>；而且这次**方向与许辉完全对口**，不用再"套壳"：

> [!important] 一句话策略：<span style="color:#e67e22">**方向归机械材料，署名靠"对口"**</span>
> - **方向（真贡献）**：落在**电致发光器件（EL device / OLED）的力学与可靠性**这个实体对象上——机械端出**力学 / 疲劳 / 封装 / 结构仿真**，材料端出**发光层 / 封装阻隔 / 叠层材料**，两边都是你的真实落点；
> - **署名（对口）**：[[总结好的大纲以及笔记/学校/科研/学术裁缝/第一篇论文/导师/最佳人选]] 的许辉，**本就做电致发光器件**——他署名是<span style="color:#e67e22">**名正言顺**</span>（"杰青 + 院长"的帽子顺带帮论文推区），<span style="color:#e74c3c">**不再是硬挂**</span>；
> - **例子（方向，非定题）**：*"某可折叠 OLED 显示模组的弯折应力与疲劳可靠性研究"*——**器件力学 + 材料**，天然成立。
>
> 这样一来，**论文的材料成分是自带的、机械落点是真实的、许辉署名是对口的**，三方都站得住。

### 2.4 备选（若主推文献不合适时启用）

若主推方向（**电致发光器件的力学与可靠性**）**搜不到合适的 A / 模块**，则切到**同一套 A+b′+c′ 骨架**下的另两个备选方向——**封装 / 界面力学**（薄膜封装 TFE、界面分层、循环内聚区建模）/ **可拉伸显示力学**（stretchable display）（见 [[总结好的大纲以及笔记/学校/科研/学术裁缝/第一篇论文/选题/领域方向与文献搜集清单.md]] §2）。**本路线 90% 的步骤不变**，只有"具体落点"那一格换一换。

- **怎么搜**：**只搜近 3–5 年**；<span style="color:#e74c3c">**区位只留 SCI 一区（顶刊）+ 四区**</span>，二、三区跳过（一区看"怎么写"、四区看"怎么动手"）。
- **建什么表**（表头固定五列）：`标题 ｜ 期刊 ｜ 下载链接 ｜ 分区 ｜ letpub 链接`；**分区**用 **LetPub** 查。
- **引用格式**：统一用 **GB/T 7714**。
- **产出**：`论文台账表`。
- **🤝 分工**：**你把 PDF / 文献摘抄发我**，我负责**登记进表、查分区、排格式**。

### 阶段 2 · 读论文、拆成 A + b + c

- **做什么**：把每篇论文**拆成 A（基准模型）+ b（模块）+ c（模块）**，看清"别人是怎么缝的"。
- **看什么**：**论文只看四块**——**摘要、引言、方法、总结**；**相关工作、实验与分析不看**（读的时候不看，写的时候再看）。
- **怎么拆**（4 个寻找位置）：
  1. **摘要里的"基于××"** —— 那个 ×× 往往是 A；
  2. **引言最后几段** —— "因此我们设计了……"就是 b′/c′；
  3. **方法里的结构图 / 流程框架图** —— **一部分是 A、另一部分是 b**，一眼看出"这篇=什么+什么"；
  4. **对照 / 控制变量实验** —— 逐块拿掉看效果掉多少。
- **判别标准**（谁是 A、谁是 b）：**拿掉 A→效果塌掉（几乎不成器件）；拿掉 b→效果只动 ±5~10%**。
- **怎么定位**：**一区看"怎么写"（手法、编故事），四区看"怎么动手"（裁缝本身）**；中间二、三区跳过。
- **产出**：`A+b+c 拆解表`。
- **🤝 分工**：**你摘抄论文的摘要/引言/方法段**发我，我拆成 A/b/c。

### 阶段 3 · 定基准 A

- **做什么**：从拆过的论文里，**选 1 个当你的基准 A**——你后面的所有模块都加在它上面。
- **两条原则（缺一不可）**：
  > [!important] 定 A 的两条铁律
  > 1. **缝合后的效果 > 基准，且 > 近两年部分顶刊**（要比它"能打"）；
  > 2. <span style="color:#e74c3c">**方案必须写得清、可复现**</span>——**器件结构 / 层叠图 / 材料配比 / 关键工艺**写得明白；说不清的直接换论文。
- **看什么**：论文的**结构示意图（层叠图）/ 方法段**——**层叠顺序、材料配比、关键工艺**能一眼看懂，才算能用。
- **⚠️ 关键**：**以"你能照着复述 / 复算"为准**——别人报的效果再好，你讲不清它是怎么做出来的，就换一篇。
- **产出**：`一个说得清、能照着做的基准 A`。

### 阶段 4 · 定模块 b′ 和 c′

- **做什么**：选 **2 个小模块**（小论文标准），**加进 A 里看效果涨不涨**。
- **唯一原则**：<span style="color:#e67e22">**加进基准后效果有提升 → 可用**</span>；没提升就换模块。
- **怎么选**：从**别人的论文里"抠"模块**——你**不需要发明**，"学术裁缝**从不创新，而是找创新**"。
- **⚠️ 红线：B → B′ 必须改**——哪怕是**改个命名、换个表达形式、调个参数 / 配比**，也**必须"做过改动"**，才能叫"**我们设计的模块**"。
- **产出**：`b′ + c′ 两个模块`。
- **🤝 分工**：**你找"看起来能加"的模块论文**，我判断**能不能加、加哪、怎么改**。

### 阶段 5 · 缝合 + 做实验

- **做什么**：把 **A + b′ + c′** **拼在一起**（缝合），然后**做实验证明"缝法是有效的"**。
- **怎么缝**：缝合的**位置**要**"不反常识"**（别把模块接在明显不合理的地方）。
- **做实验（证明"缝法是有效的"）**：
  - **① 对比**：你的 A+b′+c′ vs. 基准 A vs. 别人方案（**越多对比，参考文献越多**）；
  - **② 控制变量**：逐块拿掉 b′、拿掉 c′，看效果各差多少（证明**每个模块都有用**）；
  - **③ 案例分析**：挑几个样例"秀"效果（**案例是可以"挑好的"展示的**）。
- **🔴 红线**：<span style="color:#e74c3c">**必须做实验**——不做实验 = 学术不端</span>。这条线里，"做出并跑出一个能对比的结果"就是做实验。
- **产出**：`对比表 + 控制变量表 + 案例图`。
- **⚠️ 关键**：**不做实验绝对不能写**；**做了实验，学术裁缝就不是学术不端**（A/B/C 是借鉴不是抄）。

### 阶段 6 · 编故事（引言）

- **做什么**：把"**前人有不足 → 我设计模块解决 → 效果好**"讲成一个**完整故事**。
- **引言四部分**：
  > [!important] 引言 = ①我做了个啥 ②前人咋做的 ③前人不行 ④我来解决
  > - **①你做了个什么东西**：宏观讲、**不讲技术细节**；说它能解决什么**应用**问题；
  > - **②前人怎么做的**：= **相关工作的浓缩**；
  > - **③前人做的不足**：🔥 <span style="color:#e74c3c">**全篇核心、编故事的地方**</span>——"**不足一不解决天塌了，不足二不解决这领域不用研究了**"；
  > - **④提出你的创新**：**引言里不详解模块**，给**全称+缩写**即可，细节留到方法章；**插一张"无 X vs 有 X"对比图是顶刊技巧**。
- **两条判断标准（唯一的底线）**：**不要反常识 + 要有逻辑**——"模棱两可都可以，只要看起来是那么一回事"。
- **怎么写**：**全是抄**——找 2~3 篇顶刊，把它们的"相关工作"抠过来，**改造成 b′、c′ 并稍作变化**。
- **产出**：`引言`。
- **🤝 分工**：**我主笔**，你提供材料与判断"贴不贴合领域"。

### 阶段 7 · 写作（固定顺序）

- **写作顺序（照做，别乱序）**：**方法 → 实验 → 相关工作 → 引言/摘要/总结**。
- **各块要点**：
  - **方法**：唯一**"客观事实陈述"**的地方，**不讲故事、不抽象**；模块给**全称+缩写**；
  - **实验**：对比 / 控制变量 / 案例分析三件套；
  - **相关工作**：**只写"与你 A/b′/c′ 相关"的一小部分**；先找**综述**→找 A/b′/c′ 各自相关 **2~3 篇**→**东抄一篇西抄一篇→降重**→用"某某做了什么、有什么缺点，因此某某又做了什么"串起来；**唯一难度在降重**；
  - **引言/摘要/总结**：**"编故事"编在这三块**（见阶段 6）；
  - **参考文献**：**只有八类位置**用得到（引言开头 / 引言中间 / 材料·样品来源 / Related Work / 方法来源 / 小模块 / 实验对比对象 / 结果分析）；**想凑数量就在"相关工作 + 对比方法"做文章**。
- **产出**：`论文初稿`。
- **🤝 分工**：**我起草正文**，你负责**英文润色 + 补充你领域内的具体细节**。

### 阶段 8 · 选刊 + 投稿（面向 SCI 二区）

- **选刊口径**：**目标期刊只认"你真正要投的那一档"**；**同区内按影响因子选最低的**（更好中）；用 **LetPub** 查刊。
- **投稿动作**：
  1. **加引用目标期刊的论文**（投其所好）；
  2. **按投稿指南（Author Guidelines）排版**；
  3. 写 **cover letter**（投稿信）；
  4. 理工科用 **LaTeX** 排版。
- **产出**：`投稿`。

### 阶段 9 · 返修

- **做什么**：按审稿意见改稿、写 **Response Letter**（逐条回复信）。
- **原则**：**舔狗原则**——对审稿人**尊重、顺从、能改就改**。
- **⚠️ 经验**：**小论文返修一般不用大改**；**改完必须重查排版**。
- **产出**：`录用（accept）`。

## 5. 精准定位方向：先定「领域方向」，把选题留到后面缝

> [!warning] 这一步决定成败，不能省——但记住：**这里只定"方向"，不定"选题"**
> 按学术裁缝的方法论，**论文 = A + b′ + c′**，题目是由"**你找到了哪些 A 和哪些模块**"决定的——<span style="color:#e74c3c">**先把选题定死，等于先把"能缝什么"堵死**</span>。所以本节只做一件事：**给一个够宽、够热、够机械的领域方向**；具体选题**等 A 和模块到手后反向缝出来**（完整清单见 [[领域方向与文献搜集清单]]）。

### 5.1 三步收窄法（收到"二级"就停）

1. **大领域**：机械 + 材料（跨学科）；
2. **中方向（＝领域方向，本节只到这一层）**：**电致发光器件（EL device / OLED）的力学与可靠性**——这是 [[总结好的大纲以及笔记/学校/科研/学术裁缝/第一篇论文/选题/领域方向与文献搜集清单.md]] 定的主推方向，满足"做的人多 + 够机械 + 材料成分足"三条硬标准；
3. **小题目（＝最终选题，<span style="color:#e74c3c">现在不定</span>）**：等文献到手、A 与 b′/c′ 抠出来之后，再**反向缝出来**。

### 5.2 收窄层级（一眼看清"停在哪一层"）

| 层级 | 示例 | 现在能不能定 |
|:---:|:---|:---:|
| 领域 | 机械 + 材料 | ❌ 太大 |
| **领域方向** | **电致发光器件（器件 — 叠层 — 封装 → 力学）** | ✅ **本节就停在这** |
| 可做的子问题 | 中性层调控 / 封装结构 / 界面失效 / 弯折疲劳 | ⏳ 搜完文献再挑 |
| **最终选题** | **A + b′ + c′ 缝出来的结果**（如"用【b′ 的中性层方法】+【c′ 的弯折疲劳方法】改进【A 的显示模组】的【某个具体问题】"） | ⏳ **等 A 和模块到手后反向定** |

### 5.3 领域方向的三条硬标准（方向不对就换方向）

> [!important] 这个方向必须同时满足（否则换一个）
> 1. **做的人多**（你才有得"抄"）——搜得到大量近 3~5 年的相关论文；
> 2. **够机械**（贴你专业）——落在**力学 / 疲劳 / 封装 / 结构仿真**这类机械自己的方向上；
> 3. **材料成分足**——发光层 / 封装阻隔材料 / PI 基板 / 叠层材料都是材料内容，**能写成材料论文**。

### 5.4 避坑

- ❌ <span style="color:#e74c3c">**一上来就把选题定死**</span>——**这是本路线最大的坑**；选题是缝出来的**结果**，不是**起点**；
- ❌ **不要定"造航母"的冷门方向**（论文太少，没得抄）；
- ❌ **不要把方向做成纯理论**（踩雷，见 [§2.1](#21-为什么是这条偏应用是底线结合-ai-对你用不上)）；
- ✅ **要定"做的人多 + 够机械 + 材料成分足"的热门材料方向**（好抄、好缝、好发）。

## 6. 缝合套路：A + b′ + c′ 具体怎么拼

### 6.1 一张图看懂缝在哪

> [!important] 🔥 缝合的本质
> <span style="color:#e74c3c">**A 是别人的主流方案（不动），b′、c′ 是你从别人论文里抠来、做过改动的小模块**</span>，把它们接到 A 上，<span style="color:#e67e22">**跑出更好的效果，就是你的论文**</span>。

```
基准方案 A（别人的）
        │
        ├──✚ 模块 b′（抠来的，改过命名/参数）
        │
        └──✚ 模块 c′（抠来的，改过命名/参数）
                ↓
        缝合结果 → 做实验 → 效果 > A  → 论文成立
```

### 6.2 缝合的四个关键动作

| 动作 | 要点 | 依据 |
|:---|:---|:---|
| **抠模块** | 从别人论文里"拿"模块，**不自己发明** | "从不创新，而是找创新" |
| **改模块** | **B → B′ 必须改**（改命名/表达/参数/配比），叫"我们设计的" | 2.7 实操 |
| **接模块** | 接的位置要**不反常识**（别乱接） | 2.7 实操 |
| **验模块** | 加进去**效果必须涨**；不涨就换 | 2.5 定模块 |

### 6.3 什么算"改过了"（B→B′ 的最低标准）

> [!tip] 💡 哪怕只做到以下任意一条，就算"你改过"
> - 换一种**写法 / 表述**（等价也行）；
> - 改一个**命名 / 符号**；
> - 调一个**参数**（尺寸、层厚、配比、工艺条件）；
> - 换一种**实现方式**（换材料、换结构形式）；
> - 把两个模块的**顺序换一下**。
>
> <span style="color:#2980b9">**目的只有一个：让它"看起来是你的"，且论文里能写"我们设计的模块"。**</span>

### 6.4 缝合成功的三条自检

> [!important] 缝完自问三句
> 1. **拿掉 A**，效果是不是塌掉（几乎不成器件）？（是→ A 选对了）
> 2. **拿掉 b′ 或 c′**，效果是不是只动 ±5~10%？（是→ 模块是"辅助"的，符合裁缝特征）
> 3. **缝合后**，是不是 > 基准 A，且 > 近两年部分顶刊？（是→ 可以写论文了）

## 8. 风险与本科生常见坑

> [!warning] ⚠️ 六个必踩的坑（提前规避）
> 1. **不做实验** → 🔴 <span style="color:#e74c3c">**学术不端红线**</span>。这条线里"做出并跑出一个能对比的结果"就是做实验，**绝不能跳过**。
> 2. **不改成 B′ 直接用 B** → 被认作"拿来主义"，不能叫"我们的模块"。**B 必改**。
> 3. **缝合后效果不涨 / 下降** → 论文**立不住**，直接换模块。**效果必须提升**。
> 4. **基准 A 说不清 / 复现不了**（结构、配方、工艺讲不明白）→ 基准不可用；**说不清就换论文**。
> 5. **方向定得太大或太冷门** → **做不出来 / 没得抄**；回到 [§5](#5-精准定位方向先定领域方向把选题留到后面缝) 收窄。
> 6. **群发导师** → [[总结好的大纲以及笔记/学校/科研/学术裁缝/第一篇论文/导师/最佳人选]] 明确警告：<span style="color:#e74c3c">**同院导师之间会交流，群发会大幅减分**</span>——**先发许辉、等 3–5 个工作日、再发付宏刚**。

### 8.1 心态定位（别想得太高大上）

> [!quote] 💬 水导的话
> "论文说得难听点，狗屁不是……**发一篇论文不能代表什么**，仅仅只是证明你发了一篇论文。"
>
> "**别拿你的学术道德感，去衡量学术圈的学术道德感。**"
>
> "**创新性不足和学术不端是有一个鸿沟的。**"

💡 **结论**：你的目标是**"发出去一篇二区、顺利达成"**，不是"做出真正有意义的科研"。<span style="color:#2980b9">**创新性不足是可以的**</span>——只要**做了实验、不造假、不一稿多投、不买卖论文**，学术裁缝就**不是学术不端**。

### 9.1 你发给我的"文献摘抄"长什么样

> [!note] 📄 摘抄模板（照这个发我即可）
> ```

> 【期刊/年份/分区】……
> 【摘要】……（原文或翻译）
