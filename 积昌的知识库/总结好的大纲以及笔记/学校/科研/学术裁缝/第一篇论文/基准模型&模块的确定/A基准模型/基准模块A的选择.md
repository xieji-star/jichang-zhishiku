## 4. A 的力学内核：中性层应力模型

> [!important] 🧮 全篇的"发动机"就在这里
> 论文的核心是一个**解析应力公式**——给定弯曲半径 R 与各层厚度/模量，算出**任意一层**承受的应力。

**（1）中性层的物理含义**：叠层弯曲时，内部存在一个**既不受拉、也不受压的平面**（中性面 / neutral plane）。<span style="color:#2980b9">**离它越远的层，应力越大。**</span> 因此——**把脆弱的 OLED 层"挪"到中性面上，它的应力就趋近于零。**

**（2）原文给出的应力表达式**（记各层弹性模量 $E_n$、厚度 $h$、到中性层的距离 $z_n$）：

$$\sigma_n = \bar{E}_n\left[\varepsilon_{bot} + \frac{z_n}{h}\left(\varepsilon_{top} - \varepsilon_{bot}\right)\right]$$

其中 $\varepsilon_{top}$、$\varepsilon_{bot}$ 分别为叠层最上、最下表面的应变。

**（3）几何约束**（各层厚度之和必须落在叠层总厚度 $h$ 内）：

$$d_1 + d_2 + \cdots + d_{n-1} \le z_n \le h$$

> [!tip] 💡 这个公式为什么"可超越"
> 它是**线弹性、单一工况、单一目标**的——<span style="color:#e67e22">**把"线弹性"换成"黏弹性"、把"单次弯曲"换成"循环疲劳"、把"层厚优化"换成"模量/界面优化"，每换一样都是一篇新论文。**</span> 这正是 [§6](#6-b--c-模块候选含逻辑连接与性能提升论证) 模块的来源。

**（4）原文怎么用它**：原文靠**遗传算法**（genetic algorithm，一种模拟"优胜劣汰 + 交叉 + 变异"的搜索算法）在各层厚度的**组合空间**里搜最优解——因为组合数太大（原文举例：仅 3 层、每层 20 档厚度 → 就有 **8000** 种组合），穷举仿真跑不完。

### 6.2 备选模块（主路不顺时换）

| 模块 | 从哪抠 | 逻辑连接 | 性能提升点 |
|:---|:---|:---|:---|
| **c′ 备选 = 梯度模量层** | [`9.s41528-026-00617-6_reference.pdf`](9.s41528-026-00617-6_reference.pdf)（npj 2026，**梯度模量三层基板**）；`1.jsid.1305.pdf`（把 SiNₓ 无机 ILD **换成有机低模量 ILD** 降应力） | 直接把 A 里的**某一层（如 PI 基板 / 阻隔层）**从"均匀模量"改成"**梯度模量**"，仍是改 A 自己的层 ✅ | 层间模量跳变被抹平 → **应力集中消失**，OLED 层应力进一步下降 ✅ |
| **b′ 备选 = 封装阻隔层低应力化** | [`12.s41528-025-00468-7.pdf`](12.s41528-025-00468-7.pdf)（npj 2025，**PEALD + PDMS 起皱释放残余应力**，应力降两个数量级） | 对应 A 的 **Passivation / Barrier 层** ✅ | 残余应力释放 → 翘曲与层间剥离风险下降 ✅ |

> [!warning] ⚠️ 一个必须守住的纪律
> <span style="color:#e74c3c">**不要一次上三个模块。**</span> 按 [[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/2.5定学术模块.md]] 的口径，模块要"一个一个缝、一个一个验证性能"。**先 A + b′，确认性能升了，再加 c′。**

## 7. 缝合链：A → A+b′ → A+b′+c′

> [!important] 🪡 性能单调上升的完整推理
> 这一节回答用户最关心的问题：<span style="color:#e74c3c">**"我缝完之后性能会不会反而下降？"**</span>

| 阶段 | 构型 | 算什么 | 相对上一阶段的提升 | 提升从哪来（物理上说得通） |
|:--:|:---|:---|:---|:---|
| **第 0 阶** | **A**（叠层 + 线弹性中性层模型 + 层厚优化） | 单次弯折下各层瞬时应力 | — | 基准 |
| **第 1 阶** | **A + b′**（+ 松弛–塑性自洽耦合本构 SCRP） | 单次弯折 + **时间/温度**下的应力演化 | <span style="color:#e67e22">**长期应力更低**</span> | 本构算的是**松弛后稳态**，比线弹性瞬时值低；且中性面**随时间漂移** |
| **第 2 阶** | **A + b′ + c′**（+ CDSE 循环损伤自演化界面） | **N 万次循环后的界面损伤与分层寿命** | <span style="color:#e74c3c">**从"应力"升级到"寿命"</span>** | 循环累积损伤给出失效判据，能预测**先坏哪个界面、坏几次**；且**寿命最优层厚 ≠ 应力最优层厚** |
| **第 3 阶（可选）** | **+ 实验验证**（自制叠层试样 + 弯折试验） | 实测裂纹萌生 / 界面剥离 循环数 | <span style="color:#2980b9">**模型被实测锚定**</span> | 仿真曲线与实验点吻合 → 论文可信度成立 |

> [!tip] 💡 为什么这条链"逻辑上必然升"
> **每加一个模块，都是把 A 的"简化假设"换成"更真实的假设"**——线弹性 → 黏弹（更真）、单次 → 循环（更真）、均匀 → 梯度（更真）。<span style="color:#2980b9">**模型更真，对同一个物理量（OLED 层的应力/寿命）的预测，就一定比简化版更准、更低、更保守。**</span> 这就是"性能必然提升"的逻辑根据，也是编故事时最硬的落脚点。

## 8. "好做"在哪——复现路径与实验怎么落地

> [!important] 🛠️ 全篇最要紧的一节：这条路一个本科生真能走通吗
> 对照 [[总结好的大纲以及笔记/学校/科研/学术裁缝/第一篇论文/选题/许辉方向与机械接口（选题备选）.md]] §5 的"实验红线怎么落地"，走的是它推荐的 🥇 **纯力学 / 仿真侧**。

### 8.1 复现 A（第 1 步：把基准立起来）

| 步骤 | 做什么 | 工具 | 难度 |
|:--:|:---|:---|:--:|
| ① | 把 10 层叠层与材料参数**抄成一张表** | Excel / Python | ⭐ |

| ③ | 建**有限元模型**（施加弯曲，输出各层应力云图） | **ABAQUS / COMSOL / ANSYS** | ⭐⭐⭐ |
| ④ | 复现原文的**层厚优化**（遗传算法可先用 Python 现成库，如 `DEAP`） | Python | ⭐⭐⭐ |

> [!tip] 💡 关键判断
> <span style="color:#2980b9">**第 ①②③ 步就是"复现基准"的全部内容，不需要任何实验设备。**</span> 按 [[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/2.4定基准模型.md]] "复现结果以复现为准"——**我跑出来的数，就是我需要超越的基准线**，不必跟原文数字一模一样。

### 8.2 做实验（第 2 步：守住"必须做实验"的红线）

> [!warning] ⚠️ 红线提醒
> [[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/2.8学术不端与学术裁缝的区别.md]] 明确：<span style="color:#e74c3c">**不做实验 = 学术不端。**</span> 所以这一节不能省。

**思路：不烧真的 OLED，做"叠层力学试样"。**

| 项 | 做法 |
|:---|:---|
| **试样** | 用**机理相同的替代材料**手工叠出与 A 同构的多层试样——如 **PET 膜（模拟 PI/盖板）+ OCA 双面胶（模拟 Glue）+ 薄膜（模拟阻隔层）**。**不发光，但力学结构一致。** |
| **加载** | 自制的**纯弯 / 三点弯夹具**（机械专业典型毕业设计级工装），或用**弯折疲劳试验机**做循环加载 |
| **测量** | ① **应变片 / 光纤应变**测表面应变；② **光学显微 / 数字图像相关（DIC）**观察裂纹萌生与界面剥离；③ 记**失效循环数 N** |
| **对照** | 实测的"裂纹萌生循环数 / 分层位置" vs 模型预测的"损伤累积曲线" → <span style="color:#2980b9">**吻合即验证成功**</span> |

> [!tip] 💡 这条路最大的优点
> <span style="color:#e67e22">**"叠层力学试样 + 弯折夹具 + 应变测量"完全在机电工程学院的能力范围内**</span>——它不需要真空蒸镀、手套箱、超净间、光谱仪。**发光层的数据用文献现成值做对比即可。**
