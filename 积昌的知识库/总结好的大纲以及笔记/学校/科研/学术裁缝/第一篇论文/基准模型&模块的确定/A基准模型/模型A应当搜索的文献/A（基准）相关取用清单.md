> [!note] 📌 逐篇"为什么对口"
> - **① Nature Electronics（2026）**——**疲劳力学**（fatigue）+ **梯度纳米层状架构**，且论文里**实测做了一块 model EL device**。⭐ 力学落点最硬。
> - **② Carbohydrate Polymers（2026）**——**EL 器件 + 温度耐受 + 机械循环稳定性**，正是"**器件力学 + 可靠性**"正题（`ACEL` = 交流电致发光）。
> - **③ Nature Communications（2025）**——柔性 **microLED** 器件 + **AlN 钝化层**（讲的是**器件层结构与钝化**）。
> - **④ Nature Communications（2025）**——**可拉伸** π 共轭聚合物，做**柔性喷墨打印 LED**（讲的是**材料 + 器件集成**）。
> - **⑤ Advanced Fiber Materials（2026）**——**ACEL 纤维器件**与电池集成（讲的是**纤维结构 + 系统集成**）。
> - **⑥ Advanced Materials（2026）**——多层**力致发光**复合材料的力学性能（含 **FEA 应力仿真**）——⚠️ **半对口**：力致发光 ≠ 电致发光，但"多层结构 + 力学 + 仿真"的**方法**可借鉴。
> - **⑦ Advanced Science（2026）**——**多层可拉伸 OLED 平台 + 应变解耦架构**：multilayer substructure、**layer-by-layer lamination**、**element modeling + extended stress analyses**、并以之改善 **WVTR / flexibility**——⭐ **本批最对口之一**：EL 器件 + 多层叠层 + 应力分析 + 柔性/阻隔，几乎逐字命中第 ② 类口径。
> - **⑧ Nature Communications（2026）**——**全可拉伸 OLED**：conformal **lamination** 贴合、以 **FEA 仿真**验证最大应力、柔性电极**缓解界面应力**——⭐ **本批最对口之一**：EL 器件 + 叠层贴合 + 应力仿真 + 界面应力，正是"器件力学"正题。
> - **⑨ npj Flexible Electronics（2026）**——**梯度模量三层基板**做**应力缓释**（von Mises 应力仿真）——⭐ **"叠层剖面 + 应力仿真"的骨架教学件**（虽非 EL，但正是 A 那类"层叠结构 + 应力"论文的标准写法）。
> - **⑩ npj Flexible Electronics（2025）**——**纤维增强折纸电子**，**display applications**、200 μm **PET 膜层压**、laser-cut、**stress relief 仿真**——⭐ 讲的是**叠层 + 应力缓释 + 显示应用**，可当"叠层怎么讲故事"的范本。

> [!tip] 🎁 **超额加料（⑪–⑭，配额已满，但内容太对口，舍不得扔）**
> - **⑪ npj Flexible Electronics（2024）**——**高可靠可拉伸 OLED**：3×3 SOLED **显示模组**、**lamination 层压**、**ANSYS 静力仿真**验证互连应力——🔴 **"OLED 模组 + 层压 + 应力仿真"逐字命中**，被引 68，**本批最值钱的一篇**。
> - **⑫ npj Flexible Electronics（2025）**——**OLED 封装减应力法**：低应力柔性 **Al₂O₃ 封装膜** + **残余应力分析** + **多层柔性阻隔膜（SiNx）**——🔴 **"封装 + 残余应力"正题**，正是 c′ 的现成模块。
> - **⑬ Advanced Materials（2024）**——**UV 可解胶的 OCA**（光学透明胶）用于柔性显示、**解离（delamination）仿真**、含 foldable display 结构图——🔴 **OCA + 分层仿真**，**b′ 模块的金矿**（被引 60）。
> - **⑭ Advanced Science（2026）**——**异山梨醇基 OCA**：超高透明 + **快速应变回复**、**层压到模组**、**防应力累积**——⭐ OCA 材料学写法范本。

> [!warning] ⚠️ 一区这 14 篇的构成：**"器件/材料"仍多，但"叠层 + 应力"已明显补强**
> 严格按第 ② 类的要求（**讲叠层结构 / 模组设计 / 应力仿真**），14 篇里 **②⑥⑦⑧⑨⑩⑪⑫⑬** 都真正沾"力学 / 仿真 / 叠层 / 封装"边；其中 <span style="color:#e74c3c">**⑦ Advanced Science、⑧ Nature Communications、⑪⑫ npj Flexible Electronics** 是"多层叠层 + 应力 / 封装"的**正题**</span>，<span style="color:#e67e22">**⑬⑭ 两篇 OCA（Advanced Materials / Advanced Science）** 是"胶层 + 分层仿真"的**b′ 金矿**</span>。
> **但仍缺最硬的那把尺子**——**可折叠 AMOLED 商用模组叠层**（盖板 / OCA / 偏振片 / TFT / TFE / PI 的完整堆叠 + 中性层计算）**还得按 §2.3 单独去挖**（四区刊、会议 digest 里最多）。
