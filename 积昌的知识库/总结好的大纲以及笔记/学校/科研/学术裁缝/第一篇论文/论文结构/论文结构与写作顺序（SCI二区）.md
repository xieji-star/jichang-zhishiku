# 论文结构与写作顺序（SCI 二区）

> [!summary] 概要
> 本文只回答三个问题：<span style="color:#e74c3c">**① 这篇论文由哪些「章节模块」组成？② SCI 二区对结构有哪些硬要求？③ 按水导的口径，动手写的顺序是什么？**</span>
>
> 🎯 **结论先给答案（三条）**：
>
> **① 结构 = 水导的「六块骨架」，并已用 18 篇近两年 SCI 论文的实测目录校准。**
> 水导底图：**摘要 → 引言 → 相关工作 → 方法 → 实验与分析 → 总结**。实测（§3）显示：<span style="color:#e74c3c">**SCI 论文（含一区顶刊）的主流做法是把「相关工作」并进「引言」，不是独立成章**</span>——17 篇有效样本里只有 1 篇独立成章。所以本篇落地骨架取**工程/力学期刊范式**：
> **摘要 → 引言（含相关工作）→ 理论模型（方法）→ 结果与讨论（实验与分析）→ 结论**。
>
> **② 目标 SCI 二区**：<span style="color:#2980b9">**结构上必须"照目标期刊实文对齐"**</span>——**必须有一张架构图/机理图**、**必须有实验**（水导红线）、**实验细节（Experimental Section / Methods）几乎一律后置**。参考文献 40~60 条、图 8~12 张、表 3~5 张是**参照值，定稿前必须去目标期刊扒 2~3 篇同领域论文，用它们的实际数字为准**。
>
> **③ 写作顺序（严格按水导）**：<span style="color:#e74c3c">**方法 → 实验 → 相关工作 → 引言 → 总结 → 摘要 → 参考文献**</span>（"先写定死的东西，后写灵动的东西"）。

> [!important] 📌 本文的一条纪律
> **本文只定「骨架」和「顺序」，不写正文。** 每一章要写什么内容、材料从哪来，见 [[#8. 动笔前要备齐的材料（写作素材表）|§8]] 的素材表——<span style="color:#e67e22">**A / b′ / c′ 三份文档已经把方法章的全部素材备好了，写作时是「搬运 + 客观陈述」，不是「重新发明」。**</span>

## 1. 一句话结论

> [!important] 🎯 三句话把整篇论文说清楚
> - **论文 = A + b′ + c′**：基准模型 **A**（可折叠 OLED 十层叠层 + 中性层应力模型）＋ 模块 **b′**（把第 2 层 Glue 从「线弹性」升级为「粘弹-粘塑」）＋ 模块 **c′**（把层间从「理想绑定」升级为「会随循环劣化的界面」）。
> - **骨架 = 水导六块 + 实测校准**：摘要 → **引言（含相关工作）→ 理论模型（方法）→ 结果与讨论（实验与分析）** → 结论（见 [[#3. 近两年 SCI 论文的实测章节结构（18 篇样本）|§3]]）。
> - **顺序 = 先定死后灵动**：方法 → 实验 → 相关工作 → 引言 → 总结 → 摘要 → 参考文献。

> [!tip] 💡 一句话记住本篇的「卖点」
> A 只能算**「某一时刻、某一层的瞬时应力」**；A + b′ + c′ 能算<span style="color:#e74c3c">**「弯折 N 万次之后，哪一个界面先分、寿命还有多长」**</span>——<span style="color:#e67e22">**而且会证明「寿命最优的层厚 ≠ 应力最优的层厚」。**</span> **这就是引言里「不足二」的落点，也是全篇最硬的一个新结论。**

## 2. 水导给的通用骨架（原样照搬，不自己发明）

### 2.1 水导的期刊论文典型大纲

> 🦴 **<span style="color:#2980b9">典型大纲（期刊论文）</span>**（[[总结好的大纲以及笔记/学校/科研/学术裁缝/课堂视频——如何写论文/3.2如何写小论文.md]] §五，水导原话）
> **摘要 → 引言 → 相关工作（会议论文一般没有）→ 方法 → 实验和实验分析 → 总结**

- 📌 水导同时强调：**「没有实验就不要用『实验和实验分析』——一切照同领域顶刊来。」**
- 📌 会议论文**常常没有「相关工作」**这一章，结构直接是「引言 → 方法」（[[总结好的大纲以及笔记/学校/科研/学术裁缝/充电视频——写论文从入门到精通/015，相关工作如何写作/015，相关工作如何写作.md]] §九）；
  <span style="color:#e74c3c">**水导口径：期刊页数多、要求细，相关工作"可能有一定意义"，可以独立成章。**</span>
  ⚠️ **但这条口径已被实测部分推翻——见 [[#3. 近两年 SCI 论文的实测章节结构（18 篇样本）|§3.3]]：17 篇有效样本里只有 1 篇把相关工作独立成章。**

### 2.2 「不自己发明」的纪律（本节最容易犯的错）

> 🔥 **<span style="color:#e74c3c">参考两到三篇顶刊论文的大纲——他们的大纲怎么定你就怎么定，他们用了什么英文你就用什么英文。</span>**（3.2 §五）

这条纪律有三层含义，**写作时必须逐条落实**：

| 层次 | 具体要求 | 本项目的落实动作 |
|:---|:---|:---|
| **① 结构不能自己发明** | 小节怎么切、有几级标题，照抄同领域论文 | 水导给的是**底图**；本篇已用 **18 篇实测**（[[#3. 近两年 SCI 论文的实测章节结构（18 篇样本）|§3]]）做第一轮校准 |
| **② 英文用词不能自己发明** | 别人用 method 你就用 method、别人用 approach 你就用 approach | 「方法」章到底叫 *Theoretical Model / Constitutive Model / Methodology* ——**去目标期刊看**（实测见 §3.2） |
| **③ 有目标期刊就原封不动模仿** | 目标期刊论文里有什么结构，就原封不动地模仿 | **定稿前必须去目标期刊扒 2~3 篇近两年同领域论文，逐节对齐** |

> [!warning] ⚠️ 水导原话里的一个「防空转」提醒
> 「其他领域可能不一样——<span style="color:#e74c3c">**去参考你们领域的顶刊论文，不是以水导讲的为准**</span>（有些人真的有点呆，光参考课不讲而不去找同领域顶刊）。」（3.2 §五）
> —— **本篇已经把这条纪律执行了一半：用知识库内 18 篇 2024–2026 SCI 论文完成了"本领域实测"（§3）；剩下"目标期刊实文"这一半，选刊后必须补齐。**

> [!note] 📌 模仿大纲不叫学术抄袭
> 「模仿大纲/结构框架完全没有任何问题，这不叫学术抄袭——因为**你的细节和他完全不一样**，你现在是在**搭骨架**。」（3.2 §六）

### 3.2 归纳出的四种结构范式

**范式一【材料/器件类顶刊 · Wiley 系】——样本最多（5 篇）**

```
1. Introduction
2. Results and Discussion
3. Conclusion
4. Experimental Section      ← 实验细节后置
```
代表：#8 Adv. Mater. 2025、#9 Adv. Sci. 2025、#16 Adv. Sci. 2026、#10 AFM 2024、#17 Small 2025。

**范式二【工程/力学类期刊 · 传统式】——<span style="color:#e74c3c">最贴近本篇的目标</span>**

```
1. Introduction
2. [Model / Theoretical Model / Constitutive Model]   ← 方法章
3. Results and Discussion                            ← 实验与分析章
4. Conclusion
```
代表：#1 JSID 2025（A 源：Model → Optimization → Results）、#7 MNE 2026（b′ 源：Constitutive Model → Materials and Methods → Results）、#11 ASME JEP 2026（c′ 源：Experiment → Extraction & Validation → Application）、#12 ASME JEP 2026。
<span style="color:#2980b9">**这三篇恰好就是 A、b′、c′ 三份文档的「娘家」——它们的结构就是本篇最直接的模板。**</span>

**范式三【Nature 系 · 倒序式】**

```
Introduction → Results（结果型小标题）→ Discussion → Methods（方法后置）
```
代表：#13 npj FE 2025、#14 Nat. Electron. 2026、#15 Nat. Commun. 2026。
💡 特点：**方法章（Methods）放到全文最后**；**Discussion 常独立成章**；**Results 用"结果型小标题"**（如"Fatigue resistance mechanisms"），而非"方法/实验"二分。

**范式四【短报/快报 · 极简式】**

```
1. Introduction → 2. Experiments (and Results) → 3. Conclusion
```
代表：#2 JSID 2024、#3 JSID 2026。

### 3.3 关键发现（★全节最重要的一条）

> [!warning] 🔴 「相关工作」独立成章——**实测结果与水导口径不一致**
> | 对照 | 说法 | 证据 |
> |:---|:---|:---|
> | **水导 015 口径** | 期刊页数多、要求细，相关工作"可以有一定意义"，**建议独立成章** | 015 §十一 |
> | **实测（17 篇有效样本）** | <span style="color:#e74c3c">**只有 1 篇**（#6 JSID 2026 AI 长文）把 **Related Work 独立成章**；其余 **16 篇**全部把相关工作**压缩进 Introduction**（一段话 + 引证文献）</span> | §3.1 表 |
>
> **结论**：<span style="color:#e74c3c">**SCI 论文（含一区顶刊）的主流做法是"相关工作并入引言"，不是独立成章。**</span> 水导 015 讲的是"可以"，不是"必须"。
> **对本篇**：<span style="color:#2980b9">**✅ 已定案：独立成第 2 章**（2026-09-25，采纳水导 015 白板口径）——方法章顺延为 **§3**、实验章为 **§4**，全文 "Section N" 交叉引用已同步 +1 改号；引言不再重复相关工作内容。定稿前仍可据目标期刊 2~3 篇实文微调。</span>

> [!note] 📌 另两条实测发现
> 1. **❝必有一张架构图 / 机理图❞**——几乎每篇在第一次展开处（Introduction 末 或 Model/Results 首）都配一张总图（A 源 Figure 1 叠层剖面、Nature 系 Figure 1 概念图）。→ 印证水导「第三章一定对应一张架构图」。
> 2. **❝实验细节一律后置❞**——`Experimental Section / Methods` 要么放到 Conclusion 之后独立成章（范式一 #10/#16/#17），要么整章移到最后（范式三 #13/#14/#15）。→ <span style="color:#e67e22">**本篇实验章宜把"材料与参数、试样制备、测试方法"下沉为独立的 Experimental Section（后置），或并入 §4.1。**</span>

## 5. 写作顺序（水导口径 + 本篇落地）

### 5.1 水导原话的顺序

> 🔥 **<span style="color:#e74c3c">核心写作顺序：先写方法 → 再写实验 → 再写相关工作 → 最后写引言、摘要、总结。</span>**（3.2 §七）

**为什么是这个顺序**（水导逐条给的理由，全部照抄）：

| 顺位 | 写什么 | 水导给的理由 |
|:--:|:---|:---|
| **①** | **方法** | **客观实事求是**——模型 D 做出来之后**不可能改变**（实验都跑出来了，c′ 是有效的，D 是动不了的） |
| **②** | **实验** | 也是**动不了的东西**——你跑了哪些实验是既成事实；而且**跑实验的过程中，消融实验和对比实验就全部完成了** |
| **③** | **相关工作** | 相当于参考文献部分——**我们参考了 b′ 和 c′，就参考 b′ 和 c′ 论文的相关工作**，摘抄相同即可（<span style="color:#e67e22">**实测口径：这一步产出的内容，默认折进引言第②部分**</span>） |
| **④** | **引言** | 故事是编好的，但写方法/实验的过程中**可能想到更新颖的故事** → 先把「定死的」写完，再写「可以变化的」 |
| **⑤** | **总结** | 同上，**全篇写完再写**（017 期：「你要把全篇的所有东西都写完了，才会再去写这个摘要总结」） |
| **⑥** | **摘要** | 摘要 = **引言的浓缩**，所以**引言写完之后**再写最顺 |
| **⑦** | **参考文献** | 全程随手记，最后统一按目标期刊格式（APA / IEEE / …）排版 |

> [!note] 📌 摘要与总结谁先谁后？
> 水导把两者都归入「最后写」。**本文建议「先总结、后摘要」**——因为 017 期明确「**摘要 = 概括版，总结 = 详述版**」，**先把详述版定稿，再压缩成概括版**最省力。
> （水导原话只说「都放最后」，未强行规定先后，此处按「先详后简」的工程习惯排。）

> [!important] 📝 按这 7 步走，每一步都是一次「可交付」
> **第 1 步 · 方法章**：`§3.1 基准模型 A` → `§3.2 b′` → `§3.3 c′` → `§3.4 耦合框架` + **画出两张标配图**
> **第 2 步 · 实验章**：`§4.1 材料与参数` → `§4.2 设置` → `§4.3.1 对比` → `§4.3.2 消融` → `§4.3.3 案例` → `§4.4 讨论`
> **第 3 步 · 相关工作**：`§2.1 A 相关` → `§2.2 b′ 相关` → `§2.3 c′ 相关` →（补 `§2.0 发展史`、`§2.4 小结`）→ **折进引言第②部分**
> **第 4 步 · 引言**：四部分依次写，**第③部分（不足）反复打磨**
> **第 5 步 · 总结（Conclusions）**：三步走
> **第 6 步 · 摘要（Abstract）**：五步走，**从总结压缩而来**
> **第 7 步 · 参考文献**：统一格式化 + **补插 2~3 篇目标期刊的近两年同领域论文**（投稿策略，见 §7）

### 5.3 为什么这个顺序对「本篇」成立（不是空喊口号）

- **方法为什么能先写**：A / b′ / c′ 三份文档已经把公式、参数、改动清单全部备好——<span style="color:#2980b9">**方法章是「搬运 + 客观陈述」，不需要新灵感，天然可以最先动笔**</span>。
- **实验为什么紧随其后**：消融四组（A / A+b′ / A+c′ / A+b′+c′）在**跑仿真的过程中就自然产出了**，数据一到手，实验章就是「客观陈述表格」（014 期：「分析表格，就像高中数学分析数据一样」）。
- **引言为什么必须最后**：引言的「不足」要和**真实的实验结论**对齐。**先写引言容易吹过头**，最后写才能一边吹、一边用 §4.3 的真实数据兜住。

## 6. 「定死」与「灵动」：每章的投入配比

> 🔥 **<span style="color:#e74c3c">分配原则（3.2 §九）：摘要、总结、引言要细细打磨；方法、实验部分可以「抄」一点</span>**——它是定死的东西，没有什么灵性。

| 部分 | 性质 | 策略 | 投入 | 决定录用率？ |
|:---|:---|:---|:--:|:--:|
| **摘要** | 🟥 **灵动** | **细细打磨** | ★★★★★ | ✅ **决定** |
| **引言** | 🟥 **灵动** | **细细打磨**（尤其「不足」部分） | ★★★★★ | ✅ **决定** |
| **总结** | 🟧 **灵动** | 打磨 | ★★★★ | ✅ 有影响 |
| **相关工作** | 🟨 半定死 | **东抄一篇西抄一篇 + 降重 + 加逻辑连词**（已独立成第 2 章） | ★★ | ❌ |
| **方法** | ⬜ 定死 | **照 b′/c′ 文档客观陈述** | ★★ | ❌ |
| **实验** | ⬜ 定死 | **客观陈述数据**（表格分析） | ★★ | ❌ |

> [!warning] 🔴 反常识真相（水导原话，务必记住）
> 「理论上一篇论文的好坏取决于方法和实验；**但**在目前学术圈，一篇论文的「好」= **想法好一点**——**摘要、总结、引言打磨得好一点，故事编得新颖一点**。」（3.2 §九）
> **验收标准**：读完摘要和总结，要有那种**很通顺、酣畅淋漓的感觉**。

> [!tip] 💡 查重不用怕（3.2 §十）
> 「方法部分是自己的（b 改成了 b′）、实验部分跟别人不一样、摘要是东拼西凑的——**最后重复率不可能高**。」写完之后**自己稍微降下重**即可，不必额外折腾。

> ✅ **写完之后，逐条核对**
>
> - [ ] **结构**：是否**逐个对齐**了目标期刊 2~3 篇同领域论文的小节标题与英文用词？（§2.2 纪律）
> - [ ] **结构**：是否已按 **§3 的 18 篇实测**确定范式（默认范式二：Intro → Model → Results & Discussion → Conclusion）？
> - [x] **相关工作**：**已独立成第 2 章**（2026-09-25 定案）；方法章 §3、实验章 §4；全文 "Section N" 交叉引用已 +1 改号
> - [ ] **方法章**：是否有**开篇总述一段** + **一张总图/架构图**（§3.3 实测）？是否按「分块」介绍？
> - [ ] **方法章**：b′ / c′ 的**改动点**是否写清楚（而不是直接写原文）？——「**b′ 是不是你设计的？谁敢说 b′ 是别人设计的？**」
> - [ ] **实验章**：**消融实验四组**（A / A+b′ / A+c′ / A+b′+c′）是否齐全？——这是「原则 3」唯一的证据形式
> - [ ] **实验章**：对比实验是否**好过近两年顶刊/顶会一点**？（好万分之一也算）
> - [ ] **实验章**：`Experimental Section / Methods` 是否**后置**（§3.3 实测）？
> - [ ] **引言**：四部分是否齐（我做了啥 → 前人咋做 → **前人不行** → 我来解决）？「不足」是否吹到位？
> - [ ] **引言**：是否**全程大白话**、**不出现技术术语**？
> - [ ] **摘要**：五步齐？第③步是否**简短、大白话、无技术用词**？ABC 是否**3 个封顶**？
> - [ ] **总结**：三步齐？是否**没讲**「为什么做这件事」？
> - [ ] **摘要 vs 总结**：读下来是否「通顺、酣畅淋漓」？
> - [ ] **参考文献**：40~60 条？近 3 年 ≥ 50%？**是否插了 2~3 篇目标期刊论文**？
> - [ ] **红线**：是否**做了实验**？是否**一稿多投 / 买卖论文 / 数据造假**？（学术裁缝 ≠ 学术不端）

>
> 「**摘要、总结、引言要细细打磨**；方法、实验部分可以『抄』一点——它是定死的东西。」
