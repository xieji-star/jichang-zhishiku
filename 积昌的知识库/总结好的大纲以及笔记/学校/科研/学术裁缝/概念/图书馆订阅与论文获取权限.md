# 图书馆订阅与论文获取权限

> [!summary] 概要
> 一句话：<span style="color:#e74c3c">**决定"一篇论文能不能下载"的，根本不是"它发表在哪个期刊"，而是三件事——① 你所在学校**买了什么**、② 你以**什么身份**访问、③ 这篇文**本身收不收费**。**</span>
>
> 所以会出现你遇到的现象：**同一本期刊、同一篇论文，广西大学的图书馆能搜到、黑龙江大学却搜不到**——<span style="color:#2980b9">因为他们向出版社买的**订阅范围（套餐）不一样**，登录的**身份方式不一样**，用的**检索入口也不一样**</span>。
>
> 📌 记住一个底线：**"搜不到"绝大多数时候 ≠ "这篇论文不存在"，也 ≠ "这本期刊没被收录"，而只是"你这个入口没有权限看到它"。**

> [!note] 这属于**社会性概念**
> 它不涉及任何技术原理上的对错，而是**人与人、机构与机构之间的"购买合同"**——谁花了钱、买了哪一档、给谁用。所以下面**既讲规则怎么运作，也讲"圈内黑话"和"最容易踩的坑"**。

## 1. 一句话解释

<span style="color:#e74c3c">**同一个出版社（如 Wiley）旗下的"内容"，是一大锅菜；每个学校的图书馆只是从锅里"买走了一部分"。你所在的学校买到了哪一部分、以什么方式给你用、这篇菜本身是不是免费——三者共同决定你能不能下到。**</span>

- 广西大学买到了**包含这篇论文**的那一份 → 能下；
- 黑龙江大学**没买到那一份**（或买的部分不含这本刊、不含这个年份）→ 下不到。

**期刊本身对所有学校都是"同一本"**，不一样的只是"谁买了、谁没买"。

---

## 2. 先分清四层：期刊 / 出版社 / 数据库 / 图书馆订阅

> [!important] 🔥 一大半的困惑，来自把这四层当成了一层

| 层 | 是什么 | 例子 |
|:---|:---|:---|
| **① 期刊（Journal）** | 一本本"学术杂志"，如 *Journal of the Society for Information Display* | 论文真正发表的地方 |
| **② 出版社（Publisher）** | 拥有这些期刊的公司，自己开网站放全文 | **Wiley**、Springer、Nature、**Elsevier（爱思唯尔）**、IEEE |
| **③ 平台/数据库** | 出版社的网站，或第三方聚合商放的检索库 | **Wiley Online Library**（网页）、Web of Science（只查不全文）、知网（中文） |
| **④ 图书馆订阅（Subscription）** | 学校与出版社签的**购买合同**：买哪些刊、哪几年、能给谁用 | 黑大买的 Wiley 套餐 vs 广西大学买的 Wiley 套餐 |

关键点：

- <span style="color:#e67e22">**同一本期刊 = 同一份内容；但"能不能访问"是第 ④ 层（图书馆的合同）决定的事。**</span>
- 图书馆网站上那个"**电子期刊导航 / 数据库导航**"，<span style="color:#2980b9">**只会列出本校已经买过的资源**</span>——买过才列，没买就不列。这是"搜不到"最直接的原因。

## 3. 同一篇论文，为什么广西大学能下、黑大不能

> [!warning] ⚠️ 原因不止一个，按"最可能 → 次可能"排列

**原因① 订阅范围不同（最常见）**
出版社卖给图书馆的**从来不是"整本期刊"，而是"一揽子套餐（package / collection）"**。比如 Wiley 会把旗下几千本刊分成若干学科包，学校可以选择性购买。
- 黑大可能只买了 Wiley 的**部分学科包**，恰好**不含**这本刊；
- 广西大学买的范围更大（或买了含这本刊的包）→ 能下。

**原因② 覆盖年份不同（"年限墙"）**
就算都买了这本刊，**合同也常约定只覆盖某年起（或某年止）**。
- 论文落在黑大买的年份区间**之外** → 下不到；
- 落在广西大学买的区间**之内** → 能下。

**原因③ 访问身份没生效**
- **校内**：靠**校园网 IP** 自动识别成"黑大用户"；
- **校外**：必须走学校提供的 **CARSI 统一认证** 或 **WebVPN / EZproxy** 登录。
如果这条路没走通，你其实是以"**游客**"身份在逛出版社官网——游客只能看标题摘要和**开放获取（OA）**文章，付费文章一律下不了。

**（附）原因④ 检索入口不同**
- 你在黑大用的是"**本馆已购资源检索**"→ 只显示买过的，没买的一律不显示，就"搜不到"；
- 你在广西大学用的是**出版社官网检索**或**另一个发现系统** → 显示的是全量，自然搜得到。
> <span style="color:#2980b9">同一个问题，换个入口，结果就变了——这就是"同一本期刊、不同结果"最迷惑人的地方。</span>

## 4. "搜不到"和"下不了"是两回事

> [!note] 📌 这两件事，处理方式完全不同

| 现象 | 真实含义 | 代表什么 |
|:---|:---|:---|
| **搜不到**（列表里根本没有这条） | 你用的入口**没把这条收录进来** | 大多是因为你走的是"**只显示本馆已购**"的入口，或该刊不在本馆订阅清单 |
| **搜得到，但点全文要付费/要登录** | 论文的**元数据（标题、摘要）是公开的**，只是**全文**受版权保护 | 说明"文存在、期刊也收录了"，只是**你没权限** |

<span style="color:#e74c3c">**记住**：出版社官网上"能搜到标题"是常态（元数据免费），"能下到 PDF"才是有权限的证明。</span>

## 5. 术语"黑话"速查

> [!note] 听懂这些话，就不会再被绕晕

| 黑话 | 实际含义 |
|:---|:---|
| **订阅（Subscription）** | 学校花钱买的"访问权"，通常有期限、有范围 |
| **授权 / 权限（Entitlement / Access）** | 合同里写明"你能访问哪些刊、哪些年"的那张清单 |
| **机构访问（Institutional Access）** | 以"某大学成员"的身份访问，而非个人身份 |
| **IP 识别** | 在校园网内，出版社凭你的 IP 认出你是"某校用户" |
| **CARSI** | 中国高校统一认证联盟，**校外**也能用学号登录各出版社官网 |
| **WebVPN / EZproxy** | 学校自建的"校外访问代理"，转发到出版社时带上机构身份 |
| **发现系统（Discovery）** | 图书馆首页那个"一框式搜索"（如 Primo、超星、Summon），**收录范围未必等于全量** |
| **大包 / Big Deal** | 出版社把一大批期刊打包卖的商业模式 |
| **集团采购** | 多所学校联合（如 DRAA 高校图书馆数字资源采购联盟）一起谈价购买 |
| **年代墙 / 追溯年限** | 订阅只覆盖"某年之后/之前"的一段时间 |
| **OA（Open Access）** | 开放获取，**任何人免费**都能下；分金色（出版社免费）、绿色（作者自存档）等 |
| **Early View / OnlineFirst** | 论文先在官网发布、还没编进正式卷期，**部分索引还没收录** |
| **文献传递 / 馆际互借（ILL）** | 本校没有的资源，由图书馆**替你向别馆申请**，通常邮件发 PDF |
| **机构库（Repository）** | 作者所在大学存放其论文的公开库，常见**免费可下** |
| **预印本（Preprint）** | 正式发表**之前**挂在 arXiv、ChemRxiv 等平台的版本，免费 |

## 6. 常见坑点（最容易吃亏的地方）

> [!warning] ⚠️ 这几条，每条都有人栽过

1. **把"没权限"当成"没有这篇论文"**
   搜不到就以为这文不存在，白白错过——**换入口、换身份再试一次**。

2. **以为"同一本期刊，A 校能下，B 校就一定能下"**
   期刊相同，**订阅套餐可以完全不同**。<span style="color:#e67e22">能下不能下，看的是"学校的合同"，不是"期刊的名字"。</span>

3. **校园网没连、或校外没登录，就断定"学校没订"**
   先确认你处在**校内 IP** 或已通过 **CARSI / WebVPN** 登录，再下结论。

4. **把"Google 学术能搜到"当成"能下到"**
   Google 学术会链接到**付费墙**；它只帮你"找到"，不帮你"拿到"。

5. **忽略"年代墙"**
   同刊不同年，权限可能不同；**订了的刊，也可能只覆盖部分年份**。

6. **忽视 OA / 机构库 / 预印本**
   同一篇论文，**作者版本往往免费**——不要只在出版社官网这一棵树上吊死。

## 7. 想拿到论文，可以走的五条路

> [!tip] 🛠️ 按"最省事 → 最费事"排列

1. **先查是不是开放获取（OA）**
   用 **Unpaywall**（浏览器插件）、**DOAJ**、或在出版社页面看有没有 **"Open Access"** 标识——是的话，人人可下，与学校无关。

2. **找"绿色版本"：机构库 / 预印本 / 作者主页**
   搜论文标题 + `repository` / `preprint` / 作者名字，常见于 arXiv、ChemRxiv、Research Square、作者所在大学的机构库。

3. **走学校的校外访问通道**
   用 **CARSI**（学号登录）或 **WebVPN**，以"黑大用户"身份重试；并确认这本刊**确实在黑大订阅清单里**（图书馆"电子期刊导航"里搜刊名，搜不到就是没订）。

4. **文献传递 / 馆际互借（本校没订时的正路）**
   通过图书馆申请 **BALIS、CALIS、CASHL 或 NSTL（国家科技图书文献中心）**的文献传递，由图书馆向别馆索取，一般几个工作日内发到邮箱。

5. **向作者本人索取**
   发邮件或在 **ResearchGate** 点 **"Request full-text"**——作者大多乐意免费给你，这也是完全正当的。

> [!quote] 💬 一句话
> **"能不能下"是权限问题，"去哪儿下"是渠道问题。权限解决不了，就换渠道——正路至少有这么五条。**

## 8. 一个比喻，彻底记牢

> [!quote] 🍽️ 一次自助餐，两家分店，不同的会员卡

把**出版社（Wiley）**想成一家**连锁自助餐厅**：

- 餐厅**总菜单**上有几千道菜（= Wiley 旗下所有期刊）；
- 广西大学和黑龙江大学**各自办了一张卡**（= 各自的订阅套餐）——<span style="color:#2980b9">**两张卡能进的区域、能拿的菜不一样**</span>；
- 而且进店要**刷自己的卡**（= IP 识别或 CARSI 登录）才生效，**不刷卡只能看看菜名**（= 只能看标题摘要）；
- 少数菜是**免费试吃**的（= OA 论文），**谁都能拿**。

<span style="color:#e74c3c">**同一道菜、同一家店——广西大学的卡能拿，黑大的卡不能拿。这既不是菜的问题，也不是店的问题，是"卡（订阅）"的问题。**</span>

## 9. 回到你的问题：Wiley × 黑大 vs 广西大学

你的现象可以这样逐条对上：

| 你可能遇到的 | 对应原因 |
|:---|:---|
| 在黑大图书馆网站**搜不到**这篇 Wiley 论文 | 多半是**原因①**：黑大的 Wiley 套餐**不含这本刊**（图书馆入口只显示已购，没买就不显示）；也可能是**原因④**：你走的是"只显示本馆已购"的入口 |
| 在广西大学图书馆网站**能搜到** | 广西大学的 Wiley 订阅**含这本刊**（或含它的学科包） |
| （可能）在黑大搜到却**下不了** | **原因②**：买是买了，但该文**不在覆盖年份内**；或**原因③**：你的**身份没认证成功** |

**下一步怎么确认（三个动作）**：

1. 在黑大图书馆的**"电子期刊导航"**里搜这本刊的刊名——**搜得到**说明订了（问题在年份或登录），**搜不到**说明没订；
2. 确认你当时是否处于**校内 IP** 或已用 **CARSI / WebVPN** 登录；
3. 若确认黑大没订，直接走**第 7 节第 4 条（文献传递）**或**第 5 条（问作者）**。

<span style="color:#2980b9">这也正是"学术裁缝"路线里"**剔除爱思唯尔**"那类规则的现实背景：**下不到的文献，再好的思路也用不上**——选文献时要先考虑"我能不能拿到"。</span>

---

## 10. 一句话总结

<span style="color:#e74c3c">**决定一篇论文能不能下的，是"你学校买了什么（订阅范围）+ 你以什么身份访问（IP/CARSI）+ 这篇文本身收不收费（OA）"这三件事，而不是期刊本身。**</span>

所以，**广西大学能下、黑大不能下**，答案永远是这句：**"不是这篇论文的区别，是两所学校"买的套餐"不一样。"**
