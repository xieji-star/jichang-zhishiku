# JCR 与中科院分区

> [!summary] 概要
> 一句话：<span style="color:#e74c3c">**"分区"就是给期刊排的名次榜**</span>——同一本期刊，在"国际评委（JCR）"和"国内评委（中科院）"两张榜上，可能坐在**完全不同的位子**。
>
> 我们平常说的"**一区 / 二区**"，<span style="color:#e74c3c">**在中文语境里默认指"中科院分区"**</span>；英文世界说的"**Q1 / Q2**"，指的是 **JCR 分区**。两套系统**都在给期刊分四个档**，但**分档的比例和口径完全不同**——这就是一切混淆的根源。
>
> 📌 **关于叫法**：习惯说的"几区"，标准名称是 **中科院分区**（由**中国科学院文献情报中心**发布）。<span style="color:#e67e22">注意别写成"中科大分区"</span>——"中科大"= 中国科学技术大学，是另一回事，跟分区无关。

> [!note] 这属于**社会性概念**
> 分区不是自然规律，而是**人为制定的学术评价规则**——背后有机构、有利益、有潜规则。所以下面**既讲它怎么运作，也讲"圈内黑话"和"普通人最容易踩的坑"**。

## 1. 一句话解释

<span style="color:#e74c3c">**分区 = 把同一学科里的期刊，按"影响力"从高到低排队，再切成四个档次（一档最好、四档最差）。**</span>

- 中文语境说"**几区**"（一区、二区……）→ 默认指 **中科院分区**；
- 英文语境说"**Q几**"（Q1、Q2……）→ 指 **JCR 分区**。

两套榜**都在排四个档**，但**"切几刀、按什么切"完全不同**，所以同一本期刊会有两个可能打架的名次。

---

## 2. 为什么要给期刊分区

期刊太多、水平参差，光看"名字"没法判断好坏。早期大家看**影响因子（IF）**——一个衡量"这本刊上文章平均被引用多少次"的数字。但 IF 有两个毛病：

1. **不同学科不可比**：数学的 IF 天然就低，医学的 IF 天然就高，拿数字直接比不公平；
2. **"高分"没有统一门槛**：25 分算高吗？在材料学算，在临床医学不算。

于是就有了**分区**：<span style="color:#2980b9">**先按学科分组，再在组内排名分档**</span>——这样"一区"在数学和医学里，含义才是公平可比的。

> 💡 一句话：**分区是为了"跨学科公平地比期刊"，而发明出来的规章制度。**

---

## 3. JCR 分区：国际版"四等分"

**JCR** = *Journal Citation Reports*（期刊引证报告），由国外商业公司**科睿唯安（Clarivate）**发布，<span style="color:#2980b9">每年 6 月左右更新</span>。

**怎么划**：把同一学科里的期刊按影响因子从高到低排，**平均切成 4 份，每份各占 25%**：

| 档次 | 名称 | 排名区间 |
|:---:|:---:|:---|
| 第 1 档 | **Q1** | 前 25% |
| 第 2 档 | **Q2** | 25% ～ 50% |
| 第 3 档 | **Q3** | 50% ～ 75% |
| 第 4 档 | **Q4** | 75% ～ 100% |

特点：**宽松**——只要排在学科**前 1/4**，就能叫 Q1。所以 JCR 的 Q1 队伍很庞大。

---

## 4. 中科院分区：国内版"金字塔"

**中科院分区**由**中国科学院文献情报中心**发布（自 2004 年起），<span style="color:#2980b9">每年 12 月左右更新</span>，是国内**毕业、评职称、申基金**时真正被拿来看的那张榜。

**怎么划**：同样按影响力排名，但**不是平均切**，而是切成一个**头重脚轻的金字塔**：

| 档次 | 名称 | 排名区间 | 俗称 |
|:---:|:---:|:---|:---|
| 第 1 档 | **1 区** | **前 5%** | **顶刊** |
| 第 2 档 | **2 区** | 6% ～ 20% | 好刊 |
| 第 3 档 | **3 区** | 21% ～ 50% | 普通刊 |
| 第 4 档 | **4 区** | 51% ～ 100% | 门槛刊 |

另外一个关键设计：中科院分区**同时给"大类"和"小类"两套分区**——

- **大类**：把学科粗分成十几个大学科门类（如"材料科学""工程技术"）；
- **小类**：再细分成几十个具体方向。

<span style="color:#e67e22">**同一本期刊，大类可能是 2 区，小类却是 1 区**</span>——这就是后面"坑点"里要重点讲的地方。

## 5. 两套系统正面对比

> [!important] 🔥 一表看懂

| 对比维度 | **JCR 分区** | **中科院分区** |
|:---|:---|:---|
| **发布方** | 科睿唯安 Clarivate（国外商业公司） | 中国科学院文献情报中心（国内机构） |
| **俗称** | Q1 / Q2 / Q3 / Q4 | 1 区 / 2 区 / 3 区 / 4 区 |
| **划分比例** | 每档各 **25%**（平均切四份） | **5% / 15% / 30% / 50%**（金字塔） |
| **用的指标** | **当年**影响因子 | **近 3 年平均**影响因子 |
| **学科分类** | 按 WoS 学科类别（几百个细类） | **大类**（十几个）+ **小类**（几十个） |
| **严格程度** | **宽松**（前 25% 就是 Q1） | **严格**（前 5% 才是 1 区） |
| **更新节奏** | 每年 **6 月**左右 | 每年 **12 月**左右 |
| **常见使用场合** | 国际投稿、英文语境 | **国内毕业、评职称、基金申报**（我们的场景） |

<span style="color:#e74c3c">**核心差异一句话**：JCR 是"前 25% 即优秀"，中科院是"前 5% 才算优秀"——所以**中科院 1 区比 JCR Q1 难得多**。</span>

## 6. 学术界"黑话"速查

> [!note] 听懂这些话，才算进了圈子

| 黑话 | 实际含义 |
|:---|:---|
| **一区 / 二区** | 默认指**中科院分区**（国内语境） |
| **Q1 / Q2** | 默认指 **JCR 分区** |
| **顶刊 / Top 刊** | 一般指**中科院 1 区**（或 1 区里的顶尖刊） |
| **大子刊 / 小子刊** | 顶级刊的"子刊"，如 Nature 系列子刊；地位通常按分区衡量 |
| **大类 / 小类** | 中科院分区的两套口径（粗分 / 细分） |
| **水刊** | 门槛低、好发、口碑一般的期刊（常与"水论文"配套出现） |
| **预警期刊** | 中科院每年发布的《国际期刊预警名单》上的期刊——**发在上面的可能不被认可** |
| **升区 / 降区** | 期刊今年的分区比去年高了 / 低了 |
| **影响因子（IF）** | 平均被引次数，分区的原始依据 |
| **OA / 版面费** | 开放获取期刊，作者需交钱，有的很贵 |
| **毕业线 / 职称线** | 学校/单位规定的"必须发到几区"的硬门槛 |

## 7. 常见坑点（最容易吃亏的地方）

> [!warning] ⚠️ 这五条，每条都有人栽过

1. **JCR Q1 ≠ 中科院 1 区**（**最常见、最致命的混淆**）
   例：`Small` 这本刊，JCR 是 **Q1**，但中科院**大类只有 2 区**。别人说"我发的是 Q1"，你一听以为是顶刊——其实不是。

2. **说"1 区"时，要问清是"大类"还是"小类"**
   有些期刊**大类 2 区、小类 1 区**。有人拿"小类 1 区"当"1 区"说，听起来很唬人，实际含金量要打折。

3. **分区每年会变**（期刊升区 / 降区）
   引用分区时**必须注明是哪一年的**。默认用**最新一年**的分区，别拿几年前的旧榜说事。

4. **影响力 ≠ 分区**
   影响因子高的刊不一定分区高（不同学科不可比）；反过来，某些学科 IF 不高但稳居 1 区。**看分区，别只看 IF 数字大小。**

5. **预警期刊 + 无分区期刊**
   - 中科院每年发布《国际期刊预警名单》，发在上面**可能影响毕业/考核**；
   - **新刊、部分国产刊可能还没被 SCI 收录 → 根本没有分区**，别想当然认为它是一区。

> [!tip] 🧠 排查口诀
> **"Q 打头 → JCR；数字带'区' → 中科院；听到'1 区'先问一句——大类还是小类？哪一年的？"**

## 8. 一个比喻，彻底记牢

> [!quote] 🍜 两家美食榜，给同一家餐厅打分

把**期刊**想成**餐厅**，把**分区**想成**美食榜的评级**：

- **JCR 榜** = 一家"宽松"的榜：**前 25% 的餐厅都能拿"优秀"**，榜单上一大堆优秀，含金量分散；
- **中科院榜** = 一家"严格"的榜：**只有前 5% 的餐厅才戴上"一星"**，名额极少，牌子格外硬。

同一家餐厅（同一本期刊），在宽松榜上可能是"优秀"，在严格榜上却连边都摸不到——**所以有人说"我这是 Q1（JCR）"，你千万别自动翻译成"1 区（中科院）"。**

> 💡 再补一个考场的画面：同一个班的学生（一个学科的所有期刊），JCR 说"**考进前 25% 就是优等生**"，中科院说"**考进前 5% 才算优等生**"——**同一个学生，在两份榜单上的档位完全不同**。

## 9. 回到我们的路线：为什么"读只读一区+四区，投却投二区"

这是"学术裁缝"方法论里最容易被误解、也最需要说清的一条规则。**"读"和"投"是两件事，用两套口径。**

> [!important] 📖 读：只读 **一区（顶刊）+ 四区**，二、三区跳过
> 因为读的目的是**"学东西"**，而不同档位能学到的东西不一样：
> - **一区（顶刊）→ 学"怎么写"**：编故事的手法、引言的框架、图表的画法——**学写作**；
> - **四区 → 学"怎么缝"**：四区的论文结构最"**裸**"，A+B+C 一目了然，**最好扒、最好抄**——**学缝合**；
> - **二区、三区 → 学不到东西**：既没有顶刊的手法，又没有四区的"好抄"，**直接跳过**。

> [!important] 📮 投：照样投 **中科院二区**
> 因为投的目的是**"能中 + 不掉价"**。对**本科生 + 机械材料方向**来说，**二区是"够得着、又有分量"的甜点位**——既不像一区那样高不可攀，又比三、四区体面得多。

<span style="color:#2980b9">**一句话：读的口径是"学"，投的口径是"中"，两者不冲突，别混着理解。**</span>

> [!note] 📌 怎么查分区（我们用的土办法）
> 拿到一篇论文 → 记下**期刊名** → 去 **熊猫学术**（`sc.panda985.com`）或 **LetPub**（`letpub.com.cn`）查"**中科院分区**" → 显示"**1 区**"或"**4 区**"就留下，"**2 区 / 3 区**"就跳过。
> ⚠️ 注意：查的是 **中科院分区**，不是 JCR——别被"Q1"误导。

---

## 10. 一句话总结

<span style="color:#e74c3c">**"几区"是中科院的榜、"Q几"是 JCR 的榜；中科院只给前 5% 发 1 区，JCR 前 25% 就叫 Q1——记住"中科院更严"，就再也不会把 Q1 误当成 1 区。**</span>

而我们这条路线只需要记牢一句：**读文献按"一区学手法、四区学缝合"来筛，投稿时安心投二区。**
