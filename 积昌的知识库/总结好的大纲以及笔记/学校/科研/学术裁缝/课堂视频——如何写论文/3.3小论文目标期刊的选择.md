# 🎯 3.3 小论文目标期刊的选择

> [!INFO] 📌 课程信息
> - **类型**：课程讲解（写作篇：目标期刊选择 + 投稿实操）
> - **日期**：2026-09-02（上） / 2026-09-03（中） / 2026-09-09（下）
> - **讲师**：水导
> - **系列**：学术裁缝（第 3 章第 3 节·上中下合并）
> - **来源**：视频课程转录

> [!summary] 📝 概要
> 本节讲写完小论文后的目标期刊选择与投稿。核心立场：**课题组要求就是放屁，只认研究生培养计划**（学生管理系统/辅导员/学生手册可查，里面有明文规定的最低毕业要求）——按**最低要求**投心中的目标期刊。应对导师用"**先奏后斩**"：第一次按他的要求投（时间来得及），第二次开始不予理会；留下"按你要求投过、没中"的**实质性证据**——教育部明文规定不能无故延毕。发表途径按难度排序：**软著 < 普刊 < EI 会议 < 核心 < SCI 3/4 区 < 新型专利/发明专利 < 国内核心**（国内核心靠导师关系）；对学术裁缝而言 **SCI 4区足够**；水导顺带普及了各项明码标价（防被骗）——**找机构远没有自己搞靠谱**。选刊方法：**SCI 4区按影响因子排序选最低的，国内核心选名声最烂的**，用选刊神器 **LetPub**。EI 会议版面费 3800、**99% 能录**；OA 期刊稍微有点要求也基本能录。投稿实操：去目标期刊挑几篇同领域论文**加引用**（审稿人可能是作者）、按官网投稿指南**重新排版**、cover letter 百度个模板没定式；**理工科用 LaTeX（学两三天就会）、文科用 word**；期刊一般不要求代码开源。

## 一、总纲：写完小论文，接着就是投稿

- **承接 3.2**：写完一篇小论文之后，应该是要去**投稿**了——目标期刊的选择、投稿的方法都在本期讲（呼应 [[3.2如何写小论文]] 的"目标期刊论文"准备）。
- 📌 3.1 里说的"看目标期刊论文"，你可以先看 3.2 再看本期，也可以不用看——**每个人的需求不一样**。

## 二、课题组要求就是放屁：只认研究生培养计划

- 🔥 **<span style="color:#e74c3c">核心立场：对于我们小论文目标期刊的选择，课题组要求就是放屁</span>**——理由很简单：**同一个学院的同一届的**，凭什么他们（其他课题组）发 SCI 3、4 区就行，我们就必须 SCI 1 区？一区不存在、不现实的好不好？**这是可以据理力争的**——你们课题组这个要求你完全可以不用理会。
- 📌 **但姿态是先礼后兵**（见下节）。
- 🔥 **<span style="color:#e74c3c">我们只认什么？只认研究生培养计划</span>**：
	- 一般在**学生管理系统**里能找到；找不到可以**找辅导员要**、或者去**学生手册**里看；
	- **研究生培养计划里会明文规定你们的毕业要求**；
	- 去看培养计划里面的**最低要求**是什么——**按最低要求来投你们心中的目标期刊**，基本上是这样的。
- ⚠️ 基本上不会出现"要求 SCI 1、2 区"这种（培养计划里的合理要求）。

---

## 三、先奏后斩的应对与实质性证据

- 🔥 **<span style="color:#e74c3c">先奏后斩（不能先斩后奏）</span>**：
	1. **第一次**：时间来得及的情况下，先按照导师的无理要求**投一次**（这个要求是无理要求）；
	2. **第二次开始**：不予理会；
	3. 投了一次又一次老师还怎样的话——**先奏后斩**：已经按你要求投过一次了，然后再和他讲"我们要投我们心中的目标期刊了"。
- **他大概率不同意**——不同意**直接投**，不用理他：**这是你自己的权利**。
- 🔴 **<span style="color:#e74c3c">实质性证据链</span>**：我按照你的要求投了一次、没有中；现在我要毕业了，**你不能以这个（无理）要求来卡我的毕业**——这就属于**无故延毕**。教育部明文规定**不能无故延毕学生**，这是有**红头文件**的；他不认可的话，让他去找教育部、教育厅说"这个文件有问题"——跟我没关系。**他绝对讲不出什么话，敢讲就都是证据。**
- ⚠️ **转写备注（不做建议，仅描述课程原话）**：水导提到有些"粗心"的同学会出现"导师邮箱写错一个字母、消息发不进导师邮箱"的情况，等到论文录用了才发现——这时候导师什么都不能做：我投了新目标期刊、我能毕业了，你说这篇论文录用没有用？**这就叫实质性证据，他没这个权利，他要是敢撤稿那他就完蛋**——延毕就是他造成的无故延毕。（此段仅作课堂观点记录。）

## 四、发表途径分级：从软著到国内核心

- 📊 **<span style="color:#e67e22">难度/含金量大致排序（从低到高）</span>**：
	**软著 < 普刊 < EI 会议 < 核心 < SCI 3、4 区 < 实用新型专利/发明专利 < 国内核心**
	- EI **期刊**其实比 SCI 3、4 区容易一点，但**投起来麻烦**（水导当年投得挺麻烦）；
	- 对学术裁缝而言，**SCI 4 区足够了**；还有 **OA 的 SCI** 这个选项；
	- **国内核心最难**——别问为什么最难，**它也很简单：如果你导师有（关）系就简单**；导师没关系那就没关系（靠关系的事，问水导没用）。
- 📊 **<span style="color:#e67e22">各途径的市场行情（水导按某鱼/某宝行情随口普及）</span>**：软著、新型专利、普刊、EI 会议大概到某个价位档；省级竞赛 1000~2000（1500 一档）、国家级竞赛 5000 起、OA SCI 一般 1.5~2.5 万、发明专利要有渠道——**具体见下节价格表**。
- 📌 **计算机领域补充**：CCF C 类会议大致相当于/小于等于 SCI 3 区的难度。
- 📌 **最推荐**：靠自己能力、不花钱——**最推荐就是 SCI 4 区**；EI 期刊特嫌麻烦。

---

## 五、明码标价普及：自己搞，不找机构

- 💡 **<span style="color:#2980b9">为什么普及价格</span>**：这里一般都是可以**明码标价**的，**不用去找机构**——水导大概知道机构的**服务费**行情，给你们排个名，**免得你被骗**。
- 📊 **<span style="color:#e67e22">大致市场价（以某宝/某鱼实时为准）</span>**：
	| 项目 | 大致价位 |
	|:---|:---|
	| 软著 | 300 内；加急（按 3 天算）可能 1000~3000 |
	| EI 会议（版面费） | 约 3800 |
	| 实用新型专利 | 约 1500 |
	| 普刊 | 卷到三四千也有便宜的，也有 5000~7000，甚至过万 |
	| 省级比赛（按一~三等奖） | 约 1000 起 |
	| 国家级竞赛 | 5000 起（以前了解） |
	| OA SCI | 一般 1.5~2.5 万（现在有些挺贵） |
	| SCI 1、2 区期刊 | 更贵（数万级） |
	| 发明专利 | 要有渠道 |
- 🔥 **<span style="color:#e74c3c">两条铁律</span>**：
	1. **这些都不用花钱的，千万不用花钱**——都靠自己的能力；
	2. **找机构远没有自己搞靠谱，是远远远远（不靠谱）**——看完课程按学术裁缝来就行，没必要找机构。
- 📌 **配套要求**：2026 年 2 月 8 日那期视频（50 分钟）**必须看**——明白发论文到底有多么容易；另有一期"**最全的期刊分级**"视频（软著/新型专利/普刊/SCI 4区是什么），**研零研一新生必看**，本期不重复。

---

## 六、SCI 4区怎么挑：影响因子选最低

- 💡 **<span style="color:#2980b9">SCI 4 区怎么调（挑）</span>**：按照你能找到的**影响因子**——把你能找到的**所有 SCI 4 区期刊**给它**分个类、排个序**（按影响因子大小排序），**选择影响因子最低的**。
- 💡 **<span style="color:#2980b9">国内核心怎么挑</span>**：**选择名声最烂的**。就这样，对，就这样。
- 🛠️ **选刊神器**：**LetPub（letpub）**——去上面获取期刊信息；水导另有一期"选刊神器的使用方法"视频（必看）。
- 📌 **流程总结**：看完两期视频（期刊分级 + 选刊神器）→ 知道怎么挑 SCI → 怎么从 SCI 里按影响因子挑最低的 → 得到你的目标期刊。

---

## 七、EI 会议与 OA 期刊：99% 能录

- 📊 **<span style="color:#e67e22">EI 会议</span>**：版面费 3800——**别人只要你的版面费**，你的论文写得怎么样基本无所谓；至少 EI 会议**基本上投了都能录，99% 的概率能录用**，还有 1% 是你连形式上都不过关。
- 📊 **<span style="color:#e67e22">OA 期刊</span>**：也是只要版面费，对你的论文**稍微有点要求**（要求不多）；OA 的 SCI 一般**能够满足毕业**——如果你真要这样的话，OA 的 SCI **就足够你毕业了**。

---

## 八、投稿实操：加引用、重新排版、cover letter

- 💡 **<span style="color:#2980b9">得到目标期刊后的动作</span>**：
	1. **去目标期刊挑选几篇你们领域的论文，想办法把它们加引用到你自己的论文里面去**——有一点好处、但用处不大，**但一定要做**：因为这个期刊的**审稿人很有可能在这个期刊发过论文**，正巧遇到你引用了他的论文，可能就会好一点；编辑看到你引用他刊的其他论文，也可能相对而言好一点；
	2. 一般是在**相关工作**那里加几篇进去——**参考文献再添加，然后重新排版**。
- 💡 **<span style="color:#2980b9">重新排版</span>**：按照**期刊官网的要求（投稿指南）**来；排版教程随便去 B 站找个视频都行——都读到研究生了，稍微看一眼就懂，**按投稿指南一步步来**。
- 📌 **投稿 cover letter（附信）模板**：**随便百度一个，没有定式**。
- 🔥 **<span style="color:#e74c3c">投稿没那么麻烦</span>**：都是一些很简单的步骤，就是可能繁琐一点（排版可能需要一点时间）——**半天时间就全部搞定了**。

---

## 九、排版与开源：LaTeX 与 word

- 💡 **<span style="color:#2980b9">排版工具</span>**：
	- **理工科用 LaTeX**——自己找个教程学两三天就会；
	- **文科没有 LaTeX 排版要求的，就用 word 排版**。
- 📌 **排版硬性要求**：除了投稿信，**论文的排版是必须要严格按照期刊要求排版的**。
- 💡 **<span style="color:#2980b9">代码和数据开源问题</span>**：期刊**一般不要求开源**；如果要求的话，你换个期刊投（投水刊一般都不要求）。
- 📌 **轻重排序**：返修意见修改这些都是**不重要的东西**；**真正重要的东西是把学术裁缝的方式方法学会**，把小论文细节视频看完、把论文写出来——很多同学根本没有小论文要求，论文发不发表都无所谓。
