# 2027推免论文与著作科研加分规则详解

> [!summary] 概要
> 黑龙江大学2027年推免实施细则里，论文、著作、专利三类学术成果**只认"高水平学术期刊 / 核心学术期刊"两档**来加分（论文最高4分 / 1.5分），**不逐本列期刊名单**，最终由学校《高水平学术期刊等级目录》和特殊学术专长专家审核小组认定。**"专业学术著作10万字"是专著的门槛，不是论文的字数要求**——论文按期刊层级加分，与字数无关。本笔记结合政策原文与黑大官方期刊分级体系，讲清"认什么、不认什么、机械专业怎么发能加分"。

## 1. 政策依据：论文加分怎么算

细则第九条第（四）项给定了测评公式：

> **测评总分 = 专业成绩测评分数 + 专业学术著作/论文/专利加分 + 重大社会活动表彰加分 + 外语高水平加分**

其中**论文、著作、专利**三类"特殊学术专长"的加分规则（附件1）如下：

1. 📌 **署名单位**：成果必须**以黑龙江大学为第一署名单位**——即论文/著作/专利上的单位归属必须是黑大。
2. 📌 **论文作者**：**文科只计独立作者；理科只计第一署名作者**。
3. 💡 **论文分两档**：**高水平学术期刊**最高 **4 分**；**核心学术期刊**最高 **1.5 分**。
4. 📌 **著作字数门槛**：专业学术著作**字数起点 10 万字**（最高可计 3 分），每增加 5 万字最高可加 1 分，**最高不超过 4 分**。
5. 📌 **专利**：仅认定**发明专利**，只计**第一发明人**，最高不超过 **3 分**。
6. 📌 **封顶**：著作、论文、专利**三项加分累计不超过 5 分**；且**每一类内部不累计**，只取该类的**最高一项**加分。
7. 📌 **时间**：著作/论文的**发表时间**、专利的**申请和授权时间**，必须在**本科在读期间内**。

> [!note] 关键：这句"不累计加分"到底怎么算？（两层规则）
> 附件1第6条写得很明确——"各项目内部不累计加分，仅取各项目最高项加分，三项加分累计不超过5分"。它其实是**两层**：
> ① **每个类别内部**（著作/论文/专利各自内部）：多份成果**只认最高那一份，不叠加**；
> ② **三个类别之间**：把"著作最高分 + 论文最高分 + 专利最高分"**相加**，但**总和封顶 5 分**。
> 所以——**同类只认最高，跨类才相加，总数封顶5分。**
>
> **举例最清楚：**
> - **例A**：2项发明专利 + 1篇高水平论文(4) + 1篇核心论文(1.5) → 专利取最高3 + 论文取最高**4**（核心1.5被同类吞掉）+ 著作0 = 7，**超5封顶为5分**；
> - **例B**：只有1篇高水平论文 → 4分（未超5）；
> - **例C**：1篇核心论文(1.5) + 1项发明专利(3) → 1.5 + 3 = 4.5分（未超5）；
> - **例D**：2项发明专利 → 专利取最高3分。
>
> 🔥 **一句话：同一类里只取最高一项（不叠加）；三类各自取最高后相加，但总数最多5分。集中冲一项高档次，最划算。**
>
> 📌 **专业竞赛是单独一项**（附件2/附件3），**不在"三项封顶5分"里**，它有自己的权重表（最高4分），同类也只取最高，别和"著作/论文/专利三项封顶5分"混为一谈。

>🔥 **<span style="color:#e74c3c">一句话记牢：理科论文必须是"黑龙江大学 + 第一署名作者 + 高水平或核心期刊"。</span>**

## 2. 什么是"高水平学术期刊"

⚠️ **先说结论：推免文件（附件1）并没有逐一列出"哪本期刊是高水平期刊"，只用"高水平 / 核心"两个层级定分数上限。** 具体认定要查黑龙江大学的**《黑龙江大学高水平学术期刊等级目录》**。

### 2.1 黑大官方期刊分级体系（两套并行）

黑龙江大学有一套成体系的学术期刊分级标准，用于职称评聘、奖学金评审、学位申请、推免认定等科研考核：

| 体系 | 分级 | 说明 |
|------|------|------|
| **《黑龙江大学学术期刊等级认定标准》**（黑大校发〔2006〕130号） | 国家级重要 / 国家级一般 / 省部级重要 / 省部级一般 | 按主办单位层级划分的早期标准 |
| **《黑龙江大学高水平学术期刊等级目录》**（人文社科类另设 Cˉ 类） | **A 类 / B 类 / C 类** | 目前推免"高水平学术期刊"主要参照这一套，A 类最高 |

### 2.2 高水平等级目录里，期刊怎么归位

| 档位 | 大致对照 | 说明 |
|:---:|------|------|
| A 类 | 本学科领域最高权威期刊 | 分数最高 |
| B 类 | **SCI 收录期刊**（理工科常按此档） | 属于高档次 |
| C 类 | **EI 期刊**、**CSSCI 来源期刊** | 属于高水平（Cˉ 类为目录补充，标准比照 C 类但性质略低） |

> 💡 **<span style="color:#2980b9">什么是 SCI、EI、CSSCI？</span>**
> - **SCI**（Science Citation Index，科学引文索引）：国际权威自然科学引文数据库，收录全球高水平理工类期刊，机械、材料、制造等方向的国际顶刊大多在列。
> - **EI**（Engineering Index，工程索引）：国际工程领域权威检索，收录工程技术类期刊与会议，对工科学生很关键。
> - **CSSCI**（中文社会科学引文索引，南大核心）：人文社科类权威核心库，机械等理工科一般用不到。

>⚠️ **<span style="color:#e67e22">注意：以上"SCI按B类、EI期刊按C类"是黑大官方分级体系的大致映射，具体以当年《黑龙江大学高水平学术期刊等级目录》为准。</span>** 目录可能随年份调整（如增列、升档），裁决权在**学校特殊学术专长（科研创新能力）专家审核小组**。

## 3. 什么是"核心学术期刊"

"核心学术期刊"是**高水平之下的第二档**，加分上限 1.5 分。指进入以下**通用核心期刊目录**的期刊：

| 核心目录 | 全称 | 适用 |
|------|------|:---:|
| **北大核心** | 北京大学《中文核心期刊要目总览》 | 文理通用 |
| **CSSCI（南大核心）** | 南京大学《中文社会科学引文索引》 | 人文社科 |
| **社科院核心** | 中国社科院《中国人文社会科学核心期刊要览》 | 人文社科 |
| **CSCD** | 中国科学引文数据库 | 理工科 |
| **SCI / EI 源刊** | 未进入高水平目录但被 SCI/EI 收录的期刊 | 理工科 |

> 📊 **<span style="color:#e67e22">两者的本质区别是"档次"二字：</span>** 高水平学术期刊 ≈ 黑大目录里的 A/B/C 类（4分档）；核心学术期刊 ≈ 北大核心/CSSCI/CSCD/SCI/EI源刊（1.5分档）。**同样一篇论文，进高水平目录就多拿 2.5 分。**

## 4. 论文加分：认哪些期刊、不认哪些

### 4.1 认的：三个硬条件缺一不可

1. 📌 **期刊类型**：属于**高水平学术期刊**（↑4分）或**核心学术期刊**（↑1.5分）。
2. 📌 **作者位次**：**理科必须是第一署名作者**，**文科必须独立作者**。
3. 📌 **署名单位**：**黑龙江大学为第一署名单位**。

>🔥 **<span style="color:#e74c3c">三者同时满足才加分，缺一项都不认。</span>**

### 4.2 不认的（踩坑重灾区）

- ✗ **第二、第三署名作者**（理科）：不是第一作者，不加分。
- ✗ **非黑大第一署名单位**：挂靠外校，不加分。
- ✗ **非高水平/非核心的一般期刊**：级别不够，不加分。
- ✗ **发表时间不在本科在读期间**：早于或晚于本科在读期，不加分。
- ✗ **考试作弊、学术不端、抄袭造假、冒名顶替**：不但不加分，还会取消推免资格（细则第十一条）。
- ⚠️ **与"明显高于本人者"合作**：若与**直系亲属**或**学历/职称/职务明显高于本人者**合作，该成果**仅作参考、不予加分**。但有一个重要例外——**与"具有学业指导关系的本校教师且无亲属关系"合作**，不被视为"明显高于本人者"，可按正常规则加分。

> 💡 **<span style="color:#2980b9">"与导师合作"到底加不加分？</span>** 细则第九条第（四）项第3句：与**具有学业指导关系的本校教师且无亲属关系**合作的成果，**排除在"明显高于本人者"之外**。也就是说，**跟自己的黑大导师（无亲属关系）合作发表的论文，只要你是第一署名作者且黑大是第一署名单位，就属于"正常加分"范围**；但如果导师排第一作者、你是第二，理科就不加分了。所以**争取自己当第一作者**是关键。

## 5. 专业学术著作字数要求（≠ 论文字数）

### 5.1 著作的字数规则（附件1 + 细则）

| 要求   | 内容                            |
| ---- | ----------------------------- |
| 性质   | 只认定**专业学术著作**（学术专著/教材类，非普通文章） |
| 字数起点 | **10 万字**（本人撰写工作量不得少于 10 万字）  |
| 起评分  | 达到 10 万字，最高可计 **3 分**         |
| 递增   | 每增加 **5 万字**，最高可加 **1 分**     |
| 封顶   | 最高不超过 **4 分**                 |

### 5.2 ⚠️ 能否把"10万字"当作论文的字数要求？—— **不能！**

>🔥 **<span style="color:#e74c3c">这就是最容易混淆的地方：10万字是"学术专著"的认定门槛，不是"论文"的加分规则。</span>**

- **论文**没有字数加分一说，论文只看**期刊层级**（高水平4分 / 核心1.5分）。一篇正规学术期刊论文通常几千到一两万字，**不可能也无需达到10万字**。
- **著作**才按字数加分，且要求是**专业学术著作**（独立成书的专著），10万字是"起评分"的门槛。
- 所以——**论文按"层级"加分、著作按"字数"加分，两者机制完全不同，别把著作的10万字套到论文头上。**

> 📌 **<span style="color:#e67e22">现实提示：对本科生而言，10万字学术专著几乎不现实；真正能操作的加分路径，主要靠"论文"这一块。</span>** 著作加分更多是给已有学术积累的学生的额外通道，且单独立项、需黑大第一署名 + 本人在读期间完成。

## 6. 机械专业（理工科）发哪些论文可加分

🏭 **机械（理工科）学生的论文加分，核心是"第一署名作者 + 黑大第一署名单位 + 期刊档次"这一条线。** 分两档冲：

### 6.1 高水平学术期刊（最高 +4 分）

理工科高水平期刊主要指**进入《黑龙江大学高水平学术期刊等级目录》的 SCI/EI 收录期刊**（大体按 B/C 类归位）。方向要跟**机械 / 制造 / 材料 / 工程**等学科专业相关。代表性方向（举例，供筛选方向用，**具体以当年黑大目录为准**）：

- 机械设计、机构学、传动：*Mechanism and Machine Theory*、*Journal of Mechanical Design*
- 机械制造、加工工艺：*International Journal of Machine Tools and Manufacture*、*Journal of Materials Processing Technology*
- 力学、结构强度：*International Journal of Mechanical Sciences*、*Thin-Walled Structures*
- 机器人、机电一体化：*Robotics and Computer-Integrated Manufacturing*、*IEEE/ASME Transactions on Mechatronics*
- 摩擦、轴承、振动：*Tribology International*、*Mechanical Systems and Signal Processing*

### 6.2 核心学术期刊（最高 +1.5 分）

理工科"核心学术期刊"主要指**北大中文核心 / CSCD 收录的机械类中文期刊**，以及**未进高水平目录的 SCI/EI 源刊**。代表性中文核心期刊（举例，具体以当年《中文核心期刊要目总览》为准）：

- 《机械工程学报》
- 《中国机械工程》
- 《机械设计与制造》
- 《机械传动》
- 《机床与液压》
- 《农业机械学报》
- 《轴承》《机械强度》

> 📊 **<span style="color:#e67e22">性价比提醒：</span>** 同样一篇论文，进**高水平目录（SCI，4分）**比**核心（北大核心/CSCD，1.5分）**多 **2.5 分**，冲刺价值更大。但 SCI 发表周期长、要求高，**本科生发第一作者 SCI 很难**，需结合自身科研进度权衡：能发核心先稳住，能冲高水平就冲高水平。

### 6.3 机械专业实操建议

1. 🎯 **尽早进实验室 / 导师课题组**，跟着本校导师（无亲属关系）做项目，为"第一作者"身份打基础。
2. 🎯 **确认"黑龙江大学是第一署名单位"**——投稿时单位归属必须写黑大。
3. 🎯 **投稿前先核对期刊档位**——查当年《黑龙江大学高水平学术期刊等级目录》，确认目标期刊属于高水平还是核心。
4. 🎯 **争取第一作者**——理科非第一作者不加分；导师可通讯作者，学生本人尽量排第一。
5. 🎯 **盯紧时间**——论文发表时间必须在**本科在读期间内**，规划好投稿周期（从投出到见刊/录用通常数月）。

## 7. 关键红线与行动清单

### 7.1 红线（犯了就前功尽弃）

- ⚠️ **<span style="color:#e74c3c">著作/论文/专利三选最高项，且三类合计不超过5分。</span>** 别零散凑数，集中冲一项高档次。
- ⚠️ **<span style="color:#e74c3c">论文必须是第一署名作者（理科）+ 黑龙江大学第一署名单位 + 高水平/核心期刊，三者缺一不可。</span>**
- ⚠️ **<span style="color:#e74c3c">论文/著作/专利的加分审核，须经学院专家组材料审核 + 现场公开答辩，报学校专家审核小组鉴定，结果校园网公示。</span>** 答辩不过不加分；答辩全程录音录像。
- ⚠️ **<span style="color:#e74c3c">与直系亲属或"明显高于本人者"合作成果不加分（与本校导师、无亲属关系的除外）。</span>**
- ⚠️ **<span style="color:#e74c3c">弄虚作假（论文抄袭、虚报成果）会取消推免资格并记入诚信档案。</span>**

### 7.2 行动清单（对照做）

- [ ] 确认目标期刊在当年《黑龙江大学高水平学术期刊等级目录》中的档位（高水平 or 核心）
- [ ] 落实"黑龙江大学第一署名单位" + "本人第一署名作者"
- [ ] 确认论文发表时间在本科在读期间内
- [ ] 准备完整佐证材料（论文首页/期刊封面/出版社出版证明等）
- [ ] 提前熟悉学院专家组答辩流程，准备个人贡献说明
- [ ] 咨询教务处（0451-86604300）或学院专家组，核实当年认定细则

> [!note] 拿不准就查
> 本笔记中"某期刊具体属于高水平还是核心"这类问题，**以学校当年发布的《黑龙江大学高水平学术期刊等级目录》为准**，最终由**特殊学术专长（科研创新能力）专家审核小组**认定。建议直接咨询教务处或所在学院推免生遴选工作领导小组，不要凭第三方解读判断。
