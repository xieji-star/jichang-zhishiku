## A 创新点框架重构（最高优先级，影响评分最大）

### A-1 最终要改成的新框架（所有写「创新点/创新/核心竞争力」的地方统一对齐）

- ⭐ **核心创新（1 个）**：农艺知识驱动的玉米全生育期水肥智能体（AI Agent）
- 🚨 **创新点 2**：水分临界期保产引擎
- 📷 **创新点 3**：农艺症状标准的视觉营养诊断与水肥处方闭环
- 🧪 **创新点 4**：全生育期水肥处方自动生成器
- 🛠️ **支撑技术（进技术章节，不占创新名额）**：① 双核心异构边缘 AI 架构 ② 多协议兼容 ③ 模块化即插即用维护

> 原计划书的「LSTM 预测 / 智能 Agent / APP 一键 / 国产化 / 开放协议」5 个点，在国赛评审语系里属于**工程实现/体验层**，不算「创新」。要整体搬到「支撑技术 + 体验优势」，把创新名额让给上面 3 个真正的创新点。

## B 补齐三大创新点内容（现在的产品技术 3.4 里几乎没有，创新分大头）

### B-1 创新点 2：水分临界期保产引擎

**位置：左下角页码 14～15 ·「3.4.1 水肥决策算法·决策依据 + 智能 Agent 动态水肥决策」**

> **原文（决策依据）：**
> 「决策依据：…未来 3 天降雨预测（如预报有雨，自动减少灌溉量）…」
> **原文（智能 Agent 动态水肥决策）：**
> 「智能 Agent 根据 LSTM 预测的需水需肥量，结合当前生育期，自动计算每日灌溉时长和注肥泵占空比，使水肥配比在 1:100～1:1000 范围内连续可调。」

**改成：** 在「水肥决策算法」处**新增**一段「水分临界期保产引擎」：
1. 基于经典研究数据「**抽雄—吐丝期（VT-R1）干旱 1 天减产约 8%**」，实施**关键期优先灌溉**；
2. 关键期土壤相对含水量（田间土壤含水量占最大持水量百分比）**自动守住 70–80%**，峰值日需水约 **5.42 m³/亩** 足额供给；
3. 苗期反直觉「**控水蹲苗**」促根系下扎；
4. 叠加「**极端天气三道防线**」（气象预警 → 主动防御如灌水防霜冻 → 灾后恢复评估）。

### B-2 创新点 3：视觉营养诊断与水肥处方闭环（现在完全没有，需新增模块）

**位置：左下角页码 11 ·「3.1 产品形态」 + 左下角页码 13 ·「3.4.1 技术架构」 + 左下角页码 14～15 ·「3.4.1 算法」**

> **原文（3.1 产品形态）：**
> 「核心硬件包括：Jetson Nano 边缘计算板、4G/LoRa 双模通信模块、国产化 EC/pH 传感器、注肥泵（支持四通道）、触摸屏及物理按键双操作面板。」
> **原文（3.4.1 边缘计算核心）：**
> 「边缘计算核心：NVIDIA Jetson Nano，运行 LSTM 预测模型和智能 Agent 决策算法。」

**改成：**
1. **3.1 产品形态**硬件清单里加「**低成本摄像头（约 50 元级，用于叶色图像采集）**」；
2. **3.4.1 边缘计算核心**补「**搭载视觉营养诊断模块**」；
3. **3.4.1 算法**新增「**农艺症状标准的视觉营养诊断**」：按**缺氮→叶色浅黄、缺磷→暗绿泛紫、缺钾→叶缘焦枯、缺水→卷叶**诊断；诊断结果**自动触发该生育期处方**，施肥后**拍照复检**叶色变化量化肥效，形成「观察—诊断—处方—执行—复检」全自动闭环。

### B-3 创新点 4：全生育期水肥处方自动生成器（需新增）

**位置：左下角页码 14 ·「3.4.1 智能 Agent 动态水肥决策」**

> **原文：**
> 「智能 Agent 根据 LSTM 预测的需水需肥量，结合当前生育期，自动计算每日灌溉时长和注肥泵占空比，使水肥配比在 1:100～1:1000 范围内连续可调。」

**改成：** 在该处新增「**全生育期水肥处方自动生成器**」：
1. 内置**分阶段施肥规则库**：苗期重磷稳氮 → 拔节氮钾并重 → 大喇叭口重肥 → 授粉叶面补硼 → 灌浆高钾零氮；
2. 全程**锌硼微量元素管理**；
3. **四大施肥禁忌规则库**（底肥只重氮缺磷钾、中后期只追单一氮肥、灌浆期完全不补肥、肥料搭配冲突/时间错位）**自动拦截提醒**；
4. 农户只需选作物和面积，系统按农艺标准自动配比，杜绝「一刀切施肥」。

> 注：V2.2 §7 要求，施肥方案表述为「**参考农艺文献与专家施肥方案整理**」，不要写成无出处的自定义配比。
