### 1.2 一句话定位

面向玉米种植场景的智慧农业水肥管理系统，通过「感知层土壤多深度传感器 + 决策层 LSTM / Agent 智能模型 + 执行层水肥一体机 / 阀门 / 滴灌管网 + 物联网远程监控」，实现玉米水肥精准决策、自动执行、闭环反馈和低成本落地，解决"水肥决策不准、设备成本高、操作门槛高、兼容性差"等痛点。其中 💡 **<span style="color:#2980b9">LSTM（长短期记忆网络，擅长处理时间序列预测的深度学习模型）</span>** 负责需水需肥预测，💡 **<span style="color:#2980b9">Agent（智能体，按玉米生育期与土壤反馈自动切换水肥配比的决策程序）</span>** 负责动态决策。

## 2. 验收标准与当前差距

### 2.1 "做完"的验收标准

🔥 **<span style="color:#e74c3c">验收不是生成几张图片，而是形成一整套可提交、可路演、可答辩的成果包</span>**，满足七条：

1. **内容准确**：严格依据项目计划书「智灌云联2」、技术手册、路演大纲，禁止胡编乱造技术参数、合作单位、专利、财务数字
2. **视觉统一**：整体风格统一，不能一页一个风格；网评版、路演版、计划书版各自统一规范

4. **字少图多**：页面不堆大段文字，路演页让评委一眼看懂；每页主信息明确、文案高度凝练

6. **可演讲**：路演 PPT 配套 5 分钟讲稿，每页对应讲稿内容

## 3. 项目背景与来龙去脉

### 3.1 项目来源

用户是**黑龙江大学机械设计制造及其自动化专业**本科生，正在参加 2026 年中国国际大学生创新创业大赛，组别为**本科生创意组 / 高教主赛道创意组**。项目主题智慧农业，重点聚焦**玉米**，围绕寒地农业、玉米水肥管理、智能灌溉、国产化设备、AI 决策与物联网远程监控展开。

### 3.2 要解决的问题

1. **水肥决策粗放**：传统水肥一体机多为定时定量控制，缺乏针对玉米不同生育期的动态预测，缺少闭环反馈
2. **设备成本高**：高端 / 进口方案价格通常在 3 万—8 万元，普通农户、合作社、家庭农场接受度有限
3. **操作门槛高**：界面专业术语多、半英文，农户学习成本高
4. **传感器兼容性差**：部分设备只能兼容自家品牌、私有协议多，扩展难
5. **农业场景适配不足**：寒区、坡地、黑土地、玉米全生育期需求变化等场景适配不足

### 3.3 关键前置信息

- 主要面向玉米种植场景，尤其是黑龙江、北大荒、合作社、种植大户
- 强调"寒区智慧农业""玉米水肥管理""低成本国产化""智能硬件+算法闭环"

### 3.4 用户长期偏好

📌 **<span style="color:#e67e22">视觉与内容偏好（硬性）</span>**：

- 页面必须高清、图片真实、不要 AI 感、禁止廉价塑料感、风格高级有层次
- 字少图多、重要数据放大、评委一眼能懂、背景不抢文案
- 不要大段文字、不要胡编乱造、页面尽量统一
- 产品图要真实、细节清晰；有些图片故意要求降低清晰度以匹配旧论文/实地照片风格
- 需要逐页生成图片，不要一张图堆多个页面
- 输出比例：PPT 常用 16:9；计划书封面/背景常用 A4；短视频封面常用 1080×1920 或 941×1672
