# 1. 项目总览与验收

## 1.1 项目内容

项目名称：

> **智灌云联——AI硬件驱动的玉米水肥智能生态系统**

核心目标：

> 面向玉米种植全生育期，以农艺知识为基准，结合气象、作物阶段、土壤数据、LSTM 和智能 Agent，自动生成水肥方案并执行。

核心硬件/系统：

- Jetson Nano：边缘 AI / 决策；
- STM32：设备实时执行；
- EC/pH 传感；
- 可选土壤传感器；
- 注肥泵；
- 电磁阀；
- 4G + LoRa；
- APP；
- 云平台；
- Modbus-RTU / SDI-12 / JSON 等协议。

---

## 1.2 最新创新点口径

最终统一口径必须是：

> **农艺知识驱动的玉米全生育期水肥智能体（AI Agent）**

五要素：

```text
感知 → 记忆 → 规划 → 行动 → 学习
```

对应工程模块：

| 智能体环节 | 项目真实模块 |
| --------- | ------------- |
| 感知 | 气象、生育期、播种日期、土壤/EC/pH |
| 记忆 | 农艺知识库、专家规则、生育期知识 |
| 规划 | 保产引擎、处方生成、Agent自主规划 |
| 动态修正 | LSTM 气象修正 |
| 行动 | Jetson / STM32 / 泵 / 阀 |
| 学习 | 田间数据回流、参数持续修正 |

### 必须保留的三个创新点

1. 水分临界期保产引擎；
2. 视觉营养诊断与处方闭环；
3. 全生育期水肥处方自动生成器。

### 支撑技术

- 双核心异构边缘 AI；
- 多协议开放兼容；
- 模块化即插即用。

### 禁止回退的旧表述

原先：

```text
LSTM + Agent
决策大脑
Agent自动调节水肥配比
1:100—1:1000
```

新版应避免把这些作为核心创新。

特别是：

> **"1:100—1:1000"旧口径已要求删除。**

## 13.2 自动检查所有 PNG 比例

```powershell
Add-Type -AssemblyName System.Drawing

$dirs = @(
    "$Work\03_output_roadshow",
    "$Work\04_output_webreview"
)

foreach ($d in $dirs) {
    Get-ChildItem $d -Filter *.png | ForEach-Object {
        $img = [System.Drawing.Image]::FromFile($_.FullName)
        $ratio = $img.Width / $img.Height

        [PSCustomObject]@{
            File = $_.Name
            Width = $img.Width
            Height = $img.Height
            Ratio = [math]::Round($ratio,4)
            Is16x9 = ([math]::Abs($ratio - 1.7777778) -lt 0.01)
        }

        $img.Dispose()
    }
}
```
