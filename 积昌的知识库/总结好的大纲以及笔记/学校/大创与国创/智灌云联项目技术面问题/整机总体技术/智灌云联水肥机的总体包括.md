# 智灌云联产品技术体系梳理

## 一、整体逻辑：这套系统到底在解决什么问题？

- 智灌云联本质上是一套面向玉米种植场景的**智能水肥一体化控制系统**。
- 它不是单一硬件，也不是单一算法，而是一个完整的**机、电、软、云、农艺模型一体化系统**。
- 整个系统围绕一个核心目标展开：

> 根据玉米当前生育期、未来天气变化和田间反馈数据，自动判断“什么时候灌、灌多少水、施多少肥、怎么执行、执行后如何修正”。

### 1. 系统完整工作链路

```text
气象数据 / 播种日期 / 传感器数据
        ↓
LSTM预测未来3天需水需肥量
        ↓
智能Agent结合生育期与农艺规则生成水肥方案
        ↓
STM32控制注肥泵、电磁阀、滴灌系统执行
        ↓
EC/pH/土壤传感器反馈实际效果
        ↓
模糊PID与Agent修正下一轮控制参数
        ↓
4G/LoRa/MQTT/APP实现远程监控与数据同步
```

### 2. 六大技术板块之间的关系

| 技术板块          | 解决的问题           | 核心支撑                           |
| ------------- | --------------- | ------------------------------ |
| 系统设计与控制       | 整个系统如何协同运行      | Jetson Nano、STM32、开闭环控制        |
| 硬件与装置研发       | 设备如何在田间稳定工作     | IP65机箱、水泵、注肥泵、传感器、电磁阀          |
| 智能控制算法与决策模型   | 如何决定灌多少、施多少、怎么调 | 智能Agent、模糊PID、Kc值、生育期模型        |
| 物联网与远程监控      | 如何联网、上云、远程查看和控制 | 4G、LoRa、MQTT、JSON、HTTP API、APP |
| 需水需肥预测与LSTM算法 | 如何预测未来水肥需求      | 双层LSTM、过去7天气象数据、未来3天预测         |
| 滴灌施肥与变量施肥     | 如何把算法决策真正执行到田间  | 四通道注肥泵、PWM、电磁阀、滴灌管网、EC闭环       |

## 二、第一层：硬件基础系统

### 1. 水源与动力单元

- 水源与动力单元负责解决“水从哪里来、如何加压、如何稳定输送”的问题。
- 常见水源包括：
  - 河流
  - 水库
  - 机井
  - 池塘
  - 蓄水池

### 2. 水泵系统

- 水泵用于为水肥系统提供稳定水压。
- 可兼容用户已有水泵。
- 推荐使用：
  - 增压泵
  - 变频恒压泵

### 3. 变频恒压泵的作用

- 变频泵可以根据系统需水量自动调节转速。
- 当灌溉分区多、压力变化大时，变频泵可以保持管网压力稳定。
- 它的作用是：
  - 稳定供水压力。
  - 降低能耗。
  - 避免压力过大损坏管道。
  - 避免压力不足导致滴灌不均匀。

### 4. 过滤系统

- 过滤器用于防止泥沙、杂质和肥料沉淀堵塞滴头和管道。
- 常见过滤器包括：
  - 砂石过滤器
  - 叠片过滤器
  - 网式过滤器

### 5. 过滤系统的重要性

- 滴灌系统的滴头孔径较小，容易堵塞。
- 如果没有过滤系统，容易出现：
  - 滴头堵塞。
  - 灌溉不均匀。
  - 肥液输送不稳定。
  - 管网维护成本增加。

## 三、第二层：肥料供给与混合系统

### 1. 肥料储存单元

- 肥料储存单元用于存放可溶性肥料或液体肥。
- 常见形式包括：
  - 肥料罐。
  - 肥液桶。
  - 多通道肥液箱。

### 2. 智灌云联的四通道注肥设计

- 智灌云联采用四通道注肥泵设计。
- 可同时管理多种肥料。
- 四通道可用于：
  - 氮肥通道。
  - 磷肥通道。
  - 钾肥通道。
  - 复合肥或备用通道。

### 3. 吸肥装置类型

#### 文丘里注肥器

- 文丘里注肥器利用水流通过喉部时产生的负压吸取肥液。
- 优点：
  - 结构简单。
  - 成本低。
  - 不需要额外动力。
- 缺点：
  - 控制精度较低。
  - 难以实现数字化变量施肥。

#### 注肥泵

- 注肥泵通过电机主动抽取肥液。
- 智灌云联采用国产四通道注肥泵。
- 通过 PWM 控制注肥泵占空比，实现精准注肥。
- 优点：
  - 控制精度高。
  - 可实现连续变量调节。
  - 可配合 EC 传感器形成闭环控制。

### 4. 水肥混合装置

- 水和肥液进入主管道后，需要充分混合。
- 常见方式包括：
  - 管道自然混合。
  - 多折弯主管道混合。
  - 混合腔混合。
  - 静态混合器混合。

### 5. 管道折弯混合原理

- 管道折弯会增加流体扰动。
- 水流经过折弯处时会产生湍流。
- 湍流可以促进水和肥液混合均匀。
- 研究中常采用 CFD 仿真分析管道内流速和湍流强度。
- 多次折弯的主管道有助于提高水肥混合效果。

### 6. EC/pH传感器

- EC 传感器用于检测肥液浓度。
- pH 传感器用于检测肥液酸碱度。
- 二者是闭环施肥控制的重要反馈元件。

### 7. EC闭环控制逻辑

```text
目标EC值
  ↓
注肥泵开始工作
  ↓
EC传感器检测实际肥液浓度
  ↓
实际EC值与目标EC值对比
  ↓
模糊PID调节注肥泵PWM占空比
  ↓
肥液浓度稳定在目标范围内
```

## 四、第三层：管路与管网输送系统

### 1. 管网系统的作用

- 管网系统负责将水肥混合液从首部设备输送到田间作物根部。
- 它是连接水肥一体机和田间终端的关键输送网络。

### 2. 管路类型

| 管路类型      | 功能说明                      |
| --------- | ------------------------- |
| 主输水管道     | 从水泵出口到田间的主干管，通常采用PVC或PE管材 |
| 支路管道      | 从主管道分支到各灌溉小区              |
| 施肥通道管路    | 连接肥料罐与注肥泵或混合装置            |
| 混合液输出管路   | 将混合均匀的水肥溶液输送到田间           |
| 滴灌支管      | 将水肥液分配到具体作物行              |
| 滴灌带 / 滴灌管 | 将水肥精准输送到玉米根部附近            |

### 3. 管路设计关键技术

#### 管道布局优化

- 管道布局影响水压分布和水肥均匀性。
- 管道设计需要考虑：
  - 管径。
  - 管长。
  - 弯头数量。
  - 分区数量。
  - 地块坡度。
  - 水泵压力。

#### 压力调节

- 管道中可安装压力调节阀。
- 作用是保证各灌溉区域出水压力均衡。
- 对坡地和长距离输水尤其重要。

#### 防堵设计

- 防堵设计主要依靠：
  - 前端过滤器。
  - 合理流速控制。
  - 合理管径选择。
  - 管网自清洁。
  - 一键排水功能。

#### 管道材料

- 常用材料包括：
  - PE管。
  - PVC管。
- 选择要求：
  - 耐腐蚀。
  - 抗老化。
  - 抗压。
  - 适应田间环境。

## 五、第四层：田间终端与执行器系统

### 1. 田间终端的作用

- 田间终端负责将水肥真正送到作物根部。
- 它是算法决策转化为农业生产效果的最终执行环节。

### 2. 滴灌管 / 滴灌带

- 滴灌管或滴灌带是水肥一体化的核心执行终端。
- 作用是将水肥精准输送到玉米根区。
- 优点：
  - 节水。
  - 减少地表蒸发。
  - 提高水肥利用率。
  - 降低杂草生长。
  - 有利于精准施肥。

### 3. 喷头 / 微喷头

- 喷头或微喷头适用于喷灌场景。
- 覆盖面积较大。
- 但相比滴灌，水分蒸发损失更大。
- 智灌云联更适合与滴灌系统结合。

### 4. 电磁阀

- 电磁阀用于控制不同灌溉分区的开关。
- 作用包括：
  - 分区灌溉。
  - 轮灌控制。
  - 坡地补偿。
  - 变量灌溉。
  - 远程启停。

### 5. 智能电动球阀

- 智灌云联可支持智能电动球阀。
- 可通过 4G 或 LoRa 进行控制。
- 适合在田间进行远程分区管理。

### 6. 阀门控制器

- 阀门控制器集中管理多个电磁阀。
- 可以按照 Agent 下发的方案控制不同区域阀门开闭。
- 与 STM32 控制器配合，实现多路输出控制。

## 六、第五层：线路与电气系统

### 1. 电气系统的作用

- 电气系统是整套水肥一体机的“神经网络”。
- 它负责连接：
  - 控制器。
  - 传感器。
  - 注肥泵。
  - 电磁阀。
  - 通信模块。
  - 电源模块。

### 2. 电力线路

#### 主供电线路

- 主供电线路可接入：
  - AC220V。
  - AC380V。
- 主要为水泵、控制器、电磁阀等供电。

#### 低压供电线路

- 低压供电线路包括：
  - DC24V。
  - DC12V。
  - DC5V。
- 主要为以下模块供电：
  - 传感器。
  - 通信模块。
  - 控制板。
  - 触摸屏。
  - LoRa模块。

#### 太阳能供电线路

- 太阳能供电为选配方案。
- 基本链路为：

```text
光伏板 → MPPT控制器 → 蓄电池 → 设备
```

- 适用于无电网覆盖的偏远农田。

### 3. 信号线路

#### 传感器信号线

- 用于将传感器数据传回控制器。
- 支持信号类型包括：
  - RS485。
  - 4-20mA。
  - 0-10V。
  - 脉冲信号。

#### 通信线路

- 通信线路包括：
  - 4G天线馈线。
  - LoRa天线。
  - RS485通信线。
  - UART/SPI内部通信线。

#### 控制信号线

- 控制器向执行器发送控制信号。
- 主要包括：
  - PWM控制信号。
  - 开关量信号。
  - 继电器控制信号。

### 4. 线路设计要点

- 信号线与电力线分开布线，避免电磁干扰。
- 田间线路采用防水、防腐蚀接头。
- 关键线路进行防呆设计。
- 重要接口采用模块化插接。
- 必要位置增加防雷、防浪涌设计。
- 线缆标识清晰，便于农户和售后维护。

## 七、第六层：机柜与环境防护系统

### 1. 防护机柜

- 智灌云联将核心电子设备集成在防护机柜中。
- 机柜内部包括：
  - Jetson Nano。
  - STM32控制板。
  - 4G模块。
  - LoRa模块。
  - 电源模块。
  - 接线端子。
  - 传感器接口。
  - 控制接口。

### 2. IP65防水防尘

- 设备采用 IP65 防水防尘机箱。
- IP65含义：
  - `6`：完全防尘。
  - `5`：防低压喷水。
- 适用于田间灰尘、水汽、雨水环境。
- 但不代表设备可以长期浸水。

### 3. 环境适应性

- 设备适用于东北寒区田间环境。
- 环境适应设计包括：
  - 防水防尘。
  - 耐低温。
  - 耐高温。
  - 线缆防腐蚀。
  - 接口密封。
  - 模块化维护。

- 检验报告显示，整机已通过：
  - -40℃低温贮存试验。
  - +60℃高温贮存试验。
  - 符合 GB/T2423.1-2008 标准。

## 八、系统设计与控制

### 1. 核心架构

- 智灌云联系统设计可以概括为：

```text
双核心异构计算 + 双模通信 + 开闭环混合控制
```

### 2. 双核心异构计算

#### Jetson Nano：决策大脑

- Jetson Nano 负责高负载 AI 推理和策略生成。
- 主要运行：
  - LSTM需水需肥预测模型。
  - 智能Agent决策模型。
  - 数据预处理模块。
  - 边缘端推理程序。
  - 云端通信与数据打包程序。

#### STM32：执行神经

- STM32 负责实时设备控制。
- 主要执行：
  - 注肥泵PWM控制。
  - 电磁阀控制。
  - 传感器采集。
  - 模拟量读取。
  - 开关量检测。
  - 故障报警触发。

#### 双核心协同

- Jetson Nano 与 STM32 通过 UART 或 SPI 通信。
- 分工逻辑为：

```text
Jetson Nano负责“算得准”
STM32负责“控得快”
```

- 这样可以将高算力 AI 推理与毫秒级底层控制解耦。

### 3. 双模通信

#### 4G全网通

- 4G是默认主链路。
- 主要用于：
  - 拉取气象API。
  - 上传设备数据。
  - 接收APP远程指令。
  - 与云平台同步。

#### LoRa通信

- LoRa是备控链路。
- 使用 SX1278 芯片。
- 频段为 470-510MHz。
- 主要用于：
  - 无4G信号时本地组网。
  - 田间设备之间通信。
  - 弱网环境下保底传输。
  - 空旷地通信距离可达2km以上。

### 4. 开闭环混合控制

#### 开环模式

- 开环模式是默认模式。
- 不依赖田间土壤传感器。
- 决策依据包括：
  - 气象数据。
  - 播种日期。
  - 当前生育期。
  - LSTM预测结果。
  - 作物需水需肥模型。

- 优点：
  - 部署成本低。
  - 对农户要求低。
  - 不需要额外购买传感器。
  - 适合大规模推广。

#### 闭环模式

- 闭环模式为可选模式。
- 用户接入 RS485 土壤传感器后启用。
- 系统读取：
  - 土壤墒情。
  - 土壤EC。
  - 肥液EC。
  - pH值。
  - 其他传感器反馈。

- 控制逻辑为：
  - 先预测。
  - 再执行。
  - 后反馈。
  - 再修正。

### 5. 供电与功耗

- 系统支持：
  - AC220V。
  - 太阳能 + 蓄电池选配。

- 整机功耗：
  - ≤30W。

- 适合：
  - 有电网农田。
  - 无电网偏远农田。
  - 北方大田场景。

  - 阀门模块。

- 优点：
  - 农户可自行更换。
  - 维修门槛低。
  - 降低停机时间。
  - 降低售后成本。

## 十、传感层：系统如何感知田间状态？

### 1. 传感层的作用

- 传感层负责获取系统运行所需的环境和设备状态数据。
- 它是整个系统的“感知器官”。

### 2. 主要传感器类型

| 传感器类型 | 功能 | 信号类型 |
|---|---|---|
| 土壤水分传感器 | 监测土壤含水量 | 模拟量 / RS485 |
| EC传感器 | 监测肥液浓度 | 模拟量 / RS485 |
| pH传感器 | 监测肥液酸碱度 | 模拟量 / RS485 |
| 流量传感器 | 监测水肥流量 | 脉冲 / RS485 |
| 压力传感器 | 监测管道压力 | 模拟量 |
| 气象数据接口 | 获取温度、降雨、日照等数据 | 4G / API |

### 3. 开环与闭环下的传感差异

- 开环模式下：
  - 不强制依赖田间传感器。
  - 主要依靠气象数据和生育期模型。
  - 降低部署成本。

- 闭环模式下：
  - 接入土壤水分、EC/pH等传感器。
  - 通过实测数据修正决策。
  - 提高控制精度。

## 十一、需水需肥预测与LSTM算法

### 1. LSTM算法的作用

- LSTM负责预测未来3天玉米需水需肥量。
- 它解决的是：

```text
未来几天玉米大概需要多少水、多少氮、多少磷、多少钾？
```

### 2. 模型结构

- 模型采用：
  - 双层LSTM。
  - 隐藏单元数128。
  - 输入窗口为过去7天逐小时气象数据。
  - 输出窗口为未来3天逐日需水需肥量。

### 3. 输入数据

- 输入数据包括：
  - 过去7天温度。
  - 过去7天降雨。
  - 过去7天日照时数。
  - 用户输入播种日期。
  - 系统推算的当前生育期。
  - 必要的作物参数。

### 4. 输出结果

- 输出未来3天逐日预测结果。
- 包括：
  - 需水量。
  - 需氮量。
  - 需磷量。
  - 需钾量。

### 5. 为什么输入过去7天？

- 玉米需水需肥具有滞后效应。
- 连续高温、连续少雨、持续日照都会影响未来需水。
- 过去7天能够反映一轮较完整的天气变化过程。
- 比只看1天或3天更能捕捉趋势。

### 6. 为什么输出未来3天？

- 未来3天对应72小时天气预报较可靠窗口。
- 超过3天后降雨预测误差会增大。
- 3天也符合农户安排灌溉、备肥、调度设备的时间需求。

### 7. 滚动预测机制

- 系统每6小时重新预测一次。
- 每次读取最新过去7天数据。
- 每次重新输出未来3天计划。

```text
第0小时：读取过去7天 → 预测未来3天
第6小时：读取最新过去7天 → 重新预测未来3天
第12小时：继续更新 → 再次预测未来3天
```

### 8. 模型部署

- LSTM模型部署在Jetson Nano上。
- 使用TensorRT进行推理加速。
- 设备端完成边缘推理。
- 优点：
  - 降低云端依赖。
  - 减少网络延迟。
  - 断网仍可运行。
  - 保证田间设备独立决策能力。

### 9. 模型验证

- 模型在黑龙江大学试验田历史数据上训练与测试。
- 采用时间顺序留一法交叉验证。
- 验证集预测误差：
  - ＜5%。

## 十二、智能控制算法与决策模型

### 1. 核心算法组合

- 智灌云联的智能控制算法可以概括为：

```text
LSTM预测 + 智能Agent决策 + 模糊PID执行控制
```

### 2. 智能Agent的作用

- 智能Agent负责把预测结果转化为可执行方案。
- 它不是通用大模型，而是面向玉米水肥管理的专用决策程序。

### 3. Agent输入

- Agent接收以下输入：
  - LSTM预测的需水需肥量。
  - 当前生育期。
  - 未来3天降雨预报。
  - 土壤水分亏缺量。
  - 作物系数Kc值。
  - 传感器反馈数据。
  - 设备状态。

### 4. Agent决策依据

#### 土壤水分亏缺量

- 有传感器时：
  - 读取土壤墒情实测值。
- 无传感器时：
  - 使用蒸散模型估算。

#### 生育期作物系数Kc

- Kc值用于修正作物实际耗水量。
- 不同生育期Kc不同。
- 例如：
  - 苗期Kc约0.7。
  - 拔节至灌浆期Kc约1.2。

#### 未来降雨预报

- 如果未来3天预报有雨：
  - 系统自动削减灌水量。
- 如果未来持续高温少雨：
  - 系统提高灌溉建议。

### 5. Agent输出

- Agent最终输出：
  - 每日灌溉时长。
  - 灌水量。
  - 注肥泵占空比。
  - 水肥配比。
  - 电磁阀开闭顺序。
  - 分区灌溉策略。

### 6. 模糊PID控制

- 模糊PID负责执行层精准调节。
- 主要控制对象：
  - 注肥泵转速。
  - 肥液EC值。
  - 电磁阀开闭。
  - 水肥流量。

### 7. 模糊PID控制目标

- 控制目标包括：
  - 肥液EC值与目标值偏差＜0.1 mS/cm。
  - 阶跃响应时间≤12秒。
  - 避免浓度过冲。
  - 保持肥液浓度稳定。

### 8. 不同生育期自动切换参数

- 不同生育期对应不同PID参数组。
- 例如：
  - 苗期控制更温和，避免施肥过量。
  - 抽雄期控制更快速，保障需水高峰。
  - 灌浆期更重视钾肥供应稳定性。

### 9. 自诊断与报警

- 系统具备故障自诊断功能。
- 可检测：
  - EC传感器异常。
  - pH传感器异常。
  - 注肥泵故障。
  - 电磁阀未响应。
  - 通信中断。
  - 肥箱液位异常。

- APP会推送具体报警，例如：

```text
EC传感器异常，请检查连接线
```

## 十四、滴灌施肥与变量施肥

### 1. 这一板块解决的问题

- 滴灌施肥与变量施肥解决的是：

```text
算法算出来之后，如何真正把水肥精准送到田里？
```

### 2. 水肥配比调节

- 系统使用四通道国产注肥泵。
- 智能Agent根据以下因素生成水肥配比：
  - LSTM预测结果。
  - 当前生育期。
  - Kc值。
  - 未来降雨。
  - 目标EC值。

- 支持水肥配比范围：

```text
1:100 ~ 1:1000
```

### 3. PWM控制注肥泵

- STM32输出PWM信号。
- PWM控制注肥泵占空比。
- 占空比越高，注肥量越大。
- 占空比越低，注肥量越小。

### 4. EC闭环修正

- EC传感器实时回读肥液浓度。
- 如果实际EC低于目标值：
  - 提高注肥泵占空比。
- 如果实际EC高于目标值：
  - 降低注肥泵占空比。
- 模糊PID不断修正，使EC值稳定在目标范围。

### 5. 分区变量灌溉

- 设备具备多路电磁阀驱动接口。
- 可以控制不同区域独立灌溉。
- 适用于：
  - 坡地。
  - 不同土壤区域。
  - 不同长势区域。
  - 不同水压区域。

### 6. 坡地补偿逻辑

- 坡地中，坡顶和坡底水压不同。
- 坡顶水压低，容易灌水不足。
- 坡底水压高，容易积水。
- 系统通过调整阀门占空比实现补偿。

| 区域 | 问题 | 控制策略 |
|---|---|---|
| 坡顶 | 水压低、供水不足 | 提高占空比，例如90% |
| 坡底 | 水压高、易积水 | 降低占空比，例如60% |

### 7. 管网自清洁

- 滴灌管网容易堵塞。
- 堵塞来源包括：
  - 泥沙。
  - 肥料结晶。
  - 水中杂质。
  - 滤网沉积物。

- 系统内置自清洁反冲洗装置。
- 通过占空比冲击力冲刷滤网杂质。
- 作用是：
  - 减少堵塞。
  - 降低人工维护频次。
  - 延长滴灌系统寿命。

### 8. 一键排水功能

- APP支持一键排水。
- 适用于：
  - 灌溉结束后排空管路。
  - 冬季防冻。
  - 设备维护前排液。
  - 清理肥液残留。

### 9. 模块化维护

- 关键部件模块化插接。
- 农户可自行更换：
  - EC传感器。
  - 注肥泵。
  - 电磁阀模块。
  - 通信模块。

- 优点：
  - 降低维护门槛。
  - 减少停机时间。
  - 降低售后成本。

## 十六、六大板块如何协同工作？

### 1. 从数据到决策

- 用户输入播种日期。
- 系统获取气象数据。
- LSTM读取过去7天逐小时气象数据。
- 模型预测未来3天需水需肥量。
- Agent结合生育期、Kc值和降雨预报生成水肥方案。

### 2. 从决策到执行

- Jetson Nano将决策方案下发给STM32。
- STM32输出PWM信号。
- PWM控制注肥泵和电磁阀。
- 四通道注肥泵调整水肥比例。
- 电磁阀控制不同灌溉分区。

### 3. 从执行到反馈

- EC/pH传感器读取肥液浓度和酸碱度。
- 土壤传感器读取墒情。
- 流量和压力传感器监测管道运行状态。
- STM32采集反馈数据。
- Jetson Nano分析偏差。

### 4. 从反馈到修正

- 如果EC偏低，系统提高注肥泵占空比。
- 如果EC偏高，系统降低注肥泵占空比。
- 如果土壤水分不足，下一轮增加灌溉量。
- 如果预报有雨，系统自动削减灌水量。
- 这样形成持续优化的闭环。

### 5. 从本地到远程

- 设备本地完成预测、决策和执行。
- 4G负责上传数据。
- LoRa负责弱网备控。
- APP负责远程查看和控制。
- 云平台负责存储、回放和管理。
