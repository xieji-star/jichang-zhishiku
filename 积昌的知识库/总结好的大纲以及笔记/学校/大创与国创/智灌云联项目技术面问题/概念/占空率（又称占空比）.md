# 智灌云联——占空比（占空率）详解及其在产品中的应用

“占空率”（更专业的叫法是**占空比，Duty Cycle**）是电子控制和工业自动化里最核心的概念之一。说白了，它就是**在一个工作周期里，“干活”的时间占总时间的百分比**。

## 一、用“冲咖啡”的比喻理解它

假设你要用一台自动咖啡机接一杯咖啡，按一下按钮，机器运转1分钟。

- 你按住按钮60秒不松手 → 机器一直干活 → **占空比 = 100%**
- 你按一下，机器转30秒，停30秒，再转30秒 → 总共60秒里干活30秒 → **占空比 = 50%**
- 你按一下，转1秒，停9秒，循环往复 → **占空比 = 10%**

**占空比就是“干活时间 ÷ 总时间”的百分比。** 在你们的设备里，这个“干活”就是注肥泵的转动和电磁阀的开启。

## 二、占空比在“智灌云联”产品里怎么用？（核心）

### ① 控制注肥泵的转速（决定肥料加多少）

智能Agent算出“现在需要把EC值从1.5调到2.0”，模糊PID算出“注肥泵需要加大力度”。

- **具体怎么做？** 不是改变电压（调电压容易烧电机），而是控制每秒通断电的比例。
  - 如果一套周期设为1秒：通电0.9秒、断电0.1秒 → **占空比90%** → 泵转得很快，肥料猛加。
  - 如果通电0.3秒、断电0.7秒 → **占空比30%** → 泵转得慢，肥料少量添加。
- 计划书里写的“配比范围1:100～1:1000”，就是靠占空比的变化来实现的：
  - 占空比5% → 对应1:1000（稀肥）
  - 占空比50% → 对应1:100（浓肥）

### ② 控制滴灌电磁阀的开启时长（决定浇多少水）

田里分多个灌溉区，每个区装一个电磁阀。

- 系统判断1号区需要浇水10分钟，但阀门全开水流太猛容易积水。
- 控制器让阀门以**占空比70%** 运行：开7秒、关3秒，循环10分钟 → 实际总出水量只有全开的70%，避免了地表径流，让水慢慢渗下去。
- **坡地压力补偿也一样**：坡顶水压小，阀门占空比设到90%多给点水；坡底水压大，占空比降到60%少给点，保证全田均匀。

### ③ 节能与硬件保护（评委看好感分）

- 如果让注肥泵一直以100%占空比全速转，电机3个月就会过热烧坏。
- 用50%-70%占空比，既满足了流量需求，又给电机留出了散热时间，寿命延长2-3倍。这对“低成本维护”是实实在在的技术支撑。

## 三、占空比怎么被“算”出来的？

整个过程是这样的：

> LSTM预测需水量 → 智能Agent换算成“目标EC值” → 模糊PID根据当前EC和目标EC的差距 → **计算出一个具体的占空比数值（比如68%）** → 单片机产生对应的方波信号 → 驱动泵/阀门执行。

## 四、一句话总结

> 占空比就是水肥一体机“执行命令”的精确刻度盘。AI说“多加点肥”，占空比就调高；AI说“少浇点水”，占空比就调低。它是连接“算法决策”和“硬件动作”的关键桥梁。
