# 3.2 二力构件

> [!summary] 概要
> 本节专门讲解工程中一类很常见也很重要的结构——**二力构件**。核心定义：**只在两个力的作用下平衡的构件**称为二力构件（直杆或弯杆则称为二力杆）。其受力特点是：两个力必定**沿着两个力作用点的连线**方向、**大小相等、方向相反**。课程通过一个水平均质梁 AB 与轻直杆 CD 的实例，演示了识别二力构件后如何简化受力图，并强调画受力图时方向可以**先假定**、真实方向需由定量计算确定，最后通过四个结构练习判断二力构件。本节是对 [[3.1受力分析与受力图]] 中"二力构件处理方法"的展开，也是 [[2.3约束与约束反力]]、[[2.4工程中常见的约束]] 知识的综合运用。

## 1. 二力构件的定义

- **二力构件**：只在两个力的作用下平衡的构件。
- **注意**：只能在两个力的作用下，不能多一个力，也不能少一个力。
- **二力杆**：如果这个构件是直杆或弯杆，就称为二力杆。
- 💡 **<span style="color:#2980b9">一个构件是否为二力构件，仅仅与它的受力有关，而与它的形状没有直接关系。</span>**

## 2. 二力构件的受力特点

由二力平衡公理，二力构件保持平衡的必要和充分条件是：**两个力大小相等、方向相反，并且作用在同一条直线上**（等值、反向、共线）。

- **受力特点**：这两个力必定**沿着两个力作用点的连线**，并且大小相等、方向相反。
- 💡 **<span style="color:#2980b9">二力平衡公理：等值、反向、共线——这是二力构件受力分析的理论依据。</span>**
- **直杆**：两个力作用点的连线沿杆的方向，因此直杆形式的二力杆，两个力都沿杆的方向，等值反向，可能是**压力**，也可能是**拉力**。
- 📊 **<span style="color:#e67e22">二力杆上的力可能是压力也可能是拉力，画图时二者皆可。</span>**
- **弯杆**：不管其形状如何，两力的作用线总是沿着作用点连线的方向，等值反向。
- **任意形状**：只要是在两个力作用下平衡的构件，两个力也必定沿两个力作用点的连线、等值反向。
- 🔥 **<span style="color:#e74c3c">对二力构件来说，它其实只有一个未知的约束力——知道了一个，另一个自然就得到了。这是二力构件在受力分析中最大的简化价值。</span>**

## 3. 实例分析 CD 杆与 AB 梁

**题目**：有一个水平的均质梁 AB，自身重力为 P1，一端铰接在竖直墙壁上，另一端放置一个重力为 P2 的电动机。梁被一根不计自重的轻直杆 CD 支撑，CD 杆在 D 点与 AB 梁铰接在一起，在 C 点与竖直墙壁铰接在一起。画出 CD 杆和 AB 梁的受力图。

### 3.1 CD 杆的受力分析（识别二力构件）

1. **取研究对象**：取 CD 杆为研究对象，画出简图。注意画简图时 CD 杆**没有带销钉**。
2. **画主动力**：因为不考虑 CD 杆的自重，所以没有主动力存在。
3. **画约束力**：
   - **C 点**：固定铰支座与墙壁连接，约束力可表示为两个正交分力 FCX、FCY；
   - **D 点**：光滑圆柱铰链与 AB 杆连接，约束力可表示为两个正交分力 FDX、FDY。

**这样画到底对不对？** 进一步分析：

- D 点是光滑圆柱铰链约束，本质上是光滑接触约束，其约束力本质上是一个力；
- C 点是固定铰链支座约束，其约束力本质上也是一个力；（两类约束的性质详见 [[2.4工程中常见的约束]]）
- 因此 CD 杆其实是在**两个力**的作用下平衡。

由**二力平衡公理**可知，这两个力使 CD 杆平衡的必要和充分条件是：大小相等、方向相反、作用在同一条直线上。所以这两个力**等值、反向、共线**，方向应沿着两个力作用点的连线方向。

- 🔥 **<span style="color:#e74c3c">CD 杆是二力构件（二力杆），其受力应画成沿 CD 方向的一对力（压力或拉力），而不是两个正交分力。</span>**

### 3.2 AB 梁的受力分析

1. **取研究对象**：取 AB 梁为研究对象，画出简图。
2. **画主动力**：AB 梁自身的重力 **P1**、电动机的重力 **P2**。
3. **画约束力**：
   - **A 点**：固定铰链支座约束，约束力为两个正交分力 **FAX、FAY**；
   - **D 点**：约束力是 CD 杆给 D 点销钉的作用力。因为已识别出 CD 杆是二力杆，其受力已知，所以 D 点受到的力是 **FD′**，它与 CD 杆在 D 点受力是作用力和反作用力关系。
- 📌 **<span style="color:#e67e22">识别出二力杆后，AB 梁 D 点的约束力方向就由 CD 杆的受力直接确定，无需再分解为正交分力。</span>**

## 4. 受力方向的假定

- 画受力图时，**不一定**要给出真实的受力方向，因为实际情况中真实受力方向有时很难判断。
- **定性分析给出的都是假定的受力方向**，真实的方向需要根据定量的计算结果来确定。
- **示例**：在刚才的例子中，很容易判断 CD 杆受的是压力。但如果再在 AB 梁上作用一个向上的力 F，此时 CD 杆到底是受拉力还是受压力，就不太容易判断了。
- 📌 **<span style="color:#e67e22">做法：先假定一个方向画出来（画成拉力或压力都可以），通过定量计算求出结果后，若结果为正值则方向与假定一致，若为负值则相反。</span>**
- ⭐ **<span style="color:#e74c3c">同一根二力杆，先假定它受压力、或先假定它受拉力，都是可以的——AB 梁在 D 点的约束力会相应反向，但最终计算结果一致。</span>**

## 5. 练习 判断二力构件

判断下列结构中哪些是二力构件，并画出杆上 D 点的受力方向。

### 5.1 结构一

- 由两根杆铰接组成。
- **CD 杆是二力杆**；D 点受力方向沿杆的方向，可以是拉力，也可以画成压力。

### 5.2 结构二

- 显然 CD 杆也是一个二力杆；D 点受力方向沿杆的方向，可以是拉力，也可以画成压力。

### 5.3 结构三（直杆 + 弯杆）

- CD 杆是一个二力的**弯杆**；D 点受力方向沿两个作用点的**连线方向**。

### 5.4 结构四（三根杆）

- **DB 杆**：一端通过固定铰链支座与地面连接，另一端是光滑圆柱铰链约束。这两个约束本质上都是光滑接触约束，所以 DB 杆是**二力杆**。
- **AB 杆**：类似的，也是**二力杆**。
- **AC 杆**：A 点是固定铰链支座约束，本质是光滑接触约束，是一个力。C 点的约束力可从两个角度考虑：
  - 把杆与销钉**分开**：C 点受到来自销钉的作用力，是光滑接触约束，本质上也是一个力；
  - 把销钉与杆**放在一起**：C 点的约束力是作用在销钉上的两段绳子的拉力，这是两个**共点力**，可以合成为一个力。
  - 两种角度都表明 C 点约束力可看作一个力 → **AC 杆也是二力杆**。
- 💡 **<span style="color:#2980b9">两个共点力可以合成为一个力，因此"受两段绳子拉力"的销钉端仍可视为单力作用，不破坏二力杆条件。</span>**
- 结论：这个结构中**三根杆都是二力杆**；DB 杆在 D 点的受力方向沿杆的方向。
- 💡 **<span style="color:#2980b9">判断二力杆的关键：逐一检查杆两端约束的本质——若每个约束本质上都相当于"一个力"（如光滑接触、光滑圆柱铰链、固定铰链支座），且杆上无其他主动力，则该杆是二力杆。</span>**

> [!tip] 学习提醒
> 实际结构中二力构件的具体形式多种多样，无法一一列出；有些二力构件还比较隐蔽，不能一眼就看出。同学们需要在实际做题或应用过程中多加练习。
