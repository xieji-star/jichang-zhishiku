# 3.1 受力分析与受力图

> [!summary] 概要
> 本节讲解如何对受力物体进行受力分析并画出受力图，是静力学求解的基础环节。内容包括：**受力分析与受力图的概念**（定性分析物体受力情况，再以图形形式画出）、**取分离体**（将研究对象从周围物体中隔离出来单独画简图）、**画受力图的一般步骤**（取研究对象 → 画主动力 → 依约束性质画约束力），并通过**碾子**和**三角拱桥结构**两个典型例题演示。核心原则：**内力一律不画在受力图上**。本节用到的约束力知识来自 [[2.3约束与约束反力]] 与 [[2.4工程中常见的约束]]。

## 1. 受力分析与受力图的概念

本节主要内容包括四个方面：

1. 受力分析和受力图的概念，以及画受力图的方法；
2. 受力分析中一个很重要的构件——**二力构件**的处理方法（详见 [[3.2二力构件]]）；
3. 几个典型的画受力图练习；
4. 如何将实际问题进行简化，得到力学模型，并画出力学简图。

### 1.1 什么是受力分析

- **定义**：受力分析就是分析物体的受力情况，确定物体受到哪些力的作用、每个力的作用点在哪儿、每个力的作用方向指向哪儿。
- **性质**：这是一个**定性**的分析过程。
- 💡 **<span style="color:#2980b9">受力分析三问：受哪些力？每个力的作用点在哪？每个力的方向指向哪？</span>**
- **示例**：台北 101 大厦的风阻尼器——主体是一个重达 **660 吨**的巨大钢球，由 4 根钢索悬挂在楼顶，底部由 8 根液压活塞与楼体连接。楼体晃动时，会受到活塞传递过来的钢球反作用力，从而产生减震效果。要计算活塞传力的大小，就需要对钢球进行受力分析。
- **为什么要先做受力分析**：
  - 只有先**定性**给出物体的受力情况，才能**定量**求解各个力的大小，进而解决其他问题；
  - 没有受力分析，求解静力学问题将无从下手。
- 💡 **<span style="color:#2980b9">受力分析是所有静力学理论应用的基础。</span>**

### 1.2 什么是受力图

- **定义**：把受力分析的结果以图形的形式画出来，更准确地说，是把物体所受到的**所有力**以一种简明的图形画出来。
- ⚠️ **<span style="color:#e74c3c">画受力图时是所有力，不能多，也不能少。</span>**
- **示例**：101 大厦风阻尼器的受力图包括：
  - **重力**（主动力）：作用在质心处，方向竖直向下；
  - **4 根钢索的拉力**（约束力）：沿钢索方向、背离钢球；
  - **8 根液压活塞的作用力**（约束力）：作用在各自的接触点，方向沿杆方向（假设均为拉力）。

## 2. 取分离体

- **定义**：为了把结果清晰地显示出来，把所要研究的那个物体从周围的物体中**分离**出来，单独画它的简图。这一过程叫**取分离体**，也叫**取研究对象**；画出来的图叫**分离体图**。
- **为什么需要取分离体**：当结构中包含多个构件（如 3 根杆、2 个滑轮、1 个重物、若干铰链和绳索）时，如果把所有结构的受力都画在同一张图上，各结构的受力会相互交织、无法分辨。此时需要把它们分开隔离，单独取所研究的结构为研究对象来画它的受力图。
- 💡 **<span style="color:#2980b9">取分离体 = 取研究对象 + 单独画简图，让目标物体的受力不被其他构件干扰。</span>**
- **示例**：研究 AB 杆就取 AB 杆为研究对象画简图；研究 DE 杆就取 DE 杆为研究对象画简图。
- 📌 **<span style="color:#e67e22">销钉的归属：将 DE 杆与 AB 杆分开时，将销钉与 AB 杆画在一起，AB 杆简图上 C 点对应一个黑色圆点（代表有销钉）；而 DE 杆上 C 点对应一个孔洞（代表没有销钉）。</span>**

## 3. 画受力图的一般步骤

画受力图没有固定方法，但遵循以下步骤会使过程清晰简单：

1. **取研究对象**：要画哪个物体的受力图，就取该物体为研究对象，画出它的简图；
2. **画主动力**：画出所有主动力，一般情况下主动力是已知的；
3. **画约束力**：依据约束的性质画出所有约束力。

- ⚠️ **<span style="color:#e74c3c">第 3 步要注意不要多画力、也不要少画力。</span>**
- 📊 **<span style="color:#e67e22">初学者往往在第 3 步出错，经常想当然地多画出一些力，或漏掉一些力——主要原因是对约束的性质没有完全掌握。</span>**

## 4. 典型例题 碾子的受力图

**题目**：一个碾子自身重力为 P，在碾子的中心作用有一个斜向上的拉力 F，想把这个碾子拉上一个由 AB 所构成的台阶，AB 接触处认为是光滑的。画出这个碾子的受力图。

**解答**：

1. **取研究对象**：取碾子为研究对象，画出它的简图。
2. **画主动力**：碾子上作用有两个主动力：
   - 重力 **P**：作用在碾子质心处，方向竖直向下；
   - 斜向上的拉力 **F**：作用在碾子的中心处。
3. **画约束力**：碾子在 B 点和 A 点受到两个约束：
   - **B 点**：光滑接触约束，约束力 FNB 作用在接触点，沿法线方向指向碾子中心；
   - **A 点**：光滑接触约束，约束力 FA 作用在接触点 A，沿接触点的公法线方向指向碾子中心。

- 💡 **<span style="color:#2980b9">光滑接触约束的约束力一律作用在接触处，方向沿公法线指向被约束物体（圆心）——这与 [[2.4工程中常见的约束]] 中光滑接触约束的性质完全一致。</span>**

## 5. 典型例题 三角拱桥结构与内力

**题目**：一个三角拱桥结构，由两个拱 AC、BC 在 C 点通过一个铰链铰接在一起，并且两个拱分别通过铰链 A、B 固定在地面上。已知左右两个拱自身的重力都是 P，并且在 AC 拱上作用有一个集中力 F。分析 AC 拱、BC 拱以及整体的受力，并画出受力图。

### 5.1 AC 拱的受力图

1. **取研究对象**：取 AC 拱为研究对象，画出简图。
2. **画主动力**：两个主动力——自身重力 P、集中力 F。
3. **画约束力**：
   - **A 点**：固定铰链支座与地面固定，约束力为两个正交分力 **FAX、FAY**；
   - **C 点**：光滑圆柱铰链与右边的拱连接，约束力为两个正交分力 **FCX、FCY**。

### 5.2 BC 拱的受力图

1. **取研究对象**：取 BC 拱为研究对象，画出简图。注意 C 点是**带着销钉**的。
2. **画主动力**：只有自身的重力 P。
3. **画约束力**：
   - **B 点**：固定铰链支座与地面连接，约束力为两个正交分力 **FBX、FBY**；
   - **C 点**：受到的是 AC 拱对销钉的作用力，可表示为 **FCX′、FCY′**，与 AC 拱 C 点的受力是一对作用力和反作用力。

### 5.3 整体的受力图与内力

1. **取研究对象**：取整体为研究对象，画出简图。
2. **画主动力**：两个拱自身的重力 P、P，以及作用在 AC 拱上的集中力 F。
3. **画约束力**：AC 拱和 BC 拱所受到的约束力——A 点 FAX、FAY，B 点 FBX、FBY，以及 C 点的两组约束力。

- ⚠️ **<span style="color:#e74c3c">如果把 C 点的受力也画出来，你会发现 C 点受力很杂很乱，仔细分析后它其实是两组相互平衡的作用力和反作用力——画出来没有任何意义。</span>**
- **内力定义**：在所研究的系统内，物体与物体未分离处的作用力，称为**内力**。例如整体结构中 AC 拱和 BC 拱在 C 点没有分离开，C 点的作用力就是内力。
- 🔥 **<span style="color:#e74c3c">画受力图的一条重要原则：内力一律不画在受力图上，或者说内力要绝对禁止画在受力图上。</span>**

### 5.4 本节总结

- 受力图是静力学求解中**非常关键**的一步，受力图画错的话，后面的求解过程再完美都没有意义。
- 想画得快又准确，除了多加练习，没有更好的方法。课后应进行大量练习，尽快掌握如何画物体受力图。

> [!tip] 画受力图自查要点
> ① 是否把所有主动力都画上了？② 是否依据约束性质正确地画出所有约束力（不多画、不少画）？③ 是否误把内力画上了？
