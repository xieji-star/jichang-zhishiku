# Obsidian 仿真图 · 制作规范（CircuitJS 画布尺寸）

> **目的**：规定「仿真图」（CircuitJS 交互仿真）在 Obsidian 中的**标准尺寸**，使其与 draw.io 图（如 `回路电流法-双回路电路.drawio.svg`，780×540）观感一致。
> **适用范围**：所有用 ` ```circuitjs ` 代码块嵌入的电路仿真图（永久默认，无需逐图调整）。

---

## 一、结论（默认规范）

| 项 | 标准值 |
|----|--------|
| 目标观感尺寸 | **≈ 780 × 540 px**（与 draw.io 参考图一致） |
| 画布宽度 | netlist 坐标跨度 **≈ 768**（x 最大值 ≈ 768） |
| 画布高度 | netlist 坐标跨度 **≈ 384** |
| netlist 坐标粒度 | **16 的整数倍**（Falstad 网格 = 16，避免元件错位） |
| 容器尺寸（CSS） | 宽 780px / 高 540px，配 `max-width:100%` 兜底 |

---

## 二、原理（为什么必须放大坐标）

1. **Falstad CircuitJS 不会自动缩放**电路以适应容器——坐标多大，图就画多大；
2. `obsidian-circuitjs` 插件把容器固定为 `width:100%; height:600px`（见插件 `styles.css`），且**插件设置面板里没有尺寸选项**；
3. 结论：**容器不是瓶颈，netlist 的坐标数值才是**。改容器 CSS 只能改外框，改不了图的大小。
4. 因此**唯一有效的放大手段** = 放大 netlist 里**坐标字段**的数值（只放大坐标，不动参数值）。

---

## 三、操作方法

1. 取得原始 netlist：推荐在 <https://www.falstad.com/circuit/> 画好后用「文件 → 导出为文本」，再粘贴进 ` ```circuitjs ` 代码块。
2. 把**每条元件行里前 4 个数字**（`x1 y1 x2 y2`）乘以放大倍数 **k**，使 **x 最大跨度 ≈ 768**：
   - 例：跨度 384 → k = 2；跨度 256 → k = 3；跨度 192 → k = 4。
   - **切记不要**乘后面的参数（阻值、电压、频率、flags 等）。
3. 乘积取 **16 的整数倍**，保证元件落在网格上、不错位。
4. 容器尺寸由 CSS 片段 `circuitjs-size` 统一控制，一般**无需逐图设置**。

> 各类元件行的坐标字段位置：
> `v x1 y1 x2 y2 flags ...`（电压源）、`r x1 y1 x2 y2 flags 阻值`（电阻）、
> `w x1 y1 x2 y2 flags`（导线）、`g x1 y1 x2 y2 flags`（接地）。

---

## 四、范例（×2 放大：384×192 → 768×384）

```circuitjs
$ 1 0.000005 10.20027730826997 50 5 50
v 0 384 0 0 0 0 40 10 0 0 0.5
r 0 0 384 0 0 100
r 384 0 768 0 0 100
r 384 0 384 384 0 100
v 768 0 768 384 0 0 40 10 0 0 0.5
w 0 384 384 384 0
w 384 384 768 384 0
g 384 384 384 384 0
```

---

## 五、校验清单

- [ ] x 坐标最大跨度 ≈ 768（±32 内可接受）
- [ ] **只放大了坐标**，参数值（阻值/电压/频率/flags）未变
- [ ] 所有坐标均为 **16 的整数倍**
- [ ] CSS 片段 `circuitjs-size` 已在 `.obsidian/appearance.json` 的 `enabledCssSnippets` 中启用
