# 回路电流法 · 电路（CircuitJS 交互仿真版）

> 由 **CircuitJS**（`obsidian-circuitjs`）渲染：下方 `circuitjs` 代码块是一个**可交互的电路仿真器**。
> 标识：` ```circuitjs `　·　**需切到阅读视图**才能交互（可拖动元件、改参数、看电流/电压变化）

---

```circuitjs
$ 1 0.000005 10.20027730826997 50 5 50
v 0 384 0 0 0 0 40 10 0 0 0.5
r 0 0 384 0 0 100
r 384 0 768 0 0 100
r 384 0 384 384 0 100
v 768 0 768 384 0 0 40 10 0 0 0.5
w 0 384 384 384 0
w 384 384 768 384 0
g 384 384 384 384 0
```

---

**元件对照**：`v` = 电压源（E₁/E₂）、`r` = 电阻（R₁/R₂/R₃）、`w` = 导线、`g` = 接地。

**尺寸规范**：本图已按 **×2** 放大（坐标跨度 768 × 384），与 `回路电流法-双回路电路.drawio.svg`（780×540）观感一致。Falstad **不会自动缩放**，放大只能靠放大 netlist 坐标 → 详见 [[Obsidian仿真图-制作规范]]。

> 若上方未渲染：netlist 手写容易出错，推荐在 <https://www.falstad.com/circuit/> 画好后用「文件 → 导出为文本」，再粘贴进代码块。
