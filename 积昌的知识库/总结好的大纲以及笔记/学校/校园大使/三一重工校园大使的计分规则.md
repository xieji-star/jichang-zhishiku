# 三一重工校园大使的计分规则

> [!summary] 概要
> 本文整理自 **2026-08-28 三一集团校园大使宣贯会**（语音转写）。核心是校园大使的**积分规则**：无底薪，以积分兑换现金（**1 积分 = 1 元**），通过**简历推荐 / 推广宣传 / 线下活动 / 校内调研 / 日常运营**五大维度赚取积分，**多劳多得、不设上限**。同时涵盖三一集团背景、任职要求、兑换规则、福利与退出机制。

## 三、校园大使任职要求

| 要求 | 说明 |
|------|------|
| 任职周期 | 秋招期间在职：**9 月初 ~ 11 月底（至少 3 个月）** |
| 时间投入 | 每周累计 ≥ **10 小时** |
| 毕业届别 | **27 届及以后** |
| 学历 | 本科 / 硕士在校生 |
| 薪资模式 | **无底薪**，积分兑换现金（1 积分 = 1 元） |
| 考核 | 无强硬考核，按要求完成工作任务即可 |

> 💡 集团原则：**不给大使增加额外负担**，管理与对接尽量精简，不做过多考核，不耽误太多时间。

> 💡 **<span style="color:#2980b9">薪资模式：无底薪，以积分兑换现金（1 积分 = 1 元）</span>**，多劳多得

## 四、积分获得维度（五大维度）

### ① 简历推荐（内推码）—— 核心维度，不设上限

| 节点 | 积分 |
|------|:----:|
| 内推码（内部推荐专属邀请码）投递**有效简历** 1 份 | +5 分 |
| 进入面试 | +10 分 |
| **入职**（在职满 1 个月才算入职完成） | +50 分 |
| 单人次全流程合计 | **65 分** |

- 有效简历 = 被推荐人基础条件符合集团标准（并非随便拉人即可）
- 秋招需求多、岗位多，对简历需求量极大 → **推荐不设上限，有效简历越多积分越多**

> 📊 **<span style="color:#e67e22">单人次全流程最高 65 积分（5 + 10 + 50）</span>**
> 🔥 **<span style="color:#e74c3c">推荐不设上限：有效简历越多、积分越多，是五大维度中的核心</span>**

### ② 推广宣传

| 动作                  |   积分    |
| ------------------- | :-----: |
| 转发朋友圈               | +5 分/次  |
| 转发学校社群（就业群、学院/学校群等） | +5 分/次  |
| 小红书指定话题发布**原创内容**   | +10 分/次 |
| 内容优质（点赞 > 100）      |  +20 分  |

- **统计方式**：线上系统自动统计（如简历数）；系统实现不了的，用文档手动提交
- 每周统计公布一次，每月计算积分并公布一次

> 💡 **<span style="color:#2980b9">统计方式：线上系统自动统计，系统实现不了的用文档手动提交</span>**
> 📣 黑大校园宣传渠道的完整打法（辅导员 / 就业群 / 双选会等）见 [[三一重工黑大校园大使-招聘宣传渠道全案]]

### ③ 线下活动支持（现金，不计积分）

| 活动 | 报酬 |
|------|------|
| 进校宣讲会 / 沙龙 | **150 元/天** |
| 贴海报 / 发传单 | **50 元/天** |

- 按实际工作时长折算（如半天按半天结算）
- 现金在**秋招结束后统一发放**

> 📊 **<span style="color:#e67e22">宣讲会 / 沙龙 150 元/天、贴海报 / 发传单 50 元/天（现金结算，不计积分）</span>**

### ④ 校内调研

| 动作 | 积分 |
|------|:----:|
| 帮助获取学校公开信息 | +5 分 |
| 定向找到特定专业/研究方向同学联系方式（对方同意） | +5 分/人 |

### ⑤ 日常运营

| 动作 | 积分 |
|------|:----:|
| 管理自有社群、帮做宣传 | +25 分/月 |
| 每月积分排名前三 | **额外 +50 分** + 公司周边礼品 |

## 五、积分兑换规则

| 规则 | 说明 |
|------|------|
| 兑换比例 | **1 积分 = 1 元** |
| 兑换时间 | 每月**最后一周**开放兑换申请（具体时间不定） |
| 兑换下限 | 单次需**满 100 积分**才能兑换 |
| 上限 | **不设上限，多劳多得** |
| 未满 100 分 | 可**延迟到下月**兑换（如 95 分不会强制作废，下月累计到 120 分照常结算） |
| 发放时间 | 大使薪资在**秋招结束后统一发放** |

> 💡 **<span style="color:#2980b9">兑换比例 1 积分 = 1 元</span>**，🔥 **<span style="color:#e74c3c">不设上限、多劳多得</span>**
> ⚠️ **<span style="color:#e74c3c">单次兑换须满 100 积分</span>**，未满可延迟到下月累计结算

## 六、额外福利

| 福利 | 条件 / 说明 |
|------|------------|
| 聘书 / 实习证明 / 实践证明 | **满 3 个月 且 总积分 > 200**，发放**带公章**聘书或证明 |
| 职业发展支持 | 每月 **1 次 1 对 1 职业规划**咨询 + 简历修改支持 |
| 内推推荐 | 利用集团渠道帮推荐岗位，**不限于三一**（其他公司也可） |
| **面试直通机会** | 任期内 **2 次**（免简历筛选、免测评（在线能力测试），**直通专业面**=第一轮面）；需单独联系 HR，**仅限本人使用** |
| 金牌校园大使 | 秋招结束评选**前 20 名**，受邀参加三一**开放日**（预计明年上半年，"星辰计划"） |

> 📌 面试直通卡使用提醒：因内部协调安排需要流程和时间，用前**先想好目标岗位**再联系 HR；直通卡**仅限 27 届当年使用**（28 届校招时需重新获取）。

> 🎁 **<span style="color:#e74c3c">任期内 2 次面试直通</span>**（免简历筛选、免测评，直通专业面 = 第一轮面），仅限本人使用

## 七、退出机制

| 场景 | 处理 |
|------|------|
| 宣贯会后决定不参加 | 联系 HR 说明后直接**退群**即可 |
| **连续两个月积分 < 20**（基本啥也没干） | 会被建议退出，不再继续担任 |

> ⚠️ **<span style="color:#e74c3c">连续两个月积分 < 20（基本啥也没干）会被建议退出</span>**

## 八、Q&A 要点

- **面试直通**：只能自己用，直通的是**专业面（第一轮面）**；"星辰计划"的面试直通同样直通专业面
- **沈阳岗位**：主要集中在**三一重装**，今年岗位数量较多（优于往年）
- **招聘规模（HC，Headcount 招聘名额）**：1000+，尚未完全定档
- **秋招启动时间**：预计**下周（8 月最后一周）**正式启动，启动推文届时需大使转发
- **提前批**：投递已截止，流程中的简历会继续推进（该面试的会安排完）
- **海外岗位**：有**海外营销**等岗位
- **线下行程**：第一批线下学校行程预计下周公布，对外公开
