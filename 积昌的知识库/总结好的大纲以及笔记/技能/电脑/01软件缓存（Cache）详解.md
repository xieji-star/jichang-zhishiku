# 💾 01 软件缓存（Cache）详解

> [!summary] 概要
> 缓存（Cache）是计算机为了"提速"而把常用数据临时存放副本的高速存储区。它把频繁使用的数据放在离使用方更近、读写更快的地方，省去重复计算和重复传输。本文用生活比喻讲清缓存是什么、为什么需要、常见类型、好处与代价，以及什么时候该清理、怎么清理缓存。

## 1. 什么是缓存

一句话定义：**缓存（Cache）是把"可能反复使用"的数据，提前复制到离使用方更近、读写更快的地方，用空间换速度。**

> 💡 **<span style="color:#2980b9">缓存 = 空间换时间：用一部分存储空间，换取更快的访问速度。</span>**

三个生活比喻：

1. **图书馆借书**：常看的几本书不用每次跑大书库（慢），直接放桌上（快）——桌子就是缓存。
2. **外卖备餐**：热门菜品提前做好保温放着，点单直接出餐，不用现做——备餐台就是缓存。
3. **快递驿站**：常收货的小区设一个驿站，不用每次跑几公里外的总仓——驿站就是缓存。

---

## 2. 为什么需要缓存

### 2.1 不同存储的"速度差"巨大

| 存储层级 | 典型容量 | 读取速度 | 离 CPU 距离 |
|---------|---------|---------|:----------:|
| CPU 寄存器 | 极小 | 最快 | 最近 |
| CPU 缓存（L1/L2/L3） | KB ~ MB | 纳秒级 | 很近 |
| 内存（RAM） | GB 级 | 数十纳秒 | 较近 |
| 固态硬盘（SSD） | 数百 GB | 微秒级 | 较远 |
| 机械硬盘（HDD） | TB 级 | 毫秒级 | 远 |
| 网络 / 云端 | 无限 | 数十毫秒~秒级 | 最远 |

> 📊 **<span style="color:#e67e22">速度差距可达百万倍：CPU 缓存比网络快约 10⁵~10⁶ 倍。</span>** 如果每次都去最慢的地方取数据，电脑就会明显卡顿。

### 2.2 二八定律（局部性原理）

程序运行存在明显的"局部性"：

- **时间局部性**：刚用过的数据，很快还会再用（如循环体里的变量）
- **空间局部性**：刚用过的数据附近的地址，很快也会用到（如连续数组）

> 💡 **<span style="color:#2980b9">把"经常用的那 20% 数据"放到快的地方，就能覆盖 80% 以上的访问需求——这就是缓存高效的底层原因。</span>**

---

## 3. 缓存是怎么工作的

核心围绕两个词：**命中** 和 **未命中**。

1. 程序要数据 X，先到缓存里找；
2. 找到 → **缓存命中（Cache Hit）**，直接取用，飞快；
3. 没找到 → **缓存未命中（Cache Miss）**，到内存、硬盘或网络上取原始数据，取回后**顺手存一份到缓存**，下次就用上；
4. 缓存满了 → 按淘汰策略（如 LRU 最近最少使用）把最不常用的数据清掉，腾出空间给新数据。

```
请求数据 → 查缓存 → 命中：直接返回（快）
                → 未命中：去源数据取（慢）→ 写回缓存一份 → 返回
```

> ⭐ **<span style="color:#e74c3c">缓存的本质就是"以空间换时间"：多存一份副本，换取下次访问不再走慢路。</span>**

## 4. 缓存无处不在：常见类型

### 4.1 CPU 缓存（L1 / L2 / L3）

CPU 内部的多级高速缓存，离核心最近、最快、容量最小。L1 最快最小，L3 相对大而慢。编程时让数据"贴得近"（局部性好）就能提升缓存命中率，程序跑得更快。

### 4.2 浏览器缓存

浏览器为了"秒开网页"做的缓存：

| 类型 | 作用 |
|------|------|
| **DNS 缓存** | 记住域名对应的 IP，省去每次 DNS 解析 |
| **HTTP 缓存** | 按服务器规则把页面资源存本地，下次直接读本地 |
| **静态资源缓存** | 图片、CSS、JS 存本地，重复访问不用重新下载 |

> 🧹 网页样式错乱、改完代码刷新还是旧版 → 多半是浏览器缓存没清。

### 4.3 软件 / 系统缓存

- 系统缩略图缓存：文件夹里图片、视频的缩略图
- 应用缓存：微信、QQ、浏览器产生的缓存图片、聊天缩略图
- 插件 / 会话缓存：如 Obsidian 的会话缓存（相关排错案例见 [[01-Obsidian反复报错Request too large]]）

### 4.4 网络缓存：CDN

CDN（内容分发网络）把网站静态资源复制到全国乃至全球各地的节点服务器，用户就近访问，不用都挤到源站。这也是"同一个网站不同地区打开速度不同"的原因。

### 4.5 数据库 / 服务器缓存

高并发场景下，服务器把热点数据放在内存缓存里（如 Redis、Memcached），避免每次查询都打数据库，从而扛住更大流量。

### 4.6 AI 与提示词缓存（Prompt Caching）

大模型调用时，厂商把**重复的上下文内容**计算一次后缓存复用，命中部分按更便宜的"缓存价"收费。这就是"命中缓存"的省钱机制，详见 [[Token的计费方式以及如何更好的省Token]]。

---

## 5. 缓存带来什么好处

1. **快**：网页秒开、软件启动快、文件秒出——减少等待
2. **省**：少走网络、少传数据，节省流量和带宽
3. **稳**：降低服务器压力，高峰期也不容易崩（配合 CDN、Redis）

> ✅ **<span style="color:#2980b9">没有缓存的互联网是不可想象的：一次网页访问会涉及几十个请求，全靠缓存才"秒开"。</span>**

---

## 6. 缓存的代价与风险

缓存不是免费的，主要代价：

| 风险 | 说明 |
|------|------|
| **占用空间** | 缓存越积越多，吃硬盘、内存，需定期清理 |
| **脏数据 / 缓存不一致** | 源数据变了，缓存还是旧的 → 看到过期内容 |
| **首次访问慢（冷启动）** | 刚清完缓存或第一次访问，全部走慢路 |
| **缓存雪崩** | 大量缓存同时失效，请求全部打到数据库，系统被压垮 |
| **缓存击穿** | 某个热点 key 失效瞬间，大量请求同时打到数据库 |
| **缓存穿透** | 查询一个根本不存在的数据，每次都绕过缓存打到数据库 |

> ⚠️ **<span style="color:#e74c3c">缓存一致性是工程中最头疼的问题之一：既要快，又要保证用户看到的是"最新"数据。</span>**

---

## 7. 什么时候该清理缓存

出现以下"怪毛病"，优先考虑清缓存：

1. 网页打开报错、样式错乱、显示的还是旧版本
2. 软件界面异常、功能失效（如 Obsidian 插件异常）
3. 磁盘空间告急（手机提示"存储空间不足"）
4. 软件越来越卡、启动越来越慢
5. 网页或 App 内容更新后没变化（可能是旧缓存顶住了新数据）

> 💡 **<span style="color:#2980b9">清缓存是"保守的万能药"：多数情况下无害，代价只是牺牲一次"首次加载速度"。</span>**

---

## 8. 如何清理缓存

### 浏览器

- 设置 → 隐私 / 清除浏览数据 → 勾选"缓存的图片和文件" → 清除
- 快捷键：Chrome / Edge 用 `Ctrl + Shift + Delete`

### Windows

- 设置 → 系统 → 存储 → 临时文件 → 删除
- 或 `Win + R` 输入 `%temp%` 清空临时文件夹（谨慎操作，只删可删项）

### 手机 App

- 微信：我 → 设置 → 通用 → 存储空间 → 清理缓存
- 其他 App：设置 → 应用 → 找到对应 App → 存储 → 清除缓存

> 🛠️ **<span style="color:#e67e22">清理前先退出正在运行的程序；浏览器缓存清掉后，已保存的密码、书签、历史记录默认不会丢（按需勾选）。</span>**

---

## 9. 缓存、内存与临时文件的区别

| 概念 | 本质 | 是否可删 | 说明 |
|------|------|:-------:|------|
| **缓存（Cache）** | 数据的高速副本 | 可删（会自动重建） | 为提速而生 |
| **内存（RAM）** | 程序运行时的工作空间 | 重启即清 | 断电丢失 |
| **临时文件（Temp）** | 程序运行产生的中间文件 | 多数可删 | 可能残留 |

> 🔍 **<span style="color:#e67e22">一句话区分：缓存是"复制一份快的"，内存是"正在用的"，临时文件是"用剩下的"。</span>**

---

## 10. 常见误区

1. ❌ **"清缓存会删掉我的数据"** → 清缓存不会删聊天记录、收藏、账号数据，只会删"加速副本"
2. ❌ **"缓存越多电脑越快"** → 过量缓存反而占空间、拖慢系统，适度即可
3. ❌ **"内存越大就不用缓存"** → 缓存机制与内存大小无关，是架构层面的提速手段
4. ❌ **"清完缓存就一劳永逸"** → 清缓存后首次访问会变慢，缓存会随使用重新生成，属正常现象

> 📌 **<span style="color:#e67e22">遇到"莫名奇怪"的软件问题，先清缓存再重启——这是性价比最高的一招。</span>**

---

> [!tip] 一句话总结
> 缓存 = 用空间换时间的"加速副本"。它让电脑更快、更省、更稳，但也需要定期清理、注意数据一致性。看懂缓存，你就看懂了电脑为什么"快"。
