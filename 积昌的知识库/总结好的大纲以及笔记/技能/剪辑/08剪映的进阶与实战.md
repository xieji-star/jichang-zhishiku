## 二、核心概念：帧与帧率

### 2.1 什么是帧？

| 概念 | 定义 | 类比 |
|:----:|:----:|:----:|
| **帧（Frame）** | 记录画面信息的一张图片 | 类似于动画片中的每一张画 |
| **帧率（FPS）** | 一秒钟内播放多少张画面 | 每秒翻多少张画 |

### 2.2 常见帧率

| 帧率 | 用途 | 说明 |
|:----:|:----:|:----:|
| **24 FPS** | 电影/动画标准 | 影视行业最常见的帧率 |
| **23.976 FPS** | 日本动画专用帧率 | 日本动画行业特殊标准 |
| **30 FPS** | 通用标准 | 网络视频、日常拍摄常用 |

### 2.3 23.976 FPS 的注意事项

> 💡 23.976 FPS 是日本动画素材专用的帧率。如果你不做整部电影/动画的字幕，其实**不用纠结**。

| 场景 | 建议 |
|:----:|:----:|
| **日常剪辑** | 用 30 FPS 序列剪 23.976 FPS 素材没问题 |
| **整部电影/动画字幕** | 长时间的音画错位会导致口型对不上歌词，需匹配帧率 |

### 2.4 在剪映中观察帧

在剪映时间轴上放大到最大，可以一帧一帧地移动（从第 8 帧到第 9 帧到第 10 帧）。如果相邻帧的画面信息一样，画面不会动；如果包含的信息不一样，画面就开始动了。

## 三、关键帧

### 3.1 历史渊源

> 📌 **关键帧（Keyframe）是所有剪辑师都绕不开的进阶操作。**

关键帧的概念最早来自 **20 世纪迪士尼工作室的动画制作**：

| 时期 | 制作方式 |
|:----:|:--------:|
| **传统动画时代** | 首席动画师绘制角色的关键动作姿势（**关键帧**），助手在中间补充过渡画面（**中割**） |
| **21 世纪以后** | 中间画面的补充由**计算机自动完成** |

**图解理解：**
- 白色的三个人形 → 关键帧（首席动画师画的）
- 中间的绿色过渡 → 中割（以前是助手画的，现在是计算机算的）

### 3.2 在剪映中的操作

**核心原则：** 只需要设置**起始位置**和**最终位置**两个关键帧，计算机会自动补充中间的画面。

**操作步骤：**

1. **选中素材** → 右侧出现基础面板（位置、缩放、旋转等参数）
2. **添加起始关键帧** → 点击参数后面的**菱形图标**（空心菱形）
3. **移动时间指针** → 拖到目标位置
4. **修改参数** → 移动位置、调整角度、改变大小等
5. **自动生成** → 第二个关键帧自动生成，中间由计算机补充

> 💡 **每个菱形小标就是一个关键帧。**

### 3.3 查看和调整关键帧

**显示关键帧变速曲线：**
1. 右键已添加关键帧的素材
2. 点击 **"显示关键帧变速曲线"**
3. 可以看到动画的曲线变化
4. 在曲线面板中可以精细调整参数

**隐藏曲线：**
- 右键 → **"隐藏关键帧变速曲线"**

### 3.4 关键帧的通用规则

| 规则 | 说明 |
|:----:|:------|
| **任意参数皆可** | 只要参数后面有菱形图标，都可以做关键帧动画 |
| **同步进行** | 多个参数可以同时做关键帧动画（如位置 + 旋转一起动） |
| **依次进行** | 也可以等一个动画结束再做下一个 |
| **音频也可以** | 不只是画面参数，音频参数也可以打关键帧 |

## 四、关键帧四大应用场景

### 场景 1：位置变化

**效果：** 让素材从 A 点移动到 B 点

**操作：**
1. 在素材起始位置给**位置参数**添加关键帧
2. 指针移到结束位置
3. 修改位置的 X/Y 数值（或直接在画面上拖动）
4. 可结合旋转一起使用

### 场景 2：色彩变化

**效果：** 画面颜色随时间变化

**可调节的参数：**
- 色温、色调
- **饱和度**、**自然饱和度**
- **亮度**、**对比度**
- 所有明度相关参数

**示例一：白天 → 夕阳**
- 开头：正常色温 + 正常饱和度
- 结尾：色温调暖 + 饱和度调低
- 效果：模拟从白天到夕阳的过程

**示例二：彩色 → 灰白 / 灰白 → 彩色**
- 开头：饱和度正常
- 结尾：饱和度调为 0
- 氛围感拉满

> 💡 不管是哪一个颜色参数（色温、色调、饱和度、自然饱和度、亮度、对比度），都可以用关键帧动画进行更改。

### 场景 3：大小变化（缩放）

**效果：** 画面放大或缩小

**操作：**
1. 在**缩放参数**后添加关键帧
2. 到目标位置调整缩放数值
3. 可以配合位置移动一起使用

**示例：** 让观众更清楚地看画面中的某个细节 → 开头正常大小 → 结尾放大到指定区域

> 💡 缩放和位移可以同时进行，也可以依次进行。比如放大之后，再往下调整位置。

**可以做希区柯克变焦吗？**
> 当然可以！只需要两条素材，反着对一下关键帧就可以了。这节课还没有准备素材，之后有机会再讲。

### 场景 4：透明度变化（渐隐效果）

**效果：** 画面逐渐出现或逐渐消失

**操作：**
1. 在 **混合 → 不透明度** 后添加关键帧
2. **从无到有（渐入）：** 前面不透明度设为 0 → 后面设为 100
3. **从有到无（渐出）：** 前面设为 100 → 后面设为 0

> 💡 越朴实无华的转场越高级。一个简单的渐隐效果，放在电影里就是相当高级的转场。

**同一素材可以打多个关键帧：**
- 前面打两个（从无到有）
- 后面再打两个（从有到无）
- 中间段没有变化就没有问题

**应用场景：**
- 两个素材叠在一起时做转场
- 嵌套素材的过渡效果

## 五、实战案例一：进度条动画

### 5.1 效果说明

利用关键帧的位置变化，制作一个跟随视频进度移动的进度条动画。效果包括：
- 底部进度条从左侧移动到右侧
- 分段标记（用大写字母 I 做隔板）
- 章节名称
- 小飞机/图标跟随

### 5.2 制作步骤

#### 第一步：制作进度条底色

1. 在**贴纸**中搜索一个矢量图作为进度条底色
2. 拖动到时间轴上，拉到与视频一样长
3. 缩小到合适大小，拖到画面底部

#### 第二步：复制并换色

1. **按住 `Alt` + 鼠标左键**拖动素材 → 复制一层一模一样的
2. 给上面这层换个颜色（如从红黄色换成蓝色）
3. 建议：新建复合片段，方便操作（非必须）

#### 第三步：添加位置关键帧

1. 先移动到**视频最后**位置
2. 给上面那层的位置参数添加关键帧（保持当前位置）
3. 再回到**视频开头**
4. 将进度条拖到最左边

> 💡 **为什么先在最后打关键帧？** 省得先跑到开头做完，后面还要再去点一下——怎么方便怎么来。

#### 第四步：添加分段标记

1. 使用**文本工具**，输入大写字母 **`I`**
2. 调整大小 → 作为分段隔板
3. 复制多份，分别放到不同位置
4. 加上章节名称文本（如"开头""关键帧""抠像""蒙版"）

#### 第五步：装饰

1. 在贴纸库中找一个小飞机或小图标
2. 放在进度条开始位置
3. 给飞机也加上位置关键帧，跟随进度条移动

### 5.3 操作建议

> ⚠️ **推荐在具体参数面板中改参数**，而不是在画面上直接拖动素材。
>
> - 手动拖动容易出现误差
> - 素材量多时容易误触到其他素材
> - 养成好习惯，直接改参数更准确

## 六、抠像

剪映提供 **3 种抠像方式**：

### 6.1 智能抠像

| 项目 | 说明 |
|:----:|:----:|
| **操作** | 一键点击 → 自动识别画面中主体（特别是人物） |
| **调整** | 可调节羽化、边缘缩放 |
| **进阶** | 可配合自定义抠像增减区域 |

**操作步骤：**
1. 选中素材 → 点击"抠像"
2. 点击 **智能抠像**
3. 自动识别并抠出人物
4. 在羽化和边缘缩放中调整细节
5. 可以加描边效果

### 6.2 自定义抠像（画笔抠像）

| 项目 | 说明 |
|:----:|:----:|
| **适用场景** | 抠不规则物体（石头、山、非人物体等） |
| **操作** | 用智能画笔在要抠的区域划一下 |
| **工具** | 智能画笔 + 智能擦除 |

**操作步骤：**
1. 选择 **自定义抠像**
2. 用智能画笔在目标物体上划一下
3. AI 自动识别并处理
4. 点**应用效果**完成
5. 同样可以调节羽化、边缘缩放、描边

### 6.3 色度抠像（绿幕抠像）

| 项目 | 说明 |
|:----:|:----:|
| **适用场景** | 绿幕/蓝幕素材 |
| **操作** | 用取色器选取要扣除的颜色 |
| **调整** | 调节强度去除残留颜色 |

**操作步骤：**
1. 选择 **色度抠像**
2. 用**取色器**点击要扣除的颜色（如绿色）
3. 调整**强度**参数去除残留颜色
4. 可以在 B 站或 YouTube 下载绿幕素材使用

> ⚠️ 色度抠像效果可能有点粗糙（如绿色阴影残留），需要通过调节强度来精细处理。

## 七、实战案例二：人物介绍动画

### 7.1 效果说明

结合**关键帧 + 抠像**，做出一个人物定格 + 介绍的效果：
1. 人物摆了一个好看的 pose → 画面定格
2. 人物被抠出 → 背景模糊
3. 加上描边、笔刷装饰
4. 打出人物名称
5. 关键帧动画让元素动起来

### 7.2 制作步骤

#### 第一步：定格画面

1. 在素材中找到人物比较帅的一个动作（如撩头发）
2. 点击 **定格** → 自动生成 3 秒静态画面
3. 时间太长可以缩短

#### 第二步：抠像

1. 复制一层定格画面
2. 对上层做 **智能抠像** → 人物被抠出
3. 如果有遮挡（如头发），用自定义抠像删除或保留

#### 第三步：添加描边

1. 在贴纸中选择描边样式
2. 可选：折线、虚线、单层描边
3. 放在人物旁边作为装饰

#### 第四步：背景模糊

1. 在**特效**中搜索"模糊"
2. 放在下层画面和上层抠像之间
3. 模糊只影响下层
4. 调低模糊强度，达到合适的虚化效果

#### 第五步：笔刷装饰

1. 在贴纸中搜索笔刷
2. 放在最上层或下层（根据想要的伪 3D 错位感决定位置）

#### 第六步：添加文字

1. 打上人物名称（如"小红"）
2. 调整字体和颜色
3. 调整位置和旋转角度

#### 第七步：关键帧动画

1. 对定格画面添加**缩放 + 位移**关键帧
2. 开始位置放大 → 结束位置缩小到合适大小并移动到位
3. 对笔刷也添加缩放 + 位移动画
4. 对文字同样添加缩放 + 位移动画
5. 对齐各个元素的关键帧位置

#### 第八步：调整动画速度

- 如果动画太慢 → 将关键帧往前推
- 如果太快 → 往后拉
- 确保关键帧位置对齐，时间同步

> ⚠️ **再次提醒：** 尽量在参数面板中调整数值，不要在画面上拖动，避免误触其他素材。

## 八、蒙版

### 8.1 蒙版的本质

> 📌 **蒙版的唯一功能：保留想要的画面部分，去掉不想要的画面部分。**

蒙版**不是**把蒙版外的内容变成黑色，而是**把蒙版外的内容消去**。

### 8.2 基本操作

1. 选中素材 → 找到 **「蒙版」**
2. 选择形状（圆形、方形、爱心、圆角、饼干、镜面等）
3. 蒙版区域外的内容被消去
4. 可在下方放纯色/背景图填充空白区域

### 8.3 蒙版的应用场景

#### 应用 1：高亮提示

**效果：** 把画面中某个物体圈出来高亮显示

**操作：**
1. **复制一层**素材
2. 在上层用**圆形蒙版**框出想要高亮的物体（如一辆车）
3. 下层素材调低**不透明度**
4. 一个"光遮罩"效果就完成了

#### 应用 2：蒙版 + 关键帧

**蒙版也可以加关键帧！**

- 蒙版参数后面也有**关键帧的栏位**
- 可以在不同时间点调整蒙版的位置和大小

**跟踪功能：**
- 可以使用**跟踪**功能让蒙版自动跟随物体运动
- 但目前跟踪功能**还不够智能**，不够完美

**逐帧动画：**
- 更精细的方法是做逐帧动画（每一帧手动调整蒙版位置）
- 这是进阶课程的内容

#### 应用 3：蒙版的时间控制

> 如果不想整段素材都显示蒙版：
> **把素材裁切为两半** → 前半段加蒙版，后半段关闭蒙版即可

## 九、实战案例三：裸眼 3D 效果

### 9.1 效果说明

结合**抠像 + 蒙版 + 关键帧**三种功能，做出物体冲出屏幕的视觉效果。这是本节课的"组合拳"案例。

### 9.2 原理

利用视觉错位——让抠出的物体看起来"冲破"了画面边框的限制。

### 9.3 制作步骤

#### 第一步：抠像

1. 在素材中找到物体要冲出画面的关键帧位置
2. **复制一层**素材
3. 对上层做**智能抠像** → 将物体（如一条龙）抠出
4. 如果有未抠好的细节（如翅膀），用自定义抠像追加
5. 点**应用效果**完成

#### 第二步：蒙版关键帧动画

1. 在原始画面上添加**镜面蒙版**
2. 在物体冲出之前：蒙版覆盖画面边缘（遮住边框）
3. 在物体冲出的瞬间：将蒙版拉开/下移 → 露出抠出的物体

#### 第三步：叠层

图层顺序（从下到上）：
| 层级 | 内容 | 作用 |
|:----:|:----:|:----:|
| **最下层** | 原始画面 | 正常播放的背景 |
| **中间层** | 加了蒙版的画面 | 制造"边框"效果 |
| **最上层** | 抠出的物体 | 看起来冲出屏幕 |

### 9.4 效果优化

- 同样的原理可以做多层嵌套
- 多做多叠，可以做出更丰富的效果
- 和第五节课讲的"四路抠像给人物做文字背景"是同样的道理——做一个**伪 3D 叠层效果**

### 9.5 老师说

> 这种裸眼 3D 效果，下次你可以做一个把甄嬛抠出来的动画交上来。当然，这其实是一个很简单的关键帧动画，上了进阶课程之后，做这种动画跟喝水一样简单。

## 十、关键帧曲线与缓入缓出

### 10.1 当前的问题

目前打的关键帧都是**匀速**的——物体从开始到结束速度完全一样。这样的动画看起来比较生硬。

### 10.2 解决方案

**关键帧动画曲线（缓入缓出）：**

1. 选中两个关键帧
2. 调整曲线参数：
   - **缓入（Ease In）**：开始慢，逐渐加速
   - **缓出（Ease Out）**：开始快，逐渐减速
3. 效果：运动更加**自然**，不会有机械感

> 📌 **这是进阶课程的内容。** 这节课只是先提一下，进阶课程会详细教大家怎么做关键帧曲线。

### 10.3 细化的思路

> 所谓"细化"，就是往效果上再加更多的效果。但注意：效果不要特别夸张，主要起到**辅助功能**。

可以细化的方向：
- 加上下黑边 → 电影镜头感
- 给人物加拖影、光效
- 文字做生长动画
- 笔触做从无到有的效果

## 十一、课程答疑精选

> [!QUESTION] ❓ 蒙版可以调整放置的时间吗？
> **老师回答：** 可以！把素材裁切成两半 → 前半段加蒙版，后半段关闭蒙版即可。

> [!QUESTION] ❓ 画质太粗糙怎么办？
> **老师回答：** 去下载高清素材源。之前给过大家一个 B 站视频下载工具，可以下载高清片源。后面也会给大家讲在哪下载高清的片源（比如 8K 蓝光原盘）。

> [!QUESTION] ❓ 剪映好学还是 PR 好学？
> **老师回答：** 道理都是互通的。学会剪映后，PR 很多操作都是一样的逻辑。PR 可以做到更精细的操作。

> [!QUESTION] ❓ PS 被删除了怎么办？
> **老师回答：** 周五 PS 课前重新下载即可。PS 不太占硬盘空间，但它的虚拟内存会有 8~10GB。

> [!QUESTION] ❓ 在画面里直接拖素材行不行？
> **老师回答：** 可以在画面里拖动素材打关键帧，但是**不推荐**。因为手动拖动的精细度不够，容易出现误差。等素材量叠多了之后，还容易误触到其他素材。建议养成好习惯，直接在参数面板里改数值。

> [!QUESTION] ❓ 能做希区柯克变焦吗？
> **老师回答：** 当然可以！只需要两条素材，反着对一下关键帧就可以了。这节课还没准备素材，之后有机会再讲。

> [!QUESTION] ❓ 为什么我的 PR 打开后界面不一样？
> **老师回答：** 有些时候打开 PR 会遇到不同界面，可以点左上角 **"编辑"** 回到正常界面。

> [!QUESTION] ❓ 同一段素材上可以打几个关键帧？
> **老师回答：** 可以打很多个！前面打两个，后面打两个，完全没问题。只要头和尾中间的关键帧之间没有变化，这段素材就没有问题。

> [!QUESTION] ❓ 有没有赚到过钱的案例可以分享？
> **老师回答：** 这个会在进阶课程里讲，现在讲太难了。

> [!QUESTION] ❓ 作业什么时候交？
> **老师回答：** 给大家两天时间（明天和后天），在自己运营的自媒体账号视频中运用这节学到的知识。交上来之后，老师会给出个人提升建议。等攒够一批作业，大家一起分析。

> [!QUESTION] ❓ 课程到什么时候结束？
> **老师回答：** 现在只是基础课程，后面还有进阶课程（关键帧进阶、嵌套、抠像超级键、颜色更改、预设等）。

## 十二、课程总结与作业

### 核心要点回顾

```
关键帧（位置/颜色/大小/透明度）
    + 抠像（智能/自定义/色度）
        + 蒙版（高亮/跟踪/遮罩）
            = 裸眼 3D 效果
```

| 技术 | 核心要点 |
|:----:|:--------:|
| **关键帧** | 设置起始和结束两个状态，计算机自动补中间 |
| **四大场景** | 位置变化、色彩变化、大小变化、透明度变化 |
| **抠像** | 3 种方式：智能、自定义、色度 |
| **蒙版** | 唯一功能：保留想要的部分，去掉不想要的部分 |
| **组合拳** | 关键帧 + 抠像 + 蒙版 = 裸眼 3D |

### 作业

> 接下来两天（明天和后天），在自己运营的自媒体账号视频中运用课堂学到的知识：

- [ ] **关键帧动画**（位置、颜色、缩放、透明度）
- [ ] **抠像**（智能抠像/自定义抠像/色度抠像）
- [ ] **蒙版**（高亮提示/跟踪/遮罩）
- [ ] **组合效果**（人物介绍动画/裸眼 3D）

> 交上作业后，老师会给出个人提升建议。
