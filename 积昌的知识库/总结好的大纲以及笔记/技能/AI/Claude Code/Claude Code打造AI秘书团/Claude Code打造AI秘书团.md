## 一、Claude Code 的定位——不只是编程工具

### 1.1 什么是 Claude Code

- **Claude Code**（简称 **CC**）是 Anthropic 于 2025 年 5 月正式发布的**终端编程代理**
- 长相"原始"（命令行界面），但非常强大
- 在编程领域是当前最顶级的 AI 编程助手之一，据称 Alphabet 内部 70% 的代码都用它编写

### 1.2 比编程更大的格局

课程的核心理念：**Claude Code 的潜在用法是作为你的思维陪练 / AI 秘书团**，团队的法务、营销等非技术岗位也都在用它。

### 1.3 CC 与普通 AI 的区别（赛博小区类比）

| 类型 | 类比 | 特点 |
|------|------|------|
| **网页聊天 AI** | 小区问询处机器人 | 没有手没有脚，不认识你，只能回答问题 |
| **打包 AI 产品** | 前台小姐姐机器人 | 不认识你，但能打电话、敲电脑做有限操作 |
| **Claude Code** | **贴身秘书机器人** | ① 了解你的全部资料、习惯、偏好，随时调用 ② 工具箱无限——自带工具 + MCP 外挂工具 ③ **能带团队**——大秘书可根据需求生成不同特长的子秘书（子代理 Sub-agent） |

## 二、安装与基础配置

### 2.1 准备工作：安装 Agent IDE

推荐使用 **Cursor**（或其他 Agent IDE 如 Windsurf、Trae），下载安装后打开，确保为 **Agent 模式**。

> [!TIP]
> 整个安装过程可以通过在 Cursor 中向 AI 提问来完成，无需手动操作。只需把 Claude Code 官方文档说明发给 Cursor，说"帮我安装一个 Claude Code"即可。

### 2.2 安装 Claude Code

#### 方式一：命令行安装

```powershell
# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
```

#### 方式二：winget 安装

```powershell
winget install Anthropic.ClaudeCode
```

#### 方式三：让 Cursor 帮你装

在 Cursor Agent 中直接说"帮我安装 Claude Code"，Cursor 会自动下载安装 Node.js 等依赖。

### 2.3 配置大模型（国内用户）

由于大部分国内用户无法直接使用 Claude 原生模型，需要**替换为国产大模型**：

1. 前往**智谱 AI**（或其他 API 平台如 DeepSeek、Minimax）获取 API Key
2. 使用 **CC Switch** 工具配置多模型切换
3. 或者在终端中设置 API Key 环境变量

```bash
# 示例：配置 API Key（以智谱为例）
export API_KEY="your_api_key_here"
```

> [!NOTE]
> 其他模型（如 DeepSeek、Minimax 等）的替换方式类似，文稿评论区有详细方案。

### 2.4 启动 Claude Code

```bash
# 进入项目目录后启动
claude
```

首次启动会：
1. 选择主题颜色
2. 进行基础设置
3. 进入主界面

#### 跳过权限确认（效率模式）

默认情况下 CC 执行每个操作前都会征求同意。如需跳过：

```bash
claude --dangerously-skip-permissions
```

> [!WARNING]
> 开启此模式后 AI 不会征求你的同意直接执行操作，请确保在相对安全的环境中使用，不要在存放重要资料的项目中开启。

## 三、熟悉 Claude Code 环境

### 3.1 核心斜杠命令

在 CC 中输入 `/` 即可看到所有命令。输入 `/help` 可查看完整命令列表。

| 命令 | 作用 |
|------|------|
| `/help` | 显示所有指令 |
| `/init` | 初始化项目，生成 CLAUDE.md |
| `/compact` | 压缩聊天上下文（当上下文占用 >60% 时使用） |
| `/clear` | 清空上下文，重开会话 |
| `/cost` | 查看上下文占比 |
| `/context` | 详细展示上下文占用情况 |
| `/model` | 切换模型 |
| `/plan` | 开启计划模式 |
| `/simplify` | 派生 3 个 agent 进行代码审核 |
| `/resume` | 恢复历史对话 |
| `/memory` | 管理记忆 |
| `/agents` | 管理子 Agent |
| `/btw` | 临时问与项目无关的问题（与上下文隔离） |

### 3.2 上下文管理

#### 监控上下文

- `/cost`：查看上下文占比，超过 60% 时 CC 会变"笨"
- `/context`：详细展示各模块占用情况

可配置**常驻状态栏**显示上下文进度条（让 CC 帮你配置）：

> 帮我配一个 statusLine，显示当前目录 + 模型 + 上下文剩余百分比

配置后需重启终端生效。

#### 管理流程

1. 上下文到达 60% → 执行 `/compact` 压缩
2. 或 `/clear` 彻底清空，重开会话
3. 新对话用 `/resume` 恢复之前的上下文

#### 压缩聊天记录（/compact）的原理

相当于让当前工作的 AI 生成一份"工作总结"和"交接文档"，交给下一个秘书继续工作。

### 3.3 对话管理

| 操作 | 方式 |
|------|------|
| 中断任务（保留上下文） | 单按 ESC |
| 退出 CC（丢失上下文） | 双按 ESC / 连续两次 Ctrl+C |
| 新开对话 | 点击 + 号新建会话，或退出后重新 `claude` |
| 恢复历史对话 | `claude --resume` 或进入后 `/resume` |
| 跟随上次对话继续 | `claude -c` |

### 3.4 /btw 临时提问

当前项目中突然想到与项目无关的问题时使用：

```
/btw 最近 Claude Code 有什么新命令吗？
```

按 ESC 退出后自动移除，不影响主上下文。

## 四、设计秘书团架构

### 4.1 创建构想文档

在项目中新建构想文件（如 `构想.md`），写下每个秘书的职责设定。

### 4.2 秘书团成员一览

| 秘书 | 角色 | 职责 |
|------|------|------|
| **新闻球** | 信息助理 | 每天早上主动搜刮最新 AI 新闻，总结后写入文档并推送飞书 |
| **穿搭球** | 形象顾问 | 询问今天场合 → 查天气 → 给出穿搭建议 + 生成参考图 |
| **教练球** | 健康管理 | 催报体重 → 记录健康数据 → 结合瘦身目标推荐运动和饮食 |
| **日报球** | 日程规划 | 问今天安排 → 规划日程早报 → 发工作群 |
| **反思球** | 成长导师 | 晚上收工时，根据当天发生的事和横向维度引导反思和复盘 |

### 4.3 让 CC 帮助完善团队设计

选中构想文档内容，对 CC 说：

> 我想设置几个 Sub-agent，这个文件里是我的想法。你能帮我完善一下，并列出需要哪些上下文文件夹、哪些 MCP 工具吗？

CC 会自动生成：
- 各秘书的详细设定
- 需要的 MCP 工具清单
- 文件夹结构建议
- 个人信息模板

### 4.4 个人信息模板

CC 会生成一个个人信息文档，你需要填写：
- 年龄
- 个人背景信息
- 偏好（穿搭风格、饮食喜好、运动习惯等）
- 健康目标

这样秘书团就能基于你的实际情况提供个性化服务。

## 五、配置 MCP 工具

### 5.1 MCP 工具超市：Smithery

**[Smithery.ai](https://smithery.ai)** 是 MCP 工具市场，可在此搜索和安装各种 MCP 工具。

### 5.2 各秘书需要的 MCP 工具

| 秘书 | 推荐 MCP 工具 |
|------|-------------|
| 新闻球 | Firecrawl（搜索 + 爬取），或 RSS MCP |
| 穿搭球 | 即梦 (Jimeng) MCP（生成穿搭参考图），天气 MCP |
| 教练球 |（健康数据记录，无需特殊 MCP） |
| 日报球 | 飞书 MCP（推送工作群） |
| 反思球 |（无需特殊 MCP） |

### 5.3 配置示例：即梦 (Jimeng) MCP

即梦是字节跳动的 AI 图片生成平台，用于生成穿搭参考图。

**配置步骤：**

1. 在 Smithery 搜索 "Jimeng" 或 "即梦"
2. 选择适合 Claude Code 的安装方式
3. 获取 Session ID：
   - 登录即梦官网
   - 右键 → 检查 → Application → Cookies
   - 找到 Session ID 并复制
4. 将 Session ID 填入配置命令

```bash
# 示例命令（实际命令以 Smithery 生成为准）
npx @smithery/cli install @jimeng/mcp --key "your_session_id"
```

> [!NOTE]
> 即梦的配置比其他 MCP 稍复杂，因为需要手动从浏览器获取 Session ID。

### 5.4 配置飞书 MCP

飞书 MCP 涉及较多权限配置，具体步骤：

1. 飞书开发后台 → 创建应用 → 获取凭证
2. 飞书官方文档有问答 AI，可直接询问"飞书的 MCP 怎么接"
3. 将飞书的配置命令适配到 Claude Code 格式：

```bash
# 格式示例（将 APP ID 和 APP Secret 替换为自己的）
claude mcp add feishu --type command --command "npx" --args "@feishu/mcp-server" --env "APP_ID=xxx" --env "APP_SECRET=xxx"
```

> [!TIP]
> 探索复杂 MCP 配置的技巧：利用官方文档的问答 AI（如飞书开发后台的 AI 助手），或使用豆包、Kimi 等插件的侧边栏询问。对于配置格式问题，直接问"我想在 Claude Code 里添加这个 MCP 命令应该怎么写"。

### 5.5 其他 MCP 工具

- **天气 MCP**：获取天气预报
- **Firecrawl MCP**：网页搜索和内容爬取
- 以上均可在 Smithery 搜索找到，配置逻辑相同

### 5.6 验证 MCP 配置

```bash
claude mcp list
```

检查是否所有 MCP 都显示 **connected** 状态。

## 六、创建子 Agent 秘书

### 6.1 创建总秘书（主 Agent）

```bash
# 进入 Claude Code 对话
claude

# 进入 Agent 管理模式
/agents
```

选择 **Create Agent**：
1. 选择使用范围：**项目级**（本项目可用）或全局
2. 描述 Agent 职责：用一句话描述（如"新闻球：每天早上主动搜索 AI 新闻并整理成文档"）
3. 配置工具权限：空格取消/选中可用工具
4. 选择模型：默认即可
5. 挑选颜色：方便在对话中区分不同秘书

### 6.2 子 Agent 的存储位置

```
项目目录/.claude/agents/
```

每个子 Agent 包含：
- **提示词（Prompt）**：定义了何时调用该 Agent、它的职责
- **工具权限**：该 Agent 可以调用哪些工具
- **模型选择**：使用的模型
- **颜色标识**

创建完成后可以手动编辑 `.claude/agents/` 下的文件来修改提示词。

### 6.3 重复创建其他秘书

按照相同流程，依次创建：
1. 穿搭球
2. 教练球
3. 日报球
4. 反思球

### 6.4 初始化秘书团规章制度

全员创建完成后，执行：

```bash
/init
```

这会基于当前项目所有文件和配置生成 **CLAUDE.md**——相当于秘书团的"规章制度"。以后所有秘书的行动都需遵循此文档。

CLAUDE.md 会包含：
- 项目结构概述
- 秘书团成员介绍
- 各个文件夹的用途
- 工作原则（如使用中文）

> [!NOTE]
> CLAUDE.md 可以手动修改，使其更符合你的个人需求。

## 七、秘书团日常工作流

### 7.1 早晨：新闻简报

对 CC 说"早上好" → CC 自动召唤 **新闻球**：

1. 搜索全网最新 AI 新闻
2. 总结并写入文档
3. 推送至飞书
4. 生成每日记录文章

### 7.2 上午：穿搭建议

新闻球完成后，**穿搭球**上场：

1. 询问今天要去什么场合（如"白天公司开会，晚上正式晚宴"）
2. 查询当地天气
3. 给出穿搭建议文档（含服装搭配、面料选择等）
4. 调用即梦 MCP 生成穿搭参考图

#### 案例：穿搭球给出的建议

> - **日间会议**：雪纺衬衫 + 黑色阔腿裤 + 西装外套
> - **晚间晚宴**：换配饰和高跟鞋，增加正式感
> - **包含**：参考照片（按用户形象生成）

### 7.3 白天：日程规划

**日报球**上场：

1. 询问今天的工作安排
2. 帮助你理清思路，倒逼你整理待办事项
3. 生成日程早报
4. 发工作群

#### 案例：用户给出的安排

> - 会议主题：线下展会方案选定，预计 2 小时
> - 晚间：与领导见面，参加新品发布会，目标拉近关系
> - 其他：收集发票、复盘上一个项目
> - 期待：完美执行

#### 日报球返回的成果

- 会议准备工作（关键决策点、注意事项）
- 晚宴攻略（提前准备什么、重点聊什么）
- 自我检测清单
- 金句："完美不是偶然，是充分准备和专业执行的必然结果"

### 7.4 全天：健康管理

**教练球**在适当时机上场：

1. 询问体重和身体状况
2. 记录健康数据
3. 结合历史数据（如之前提到的脖子酸痛）做跟进
4. 推荐运动方案和饮食建议

#### 案例：教练球的回应

> - 记录体重变化（如轻了 0.95kg）
> - 紧急消肿方案（针对"左眼肿了"的问题）
> - 饮食建议：社交场合少食多交流
> - 推荐今日运动

### 7.5 晚上：反思复盘

**反思球**在收工时上场：

1. 回顾当天发生的事情
2. 结合横向各种维度
3. 引导你进行深度思考和复盘

> [!QUESTION] 修正存疑
> 原文中"反思球"的部分描述较为模糊，原文为"根据今天发生的事儿和横向的各种文法来引导我反思和复盘"，其中的"文法"可能为"维度"或"方面"的识别错误，请确认。

## 八、进阶技巧

### 8.1 Cursor 辅助翻译和解释

在 Cursor 中使用 CC 时，看不懂的英文可以直接圈选并让 Cursor 翻译解释。

### 8.2 查看命令帮助

```bash
# 在 CC 中输入
/help
```

也可以将这些命令圈起来让 Cursor 翻译成中文版本，生成一份命令说明书。

### 8.3 上下文余量管理

- 上下文占比 >60% 时需要压缩
- 日常使用 `/cost` 监控上下文
- 可使用常驻状态栏实时监控

### 8.4 Memory 记忆系统

```
项目目录/.claude/memory/memory.md
```

- **启用 Auto Memory**：`/memory` → 选择 Auto-memory
- CC 会记住你的偏好和习惯
- 可说"忘掉刚才说的 XXX"来删除特定记忆
- 即使换了新电脑，只要有记忆文件，CC 还是那个熟悉你的 CC

### 8.5 CLAUDE.md 的作用

CLAUDE.md 相当于整个项目的"规章制度"：
- 定义项目目标和结构
- 规定秘书团成员职责
- 设定工作原则和语言偏好
- 秘书团所有行动都必须遵循

## 九、总结

### 核心收获

| 阶段 | 内容 |
|------|------|
| **① 认知升级** | Claude Code 不只是编程工具，更是可组建 AI 秘书团的"贴身秘书" |
| **② 安装配置** | 通过 Cursor 等 IDE 安装 CC，配置国产大模型 API，三步搞定 |
| **③ 团队设计** | 构想 → 完善 → 配置 MCP → 创建子 Agent → 初始化 CLAUDE.md |
| **④ 日常工作流** | 新闻 → 穿搭 → 日程 → 健康 → 反思，全自动串联 |
| **⑤ 持续优化** | 上下文管理、记忆系统、CLAUDE.md 迭代，越用越懂你 |

### 核心理念

- 掌握了这个方法，就掌握了 **"无限放秘书"的女娲技巧**——可以创建任何你需要的 AI 助手
- 从"自己动手做"到"让 AI 团队帮你做"，实现真正的效率飞跃
- Claude Code 的 **Sub-agent（子代理）** 功能是其最被低估的用法
