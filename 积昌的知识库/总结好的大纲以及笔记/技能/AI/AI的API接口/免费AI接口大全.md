## 1. 开场：免费 Token 怎么找、怎么分梯队

### 1.1 背景：不是没有免费 Token，是不知道去哪找

- 直到今天，很多人都还停留在使用**豆包这类免费聊天机器人**
- 他们不用 AI 的原因：觉得 Token（大模型计费单位，详见 [[Token的计费方式以及如何更好的省Token]]）太贵，实在舍不得
- 实际情况：🔥 **<span style="color:#e74c3c">市场上从来不缺免费 Token，只是大家不知道怎么找到它们</span>**
- 本期把市面上叫得上号的免费渠道都试了一遍，分享哪些长期稳定、靠谱

### 1.2 分类规则：三个梯队

1. 🥇 **第一梯队**：能当主力用的——长期靠得住
2. 🥈 **第二梯队**：凑合当备用的——轻度使用
3. 🥉 **第三梯队**：得自己折腾的——部署能用，但别把核心需求指望它们

> 各位研究员按需配置即可。

## 2. 第一梯队：能当主力长期用

三家共同点：🔥 **<span style="color:#e74c3c">不搞限时那一套，要么按请求频率限制，要么每天给一笔固定额度——规则摆得明明白白，只要不玩命刷就能一直稳定地用下去。</span>**

### 2.1 英伟达 NIM 模型库：额度最大

- 📊 **<span style="color:#e67e22">100 多款模型随便挑，用的是 OpenAI 兼容格式</span>**（OpenAI 兼容格式：接口调用方式与 OpenAI API 一致，各家工具可直接接入）
- 多数支持直接调用
- 限制方式：按每分钟 40 次的请求频率来限制日常使用——根本到不了上限

### 2.2 Cloudflare Workers AI：每日固定额度、永久免费

- 📊 **<span style="color:#e67e22">每天给 1 万个 Neons 免费额度</span>**（Neons：Cloudflare 自创的 AI 推理计价单位，即 Neural Units 神经单元）
- 这额度是**永久免费**的
- 覆盖 50 多个模型，文字、画图、语音类的任务都能接

### 2.3 魔塔社区：实名认证即可调用

- 每天 2000 字左右的免费调用（魔塔社区：ModelScope，阿里系的模型社区平台），**实名认证后就能调用**
- 不过每个模型还有独立的单日限额：📊 **<span style="color:#e67e22">单模型最高不超过 200 次</span>**
- 像用来跑 Qwen3（通义千问 3，阿里开源大模型）也会受到这个限制

## 3. 第二梯队：备用与轻度使用

这一类同样**不限时**，但多少有点天花板：要么额度不大，要么高峰期体验打折——**当备用、轻度使用最合适**。

### 3.1 Trae：字节的 AI 编程助手

- 字节跳动旗下的一款 AI 编程助手（Trae，AI 集成开发环境），国内几款旗舰级模型都能免费用
- ⚠️ **<span style="color:#e74c3c">短板：高峰时段得排队，动不动就是几千位</span>**——建议大家错峰使用

### 3.2 OpenRouter：free 模型直接调用

- OpenRouter（第三方模型路由平台）上有 free 的模型，可直接调用
- 挑一个生成 API Key（接口调用密钥），支持 OpenAI 式调用（这类 OpenAI 兼容接口可接入 Codex 等 AI 编程工具使用，方法见 [[Codex模型配置方法大全]]）
- 📊 **<span style="color:#e67e22">额度：不充值每天 50 次；充 10 美金能提到 1000 次；调用免费模型不扣钱</span>**

### 3.3 硅基流动：免费档覆盖广

- 硅基流动（SiliconFlow，国内 AI 算力平台）的免费档覆盖挺广
- 💡 **<span style="color:#2980b9">从小尺寸模型到 DeepSeek R1（深度求索的推理大模型）这种旗舰大模型，都有免费额度</span>**
- 支持 OpenAI 兼容，开箱即用
- 短板：每天免费调用次数有限，适合轻度使用
- 📎 接入 Claude Code 的完整配置见 [[硅基流动免费API接入Claude Code配置指南]]

### 3.4 Hugging Face：价值在托管，API 只是附带

- Hugging Face（全球最大的开源模型托管平台）也开放免费推理 API
- ⚠️ **<span style="color:#e74c3c">免费额度偏紧，高峰时段排队报错是常事儿</span>**
- 它真正的价值在**模型托管本身**，免费 API 只是附带
- 这一梯队已经是"顶一下还行"，当主力差点意思

## 4. 第三梯队：自己折腾能用，别指望核心需求

这一类要么**限时**，要么**限额不透明**，要么**得自己折腾**。部署能用，但别把核心需求指望它们。

### 4.1 OpenCode：开源 AI Agent

- 它本身是个开源 AI Agent（智能体，可自主完成编程等任务），代码在 GitHub 开源
- 进入界面后，在聊天栏输入斜杠命令 `/models` 能拉出模型列表，**带 free 标识的都能用**
- 问题：和 Trae 差不多，人多的时候速度明显下降；限额规则也不透明

### 4.2 MiMo Code：基于 OpenCode 改造，免费限时

- 它就是在 OpenCode 的基础上改的，不过把内置模型换成了**小米自家的 MiMo V2.5**（小米自研大模型）
- 上下文窗口开到 100 万 Token，装完即用
- ⚠️ **<span style="color:#e74c3c">它的免费是限时的：眼下额度很大方、响应也正常，但没有公布截止时间——趁现在还能用先用上，能用一天算一天</span>**

### 4.3 Free AI API：聚合免费额度的开源项目

- GitHub 上的开源项目，思路比较特别：**把 10 多家平台的免费额度聚合成一个 OpenAI 接口**
- 本地用 Docker（容器化部署工具）部署一个代理服务，就能在后台统一调度
- 💡 **<span style="color:#2980b9">带智能路由和自动故障切换，会自动帮你切到可用的模型</span>**
- 短板：聚合来的模型质量参差不齐，偶尔会抽到能力很弱的
- 不过好在后台能勾选启用哪些项目
- 标注：⚠️ **<span style="color:#e74c3c">仅供个人实验，爱折腾的话拿来玩挺合适的</span>**
