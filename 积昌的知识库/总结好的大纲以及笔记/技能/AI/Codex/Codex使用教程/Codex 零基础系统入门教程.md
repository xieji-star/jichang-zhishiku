## Codex 与 Claude Code 对比

在正式开始之前，先搞清楚 Codex 和 Claude Code（CC）的区别：

| 对比维度 | Codex | Claude Code |
|---------|-------|-------------|
| 背后公司 | OpenAI | Anthropic |
| 默认模型 | GPT 系列 | Claude 模型（但可自行替换） |
| 目标用户 | 零基础、白领工作者 | 偏向专业开发者 |
| 桌面端 | 仅支持 OpenAI GPT 模型 | 支持替换任意模型 |
| 功能丰富度 | 浏览器操控、Computer Use、内置 DALL-E 生图模型 | 最早支持 slash 命令和远程操控 |
| 手机控制 | ✅ 已发布手机端，可用手机 ChatGPT 控制电脑 | ❌ |
| 会员额度 | 20美元/月会员就很够用，且不易封号 | 官方账号大多需自行调用API，花多少用多少 |

> 📌 **结论：** 入门用户用 Codex 就很强了，有条件的用户两个都配齐最完美。两者的逻辑其实是一样的，学一个另一个也就会了。

## 安装与基本设置

### 准备工作

- **唯一需要准备的就是一个 ChatGPT 账号**（免费的也行，只是额度稍微少一些）

## 能力一：本地文件操作

这是 Codex 这类桌面端 Agent 跟对话式 AI（如 ChatGPT）最显著的区别和能力。

### 对比 ChatGPT

过去要让 AI 看到本地内容，只有两种方式：
1. **复制粘贴** 到对话里
2. 以允许的格式和数量 **上传文件**

但 **Codex 可以自主读取和操作本地文件，而且不限数量**。

### 项目（Project）机制

在 Codex 界面中点击"项目"→ 选择本地文件夹 → 该文件夹就成为项目目录，里面所有文件 Codex 都可以自由读取和操作（当然需要用户授权）。

### 三种权限模式

| 权限模式 | 说明 |
|---------|------|
| **默认权限** | 在当前文件夹内自由读写文件；如需联网、下载东西或碰文件夹外的文件，需要向用户请求提高权限 |
| **自动审查** ⭐（推荐） | 由 AI 自动判断操作是否危险，危险才来问用户。比默认模式更宽松和智能 |
| **完全访问** | Codex 可以在电脑上几乎什么都能干（修改删除任何文件、在任何位置执行命令） |

> 💡 **新手建议选择"自动审查"模式**，相信 AI 就完了。

### 实战案例：视频素材重命名

**场景：** 本地有 80 多条视频素材，命名全是乱的，想按实际画面内容来重新命名。

**操作：**
1. 选择视频文件夹作为项目
2. 告诉 Codex：「帮我把这个文件夹里的所有视频素材都按他们的实际画面来重新命名」
3. Codex 会自动抽帧、提取关键画面来判断内容
4. 它还知道拼成缩略图形式一组组地看，非常聪明

**结果：** 文件名全部改变，遵循「序号-任务-场景-行动」的清晰命名格式。例如：
- ✅ `01-钢琴家-音乐演奏厅.mp4`
- ✅ `02-雪山-近身格斗.mp4`
- ✅ `03-旗袍女人-卖热饮.mp4`

> 📌 AI 做事的细心程度，人类你不服不行。

### 同一项目多对话

可以在同一个项目里开多个不同的对话，上下文各不相同，但都能随时访问项目中的文件。例如另一条对话中，让 Codex「把所有关于风景的视频都剪成一整条」，它真的能用 FFmpeg 拼接在一起。

### 上下文管理

- 对话窗口中的小圆圈显示当前对话使用了多少上下文窗口
- 鼠标悬停可查看更详细信息
- 当上下文快满时，Codex 会自动压缩
- 也可以手动输入 `/压缩` 命令来手动压缩，让模型更聚焦在新任务上

### 额度查看

两种方式查看剩余额度：
1. **设置 → 剩余额度**：查看 5 小时内和本周内的剩余额度，以及刷新时间提示
2. **对话框输入 `/` → 选择「状态」**：持续显示上下文余量

> 📌 Codex 的额度非常大方，20 美元/月的额度可以满足大多数白领工作的高频使用。

### 模型选择

- **速度快**：相当于是加急通道，会消耗更多额度
- **模型切换**：可以选择其他模型（但推荐用最新版 GPT）
- **智能程度**：一般中度智能就够了
- **语音输入**：小麦克风按钮，比手打字快很多

## 能力二：命令行工具使用

Codex 的第二大能力是在用户授权的情况下使用终端来替我们做事。

### 第一类：安装常用依赖

比如 Node.js 等开发工具。之前要装这些都得看手把手教程照着命令抄，现在直接跟 Codex 说「帮我安装个 Node.js」，在自动审核权限下它基本不问就直接装好了。

### 第二类：安装爆火的新 AI 工具

例如 Hermes（一个 AI Agent），不需要给官网链接，直接说「最近有一个叫 Hermes 的 Agent 很火，你帮我安装一个吧」，它会自己去搜索、判断是哪个，然后根据官方文档装好并验证。

> 💡 有了 Codex 以后，那些复杂的要收你 599 的教程步骤，你都可以直接让 Codex 帮你做——**怒省 599**。

而且在使用过程中遇到任何问题还可以截图去问 Codex，出了 bug、升级出了问题都可以让 Codex 直接帮你修。

### 第三类：安装软件应用

类似 Cursor 这种软件应用，平时需要手动在网页上下载，Codex 也可以帮你下载和卸载。

> 💡 建议同时下载一个 **AI IDE（编辑器）**，因为 Codex 目前有个缺点是无法直接手动编辑文件内容。安装 IDE 后可以在右上角随时把项目在编辑器中打开进行手动编辑。

### 第四类：安装 Skill 和 MCP

Codex 本身就支持 Skill 和 MCP，这部分后面会详细讲到。

- **安装 Skill**：把具体仓库或官网链接拷贝给 Codex，跟它说「帮我装一下这个 Skill」
- **安装飞书 CLI**：也非常典型，装好后 Codex 就能帮我们操作飞书的各种功能（写文档、发消息、建日历、做表格等）

### 并行任务处理

Codex 支持并行任务——可以在它做一件事的时候再开一个对话，让它去下载别的。界面中会显示每个任务的处理状态：
- 🔄 **正在转**：执行中
- 🔵 **蓝色点**：已完成
- ⚠️ **需要申请权限**的标识

## 能力三：持久记忆系统

Claude Code 有手动的持久记忆（CLAUDE.md）和自动记忆系统。Codex 也是类似的，也有两套持久的记忆系统。

### 手动持久记忆：agent.md

**全局级 agent.md（自定义指令）：**
- 位置：**设置 → 个性化 → 自定义指令**
- 作用：在任何项目跟 Codex 对话时，都会第一时间作为上下文发给大模型
- 适合：适用于所有任务的大原则（工作习惯、要说中文、修改文档要留修订痕迹等）

**更推荐的方式：直接在对话中告诉 Codex**

例如：「我希望你以后对飞书文档里的任何修改都使用专属的文字颜色和删除线的方式来修改，不要直接修改，然后帮我记到全局的 agent.md 里。」

Codex 会帮你写好在个性化设置中，下次使用就会自动遵循。

> [!TIP] 📎 案例效果
> 让 Codex 根据侧边评论修改飞书文档 → 它果然用了紫色字和删除线的方式来修改文档。

**项目级 agent.md：**
- 选择项目对话 → 打开编辑器 → 手动创建 `agent.md`
- 只在该项目中生效
- 建议：项目里有了一些内容后，让 Codex 根据对项目的了解来帮你写

### 自动记忆机制

- 在「个性化」设置中手动打开「自动记忆」功能
- 机制：对话结束或闲置一段时间后，Codex 将对话总结成记忆记在一个地方
- **原则：**
  - 太短的对话不记
  - 对话总结会消耗额度，额度太低时不记
  - OpenAI 不建议手动修改自动记忆文件，最多删一些没必要的信息

**自动记忆文件结构：**
- 记忆来源（哪段对话、工作目录）
- 触发关键词（什么条件下会召回这份记忆）
- 用户偏好
- 可复用的知识和踩坑记录

> 💡 更多时候，明确的规则和要求还是通过 **agent.md** 来实现。

## 能力四：图片生成与项目开发

### 个人主页开发项目实战

**步骤：**

1. **新建项目** → 输入「个人主页」
2. **打开计划模式**：任务复杂时，Codex 会先列出一个详细计划，确认后才开始执行
3. **需求沟通**：项目中没有内容时，Codex 会以选择框形式询问细节
4. **选择风格**：选择「个人品牌」→ 补充要求（叙事感、高级感、针对合作伙伴、中英双语等）
5. **确认计划**：Codex 给出详尽计划，可以补充调整方案（如「网页上多用图片，使用 DALL-E 生成高级感的图片」）
6. **开始生成**：Codex 逐步执行

### 引导（Steering）功能

> 📌 在 Codex 执行长任务的过程中，如果觉得它跑偏了，可以随时补充纠偏。

**操作方式：**
- 输入补充指令 → 不会立刻打断任务
- 右边会出现「引导」按钮，写着「我们不打断模型运行，会在下次调用工具后发送过去」
- 点击即可发出，**不会让 Codex 在错误道路上一路狂飙花光额度，也不会让它重新再跑一轮任务**

### 分叉对话（Fork）

每个 AI 回复下方都有「分叉」按钮，可以随时从这里开一个新对话。适合前面聊得挺好、上下文也很有价值，但再往下聊就有点岔劈的情况。

### 桌面宠物

设置 → 外观 → 有小宠物可以选择，甚至可以让 Codex 根据对你的了解生成定制化宠物。唤醒后会在桌面上常驻一个小桌宠，脑袋上会冒出 Codex 正在做任务的提示。

### 预览浏览器与批注

- Codex 内置预览浏览器，可在右侧边栏打开
- **批注功能**：点击右上角的批注按钮，可以在页面上选中具体元素写修改意见（包括重新生成图片）
- 例如：选中 LOGO 说「放大一点」，选中某张图说「加上一个人物」
- 对话框会自动加上批注，发送后 Codex 会针对意见修改

### 项目级 agent.md 生成

项目有了一定内容后，让 Codex 生成项目级的 agent.md。打开编辑器可以看到：项目背景、各种信息规则、各种跟踪器都已写好。以后无论新开对话还是聊天记录被清空，Codex 都可以通过这个 agent.md 立马了解项目基本情况。

### 部署上线

通过 **Netlify** 插件部署：
1. 在插件栏找到 Netlify（适合国内访问），点击安装
2. 告诉 Codex 想用 Netlify 把网站部署上去
3. Codex 会引导完成登录授权
4. 搞定后会提供链接，发出去别人就能访问

> 📌 想换成自己的域名？直接问 Codex 教你怎么操作即可。

## 能力五：插件系统

### 内置插件

| 插件名 | 功能 |
|-------|------|
| **Browser Use** | 操控浏览器（点击、翻页、截图、填写表单等） |
| **Computer Use** | 操控电脑上的 APP（目前仅支持 Mac） |
| **Chrome 浏览器** | 控制自己已登录的浏览器，可在后台执行多页面操作 |

### Browser Use 示例：MBTI 测试

让 Codex 打开 MBTI 测试页面：
- 鼠标在屏幕上自己移动
- 自己看题目、填写答案、翻页
- 一通操作后出结果——"原来 GPT-5 是 INFP，我说怎么跟我这么聊得来呢"

### Chrome 插件

- 控制用户自己已登录的浏览器（不打开新浏览器）
- 好处：可以在后台执行多个页面的浏览器操作，不占用整个浏览器，用户可继续用浏览器干别的

### Computer Use 示例（Mac）

开启电脑插件，让 Codex：
- 「帮我放一首 99 年最火的歌」
- 「用我的微信给 QQ 发条微信」

> 📌 虽然微信现在可能严防 AI 操作会失败，但确实能成功操作音乐软件，还可以操作剪映给项目加音乐。

> 💡 目前这两个功能的操作效率还稍微有点低，但后面要说的 **Skill 系统**才是每天都会用的东西。

## 能力六：Skills（技能）系统

> 📌 Skill 本质上是人为沉淀的可复用的方法、流程和工具的组合——相当于给 Agent 做某些具体任务的行动指南。

### 安装社区 Skill

安装 `find-skill`（找 Skill 的工具）后，后续要装社区上的 Skill，直接用自然语言让 Codex 下载即可。

如果 find-skill 找不到的，也可以直接把链接发给 Codex 帮下载。

### 创建自定义 Skill

**最好用的 Skill 永远是自己创建的、符合自己工作的专属 Skill。**

#### 方式一：直接对话创建

直接告诉 Codex 想要创建一个什么样的 Skill，通过跟它讨论打磨出来。

#### 方式二：先跑通流程再生成（推荐）

**实战案例：自动化写热门项目推荐文章**

1. **开新对话** → 通过已装的飞书插件查询 GitHub 热门项目
2. **让 Codex 解释各项目是干嘛的**
3. **挑选星星最多的** → 写一篇本周热门项目推荐文章
4. **优化风格** → 觉得太人机化 → 要求更口语化、只要 5 个精选
5. **用去 AI 味 Skill 优化**
6. **加固定开头结尾** → 用 DALL-E 生成配图
7. **格式化输出** → 要求飞书文档格式，图文并茂
8. **最终发布** → 发到指定群里

**对结果满意后 → 让 Codex 把这一整套流程做成 Skill：**
- 输入斜杠 → 找到新建 Skill 的选项
- Codex 会自动把整套标准和动作保存为 Skill
- 以后直接说「生成一篇热门项目推荐图文」，Codex 就会自动调用

> 📌 Skill 可以把经过验证调好的一次性流程固定下来，下次做同样的事，Codex 就可以按照这个方式稳定输出。

## 能力七：MCP 连接

## 能力八：自动化定时任务

> 📌 定时任务本身不稀奇（如每天早上提醒吃药），但结合前面学到的各种能力，把一整套组合起来的任务让 AI 定点执行——**自动化 + 智能化 + 定制化，方显美妙。**

### 创建方式

#### 方式一：通过自动化面板

1. 进入「自动化」面板
2. 新建自动化任务
3. 用提示词写好要做什么
4. 选择触发时间（也可自定义）
5. 选择执行的模型和思考强度
6. 点击创建

#### 方式二：直接对话创建（推荐）

直接在对话里跟 Codex 说：

> 「帮我创建一个自动化任务，每周一早上 9 点自动化执行热门项目推荐的 Skill，产出一篇图文发到群里。」

Codex 会自动在自动化面板中设置好。

**进阶示例：**
当邮箱插件、GitHub、飞书都连上 Codex 后：
> 「每天下午 6 点帮我汇总日历上完成的会议、GitHub 上的提交记录和邮箱回复记录，生成一份全面的工作日报。」

## 手机操控 Codex

### 设置方法

1. 手机上的 **ChatGPT** 和电脑上的 **Codex** 都更新到最新版
2. 打开手机上的 ChatGPT
3. 点击侧边栏的 **Codex** 图标
4. 提示「允许这台手机控制你的电脑」→ 确认即可

### 使用场景

不管在大街上、地铁上还是朋友聚会，都可以随时随地用手机下发任务，让 Codex 在你的电脑上干活——它就更像一个可以跟你远程协作的同事了。

> 📌 目前免费版也可以用，但主要支持 Mac 系统的 Codex。

| 7 | **MCP 连接** | 连接外部服务和数据 |
| 8 | **自动化定时任务** | 定点执行组合任务 |

### 两个核心认知转变

> 📌 **第一：** 我们真的有很多事情已经可以交给 AI 去做了。

> 📌 **第二：** 我们已经从 **「问 AI」** 的阶段走向了 **「管理 AI」** 的阶段。

过去我们使用 AI 是提出问题，得到答案就走了。现在使用 Codex 这类 AI Agent，每个人都要像领导一样：
- 🎯 帮它准备所需要的上下文和工作环境
- 🎯 给它指明任务目标
- 🎯 检查它的计划、监督它的过程、验收它的结果
- 🎯 把好的方法和流程沉淀成可复用的 Skill
- 🎯 把反复要做的事情设成自动化执行的规律

**恭喜大家，今天都升职了！** 🎉
