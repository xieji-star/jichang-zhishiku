## Step 2 公司调研 🔍

> [!TIP] 一句话摘要
> 紫金矿业 = 全球矿业头部央企，A+H 上市，市值超 5000 亿，海外业务占比过半。校园大使是其"金榜生"校招的排头兵渠道。

### 2.1 公司基本信息

| 维度 | 信息 |
|------|------|
| **全称** | 紫金矿业集团股份有限公司 |
| **性质** | 国有控股（福建省属）+ 混合所有制 |
| **上市** | A 股（601899.SH）+ H 股（2899.HK） |
| **规模** | 全球员工约 **5.6 万人**，市值超 **5000 亿元** |
| **行业** | 有色金属采选冶（铜、金、锌、锂为主） |
| **全球地位** | 中国最大的黄金、铜生产企业之一，全球矿业公司第一梯队（按铜/金产量） |
| **海外布局** | 塞尔维亚、刚果（金）、巴新、哥伦比亚等 15+ 国家，海外产量占比高 |

### 2.2 商业逻辑与变现逻辑 💰

```
         ┌─────────────────────────────────────────┐
         │              商业闭环                     │
         │  矿山勘探/开采 → 冶炼加工 → 精炼金属销售   │
         │  (资源获取)   (成本控制)  (铜价/金价定价)   │
         └─────────────────────────────────────────┘
```

| 环节 | 紫金的具体做法 |
|------|--------------|
| **价值创造** | 全球范围内勘探、收购、开发大型矿山（铜/金/锌/锂），生产精炼金属 |
| **价值传递** | 大宗商品销售（按国际金属价格结算），长协+现货组合 |
| **价值交换** | 金属价格 × 产量 — 成本（低成本采矿能力是其核心竞争力，"矿石流五环"管理） |
| **价值反馈** | 周期底部逆势并购（如卡莫阿铜矿），高利润周期再投入勘探 |

### 2.3 为什么做校园大使（雇主品牌逻辑）

> 🔑 **关键洞察**：矿业是**强周期、重资产、人才短缺**行业。紫金近年大规模国际化（法语、西班牙语、塞尔维亚语岗），急需理工+外语复合人才。校园大使本质是**低成本、高信任度的校招渠道铺设**——让目标院校的学生"自己人拉自己人"。

## Step 3 甲方视角分析 🏢

> [!TIP] 一句话摘要
> 这个岗位为什么存在？—— 紫金正在大规模铺设 2027 届校招渠道，校园大使是"人才雷达+品牌放大器"。

### 3.1 产品反推

| 推测维度 | 分析 |
|---------|------|
| **产品形态** | 雇主品牌 + 校招人才漏斗（信息触达→宣讲引流→简历直推） |
| **产品阶段** | 扩张期（2027 届金榜生计划，专项计划多、宣讲会密集） |
| **目标用户** | 矿业/机电/化工/外语/职能类专业在校生 |
| **岗位紧急度** | 常规招募，但宣讲会日程固定（秋季 9-11 月集中），**时间敏感** |

### 3.2 核心洞察

- **这个岗位为什么存在？** 矿业行业人才断层 + 紫金国际化扩张需要持续稳定的优质生源输入。大使是"以学生带学生"的最优解。
- **大使的角色是什么？** 不是打杂，而是**学校里的品牌代言人 + 信息枢纽 + 人才推荐官**。
- **这段经历最大的价值是什么？**
  1. 简历直推通道（校招时优先被看到）
  2. 官方证书 + 导师指导
  3. 矿业巨头雇主品牌背书（对你后续投其他央企/制造企业也是加分）
  4. 宣讲会/双选会策划执行实战经验

> [!WARNING] 注意
> 官方明确"受聘校园大使**不构成入职承诺**"，校招录用结果以正式流程为准。投递时放平心态——这是**低成本高杠杆的加分项经历**，不是正式 offer。

## Step 5 业务闭环分析 🔄

> [!TIP] 一句话摘要
> 大使工作闭环 = 信息触达 → 社群蓄水 → 活动转化 → 人才输送，是标准的**雇主品牌运营岗**。

### 5.1 工作闭环图

```
官方校招信息 → ①校园宣传（公众号/朋友圈/海报） → ②校招社群运营（蓄水） 
    → ③宣讲会/双选会协助（现场转化） → ④内推/简历直推（人才输送） → 官方反馈与激励
```

### 5.2 流量·产品·交付三要素

| 三要素 | 对应工作 | 占比 | 说明 |
|--------|---------|:----:|------|
| 🚀 **流量** | 宣传、社群拉新、自媒体曝光 | ~45% | 核心是"让更多同学知道紫金" |
| 🏗️ **产品** | 宣讲会策划协助、内容策划 | ~20% | 配合为主，自主空间小 |
| ✅ **交付** | 现场协助、拍摄记录、内推执行 | ~35% | 执行力是底线 |

**岗位类型判断**：运营侧岗位（流量+交付为主），与你的运营经历高度同构。

### 5.3 岗位核心指标（HR 怎么评价大使好坏）

| 指标 | 说明 |
|------|------|
| **社群规模与活跃度** | 拉了多少人进校招群、群内是否有人提问互动 |
| **宣讲会到场转化** | 宣讲会到场人数 / 报名人数 |
| **内推简历数量与质量** | 推荐了多少份有效简历 |
| **宣传物料产出** | 公众号推文、海报、视频的数量与质量 |

> 💡 **面试/汇报时主动提这些指标**，说明你理解大使的"KPI"，会显得很专业。
