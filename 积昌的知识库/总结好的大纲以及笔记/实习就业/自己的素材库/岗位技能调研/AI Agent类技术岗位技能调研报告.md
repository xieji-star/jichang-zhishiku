# AI Agent 类技术岗位技能调研报告

> [!INFO] 报告定位
> 本报告只做一件事：**把 6 份 JD 里"这个岗位到底要什么本事"扒清楚**——硬技能、软能力、隐性要求，并跨 JD 归纳**通用能力**与**差异点**。
> **不调研**：公司背景、业务线、商业逻辑、薪资、投递策略、简历写作（这些属于「默认岗位调研」功能）。

---

## 一、调研概览

### 1.1 输入材料

| 来源目录 | 岗位名 | 方向关键词 |
|---------|--------|-----------|
| 岗位1 | AI Agent 实习生（多模态大模型方向） | 多模态、Agent 系统建设、skill 调用 |
| 岗位2 | 全栈工程师（偏 Agent）· 京东科技 | AIGC 创作 Agent、Multi-Agent 框架、Agent 评测 |
| 岗位3 | AI Agent 实习生（Agent 部署与 AI Coding 方向） | Agent 配置/集成/部署、AI Coding |
| 岗位4（前两张） | Agent 实习生 · 基流 | 智能体开发、知识库、大模型微调 |
| 岗位4（后两张）＝岗位5 | AI 全栈实习（AI 全栈方向） | AI 应用全栈、RAG、知识图谱 |
| 岗位6 | AI Agent 实习生（创业团队 · Next.js 方向） | 全栈 + 产品设计、React/Next.js |

> [!WARNING] 去重说明
> 「岗位4」目录内混装了两份不同 JD（前两张＝基流 Agent 实习生；后两张＝AI 全栈实习），而「岗位5」的两张图与「岗位4」后两张**完全重复**。**去重后实际共 6 份不同 JD。**

### 1.2 一句话结论

> [!IMPORTANT] 核心判断
> 这 6 份 JD 虽然公司、方向各异，但**都在招同一类人**：**"会 Python + 能动手搭 Agent + 懂 RAG/LLM 应用、并且愿意快速自驱学习"的人**。
> 其中 **Python、AI Agent 动手能力、LLM 应用开发认知、知识库/RAG** 是**几乎所有岗位都点名**的硬通货；差异主要落在**"前端/全栈深浅、大模型微调、多模态、Agent 评测、部署运维"**这几个加分维度上。

### 4.3 差异点提炼（3 句话看懂）

> [!IMPORTANT] 差异总结
> 1. **方向光谱**：JD1/JD2 偏**多模态 Agent**（要求图像/视频 + 评测）；JD3 偏**部署落地**（Docker/Linux/容器化最重）；JD4 偏**算法**（唯一要大模型微调 + 深度学习框架）；JD5/JD6 偏**全栈**（前端/数据库最全，JD6 前端与产品设计最强）。
> 2. **前端要求梯度**：JD6（React/Next.js 独立开发）＞ JD5（Vue/React + 三数据库）＞ JD3（HTML/CSS/JS 基础）＞ JD1/JD2/JD4（无）。
> 3. **"差异化加分技能"**：多模态（JD1·2）、Agent 评测（JD1·2）、大模型微调（JD4）、自动化工作流编排（JD6）、部署运维（JD3）——这几项**只要命中一项，就能在同岗位竞争中显著区分出来**。
