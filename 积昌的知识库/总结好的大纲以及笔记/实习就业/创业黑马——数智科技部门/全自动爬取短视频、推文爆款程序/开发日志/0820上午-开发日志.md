## 9. Open P0 and P1 blockers / 未解决P0与P1

### P0 — Admission winner truth / 准入胜出者真实性

- Current zero-timeout Link admission can lose a race and surface `LinkStoreBusyError` before it can read the authoritative legacy winner.
- 当前零超时 Link 准入可能在竞态中失败，并在读取权威 legacy 胜出者前直接抛出 `LinkStoreBusyError`。
- Required behavior: bounded retry/read-after-unlock within a caller-owned budget, never an unbounded wait and never a single ambiguous attempt.
- 必须在调用方预算内进行有界重试/解锁后读取；既不能无界等待，也不能只进行一次含糊尝试。

### P1 — Replay `is_last` and terminal-state binding / 重放末项与终态绑定

- Existing-item replay currently does not bind `normalized['is_last']` before the replay branch.
- existing-item 重放分支前尚未绑定 `normalized['is_last']`。
- Exact replay must require `is_last == (index == item_count - 1)`.
- 精确重放必须要求 `is_last == (index == item_count - 1)`。
- Historical task status must be `running` for a non-final item and `completed` for a final item.
- 历史任务状态必须在非末项为 `running`、末项为 `completed`。

### P1 — Complete durable-prefix receipt truth / 完整持久前缀回执真实性

- Current replay validation binds the replayed item but does not yet prove the complete historical prefix against current durable item rows.
- 当前重放校验绑定了本次重放 item，但尚未证明完整历史前缀与当前持久 item 行一致。
- It must bind every prefix item, `item_count`, all tallies, `next_index`, and expected status.
- 必须绑定每个前缀 item、`item_count`、全部聚合计数、`next_index` 与预期状态。

- 三条任务中“结构合法但前缀伪造”的快照必须以 `link_commit_snapshot_invalid` 失败关闭且零变更。
