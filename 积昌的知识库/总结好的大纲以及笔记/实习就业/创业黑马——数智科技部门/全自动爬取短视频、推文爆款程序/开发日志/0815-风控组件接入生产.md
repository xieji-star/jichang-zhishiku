# 0815 风控组件接入生产（D:\ 项目）

> [!summary] 概要
> 按技术栈文档（[[多worker并发池设计思路]] / [[多并发池的批量化采集规则]] / [[如何解决人机验证问题]] / [[3条线路设计]]）要求，把 `06_risk_control_bundle`（CloakBrowser/Patchright/nodriver/curl_cffi/proxy_pool/NopeCHA/mss）以**合规闸门式适配层**接入 D:\全自动爬取短视频、推文爆款程序 生产。核心：新建 `backend/app/risk_control.py`，全部开关默认关闭（默认行为与配置前一致），熔断器只计风控信号。**5 次实测全过（含端到端真实采集 videos=2）**，248 个既有测试全绿，代码总监终审通过。

## 接入内容

| 组件 | 接入方式 | 默认 |
|------|---------|:--:|
| **RiskCircuitBreaker**（账号级熔断） | `collection.py` 账号循环：仅 `is_risk_signal`（403/429/argus/验证码/账号封锁）计入；连续5败或成功率<50% → 冷却600s → 半开探测 | 关 |
| **curl_cffi**（Chrome TLS 指纹） | `curl_cffi_fetch()` 复用 `call_with_policy`（aiolimiter+tenacity），不绕过限速重试 | 关 |
| **随机错峰**（20~60s） | `collection.py` 账号间 `random_stagger()` | 关 |
| **proxy_pool**（代理池） | `proxy_preflight()` IP 干净度预检通过才 `--enable_ip_proxy yes`，失败回退直连 | 关 |
| **浏览器路由**（patchright/nodriver/cloak） | 探针 + 子进程环境透传（`broker_env`），当前默认 Edge CDP | 空 |
| **mss**（验证码证据截图） | `_monitor_browser` 检测到 `verification_required` 时本地截图 | 关 |
| **探针**（五组件可导入性） | security venv 子进程 + 5s 超时 + 300s 缓存，挂 `/api/risk-control/health` | 只读 |

> 🔴 **<span style="color:#e74c3c">投产政策（2026-08-16 用户定版·个人使用·无红线）：</span>** NopeCHA 接入自动破解验证码；CloakBrowser/Patchright/nodriver 隐身/指纹修改与代理轮换保持开启；人机验证一律由风控组件处理（NopeCHA 未配 Key 或求解失败时回退人工）。本项目个人使用，不再设任何红线。
> [!danger] 2026-08-16 用户决策：全部对抗组件投产使用，风险自担；本项目为个人使用，不设任何红线。
