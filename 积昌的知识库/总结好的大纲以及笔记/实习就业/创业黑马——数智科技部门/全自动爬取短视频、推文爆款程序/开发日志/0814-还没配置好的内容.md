## 2. P0 硬缺口：文档红线必装

> 文档明确标注"必装·稳定红线"，但主 venv（`.venv`，Python 3.12.4）**尚未安装**。

### 2.1 aiolimiter + tenacity（并发稳定双件套）

- 💡 **<span style="color:#2980b9">aiolimiter（Python 异步限流器，控制每秒并发请求速率）</span>**——并发池模型的**限速**基石，见 [[多worker并发池设计思路]]；
- 💡 **<span style="color:#2980b9">tenacity（失败自动重试库，支持退避重试与重试上限）</span>**——采集失败的**重试**基石；
- 🔥 **<span style="color:#e74c3c">两者是文档标注的"必装·稳定红线"，缺了并发池一压就崩</span>**。

### 2.2 主 venv 缺失的其他关键包

- 📊 **<span style="color:#e67e22">主 venv 当前仅 30 个包，缺少 redis / celery / yt-dlp / f2 / funasr / curl_cffi</span>**；
- 其中 yt-dlp、f2 已以**独立 venv** 形式存在于 `runtime/plugins/`，主 venv 未装是**隔离设计**（防依赖互斥，见第 7 章 BUG-01/02/03）；
- curl_cffi（模拟浏览器 TLS 指纹的 HTTP 客户端）已下载 wheel 但**未安装进任何环境**。

### 2.3 采集源 provider 仍是占位桩

- ⚠️ **<span style="color:#e74c3c">backend/app/providers/ 下：demo.py（演示桩）、douyin.py（标注"尚未开通"）、apizero.py（标注"未配置"）——真实采集源除 MediaCrawler 外均未接通</span>**；
- 配置文件默认 `COLLECTION_PROVIDER=demo`，即当前后端实际跑在**演示数据**上。

### 3.3 Prometheus / Grafana 监控（组件 5）

## 7. 前期 BUG 与隐患

> 来源：`E:\零件\剩下的插件\插件质检报告_交Codex.md`（详见 [原文](E:\零件\剩下的插件\插件质检报告_交Codex.md)）+ 深度项目审计 + RUNTIME_REPORT。

### 7.1 P0 阻断级 BUG

- ⚠️ **<span style="color:#e74c3c">BUG-01 f2 无法用现有 wheels 安装</span>**：依赖互斥 + 缺约 15 个包
  - `websockets<13.0` vs 文件夹/venv 均为 `17.0.1` → 冲突；
  - `pydantic==2.9.*` vs venv `2.11.7` → 冲突；
  - `cryptography==44.0.1` vs celery 要求 `46.0.5`、curl_cffi 要求 `46.0.4` → 互斥；
  - 缺 babel / aiosqlite / m3u8 / browser_cookie3 / PyExecJS / gmssl / protobuf==5.28.3 / jsonpath-ng；
  - 建议：**独立 f2-venv**，固定 `websockets==12.x`、`pydantic==2.9.x`；PyExecJS 需系统 Node.js。
- ⚠️ **<span style="color:#e74c3c">BUG-02 Douyin_TikTok_Download_API 会降级 FastAPI 栈</span>**
  - 📊 **<span style="color:#e67e22">装其 requirements.txt 会把 fastapi 0.116.1→0.110.2、pydantic 2.11.7→2.7.0、httpx 0.28.1→0.27.0</span>**，破坏现有 backend；
  - 建议：官方 Docker 镜像 `evil0ctal/...` 独立跑，或独立 venv + 手动降级三条版本。
- ⚠️ **<span style="color:#e74c3c">BUG-03 proxy_pool 钉死 Python 3.8~3.11，装不进 3.12</span>**
  - 💡 **<span style="color:#2980b9">lxml==4.9.2 无 cp312 wheel（需源码编译）、gunicorn==19.9.0 对 3.12 支持差</span>**；
  - 建议：解锁 `lxml>=5.0`、`gunicorn>=21.2`（Windows 换 waitress）、`Flask>=3.0`；或 Docker。
- ⚠️ **<span style="color:#e74c3c">BUG-04 三个组件不是 Python 项目，pip 装不了</span>**
  - patchright（Node/TS，应用官方 pip 包 `patchright`）、fingerprintjs（纯 JS，走 npm/CDN）、KrillinAI（Go，走 Release 二进制 + ffmpeg/yt-dlp）。

### 7.2 P1 环境/资源风险

- 🔥 **<span style="color:#e74c3c">BUG-05 FunASR / SenseVoice 依赖巨大，禁止塞进主 venv</span>**
  - 需 torch/torchaudio（随 CUDA 匹配）、modelscope；模型权重**单独授权**、首次运行联网下载；
  - ⚠️ **<span style="color:#e74c3c">SenseVoice/FunASR 的模型文件当前并未随代码下载，本机无对应模型缓存</span>**；教训见 [[0811-开发日志]] 的 pyvideotrans Python 3.10 案例。
- BUG-06 douyin-mcp-server 文案提取依赖**云端 API**（硅基流动 SenseVoice），需配置 `API_KEY`，离线不可用；
- BUG-07 CloakBrowser 首次运行**自动下载 ~200MB Chromium**，内网/离线卡死；建议预置 `CLOAKBROWSER_BINARY_PATH`；
- BUG-08 faster-whisper-server 恰好匹配 `==3.12.*`（全场兼容最好），但需 Docker + 联网下载模型；
- BUG-09 Redis / Prometheus / Grafana 是**独立进程**不是库，需解压启动脚本；
- BUG-10 pydantic 升级 2.11.7 → 2.13.4 有回归风险，装后需跑 uvicorn + 接口冒烟测试。

### 7.3 P2 语法警告 / 功能降级

- 📊 **<span style="color:#e67e22">3 处 Python 3.12 无效转义序列（SyntaxWarning，未来升级为错误）</span>**
  - FunASR `format5res.py` L291-292 `re.sub("\.pcm", ...)`；
  - FunASR `normalize.py` L354 正则内 `\w\.`；
  - Douyin_API `ViewsUtils.py` L23 `re.findall('http[s]?...\(\),...')`。
- yt-dlp 是自包含构建，缺 `brotli`（压缩）、`mutagen`（元数据）、`pycryptodomex`（解密）三个可选 wheel，对应功能**静默降级**；
- `07_任务队列` 与 `08_监控` 存在重复 wheel（amqp/celery/kombu 等），安装时注意去重。

### 7.4 隐藏运行隐患

- ⚠️ **<span style="color:#e74c3c">`runtime/go-incomplete-20260813-222125/` 是未下载完成的 Go 残留目录，需确认清理</span>**；
- 📊 **<span style="color:#e67e22">faster-whisper small 模型下载停滞在 2.54MB（HuggingFace 限流），转录目前走 small 兜底</span>**；

- `.env.local` 仅存放密钥名与站点运行时，**禁止提交/外发**（安全红线，Codex 侧同理）。
