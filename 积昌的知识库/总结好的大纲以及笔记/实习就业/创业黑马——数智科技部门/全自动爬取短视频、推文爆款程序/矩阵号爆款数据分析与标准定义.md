## 三、爆款标准定义（S/A/B/C 分级）

### 3.1 核心原则

> **"爆款"不是固定数字，而是相对于各账号自身历史水平的相对位置。**

同一内容在百万粉账号和万粉账号上的表现天差地别。因此，每个账号应有独立的爆款基准线。

#### 爆款标题公式

根据数据分析，爆款标题的常见公式：

```
1. [否定式] 别[做X]，要[做Y] → "别再把PINN+GAN写成补数据了"
2. [疑问式] [问题]？→ "读了一百篇文献还是没Idea？"
3. [断言式] 这样做[结果] → "AI写论文一股机味？要先学会学术投喂"
4. [痛点式] 没[资源]怎么[结果] → "没导师，没数据，难道普通人就不配发一区SCI？"
5. [热点式] [热门技术]+[方向]→ "Mamba+多模态特征融合"
6. [风口式] 下一个发文风口，[技术]！→ "下一个发文风口，多变量时序预测！"
```

## 四、分级判定规则（自动化评分用）

### 4.1 评分维度

| 维度 | 权重 | 说明 |
|:----|:---:|------|
| **点赞数** | 40% | 相对于该账号历史平均点赞的倍数 |
| **评论数** | 30% | 相对于该账号历史平均评论的倍数（互动深度） |
| **收藏/转发** | 30% | 来自 API 的数据（暂未获取，可用正向反馈替代） |

### 4.2 评分公式

```
点赞得分 = min(视频点赞数 / 该账号平均点赞数 × 40, 40)
评论得分 = min(视频评论数 / 该账号平均评论数 × 30, 30)
互动得分 = min((点赞+评论) / (该账号平均点赞+平均评论) × 30, 30)
总分 = 点赞得分 + 评论得分 + 互动得分
```

### 4.3 等级判定

| 总分 | 等级 | 含义 |
|:---:|:----:|------|
| **≥80** | **S** | 爆款 — 远超该账号平均水平的超级内容 |
| **≥60** | **A** | 潜力 — 显著高于该账号平均水平的优质内容 |
| **≥40** | **B** | 普通 — 接近该账号平均水平的正常内容 |
| **<40** | **C** | 一般 — 低于该账号平均水平的较弱内容 |

### 4.4 边界情况处理

| 情况 | 处理方式 |
|:----|---------|
| **新账号（数据<30条）** | 使用全局默认基准值（点赞1000、评论50） |
| **账号风格变化** | 校准器每周自动重新计算各账号的平均值 |
| **跨组比较** | 不跨组比较，每组内部独立评分 |
| **极端值影响** | 使用中位数而非平均数作为基准（如搞科研的华哥、七哥不水科研） |
| **胖子和YUK类账号** | 单独建立评分体系（获客类内容的互动率和转化率为核心指标，非点赞评论） |

## 六、数据校准机制

### 6.1 自动校准流程

```
每周自动执行:
  1. 从 SQLite 读取各账号过去 30 天的视频数据
  2. 按账号分组计算平均点赞、平均评论（使用中位数更佳）
  3. 更新 calibration_stats 表
  4. 评分系统使用最新的校准数据
```

### 6.2 冷启动默认值

当账号数据不足 30 条时，使用以下默认基准值：

| 指标 | 默认值 | 说明 |
|:----|:-----:|------|
| 平均点赞 | 1000 | 基于科研论文类账号的平均水平 |
| 平均评论 | 50 | 基于科研论文类账号的平均水平 |
| 平均收藏 | 500 | 暂估，后续校准 |
| 平均分享 | 100 | 暂估，后续校准 |

### 6.3 异常值处理

- **极端爆款**（如搞科研的华哥 7953赞、七哥不水科研 7171赞）：会导致平均值被拉高。建议使用**中位数**而非平均数作为基准。
- **低互动内容**（如评论数<5的视频）：不纳入平均值计算，避免拉低基准。
- **发布时间影响**：新发布视频数据不足时，暂使用该账号历史数据作为参考。
