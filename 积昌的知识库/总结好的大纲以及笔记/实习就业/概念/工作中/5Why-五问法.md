# 🕳️ 5Why — 五问法

> [!INFO] 📌 一句话解释
> **5Why（五问法）= 遇到一个问题，连续问 5 次"为什么"，一层层往下挖**，直到找到那个"**再往下问就没意义了**"的根本原因。它不问"是谁的错"，只问"**问题到底为什么会发生**"——把表面症状和根本原因拆开。

---

## 一、5Why 到底是什么

### 1.1 一句话理解

- 平时我们解决一个问题，往往**只处理了表面**（"机器停了 → 重启一下"），下次还会再犯；
- 5Why 的做法是：**顺着因果链一路追问**——
  - 现象 → 为什么？→ 原因 1 → 为什么？→ 原因 2 → … → 直到**根因**；
- 找到根因，才能"**<span style="color:#e74c3c">一刀切掉病根</span>**"，而不是反复贴创可贴。

### 1.2 它从哪来

- 由**丰田佐吉**（丰田汽车创始人）提出思路，后经**大野耐一**在**丰田生产系统（TPS）**中系统使用并推广；
- 现已成为制造业、互联网、医疗、航空等行业的**"根本原因分析（RCA）"标准工具**——事故复盘、线上故障复盘几乎都在用它。

> 💡 **<span style="color:#2980b9">"5"只是约数：</span>** 不是必须问满 5 次。**可能 3 次就到底，也可能 7 次才到底**——"5"只是经验值。判断标准是：**再往下问"为什么"已经得不到可执行的答案了，就停。**

---

## 二、经典案例（丰田"机器停转"）

这是 5Why 最著名的示范，一看就懂：

| 层级 | 问题 | 答案（原因） |
|------|------|-------------|
| 现象 | 机器停了 | —— |
| 为什么 1 | 为什么停了？ | 因为**超负荷，保险丝烧断了** |
| 为什么 2 | 为什么会超负荷？ | 因为**轴承部分润滑不够** |
| 为什么 3 | 为什么润滑不够？ | 因为**润滑泵吸不上油** |
| 为什么 4 | 为什么吸不上油？ | 因为**油泵轴磨损、松动了** |
| 为什么 5 | 为什么不磨损就好了？ | 因为**没有装过滤器，铁屑等杂质混了进去** |

- ❌ **表面解决**：换一根保险丝（下次还会烧）；
- ✅ **根因解决**：**给油泵装上过滤器**（杂质进不去，链条从源头断掉）。

> 🔥 **<span style="color:#e74c3c">这就是 5Why 的全部威力：</span>** 从"换保险丝"到"装过滤器"，解决的层次完全不同。

## 三、5Why 怎么用（四步）

### 3.1 第一步：把问题**精确描述**出来

- 别写"系统出问题了"，要写"**X 月 X 日 14:00，A 客户在支付页点击提交后报错**"；
- 这一步常用 [[5W2H-七何分析法]] 把时间、地点、影响、程度说清楚——**<span style="color:#2980b9">先描述，再追问</span>**。

### 3.2 第二步：每一问都基于**可验证的事实**

- 每个"为什么"的答案**必须是有证据的事实**，不能是猜测；
- 工厂里的做法是**"到现场去（Gemba）"**——亲自看、亲自量，而不是坐在办公室拍脑袋。

### 3.3 第三步：判断"是不是根因"

- 如果这个答案**还能继续问"为什么"**，说明还没到底；
- 如果这个答案**已经能直接对应一个可执行的对策**，就到根了。

### 3.4 第四步：针对根因，制定**纠正 + 预防**措施

- **纠正**：把这次的坑补上；
- **预防**：改流程／加检查／设标准，**<span style="color:#2980b9">让这个坑以后根本不可能再出现</span>**。

## 四、行业黑话 / 常见叫法

| 叫法 | 含义 |
|------|------|
| **五问法 / 五个为什么** | 5Why 的中文名 |
| **why-why 分析** | 因为它是一串"为什么→为什么"的链条，日式叫法 |
| **RCA（根本原因分析）** | Root Cause Analysis，5Why 是其中最常用的一种方法 |
| **"复盘问到根"** | 互联网公司开故障复盘会时的口头说法 |
| **"Gemba / 现场"** | 精益生产黑话，指"到问题实际发生的地方去看" |
| **5 Whys** | 英文标准写法 |

## 五、常见坑点

### 坑 1：问成"追责会"（5 Whos，不是 5 Whys）🔴

**症状：** "为什么出这个错？→ 因为小李没检查 → 为什么没检查？→ 因为他马虎"——最后变成批斗小李。
**真相：** 5Why 追的是**流程和系统**的漏洞，不是"谁的锅"。个人疏忽只是现象，**背后的流程缺陷才是根因**（比如"为什么没检查"应该是"因为流程里根本没设检查环节"）。
**正确姿势：** **<span style="color:#e74c3c">对事不对人，问到制度为止。</span>**

### 坑 2：停在"人为疏忽"就收工 🔴

**症状：** 一挖到"员工忘了""操作失误"就停手。
**真相：** "人为疏忽"几乎从不是根因——**它往往是"缺少防错设计、没有标准、没有复核"的信号**。
**正确姿势：** 继续问："**<span style="color:#e74c3c">为什么人会疏忽而不被发现？流程里有没有防住它的机制？</span>**"

### 坑 3：靠猜，没有事实支撑

**症状：** 每一问都用"我觉得""可能是"来回答。
**真相：** **<span style="color:#e67e22">没有事实的 5Why，就是一条自欺欺人的故事线。</span>**
**正确姿势：** 每个答案都要能**拿数据／到现场／问当事人**验证。

### 坑 4：只追一条线，忽略"多个原因"

**症状：** 一个"为什么"可能有多个并列原因，却只挑了其中一个往下追。
**真相：** 现实问题常常**多因一果**。
**正确姿势：** 遇到多个答案就**分叉各自追**（配合鱼骨图／因果树），别只走一条。

### 坑 5：迷信"必须问满 5 次"

**症状：** 明明 3 次就到根了，还硬凑到 5 次；或者该继续挖却停了。
**真相：** **"5"是经验值不是硬指标**，到根即停，没到根就继续。

> 📌 **<span style="color:#e67e22">坑点一句话复盘：</span>** 5Why 最怕两件事——**挖着挖着变成"追责"，或者还没挖到根就收手。**

---

## 六、一句话总结

> **5Why（五问法）= 连续问"为什么"，把表面现象一路追到根本原因，再针对根因做纠正与预防。**
>
> - 它和 [[5W2H-七何分析法]] 是搭档：**5W2H 负责把问题描述清楚，5Why 负责往下挖根因**（先描述、后挖因）；
> - 它和 [[5W1H-六何分析法]] 里的"一次 Why"不是一回事——**5Why 是连续追问**；
> - 记住三句：**<span style="color:#e74c3c">对事不对人、每个答案要有事实、到根了就停。</span>**
