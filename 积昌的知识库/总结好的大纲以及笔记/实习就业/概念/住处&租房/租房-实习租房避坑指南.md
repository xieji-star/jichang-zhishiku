# 🏠 租房 — 实习租房避坑指南

> [!INFO] 📌 一句话定义
> **实习租房 = 用最短的时间、最少的钱，把一个"能安心住、退租不被讹"的落脚点搞定。**
>
> 🔥 **<span style="color:#e74c3c">租房的核心不是"找到一个房子"，而是"防住五种人"：</span>** 假房东、二房东、黑中介、甲醛房、"口头承诺大师"。**所有关键约定，一律落到纸面 + 留下证据。**

## 一、第一步：确认真房东

### 一句话解释

**确认站在你面前的人，到底是不是这套房子的真正主人。** 这是租房的第一道生死线——如果你把押金和租金交给一个"二房东"（把房子转租出来的人）或假房东，他一旦卷钱跑路，**你可能被真房东直接赶出门，钱也追不回来。**

### 怎么确认

- 🕵️ **让房东出示"身份证 + 房产证"（或购房合同），核对两个名字是不是同一个人**；
- ⚠️ **<span style="color:#e74c3c">对方说"房产证不在手边 / 房产证在老家 / 是爸妈的房子"——高度警惕</span>**，要求出示能证明关系的材料（户口本、委托书等）；
- 🔄 **如果是"转租"**：必须让转租人出示**他和原房东签的合同**，确认合同里**明确允许转租**，最好**直接联系上原房东**当面确认；
- 🧑💼 **如果是中介带看**：要求中介出示**房主的委托书**，确认中介有代理资格。

### 行业黑话

| 黑话 | 实际意思 |
|------|---------|
| **一手房东 / 房东本人** | 房产证上写着名字的那个人，直接和他签最安全 |
| **二房东** | 把租来的房子再转租出去的人。**他不是房主，却收着你的钱** |
| **转租** | 租客把剩余租期转给别人，常见于实习/毕业季 |
| **假房东** | 冒用房主身份骗押金的人（有的是租客假扮，有的是纯粹的骗子） |

### 常见坑点

1. 🔴 **<span style="color:#e74c3c">二房东卷钱跑路</span>**：你交了押金+房租，二房东不交给原房东，原房东来收房，你被赶走还追不回钱。
2. ⚠️ **<span style="color:#e74c3c">"房产证在老家"话术</span>**：多用于假房东，**见不到证件就别签、别转账**。
3. ⚠️ **转租合同里"禁止转租"**：你签了也无效，原房东一发现就能清你出门。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把租房比作"买二手货"：</span>** 你一定要**确认卖家就是这台手机的机主**——否则他拿着不存在的手机收你钱，你连人都找不着。房产证+身份证，就是房子的"保修卡和购买凭证"。

> 📌 **例子：** 小谢看中一套转租房，对方是个研究生。小谢**让他当场翻出他和原房东的合同**，确认房东允许转租，还加了原房东微信确认——后来退租时果然出了岔子，正因为联系得上原房东，才没被坑钱。

## 二、看房：录视频、拍照、抄表、测甲醛

### 一句话解释

**进房门第一件事，掏出手机开始录视频，家具、墙面、家电、地板，从头到尾拍一遍。** 这些影像就是你入住前的"证据"——**退租时房东要是说"这里是你弄坏的"，你直接甩出视频，一分冤枉钱不用赔。**

### 进房必做的四件事

| 动作 | 具体怎么做 | 为什么 |
|------|-----------|--------|
| **① 录视频** | 进门**先开录像**，从门口一路拍到阳台、厨房、卫生间，**每个角落都扫一遍**，边走边口述"这里是 XX" | 退租时的"现场对比证据"，防讹赔 |
| **② 拍细节** | 墙面（裂缝/污渍/发霉）、地板（起翘/划痕）、家具（破损/缺件）、家电（外观+型号）逐张拍 | 破损处**特写**，越清楚越安全 |
| **③ 抄水电表** | 入住前**拍下水表和电表的读数**（数字要拍清楚） | 交水电费、退房结算时**核对用量** |
| **④ 测甲醛** | 房子味大 → 提前买个**甲醛测试纸**带在身上，进门放上去测；**看完说"后面再来一次"，顺便回来看结果** | 甲醛超标=健康风险，也是砍价/拒租的理由 |

### 还要顺手检查

- 🔌 **家电能不能用**：空调开一下、热水器放放水、洗衣机转一转、冰箱通电**——别等住进去才发现是坏的**；
- 🚰 **水压、下水**：打开水龙头看水压，冲一下马桶看下水顺不顺；
- 🔒 **门窗锁具**：能不能正常锁上，钥匙有没有配齐；
- 🌫️ **异味**：霉味、装修味、下水道味——**味大先别急着租**。

### 🔊 重点：避开"嗡嗡"低频噪音源

**租房一定要避开"换电站、水泵、各种管道"这类设施**——它们会持续发出**"嗡嗡"的低频噪音**，是租房里**最容易忽略、又最没法补救**的一个坑。

- 📌 **什么时候最难受**：白天有车声、人声盖着不明显，**一到夜深人静就格外刺耳**，直接毁睡眠；
- ⚠️ **为什么难搞**：低频噪音**穿透力极强，关窗、隔音都挡不住**——**住进去再想解决，基本无解**；
- 🔥 **<span style="color:#e74c3c">所以，看房时一定要亲耳听，最好挑安静时段去。</span>**

**怎么看（照着做）：**

1. **问清设施**：房子楼下、隔壁有没有**换电站、水泵、各种管道**；
2. **挑安静时段看房**：**晚上或清晨**去看——噪音源只有在周围安静时才听得出来；
3. **进门静听一分钟**：先**关掉所有电器**，安静下来听有没有持续的"嗡嗡"声。

### 行业黑话

| 黑话 | 实际意思 |
|------|---------|
| **甲醛房 / 串串房** | 刚装修完、甲醛超标就拿出来出租的房子，住进去伤身体 |
| **押金讹赔** | 退租时房东以"这里坏了"为由扣押金，**没有入住视频就只能吃哑巴亏** |
| **验房** | 入住/退租时对照房屋状况的检查，**有录像才算真验房** |

### 常见坑点

1. 🔴 **<span style="color:#e74c3c">不录视频 = 退租任人宰割</span>**：房东说墙是你弄脏的、地板是你划的，你**拿不出证据就只能赔**。
2. ⚠️ **<span style="color:#e74c3c">忘了抄水电表</span>**：退房时房东说"你用了 800 度电"，你无从对质——**入住当天必须拍表**。
3. ⚠️ **<span style="color:#e74c3c">甲醛房不测就住</span>**：新装修、串串房味道重却急着住，健康代价极大。**味大就测，测了超标就拒租或砍价。**
4. 📌 **只看了一次就定房**：**"看完说后面再来一次"是聪明的做法**——隔一两天再去，能发现白天看不到的问题（如采光、噪音、甲醛散味后的变化）。
5. 📊 **<span style="color:#e67e22">家电当场不试，入住才发现坏</span>**：维修费最后往往算到你头上。
6. 🔊 **<span style="color:#e74c3c">忽略"嗡嗡"低频噪音源</span>**：**换电站、水泵、各种管道**这类设施会持续发出低频噪音，**白天听不见、深夜折磨人，且几乎无法隔绝**——**看房务必挑安静时段亲耳听。**

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把看房录视频比作"给房子拍身份证照"：</span>** 你入住时它长这样，退租时它还得长这样——**中间多出来的伤，才该由你负责；本来就有的伤，有照片为证，与你无关。**

## 三、签合同：白纸黑字，别信口头承诺

### 一句话解释

**合同是租房里唯一算数的东西。** 房东嘴上说"水电两块一度、随时可以退押金、包维修"——**只要没写进合同，退租时他一句"我没说过"就全没了。**

### 合同里必须写清的 6 项

| 项目 | 要写清什么 |
|------|-----------|
| **① 房租** | 一个月多少钱、**精确到数字**（大写+小写都写） |
| **② 水电燃气单价** | **每度电多少钱、每吨水多少钱、燃气怎么算**——这是最容易被坑的一项 |
| **③ 付款周期** | 押几付几（如押一付三）、**每期什么时候交、交多少** |
| **④ 押金** | 押金多少、**什么条件下退、什么条件下不退**（退押金条款一定要看） |
| **⑤ 租期** | 起止日期、**中途退租怎么算**、能不能转租 |
| **⑥ 费用归属** | 物业费、网费、取暖费、维修费**谁出**，房租里"包含哪些"要写明白 |

> 📊 **<span style="color:#e67e22">签合同前必问：</span>** "房租里包含哪些？水电网物业谁交？坏了谁修？"——**对方说得越模糊，你越要让他写进合同。**

### 行业黑话

| 黑话 | 实际意思 |
|------|---------|
| **押一付三 / 押一付一** | 押金交 1 个月租金，房租一次交 3 个月 / 1 个月 |
| **商水商电** | 按"商业"标准收的水电，**比民用贵很多**（电可能 1~1.5 元/度） |
| **民水民电** | 按"民用"标准收，便宜（电几毛钱一度）——**租房优先选民水民电** |
| **口头承诺** | 房东嘴上答应、但不写进合同的话，**基本等于没说** |
| **霸王条款** | 合同里明显偏向房东的条款，如"任何情况押金不退" |
| **空置期 / 免租期** | 房东给几天不算钱的搬入时间，能谈就谈 |

### 常见坑点

1. 🔴 **<span style="color:#e74c3c">口头承诺最后不上合同</span>**：这是用户反复强调的重点——**"说好的"必须落纸，口头承诺一律不信**。
2. ⚠️ **<span style="color:#e74c3c">水电单价没写清</span>**：二房东常在电费上加价，**合同不写单价，账单他说多少是多少**。
3. ⚠️ **<span style="color:#e74c3c">商水商电冒充民水民电</span>**：很多公寓、二房东按商电收钱，一个月电费可能翻好几倍。
4. ⚠️ **"押金不退"条款**：有的合同写"租期未满不退押金""清洁费从押金扣"——**签之前逐条读，不合理的当场提**。
5. 💡 **<span style="color:#2980b9">合同不留一份给自己</span>**：**签完一定要拿走一份**（最好拍照存手机），别让房东"统一保管"。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把合同比作"游戏规则书"：</span>** 口头承诺是"朋友间的口头约定"，出了事谁都能赖；**合同是白纸黑字的"字据"，法院只认它**。写进合同的那一刻，承诺才真正存在。

> 📌 **例子：** 房东说"押金随时能退，你放心"。小谢要求在合同里加一句"租期未满退租，押金全额退还"。房东**不肯写**——这一下就暴露了：他不是真打算退。**肯写进合同的，才是真的。**

## 四、押金与付款：留凭证、开收据

### 一句话解释

**押金是租房里最容易"打水漂"的一笔钱。** 收好两样东西——**转账记录 + 收据**，是你日后追回押金的唯一武器。

### 必须做的三件事

1. 💰 **押金转账时，备注写清"租房押金"**：
   - 转给房东/二房东的钱，**在转账备注里写上"XX 房租房押金"**；
   - 后面每期房租，也备注"XX 月房租"；
   - ⚠️ **尽量走转账（微信/支付宝/银行），别给现金**——现金没有痕迹，赖账无从举证。
2. 🧾 **让房东开一张收据**：
   - 收据上写清：**收款人、金额、用途（押金/房租）、日期、房子地址**；
   - 有房东**签字/手印**最好；
   - **收据拍照存手机 + 转发自己一份**。
3. 📂 **保存所有转账记录**：
   - 每一笔给房东的转账都**截图保存**，建个相册专门放；
   - 微信/支付宝的**账单记录别删**，那是你最终对质的凭据。

### 押金要提前谈清楚

- **押金多少**？（一般 1 个月租金）
- **什么情况能退、什么情况扣**？（正常磨损不该扣押金）
- **退租后多久退押金**？（写进合同，别让他"拖"）
- ⚠️ **<span style="color:#e74c3c">小心"押金不退"的隐藏条款</span>**（见第三节）。

### 行业黑话

| 黑话 | 实际意思 |
|------|---------|
| **押金 / 按金** | 交给房东的"保证金"，退租时按约定退还 |
| **押一付三** | 押金 1 个月 + 一次性付 3 个月房租 |
| **押金抵扣** | 退租时房东从押金里扣除"损坏费/清洁费"，**合理性要盯紧** |
| **赖押金** | 房东找各种理由不退押金，是租房最常见的纠纷 |

### 常见坑点

1. 🔴 **<span style="color:#e74c3c">给现金 + 没备注</span>**：押金打了水漂，**没有任何证据能证明你交过**。
2. ⚠️ **<span style="color:#e74c3c">转账不备注</span>**：房东可以狡辩"这是你交的房租，不是押金"——**备注是防这一手的**。
3. ⚠️ **没有收据**：金额、用途说不清，维权时被动。
4. 📌 **"清洁费/维修费"从押金里乱扣**：退租时房东列一堆莫名的扣款项目——**入住时的录像 + 合同条款就是你反驳的依据**。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把押金比作"寄存行李的凭证"：</span>** 你寄存行李时，柜台给你一张**取件凭证**；退租时房东不退钱，你的"凭证"就是**转账备注 + 收据**——没有凭证，你连"我存过东西"都证明不了。

## 五、找房渠道怎么选

> 📌 **结论先行：最好的方式永远是"自己线下跑一趟"。** 中介不敢全信，网上图片水分大，**亲自去看、亲自去谈，才最踏实。**

| 渠道 | 优点 | 缺点 / 风险 | 适合谁 |
|------|------|------------|--------|
| **自己线下跑** ⭐ | 最直观、能当面验房、能砍价 | 费时间 | **所有人（最优解）** |
| **中介** | 房源多、省事 | **中介费（通常 1 个月租金的 50%~100%）、房源真假难辨、不敢全信** | 时间紧、预算够的人 |
| **包月公寓**（如微领地青年社区） | 拎包入住、按月起租、省心、一线城市多有 | **多为商水商电、价格偏高** | 短期实习、图省事的人 |
| **转租** | 常比市场价便宜、家电齐全 | 要确认**原房东允许转租**（见第一节） | 能联系上原房东的人 |
| **合租** | 分摊租金、有人作伴 | 室友磨合、公共区域纠纷 | 预算有限、不介意合住的人 |
| **青旅** | **最便宜、可长住、有优惠、不用收拾** | 隐私差、长期不如租房 | 短期过渡 / 喜欢社交的人 |

### 关于"中介"和"问人"

- ⚠️ **<span style="color:#e74c3c">中介不太敢信</span>**：房源照片常"货不对板"，同一房源被多家包装；
- 💡 **<span style="color:#2980b9">但可以多渠道打听：</span>** 自己也问几个中介，再**找 HR 推几个**；
- 🔥 **<span style="color:#e74c3c">入职后先跟部门"破破冰"，顺口问问有没有合租的房子</span>**——同事、HR 的内部房源，往往比中介靠谱得多。

### 关于"青旅"（短期过渡首选）

- 💰 **青旅是最便宜的方案**，**长住还有优惠**，而且**不用你收拾**（有人打扫）；
- 🧑🤝🧑 **有办公区域（没办公区也有桌子）**，能跟很多人聊天、交流信息；
- ✅ **青旅基本不会有"串串房"问题**——它便宜，最多是条件好坏的区别；
- 📌 **除非你有事情需要一个人单独做（如线上面试、录课），否则住青旅其实挺舒服。**

### 行业黑话

| 黑话 | 实际意思 |
|------|---------|
| **串串房** | 把民房**违规改造**后出租的房子，隐患多（消防、甲醛、被查处） |
| **隔断房** | 一套房用隔板**隔成好几间**分别出租，隔音差、不合规 |
| **群租** | 一间房里塞很多人，通常违规，风险高 |
| **包月公寓** | 按月起租的长租公寓（如微领地青年社区），拎包入住 |
| **青旅 / 青年旅舍** | 按床位出租的便宜住宿，有公共区域，适合短住 |
| **转租** | 接手别人没到期的租约 |

### 常见坑点

1. ⚠️ **<span style="color:#e74c3c">串串房 / 隔断房</span>**：这类房子是**民房被违规改造**出来的，隔音差、消防隐患大，**且随时可能被查处清退**——看到"一间大房隔成好几小间"，直接走。
2. ⚠️ **中介费没问清就签**：中介费通常按租金比例收，**提前问清多少、谁出**。
3. 📌 **只看网图就下单**：**"线下跑一趟"永远不可替代**——照片再好，也不如亲眼看。
4. 🔴 **<span style="color:#e74c3c">青旅也有"条件好坏"之分</span>**：便宜的青旅条件差是正常的，但**它一般不是串串房**——选择时看评价、看卫生。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把找房渠道比作"找对象"：</span>** 中介像婚介所（资源多但要花钱、信息未必真），**自己线下跑像自由恋爱**（费劲但最靠谱），青旅像"青年社交公寓"（便宜、热闹、适合过渡）。

> 📌 **例子：** 小谢的第一个房子看的是**别人的转租**，看房时**遇上一个也在看房的研究生**，聊了几句，对方说自己找了中介——**小谢干脆和他一块看**。多一个人看房，多一双眼睛发现问题，也多一个信息源。

## 七、各城市租房黑话 & trick

> 📌 **同一条"租房常识"，在不同城市可能完全是反的。** 这个板块专门收录**各城市特有的规矩、黑话和"反直觉"的坑**——一座城市的经验，搬到另一座城市，可能反而让你吃亏。
>
> 🔥 **<span style="color:#e74c3c">本节按城市持续补充中。</span>** 当前已收录：**上海**。

### 📍 上海

**黑话 / 规矩：** 在上海租房，**别主动去问"水电网燃气包不包"**。

**背后的逻辑（反直觉，重点看）：**

- 🕳️ **不问 = 默认都包**：上海不少房源的水、电、网、燃气费用是**含在房租里**的——**你不提，它就按"全包"来算**；
- 💸 **问了 = 主动把便宜问没**：一旦你开口问"这些费用包不包"，房东 / 中介就会顺势接一句"哦，这些要另外算"——**你这一问，等于自己给自己加了一笔开销**；
- 🔥 **<span style="color:#e74c3c">上海的正确姿势是：不主动问，就按它默认"全包"来。</span>**

**坑点：**

- ⚠️ **<span style="color:#e74c3c">别把其他城市"先问清费用"的习惯带进上海</span>**：在很多城市，签合同前问清"水电网谁出"是标准操作；**但在上海，主动问反而容易被"割韭菜"**——这就是城市规矩的反差，也正是本节要单独拎出来讲的原因；
- 📌 **"默认全包"多是口头惯例，仍需落到合同**：上海这一条**更多是口头默认**，**真要保稳，还是让合同白纸黑字写明"房租含水电燃气"**（呼应第三节"口头承诺必须写进合同"）；
- 💡 **<span style="color:#2980b9">换个问法更稳：</span>** 真想确认，**别问"包不包"，直接看合同的"费用条款"**——**合同里写了才算数**，口头的不算。

> ⭐ **<span style="color:#e74c3c">一句话：</span>** 上海租房，水电网燃气是**"不问默认包、问了要另付"**——别把"先问清楚"的习惯带到上海，否则容易反被割韭菜。

### 📍 其他城市

> 📝 **待补充。** 每个城市一格，**格式统一为：城市名 → 黑话/规矩 → 背后逻辑 → 坑点 → 一句话**。补充时直接复制上面"上海"这一节的结构往下写即可。

## 八、常见坑点总清单

> ⚠️ **<span style="color:#e74c3c">照着这张表逐条打勾，能挡掉 90% 的租房坑。</span>**

### 签之前

- [ ] 确认对方是**真房东**（身份证 + 房产证核对）
- [ ] 转租房**确认原房东允许转租**，最好直接联系上原房东
- [ ] 中介带看，**要求出示房主委托书**
- [ ] 合同里的**房租、水电单价、付款周期**逐项写清
- [ ] **口头承诺一律要求写进合同**，写不进去的就不信
- [ ] 押金**退不退、什么条件退、多久退**，全部写清
- [ ] 合同**自己留一份**（拍照 + 原件）

### 看房时

- [ ] **进门先录视频**，家具、墙面、地板、家电全拍
- [ ] 破损处**拍特写**
- [ ] **抄下/拍下水表和电表读数**
- [ ] 检查**家电能不能正常用**（空调、热水器、洗衣机、冰箱）
- [ ] 房子**味大就测甲醛**（提前备好甲醛测试纸）
- [ ] 🔊 **安静时段亲耳听噪音**：避开**换电站、水泵、各种管道**的低频"嗡嗡"声
- [ ] **看完说"后面再来一次"**，隔天再来看一次

### 付款时

- [ ] 押金**转账备注"XX 房租房押金"**
- [ ] 每期房租**转账备注"XX 月房租"**
- [ ] **让房东开收据**（金额、用途、日期、地址、签字）
- [ ] **保存所有转账记录**（截图 + 账单不删）
- [ ] ⚠️ **尽量别给现金**

### 找房时

- [ ] **优先自己线下跑一趟**
- [ ] 中介费**提前问清多少、谁出**
- [ ] 避开**串串房、隔断房**（民房违规改造）
- [ ] 短期过渡可考虑**青旅**（最便宜、可长住、有优惠）
- [ ] **向 HR / 部门同事打听**内部合租房源

## 九、一句话总结

> 🔥 **<span style="color:#e74c3c">租房 = 确认人 + 留证据 + 写合同。</span>**
>
> 记住四句话：
> 1. **先确认真房东**——身份证 + 房产证对得上，才谈钱；
> 2. **看房先录视频、抄水电表、测甲醛**——入住前的证据，是你退租时的护身符；
> 3. **一切口头承诺必须写进合同**——房租、水电单价、付款周期、押金条款，一项都不能含糊；
> 4. **押金转账备注 + 开收据 + 存转账记录**——这三样，是你日后要回押金的唯一靠山。
>
> 💡 **<span style="color:#2980b9">最优路线：</span>** **自己线下跑一趟**看房 → 确认房主身份 → 录视频抄表 → 谈清合同细节 → 转账备注开收据。**图省事就选包月公寓（如微领地青年社区）或青旅，但该留的证据一样不能少。**
