# 🧳 实习准备清单 — 入职要带什么

> [!INFO] 📌 一句话定义
> **实习行前准备 = 用"一箱行李"，覆盖你在异地实习期间的"证件、吃穿住用"四件事。**
>
> 🔥 **<span style="color:#e74c3c">核心原则：证件和入职材料随身带（丢了最麻烦），被子等大件到当地再买（别一路背着）。</span>** 其余按清单逐项打勾，一件不落。

## 一、证件与入职材料（最重要）

### 一句话解释

**这一组是"没有就寸步难行"的东西，必须随身携带、绝不能托运、绝不能丢。** 身份证丢了住不了酒店、进不了公司；入职材料缺了当天可能就办不了入职。

### 必带清单

| 物品 | 说明 |
|------|------|
| **身份证** | 最重要，随身带，**别放托运行李** |
| **学生证** | 部分公司/优惠会用得上 |
| **银行卡** | 发工资、交房租都要用（提前确认工资卡要求） |
| **证件照** | 一寸、两寸各若干张（入职常要贴） |
| **入职通知 / offer** | 纸质版或存手机，报到时可能要看 |
| **入职材料** | ⚠️ **提前问 HR 要清单**（体检报告、学历证明、离职证明、身份证复印件等） |
| **体检报告** | 很多公司要求入职体检，提前做好 |
| **纸质简历** | 备几份，填表或临时用得上 |

### 常见坑点

1. 🔴 **<span style="color:#e74c3c">证件放托运行李 → 行李延误就全完了</span>**：身份证、银行卡一定**随身**。
2. ⚠️ **<span style="color:#e74c3c">入职材料没提前问 HR</span>**：不同公司要求不同，**缺一样可能当天办不了入职**。
3. ⚠️ **身份证复印件没备**：现场没地方复印，**提前备好几份**。
4. 📌 **证件照白底/蓝底没搞清**：按公司要求准备，**多备几张总没错**。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把证件比作"游戏的入场券"：</span>** 行李可以晚到、可以再买，但**入场券没了，你连门都进不去**——所以它永远放你随身的包里。

## 二、衣物

### 一句话解释

**实习不是旅游，衣物以"够换洗、能上班、耐穿"为准。** 用户的核心建议是：**换洗衣物至少三套**，避免天天洗衣服。

### 必带清单

| 物品 | 说明 |
|------|------|
| **换洗衣物 × 3 套** | 上衣 + 裤子/裙子，**能撑过几次洗衣服的间隔** |
| **正装 / 稍正式的衣服 × 1 套** | 有些公司要求，面试、正式场合也用得上 |
| **内衣裤、袜子** | ⚠️ **多带几套**（用户原话：**"裤头别忘带"**） |
| **外套 / 薄羽绒** | ⚠️ **按当地气候带**——南方潮湿、北方干冷，别只按老家的天气装 |
| **鞋子** | 通勤鞋 + 拖鞋各一双 |
| **睡衣** | 住青旅/合租必备 |
| **雨伞** | 通勤刚需 |

### 常见坑点

1. ⚠️ **<span style="color:#e74c3c">内衣裤袜子忘带</span>**：最容易忽略、又最不方便临时买——**用户特别提醒"裤头别忘带"**。
2. ⚠️ **<span style="color:#e74c3c">按老家气候装衣</span>**：实习城市可能完全不同的天气，**提前查当地季节气温**。
3. 📌 **带太多衣服**：实习结束还要搬回来，**够穿就行，别把衣柜搬过去**。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把行李比作"移动的家"：</span>** 你要搬的不是"全部家当"，而是"刚够撑起一段生活的最小套装"——**够换洗、能上班、扛得住当地天气，就够了。**

## 三、洗漱与护肤

### 一句话解释

**牙刷牙膏杯子是刚需，护肤看个人。** 用户一句话概括：**"护肤的，男的洗面奶差不多了。"**

### 必带清单

| 物品 | 说明 |
|------|------|
| **牙刷、牙膏、漱口杯** | 标配三件套 |
| **毛巾 / 浴巾** | 住青旅/合租必备 |
| **洗面奶** | 男生一支洗面奶基本够用 |
| **护肤品** | 按个人习惯（水乳、面霜等） |
| **洗发水 / 沐浴露** | 旅行装先撑着，到当地买大瓶 |
| **剃须刀 / 梳子** | 按个人需要 |
| **指甲刀** | 小件但常用 |

### 常见坑点

1. 📌 **液体超量**：坐飞机注意**随身液体限制**，大瓶洗漱品走托运或到当地买。
2. ⚠️ **<span style="color:#e74c3c">毛巾忘带</span>**：住青旅、刚租到房时，**毛巾是最容易临时缺的东西**。

## 四、电子设备

### 一句话解释

**电脑是实习的"生产工具"，充电器、吹风机是日常刚需。** 这组东西**贵、怕丢、怕坏**，要单独装好。

### 必带清单

| 物品 | 说明 |
|------|------|
| **电脑 + 充电器** | 实习生产工具，**必带** |
| **手机 + 充电器 + 充电宝** | 通信 + 应急 |
| **数据线（多备一根）** | 最容易坏、最容易忘 |
| **耳机** | 通勤、开会、青旅里不打扰别人 |
| **吹风机** | 用户明确提到——**刚租房/住青旅常常没有** |
| **转换插头 / 插排** | 老房子插座少，**一个插排能救命** |
| **相机 / 电脑外设** | 按工作是否需要 |

### 常见坑点

1. ⚠️ **<span style="color:#e74c3c">充电器、数据线忘带</span>**：到当地买贵又麻烦，**出发前逐个数一遍**。
2. 📌 **吹风机**：**很多出租房和青旅不提供**——用户特意提醒要带。
3. 📊 **插座不够用**：老房子、合租房插座少，**带个插排**能省很多事。

## 五、药品与应急

### 一句话解释

**异地在外的"小药箱"**——生个小病不用满城找药店，**关键时刻能省一大堆麻烦。**

### 必带清单

| 物品 | 说明 |
|------|------|
| **感冒药** | 换季、空调房常中招 |
| **肠胃药** | 水土不服、外食闹肚子 |
| **创可贴** | 小伤口应急 |
| **晕车药** | 通勤远、坐车多的人 |
| **个人常用药** | 有慢性病/过敏史的**务必带足** |
| **体温计 / 口罩** | 基础应急 |

### 常见坑点

1. 📌 **常用药没带足**：异地买同款可能不方便，**按实习时长备够量**。

## 六、到当地再买（别一路背着）

### 一句话解释

**大件床品和生活用品，一律到当地再买**——行李越轻，路上越省事。用户的原话：**"到时候还得买被子，拼多多几十块来一床。"**

### 到当地再买清单

| 物品 | 在哪买 / 怎么买 |
|------|----------------|
| **被子** | ⭐ **拼多多几十块一床**，或当地超市/无印良品 |
| **枕头、床垫 / 床褥** | 当地买，或拼多多 |
| **被套、床单、枕套** | 和被子一起买 |
| **衣架** | 超市/拼多多，便宜 |
| **脸盆、水桶** | 当地买 |
| **洗衣液、纸巾、垃圾袋** | 到当地超市采购 |
| **插排、小台灯** | 看房子情况补 |
| **拖把、扫帚等清洁工具** | 租房后按需买 |

### 常见坑点

1. 🔴 **<span style="color:#e74c3c">被子从家里背过去</span>**：又占地方又重，**到当地几十块就能买一床**，完全没必要。
2. 💡 **<span style="color:#2980b9">先到货再买大件</span>**：**确定住处之后再买床品**，否则搬家时是全套累赘。

### 比喻 / 例子

> 💡 **<span style="color:#2980b9">把行李比作"搬家式旅行"：</span>** 你只带"贴身的那层"（证件、衣物、电脑、洗漱），**"铺开的那层"（被子、脸盆、清洁工具）落地再补**——轻装上阵，到站安家。

## 八、注意事项与易忘点

> ⚠️ **<span style="color:#e74c3c">这几条是最容易翻车的地方，出发前重点核对。</span>**

1. 🔴 **<span style="color:#e74c3c">证件随身，绝不托运</span>**：身份证、银行卡、入职材料放随身包。
2. ⚠️ **<span style="color:#e74c3c">入职材料提前问 HR 要清单</span>**：每个公司要求不同，**缺一样当天可能入不了职**。
3. ⚠️ **<span style="color:#e74c3c">"裤头"（内衣裤袜子）别忘带</span>**：用户特意强调——最容易忘、又最不方便临时买。
4. 📌 **被子等大件到当地买**：别从家里背，**拼多多几十块一床，轻装上路**。
5. ⚠️ **<span style="color:#e74c3c">衣物按当地气候装</span>**：提前查实习城市的季节气温，别只按老家天气。
6. 💡 **<span style="color:#2980b9">充电器、数据线、吹风机</span>**：这三样最常被忘——**出发前列一遍**。
7. 📊 **<span style="color:#e67e22">先安顿住处，再买大件</span>**：住哪还没定，就别急着买被子和脸盆（配合 [[租房-实习租房避坑指南]] 一起看）。
8. 📌 **报到信息提前确认**：问清 **HR / [[+1+2-职场上下级层级|+1]] 报到的时间、地点、材料、联系人**。

## 一句话总结

> 🔥 **<span style="color:#e74c3c">实习行装 = 证件随身 + 够换洗 + 生产工具 + 落地补货。</span>**
>
> 记住三句话：
> 1. **证件和入职材料**是最重要的，**随身带、提前问清单**；
> 2. **衣物三套起步，内衣裤袜子别忘**，按当地气候带；
> 3. **被子、脸盆等大件到当地再买**——行李越轻，路上越省事。
>
> 💡 **<span style="color:#2980b9">最优路线：</span>** 按第七节速查表逐项打勾 → 证件随身 → 大件留到当地买 → 先安顿住处再补日用。**到了当地，配合 [[租房-实习租房避坑指南]] 把租房和落脚点一次搞定。**
