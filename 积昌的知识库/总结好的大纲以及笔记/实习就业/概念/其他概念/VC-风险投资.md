# 💸 VC — 风险投资

> [!INFO] 📌 一句话定义
> **VC = Venture Capital（风险投资 / 创业投资）**，是给"早期创业公司"投钱、换取股份的机构和个人。职场里听到"VC"，通常指三样东西：
>
> **一个行业（投早期创业公司的生意）、一类机构（红杉 / IDG / 经纬等）、一群职业（投资人 / 分析师 / 投资经理）。**

---

## 一、VC 到底是什么

### 1.1 用一句话理解 VC

> **VC 做的事情：用一笔钱，换一家还没长大的公司的一部分股份，赌它以后变成巨头，然后靠股份赚大钱。**

- 你借给朋友钱 → 你拿回本金 + 利息（这是**借钱**）；
- 你给一家创业公司投钱 → 你不拿利息，而是拿走它的一部分股份，公司做大后股份值钱，你卖掉赚差价（这是**投资**）。

### 1.2 职场里"VC"指什么

| 说法 | 具体指 |
|------|--------|
| **VC 行业** | 专门投资早期创业公司的一门生意 |
| **VC 机构** | 红杉资本、IDG、经纬创投、真格基金、创新工场…… |
| **VC 职业** | 投资经理、分析师、合伙人（天天看项目、看人、看赛道） |
| **VC 轮 / 拿 VC** | 公司拿到了风险投资机构的钱（融资） |

> 💡 **<span style="color:#2980b9">记住一个画面：</span>** 创业者带着 BP（商业计划书）去讲自己的创业点子，投资人觉得靠谱就给钱换股份——那个"给钱的"就是 VC。

---

## 二、VC 是怎么运作的（钱从哪来、到哪去）

### 2.1 完整的钱流动线

```
有钱人/机构（LP：出钱的"金主爸爸"）
      ↓ 把钱交给
VC 基金（GP：负责投资决策的"管家"）
      ↓ 选中公司投进去
创业公司（拿钱换股份，拼命做大）
      ↓ 公司做大/上市/被收购
退出赚钱（IPO 上市 / 并购 / 老股转让）
      ↓ 赚的钱
按比例分回给 LP 和 GP
```

> 📊 **<span style="color:#e67e22">两个缩写先记牢：</span>** **LP**（Limited Partner，出钱不决策的金主）和 **GP**（General Partner，负责挑项目、做决策的基金管理人）。

### 2.2 融资轮次（VC 投的是哪个阶段）

| 轮次 | 公司状态 | 谁在投 |
|------|---------|--------|
| **天使轮** | 只有一个 idea，可能还没产品 | 天使投资人 / 天使基金 |
| **A 轮** | 产品做出来了，在找商业模式 | 早期 VC |
| **B 轮** | 模式被验证，要快速扩张 | VC / 部分 PE |
| **C、D 轮及以后** | 公司很大了，准备上市 | PE / 大机构 |

> 🔥 **<span style="color:#e74c3c">VC 的核心赌注：</span>** 投 10 家公司，可能 8 家倒闭、1 家平平、1 家成为巨头——**用那 1 家的暴赚，覆盖其他 9 家的亏损**。所以 VC 看的是"万一成了能赚多少倍"，而不是"稳不稳"。

## 三、职场里 VC 这个词怎么用

### 3.1 日常说法

| 场景 | 例句 |
|------|------|
| 聊行业 | "AI 是这两年 VC 最看好的赛道。" |
| 聊公司 | "我们公司去年拿了 VC 融资，估值翻了三倍。" |
| 聊项目 | "这个项目方向不错，可以去接触一下 VC。" |
| 聊职业 | "我想去 VC 当投资分析师，天天看项目。" |

### 3.2 为什么上市公司 / 大厂也提 VC

- **创业黑马**这类上市公司，本身可能就是很多创业公司的"投资方 / 孵化方"（A 股公司常设产业基金投早期项目）；
- 大厂也都有自己的投资部门（战略投资，叫"CVC"），到处投自己生态里的公司；
- 所以即使你在成熟公司，"VC"照样会从你 mentor / 领导嘴里冒出来。

> 📊 **<span style="color:#e67e22">一个规律：</span>** 公司越大越要"对外投资"——**不是它钱多烧不完，而是不投就会被生态边缘化**。所以上市公司、大厂的财报里，经常能看到"投资收益"这一项。

> 💡 **<span style="color:#2980b9">放到你的岗位上理解：</span>** 图灵学术这类业务线，公司要扩张、要搞流量、要做产品，背后都要花钱——**钱从哪来、够不够烧、值不值，背后全是 VC 那套"算估值、看回报"的逻辑**。听懂 VC，就能听懂公司为什么会做某些决定。

## 四、VC 和其他投资概念的区别（别搞混）

| 概念 | 全称 | 投什么 | 一句话区分 |
|------|------|--------|-----------|
| **天使投资** | Angel | 最早期的 idea | 比 VC 更早、更个人化 |
| **VC** | Venture Capital | 早期创业公司 | 高风险、高回报、赌爆发 |
| **PE** | Private Equity | 成熟/拟上市公司 | 公司很稳了才进，低风险 |
| **FA** | Financial Advisor | 不投钱，做中介 | 帮公司找钱的"红娘"，收佣金 |
| **CVC** | Corporate VC | 大厂战略投资 | 公司拿自己的钱投生态 |

> ⚠️ **<span style="color:#e74c3c">最容易混的两个：</span>** **VC 投"很早期"的创业公司，PE 投"快上市"的大公司**。一个赌爆发，一个图稳当。

## 五、对实习生 / 新人意味着什么

### 5.1 在不同公司实习，VC 离你多近

| 你在哪实习 | VC 和你的关系 |
|-----------|--------------|
| **创业公司** | 公司的钱很可能就是 VC 投的，你天天用的办公位、发的工资，背后有 VC 的影子 |
| **大厂 / 上市公司** | 公司的战投部 / 产业基金在做 CVC，相关岗位会频繁提 VC |
| **投行 / 咨询 / VC/PE 机构** | VC 就是你的核心业务，天天看 BP、做行业研究 |

### 5.2 想进 VC 行业，门槛长什么样

- 常见路径：名校背景 → 投行 / 咨询 / 互联网大厂锻炼 → 转 VC 分析师；
- 核心能力：行业研究、财务分析、看人（判断创始人）、写投资备忘录；
- 实习生的活：做行业研究、整理竞品数据、跟项目、写会议纪要。

> 🔥 **<span style="color:#e74c3c">残酷的现实：</span>** VC 校招名额极少，很多头部机构一年只招个位数新人。**别把它当唯一出路，而要当成"加分视角"**——懂 VC 的思维，放在营销、运营、产品任何岗位上都是稀缺能力。

> 📊 **<span style="color:#e67e22">提醒一句：</span>** VC 岗位很少，门槛高，但"了解 VC 怎么看项目"这个能力，放在**任何岗位的面试里都很加分**——因为它代表你能站在"钱的角度"看业务。

## 六、VC 相关的必懂名词（一次看清）

| 名词 | 意思 |
|------|------|
| **BP** | Business Plan，商业计划书，创业者给投资人看的"项目说明书" |
| **DD** | Due Diligence，尽职调查，投资前把公司里里外外查一遍 |
| **TS** | Term Sheet，投资条款清单，双方谈好条件的"意向书" |
| **估值** | 这家公司值多少钱，决定 VC 投多少钱换多少股份 |
| **独角兽** | 估值超过 10 亿美元的未上市公司 |
| **IPO** | 公司上市，VC 退出的最理想通道 |
| **退出** | VC 把股份变成现金（上市 / 被收购 / 转让），赚不赚钱就看这一下 |

> 📌 **<span style="color:#2980b9">看新闻看懂一半：</span>** 只要看到"XX 公司完成 X 轮融资、估值 X 亿、投资方是 XX VC"——用上面这张表，就能翻译出这段新闻的全部信息。

## 七、一句话总结

> **VC 是"拿钱赌未来"的生意：用钱换创业公司股份，赌它变成巨头，靠退出赚大钱。**
>
> 💡 **<span style="color:#2980b9">翻译成人话：</span>** VC 永远在问三个数字——**市场多大（天花板）、增长多快（增速）、回报几倍（倍数）**。把这套"三看"用到你自己的岗位上，就是高手的思维方式。
>
> 听懂 VC，从三个角度入手：
> 1. **它是行业**：专门投早期创业公司的赛道；
> 2. **它是机构/职业**：红杉、IDG、投资经理、分析师；
> 3. **它是视角**：站在"钱和回报"的角度看业务——**这和 [[ROI-职场投入产出比]] 是同一套底层思维：投入的钱，能不能换来更大的回报。**
>
> 不需要去 VC 上班，但听懂 VC，你就能听懂公司一半的战略决策。
