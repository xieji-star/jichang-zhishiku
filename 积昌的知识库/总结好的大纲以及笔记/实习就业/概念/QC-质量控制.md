# 🔍 QC — 质量控制

> [!INFO] 📌 一句话定义
> **QC = Quality Control（质量控制 / 品质控制 / 品控）**，是求职市场上很常见的一类岗位。通俗说就是**"质检 / 把关"**：
>
> **负责通过检验、测试、监督等手段，确保产品（或服务）的质量符合标准，把不合格的东西拦下来，不让它流到客户手里。**

---

## 一、QC 到底是什么

### 1.1 用一句话理解

- 工厂生产 100 个零件，**QC 负责抽查 / 全检，把不合格的那几个挑出来**；
- 电商仓库进了一批货，**QC 负责验货，发现瑕疵就退货或返工**；
- 一句话：**QC 是产品和客户的"最后一道守门员"——质量好不好，QC 说了算（或最有发言权）。**

### 1.2 QC 这个词的来源

| 英文 | 中文 | 意思 |
|------|------|------|
| **Q**uality | 质量 | 好到什么程度 |
| **C**ontrol | 控制 / 把关 | 管住、拦住、纠偏 |

> 💡 **<span style="color:#2980b9">核心动作只有三个：</span>** **检（检验）→ 判（判定合不合格）→ 拦（拦截不良品、推动整改）**。QC 干的就是这三件事。

---

## 二、QC 在哪些行业最常出现

> 📊 **<span style="color:#e67e22">QC 不是某一行特有的，而是"有产品就有质检"。</span>** 但不同行业叫法和内容略有差异：

| 行业 | 常见叫法 | 主要干什么 |
|------|---------|-----------|
| **制造业 / 工厂**（最主流） | 质检员、品检、QC 工程师 | 来料、制程、成品检验 |
| **电商 / 供应链** | 品控专员、验货员 | 供应商验货、仓库抽检 |
| **食品 / 医药** | QC 化验员、检验员 | 成分、微生物、合规检测（常需持证） |
| **服装 / 外贸** | 跟单 QC、查货员 | 大货验货、出货前查货 |
| **建筑工程** | 质量员、质检员 | 施工质量监督、验收 |
| **软件 / 互联网** | （一般不叫 QC，叫）测试工程师 | 功能 / 性能 / 兼容性测试 |

> 🔥 **<span style="color:#e74c3c">求职提醒：</span>** 互联网公司基本不叫 QC，而是叫"测试 / QA / 质量保障"。**如果你在 JD 上看到"QC"两个字，大概率是制造业、工厂、供应链、外贸类公司。**

---

## 三、QC 的日常工作（工厂体系最典型）

工厂里的 QC 通常按"检验环节"分四类，求职时看 JD 就能对上号：

| 简称 | 全称 | 中文 | 在哪个环节查 |
|------|------|------|------------|
| **IQC** | Incoming QC | 来料检验 | 原料 / 零配件进厂时 |
| **IPQC** | In Process QC | 制程检验 | 生产过程中巡检、抽检 |
| **FQC** | Final QC | 成品检验 | 成品做完后的终检 |
| **OQC** | Outgoing QC | 出货检验 | 出货前最后把关 |

> 💡 **<span style="color:#2980b9">举个例子：</span>** 一家做手机的工厂——
> - **IQC**：供应商送来的屏幕、电池，先抽检合格才让入库；
> - **IPQC**：生产线组装时，每隔一段时间抽几台，看有没有装歪、漏装；
> - **FQC**：整机装完，全功能测一遍（开机、摄像头、按键）；
> - **OQC**：打包发货前，再按客户要求抽检一次，确认没问题才出库。

### QC 日常还要做这些事

- 📋 **填检验记录**：写检验报告、不合格品台账，**所有判断都要留痕**；
- 🚨 **处理不良品**：贴红标、隔离、退货或返工，并跟进处理结果；
- 📣 **反馈质量问题**：把问题反馈给生产 / 供应商，推动改进；
- 📏 **用检具量具**：卡尺、千分尺、二次元、检测仪器，以及**按抽样标准（如 AQL）决定抽多少**。

## 四、QC vs QA 的区别（面试必考、求职必懂！）

> 🔥 **<span style="color:#e74c3c">这是 QC 相关面试里最常被问的问题，也是求职者最容易搞混的。</span>**

| 对比项 | **QC（质量控制）** | **QA（质量保证）** |
|--------|-------------------|-------------------|
| 通俗理解 | **质检员——发现问题** | **体系师——预防问题** |
| 核心动作 | 检验、把关、拦截不良品 | 建流程、定标准、审核体系 |
| 面向对象 | **产品 / 货物** | **流程 / 体系 / 人** |
| 工作方式 | 用检具去查、去测 | 写文件、做培训、搞审计 |
| 一句话 | **"查出坏的"** | **"让坏的少发生"** |

> 📌 **<span style="color:#2980b9">最好记的画面：</span>** 
> - **QC 像"交警查车"**——车开过来，拦下来查有没有问题；
> - **QA 像"修路 + 立交规"**——把路修平、把交规定好，让车少出事故。
>
> **QC 查车，QA 修路。** 一个治"已发生"，一个治"未发生"。

> 💡 **<span style="color:#e67e22">求职小贴士：</span>** 很多公司会把 QC / QA 混着叫（甚至招 QA 挂 QC 的名），面试时**一定问清楚："这个岗位是偏检验（QC），还是偏体系流程（QA）？"** 两者日常工作差别很大。

## 五、QC 的职业发展与薪资

### 5.1 发展路径

```
检验员 / QC 技术员 → QC 工程师 → 质量主管 → 质量经理 → 质量总监
（横向可转：QA、供应链管理、生产管理、采购验厂）
```

### 5.2 薪资水平（大致参考）

| 阶段 | 大致月薪 | 说明 |
|------|---------|------|
| **一线检验员** | 4k ~ 7k | 制造业入门，学历要求不高，靠加班 |
| **QC 工程师** | 7k ~ 12k | 会体系、懂统计、能对接客户审核 |
| **技术型 QC**（医药 / 精密制造） | 10k ~ 20k+ | 需持证（如化验员证）、专业门槛高 |
| **质量经理 / 总监** | 20k ~ 50k+ | 管理全厂质量体系，背质量指标 |

> ⚠️ **<span style="color:#e74c3c">两个真相：</span>**
> 1. **纯检验的 QC 天花板有限**——如果你只做"每天抽检填表"，几年后容易遇到瓶颈；
> 2. **"会体系 + 会数据 + 会沟通"的 QC 很值钱**——能参与 SQE、体系审核、客户投诉处理、用 [[ROI-职场投入产出比]] 思维推动质量改进的 QC，晋升和薪资都明显更高。

## 六、求职者怎么看 QC 岗位（面试 / 简历实战）

### 6.1 面试常被问的问题

- **"发现不合格品，但生产催着出货，怎么办？"**
  👉 考察原则性 + 沟通：先按标准隔离、标识，再上报 + 协调评审（特采要签字担责），**不能私自放行**；
- **"QC 和 QA 有什么区别？"**
  👉 答"QC 查产品、QA 建体系"即可过关（见上文第四节）；
- **"上一份工作里你发现过什么质量问题？怎么处理的？"**
  👉 用 **STAR 法则**：背景 → 任务 → 行动 → 结果（最好带数据，如"拦截了 3000 件不良品，退货率降 2%"）；
- **"你能接受倒班 / 加班 / 下车间吗？"**
  👉 制造业 QC 常需跟产线，**事先想清楚再答**。

### 6.2 简历里怎么写 QC 经历

- ❌ "负责来料检验"
- ✅ **<span style="color:#e67e22">"负责来料检验（IQC），月检 500 批次，拦截不合格物料 27 批，推动 3 家供应商整改，来料合格率从 96% 提升至 99.5%"</span>**

> 📊 **<span style="color:#e67e22">记住：写 QC 简历，数字比形容词值钱。</span>** 检了多少批、拦了多少不良、把合格率 / 退货率提了多少——**把这些写出来，才有竞争力。**

### 6.3 适合什么样的人

| 适合 | 不太适合 |
|------|---------|
| 细心、有耐心、爱较真 | 坐不住、粗枝大叶 |
| 有原则、敢说不（对质量问题） | 怕得罪人、和稀泥 |
| 愿意跑车间 / 一线 | 只接受纯坐办公室 |
| 想往制造业、供应链深耕 | 想走纯互联网 / 坐班路线 |

## 七、一句话总结

> **QC = 质量控制 = 质检把关，是"有产品就有需求"的岗位，核心就三个字：检、判、拦。**
>
> 💡 **<span style="color:#2980b9">求职时记住三句话：</span>**
> 1. **JD 上写 QC，大概率是制造业 / 工厂 / 供应链**，互联网一般叫"测试 / 质量保障"；
> 2. **面试先问清"偏检验还是偏体系"**——QC（查产品）和 QA（建体系）差别很大；
> 3. **把"检了多少、拦了多少、提升了多少"写进简历**，QC 经历也能很亮眼。
>
> 🔥 **<span style="color:#e74c3c">再补一句：</span>** 会查（QC）+ 会建体系（QA）+ 会算账（[[ROI-职场投入产出比]]）的人，才是质量领域真正值钱的人。
