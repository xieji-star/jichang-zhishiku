# 💹 IPO — 首次公开募股

> [!INFO] 📌 一句话定义
> **IPO（Initial Public Offering，首次公开募股）= 一家私人公司第一次把股份卖给公众，从而变成"上市公司"的过程。**
>
> 🔥 **<span style="color:#e74c3c">一句话：</span>** IPO 就是公司**"从关起门来自己玩，到打开门向全世界卖股票"**的那一步——**卖的不是产品，是"你这家公司的所有权（股份）"**。

---

## 一、IPO 到底是什么

### 1.1 用一句话理解

- **上市前**：公司是私人的，股份只在创始人、员工、[[VC-风险投资]]等少数人手里，普通人买不到；
- **IPO 后**：公司把一部分股份**拆成一张张股票，放到交易所**（如上交所、深交所、港交所、纳斯达克）**公开买卖**，任何人都能买；
- **IPO = 公司第一次"公开发行股票"**，所以才叫 **Initial（首次）Public（公开）Offering（发行/募股）**。

### 1.2 IPO 前后，公司发生了什么变化

| 维度 | 上市前（私人公司） | 上市后（公众公司） |
|------|------------------|------------------|
| **股份归属** | 少数创始人/机构 | 广大公众都能买 |
| **钱从哪来** | 靠融资（[[VC-风险投资]]）、借款、利润 | **可以直接向市场"卖股份"融资** |
| **信息披露** | 基本不公开 | **必须定期公开财报**（季报/年报） |
| **监管** | 几乎没有外部监管 | 被证监会、交易所严格盯着 |
| **治理** | 创始人说了算 | 要有[[高管-公司最高管理层]]、独立董事、股东大会 |
| **老板身价** | 账面估值，难变现 | **市值随股价实时变动，是"可流通的财富"** |

> 💡 **<span style="color:#2980b9">记住一个画面：</span>** 上市前公司像"一家私人蛋糕店"，只有老板和几个朋友能吃；**IPO 就是把它变成"在交易所明码标价、人人都能来买一块的上市公司"**——老板瞬间有了"公开的身价表"（市值），但也要把账本摊开给所有人看。

---

## 二、公司为什么要 IPO（四大动机）

### 2.1 为了"融资"（最直接目的）💰

- 上市能一次性募集**大量现金**，且**不需要还本、不需要付利息**（卖股份换钱，比借钱轻松）；
- 这笔钱用来**扩产、研发、并购、还债**——是公司"加弹药"最猛的方式。

### 2.2 为了让"早期投资人/创始人"套现（退出的主通道）

- **[[VC-风险投资]] 的终极目标就是"上市退出"**——公司上市后，VC 手里的股权变成可卖股票，**可以套现离场**；
- 创始人也终于能把"纸面身价"变成"真金白银"。

### 2.3 为了"品牌"和"信用背书"

- "上市公司"四个字本身是**金字招牌**：更易招人、更易贷款、更易谈合作；
- 股价是"免费广告"，大众都能看到这家公司。

### 2.4 为了"用股票做并购和激励"

- 上市后，公司可以用**股票（而非现金）去收购别的公司**；
- 可以给员工发**股权激励**（期权/限制性股票）——**用"未来"绑定人才**，而且普通员工也能分享。

> 🔥 **<span style="color:#e74c3c">本质：</span>** 公司 IPO 的冲动，往往不是"缺钱"，而是"**让老板和投资人的纸面财富变成真钱**"＋"**以后能永远用股票换钱、换人、换公司**"。这和 [[ROI-职场投入产出比]] 里"投资要能变现"是同一逻辑。

## 三、IPO 的完整流程（一步步走）

### 3.1 上市一路要过的关卡

```
选中介（投行/保荐） → 尽职调查 → 整改规范 → 报招股书
   → 监管审核（证监会/交易所） → 路演推介 → 定价 → 申购/打新
   → 上市敲钟 → 正式交易
```

### 3.2 关键节点详解

| 步骤 | 干什么 | 常见黑话 |
|------|--------|---------|
| **① 选投行/保荐** | 请券商当"承销商/保荐人"，负责帮它卖股票、把守合规 | 承销商、保荐人、主承销商 |
| **② 尽职调查** | 券商、律所、会计所把公司"扒个底朝天"，看有没有财务雷 | 尽调、D.D. |
| **③ 报招股书** | 把公司一切（业务、财报、风险）写成"招股说明书"给监管 | 招股书、招股说明书 |
| **④ 监管审核** | 证监会/交易所审：够不够资格上市、有没有造假 | 过会、注册制、核准制 |
| **⑤ 路演推介** | 公司团队到处给机构投资者"讲故事"，说服他们买 | 路演、Roadshow |
| **⑥ 定价** | 根据机构认购热度定"发行价"，即"上市后第一天的价格起点" | 发行价、定价、市盈率PE |
| **⑦ 申购/打新** | 散户/机构申购新股，抽签决定谁能买到（中签） | **打新、中签、申购** |
| **⑧ 上市交易** | 敲钟开市，股票在交易所自由买卖 | 敲钟、挂牌、首日 |

> 💡 **<span style="color:#2980b9">一句话：</span>** IPO 是一场"**包装好自己 → 求监管放行 → 求机构买单 → 求股民接盘**"的层层闯关游戏。**前面几关是公司求人，上市后就是市场说了算。**

## 四、IPO 里的各方角色（谁在参与、谁在挣钱）

| 角色 | 是谁 | 干什么 / 图什么 |
|------|------|----------------|
| **发行人（公司）** | 要上市的公司 | 卖股份换钱，最想要"高发行价 + 高市值" |
| **承销商 / 投行** | 券商（如中金、高盛） | 帮卖股票，**按募集金额抽成**（承销费），公司上市它最赚钱 |
| **保荐人** | 券商 | 做"担保人"，对公司合规负责，**出事要连带担责** |
| **中介机构** | 律所、会计师事务所 | 出具法律意见、审计报告，**赚服务费** |
| **监管机构** | 证监会、交易所 | 把关，防止造假、保护散户 |
| **机构投资者** | 基金、保险、社保 | 打新、路演认购，**赚上市后涨幅** |
| **散户（普通股民）** | 你我 | 打新、二级市场买卖，**最容易被"割韭菜"** |
| **战略/基石投资者** | 大厂、大基金 | 上市前承诺认购，**给市场信心、锁定期不能卖** |

> 🎯 **<span style="color:#e67e22">谁最想 IPO？</span>** 最想 IPO 的往往不是公司员工，而是**投行（赚承销费）＋ 早期投资人（要套现）＋ 创始人（要身价）**。**散户是这场游戏的"最后一棒"**——公司上市后，接盘压力就转移到了股民身上。

## 五、行业黑话大全（股民 / 投行黑话）

> 📌 以下黑话是 IPO 语境下**最常听到、最容易听不懂**的术语，逐一拆解。

| 黑话 | 全称 / 直译 | 到底什么意思 |
|------|-----------|-------------|
| **打新** | 打新股 | 申购 IPO 新股，赌上市后能涨 |
| **中签** | 中签率 | 申购后抽签**抽中，能买到新股**（概率极低） |
| **破发** | 跌破发行价 | 上市后股价**低于发行价**，打新者亏钱 |
| **破净** | 跌破净资产 | 股价低于公司每股净资产（比"破发"更惨的信号） |
| **市值** | 市场价值 | 股价 × 总股本 = 公司值多少钱（可流通的"身价"） |
| **市盈率（PE）** | Price/Earnings | 市值 ÷ 净利润，**衡量"股价贵不贵"**，PE 越高泡沫越大 |
| **发行价 / 定价** | — | 上市时定的"初始卖价"，也是打新者认购价 |
| **路演** | Roadshow | 公司团队四处给机构"讲故事、拉认购" |
| **绿鞋机制** | Green Shoe | 承销商稳定股价的"备用手段"，防止上市就暴跌 |
| **基石投资者** | Cornerstone | 上市前承诺大量认购的大机构，给市场信心 |
| **超额认购** | Over-subscription |申购的人太多，倍数超高 = 很火 |
| **限售股 / 解禁** | Restricted shares | 创始人和早期投资人的股票**锁定一段时间不能卖**，到期解锁（解禁）产生抛压 |
| **减持 / 套现** | Share reduction | 大股东把股票卖掉换现金（常被解读为"不看好公司"） |
| **注册制 / 核准制** | — | 两种上市审核制度：注册制更宽松，核准制更严格 |
| **主板 / 科创板 / 创业板 / 北交所** | — | 不同上市板块：主板稳、科创/创业板偏科技成长、北交所偏创新型中小企业 |
| **A股 / 港股 / 美股** | — | 国内 / 香港 / 美国市场，监管和玩法不同 |
| **过会** | 通过发审会 | 公司上市申请**通过监管审核**，获准发行 |
| **超募** | 超额募集 | 实际募到比计划更多的钱（有时是泡沫信号） |
| **割韭菜** | — | 大资金把散户当"韭菜"割，赚散户的钱（详见第六/七部分） |
| **一二级市场** | — | 一级=未上市股权（VC/PE），二级=上市后股票交易 |

> 💡 **<span style="color:#2980b9">给你翻译一句话：</span>** "**这家公司上市就破发，大股东还要减持，散户全被割韭菜了**" = 公司上市后股价跌破发行价、创始人套现离场、普通股民亏惨了。

## 六、IPO 的坑点大全（8 大坑）

> 📌 **<span style="color:#2980b9">总原则：</span>** **"上市" ≠ "公司变好了"**——上市只是"把股权公开交易"这件事。**上市后公司好不好，看的是财报和业务，不看你上市那一刻多风光。**

### 坑 1：打新不是稳赚不赔（破发风险）🔴

**症状：** 以为"打新=抽中就是赚"，结果上市第一天股价**跌破发行价**（破发），倒亏。
**真相：** 以前 A 股打新"稳赚"，现在注册制下**破发已成常态**，尤其高价发行的科创板/港股。**打新也要看公司基本面，不是闭眼申购。**

### 坑 2：上市公司财务造假（最大雷）

**症状：** 上市前为了估值、上市后为了保股价，**虚增收入、隐瞒亏损、美化报表**。
**真相：** 很多公司上市前"财技包装"，上市后业绩变脸。**财报数字再好看，也要看现金流、看真实业务**。典型如 [[净亏损-亏损公司的生存逻辑]] 里探讨的"亏损公司"。

### 坑 3：高发行价 = 割韭菜前兆

**症状：** 发行价定得极高、市盈率 PE 几十上百倍，上市就翻倍，**然后一路阴跌**。
**真相：** 高发行价往往靠"故事"撑起来——**投行和公司想多募钱，把价定高，把风险留给二级市场接盘者**。**看到"超募""高 PE"要警惕。**

### 坑 4：限售股解禁 = 抛压黑洞

**症状：** 上市满 1~3 年，创始人、VC、员工的**限售股到期（解禁）**，疯狂抛售，股价暴跌。
**真相：** **解禁是上市后最大的股价杀手**——知道哪家公司要解禁，就该提前规避。**看"解禁日历"，别在解禁前重仓。**

### 坑 5：大股东趁机减持套现

**症状：** 公司刚上市不久，**大股东/高管就大规模减持（卖股票）**，套现离场。
**真相：** "**创始人都跑了，你还留着？**" 大股东减持往往是**"最了解公司的人已经不看好"**的信号。**盯减持公告。**

### 坑 6：概念炒作上市（上市即巅峰）

**症状：** 公司上市时蹭一个热门"概念"（如 AI、元宇宙），**股价被爆炒到离谱**，然后一地鸡毛。
**真相：** 这和[[概念股-市场题材炒作股]] 是同一套逻辑——**上市题材股最容易"上市即顶点"，估值透支未来好几年**。别追上市首日的暴涨。

### 坑 7：上市前后创始人"对赌/回购"雷

**症状：** 创始人为了上市，和早期投资人签"**对赌协议**"，承诺"几年内上市，否则回购"；结果上市失败，**创始人背巨额债务**。
**真相：** 对赌是把双刃剑——**逼公司冲上市，也把创始人个人身家押上去**。这类公司一旦上市受挫，可能暴雷。（见 [[高管-公司最高管理层]] 里开课吧的教训）

### 坑 8：一二级市场倒挂 / 估值陷阱

**症状：** 公司一级市场（VC/PE 阶段）估值被炒到天上，**上市后二级市场"接不住"这个价**，市值暴跌。
**真相：** **一级市场估值 ≠ 二级市场价值**。很多公司在融资时把估值喊很高，上市后市场不认账，**VC 想套现都套不出去**。这也是 [[VC-风险投资]] 的"退出风险"。

## 七、注意点 / 注意事项（实操避雷清单）

> 📊 **<span style="color:#e67e22">一句话：</span>** 想参与 IPO（打新/买新股），**先看这 6 件事**。

### 7.1 打新时期（申购新股）

- **看发行市盈率（PE）**：同行业里 PE 明显偏高 → 破发风险大；
- **看募资额 / 超募比例**：超募越多，越可能是"为了圈钱"；
- **看公司行业**：夕阳行业、靠补贴/靠政策的，谨慎；
- **判断板块**：科创板/创业板波动大，主板相对稳——**风险偏好不同，选择不同**。

### 7.2 上市初期（次新股）

- **别追首日暴涨**：首日涨停 ≠ 公司好，可能是题材炒作；
- **警惕"开板即高点"**：很多题材料上市后 1~2 天打到高点，随后阴跌；
- **看是否有"绿鞋机制"护盘**：有绿鞋的短期更抗跌（但不是永久的）。

### 7.3 长期持有（看财报）

- ⚠️ **<span style="color:#e74c3c">看现金流，不看纸面利润</span>**：很多公司"账面盈利、现金亏损"，随时暴雷；
- **看真实业务**：毛利率、客户集中度、应收账款，**比"概念"重要一万倍**；
- **看减持与解禁**：大股东减持、限售股解禁日期，是最大的"定时炸弹"。

### 7.4 综合判断这家"刚上市公司"值不值得碰

| 检查项 | 健康信号 | 危险信号 |
|--------|---------|---------|
| **盈利能力** | 真实赚钱、现金流为正 | 靠补贴/靠非经常性损益撑利润 |
| **行业地位** | 所在赛道有护城河 | 纯蹭热点、无核心竞争力 |
| **发行定价** | PE 与同行相当或更低 | PE 高得离谱、超募严重 |
| **股东动作** | 少见减持、有锁定期承诺 | 一上市就大股东减持 |
| **解禁压力** | 近期无大规模解禁 | 解禁潮即将来临 |
| **治理结构** | 有[[高管-公司最高管理层]]、独立董事 | 创始人一言堂、无制衡 |

> 💡 **<span style="color:#2980b9">一句话：</span>** 参与 IPO，记住三条铁律——**① 打新也要看基本面；② 离解禁越近越危险；③ 创始人都减持了，你别接盘。**

## 八、一句话总结

> **IPO = 公司把股权公开卖给公众 = 公司"第一次向全世界卖自己的所有权"。**
>
> 💡 **<span style="color:#2980b9">一句话速记：</span>** **上市 ≠ 变好，上市 = 股权公开交易 + 公开接受监管 + 公开让散户接盘。**
>
> 记住三句话：
> 1. **IPO 是公司融资的第一大方式，也是最爽的退出通道**——但"爽"的是创始人和投资人，**风险往往抛给后进场的散户**；
> 2. **打新不是稳赚，破发已常态化**——评判公司靠基本面（现金流、真实业务），不靠"上市光环"；
> 3. **解禁和减持是上市后的最大杀手**——最懂公司的创始人都在卖，说明这公司不对劲。
>
> 用 [[ROI-职场投入产出比]] 的话讲：**IPO 是"一场把'纸面身价'变成'真钱'的资本游戏"，做这笔投资前，先算清"这个价格（PE），买的是公司的未来，还是买别人割你的镰刀"。** 而决定一家公司将来收不收割、能不能好好经营，看的是它有没有 [[高管-公司最高管理层]] 的制衡，和它是不是靠 [[VC-风险投资]] 输血活着。

- [[高管-公司最高管理层]] — 上市要求建立董事会、独董、信息披露，治理结构决定公司能不能好好经营
- [[ROI-职场投入产出比]] — 判断"这个发行价（PE）买的是未来，还是接盘的镰刀"
- [[GMV-商品交易总额]] — 用真实经营指标（GMV/营收/毛利）看公司，而非用"概念/市值"看公司
- [[HC-编制名额]] — 公司 IPO 募到钱后才会扩 HC、大规模招人、发股权激励
- [[+1+2-职场上下级层级]] — 上市公司层级更规范，汇报线、治理结构更清晰
