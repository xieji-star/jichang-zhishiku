# 📊 KPI — 关键绩效指标

> [!INFO] 📌 一句话定义
> **KPI（Key Performance Indicator，关键绩效指标）= 公司用来"给员工打分"的一套量化标准**——把你的工作成果翻译成**一个个能算数字的指标**（销售额、完成量、满意度……），到期按这个分数决定你的**奖金、绩效评级、升职、甚至饭碗**。
>
> 🔥 **<span style="color:#e74c3c">一句话：</span>** KPI 就是**"职场里的考试成绩单"**——公司给你出题（定指标），你答题（干活），期末按分数排名，分数决定你能拿多少奖、能不能升级。

---

## 一、KPI 到底是什么

### 1.1 用一句话理解

- **KPI = 把"你干得好不好"这件事，变成一个可以计算、可以比较、可以排名的数字。**
- 它的作用：让公司能**客观地衡量绩效、分配奖金、决定升迁淘汰**——否则"谁干得好"全靠领导主观感觉，没法服众。
- 所以 KPI 的本质是 **"用指标代替感觉"**——**能衡量的，才管得住。**

### 1.2 KPI 的三要素（缺一不可）

| 要素 | 意思 | 反例（不是好 KPI） |
|------|------|-------------------|
| **① 可量化** | 能用数字表达 | "工作要努力" ❌ → "月成交 50 万" ✅ |
| **② 有时限** | 有明确的考核周期 | "把业绩做好" ❌ → "Q3 内完成" ✅ |
| **③ 反映目标** | 指标要真的代表"做成这件事" | "打了多少电话" ❌（过程） → "签了多少单" ✅（结果） |

### 1.3 KPI 是怎么定出来的（层层拆解）

> 🔺 **KPI 是"从上往下拆"出来的——公司大目标 → 部门目标 → 你的个人 KPI。**

```
公司年度目标（如：营收增长 30%）
   ↓ 拆解
部门目标（如：销售部业绩增长 40%）
   ↓ 拆解
团队目标（如：华东大区增长 45%）
   ↓ 拆解
你的个人 KPI（如：你负责的客户业绩增长 50%）
```

> ⚠️ **<span style="color:#e74c3c">注意这里藏着一个大坑：</span>** **层层拆解的过程，往往变成"层层加码"**——公司要 30%，拆到部门变 35%，到团队变 40%，到你这儿变成 50%。这就是为什么很多人觉得"我的 KPI 根本不可能完成"（详见第六部分坑 2）。

### 1.4 常见的 KPI 类型

| 类型 | 例子 | 常见岗位 |
|------|------|---------|
| **业绩类** | 销售额、订单量、[[GMV-商品交易总额]]、回款额 | 销售、商务、电商运营 |
| **效率类** | 响应时长、处理工单数、产出效率 | 客服、运维、流水线 |
| **质量类** | 良品率、bug 数、投诉率、差错率 | 生产、研发、质检（见 [[QC-质量控制]]） |
| **过程类** | 拜访客户数、电话量、活动场次 | 地推、BD、市场 |
| **团队/管理类** | 团队留存率、下属成长、项目交付率 | 管理者 |

## 二、KPI 和它的"亲戚们"（最容易混）

> 📌 **<span style="color:#2980b9">KPI 不是孤零零的概念，它和 OKR、360、绩效评级经常一起出现，必须分清：</span>**

| 概念 | 全称 | 一句话 | 和 KPI 的关系 |
|------|------|--------|--------------|
| **KPI** | Key Performance Indicator | 关键绩效指标，**衡量结果、和奖金强挂钩** | 本体 |
| **OKR** | Objectives & Key Results | 目标与关键结果，**定挑战性目标、不和奖金直接挂钩** | **最常见的一对"冤家"**，KPI 要"做到"，OKR 要"超越" |
| **360 评估** | 360° Feedback | 让**上级、同事、下属、客户**全方位评价你 | 定性评价，常和 KPI（定量）配合使用 |
| **绩效评级** | Performance Rating | 考核后给你打个等级（S/A/B/C/D） | KPI 是"打分依据"，评级是"打分结果" |
| **MBO** | Management by Objectives | 目标管理，KPI 的"老祖宗" | KPI 是 MBO 的量化和细化 |

### KPI vs OKR：一句话分清

| | **KPI** | **OKR** |
|---|---------|---------|
| **目的** | **考核**（衡量你做得够不够） | **牵引**（激励大家够一够更高的目标） |
| **定法** | 自上而下**压**下来 | 上下结合**谈**出来 |
| **和奖金** | **强挂钩** | 通常**不直接挂钩** |
| **完成度** | 100% 完成才算好 | 完成 70% 就算优秀（因为是挑战目标） |
| **气质** | "必须做到" | "鼓励超越" |

> 💡 **<span style="color:#2980b9">记住一个画面：</span>** **KPI 是"及格线"（做不到要扣钱），OKR 是"冲刺线"（做到了很牛，做不到也不算错）**。很多公司两个一起用——**用 KPI 保底，用 OKR 拉高**。

## 三、KPI 怎么影响你（和钱包的关系）

### 3.1 KPI 决定你的"绩效工资 / 奖金"

> 📊 **<span style="color:#e67e22">大多数公司，工资 = 底薪 + 绩效工资（或奖金），而绩效部分完全看 KPI 完成度。</span>**

| KPI 完成率 | 常见结果 |
|-----------|---------|
| **超额完成（≥100%）** | 拿满甚至超额奖金、评优、升职加薪倾斜 |
| **基本完成（80%~100%）** | 拿大部分奖金、评级中规中矩 |
| **未完成（<80%）** | 扣绩效、评级差、被约谈 |
| **长期垫底** | 进入"改进计划（PIP）"→ 可能被淘汰 |

### 3.2 KPI → 绩效评级 → 排名 → 淘汰

```
KPI 完成度 → 绩效评级（S/A/B/C/D）
   ↓ 强制分布（如"361"：30% 优 + 60% 中 + 10% 差）
排名 → 末位淘汰（垫底的可能被优化）
```

> 🔥 **<span style="color:#e74c3c">关键机制："强制分布"。</span>** 很多大公司（如阿里的"361"、华为体系）**强制要求**：一个团队里**必须有 30% 是优秀、60% 是普通、10% 是垫底**。这意味着——**哪怕你干得不差，只要团队里有人比你强，你也可能被排进那 10%**。这是 KPI 体系里最让人焦虑的地方（详见坑 4）。

## 四、行业黑话 / 圈内行话

> 🗣️ **这些话说出来"一听就是打过工的人"：**

| 黑话 | 实际意思 |
|------|---------|
| **背 KPI / 扛 KPI** | 承担某个考核指标（"我这个季度背着 500 万的 KPI"） |
| **完成率 / 达成率** | KPI 完成百分比（"我这个月达成率 120%"） |
| **拆分 KPI** | 把大目标分给下面的人，一人扛一块 |
| **层层加码** | 目标从公司往下拆时，越拆越高，到个人已不现实 |
| **KPI 导向** | 一切围着考核指标转，只做"算分的事" |
| **刷 KPI / KPI 造假** | 为了完成指标而注水、刷单、走形式 |
| **361** | 阿里式绩效强制分布：30% 优 / 60% 中 / 10% 差 |
| **绩效评级** | S/A/B/C/D、或 3.75/3.5/3.25（分数越高越好） |
| **绩效面谈** | 领导跟你一对一谈考核结果（表扬 or 敲打） |
| **校准会（Calibration）** | 各主管开会统一打分口径，避免"你这个主管手松、他那个手紧" |
| **末位淘汰** | 排名垫底的人被优化掉 |
| **PIP** | 绩效改进计划（Performance Improvement Plan），**常被当作"劝退前的最后一步"** |
| **拿结果** | 用 KPI 完成情况说话（"我只看结果"） |
| **KPI 文化** | 指一家公司**唯指标论**、内卷、只做考核事的风气（略带贬义） |

## 五、常见坑点 / 陷阱

> ⚠️ **<span style="color:#e74c3c">总原则：</span>** KPI 是把**双刃剑**——用好了能激励人，用歪了会**让所有人"动作变形"**。下面这些坑，无论是员工还是管理者都躲不开。

### 坑 1：KPI 一指标化，员工就"只做算分的事" 🔴

**症状：** 考核什么，员工就只干什么——**不算分的事（帮同事、做优化、想创新）没人做**，团队协作变差。
**真相：** 这叫**"指标替代目标"**——**手段（完成指标）变成了目的，真正的目标（把业务做好）反而没人管**。比如只考核"通话时长"的客服，就会**故意拖时长**而不是解决问题。

### 坑 2：层层加码——到你这儿的指标根本完不成

**症状：** 公司要 30% 增长，一路拆下来，你的个人指标变成了 50%，**拼死也完不成**。
**真相：** **每一层为了"保险"都会多加一点**，加上留缓冲、防意外，最终到基层就成了"不可能任务"。**面试/入职时一定要问清：KPI 是怎么定的、历史上大家平均能完成多少（完成率中位数）。**

### 坑 3：单一指标 → 钻空子 / 数据注水

**症状：** 只看销量，就有人**刷单、压货给经销商**；只看 bug 数，就有人**把 bug 拆成小 bug 少记**；只看产量，就有人**牺牲质量冲量**。
**真相：** **任何单一 KPI 都会被"优化"到失真**——这就是"**上有政策，下有对策**"。看 KPI 要**看一组、看搭配**，别被单一数字骗了。

### 坑 4：强制分布——"干得不差"也可能垫底

**症状：** 你明明完成了 KPI，但团队里必须有人被评为"差"，**结果你成了那 10%**。
**真相：** **强制分布下，你的绩效不仅取决于你干得怎样，还取决于"你比同事干得怎样"**——**相对排名，而非绝对表现**。这是 KPI 体系里最反人性、最让人焦虑的部分。

### 坑 5：KPI 是"背锅指标"——不可控却要你负责

**症状：** 公司给你定的指标，**受很多你控制不了的因素影响**（市场行情、别的部门配合、政策变化），做不到还要扣你钱。
**真相：** 好 KPI 应该"**跳一跳够得着**"，且**大部分在你可控范围内**。如果指标全凭运气或别人脸色，那就是**把风险转嫁给员工**。

### 坑 6：只考核结果，不管过程——短期主义

**症状：** 为了季度 KPI，**砍掉研发、砍掉投入、透支未来**，短期数据好看，长期把公司做坏。
**真相：** **"唯结果论"会逼出短期行为**。这也是为什么很多公司引入 OKR、平衡计分卡来补充——**既要看当下结果，也要看长期健康**。

### 坑 7：KPI 和 OKR 混着用，用错了更糟

**症状：** 公司嘴上说"我们搞 OKR"，实际还是**把 OKR 当 KPI 来考核**，完不成就扣钱。
**真相：** **"假 OKR、真 KPI"** 是最常见的伪敏捷——**OKR 一旦和奖金强挂钩，就失去了"鼓励挑战"的意义**，大家都会把目标定得很低好完成。

### 坑 8：换领导 = 换 KPI，一年白干

**症状：** 你好不容易把上一任领导的指标做起来，新领导一来，**推翻重来、换一套 KPI**。
**真相：** KPI 是**领导意志的延伸**——这也是职场中"站队""跟对领导"重要的原因之一。**KPI 的稳定性，取决于组织的稳定性和领导的稳定性。**

### 坑 9：PIP 可能不是"帮你改进"，而是"劝退流程"

**症状：** 被拉进 PIP（绩效改进计划），以为还有机会，结果**过一两个月就被"优化"了**。
**真相：** **PIP 在法律上常常是公司为"合法辞退"收集证据的一步**。被拉进 PIP 时，**要立刻评估"是争取留下，还是准备找下家"**。

## 六、比喻 / 例子

> 🎓 **比喻 1：KPI = 期末考试分数**
> 公司是学校，KPI 是**期末考卷**——学期结束按分数排名，分数高发奖状（奖金）、能升年级（升职），分数低要补考（约谈）、甚至留级（淘汰）。**但考题（指标）是学校出的，你只能按题答，答不完就是答不完。**

> 🚕 **比喻 2：KPI = 网约车司机的"接单量 + 评分"**
> 平台给司机定指标：**每天接够 N 单、评分不低于 4.9**。达标了**优先派好单、给奖励**；不达标就**减少派单、降权重**。司机跑得再辛苦，平台只看这两个数字——**这就是 KPI 的逻辑。**

> 📞 **例子（不同岗位的真实 KPI）：**
> - **销售**：月销售额 50 万、新客户 10 个；
> - **客服**：满意度 ≥ 95%、首次响应 < 30 秒、解决率 ≥ 90%；
> - **电商运营**：店铺 [[GMV-商品交易总额]] 环比增长 20%；
> - **程序员**：需求按时交付率、线上 bug 数、代码评审参与度；
> - **产品经理**（见 [[PM-产品经理与项目经理]]）：所负责功能的 DAU、留存率、上线准时率。

## 七、一句话总结

> **KPI = 公司给员工打的"期末考卷"——把工作翻译成可算的数字，按数字决定你的奖金、评级、升职和去留。**
>
> 💡 **<span style="color:#2980b9">速记三句话：</span>**
> 1. **KPI 的本质是"用指标代替感觉"**——能衡量的才管得住，但**指标一旦压倒目标，人就会为数字干活**；
> 2. **KPI 是"及格线"，OKR 是"冲刺线"**——KPI 和奖金强挂钩，OKR 不挂钩（但很多公司"假 OKR、真 KPI"）；
> 3. **看 KPI 要防三个坑**——层层加码（指标不现实）、强制分布（干得好也可能垫底）、单一指标（必被钻空子）。
>
> 用 [[ROI-职场投入产出比]] 的思路：**KPI 是公司衡量你的"尺子"，也是你和公司之间的"对赌"——用自己的努力换对等的奖金与晋升。看清这把尺子"量得准不准、对不对得上你的付出"，比闷头刷指标重要得多。**
