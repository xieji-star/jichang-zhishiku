> - **讲师**：浩源学长
> - **时间**：2026年7月18日

## 一、💎 开篇

### 1.1 开场说明

- 第六天在线约**400位同学**（从第一天800人逐日递减）
- 今天采用**连麦形式**（竖屏直播），逐个诊断账号
- 连麦前需要准备以下内容：

#### 📋 连麦准备框架

| 序号 | 准备项 | 说明 |
|------|--------|------|
| 1️⃣ | **账号定位** | 一句话概括你的账号想做什么 |
| 2️⃣ | **对标博主** | 跟你有同样定位的博主有哪些？举出具体案例 |
| 3️⃣ | **受众情况分析** | 受众的作息、需求、痛点是什么？ |
| 4️⃣ | **系统描述** | 选题→写作→录制→粗剪→发布→商业化的完整链路 |
| 5️⃣ | **预计遇到的坎儿** | 你觉得可能会遇到哪些困难？ |

### 1.2 连麦规则

- 已写好文档或脑子里有完整框架的同学可以申请连麦
- 按申请顺序逐一连麦诊断
- 每位学员按统一框架汇报（定位→对标→受众→系统→商业化）

## 二、🎙️ 案例一：拖延症/成长焦虑类账号

**学员信息：**
- **定位**：面向18-24岁有成长焦虑但执行力薄弱的大学生和刚毕业学生
- **对标博主**：2323亮晶晶（专做拖延话题的成长类博主）
- **受众**：有成长焦虑、执行力薄弱、认知较窄的大学生
- **用户第一性痛点**：**无法开始**（起步困难）

**学员现有系统：**
- **选题**：精准围绕拖延及如何治疗拖延
- **写作**：从自身经验出发 + 刷相关视频结合对方语言 + 自己给出的方法。有开头留人（固定式模板）、中间给方法（情景化表达 + 承上启下）、结尾鼓励行动
- **类型**：**执行类视频**——跟着视频一步一步做就能完成某件事
- **录制**：手机横屏 + 电脑剪映专业版，第一天用题词器，第二天脱稿（脱稿更自然流畅）
- **发布**：尚未发布（还在剪辑加字幕特效），tag打算打"大学生拖延"
- **商业化规划**：先无偿分享拖延计划表格 → 卖空白计划本 → 卖详细化模板 → 飞书多维表格仪表盘系统 → 后续出健康相关视频卖健康食品

### 🔍 浩源的诊断与建议

#### 📌 问题一：选题太窄

> "拖延只是一个表现出来的**现象**，不是原因。你要讲的是**导致拖延的各种原因**。"

- 拖延的原因可以包括：不自信、自我否定、内耗、想一口气做好、懒、没有规划、不敢面对、不想负责任……
- 分门别类地去讲各种原因导致的拖延
- 不要把"拖延"当作唯一的话题来回讲

#### 📌 问题二：用户画像再定义

> 这类人群叫做"**爱学习的优等生**"——特别爱学习、爱收藏、爱收集有用的东西，但**从来不用**。

- 🐿️ **松鼠比喻**："像冬天囤松果的小松鼠——囤了一堆但就是不吃"
- 这类人爱收藏、爱收集、爱保存有用的视频，但不去使用
- 他们需要的不是大干货分享，而是**执行类视频**（一步一步带着做）
- 解决他们的核心问题：**缺少成功的正反馈**

#### 📌 具体优化建议

| 维度 | 建议内容 |
|------|---------|
| **选题延展** | 从"拖延"延伸到不自信、自我否定、内耗、不敢面对等导致拖延的各种原因 |
| **写作策略** | 继续保持**执行类视频**——小而美，带用户完成一件小事，比如"带大家清理B站收藏夹" |
| **发布时间** | 晚上9:30（可测试调整，看哪一时间段数据最好） |
| **商业化路径** | ① 组织**夸夸打卡群**（进群每晚打卡，互相夸赞）→ ② 电子版拖延规划表 → ③ 实物计划本 → ④ 收费社群 |
| **tag策略** | 干货类视频打精准tag：大学生、拖延、干货分享 |

#### 💡 核心思路

> 用户最大的痛点是**缺乏成功的正反馈**。只要能给到正反馈的东西，对这类群体就是值钱的。

- 夸夸群能解决用户最缺的"成功反馈"
- 通过粉丝群积累私域，再逐步变现
- 执行类视频 + 正反馈闭环 = 这类用户的最佳内容模式

## 三、🎙️ 案例二：恐怖游戏+情感疗愈类账号（闫妮同学）

**学员信息：**
- **定位**：构建恐怖游戏避难所的叙事者——不仅解说恐怖游戏，更以游戏中的压力作为媒介，承接并转化观众现实中的不好情绪，做另类的疗愈
- **对标博主**：B站C君（恐怖游戏方向）+ 抖音阿月（情感疗愈方向）
- **受众**：16-24岁高中生和大学生（80%女生）
- **已有经验**：在这个赛道已经做了两年
- **声音非常有特色**（直播间观众第一反应就是声音好听）

**学员的变现想法：**
- 受众80%是女生 → 选择零食（下饭场景）+ 护肤品（熬夜护肤场景）
- 用自己熬夜剪视频的皮肤对比来做护肤品推广

### 🔍 浩源的诊断与建议

#### 📌 核心问题：变现产品选错了

> "你选择的变现产品是基于'用户是女生'这个泛标签，而不是基于**用户的第一性痛点**。"

- 产品是别人的品牌，不是自己的
- 没有对标案例，商业路径不清晰
- 护肤品变现周期长（要使用→记录→对比）

#### 📌 建议路线：走虚拟IP路线

> "你的声音是最大的资产。把你的声音具象化到虚拟IP上。"

**虚拟IP的优势：**
- 可以出周边产品
- 可以出服务
- 可以走打赏
- 可以做续费频道
- B站上有大量纸片人成功案例

**具体操作建议：**
1. **设计虚拟IP形象**：去淘宝/闲鱼找人设计，或拿AI自己设计一个Live2D形象（几百元可搞定）
2. **形式不变**：原来的恐怖游戏+情感分析内容不变，只是加上虚拟IP
3. **反差感内容**：用很治愈的声音去打恐怖游戏——一边打怪兽一边温柔地和怪兽聊天，去掉恐怖音效换成自己的声音
4. **参考案例**：瓦罗兰特的"娃娃"——用打游戏+纸片人形式，代表普通游戏玩家

**变现路径拓展：**
- 开放打赏和续费频道
- 续费频道可以做情感问题解答 + 打恐怖游戏
- 给Steam独立游戏代言/接广告
- 手机独立游戏推广

> "你的内容是恐怖游戏+情感分析（创作来源），但**虚拟IP才是用户喜欢的根**。需要把声音具象化到虚拟IP上。"

## 四、🎙️ 案例三：旅游+游戏+AI多赛道（cookie同学）

**学员信息：**
- 想同时做两个账号：抖音和小红书不同赛道
  - **小红书**：旅游赛道（老家是文旅城市）
  - **抖音**：游戏赛道（王者荣耀教学，打得不错，可以直播挂小橱窗）
- 还提到对AI大模型有研究，充了会员

### 🔍 浩源的诊断与建议

#### 📌 旅游账号：建议放弃

> "把你们家老家的文旅局的任务揽到自己身上了，他们都做不好，你凭什么能做好？"

- 文旅账号对个人来说非常难做
- 建议放弃旅游赛道

#### 📌 游戏账号：需要找到壁垒

> "打游戏好的人很多，重点在于你能否在普通打游戏还不错的人里面**脱颖而出**，**有没有一个壁垒**。"

- 打游戏好不是独特卖点
- 需要找到用户能记住你的特点（就像刚才声音好听的女生一样让人印象深刻）

#### 📌 AI知识普及：可以尝试

- 推荐参考账号：**秋之2046**
- 这个账号里的任何内容都可以作为口播素材重新普及一遍
- AI赛道很有前景，甚至不用着急变现，**"一定会赚钱"**
- 可以等待秋之2046的变现模式，模仿学习

> 💡 **核心启发**：游戏博主之间的区别在于——你能不能让用户**一下子记住你**。

## 五、🎙️ 案例四：大学生信息差学委（魔法百宝箱同学）

**学员信息：**
- **定位**：面向大一/大二初期对未来有迷茫的大学生，给他们一份新时代自媒体的学生手册
- **对标博主**：皓月学长、圈宁（淡淡风格）、浩源（干货满满）、兔兔糖（信息差）
- **受众痛点**：收到有价值的竞赛信息但不知道怎么着手
- **选题**：分析信息差 + 大学小技巧
- **写作**：先定位想法 → 及时记录灵感 → 定向搜索 → 摘评论区精华问题 → 借助AI工具总结
- **录制**：手机录制 + 平板看稿，找合适机位，不用完全脱稿
- **剪辑**：剪映会员智能剪辑
- **发布**：公众号/小红书图文分享 → 抖音发视频（三步一循环）
- **商业化**：抖音创作者伙伴计划 + 植入自己领域的信息

### 🔍 浩源的诊断与建议

#### 📌 核心定位：在线学委

> "你给我的感觉就是班里边**学委**的感觉——踏实干事。你就是大家的**在线学委**。"

**人设定性：**
- 你就是大家大一大二的**线上学委**
- 负责帮大家检索大一大二能利用的信息差：竞赛、科研、就业求职、实习经验
- 每一条视频都具有实际价值

**内容创作建议：**
1. **场景真实化**：可以在寝室或空教室录，晚自习结束后最后一个走，做一天的收尾总结
2. **内容自然化**：可以多说"废话"，给人活人的感觉，不用太干货
3. **开头高价值**：每条视频开头先抛出一个高价值的信息差
4. **日常元素**：可以加入今天发现学校哪家饭好吃等日常内容

**商业化路径：**
> "你的商业化系统社区是完全够用的。你不需要去带自己的笔记本那些小东西，社区所有产品里面对这类群体有益的，都可以放到你的橱窗里。"

- 直接卖社区的知识库/教育产品
- 保研、考研、就业等产品可以对接专门的学长学姐
- 你负责引流，他们负责转化

## 六、🎙️ 案例五：高三生陪跑社区（需精准定位）

**学员信息：**
- **定位**：从后院取经学来的陪跑社区模式，面向高三学生
- **计划**：返校宣讲宣传社区 → 运营社区 → 做自媒体账号
- **想做的事情**：通过自己的经验帮助高三学生找到适合的学习方法、日常鼓励、学长学姐故事缓解压力

### 🔍 浩源的诊断与建议

#### 📌 问题：定位太太太宽了

> "你的定位宽了之后，你会发现做什么都是对的——做高材生访谈是对的，做经验分享是对的，做提分视频也是对的。**全对的事情就是全错。**"

- 学员是一本学历 → 建议聚焦"**即将面临上专科的同学**"
- 帮他们从专科越级到本科

#### 📌 精准定位建议

> "你的任务就一个：**帮大家把本科考上**，哪怕搭线也要考上。"

**具体建议：**
1. **先上课赚钱**，不要上来就想批量运营社区
2. 先收5个学生，从1月到6月帮他们从专科水平提到本科线
3. 以**网上家教/一对一咨询**形式做
4. 解决核心痛点：学校在二三轮复习时放弃这些学生，只讲难题压轴题，不管基础差的同学

#### 📌 关键原则

> "你的视频内容得**基于用户的认知**——你的用户觉得什么是好才重要，你觉得什么是好不重要。"

- 即将上专科的同学觉得"先背单词"是好内容
- 作为一本学长觉得"先搞定英语阅读"是好内容
- **一定要站在用户的认知水平以内录制他们想要的东西**

> 💡 **案例**：专为即将上专科同学出的"背单词的焚诀"，这个就踩到点子了

## 七、🎙️ 案例六：双非大学生AI工具博主（两条路线选择）

**学员信息：**
- **定位**：教大学生用AI工具和系统思维，破解大学成长信息差，实现非名校逆袭
- **对标**：陶渊明、野藤亚军
- **受众**：二本/普通一本，有焦虑也有行动力的大一大二学生
- **痛点**：在资源有限的环境中如何抹平与顶尖学生的资源差距，获得优质机会
- **写作**：痛点场景+提升认知+三步解决方案的结构
- **录制**：手机+提词器APP，人物场景统一（宿舍）
- **发布**：晚上发布，封面和标题统一，标题明确指向用户身份与痛点

### 🔍 浩源的诊断与建议

#### 📌 核心问题：用户没你想的那么优秀

> "你教的东西有点太高端了——你用的Obsidian、AI工具，这些对于普通双非学生来说门槛太高。"

#### 📌 两条路线选择

| 路线 | 核心 | 重点 | 流量特点 |
|------|------|------|---------|
| **路线A：高设路线** | **吸引力**——我是双非逆袭者，分享我的学习方法 | 让用户主动跟你学习 | 流量不会很好 |
| **路线B：低设路线** | **有用**——基于用户认知的解决方案 | 讲大家能听懂、用得上的 | 流量更大 |

**路线A的具体做法：**
- 人设立高："我是双非但通过努力逆袭了"
- 吸引目标用户跟你学习
- 把高级货（985/211用的方法）改良成双非学生能用的版本
- 做"细糠转换器"——高级方法+亲民化改良

> 💡 **万能公式**："你跟985/211同学学到了一个技能/方法→双非的姐妹们，我改良了一下，你们也能用"

**浩源为什么走亲民路线？**
> "我的人设在外边就是一个普通的大学生学长，我选择走亲民路线。因为前端做流量，把有效信息沉淀到私域里来。"

## 八、🎙️ 案例七：ENTJ/INTJ思维工具博主（极致精准定位）

**学员信息：**
- **定位**：大一新生分享思维工具和心法
- **对标**：浩源（口播形式）+ B站浩宽（构建世界观系列）
- **受众**：有点意识觉醒但缺乏思维工具、纯迷茫的大一学生
- **问题是**：定位还是不够精准

### 🔍 浩源的诊断

#### 📌 识人：你是ENTJ吧？

> "你选择的自媒体赛道和你要做的事情，我都知道你是什么人格。INTJ和ENTJ最喜欢思维工具——觉得整个世界可以结构化。"

**精准定位建议：**
- 不要面向所有大学生
- 只面向大学生中的**ENTJ和INTJ**（"小紫人"）
- 其他MBTI人格对思维工具不感冒，甚至唾弃
- "你只需要吸引跟你一样的ENTJ和INTJ就够了"

> 💡 **极致精准**：可以直接在账号上写"这个账号面向ENTJ和INTJ大学生"

**为什么能这么精准？**
> "抖音和小红书用户很多，你即使再小众也绝对大众。但**千万不要上来就走大众人群路线**。"

## 九、📌 课堂总结与课后作业

### 9.1 今天连麦的共性规律

| 案例 | 核心问题 | 解决方案 |
|------|---------|---------|
| 拖延症 | 选题太窄 | 分门别类讲原因，执行类视频 |
| 恐怖游戏疗愈 | 变现产品选错 | 虚拟IP路线 |
| 旅游+游戏 | 没有壁垒 | 放弃旅游，找独特记忆点 |
| 大学生信息差 | 定位可优化 | 在线学委人设 |
| 高三陪跑 | 定位太宽 | 聚焦"上专科"群体 |
| 双非AI工具 | 用户与内容不匹配 | 选高设/低设路线 |
| 思维工具 | 受众不够精准 | 只面向ENTJ/INTJ |

### 9.2 核心要点总结

1. **拖延是现象不是原因** — 分门别类讲导致拖延的各种原因
2. **执行类视频** — 对"爱收藏但不行动"的用户最有效
3. **正反馈是核心价值** — 夸夸群/打卡群解决用户最缺的"成功反馈"
4. **虚拟IP路线** — 声音/形象独特时走虚拟IP比带货更好
5. **产品选择要基于痛点** — 不要因为"用户是女生"就选护肤品
6. **游戏博主的壁垒** — 打得好不够，要让用户记住你
7. **在线学委人设** — 踏实、共享信息、帮大家整理笔记
8. **定位要极致精准** — 全对的事情就是全错
9. **基于用户认知做内容** — 用户觉得好才是好，不是你觉得好
10. **小众即大众** — 再小众也绝对大众，但不要上来就走大众路线
