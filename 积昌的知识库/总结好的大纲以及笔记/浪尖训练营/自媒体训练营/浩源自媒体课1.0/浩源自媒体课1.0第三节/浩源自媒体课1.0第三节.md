## 二、🎬 低成本拍摄——博主案例拆解

> [!TIP] 📎 关联讲义
> 详见 [[“流量+x”训练营，拍摄系统.pdf#page=1]] — 博主案例拆解（全宁、冤种小徐等）与低成本手机拍摄教学

### 2.1 博主一：全宁（圈宁）——横屏+贴脸+看稿子

**基本信息：**
- 北大在读
- 横屏视频，贴脸录制
- 受众：初高中生为主（之前是大学生，到大二以后就很少看他的了）
- 变现方式：广告商单

#### 横屏录制技巧——两台手机叠放法（核心实操）

> 📌 **关键发现：全宁的眼神看的是屏幕的右上角——那不是在看镜头，那是在看稿子！**

**操作步骤：**
1. 打开录制手机的视频模式，对着自己
2. 眼睛看右上角——那个位置本来是空的
3. 把稿子放到右上角位置（用另一台手机/平板/甚至纸条）
4. 眼睛看稿子 → 观众觉得你在看镜头（镜像原理）
5. 把录视频这件事变成**念稿**

**设备方案汇总：**
- 两台手机叠起来（录制的手机摄像头在右上方，叠上去不挡摄像头）
- 手机 + 电脑
- 手机 + 平板
- 运动相机（录横屏）+ 手机（提词）
- 一张纸条也行

**为什么横屏好录？**
- 横屏视频在抖音上比较稀缺（大部分是竖屏），自然让用户觉得"你要讲有用的东西"
- 横屏看稿子很自然，观众不会觉得你在念稿
- 竖屏看稿子很麻烦、很容易被发现

**关于穿帮：**
> "大家录视频不是录综艺，穿帮无所谓。iPad被眼睛反射反光出来都无所谓的——你录好了就可以了。"

**全宁视频的其他特征：**
- **一句话一切**——视频切得很碎，但画面移动不大
- 气口被剪掉 = 视频节奏快 = 没有喘息空间
- BGM：治愈系风格
- 场景：家居环境，衣服不大牌，学生气很足
- **选题广泛**：寒假自律、背单词、考研、奖学金、期末……什么都能讲
- 信息点少但选题大——这是广告号的逻辑，覆盖广才能接更多广告

#### 全宁 vs 浩源路线对比

| 对比维度 | 全宁（广告路线） | 浩源（产品路线） |
|----------|---------------|----------------|
| 粉丝画像 | 泛粉（初高中+大学+考研） | 垂直（大一新生） |
| 变现方式 | 广告商单 | 自有社区/产品 |
| 选题策略 | 广泛覆盖，不断吸引新用户 | 精准垂直，深度服务 |
| 涨粉速度 | 快 | 相对慢 |
| 一条广告报价 | 几万到十几万 | 1-2万（但浩源不接） |

> 💡 **思考题：** 你是想成为一个粉丝泛的网红（接广告），还是想成为一个垂直领域的自媒体达人（卖自己的产品）？这个定位决定你的内容策略。

### 2.2 博主二：院中小区（冤种小徐）——竖屏+快节奏+职场风

**基本信息：**
- 讲就业的职场博主
- 竖屏视频
- 受众：大三大四学生

**特征分析：**
- 后背景是**假书**——职场风，学生气消失
- 穿着像刚进职场的年轻人
- 内容围绕：工作、赚钱、就业三个关键词
- 语速**非常快**——不给用户喘息的空间
- 稿子熟读到能背下来

**浩源的评价：**
> "说实话我不太喜欢这种视频——它很明显是在博流量、制造焦虑。这种风格不适合大家初期去做。我更希望大家能沉下心来投入到长视频、横屏视频的高质量内容创作里面。"

### 2.3 博主三：计算机女生——垂类+视觉锤

**基本信息：**
- 浙大研究生在读，杭电计算机本科
- 垂类：计算机类同学找工作、就业

**特征分析：**
- 能感受到她已经就业了（上班氛围），但还保留一丝学生气
- **视觉锤：** 拿着鼠标当话筒——让人记不住她这个人，但能记住这个鼠标

> 💡 **视觉锤概念：** 你也可以拿一些奇奇怪怪的东西——农夫山泉、纸盒子、鼠标……让人一看到这个东西就想到你。

### 2.4 博主四：野塘鸭郎君——不露脸+第一视角+AI配音

**基本信息：**
- 国企上班，做了自己的自媒体账号
- 今年刚找到工作

**特征分析：**
- **不露脸**——口播+录制第一视角场景
- 第一视角模仿大学生，让用户代入
- 甚至没有自己念稿，直接用**AI生成配音**
- 前提：稿子要写得**特别好**才能用AI配音
- 素材：地铁、小吃摊、晚上下班人流、上课时人多的地方

> 💡 **适合不想露脸的同学：** 一边录在学校吃饭上课的素材，一边用手机念稿（或AI生成配音），配合第一视角画面。

### 2.5 博主五：未知大学——0.5秒留人

**基本信息：**
- 最近起号起得特别快
- 讲"大学生不要害怕"、"大学本科生才是真正的大爷"

**特征分析（浩源重点强调）：**

> 📌 **服装和感觉比稿件更重要——这是第一秒，甚至叫0.5秒。**

- 一看脸就是大学生——"那种大学已经蹉跎18载的大学生"
- 背景：出租屋/寝室，没有奢华装饰
- 每天穿白T恤，没有额外装饰
- **给人感觉**：同路人、理工类、即将面临找工作的大学生

> "你怎么能在0.5秒内留住一个用户？就是瞬间让他感觉'哇哥们儿，同路人'——这个感觉比你的稿件更重要。"

### 2.6 东北大学学弟——素人起号+系统不完整

- 只讲了一下大学制度的问题，复盘了自己大一生活
- 第一条视频就**6万多点赞**
- 但接下来几条视频都没有那么高点赞了

> ❓ **为什么？** → **系统不完整。** 他只是按照其他博主的形式尝试了一下录制风格，但因为系统搭建没有完善，没有持续创作爆款的能力。

**浩源的类比——中彩票：**
> "你今天下班买一瓶农夫山泉，用321步走到彩票站，买了一张彩票中了10万。然后你明天也这样做——下班买农夫山泉、321步走到彩票站、同一时间买同一张彩票——你觉得还能中10万吗？不可能。系统的重要性就在这个地方。"

### 2.7 关于复刻的核心逻辑

**为什么一定要复刻？**
> "你做任何训练都需要标准答案。没有标准答案，怎么来判定你这件事情好与坏呢？"

**推荐的复刻顺序：**
1. 先复刻**全宁**（横屏、看稿、自然表达）
2. 再复刻**院中小区**（竖屏、快节奏）
3. 再复刻**其他博主**
4. 最后形成自己独特的风格

**为什么每个类型都要复刻？**
> ⚠️ 如果你初期只复刻一种风格，你的录制**阈值**就锁死了。后面想换风格就换不了了。每复刻一种风格，你的录制瓶颈就往上提一截。

### 2.8 现在做自媒体还来得及吗？

浩源展示了这些博主的爆款时间线，全部是今年（2026年）7月的视频：
- "2024年就有人说自媒体红利已经过了"
- "人家2025年底起的号"
- "这个也是7月份、8月份才火的"

> ✅ 没什么火不火的问题。关键在于你能不能找到喜欢的表达模式，**不装地讲一些有用的东西**，做一个持续更新有用有趣的频道——"甚至你都不用有趣，直接有用就够了。"

## 三、🎬 浩源自己的视频拆解

### 3.1 视频风格

- 虽然是竖屏，但实际上是**1:1比例**的视频
- 黑色半袖+大学生背景+暗黄色灯光（像晚上自习时打开台灯的感觉）
- 注重逻辑，一步一步顺着大家讲

### 3.2 爆款案例分析——860万播放

**视频标题/开头：**
> "年薪百万为导向，大学四年全部信息差，11分钟讲完，少走点弯路。"

**高价值开头结构拆解：**
- 年薪百万 = **高期望**
- 四年全部信息差 = **高价值**
- 11分钟讲完 = **低时间成本**
- "你不想听就划走，划走了就是你的损失" = **反向激将**

### 3.3 看稿子的实际画面演示

浩源现场演示了他录视频时看稿子的真实动作：

1. **右手有一个抬起来的动作**——那是在划稿子（往上滑）
2. 稿子念完了，往上滑——眼睛看屏幕下方念下一段
3. 为什么眼神能往外瞟？——因为已经知道接下来要讲什么了

> 💡 **用语音转文字写稿**——念起来自然，眼神就能自由活动。如果是书面语写稿，念的时候眼神是死的。

### 3.4 视频数据亮点

- 860万播放
- **16万人分享**——基本都是家长分享给自己家孩子看的
- 评论区戾气重但数据依然很好

> 💡 **启示：** 有时候评论区有负面评论不代表视频不好。点赞、收藏、分享的转化率才是关键。

## 四、🎬 拍摄技巧进阶

> [!TIP] 📎 关联讲义
> 详见 [[“流量+x”训练营，拍摄系统.pdf#page=1]] — 场景选择、服化道、录制心魔克服、看稿技巧、拍摄情绪

### 4.1 拍摄前的准备

| 项目 | 建议 |
|------|------|
| 🎭 **拍摄场景** | 干净、光线好的背景，不要杂乱 |
| 👕 **服装** | 纯色简洁，和目标受众匹配 |
| 📄 **稿件准备** | 把稿件读顺——至少读7遍 |
| 🧠 **心理准备** | 把录视频变成念稿，降低心理难度 |

### 4.2 克服镜头尴尬的三步法

1. **看稿子不看镜头**——看不到自己整张脸，就不会尴尬
2. **把录视频变成念稿**——一按录制，只管念稿
3. **降低心理预期**——"录视频不是录综艺，你只是想把要表达的内容说出来而已"

### 4.3 情绪控制——为什么浩源在晚上录视频

**关键洞察：人在11点以后，感性占据理性。**

- 短视频需要有情绪的表达，不能变成念稿的机器
- 凌晨时大家emo，表达情绪、共情的成本更低
- "你让我在早上录视频的话，我会非常难受，早上太理性了"
- 浩源的录制时间通常是**凌晨2-3点**

**调节情绪的小技巧：**
- 录制前去**跑个步或运动一下**
- 看**相声、脱口秀、喜欢的综艺**
- 多巴胺到达一定程度后，录视频时自然而然的状态会更好

## 五、✂️ 剪辑入门——剪映实操

> [!TIP] 📎 关联讲义
> 详见 [[“流量+x”训练营，拍摄系统.pdf#page=1-2]] — 粗剪顺序、剪辑美感养成、智能剪口播、花字包装、导出教学

### 5.1 导入素材注意事项

| 设备 | 传输方式 | ⚠️ 注意 |
|------|----------|---------|
| **手机** → 电脑 | QQ或百度网盘 | **不要用微信传**——微信会压缩画质 |
| **相机** → 电脑 | U盘+SD卡组合 | SD卡拿下后插到U盘直接导 |

### 5.2 剪辑美感的养成

> 📌 **顺序：先养成美感，再学会剪辑。**

**跟学PPT一个逻辑：**
```
拆解优秀模板 → 一步步模仿 → 学技巧 → 做自己的作品
```

**剪辑 = 做PPT：**
- 每一帧都是一个PPT
- 好的剪辑 = 每一帧都排版优雅、视觉舒适
- 差的剪辑 = 初高中老师的PPT：五颜六色的艺术字、黄底红字加粗宋体
- 如果你能把视频当PPT去剪——你缺少的只是**剪辑熟练度**

### 5.3 剪映核心操作

#### 第一步：封面设置

1. 在预览窗口找到**封面设置**
2. 选择视频中某一帧作为封面
3. 浩源推荐选：人开心、快乐、自然的状态，或者看外景、想要说话的那种感觉
4. 直接完成设置，会随视频一起导出

#### 第二步：常用快捷键

| 快捷键 | 功能 |
|--------|------|
| **CTRL + 鼠标滚轮** | 放大/缩小轨道 |
| **ALT + 鼠标滚轮** | 前后滑动 |
| **B键** | 切割 |
| **CTRL + Z** | 撤销 |
| **V键** | 切换回鼠标 |

#### 第三步：智能剪口播（核心功能）

> 这是今天作业中最重要的功能。

**操作步骤：**
1. 右键点击视频轨道上的素材
2. 选择**"智能剪口播"**
3. 系统自动识别视频中的文稿，AI标出每一句话
4. 想删除哪句话，直接删除对应的文字段
5. 中间有0.3秒的停顿也可以直接删除

**效果：** 像全宁的视频那样——一句话一切，把气口、卡壳、停顿全部剪掉，视频节奏就快了。

> ℹ️ 这个功能应该是限免的，不需要VIP。但如果要做自媒体，该投资的地方还是得投资——充VIP该花还是得花。

#### 第四步：添加字幕

1. 点击左上角**文本**
2. 选择**智能字幕** → **开始识别**
3. 系统自动识别语音并生成字幕

#### 第五步：字幕风格调整——以复刻橘一城风格为例

**橘一城的字幕风格：**
- 白底+橘色字
- 下方有英文白字（翻译）

**复刻步骤：**

1. **加英文字幕：** 左上角 → 翻译语言 → 翻译成英文
2. **调英文字体：** 选一个打印体/打字机风格的英文字体，调整大小和位置
3. **调中文字幕：**
   - 选橘色
   - 加白底：背景 → 圆角调为0 → 加白色背景
   - 选字体：匹配博主的字体风格
4. **应用到全部字幕：**
   - 右上角有一个**"应用到全部字幕"**的对勾
   - **顺序：** 先把基础字幕全部调整好 → 再单独加花字
   - 如果想单独改某一个字幕而不影响全部：把右上角的**对勾去掉**

> 💡 **及格线：** "只要能看清就够了。不要让它觉得多么美多么好看——先把最基础的部分完成，能看清楚就足够了。"

#### 第六步：调色（进阶内容）

- 浩源在调节面板里有自己常用的调色预设
- 本次课程不讲太深，后续有专门的剪辑课

### 5.4 推荐学习的剪辑博主——橘一城（小红书）

**基本信息：**
- 空间科学硕士在读，设计师背景
- Vlog风格
- **每一帧都是一个海报**

> 浩源现场演示：随便暂停一帧，就是一个海报。"颜色、色调、字体、大小、位置、视频节奏、语言——合到一块儿的。"

**为什么思维导图式稿件不适合新手？**
- 橘一城用的是思维导图式稿件（没有逐字稿）
- 不适合新手的原因：表达本身就很匮乏，没有逐字稿提示容易卡壳
- 浩源自己也可以用思维导图式，但为了信息密度更强还是用逐字稿

> 💡 个人IP的核心：用户喜欢的是你这个人本身。不管你有没有废话，他都会听。

### 5.5 视频下载工具

浩源提供了一个网站（会发到群里）：
1. 复制喜欢的博主的视频分享链接
2. 粘贴到网站中
3. 点击解析
4. 下载成功
5. 导入剪映，**一帧一帧地拆解学习**

## 六、💡 用户提纯理念

> 📌 **博主的核心用户 = 被层层筛选后留下的那批人。**

- 不能把所有人都放进社群，否则鱼龙混杂
- 100万粉丝 → 20万关注 → 3万信任 → 3000核心用户
- **用户也是需要提纯的**

**浩源的逻辑：**
> "我的初心是帮你们把大学读明白。100万人我可能一个人都帮不了，但留下一批真正认可的人，我才能真正帮到他们。"

## 七、🎯 课后作业

### 作业要求

1. **录制一条1分钟的视频**
2. 从昨天写的稿件中摘取**其中一部分**
3. 用剪映做**粗剪**：智能剪口播去气口 + 加字幕
4. 对比你对标的博主的视频，写一个**对比总结文档**

### 不需要

- ❌ 不需要精修、加特效
- ❌ 不需要完美的剪辑
- ❌ 不需要拍摄多段素材
- ❌ 不需要发到平台上

### 这次作业的重点

> ✅ **先迈出第一步。** 录制+粗剪就够了，重点是体验整个流程。

### 对比总结文档内容

1. 你对标的博主是谁（全宁/院中小区/橘一城/浩源……）
2. 你和他差在哪些地方（除了"人家长得帅"之外）
3. 怎么解决这些差距

**举例：** 为什么全宁说话很顺畅？你在哪个地方卡住了？卡住的地方可以怎么优化？

### 提交方式

- **1分钟视频截图**（不用传视频原文件）
- **+ 对比总结文档**
- 截止时间：**次日中午12:00前**

### 补充说明

- 可以录2-3分钟最后剪成1分钟
- **录的时候可以很糊、很黑、乱七八糟——录了就行**
- "没有灯你就露一个大白牙，我觉得也OK"
- 没带电脑可以用手机版剪映（功能差不多，但流程没那么顺畅）
- **不管你在火车上还是在哪里——我只看作业提交，不希望你找任何借口**

> "我为什么很严格地说：作业可以做得不好，我们慢慢做得更好——但是不能不做。"

### 直播中回答的问题

> [!QUESTION] ❓ 智能剪口播在哪？
> 右键选择视频轨道 → 智能剪口播。

> [!QUESTION] ❓ 剪映可以用字由（字体）吗？
> 可以。字由里打对号的字体，剪映里能识别出来。

> [!QUESTION] ❓ 如何单独改一个字幕而不是改全部？
> 选中字幕 → 把右上角的对勾去掉 → 就可以单独修改。

> [!QUESTION] ❓ 电脑版剪映还是手机版？
> 建议大家用**电脑剪辑**。手机版的剪辑维度会差一些，而且比较麻烦。

> [!QUESTION] ❓ 剪映怎么调画面颜色？
> 在调节面板有预设，但今天不讲这么深——今天的重点是录制和粗剪。

## 📌 核心要点总结

1. **低成本拍摄** — 手机+干净场景+读顺稿件=够用
2. **两台手机叠放法** — 一个录一个提词，看右上角=看稿子但观众觉得你在看镜头
3. **晚上录视频** — 感性占理性，情绪表达成本更低
4. **0.5秒留人** — 服装和感觉比稿件更重要，瞬间让用户觉得"同路人"
5. **全宁拆解** — 横屏+看稿+一句话一切+选题广泛=广告路线
6. **院中小区拆解** — 竖屏+快节奏+制造焦虑=流量路线
7. **复刻提高阈值** — 每复刻一种风格，录制瓶颈就提高一截
8. **先养成美感再学剪辑** — 每一帧都是一张PPT
9. **智能剪口播** — 核心功能，去气口、去卡壳、提节奏
10. **先完成再完美** — 今天只要1分钟视频+粗剪，录了就行
