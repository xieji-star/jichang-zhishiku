## 核心框架：100%命中率的求职体系

> [!TIP] 💡 **核心观点**
> 整个求职过程可以拆解为三个板块：**简历** → **投递** → **面试**。这三个板块就是拿到 offer 的全部环节。

### 三大求职难点

| 卡点 | 说明 | 对应直播 |
|:----:|------|:--------:|
| 📄 **简历** | 不会包装自己，校园经历不会转化成企业需要的语言 | 简历专项 |
| 📮 **投递** | 不知道往哪里投、怎么投 | 投递专项（5月第1场） |
| 🎤 **面试** | 面试时露馅、回答不上来、紧张 | 面试专项 |

### 100%命中率的三个支点

讲师将整个求职体系总结为三个准备维度：

```
┌────────────────────────────────────────────┐
│          offer收割：100%命中率体系           │
├────────────────┬───────────────┬────────────┤
│ 乙方视角准备    │ 甲方视角准备   │ 个性化准备  │
│ （自我剖析）    │ （外部洞察）   │ （别无他选） │
├────────────────┼───────────────┼────────────┤
│ 我知道我是谁    │ 我懂这个岗位   │ 我和岗位匹配  │
│ 我有什么能力    │ 我懂这家公司   │ 我有独特优势  │
└────────────────┴───────────────┴────────────┘
```

> [!NOTE] 📌 **这套方法论不仅适用于找实习**
> 大一大二能用，大三大四秋招春招能用，研究生毕业、社招跳槽——本质都是同一套底层逻辑。

## 乙方视角：自我剖析与简历包装

### 底层逻辑：所有工作都分为三个环节

> [!WARNING] 🔴 **这是整个课程最底层的认知框架**

讲师提出：**所有公司、所有业务、所有岗位，本质都分为三个环节**：

```
流量（Traffic/Flow）→ 产品（Product）→ 交付（Delivery）
```

| 环节 | 通俗理解 | 校园经历中的对应 |
|:----:|---------|----------------|
| 🚀 **流量** | 客户从哪里来，如何吸引人 | 运营公众号/小红书/抖音、做海报宣传、地推、社群运营、外联拉赞助 |
| 🏗️ **产品** | 你卖的是什么 | 活动方案策划、课程设计、竞赛方案、PPT制作、路线规划 |
| ✅ **交付** | 服务怎么落地执行 | 现场签到、秩序维护、物资管理、问题处理、活动收尾 |

#### 案例：校园歌手大赛

| 环节 | 对应工作 |
|:----:|---------|
| **流量** | 制作活动海报、推文宣传、活动宣发 |
| **产品** | 制定活动方案、设计赛制、排名规则、颁奖方案 |
| **交付** | 现场执行、引导选手、发号码牌、公布结果、颁发奖状 |

> [!TIP] 💡 **核心思维：有意识地将校园经历归类**
> 无论是班委、社团、学生会还是兼职，你做的每一件事都可以拆进这三个环节。这样写简历时你就知道——**你的经历对应公司的哪个部门、哪个岗位**。

#### 公司的流量、产品和交付分别是什么？

以**卖手机的公司**为例：

| 环节 | 内容 |
|:----:|------|
| 📢 **流量** | 发布会、广告（电视/传媒/电梯）、短视频引流、直播、线下门店、私域、老板个人IP（如雷军） |
| 📱 **产品** | 手机本身（实体产品） |
| 🔧 **交付** | 售后服务、系统升级、维修 |

> 📌 **找工作的重要认知：**
> - 你在学校做流量端的工作 → 可以应聘所有跟流量相关的岗位（编导、拍摄、剪辑、直播运营、设计、私域运营等）
> - 你在学校做产品端的工作 → 可以应聘所有跟产品相关的岗位
> - 你在学校做交付端的工作 → 可以应聘所有跟运营/执行相关的岗位

### 产品有哪些类型？

| 类型 | 示例 |
|:----:|------|
| 🏭 **实体实物** | 耳机、麦克风、饮料——大部分品牌方 |
| 📚 **虚拟知识** | 课程、咨询方案 |
| 🎭 **体验/情绪价值** | 颜值、情感陪伴 |
| 🎬 **内容** | 综艺（内容本身即产品） |
| 🛠️ **工具** | APP、软件、网页、系统 |
| 👥 **社交圈子** | 社群、圈子 |
| 🎪 **线下活动** | 相亲会、沙龙 |
| 🏅 **背书/头衔** | 福布斯U30、胡润U30、内推资格 |
| 🎫 **机会/选择权** | 付费实习名额、评奖名额 |

### STAR法则 + 三要素（独创公式）

> [!CAUTION] 🔴 **这不是普通的STAR法则——这是讲师独创的"STAR法则 + 三要素"公式**

```
简历优化的终极公式 = STAR法则 + 流量/产品/交付三要素
```

**STAR法则：**
- **S**ituation（背景）：在什么背景下
- **T**ask（任务）：做了什么任务
- **A**ction（行动）：采取了什么行动
- **R**esult（结果）：导向了什么结果数据

**三要素（流量·产品·交付）：**
- 你知道自己做过的工作属于哪个环节
- 你知道整个业务链条的逻辑
- 你能在面试时应对任何超出本职工作范围的问题

> [!TIP] 💡 **为什么要理解整个业务链条？**
> 假设你实习时只负责做PPT（产品包装环节），但面试官可能会问：
> - "你们的产品是怎么推广的？"（流量环节）
> - "后续的用户反馈怎么样？"（交付环节）
>
> 如果你只懂自己的那部分，一问就露馅。但如果你理解了**整个流量→产品→交付的链路**，你就知道怎么回答。

### 简历包装 vs 简历造假

> [!WARNING] ⚠️ **包装可以，造假不行**

| 行为 | 说明 | 是否可行 |
|:----:|------|:--------:|
| 把同事做的业绩写到自己简历上 | 你了解整个流程，面试能回答上来 | ✅ **可包装** |
| 把项目整体的数据结果作为自己的成果 | 数据来自你的动作导向的结果 | ✅ **可包装** |
| 编造完全不存在的经历 | 一问就露馅 | ❌ **造假，不行** |

**案例：** 如果你负责的是研学方案PPT的设计（产品包装环节），最后卖出多少人不是直接归你管。但因为你的产品包装是销售转化的前提，你可以把**销售数据**作为工作成果写上去——前提是你面试时能讲清楚整个逻辑。

### 简历排版的精进技巧

| 技巧 | 操作 |
|:----:|------|
| **标题层级** | 大标题字号比小标题大一点，层级分明 |
| **行间距差异化** | 正文行间距调小（如1.4），标题行间距调大（如1.6），结构化更明显 |
| **超链接插入** | 先转PDF再插入文字链接，让URL显示为蓝色可点击 |
| **整体版面** | 控制在1页以内，板块清晰 |

## 甲方视角：外部洞察与JD拆解

> [!TIP] 💡 **甲方视角 = 站在公司的角度去理解这个岗位**

### 从JD中能推测出什么？

拿到一份岗位JD，不只是看工作要求——你可以从中推测出大量信息：

| 可推测的信息 | 方法 |
|:-----------:|------|
| 🏢 **公司产品是什么** | 从JD描述中推测产品形态（如：AI女性向产品 → 大概率是移动端APP或虚拟角色） |
| 💰 **商业模式/营收来源** | 推测是订阅制、一次性付费、增值服务（送礼、定制） |
| 📏 **公司规模** | 从团队人数描述推测是小团队（10人以内）还是多业务部门 |
| 📊 **组织架构** | 汇报层级扁平还是多层？团队分工如何？ |
| 🚀 **职业发展路径** | 做完这个产品后可以跳到哪里？同类公司有哪些？ |

#### 实战案例：AI产品运营JD拆解

讲师用Boss直聘上的一个岗位做演示：

**岗位关键词：**
- AI产品运营 / 女性向产品 / 出海
- 对女性市场有独到见解
- 熟悉AI Agent构建逻辑
- 提示词调优实战经验
- 资深乙女玩家优先

**拆解过程：**

```
JD文本
  ↓
推测产品：AI虚拟角色APP（面向海外女性）
  ↓
推测功能：温柔男友、治愈闺蜜、虚拟偶像等
  ↓
推测商业模式：会员订阅制（初级/中级/高级）
  ↓
推测公司规模：团队10人以内，但公司整体100-499人（多业务赛马）
  ↓
推测汇报结构：扁平化管理
  ↓
延伸：完成这段经历后可以跳到同类公司（国内女性产品、AI虚拟人等）
```

> 📌 **关键思维：从一份JD延伸出一张「网」**
> 你能做的不只是这个岗位——同类产品、同类用户群、同类型公司，都是你的目标。

### 甲方视角的意义

```
只知道包装简历 → 面试官问超纲问题就露馅
       ↓
理解业务本身 → 面对任何问题都能回答
       ↓
从行业高度看 → 知道自己的位置和发展路径
```

## 个性化准备：建立偏爱连接

> [!CAUTION] 🔴 **最关键的一句话：为什么选你不选别人？**

### 偏爱的底层逻辑

```
10个面试者 → 5个满足硬性要求 → 选谁？
                                          
当所有人客观条件相同时，主观偏好决定一切
```

> [!NOTE] 📌 **有选择就有偏爱**
> 就像选择产品一样——不只是因为产品好，而是因为偏爱某个人、某个品牌、某种价值观。

### 如何找到偏爱的连接点

| 连接类型 | 示例 | 效果 |
|:--------:|------|:----:|
| 🏫 **同校/同院系** | "我也是这个学校的" | 基础连接 |
| 📍 **同乡/同城市** | "我在那里待过" | 地理连接 |
| 🎯 **同爱好（小众更佳）** | 同样喜欢某部纪录片、某位导演 | **强连接** |
| 💼 **相同职业转型经历** | "我也从财务转行到猎头" | 最强连接 |
| 📖 **相同价值观** | 同样信奉某种理念 | 长期连接 |

> [!TIP] 💡 **不要找大众爱好**
> "看书"、"运动"太普通了，要找小众、垂直、有辨识度的爱好。

### 实战案例一：朋友圈策略

讲师分享了自己的亲身经历：

1. 参加线下活动，旁边坐了一位大佬
2. 活动后加微信，调研了大佬的朋友圈
3. 发现大佬每天打卡《圣经》
4. 讲师发了一条引用《圣经》的朋友圈
5. 大佬看到后觉得"你好像曾经的我"
6. **结果：主动邀约咖啡 → 直接给offer**

> 💬 **核心逻辑：** "大佬为什么愿意帮你？因为你像他。他想帮你，感觉帮助了曾经的自己。"

### 实战案例二：猎头实习

讲师面试猎头岗位时：
1. 调研到面试官（领导）是会计学转行做猎头
2. 讲师本人也是会计学专业
3. 面试时强调："我也不喜欢财务，我觉得猎头更有意思"
4. **结果：面试官觉得"这不是我吗？就要你了"**

### 务实派 vs 务虚派

> [!NOTE] 📌 **没有对错之分，只有派系之分**

| 派系 | 特点 | 适合策略 |
|:----:|------|---------|
| 🪨 **务实派** | 踏踏实实做事，靠结果说话 | 少一点社交包装，专注把活干好 |
| 🎭 **务虚派** | 善于社交、逢场作戏、左右逢源 | 充分发挥社交优势，建立广泛连接 |
| 🔄 **两派兼有** | 在不同场景切换 | 最佳状态 |

> ⚠️ **你不需要成为社交达人。** 了解这个概念，能用多少用多少即可。

### 偏爱的深层价值

```
只有工作关系 → 项目结束就断联
       ↓
有共同爱好/价值观 → 项目结束后还能做朋友
       ↓
关系进化 → 从同事变成人生中的贵人
```

## 可迁移技能：AI时代的职业护城河

> [!WARNING] 🔴 **核心问题：如果你的技能被AI替代了怎么办？**

### 以设计岗位为例

GPT推出图片生成功能后，设计师面临冲击：

```
两个设计师，设计能力同样强
       ↓
设计被GPT替代后，留哪个？
       ↓
懂业务的设计师 > 只懂设计的设计师
       ↓
因为懂业务的人可以用GPT调出更好的结果
```

### 技能 vs 行业理解

```
         技能本身（如设计、剪辑、编程）
                ↓
    可应用到不同行业场景
     ┌──────┬──────┬──────┐
     ▼      ▼      ▼      ▼
   电商    新媒体   广告   政务
     ↓      ↓      ↓      ↓
  懂电商   懂内容  懂品牌  懂体制
   的设计  的设计  的设计  的设计
```

> 📌 **AI替代的是技能，但不是「技能+行业理解」的组合。**

### 对各个专业的启示

| 专业 | 纯技能风险 | 技能+行业理解 = 护城河 |
|:----:|:---------:|:---------------------:|
| 🎨 **设计/视觉传达** | GPT能生成海报 | 懂电商/懂品牌/懂流量的设计 |
| 🎬 **剪辑/传媒** | AI能剪辑视频 | 懂政府客户/懂招商/懂网红运营 |
| 💻 **计算机** | AI能写代码 | 懂业务场景/懂用户需求 |
| 📊 **财务/金融** | AI能出报表 | 懂业务分析/懂决策支持 |

### 行动建议

> [!TIP] 💡 **讲师的核心建议**
> 多了解行业、多实习、多实践、多做项目、**多学AI、多学自媒体、多学销售**——没有任何坏处，只有好处。

## 信息储备：做加法的底层逻辑

### 为什么信息量越大，决策越高效？

> 📖 **讲师案例：香港留学与香港手机卡**

有同学去香港大学留学：
- **信息量少的同学：** 只去留学，上课、看风景
- **信息量多的同学：** 顺便办一张香港手机卡

**香港手机卡的价值：**
- 可注册苹果美区Apple ID
- 可自己充值ChatGPT会员
- 可开通香港银行账户
- 可投资美股/港股
- 不用在闲鱼上买别人的美区ID

> 📌 **核心逻辑：** 做加法是为了做减法。信息储备越丰富，决策越精准。

### 为什么要不断做加法

```
多做项目 → 理解不同行业的逻辑
多实习  → 积累不同岗位的经验
多社交  → 建立多元化的人脉
多调研  → 储备跨领域的信息
            ↓
        全局视野
            ↓
        做出更优的职业决策
```

```
│  ├── 找到小众、垂直的共同点                               │
│  └── 从工作关系到人生贵人                                 │
│                                                         │
│  四、可迁移技能（AI护城河）                               │
│  ├── 技能+行业理解 = 不可替代                            │
│  ├── 多学AI、自媒体、销售                                 │
│  └── 全局思维 > 单一技能                                 │
│                                                         │
│  五、信息储备（决策基础）                                 │
│  ├── 信息量越大，决策越精准                               │
│  ├── 多做加法，再做减法                                   │
│  └── 储备跨领域信息 → 全局视野                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
