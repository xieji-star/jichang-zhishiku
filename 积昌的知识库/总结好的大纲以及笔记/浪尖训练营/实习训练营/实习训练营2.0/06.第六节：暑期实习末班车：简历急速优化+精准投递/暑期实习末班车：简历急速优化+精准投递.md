## 🔍 第一趴：简历排版与视觉优化（上）

> [!TIP] 📎 关联课件
> 详见 [[暑期实习末班车5.13课件.pdf]]（课程幻灯片）

本节通过现场修改 3 位同学的简历，演示简历排版的实操要点。**内容方面的写法已在上一节课（四大法则+三要素）讲过，本节专注排版。**

### 📌 排版核心标准

<span style="color:#c0392b">📌 **简历排版八项核心标准：**</span>

| # | 标准 | 说明 |
|---|------|------|
| 1 | **页边距用「窄」** | 左右两边页边距要一致，不要一大一小 |
| 2 | **表格环绕设为「无」** | 表格属性 → 文字环绕 → 选「无」，否则表格可随意移动 |
| 3 | **字体统一用「宋体」** | 全文只用宋体，不要混用黑体、微软雅黑等 |
| 4 | **时间统一到「月份」** | 不要有的写到日、有的写到月，统一如 "2026.06" |
| 5 | **表格线用手绘** | 用「绘制表格」自己画线，不要在 PDF 上画线 |
| 6 | **标题调字间距** | 标题加宽字间距，比正文大一点，可加段前间距 |
| 7 | **标点符号统一中文** | 用 `CTRL+H` 替换英文句号/逗号/冒号为中文符号 |
| 8 | **清除多余空格** | `CTRL+H` → 输入空格 → 替换为空，一键删除所有多余空格 |

### ▸ Word 实操技巧

<span style="color:#2980b9">💡 **关键操作步骤：**</span>

1. **清除格式**：选中全文 → 点击「橡皮擦」清除所有格式
2. **表格自动调整**：表格工具 → 自动调整 → 先「根据内容调整」再「根据窗口调整」
3. **字体大小**：通常 10.5~12 号，根据内容多少调整
4. **行间距**：用「多倍行距」在 1.1~1.5 之间微调，以铺满一页为准
5. **标题格式**：调字间距（加宽），加「断前」0.2~0.5 行，用「格式刷」统一
6. **PDF 导出**：转 PDF 后检查是否多出空白页，如有则调页边距或删除空白页
7. **表格高度不统一**：选中表格 → 表格属性 → 行 → 取消「指定高度」或统一数值

> [!TIP] 📎 关联简历范例
> 详见 [[浪小尖-简历.pdf]]（修改后的标准简历范例）

### ▸ 进阶排版细节

<span style="color:#2980b9">💡 **以下是从 85 分到 95 分的进阶技巧：**</span>

#### 表格跳行处理

- 如果调整下面表格时上面也跟着动 → **拆分表格**（表格工具 → 拆分表格）
- 拆分后分别设置「根据内容调整」和「根据窗口调整」
- 调整完再合并回去

#### 内容模块化（内容多时）

- **内容的行间距调小**（如 1.0 倍行距）
- **标题的间距调大**（加断前 0.3~0.5）
- 标题加宽字间距
- 同一板块内的子项目之间加断前 0.2 隔开
- 效果：一眼看过去「一块一块的」，更清晰

#### 项目符号（黑点）美化

- 默认黑点太大且间距太大，很丑
- 调小：在「自定义」→「高级字体」中将字号从 10 调为 8
- 调间距：调整「制表位」和「缩进位置」到 0.2

#### 证件照

<span style="color:#27ae60">✅ **最佳做法：**</span>
- 用手机拍自己的头（正面+侧面+上面+下面）
- 用 GPT Image（GPT-4o）生成白底证件照
- 提示词写详细一点，效果比照相馆好很多
- 插入 Word：设为「浮于文字上方」→ 锁定横纵比 → 拖动到合适位置
- **统一用白底**

#### ❌ 避免孤行（跳行）

- 如果一行只有一两个字跳行 → 把前面的内容精简一两个字，让行缩回去
- 如果要跳行，至少覆盖 1/3 以上才值得跳

### 简历四大板块结构

简历建议统一为 **4 个板块**，按此顺序：

```
教育背景 → 校内经历 → 校外经历 → 技能证书
```

> [!NOTE] 📌 自我评价建议不写或极简（一两行即可），可有可无。

**经历排序原则：** 按含金量从高到低排列，**不要按时间顺序**。最亮眼的经历放第一个。

## 🧠 第二趴：创业思维倒推求职方法论（下）

### ▸ 核心框架：技能 → 产品 → 需求

创业分为三个部分，求职思维完全一样：

```
      创业                            求职
技能 = 我的能力                  技能 = 我的经历（校内/校外）
产品 = 我做出的东西              产品 = 简历 + 面试（包装后的经历）
需求 = 客户愿意付钱             需求 = 企业给我发 offer
```

<span style="color:#c0392b">📌 **核心观点：一定是从右到左，不是从左到右。**</span>

| 思维方式 | 方向 | 说明 |
|---------|------|------|
| ❌ **错误：从左到右** | 技能 → 产品 → 需求 | 我有什么技能 → 我做什么产品 → 找什么客户 |
| ✅ **正确：从右到左** | 需求 → 产品 → 技能 | 客户需要什么 → 我做什么产品 → 我需要什么技能 |

> 不要根据你的爱好、兴趣、擅长、MBTI、星座、专业、性格去推你要找什么工作。这些统统是「从左到右」的错误思维。

### ▸ 案例：咖啡店 / 服装店 / 篮球馆

<span style="color:#8e44ad">📖 **案例 1：咖啡店**</span>

| ❌ 表面认知 | ✅ 实际考验 |
|-----------|-----------|
| 我懂咖啡、爱喝咖啡 | 选址、平效、复购率、外卖运营（美团/饿了么） |
| 我能品尝出咖啡好坏 | 供应链管理（咖啡豆、冰块、杯子） |
| 我是咖啡专业人士 | 成本控制、人员管理、私域运营（拉群维护） |

<span style="color:#8e44ad">📖 **案例 2：服装店**</span>

| ❌ 表面认知 | ✅ 实际考验 |
|-----------|-----------|
| 我懂穿搭、会选款 | 获取流量（线上+线下） |
| 我有审美 | 找服装供应链、库存周转、定价策略 |
| 我会搭配 | 短视频带货、直播运营、账号运营 |

<span style="color:#8e44ad">📖 **案例 3：篮球馆**</span>

| ❌ 表面认知 | ✅ 实际考验 |
|-----------|-----------|
| 我会打篮球、爱打篮球 | 怎么找到学生（获客） |
| 我可以当教练 | 怎么让他们办卡、续费（转化） |

> <span style="color:#c0392b">📌 **关键结论：**</span> 个人优势不叫真正的优势。个人优势放到业务里还叫优势，才是真正的优势。
>
> 你会打篮球是个人优势，但开篮球馆的核心是获客。你不会打篮球可以雇教练，但不会获客就一定赚不到钱。
>
> 当你学会「获客」这项能力，你不只能开篮球馆，还能开瑜伽馆、游泳馆——这是**可迁移的核心能力**。

### ▸ 各岗位真正需要的能力分析

<span style="color:#8e44ad">📖 **岗位 1：家教**</span>

| ❌ 你以为的 | ✅ 实际需要的 |
|-----------|-------------|
| 高考分数高、教学能力强 | 分清楚谁付钱（家长，不是孩子） |
| 能把学生从 60 分提到 100 分 | 定期主动向家长汇报进度 |
| 学科功底扎实 | 维护家长关系，提高续费率 |

> 家长觉得你有用就有用。哪怕孩子只从 60 分提到 90 分，但你跟家长关系维护得好，续费率就高。甚至可以发「仅家长可见」的朋友圈展示责任心。

<span style="color:#8e44ad">📖 **岗位 2：教培机构老师**</span>

| ❌ 你以为的 | ✅ 实际需要的 |
|-----------|-------------|
| 学科能力强、上课生动有趣 | 课程转化能力 |
| PPT 做得好 | 续费率 + 转介绍（裂变） |

> 机构考核你的不只是教学，还有销售和裂变能力。

<span style="color:#8e44ad">📖 **岗位 3：新媒体运营**</span>

| ❌ 你以为的 | ✅ 实际需要的 |
|-----------|-------------|
| 爱刷小红书、抖音、网感好 | 理解用户需求，拆解爆款 |
| 喜欢看短视频 | 持续产出选题，分析数据做转化 |
| 是「输入型」爱好者 | 是「输出型」生产者——跟你怎么看没关系，跟你怎么生产有关系 |

<span style="color:#8e44ad">📖 **岗位 4：HR 招聘岗**</span>

| ❌ 你以为的 | ✅ 实际需要的 |
|-----------|-------------|
| 懂人力资源、沟通好 | 筛简历、判断岗位匹配度 |
| 性格外向、亲和力强 | 把控候选人甚至老板的心态 |
| 跟人打交道 | **比老板更懂业务需求**——老板可能也不知道自己要招什么样的人 |

<span style="color:#8e44ad">📖 **岗位 5：产品经理**</span>

| ❌ 你以为的 | ✅ 实际需要的 |
|-----------|-------------|
| 画原型图、懂技术 | 大量时间花在跨部门沟通协调上 |
| 有很多功能建议 | 把技术、业务、用户线统一起来，「让力发在一个地方」 |

## 🎯 第三趴：投递策略与时间规划（下）

### ▸ 时间节点

<span style="color:#d35400">🎯 **关键时间线：**</span>

```
5 月下半月 ─── 6 月中上旬 ─── 6 月 15 日前 ─── 期末周
     │                │              │
     └── 修改简历     └── 大量投递   └── 至少投 100 份
```

- 每天花 **10~20 分钟**，投 **10~20 个**岗位
- 简历按上述标准改好后，每周微调一次即可，不花太多时间

### ▸ 大厂投递策略

> [!TIP] 📎 关联资料
> - 详见 [[中国中厂大厂基础摸排-阿文.pdf]]（各公司详细情况 + 行业黑话）
> - 详见 [[中国中厂大厂招聘官网大全-阿文.pdf]]（各公司招聘官网链接大全）

**操作步骤：**

1. 进入招聘官网 → 点「校园招聘」（不要点社会招聘）
2. 区分「转正实习」和「日常实习」→ 投日常实习
3. 看岗位要求：没写年级要求的都可以投
4. 了解各公司限制（如字节可投 2 个职位，阿里可投 2 个意向等）

<span style="color:#27ae60">✅ **策略要点：**</span>

- **限岗位类型**：选定 2~3 个类型的岗位（如只投用户运营），不要全投
- **多城市投递**：同一个岗位可以投不同城市
- **刷经验**：大一进不去没关系，先熟悉流程，大二大三就有机会
- **能力自信**：课程教过的知识库、skill、数据治理等技能，正是大厂需要的

> 哪怕是字节的 AI 产品实习生岗位需要的技能，课程里面都教过。你们从能力上是能进去的，只是可能被学历/年级拦住。多投几次就熟悉了。

### ▸ 小厂投递技巧

<span style="color:#2980b9">💡 **六大技巧：**</span>

| # | 技巧 | 说明 |
|---|------|------|
| 1 | **多换搜索关键词** | 同一岗位在不同公司叫法不同。用 AI 问："这个岗位有哪几种叫法？"全部搜一遍 |
| 2 | **扩大地区范围** | 学校城市 + 家所在城市 + 附近高铁 1 小时可达的城市 |
| 3 | **多用账号** | 两个手机号注册两个招聘平台账号，简历微调后分别投递 |
| 4 | **全平台找** | 招聘软件 + 小红书等社交平台 |
| 5 | **实习时长灵活处理** | 要求 3 个月以上的先答应，快开学再协商能否线上或提前离职找继任 |
| 6 | **被拒也留后路** | 明确不要大一大二的，得体感谢 + 问能否加微信，后面有机会再联系 |

### ▸ 大学四年大概率能进的岗位推荐

> [!NOTE] 📌 以下岗位是讲师根据行业经验整理的、对年级和经验要求相对宽松的岗位。大一进不去大二大三也能进，大学四年总有机会。

<span style="color:#8e44ad">📖 **1. 得物（DeWu）— 商家运营**</span>

- **为什么好进**：得物实习生比正式工还多，电商做得不够强，需要大量实习生去淘宝/抖音找商家来得物入驻
- **工作内容**：对接商家需求、上下架和投流、GMV/ROI 监控
- **跳槽方向**：京东采销、阿里行业运营

<span style="color:#8e44ad">📖 **2. 哈罗（Hello）— 用户运营**</span>

- **为什么好进**：业务线单一，靠用户运营赚钱（生死线），需求大
- **工作内容**：通过用户信息拉群发活动信息

<span style="color:#8e44ad">📖 **3. 蔚来（NIO）— 销售业务运营**</span>

- **工作内容**：给销售主管打下手，做表格数据分析
- **跳槽方向**：销售运营、门店运营

<span style="color:#8e44ad">📖 **4. 转转（ZhuanZhuan）— 投放 / 商务 BD**</span>

- **为什么好进**：投放需求极大（抖音上经常刷到转转广告），每年投放预算很高
- **工作内容**：对接达人博主，问档期和广告费，对接内容和发布排期
- **跳槽方向**：其他品牌的商务 BD

<span style="color:#8e44ad">📖 **5. 创作者运营（内容平台）**</span>

- **适用平台**：支付宝、拼多多、QQ、美团等 APP 内的视频板块
- **工作内容**：去抖音/快手/小红书找博主，让他们把内容同步发布到本平台（给创作者激励）
- **为什么好进**：这些平台内容做得不够好，需要大量创作者入驻

<span style="color:#8e44ad">📖 **6. 快手 — HRBP / 校园大使**</span>

<span style="color:#8e44ad">📖 **7. 滴滴 & 携程 — 实习**</span>

- **为什么好进**：垂类市场没有竞争对手，护城河深，工作相对佛系
- **优点**：业务文档极其全面，不需要怎么学就能上手
- **缺点**：大促/节假日会忙一些

> 这些岗位比字节、腾讯的运营岗位难度低很多。**投了不一定会中，但不投一定不中。** 定期优化，坚持投递，大学四年总有机会。

## 💬 Q&A 答疑精选

<span style="color:#8e44ad">📖 **Q1：高顿实习怎么样？**</span>
> 高顿产品客单价太高（3~5 万），卖不动，比较压榨。不像新东方有几十到几千的产品线。建议慎重。

<span style="color:#8e44ad">📖 **Q2：想进外企怎么准备？**</span>
> ① 调研中国有哪些外企、分布在哪些城市（上海外企最多）
> ② 四六级考高分
> ③ 了解外企行业黑话和中英夹杂的沟通习惯
> ④ 准备英文面试
> ⑤ 不一定要雅思，四级分数高也可以

<span style="color:#8e44ad">📖 **Q3：理工科（机械、地信等）怎么找实习？**</span>
> 大一大二专业知识没学完，很难找到专业强相关的技术岗。策略：先去这家公司的边缘岗位（如机械公司做运营），半只脚踏入行业再转。

<span style="color:#8e44ad">📖 **Q4：想进服装行业但专业不对口？**</span>
> 走电商方向。服装设计已经很卷了，女装退货率极高。

<span style="color:#8e44ad">📖 **Q5：医学专业进不了医院？**</span>
> 先做医学博主/大健康博主/营养学公众号的内容编辑、编导、剪辑，大三大四再跳到医院。

<span style="color:#8e44ad">📖 **Q6：有色金属/智能冶金？**</span>
> 这个专业未来前景好（AI 时代的芯片、储能、原材料都需要）。大一大二难找专业对口，可以先找边缘岗位。

<span style="color:#8e44ad">📖 **Q7：想转行产品经理？**</span>
> 岗位就叫「产品经理」，关键是去什么样的公司——大模型公司、APP 公司、小程序公司还是外包公司，方向不同。

## 📌 总结与行动项
