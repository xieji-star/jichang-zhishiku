简历制作全流程指南

一、核心认知：简历的本质是什么？

1.1 简历不是"工作内容清单"

很多同学写简历的误区：把自己做过的事情罗列一遍——"负责推文撰写""负责视频剪辑""负责数据统计"。这是典型的工作内容清单思维。

好的简历不是写"你被要求干什么"，而是写**"你做了什么、怎么做的、结果如何"**。

核心金句：当 HR 看你的简历时，他看的不是你的工作内容，是你的工作能力。而工作能力只能通过工作成果来体现。

1.2 所有工作都分为三个环节

讲师提出的底层认知框架：所有公司、所有业务、所有岗位，本质都分为三个环节：

流量（Traffic/Flow）→ 产品（Product）→ 交付（Delivery）

这个框架有什么用？ 当你知道自己在学校做的事情属于哪个环节，你就知道可以应聘公司的哪个部门、哪个岗位。

1.3 简历包装 vs 简历造假

关键区分：包装是基于真实经历的优化表达，造假的本质是虚构不存在的事实。

二、简历排版：用 Word 表格做出最干净的简历

2.1 为什么用 Word 而不是模板

用 Word 表格做出来的简历是最干净、最舒服、最好看的，不要用市面上任何简历模板。

2.2 Step-by-Step 排版全流程

第一步：新建 Word 表格

WPS / Office → 新建空白文档 → 插入 → 表格 → 选择 3 列

简历是三列结构（左边单位/学校，中间岗位/专业，右边时间），所以先建 3 列的表格。行数没关系，后面可以加。

第二步：设置无边框

选中表格 → 表格样式 → 边框 → 选择「无框线」

这是最重要的一步！Word 表格只是排版工具，最终输出 PDF 时不应该看到表格线。

第三步：合并单元格

第四步：内容搬入 & 清除格式

所有内容复制到表格后：

  1. CTRL+A 全选
  2. 点击「橡皮擦」（清除所有格式）
    • 清除加粗、字体、大小、下划线、倾斜
    • 回到最初始的纯文本状态

第五步：全局格式化

第六步：CTRL+H 全局替换清理

删除多余空格：

CTRL+H → 查找内容输入一个空格 → 替换为空 → 全部替换

统一标点符号：

CTRL+H → 将英文标点全部替换为中文标点

建议统一为中文标点，看起来更规范。特别注意 AI 生成的文本中常有中英文混用的标点。

第七步：自动调整表格

建议先「根据内容调整」，再「根据窗口调整」。

第八步：拆分表格解决排版冲突

当某个板块（如技能证书）内容参差不齐时，3 列的对齐方式会让排版看起来很乱。

解决方案：

  1. 将光标放在需要拆分的板块
  2. 表格工具 → 拆分表格 → 按行拆分
  3. 拆分后两部分各自独立排版
  4. 再分别用「根据窗口调整表格」铺满

拆分后效果好是因为：不拆分时上下两部分共用列宽设置。下边的内容长短不一会导致全表列宽不正常。拆分后，上下可以各自独立调整。

第九步：微调页数（缩到一页）

如果内容超出一页：

  1. 全选
  2. 行距从 1.5 倍 → 多倍行距 1.4（或 1.3）
  3. 检查是否回到一页
  4. 调整段前段后间距

第十步：添加分割线

表格样式 → 边框 → 选 1.5pt 粗细 → 手动在标题下方画线

2.3 简历排版八项核心标准

2.4 进阶排版技巧

表格行高排查

当表格各行高度不一时，如果调整行距和段前段后都无法解决，问题通常出在表格行高设置：

选中行 → 右键 → 表格属性 → 行 → 指定高度 → 统一为 0.55

一般单行设 0.55，两行内容设 1.10（0.55×2），以此类推。

项目符号美化

添加项目黑点时，默认样式（黑点过大+间距过大）会让排版看起来粗糙：

  1. 选中项目符号 → 右键 → 项目符号 → 定义新项目符号
  2. 字体 → 字号从 10 改为 8（黑点变小）
  3. 制表位 → 位置设为 0.2（黑点与文字间距变小）
  4. 缩进位置也设为 0.2（第二行与左边距对齐）

调整后的黑点精致小巧，不会喧宾夺主。

内容模块化（内容多时）

当简历内容较多时，通过调整间距让内容"一块一块"分开：

  • 内容的行距调小（建议 1.0 倍）
  • 标题加段前间距（0.3 行）
  • 效果：每个板块更像一个独立模块，视觉上更清晰

从第二个板块开始加段前间距，第一个板块不用加，避免顶部空白过多。

避免孤行

如果某行只超出一两个字就换行，看起来不美观：

  • 精简前面内容的措辞，让这一两字缩回去
  • 避免为了省事多加空格或随意换行
  • 如果要换行，内容至少覆盖该行的 1/3 以上才值得换

字号选择建议

格式刷的高效使用

选中已设置好的标题 → 双击「格式刷」→ 依次刷其他标题 → ESC 退出

双击格式刷可以持续使用，单击只使用一次。

2.5 简历四大板块结构

简历建议统一为 4 个板块，按此顺序排列：

教育背景 → 校内经历 → 校外经历 → 技能证书

标题统一标准：

不建议写"自我评价"——HR 更看重你的实际经历，而非自我评价。

经历排序原则：按含金量从高到低排列，不要按时间顺序。最亮眼的经历放第一个。

三、简历内容：STAR 法则 + 三要素公式

3.1 STAR 法则

STAR 法则是简历内容优化的核心工具：

S（Situation 背景）：在什么背景下 / 为了什么目标
T（Task 任务）：需要达成什么目的
A（Action 行动）：你用了什么方法/工具做了什么事
R（Result 结果）：达到了什么成果（最好量化）

3.2 三要素框架

讲师独创的补充框架：流量 → 产品 → 交付

简历优化的终极公式 = STAR 法则 + 流量/产品/交付三要素

为什么要理解整个业务链条？假设你实习时只负责做 PPT（产品包装环节），但面试官可能会问：

  • "你们的产品是怎么推广的？"（流量环节）
  • "后续的用户反馈怎么样？"（交付环节）

如果你只懂自己的那部分，一问就露馅。但如果你理解了整个流量→产品→交付的链路，你就知道怎么回答。

3.3 不同岗位的简历包装侧重点

3.4 简历逻辑性的重要性

简历的逻辑性不是简历的丰富程度。逻辑性好的简历无论被问什么问题都能流畅回答。

常见逻辑问题案例：

原简历写："视频剪辑：月均 8~10 条短视频"

HR 可能会追问：

  1. "你剪的是什么视频？" → 应写明类型（口播、VLOG 等）
  2. "这些视频的选题是你做的吗？"
  3. "哪个选题效果最好？"
  4. "剪辑出来的数据怎么样？"

关键结论：每一条简历内容，你要能预判 HR 会问什么，并在简历中提前回答这些潜在问题。

3.5 量化数据的技巧

不要只写百分比，要写具体的数字范围。

不好的写法：

  • "视频播放量提升了 27%"
  • "播放量从 5K 提升到 1W"

更好的写法：

  • "之前 10 条视频有 1 条爆款，优化后 10 条视频有 5 条爆款"

最佳写法：戳中岗位痛点。

  • 投电商公司 → 强调"擅长切片剪辑"
  • 投 VLOG 博主 → 强调"擅长剪辑 VLOG"
  • 投品牌方 → "我对你家的产品有所了解，对你家的产品内容、能力、业务以及审美都有所了解"

3.6 简历命名

简历命名的一般公式：

姓名（大学+专业）+ 应聘岗位

举例：张三（XX大学+计算机科学）应聘新媒体运营.pdf

这样可以直接看出应聘者的需求，让 HR 一目了然。

灵活调整：

  • 若岗位对入职时间要求高 → 姓名+学校+最快入岗时间
  • 若岗位对某个技能要求高 → 姓名+学校+专业+该技能

四、简历照片与联系方式

4.1 照片的重要性

简历照片是 HR 的第一印象，比简历内容还先被看到。讲师发现一个规律：所有拿到 offer 的同学，简历照片都还可以；所有没拿到 offer 的同学，照片都很差（拉伸变形、爆炸头、戴眼镜、光线暗、乱拍）。

建议：

  • 尽量放照片，看起来更专业
  • 照片一定要好看，可以高 P（大家都高 P，不要不好意思）
  • 统一用白底

4.2 AI 生成证件照方法

不需要去照相馆拍证件照了：

  1. 用手机后置摄像头拍几张日常生活照（正面+左右侧面）
  2. 将照片发给 ChatGPT / GPT Image（GPT-4o）/ Gemini
  3. 让 AI 生成白底证件照，提示词写详细一点
  4. 效果可以比照相馆好很多

4.3 照片插入 Word 技巧

  1. 将生成的证件照插入 Word
  2. 选中图片 → 文字环绕 → 选择「浮于文字上方」
  3. 拖到合适位置，调整大小
  4. 锁定横纵比，避免变形

4.4 联系方式

  • 建议电话 + 微信都写上
  • 如果手机号 = 微信号，写"电话/微信：XXX"
  • 尽量使用有辨识度的邮箱名（如姓名拼音）

4.5 邮箱选择

原则：了解公司生态，用对应的邮箱会增加好感度。

五、简历文件格式

重要：不要直接编辑 PDF，用 Word 改好后重新导出。

六、平台简历优化（招聘平台专用）

6.1 平台简历 vs 附件简历

投递策略：双提交——平台简历和附件简历都提交。

6.2 关键词优化

为什么要优化平台简历？因为平台简历是用来推送岗位的，优化后平台推荐的岗位更精准。

步骤：

  1. 多看 JD，看 10~100 份
  2. 找出经常出现的关键词
  3. 将 AI 整理出的关键词填写在平台简历的"技能、经历"中
  4. 注意只填写与自身相关的关键词，不是所有标签都往上抄

6.3 平台个人信息完善

  • 说明清楚年级、可实习时长、每周可实习天数
  • 头像使用正式头像（没有就让 AI 生成）
  • 所有能填的信息尽量填满，提高账号完整度
  • 关闭隐私设置，让 HR 能直接查看你的简历

6.4 多版本简历

针对不同岗位准备多份适配的简历：

  • 应届生友好平台（如实习僧）→ 多写稳定性、学习能力、愿意干活
  • 垂类技术平台 → 突出技能性的内容
  • 一份简历上不要写多个意向岗位（会让 HR 觉得混乱）

七、简历中的坑点与避坑指南

7.1 常见坑点汇总

坑点 1：逻辑性不足

简历中写的每一条经历，都要能预判 HR 会追问的问题。不要写自己答不上来的内容。

坑点 2：只有工作内容，没有工作成果

"负责 XX"是最差的写法。"通过 XX 方法，实现了 XX 结果"才是好的写法。

坑点 3：排版混乱

  • 岗位和时间不在同一行
  • 顺序不合理（应该是：部门 → 职位 → 时间）
  • 字体不统一（混用宋体、黑体、微软雅黑）

坑点 4：标点符号混用

中英文标点混用是很多 AI 生成文本的常见问题。用 CTRL+H 统一替换。

坑点 5：照片质量差

拉伸变形、背景杂乱、光线昏暗、过度美颜——这些都是减分项。

坑点 6：文件格式错误

发送 Word 而非 PDF，对方打开后排版错乱。

坑点 7：简历命名不规范

"我的简历.pdf""个人简历.docx"——HR 同时收到几十份简历，你的简历马上被淹没。

7.2 简历内容的具体坑点

案例：剪辑运营岗位的简历逻辑漏洞

原简历写："视频剪辑：月均 8~10 条短视频"

暴露的问题：

  1. 职务名有问题——剪辑和运营是两个不同的岗位，不能混为一谈
  2. 没有具体量化数据，不能体现实力
  3. 没有说明视频类型和选题来源
  4. 没有展示剪辑效果数据

简历优化的正确方向：

  • 写清楚视频类型（口播/VLOG/剧情等）
  • 写清楚选题来源（自己策划/团队分配）
  • 写清楚数据效果（播放量/互动率/涨粉数）
  • 写清楚分析优化方法（数据复盘 → 优化选题 → 提升效果）

分析数据的正确理解：

  • 误区：数据分析是优化剪辑顺序和排版
  • 正解：真正影响数据的是视频的选题，而非剪辑细节

7.3 薪资与成果的坑

在简历中写数据时要注意：

  • 播放量 3K5K 偏低；5K1W 合理；1W+ 较好
  • 不要只写百分比提升，要写具体的数字范围
  • 如果数据不太好看，可以用"爆款率"等相对指标代替绝对数字

八、简历常见问题 Q&A

Q1：实习经历太少，简历写不满怎么办？

将校园经历（社团、学生会、班委、课程项目、兼职等）用流量→产品→交付框架拆解，你会发现其实做过很多事。没有"不值一提"的经历，只有"不会包装"的经历。

Q2：大一没经验，简历怎么写？

  • 重点突出学习能力和成长潜力
  • 写课程项目、校园活动、自学技能
  • 投递对年级要求宽松的岗位
  • 先投小公司和创业公司积累经验

Q3：经历太多，怎么取舍？

  • 挑与目标岗位最相关的经历
  • 按含金量从高到低排列
  • 控制在 1 页以内
  • 与目标岗位无关的经历可以删除或精简

Q4：要不要写自我评价？

不建议写或极简（一两行即可）。HR 更看重你的实际经历而非自我评价。如果一定要写，写具体的能力而非空洞的形容词。

Q5：简历需要放作品链接吗？

如果岗位与创作相关（剪辑、设计、文案等），强烈建议放作品集链接。可以在简历中插入超链接，转 PDF 后 URL 会显示为蓝色可点击。

九、简历与投递的配合策略

9.1 先完成再完美

核心策略：花一天把简历改到 60 分，剩下 6 天投递复盘，比花一周改到 90 分更有效。

去面试一次，比在家改 10 次简历更有用——面试会让你真正知道简历该怎么写。

9.2 简历的持续优化

  • 每周微调一次简历
  • 根据投递反馈不断优化
  • 每次面试后复盘，调整简历内容

9.3 不同平台的简历策略

十、行动清单

  • 打开 Word / WPS，新建空白文档
  • 插入 3 列表格，设置为无边框
  • 将现有简历内容搬入表格
  • CTRL+A → 橡皮擦清除所有格式
  • 设置宋体、1.5 倍行距、窄页边距
  • CTRL+H 删除多余空格、统一标点
  • 用拆分表格解决排版冲突
  • 将每段经历改为 STAR + 量化成果的写法
  • 准备白底证件照（手机自拍+AI 生成）
  • 优化简历命名格式
  • 另存为 PDF 检查最终效果
  • 优化招聘平台简历（关键词+个人信息）
  • 针对不同岗位准备多版本简历

十一、总结：简历制作核心公式

好的简历 = 
  干净的排版（Word 表格法）
  + STAR 法则（工作逻辑）
  + 量化数据（工作成果）
  + 针对性调整（岗位匹配）
  + 专业的照片和命名

关键金句：

"用 Word 做出来的简历是所有模板中最干净、最好看的。"

"简历不是写工作内容本身，而是写工作逻辑和工作成果。"

"当 HR 看你的简历时，他看的是你的工作能力，不是你的工作内容。"

"包装可以，但不要造假。"
