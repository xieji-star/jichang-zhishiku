## 二、校园大使实习的价值压榨（核心方法论）

> 对应文档：[校园大使.pdf](总结好的大纲以及笔记/实习训练营/DAY7业务侦探/校园大使.pdf)（岗位基础信息）

### 2.1 不要只当“牛马”，不要只给别人做嫁衣
- **现状**：很多同学只做拉群、小红书引流等前端工作，拉完熟人后就不知道下一步做什么，感觉没有意义。
- **核心思想**：你的工作内容是为企业做宣传，这是基础。但你要在这个基础上**主动为自己争取更多资源**，而不是单纯帮企业干活。

### 2.2 可以主动争取的5类资源
1. **课程资源**：主动问HR要免费试听课、高端课程内部价、课程会员等。HR基本都能给，只是你不问就没有。
2. **中后端活动参与**：不只是线上拉群，主动要求参加线下活动、公益讲座、试听课、用户咨询转化、产品设计引流路径等。这些是中后端的工作，比前端拉群更有含金量。
3. **校内人脉链接**：公司进校做活动时，你会对接学生会、社团、就业协会、校园KOL（关键意见领袖，即在校园内有影响力的博主/达人）、学霸学长学姐等。**把人加到自己的微信里**，不要只放在公司的群里，未来可以持续合作。
4. **提前咨询福利**：实习证明、优秀证书、个人推荐信（自己写好找HR签字盖章）、寒暑假实习内推、校招绿色通道等，都可以主动问。
5. **全国/省级校园大使峰会**：表现优秀可能被邀请参加，可以认识其他学校的大使、总部的人，甚至有机会参加俞敏洪见面会、总部游学等。

> **典型案例**：有同学做校园大使，把身边的熟人拉进群后就不知道下一步该干啥，觉得“为了一个虚无缥缈的内推搞得很累”。——这就是只做了最表层的工作，没有主动往更深层去挖资源。

### 2.3 用实习摸透整个行业的商业模式
- **具体操作**：以新东方为例，你手上接触到的产品有雅思、托福、考研、四六级、教资等。你要主动去思考：
  - 每个产品的**定价**是多少？班型设置（大班/小班/1对1）？
  - 师资怎么配置（几个主讲、几个助教）？
  - **服务流程**是什么？**转化链路**（用户从了解到购买的全过程）是什么？
  - **产品逻辑**（产品设计思路）、**利润率**、**复购率**（用户重复购买的比例）、**转化率**（用户从了解到购买的比例）、**客单价**（平均每个用户花费的金额）是多少？
  - 一个学校能卖多少单？一个省份能卖多少单？
- **目的**：做完这段实习，你不只是干了一份活，而是把**整个教育赛道的商业模式**摸透了。未来去任何一家教育公司，你都有基础。

> **关键提醒**：HR跟你说“你只负责拉人，不用推销产品”，那是站在他的利益角度。你的角度应该是：拉人是基础，但我要利用这个平台了解整个行业。**你不主动思考，就永远只是牛马。**

### 2.4 教育行业6大赛道全貌

> 详细数据见：[教育行业6大赛道.xlsx](总结好的大纲以及笔记/实习训练营/DAY7业务侦探/教育行业6大赛道.xlsx)（含各赛道用户群体、政策支持、市场规模、客单价、复购率、毛利率等完整指标）

直播中梳理了教育行业的6大赛道，每个赛道的受众、政策红利、市场规模、监管红线都不一样：

| 赛道 | 用户群体 | 政策支持 | 代表企业 |
|------|----------|----------|----------|
| 大学生与成人职业教育 | 考研/公考/四六级/教资/职场技能 | ⭐⭐⭐⭐⭐（最高） | 新东方、中公、粉笔、高途 |
| 留学语培与国际教育 | 雅思/托福/GRE/留学申请 | ⭐⭐⭐⭐（高） | 新东方、新航道、环球雅思、启德 |
| K12素质与研学营地 | 3-18岁艺术/体育/编程/研学 | ⭐⭐⭐（中高） | 学而思素养、斑马AI、火花思维 |
| 职业教育To B/企业培训 | 企业内训、校企合作、总裁班 | ⭐⭐⭐⭐⭐（最高） | 中欧、长江商学院、时代光华 |
| 早幼教托育 | 0-6岁亲子早教/托育 | ⭐⭐（中低，监管极严） | 美吉姆、金宝贝、红黄蓝 |
| 教育信息化/AI教育 | 智慧校园、AI题库、学习硬件 | ⭐⭐⭐⭐（高） | 科大讯飞、作业帮、希沃 |

- **逻辑分析**：越往低龄走（早幼教、K12），政策监管越严、政策红利越小；越往成年/职业教育走，政策越支持。因为国家在宏观层面强调“减负”，低龄段容易被打击；而大学生就业难，职业教育反而有政策红利。
- **应用**：你在做校园大使时，可以主动去了解这些赛道，判断自己未来想留在教育行业还是跳出去。

## 三、面试技巧与JD拆解（核心方法论）

### 3.1 面试准备的3个层次
1. **把自己扒透**：把简历上的每段经历都捋清楚，能讲出逻辑和细节。
2. **把对方公司扒透**：用下面这套方法深度拆解目标公司和岗位。
3. **直接聊业务本身**：不要只介绍自己多优秀，要展示你对业务的理解和方案。**这是高级面试逻辑：我不求你选我，你不选我是你的损失。**

### 3.2 JD拆解案例一：新媒体运营经理（30K-60K，14薪）

> 对应文档：[JD拆解-新媒体运营经理.pdf](JD拆解-新媒体运营经理.pdf)（岗位核心平台：公众号、小红书）

**第一步：看硬能力（岗位表面要求）**
- 主要负责平台：**微信公众号 + 小红书**
- 附加提及平台：微博、抖音、快手、B站（面试可能问，但主要准备前两个）
- 行业/产品：某知名**汽车研发上市公司**（杭州，大概率是新能源汽车，只有两三家可猜）

**第二步：看岗位级别与汇报对象**
- 薪资30K-60K、14薪（12个月薪资+2个月年终奖），且是**猎头招聘** → 这是一个中高级管理岗，不是执行岗。
- 汇报对象：大概率是**总监或总裁级别**，因为你的职级已经很高。
- 下属配置：你手下应该有人（编导、运营等），所以面试要问：**我手下管几个人？分别是什么岗位？**
- 权限问题：
  - **人事权限**：我能不能自己招人？能不能给下属定KPI（关键绩效指标）？
  - **预算权限**：我能不能申请经费做投放、做内容？
  - 如果有权限 → 有实权；如果没有 → 只是虚职。

**第三步：看业务本身（JD内容深度拆解）**
- JD写了三点职责（公众号运营、新品上市、跨界营销），其中**“新品上市”放在第二点，优先级高于日常流量** → 说明公司近期可能有新品发布，招这个人就是为了操盘发布会。
- 新品上市的完整闭环（以小米汽车发布会为例）：
  - 上市前：传播策略制定、账号预热、内容储备、跨界合作洽谈（如请代言人）、投放规划
  - 发布会：现场执行、全网上线
  - 上市后：线索（用户留资/联系方式）跟进、到店率（用户到线下门店的比例）、销售额转化
- **如果发布会做得好** → 晋升/奖金/出去吹牛逼；**如果做得不好** → 可能被开除（汽车行业竞争惨烈，一场车成败决定公司生死）。

**第四步：看隐性能力（JD没写但需要的）**
- **跨部门沟通**：发布会需要协调产品、研发、销售、门店、经销商、公关、法务、资本等各部门。
- **向上需求预判**：汇报对象是总裁/副总裁，要能预判他们的需求，可能方案被否要连夜重做。
- **全周期抗压**：从上市前到上市后，整个周期压力极大。

**第五步：看薪资与招聘方式**
- 30K-60K跨度太大 → 底薪大概率是30K，60K要靠业绩（绩效/奖金）才能拿到。
- 猎头招聘 → 要么公司自己HR招不到人，要么之前招过很多人但都走了（岗位难度高）。
- 可追问猎头：**这个岗位发布多久了？** 如果发布3-6个月还没关 → 说明难度极高；如果近期准备关 → 说明企业着急了，可能是捡漏机会。

### 3.3 JD拆解案例二：数据分析实习生（120-160元/天）

> 对应文档：[JD拆解-数据分析实习生.pdf](JD拆解-数据分析实习生.pdf)（工作闭环）

**第一步：看公司是干啥的（从公司介绍和招聘岗位反推）**
- 公司位于**杭州九堡**（直播电商聚集地，类似上海的陆家嘴、北京的中关村）。
- 公司简介中提到“自研DP后台”——**DP = Douyin Partner（抖音品牌服务商）**，即帮品牌在抖音上做代运营（代运营：代替品牌运营账号、直播、投放等）。
- 查看该公司其他在招岗位：直播运营总监、女装主播、拍摄剪辑、AI全栈开发 → 验证了公司是帮品牌做抖音全案服务的。

**第二步：看这个岗位的具体工作（工作闭环）**
- 领导接了一个品牌客户（比如美妆品牌），需要做行业分析、竞品分析、爆款拆解。
- 领导把任务派给你（实习生），你的工作流程：
  1. **接到需求** → 2. **拆解需求**（交付时间？看哪些指标？数据拿来干啥？交付形式是Excel还是PPT？） → 3. **抓取数据**（从飞瓜、蝉妈妈、考古加等第三方平台） → 4. **输出分析成果** → 5. **落地跟进**（方案有没有被客户采纳？有没有帮客户达成目标？）

**第三步：看公司组织架构（推测你的位置）**
- **前台（业务线）**：以品牌为单位，比如一个小组专门服务毛戈平，另一个小组服务周大生。你做的数据分析是给这些前台小组提供支持的。
- **中后台**：售后、品控、短视频拍剪等，给前台提供支持。你的岗位属于中后台。
- **职能**：财务、人事、法务等。
- **你跟前台业务线关系最密切**，因为你分析的数据帮他们做营销策略。

**第四步：看跳槽路径（这段实习能帮你跳到哪）**
- 你的**硬技能**是数据分析（但用的是Excel/PPT，不是SQL/Python，所以是偏市场向的非技术型数据分析）。
- 你的**数据来源**涉及直播数据、短视频数据、账号数据、销售数据 → 你可以包装成“直播数据分析”“短视频数据分析”等。
- 你能接触到的**行业**：大健康、美妆护肤、保健品、运动户外、鞋服、奢品、珠宝 → 未来可以跳到这些行业做运营、市场、编导、策划等。
- **核心逻辑**：你在服务商（代运营公司）做过某行业的数据分析，未来跳到该行业的品牌方，是有说服力的。

**第五步：看面试可以提前准备的**
- 第三方数据平台：JD写了艾瑞咨询、飞瓜数据，你还可以主动了解**蝉妈妈、考古加、巨量算数、猩红**等。
- 行业了解：大健康、美妆、保健品这三个赛道有哪些达人？有哪些爆品？佣金（给达人的销售分成比例）是多少？这些是面试时可以展示的“业务认知”。

## 四、JD拆解通用框架总结

> 对应文档：[JD拆解-新媒体运营经理.pdf](JD拆解-新媒体运营经理.pdf) | [JD拆解-数据分析实习生.pdf](JD拆解-数据分析实习生.pdf)

拆解任何一个JD，可以从以下维度入手：

| 维度 | 关键问题 |
|------|----------|
| **硬能力** | 要会什么平台/工具？要做什么类型的活儿？ |
| **软能力** | 跨部门沟通？向上管理？抗压？ |
| **汇报对象** | 向谁汇报？职级多高？ |
| **下属配置** | 手下有没有人？管几个人？ |
| **权限** | 有人事权吗（招人/定绩效）？有预算权吗？ |
| **业务本身** | 具体做什么？工作闭环是什么？ |
| **公司业务** | 公司靠什么赚钱？营收结构是什么？（年框基础服务费+佣金+返点等） |
| **跳槽路径** | 这段经历能帮我跳到哪些行业/岗位？ |
| **薪资与招聘方式** | 薪资跨度大不大？是猎头招还是HR直招？岗位发布多久了？ |
