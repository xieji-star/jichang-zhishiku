## 💬 分享一：简历投递与面试全流程方法论

> 分享人：第一位连麦同学

### 📄 简历准备

- **持续迭代**：从3-4月跟着社区实打实做任务（自媒体、校园大使、私域业务），简历内容不断丰富
- **量化数据**：简历中给出有量化数据且有结果，在大一群体中简历比较能打
- **排版美化**：跟着文哥直播手把手改简历，提高排版美观度

<span style="color:#2980b9">💡 技巧：</span>跟着社区一步步做任务的同学，基本不用太担心实践经历部分。

### 🎯 投递策略

- **主攻平台**：Boss直聘（岗位多、效率高），也投实习生、小红书继任
- **筛选方法**：先筛选想去的城市和岗位 → 把JD发给AI助手 → 结合文哥教的筛JD方法论筛选 → 再投递
- **公司背调**：看公司规模人数、实缴资本、近期有无官司纠纷
- **附加动作**：投递后附上自媒体账号截图

<span style="color:#c0392b">📌 核心心法：</span>**海投**。投了三四十份，2-3天内终于有一家公司发出面试邀约。千万别觉得没被回复就是没希望，这时候可以"不要脸"一点。

### 🎤 面试准备

- **自我介绍**：1分钟左右，说出与业务最相关的经历并给出结果
- **模拟面试**：跟文哥进行线上模拟面试，文哥问得很细，很多问题在实战中被覆盖
- **复盘迭代**：模拟结束后立即复盘，从简历到面试问答各方面重新改一版
- **忌高级表达**：
  - <span style="color:#27ae60">✅ 可以有适当包装，但最好不要用高大上的术语</span>
  - <span style="color:#c0392b">❌ 写太专业的术语容易给自己挖坑，面试时可能不知道怎么回答</span>
  - 最好的办法：**举例子** — 先说你做了什么 → 取得了什么成果 → 抽象出可复制的模板 → 套用到后续工作中
- **反向提问**：不要问公司能提供什么，要用**利他思维**告诉公司你能在实习中提供什么价值

### 🧠 心态建设

- **心法**：假装自己是一个很牛的人，会淡定很多
- **到岗时间建议**：如果期末结束得到7月初，可以主动跟HR提出**先线上实习一个月**

> [!NOTE]
> 此同学用这套方法论在**第一次面试就拿到了offer**。

### 🎙️ 文哥点评

#### 📌 关于投递节奏
- 3月份讲完简历内容 → 有60分的简历，4月份从60分改到80分 → **4月份就可以开始投了**
- 不需要把简历改到很高水平才开始投，改个三四版就差不多了
- 剩下的时间在投递过程中边投边改，效率更高
- **训练营结束后也要保持投递手感**：每个月花一两天、一个周末去投递，保持对市场的敏感度

#### 📌 关于简历包装
- ✅ 简历要包装，但**不能造假**，也不能写得太高大上
- 大一的同学干的事本身就比较基础，包装得特别高大上反而显得假
- 满分100分，写到六七十分就OK了，剩下二三十分在面试过程中去表达
- **适当留白**：简历中可以留一些术语或内容上的空白，面试时有更多可聊的东西

#### 📌 关于到岗时间
- 为什么让大家在期末考试前投100份出来？**提前试错**
- 你现在先投、先拿面试机会、先跟HR沟通，积累沟通经验
- 等期末考试完或大二大三时，就不会走弯路，时间卡得更精准
- 前面是给你们试错的阶段，**抱着做加法的心态去做**，不要觉得太可惜

## 💬 分享二：巧用身边资源与私域人脉

> 分享人：第二位连麦同学

### 📌 核心经验

#### 1️⃣ 抓住周围资源

- 修改了4版简历，在多个平台投递但没有很好反响
- 看到学长朋友圈发布的岗位，尝试投递
- 经过筛选后获得两个机会：**IP助理** 和 **剪辑岗位**

<span style="color:#27ae60">✅ 学长发布岗位的优点：</span>真实有效、正规、属于内推

#### 2️⃣ 其他资源渠道
- 群里的同学找老师介绍本专业的对口工作
- 招聘会直接和HR联系

#### 3️⃣ 不断投递+复盘修改
- 不会复盘就多麻烦学长帮忙
- 注重**招呼语**，简历不要过于模板化
- 投运营岗要具体标注方向（如AI运营、IP运营），不能笼统写"运营岗"
- **从企业角度自我介绍，不要自嗨**

#### 4️⃣ 面试时拿得出"真东西"
- 面试剪辑岗：没有作品集就借用同学的作品
- 面试IP助理（电商方向）：没有电商自动化经验，但学长有，把流程给面试官看
- <span style="color:#c0392b">📌 **核心逻辑**：包装归包装，但自己也要会一点。要把自己的能力无限接近面试官的要求</span>

<span style="color:#2980b9">💡 额外提醒：</span>如果收到的offer觉得不够好，不要灰心，继续投。

### 🎙️ 文哥点评

#### 📌 朋友圈 vs Boss直聘的渠道区别
- **朋友圈**（私域渠道）：中小公司或创业公司，公司背书不够强，但IP本人或项目背书强
- **Boss直聘/企业官网**：面试流程更正规，大厂可能有五六轮笔试面试
- **朋友圈**：加微信发简历就开始聊，顶多打个语音/视频电话
- ⚠️ 文哥朋友圈里的信息**鱼龙混杂、参差不齐**，即便从文哥朋友圈加的也要了解清楚，不OK可以拒绝

#### 📌 先拿到机会，能力可以慢慢补齐
- 入职前至少有一两周时间，顶多在正式工作前把能力精进一下
- 很多机会就是**你先拿到的**（因为你在场），不是你能力有多高
- **越是不属于你的机会、能力需求高于你现在能力的机会，你的成长速度越快**
- 不用担心"我能力不够所以没办法实习"这个问题

## 💬 分享三：简历迭代与多平台投递策略

> 分享人：陈悦

### 📄 简历经验

- 简历迭代了**6次**
- 方法：先参照优秀案例 → 按文哥建议修改 → **马上投递**
- <span style="color:#c0392b">📌 不要追求完美</span>：之前陷入误区，想等抖音流量好一点再投——但实际上，**只要有一个自己的账号，就算数据没那么好，也已经强过很多人了**
- 根据不同岗位准备适配版本即可：个人准备了两版（运营能力方向、AI运用能力方向），**不用根据每个JD去改，太浪费时间**

### 🎯 投递策略

- **平台选择**：Boss直聘 + 实习生（两个一起投）
- **在线简历**：认真填写，直接copy PDF版本，但信息必须补充完善
- **打招呼语**：
  - ❌ 一开始发详细个人优势介绍 → 回复率低
  - ✅ 换精简版本 → 回复率高
  - 原则：**精简、有礼貌、表达沟通意愿**
- **海投策略**：
  - 每个软件投几十份到100份
  - 实习生可以一键投递100份
  - Boss上把主页每一条都投，等对方回复后再详细看JD与公司筛选
  - 不合适的直接点"不感兴趣"
- **加分项**：投递后附带个人网站链接（作为新媒体运营作品集）

### ⏰ 到岗时间沟通

- 如果是急招岗位，HR问能否一周内到岗 → **先答应**
- 面试时或面试后再表示可以线上实习，再争取
- **先争取到面试机会**，如果面试官对你很满意，会愿意放宽到岗时间限制

### 🎤 面试经验

- **自信**：发自内心相信自己的能力，面试官才会相信你
- **提前模拟**：用AI进行模拟面试，让AI严格深挖简历细节和人岗匹配
- **提前到**：
  - 线下：提前10-15分钟
  - 线上：提前进入腾讯会议
  - 提前到是某些面试官眼里的**加分项**

### 🎙️ 文哥点评

#### 📌 关于数据
- 数据差也可以写，只是表达方式不同
- 整体数据好 → 写单条流量最高的视频数据
- 整体流量不行 → 写总播放量或总粉丝量
- 对于大一阶段，对方要求没那么高，完成手里工作不掉链子就OK

#### 📌 关于海投
- 海投100份 → 10个人回复 → 其中5个OK → 回复那5个
- **像渣男渣女一样**：消息是群发的，谁回你跟谁聊

#### 📌 到岗时间的谈判技巧
1. 沟通得好，对方基本已经下定决心要你
2. **增加对方的拒绝成本**：人家已经过完面试流程，再招一个人得重新面试
3. **提前给线上工作**：先做1周到半个月，拒绝成本更高
4. **找不可抗力理由**：不要讲自己的原因，讲学校有推不开的事情
5. **提前结束实习**：说好3个月只干了2个月，提前一周找不可抗力推掉，或者回学校后继续承担部分线上工作

#### 📌 其他技巧
- **准点到就是迟到**：不管是面试还是谈合作，尽量提早到，建立自己的主场优势

## 💬 分享四：数据分析岗求职与投递SOP

> 分享人：第四位连麦同学
> 面试岗位：数据分析（上海）

### 📄 简历投递方法论

#### 1️⃣ 多版本简历 + 常用语准备

- 准备多份简历，每份侧重点不同
- 准备好打招呼常用语

#### 2️⃣ 打招呼策略

- **保持简洁**：不能一上来就给HR发很长一段
- 简明介绍：学校、专业、拥有什么技能
- 技能要**针对JD侧重方向突出**
- 大概发三四份、五六份就会有人回复

#### 3️⃣ 投递时间

| 最佳时间 | 原因 |
|---------|------|
| **早上9点前** | HR上班前打开看到你的消息在最前面 |
| **下午2点前** | 午休完下午上班前 |

#### 4️⃣ 收藏+二次跟进策略

- 遇到非常合适的岗位，**先收藏，到最佳时间再投**
- 第二天先把收藏的岗位投掉
- 含金量高的岗位，主动发消息："有哪些疑问和顾虑呢？可以随时和我沟通"
- HR没回复 → 可以加："如果觉得不合适，麻烦也告知一下原因"（心善的HR可能会告诉你原因，帮你再次修改简历）
- **一周后再次筛选**：对没读/没回的消息，发消息激励："已经看到你收到我的消息，面试时间什么时候安排一下呢？"

<span style="color:#2980b9">💡 技巧：</span>HR可能会以为"没有安排到你"，点进来看一下。

#### 5️⃣ 多地区多岗位投递

- 投递数量要多，不同地区、不同岗位都投一些
- 如：上海投数据分析和AI岗，杭州AI发达就定向投AI岗

#### 6️⃣ 聊天技巧

- 保持**积极状态**
- 不知道回什么 → **截图给AI，用求职者口吻帮你制定回复**
- 谦虚、积极
- **主动Q流程**：HR看了在线简历不回复 → "可以方便看一下我具体的简历吗？符合要求的话我们进一步沟通"

### 🎤 面试流程（数据分析岗）

- 注重**Excel和PPT**，没有想象中那么高大上
- 第一部分：**笔试（全英文）** → 建议想来上海面技术岗的同学补英文
- 第二部分：面试 → 自我介绍（文哥讲过的心流方法）
- **反向提问**：把自己带入已入职的状态，问即将发生的事情，让HR觉得你上心

### 🔄 复盘

- 即使面试中说错或笔试有写不好的 → **稳住，马上忘掉，该说什么说什么**
- **真诚非常重要**
- 面试前对公司和业务有足够了解，面试时坦诚说出对行业的看法

### 🎙️ 文哥补充

- 直播中拆解过的岗位问题，基本上面试官都有问到
- 如果有不了解、拿不透的JD，可以发给文哥

## 💬 分享五：多段实习经历管理与AI提效

> 分享人：第五位连麦同学
> 个人经历：美团AI校园大使、深圳AI公司线上实习生、自媒体博主、家教中介、校园经济

### 📌 七点核心心得

#### 1️⃣ 遇到困难最不要想到的就是放弃

- 3月开始做美团AI校园大使，最初很难招到人
- 想了各种方法去尝试拉人，拼命做，最终转正
- 成为**福建省负责人**

<span style="color:#c0392b">📌 达克效应提醒：</span>拿到实习 ≠ 前方一片坦荡。你可能站在**愚昧之巅**，接下来是**绝望之谷**。工作中会遇到越来越多的问题和麻烦。

<span style="color:#2980b9">💡 应对策略：</span>找帮手/找大佬请教。态度要好，请教时顺便说说自己的想法和做过的事，让别人知道你不是只会问问题。

#### 2️⃣ 大厂团队 vs 小厂团队的不同思路

| 维度 | 大厂（如美团） | 小厂（如深圳AI公司） |
|------|--------------|-------------------|
| 特点 | 结构清晰、团队成熟 | 制度偏不成熟 |
| 机会 | 接触大佬、打好关系获得经验 | 和负责人一起讨论制度架构 |
| 前提 | 自己要做出成绩，做好本职工作 | 展示认知、资源和能力 |
| 发展 | 大佬愿意教你 | 上级信任你后会找其他事锻炼你 |

#### 3️⃣ 用AI加快工作效率

- 做建联工作：找博主邀请商业合作
- 自己做**爬虫工具**，自动找信息，只需筛选和建联
- **话术提前设计好**，让爬虫根据博主类型自动匹配
- 每天比其他人省下 **1-1.5小时**

<span style="color:#c0392b">⚠️ 注意：</span>建联这件事无法用AI替代。完全外包给AI和别人会错失认识高质量人脉的机会。

#### 4️⃣ 先明白"为什么做"，才能愿意干

- 国际人工智能出版社志愿者证书——看似含金量低
- 找文哥聊过后发现工作中有很多吸引人的点
- 其他实习生觉得浪费时间，但自己因为听过学长讲解，明白经验的价值
- **做实习前先问问自己想要从中获得什么，以目标为导向**

#### 5️⃣ 实习是滚雪球的过程（文哥的金句）

> **实习不是做完一个再做下一个。一个开头后，后面越做越多。**

- 3月校园大使 → 4月自媒体 → 5月校园经济 → 6月家教中介
- 每个实习需要的和能够获得的东西是**相辅相成**的
- 找到第一份实习后，机会和资源会不断涌来，形成**正循环**

#### 6️⃣ 把实习经历转化成自己的资源

- 给深圳公司做的"博主流量池建设系统"
- 即使离职也可以把工具的数据抽走、框架拿去其他公司用
- 通过建联获得自媒体人脉
- **你认识多少人、多少人愿意帮你，决定你未来的成就高度**

<span style="color:#c0392b">📌 框架思维（文哥补充）：</span>用发散思维看自己的工作：
- 积累几百个AI博主 → 未来自己账号做起来可以对接广告
- AI博主需要剪辑/编导 → 帮学弟学妹对接实习
- 手上几百个AI博主 → 做知识付费产品可以拉他们站台
- 没有一件事情是没有价值的，**只是取决于你怎么用它**

#### 7️⃣ 年龄是限制也是红利

- 大一人没资源没人脉，但**负责人因为你是最小的更愿意培养你**
- 前提：自己会AI能帮团队提效，经常分享在社区学到的视野
- 在小厂可以多向负责人汇报交流，上级愿意培养可塑性强的年轻人

> **祝福：早日找到方向，找到实习，赚到自己人生中的100万。**

### 🎙️ 文哥点评

#### 📌 应试思维 vs 商业思维

| **实习生** | ⭐⭐⭐⭐ | 可一起投，回复周期较长 |
| **猎聘** | ⭐⭐⭐⭐ | 适合有实习经历、简历不错的同学，会有猎头主动联系 |

| **小红书找继任** | ⭐⭐⭐ | 有真有假，但也是一个渠道 |

### 💡 猎聘使用技巧
- 简历不错的话，会有**猎头主动联系**
- 可以反向跟猎头聊，了解行业信息
- 例如：把AI短剧实习经历放上去后，很多企业主动来私信

### 💡 Boss直聘使用技巧

- **信息填得越完善，推荐岗位越高质量**
- 在线简历和内容意向填越完善 → 系统推荐越精准
- 简历写得OK的话，HR主动来聊的岗位质量也会不错

### 🎤 面试心法

- **不要害怕技能不过关**
  - 面试AI制作岗时，面试前完全没接触过，花两天晚上学习
  - 实操时leader觉得做得不错，成功拿到offer
  - 一个月后甚至可以当小组长带新人
- **面挂了换个HR继续投同一个岗位** — 实操过的"野路子"
- **简历可以适当美化，只要讲得出来就行**
- 实习是了解一个岗位/行业最好的方式，能获得**一手信息差**

### 🎙️ 文哥补充

#### 📌 三个阶段

| 阶段 | 名称 | 动作 | 心态 |
|------|------|------|------|
| **第一阶段** | 探索期（做加法） | 大量铺工作面，快速试错 | 像间谍一样什么都学 |

- 只要有人在的地方，规矩就是死的
- 除非是大厂机审（代码写死了），只要是HR看的，什么标准都有你的可能性

## 💬 分享七：面试全流程SOP与渠道拓宽

> 分享人：伊自然

### 📄 简历匹配度

- 按文哥直播讲的格式排版
- 内容根据投递行业做匹配
- 观察发现 **80%的岗位JD都能和你做过的事匹配上**

### 🎯 投递技巧

#### 📎 发图片+打招呼
- Boss上HR不回复不能发简历
- **先发截图裁剪的简历图片，再发简短的招呼语**
- HR一天收到很多文字招呼，根本不知道点哪个
- 先发图片 → HR好奇点进来看 → 看到不错就会沟通

#### ⏰ 到岗时间
- **一律回答JD上要求的答案**
- 学校放假时间=7月20多号，但之前说7月初→HR说时间不合适
- 后面统一按JD要求说，面试机会多了

<span style="color:#2980b9">💡 效果：</span>投20份大概有8-9份回复，一天面了3场面试。

### 🎤 面试流程

1. **面试前**：了解公司情况、公司业务、推出的产品、宣发方式
2. **面试中**：
   - 即使没准备好也要**硬着头皮聊下去，编也要编下去**
   - 面试是**掺杂真诚的一场戏，大家都是在演戏**
   - 要自信、积极
   - 开视频时要控制面部表情和语气词（嗯、啊...）
3. **面试后**：
   - 给HR发一段话：表达面试体验感很好、感谢面试官、希望进一步沟通
   - 如果HR说1-3个工作日出结果但最后一天还没通知 → 主动询问
   - 如果没回 → 大概率还在找更好的人选 → **继续投、继续面，直到拿到更多offer**

### 🌐 拓宽实习渠道

| 渠道 | 方法 |
|------|------|
| 📱 **小红书** | 搜"城市+岗位+招继任" |
| 📢 **脉脉、智联** | 除Boss外的补充渠道 |
| 🔗 **线下活动** | 行业沙龙交流会，多加联系方式 |
| 👥 **实习社群** | 找做过实习的学长，很多学长愿意分享资源 |
| 📊 **公司调研** | 面试后用企查查查公司规模、参保人数、纠纷案件 |

> **关于公司调研**：有些公司写的规模与实际查到的不符（如参保人数少、纠纷多），要仔细斟酌。

## 💬 分享八：私域运营——朋友圈就是最好的简历

> 分享人：炳坤

### 📌 核心认知

> **投简历是"通过一张纸包装自己"，朋友圈是"让你全面真实立体地被人看到"。**

### 📱 朋友圈运营方法论

#### 1️⃣ 日常运营

- **持续营销自己**：在朋友圈记录成长
- **让别人不觉得反感**：单纯记录做了什么事情
- **保持曝光**：让贵人有更多看到你的可能

#### 2️⃣ 时间节点互动

- 节假日（如五一）编辑有真情实感的信息
- 结合对方的分享经历，讲述对你的影响
- **不经意间展示最近做的事情**，让对方记住你

#### 3️⃣ 展示多元化能力

| 内容类型 | 展示的能力 |
|---------|-----------|
| 英文学习成就 | 语言能力（对涉外律所很重要） |
| 黑客松/字节跳动活动 | AI能力、技术视野 |
| 中俄沟通活动 | 英文+跨文化沟通 |
| AI生图做海报 | AI工具应用能力 |
| 自媒体10万播放量 | 内容创作能力 |
| 帮律所运营账号 | 行业实战经验 |
| 改简历/连麦经历 | 持续学习成长 |

#### 4️⃣ 让资源主动来找你

- 靠朋友圈运营：接到第一单技能级报告单子 → 与律所长期合作
- 现在手头有**两个律所的账号运营**
- 新律所也是看朋友圈后主动找来

### 🎙️ 文哥点评

- 炳坤是社区里**朋友圈做得最好的几个人之一**
- **自媒体+朋友圈**包装好之后，不会缺工作
- 同样平平无奇的事情，有的人会包装，有的人不会
- **简历信息量有限**，加上自媒体和朋友圈，对方对你的认知更丰富
- 加了微信好友看了很久朋友圈 → 对你很了解很放心 → **省掉很多前期磨合的沟通成本**

## 📌 文哥总结：核心心态与底层思维

> 以下为文哥在整个分享会中的精华观点汇总

### 1️⃣ 关于投递节奏

- 4月份就可以开始投，不需要等简历100分
- 训练营结束后也要保持投递手感
- **提前试错是给你们设置的阶段**，不要怕错过机会

### 2️⃣ 关于简历与面试

- ✅ 包装是需要的，但**不能造假，不能太高大全**
- ✅ **适当留白**，让面试有东西可聊
- ❌ **准点到就是迟到**，提前建立主场优势
- 用**利他思维**反向提问

### 3️⃣ 关于能力焦虑

> **很多机会仅仅是因为你"在场"所以拿到了，不是因为你能力有多强。**

- 先拿到机会，能力可以慢慢补齐
- 越是高不可攀的实习，对你的成长越快
- **不要怕犯错，甚至要渴望犯错** — 现在的错误都是你的学费

### 4️⃣ 指数增长飞轮

- 实习是滚雪球的指数增长，不是线性增长
- 一个机会带来多个机会，像网状一样扩宽
- **一定要让最开始的飞轮滚起来**，差距会非常非常大

### 5️⃣ 商业思维 vs 应试思维

- 商业世界没有标准答案，**反馈才是你的导航**
- 赚钱能力不是考试分数，**能赚到钱才是牛的人**
- **多实践、多行动、打开信息面**

### 6️⃣ 大学三阶段模型

| 阶段 | 心态 | 动作 | 目标 |
|------|------|------|------|
| 探索期（做加法） | 像间谍一样什么都学 | 大量铺工作面 | 快速试错，找到兴趣与能力的交叉点 |
| 生根期 | 锚定方向深耕 | 深入学习、积累SOP | 让自己变得更重要 |
| 终局期（超越工作） | 以终为始 | 将实习转化为创业/经济独立的跳板 | 毕业即经济自由 |

### 7️⃣ 只要有人在，规矩就是死的

- 不是机审的岗位，什么标准都有你的可能性
- **主动、积极、不要被JD上的硬性条件吓退**

### 8️⃣ 对自己狠一点

> "20岁你要跟25岁的人对打，25岁你要跟30岁的人对打。"

- 希望你们大一的阶段就比大四学长想得更多
- 除了方法论，多增加**底层思维、商业理解、人情世故**
- 最终目标：**人人都是超级个体，人人都是创业公司老板**
