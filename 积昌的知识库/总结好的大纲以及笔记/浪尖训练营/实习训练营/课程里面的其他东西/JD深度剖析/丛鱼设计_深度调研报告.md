## 七、商业逻辑与变现分析 💰

### 7.1 商业闭环

```
价值创造（设计服务） → 价值传递（政府采购/企业委托/口碑） → 价值交换（项目款） → 价值反馈（复购/口碑/作品集引流）
```

| 环节 | 公司具体做法 |
|------|------------|
| **价值创造** | 品牌设计、VI 设计、包装设计、广告物料设计 |
| **价值传递** | 广东省网上中介服务超市（政府定点采购）、本地口碑、站酷等设计平台作品展示 |
| **价值交换** | 按项目收费（单笔从几千到几万元不等） |
| **价值反馈** | 政府客户复购、作品集吸引新客户 |

### 7.2 变现逻辑

| 变现方式 | 具体模式 | 收入占比估算 |
|---------|---------|:-----------:|
| **项目制收费**（核心） | 品牌/包装/广告设计按单报价 | 约 70% |
| **政府定点采购** | 通过中介服务超市中标小额项目 | 约 20% |
| **印刷/制作/工程/租赁**（附加） | 设计后的延伸制作、设备租赁 | 约 10% |

> 💡 本质：这是**最典型的乙方"卖手艺"模式**——按项目收设计费，收入取决于接单量，规模天花板低、可复制性差。

## 九、生态位与竞争格局 🏟️

