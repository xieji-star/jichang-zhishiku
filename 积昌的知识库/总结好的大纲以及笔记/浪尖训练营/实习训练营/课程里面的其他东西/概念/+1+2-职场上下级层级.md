# 🏢 +1 / +2 — 职场上下级层级

> [!INFO] 📌 一句话定义
> **+1 和 +2 是互联网大厂（阿里、字节、腾讯等）职场里形容"汇报关系"的黑话**，指的是：
>
> **+1 = 你的直属上级（直接 leader，你直接向他汇报的人）；+2 = 你上级的上级（隔一级的大 leader）。** 数字代表"从你往上数第几层领导"。

---

## 一、+1 / +2 到底是什么

### 1.1 从"你"往上数

```
你（新人员工 / 实习生）
  │  +1
  ▼
你的直属上级（组长 / 主管 / 团队负责人）
  │  +2
  ▼
你上级的上级（部门负责人 / 大 leader / 总监）
  │  +3
  ▼
再往上（事业部负责人 / VP）
```

### 1.2 层级对照表

| 说法 | 指的是 | 通俗叫法 |
|------|--------|---------|
| **你** | 你自己 | 员工 / 实习生 |
| **+1** | 你的直接上级 | 直属 leader、组长、主管 |
| **+2** | 你上级的上级 | 大 leader、部门负责人 |
| **+3 / +4** | 再往上数 | 总监、VP、事业部老大 |
| **最顶层** | 公司最大的老板 | CEO / 创始人 |

> 📊 **<span style="color:#e67e22">规律：+N 就是"从你往上数第 N 层领导"。</span>** 加几，就是隔了几级。

---

## 二、为什么不说"领导"而说"+1"

> 💡 **<span style="color:#2980b9">"领导"这个词太模糊，"+1"精确到"到底是哪一位"。</span>**

| 说法 | 问题 |
|------|------|
| **"领导"** | 公司里能叫"领导"的人太多了，谁知道你说的是哪个？ |
| **"我老大"** | 口语可以，但正式场合不够清晰 |
| **"+1"** | 全世界都知道：就是那个我直接向他汇报的人 |

为什么互联网公司特别爱用？

- **组织扁平**：层级多、汇报线复杂，用数字一目了然；
- **避免办公室政治歧义**：说"领导"可能让听的人误会成更大的领导，说"+1"没有歧义；
- **沟通效率高**：一句话就能定位到"人"，不用解释半天"就是我那个组长，组长上面还有总监……"。

> 🔥 **<span style="color:#e74c3c">职场黑话的本质是"效率"：</span>** 用最短的词，表达最精确的意思。听懂 +1 / +2，就听懂了大厂的组织语言。

---

## 三、职场里 +1 / +2 怎么用（常见话术）

### 3.1 日常怎么说

| 场景 | 例句 |
|------|------|
| 介绍自己的汇报对象 | "我的 +1 是韩玲，+2 是雷总。" |
| 问一件事要不要批 | "这个选题方向，我拿去给 +1 过一下。" |
| 表达要向上沟通 | "这事我准备跟 +2 对齐一下。" |
| 说明决策权限 | "加预算得 +2 点头才行，我做不了主。" |

### 3.2 两个关键概念

- **越级汇报（skip-level）**：跳过 +1，直接找 +2 汇报。**<span style="color:#e74c3c">职场里默认是"大忌"</span>**——会让 +1 觉得被架空、不被尊重。除非 +1 明确让你去，或者有极其正当的理由。
- **skip-level 1:1**：公司有时会安排 +2 定期跟你单独聊（1:1），目的是听到"不经过中间层过滤"的真实声音。这时候可以放心聊，但要坦诚而克制，别变成打小报告。

> 📌 **<span style="color:#2980b9">一句话记牢：日常有事找 +1，+2 只在正式场合（绩效、晋升、大项目、skip 1:1）出现。</span>**

## 四、+1 和 +2 到底有什么不同

| 维度 | +1（直属上级） | +2（隔级上级） |
|------|---------------|---------------|
| **角色** | 带你干活、管你日常 | 管你 +1，管整个团队方向 |
| **接触频率** | 几乎每天 | 偶尔（周会、1:1、评审） |
| **绩效怎么评** | **你的绩效主要由 +1 打** | +1 打完，+2 复核/把关 |
| **晋升谁拍板** | +1 提名、写评语 | +2 审批、最终拍板 |
| **资源谁给** | 派活、分资源 | 定盘子、定预算 |
| **什么时候最有用** | 日常成长、工作安排 | 晋升、转岗、跨团队协调 |

> 🔥 **<span style="color:#e74c3c">最核心的区别：</span>** +1 决定你"干得好不好"（日常绩效），+2 决定你"能不能往上走"（晋升空间）。两个都要处好，但重心在 +1。

## 五、和 mentor / 老板 / 领导 的关系区别

很多朋友会把"mentor（导师）"和"+1"搞混，其实是两码事：

| 角色 | 是不是 +1 | 干什么 |
|------|:---------:|--------|
| **mentor（导师）** | 不一定 | 教你、带你、答疑，可能是 +1，也可能是老同事、隔壁组的前辈 |
| **+1（直属上级）** | 是 | 给你派活、管你绩效、决定你转不转正 |
| **+2（大 leader）** | 不是 | 管你的 +1，偶尔关注你 |
| **老板 / 领导** | 看语境 | 口语词，可能指 +1、+2 甚至更高 |

> 💡 **<span style="color:#2980b9">举个例子：</span>** 在创业黑马数智科技部门，你的 mentor 韩玲带你做账号运营（[[创业黑马的新媒体运营岗位剖析]]），而业务线负责人雷勤管着整个团队——**如果韩玲直接带你，她就是你的 +1；雷勤通常就是 +2。** mentor 的价值在"教"，+1 的价值在"管"和"评"。

> ⚠️ **<span style="color:#e74c3c">mentor 不是 +1，别搞混：</span>** 跟 mentor 可以聊成长困惑、问技术问题；但绩效、排期、转正这些"正式的事"，该找 +1 还是找 +1。

## 六、新人 / 实习生怎么和 +1、+2 相处

### 6.1 三条基本准则

1. **有事先找 +1**：工作安排、进度反馈、请假调休，都先跟 +1 说；
2. **别轻易越级**：想找 +2 之前，先想想"这件事 +1 知不知道、同不同意"；
3. **+2 主动找你时，认真对待**：这是刷脸的好机会，提前准备好你的成果和数据。

### 6.2 什么时候 +2 会"出现"

- **绩效 / 转正评审**：+2 会复核你的评价；
- **晋升答辩**：+2 坐在评审席，你的成长他要有印象；
- **skip 1:1**：公司安排的隔级沟通；
- **大项目汇报**：你代表团队讲成果，+2 会听。

> 📊 **<span style="color:#e67e22">实操建议：</span>** 平时可以把"阶段成果"攒起来（数据、作品、复盘），等 +2 出现时能三句话讲清楚你干了什么——**让 +2 认识你，比让 +2 记住你更重要。**

### 6.3 面试里怎么答"你向谁汇报"

- 被问"你之前向谁汇报、团队怎么组织"——大方说：
  - 💡 **<span style="color:#2980b9">"我直接汇报给 +1（XX岗位），业务线的 +2 是 XX，平时主要跟 +1 对齐，重要节点会向 +2 汇报。"</span>**
- 这一句就体现了你**懂组织架构、懂汇报规则**，比只会说"听领导安排"高一个段位。

---

## 七、一句话总结

> **+1 是你每天要面对的人，+2 是你往上走要认识的人。**
>
> 记住三件事：
> 1. **+1 = 直属上级**，管你的日常和绩效，最重要；
> 2. **+2 = 隔级上级**，管你的晋升和空间，要让他认识你；
> 3. **别轻易越级**——越过 +1 找 +2，是职场最容易踩的坑之一。
>
> 听懂 +1 / +2，你就听懂了大厂的"人怎么排、事怎么报"。
