# 📊 ROI — 职场投入产出比

> [!INFO] 📌 一句话定义
> **ROI = Return on Investment（投资回报率 / 投入产出比）**，本来是一个财务概念，用在职场上就是：
>
> **你在一件事上投入的成本（时间、精力、金钱、情绪），与获得的收益（薪资、技能、经验、人脉、跳槽资本）之间的比值。**

---

## 一、ROI 的核心公式

```
ROI = （收益 - 成本） / 成本 × 100%
```

或者简化理解：

```
ROI = 你得到的 ÷ 你付出的
```

| ROI 值 | 含义 | 例子 |
|:------:|------|------|
| **ROI > 1** | 赚了，值得做 | 花3个月实习，拿到了大厂Offer |
| **ROI = 1** | 持平，不亏不赚 | 干了一年，没涨薪也没学到啥 |
| **ROI < 1** | 亏了，不值得 | 免费干了半年，简历上写不出去 |
| **ROI = 0** | 白干 | 投入了时间，没有任何收获 |
| **ROI < 0** | 倒贴 | 不仅白干，还赔了钱/损害了履历 |

---

## 二、职场 ROI 的两大维度

### 2.1 短期 ROI（即时回报）

| 投入项 | 对应成本 | 收益项 | 对应回报 |
|-------|---------|-------|---------|
| 时间 | 每周X小时的劳动 | 薪资 | 到手的收入 |
| 精力 | 脑力/体力消耗 | 即时技能 | 能马上用的能力 |
| 通勤 | 路上花的时间 | 即时人脉 | 认识的人 |

> **短期 ROI 决定你能不能活下来**（房租、吃饭、基本生活）

### 2.2 长期 ROI（复利回报）

| 投入项 | 对应成本 | 收益项 | 对应回报 |
|-------|---------|-------|---------|
| 时间积累 | 长期的投入 | 职业品牌 | 行业内的认可度 |
| 试错成本 | 走弯路的代价 | 跳槽杠杆 | 下一份工作的谈判筹码 |
| 机会成本 | 放弃的其他选择 | 认知升级 | 对行业的理解深度 |

> **长期 ROI 决定你能走多远**（职业天花板、收入上限）

---

## 三、求职场景中的 ROI 评估框架

### 3.1 评估一份实习的 ROI

当你在看一份实习/工作时，从以下四个维度算 ROI：

#### 📐 公式：实习 ROI =（薪资 + 技能积累 + 履历背书 + 跳槽杠杆）÷（时间投入 + 机会成本 + 情绪消耗）

#### 得分表（每个维度 1-10 分）：

| 评估维度 | 具体内容 | 打分 |
|---------|---------|:----:|
| **💰 薪资回报** | 到手工资、补贴、福利 | /10 |
| **🛠️ 技能积累** | 能学到什么硬技能/软技能 | /10 |
| **🏆 履历背书** | 写在简历上有没有分量 | /10 |
| **🚀 跳槽杠杆** | 对下一份工作的帮助有多大 | /10 |
| **⏰ 时间成本** | 每天/每周要投入多少时间 | /10（越高=成本越低） |
| **🧠 机会成本** | 如果不去这里，还能去哪 | /10（越高=放弃的越多） |
| **😤 情绪消耗** | 工作环境是否健康、有没有PUA | /10（越高=越舒服） |

> **总分 > 40**：可以考虑
> **总分 30-40**：仔细权衡
> **总分 < 30**：慎重，大概率不值得

### 3.2 不同实习类型的 ROI 特征

| 类型 | 短期薪资 ROI | 长期履历 ROI | 典型代表 |
|:----:|:-----------:|:-----------:|---------|
| **大厂正式实习** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 字节、腾讯、美团 |
| **小厂核心岗位** | ⭐⭐ | ⭐⭐⭐⭐ | 创业公司核心业务 |
| **远程培训生** | ❌（常为零） | ⭐（几乎无） | 就是你刚看的那家 |
| **打杂实习** | ⭐⭐ | ⭐⭐ | 端茶倒水、重复劳动 |
| **付费实习（买）** | ❌（倒贴钱） | ⭐⭐⭐（造假风险高） | 中介卖的远程PTA |

## 四、高 ROI vs 低 ROI 的特征识别

### ✅ 高 ROI 实习的特征

| 特征 | 说明 |
|------|------|
| **💰 明确薪资** | 正规公司都有实习工资，远低于市场价=警惕 |
| **📋 职责清晰** | JD写清楚你要做什么、用什么技术栈 |
| **🧑‍🏫 有人带** | 有mentor或导师制度 |
| **📈 可量化产出** | 结束时能拿出作品集/数据成果 |
| **🏢 公司有产品** | 有公开的官网/产品/客户 |
| **🔗 有品牌背书** | 公司名字说出去有人知道 |

### ❌ 低 ROI/负 ROI 实习的特征

| 特征 | 说明 |
|------|------|
| ❌ **零薪资/倒贴** | 用"热爱"、"学习机会"代替工资 |
| ❌ **职责模糊** | "产品或程序或美术皆可"——你自己选吧 |
| ❌ **面试不谈技能只谈理念** | 全程画饼、洗脑 |
| ❌ **威胁候选人** | "拉黑你"、"小心点" |
| ❌ **频繁强调"不是诈骗"** | 此地无银三百两 |
| ❌ **长期招聘** | 永远在招人 = 留不住人 |
| ❌ **没产品/没官网** | 只有概念，没有落地的东西 |
| ❌ **虚拟地址/空壳公司** | 工商信息异常（实缴0、参保0） |

## 五、现实案例 ROI 计算

### 案例一：刚才分析的"造世界"培训生

| 投入 | 成本 |
|:----|:----:|
| 时间 | 每周X小时远程 |
| 机会成本 | 放弃了其他实习机会 |
| 情绪成本 | 面试就被威胁，入职后可想而知 |

| 收益 | 回报 |
|:----|:----:|
| 薪资 | **0元**（面试明确说"没有薪资"） |
| 技能积累 | ⭐ 极低（没有技术栈、没有产品） |
| 履历背书 | ❌ 公司无知名度 |
| 跳槽杠杆 | ❌ 零薪资经历没说服力 |

> **ROI 计算：**
> - 收益 ≈ 0
> - 成本 = 大量时间 + 情绪消耗 + 机会成本
> - **ROI ≈ 0 甚至为负数** ❌

### 案例二：创业黑马的正式实习（对照）

| 投入 | 成本 |
|:----|:----:|
| 时间 | 工作日通勤+工作 |
| 机会成本 | 放弃了其他选择 |

| 收益 | 回报 |
|:----|:----:|
| 薪资 | ✅ 有实习工资 |
| 技能积累 | ✅ 新媒体运营全流程（脚本→剪辑→发布→运营） |
| 履历背书 | ✅ 创业黑马是上市公司 |
| 跳槽杠杆 | ✅ 能拿出作品集和数据成果 |

> **ROI 计算：**
> - 收益 > 0（薪资+技能+履历）
> - 成本合理
> - **ROI > 1，正的投入产出比** ✅

## 六、ROI 思维的进阶用法

### 6.1 在面试中展示 ROI 思维

当面试官问"你为什么选择我们公司"，用 ROI 思维回答：

> **"我评估过自己的时间投入——我希望这段经历能给我三个回报：** 在具体业务中锻炼XX能力、接触真实的XX技术栈、产出可量化的XX成果。我看过贵公司的XX产品和XX业务，觉得这里能同时给到我这三样。"**

这样就比其他候选人"我觉得贵公司很厉害"的答案高出几个层次。

### 6.2 用 ROI 判断是否该离职

```
当前工作的 ROI = 当前收益 ÷ 当前投入

如果连续3个月 ROI < 1（即你感觉"越来越亏"），
且没有明确的改善路径 → 就该考虑动了。
```

### 6.3 "造世界"这类公司的核心套路

这类公司能存在的唯一原因，就是利用了**大学生不会算 ROI** 的心理：

| 他们的套路 | 对应的 ROI 误区 |
|-----------|---------------|
| "这是难得的学习机会" | 把"学习"和"工作"混为一谈——学习是你付钱，工作是他付钱 |
| "不要用短期眼光看" | 让你忽视**短期ROI为0**的事实 |
| "内推大厂" | 用一个**概率极低且无法兑现**的承诺来替代**确定的回报** |
| "我们有海外背景" | 用无法验证的信息包装，实际上没有可衡量的价值 |
| "热爱"、"情怀"、"理想" | 用情绪替代理性计算——**工资是工资，热爱是热爱，两者不冲突** |

> [!WARNING] 🔴 **核心原则**
> **任何让你放弃计算 ROI 的劝说，本质都是在为低 ROI 甚至负 ROI 辩护。**
>
> 真正的高 ROI 机会不怕你算——越算越觉得值。
> 只有低 ROI 的坑才希望你"别想那么多"、"看长远点"。

---

## 七、一句话总结

> **ROI 思维 = 把你投入的每一分钟时间，都当作一笔投资。**
>
> 你不是在"找工作"——你是在**配置你人生中最稀缺的资源：时间**。
>
> 时刻问自己三个问题：
> 1. 我在这件事上投入了什么？
> 2. 我从中得到了什么？
> 3. 如果我把同样的时间投入别处，会不会得到更多？
>
> **算不清楚 ROI 的事，不要做。**
