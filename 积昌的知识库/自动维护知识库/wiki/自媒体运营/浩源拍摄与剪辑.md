# 自媒体拍摄技巧与剪辑入门

## 概述

基于浩源学长自媒体训练营第三节内容，涵盖低成本拍摄方法、5 个博主案例分析、剪映实操入门和剪辑美感养成。核心逻辑：**先完成再完美**，录制+粗剪就够了，重点是体验整个流程。

## 低成本拍摄方法

### 核心实操：两台手机叠放法

1. 打开录制手机的视频模式，对着自己
2. 眼睛看右上角——那个位置看稿子
3. 把稿子放到右上角位置（用另一台手机/平板/甚至纸条）
4. 眼睛看稿子 → 观众觉得你在看镜头（镜像原理）
5. 把录视频变成**念稿**

> 横屏视频在抖音上比较稀缺，自然让用户觉得"你要讲有用的东西"。横屏看稿子很自然，观众不会觉得你在念稿。

### 克服镜头尴尬的三步法

1. **看稿子不看镜头** — 看不到自己整张脸就不会尴尬
2. **把录视频变成念稿** — 一按录制只管念稿
3. **降低心理预期** — "录视频不是录综艺"

## 博主案例拆解

| 博主 | 风格 | 变现路线 | 核心特征 |
|------|------|---------|---------|
| **全宁（圈宁）** | 横屏+贴脸+看稿子 | 广告商单 | 一句话一切，气口全剪掉，BGM 治愈 |
| **院中小区（冤种小徐）** | 竖屏+快节奏+职场风 | 流量路线 | 语速极快，不给喘息空间 |
| **计算机女生** | 垂类+视觉锤 | 垂直领域 | 拿鼠标当话筒——视觉锤概念 |
| **野塘鸭郎君** | 不露脸+第一视角+AI配音 | 适合不想露脸者 | AI 配音前提：稿子要写得好 |
| **未知大学** | 0.5 秒留人 | 快速起号 | 服装和感觉比稿件更重要 |

### 全宁 vs 浩源路线对比

| 维度 | 全宁（广告路线） | 浩源（产品路线） |
|------|----------------|----------------|
| 粉丝画像 | 泛粉（初高中+大学+考研） | 垂直（大一新生） |
| 变现方式 | 广告商单 | 自有社区/产品 |
| 选题策略 | 广泛覆盖 | 精准垂直 |
| 涨粉速度 | 快 | 相对慢 |

### 复刻的核心逻辑

> 做任何训练都需要标准答案。推荐的复刻顺序：先复刻全宁 → 再复刻院中小区 → 再复刻其他博主 → 最后形成自己独特的风格。

## 剪辑入门——剪映实操

### 核心功能：智能剪口播

1. 右键点击视频轨道 → 选择"智能剪口播"
2. 系统自动识别视频中的文稿，AI 标出每一句话
3. 想删除哪句话，直接删除对应的文字段
4. 删除气口、卡壳、停顿，视频节奏就快了

### 剪辑美感养成

> 顺序：**先养成美感，再学会剪辑。**

**类比逻辑**：每一帧都是一个 PPT。好的剪辑 = 每一帧都排版优雅、视觉舒适。如果你能把视频当 PPT 去剪——你缺少的只是剪辑熟练度。

### 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| CTRL + 鼠标滚轮 | 放大/缩小轨道 |
| ALT + 鼠标滚轮 | 前后滑动 |
| B 键 | 切割 |
| CTRL + Z | 撤销 |
| V 键 | 切换回鼠标 |

### 字幕制作流程

1. 点击左上角文本 → 智能字幕 → 开始识别
2. 系统自动识别语音并生成字幕
3. 调整字幕风格（字体、颜色、背景）
4. 应用到全部字幕

## 核心要点

1. **低成本拍摄** — 手机+干净场景+读顺稿件=够用
2. **两台手机叠放法** — 一个录一个提词
3. **晚上录视频** — 感性占理性，情绪表达成本更低
4. **0.5 秒留人** — 服装和感觉比稿件更重要
5. **先养成美感再学剪辑** — 每一帧都是一张 PPT
6. **智能剪口播** — 核心功能，去气口、提节奏
7. **先完成再完美** — 录制+粗剪就够了
8. **复刻提高阈值** — 每复刻一种风格，录制瓶颈就提高一截
