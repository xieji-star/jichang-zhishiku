# 灌溉系统管路安装

## 概述

水肥一体机灌溉系统的管路安装主要分为**旁路式（Bypass）** 和**在线式（Inline）** 两大类，决定水肥机与主水管的连接关系。选择哪种方式取决于灌溉规模和对精度的要求。

## 核心要点

### 旁路式（Bypass）安装

**连接关系**：与灌溉主管道并联。水肥机从主管道分流出一部分水进行施肥，然后将肥液注回主管道。

| 特性 | 说明 |
|------|------|
| **工作原理** | 部分水流经水肥机，被注入高浓度肥料后，再汇入主管道 |
| **适用场景** | 大中型灌溉系统（大田、果园、种植园） |
| **设备与成本** | 独立施肥泵，结构简单，成本较低 |
| **系统影响** | 不影响主管道流量，压力损失小 |
| **维护与扩展** | 施肥机可独立隔离，扩展大流量相对容易 |
| **混合效果** | 均匀度相对有所不足 |

### 在线式（Inline）安装

**连接关系**：与灌溉主管道串联。灌溉主管道的水全部流经水肥机设备。

| 特性 | 说明 |
|------|------|
| **工作原理** | 所有灌溉水都进入水肥机，在机内完成肥料混合后输送到田间 |
| **适用场景** | 中小型灌溉系统（温室大棚、花卉种植） |
| **设备与成本** | 施肥泵可能即是灌溉系统主泵，集成度高，结构较复杂 |
| **系统影响** | 全部水流经设备，产生一定水头损失（压力损失） |
| **维护与扩展** | 设备串联在主管道中，维修时需关闭整个系统 |
| **混合效果** | 水肥混合更均衡、稳定，更好控制 EC/pH 值 |

### 选型建议

- **大田、果园等大面积灌溉** → **旁路式**：更经济、灵活
- **温室、大棚等精细种植** → **在线式**：EC/pH 控制更稳定

### 更多安装细分类型

| 类型 | 原理 |
|------|------|
| **旁路吸肥式** | 利用文丘里原理，通过水压差吸取肥料 |
| **旁路注肥式** | 使用独立加压泵提供压力驱动文丘里吸肥 |
| **主管压差式** | 在主管道上安装减压阀制造压差来吸肥 |
| **主管加压式** | 利用灌溉系统水泵进出口压差驱动文丘里管 |

## 关键概念

- **文丘里原理**：流体通过缩径段时流速增加、压力降低，利用压差吸取肥料
- **水头损失**：水流经设备/管道时因摩擦等导致的压力下降
- **旁路式**：并联连接，部分水流经设备
- **在线式**：串联连接，全部水流经设备
