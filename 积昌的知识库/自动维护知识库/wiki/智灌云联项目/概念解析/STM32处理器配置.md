# STM32 处理器配置

## 概述

STM32 是意法半导体（ST）推出的 32 位微控制器家族，基于 ARM Cortex-M 内核。在智灌云联项目中，STM32 作为**下位机执行核心**，负责模糊 PID 运算、注肥泵 PWM 驱动和 EC/pH 传感器读取，是连接 AI 决策与物理执行的"肌肉"。

## 核心要点

### STM32 不是一颗芯片，而是一个产品家族

STM32 是一个庞大的产品家族，不同系列搭载不同性能档次的 ARM Cortex-M 处理器内核。可以将 ARM Cortex-M 理解为一系列不同性能档次的"发动机"，STM32 的不同系列就是搭载了不同"发动机"的车型。

### 常见 Cortex-M 内核型号

| 内核型号 | 定位 | 特点 |
|----------|------|------|
| **Cortex-M0/M0+** | 入门级 | 超低功耗，成本极低 |
| **Cortex-M3** | 主流性能 | 性价比高，最普及 |
| **Cortex-M4** | 高性能 | **带浮点运算单元(FPU)和 DSP 指令**（适合做算法） |
| **Cortex-M7** | 超高性能 | 主频最高可达 600MHz |
| **Cortex-M33** | 最新一代 | 带硬件安全功能，适合物联网 |
| **Cortex-M55** | AI 加速旗舰 | 专为边缘 AI 设计 |

### STM32 主要系列及对应处理器

| STM32 系列 | 处理器内核 | 定位 | 典型型号 |
|-----------|-----------|------|----------|
| **STM32F1 系列** | Cortex-M3 | 通用型，最经典普及 | STM32F103C8T6 |
| **STM32F4 系列** | Cortex-M4（带 FPU） | 高性能，适合算法处理 | STM32F407、STM32F429 |
| **STM32F7 系列** | Cortex-M7 | 超高性能，主频 216MHz | STM32F767 |
| **STM32H7 系列** | Cortex-M7（或 M4 双核） | 性能旗舰，支持 AI 加速 | STM32H743 |
| **STM32G4 系列** | Cortex-M4 | 混合信号处理，优化电机控制 | STM32G474 |
| **STM32L4 系列** | Cortex-M4 | 低功耗与性能平衡 | STM32L476 |
| **STM32MP1 系列** | Cortex-A7 + M4 双核 | 可跑 Linux 的应用处理器 | STM32MP157 |
| **STM32WL 系列** | Cortex-M4 + M0+ 双核 | 集成 LoRa 无线通信 | STM32WL55 |

### 智灌云联项目的选择

根据技术描述（负责模糊 PID、实时控制注肥泵、EC/pH 读取），最可能的型号是：

#### 首选：STM32F407（Cortex-M4 内核）

| 参数 | 值 |
|------|-----|
| **主频** | 168MHz |
| **浮点运算单元（FPU）** | 有（单精度 FPU） |
| **DSP 指令** | 有 |
| **Flash** | 1MB |
| **RAM** | 192KB |
| **优势** | 性能充足，生态成熟，资料丰富，价格实惠（约 30-50 元） |

> 项目中使用 STM32F407 微控制器，搭载 ARM Cortex-M4 内核，主频 168MHz，内置浮点运算单元，专门负责模糊 PID 运算和注肥泵的实时 PWM 驱动控制，确保 EC 调节的阶跃响应时间 ≤12 秒。

#### 备选：STM32G474（Cortex-M4 内核）

- **主频**：170MHz
- **优势**：比 F4 系列在模拟信号处理和电机控制上更强，适合四通道注肥泵的精准驱动
- **高精度定时器**：专门优化了电机/泵控制

#### 不推荐：STM32F103（Cortex-M3 内核）

- 虽然便宜（约 10-20 元），但**没有 FPU**，做浮点数 PID 计算会很吃力，精度和响应速度不够

### 型号命名规则（以 STM32F103C8T6 为例）

| 部分 | 含义 |
|------|------|
| **STM32** | 品牌和架构（32 位 ARM） |
| **F** | 系列：F=通用，L=低功耗，H=高性能 |
| **103** | 子系列：数字越大性能越强 |
| **C** | 引脚数：C=48 脚 |
| **8** | Flash 容量：8=64KB |
| **T** | 封装类型：T=LQFP |
| **6** | 温度范围：6=工业级（-40°C ~ 85°C） |

### 在系统架构中的角色

```
Jetson Nano（上位机 - AI大脑）
    ↓ UART 串口通信
STM32（下位机 - 执行核心）
    ↓ PWM 控制
注肥泵/电磁阀（执行器）
    ↓ ADC 采样
EC/pH 传感器（反馈）
```

- **Jetson Nano**：运行 LSTM 模型做 AI 推理，生成灌溉决策
- **STM32**：接收决策指令，执行模糊 PID 控制，驱动注肥泵和电磁阀
- **通信方式**：UART 串口连接，两块板子之间最简单的通信方式（3 根线）

## 关键概念

- **MCU（微控制器）**：单片集成电路芯片，包含处理器、内存、输入输出接口，无操作系统，通电即运行
- **FPU（浮点运算单元）**：专门处理浮点数计算的硬件单元，对 PID 控制精度至关重要
- **PWM（脉宽调制）**：通过快速开关控制平均功率，以 1kHz 频率控制注肥泵转速
- **UART 串口**：两块板子之间最简单的通信方式（3 根线）
