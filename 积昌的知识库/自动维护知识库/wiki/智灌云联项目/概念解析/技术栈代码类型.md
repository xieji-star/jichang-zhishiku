# 技术栈代码类型

## 概述

智灌云联项目的技术栈分为三个清晰的层次：前端（用户交互层）、后端（业务逻辑与数据处理层）、AI 核心（模型训练与边缘计算层）。三层各司其职，共同构成一个完整的智能水肥系统。

## 核心要点

### 前端：用户交互层

| 平台 | 框架 | 语言 | 功能 |
|------|------|------|------|
| **手机 APP** | Flutter / React Native | Dart / JavaScript | 跨平台（安卓 + iOS），展示设备状态，提供"一键启动"等操作 |
| **设备触摸屏** | Qt | C++ | 本地调试和应急操作，嵌入式环境运行效率高 |

### 后端：业务逻辑与数据处理层（云端服务器）

| 组件 | 方案选择 | 说明 |
|------|----------|------|
| **云服务器** | 阿里云 | 管理用户账号、处理设备数据、提供 API 接口 |
| **后端框架** | Flask/Django（Python）或 Spring Boot（Java） | Python 开发效率高、便于与 AI 模型集成；Java 处理高并发更稳定 |
| **数据库** | InfluxDB（时序数据库） | 专门用于高效存储和查询时间序列数据 |

### AI 核心：模型训练与边缘计算层

| 阶段 | 平台 | 工具/框架 | 作用 |
|------|------|-----------|------|
| **模型训练** | PC（如 RTX 3060 显卡） | Python + PyTorch | 利用历史数据训练 LSTM 预测模型 |
| **模型部署** | Jetson Nano | TensorRT（模型优化转换） + C/C++ | 将模型部署到设备端，加速推理，控制底层硬件交互 |

### 技术栈总结

| 任务 | 语言/框架 |
|------|-----------|
| AI 模型研发 | Python + PyTorch |
| 后端业务逻辑 | Python (Flask/Django) 或 Java (Spring Boot) |
| 用户端 APP | Dart (Flutter) 或 JavaScript (React Native) |
| 底层硬件交互 | C++ |

## 技术选型理由

- **PyTorch 用于模型训练**：动态计算图机制更适合学术研究与快速迭代
- **TensorRT 用于模型部署**：将 PyTorch 模型优化转换，提高在 Jetson Nano 上的推理速度
- **Python 用于后端**：开发效率高，且便于与 AI 模型集成
- **Flutter/React Native 用于 APP**：一套代码生成两个系统应用，降低维护成本

## 关键概念

- **跨平台开发**：一套代码同时生成安卓和 iOS 应用
- **时序数据库**：专门为时间序列数据优化的数据库（如 InfluxDB）
- **TensorRT**：NVIDIA 的模型优化推理引擎
- **边缘计算**：在设备本地（Jetson Nano）而非云端完成计算
