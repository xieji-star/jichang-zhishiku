# 占空比与 PWM 控制

## 概述

占空比（Duty Cycle）是电子控制和工业自动化中最核心的概念之一，指**在一个工作周期里，"干活"的时间占总时间的百分比**。在智灌云联项目中，占空比是连接"算法决策"和"硬件动作"的关键桥梁——AI 说"多加点肥"，占空比就调高；AI 说"少浇点水"，占空比就调低。

## 核心要点

### 通俗理解

占空比就是"干活时间 ÷ 总时间"的百分比：
- 占空比 **100%** → 一直干活（全力输出）
- 占空比 **50%** → 一半时间干活，一半休息
- 占空比 **10%** → 大部分时间休息，偶尔干活

### 在项目中的应用

#### ① 控制注肥泵转速（决定肥料添加量）

智能 Agent 算出目标 EC 值后，模糊 PID 计算注肥泵需要加大或减小力度。**具体实现方式不是改变电压（容易烧电机），而是控制每秒通断电的比例（PWM）**：

- 通电 0.9 秒、断电 0.1 秒 → **占空比 90%** → 泵转得很快，肥料猛加
- 通电 0.3 秒、断电 0.7 秒 → **占空比 30%** → 泵转得慢，肥料少量添加

计划书中的"配比范围 1:100～1:1000"通过占空比实现：
- 占空比 5% → 对应 1:1000（稀肥）
- 占空比 50% → 对应 1:100（浓肥）

#### ② 控制滴灌电磁阀开启时长（决定浇水量）

田间分多个灌溉区，每个区装一个电磁阀：
- 系统判断某区需浇水 10 分钟，但阀门全开水流太猛容易积水
- 控制器让阀门以 **占空比 70%** 运行：开 7 秒、关 3 秒，循环 10 分钟
- 实际总出水量只有全开的 70%，避免地表径流，让水慢慢渗入

**坡地压力补偿**：
- 坡顶水压小 → 占空比设到 90% 多给水
- 坡底水压大 → 占空比降到 60% 少给水
- 保证全田灌溉均匀

#### ③ 节能与硬件保护

- 注肥泵长期以 100% 占空比全速运转，电机 3 个月可能过热烧坏
- 用 **50%-70% 占空比**，既满足流量需求，又给电机留出散热时间
- 电机寿命延长 **2-3 倍**，是"低成本维护"的重要技术支撑

## 完整控制链路

> LSTM 预测需水量 → 智能 Agent 换算成目标 EC 值 → 模糊 PID 根据当前 EC 和目标 EC 的差距 → **计算出占空比数值（如 68%）** → 单片机产生对应方波信号 → 驱动泵/阀门执行

## 关键概念

- **PWM（脉宽调制）**：通过快速通断电来模拟不同电压/功率水平的技术
- **占空比（Duty Cycle）**：一个周期内高电平时间占总时间的百分比
- **方波信号**：PWM 产生的交替通断的波形
- **模糊 PID**：结合模糊逻辑的 PID 控制算法，适应非线性系统
