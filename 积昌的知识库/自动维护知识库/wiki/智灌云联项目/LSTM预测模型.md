# LSTM 预测模型

## 概述

LSTM（长短期记忆网络）是智灌云联的核心 AI 模型，用于预测玉米未来 3 天的需水需肥量。使用 PyTorch 2.0 训练（实验室 RTX 3060 GPU），转换为 TensorRT 引擎部署到 Jetson Nano 边缘设备。7 年田间数据，预测误差 < 5%。

## 核心要点

### 模型架构

| 参数 | 值 |
|------|-----|
| 模型类型 | 双层 LSTM |
| 隐藏单元 | 128 |
| 参数量 | ~15 万 |
| 输入窗口 | 过去 7 天逐小时气象数据 |
| 输出 | 未来 3 天需水需肥总量 |
| 训练框架 | PyTorch 2.0 |
| 推理框架 | TensorRT（FP16 量化） |

### 推理性能

| 指标 | 值 |
|------|-----|
| PyTorch 直接运行 | ~2 秒/次 |
| TensorRT 推理 | ~0.5 秒/次 |
| 精度损失（FP32→FP16） | ~0.3%-0.5% |
| 预测频率 | 每 6 小时 |
| 模型文件大小 | ~25MB（FP16 量化后） |

### 小样本应对策略

2 万条原始数据对 LSTM 来说属于小样本。团队采取三类措施：

1. **正则化**
   - L2 正则化（防参数过大）
   - Dropout = 0.3（训练时随机关闭 30% 神经元）
   - 早停法（验证集误差不再下降时提前终止）

2. **数据增强**
   - 温度 ±0.5℃、降雨量 ±5%、日照时数 ±5%
   - 样本扩充至约 **10 万条**

3. **轻量化模型**
   - 仅 15 万参数
   - 验证集 vs 训练集误差差距 < 2%

### 验证方法：留一法交叉验证

- 用 6 年数据训练，预测剩余 1 年
- 轮换 7 次，取平均误差
- 严格按时间顺序划分（以每年 12 月 31 日为切割点）
- **绝不**用随机划分（会造成未来数据泄露）

### 各年份误差

| 年份类型 | 代表年份 | 误差 |
|----------|----------|------|
| 偏旱年 | 2018 | ~5.8% |
| 偏涝年 | 2021 | ~7.2% |
| 平年 | 2022、2023 | ~3.9%-4.5% |

> 偏涝年误差较高原因：7 年仅 1 年偏涝样本，模型对极端湿润条件的泛化能力较弱。

### 输入特征

| 类别 | 具体字段 |
|------|----------|
| 气象数据 | 逐日最高温、最低温、平均温、降雨量、日照时数 |
| 土壤数据 | 播前全氮、速效磷、速效钾、有机质、pH |
| 作物数据 | 品种（天育108/先玉335等）、播种日期 |

### 训练频率

- **每季度微调**（3月/6月/9月/12月）：增量 Fine-tuning（1-2 小时）
- **每年秋收后完整重训**：7 折交叉验证（6-8 小时）

## 关键概念

- **LSTM**：带三道门（输入/遗忘/输出）的循环神经网络，专门处理时间序列
- **留一法交叉验证**：每次留一年做验证，其余做训练——适合时间序列
- **数据增强**：对原始数据加微小扰动以扩充样本
- **TensorRT**：英伟达推理优化引擎，将 PyTorch 模型转 FP16 量化
- **过拟合**：模型记住了训练数据而非学到了规律——通过验证集误差监控
