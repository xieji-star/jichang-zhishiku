# 硬件架构

## 概述

智灌云联采用 **Jetson Nano（上位机）+ STM32（下位机）** 双层架构。Jetson 负责 AI 推理与决策（LSTM + Agent），STM32 负责实时控制执行（模糊PID）。两块板独立安装，通过 UART 串口通信。整机防护 IP65，工作温度 -30℃~+70℃。

## 核心要点

### Jetson Nano vs STM32

| 对比维度 | Jetson Nano | STM32 |
|----------|-------------|-------|
| **本质** | 微型电脑（带 Linux 系统） | 微控制器芯片（裸机/FreeRTOS） |
| **擅长** | 复杂计算、AI 推理、联网 | 实时控制、精确计时 |
| **响应速度** | 毫秒~秒级（偶尔卡顿） | 微秒级（永不卡顿） |
| **价格** | ~500-800 元 | ~20-50 元 |
| **角色** | **上位机（指挥官）** | **下位机（执行者）** |
| **任务** | LSTM 推理 + Agent 调度 | 模糊PID + 泵/阀控制 |

### 三级分工

| 层级 | 负责芯片 | 任务 | 频率 |
|------|----------|------|------|
| **高层决策** | Jetson Nano | LSTM 预测未来 3 天需水需肥总量 | 每 6 小时 |
| **中层调度** | Jetson Nano | Agent 将总量拆成每日指令 | 每天 |
| **底层执行** | STM32 | 模糊PID 控制泵速，稳住 EC 值 | 每秒几十次 |

### 通信方式

- Jetson ↔ STM32：**UART 串口**（3 根线：TX、RX、GND）
- Jetson ↔ 云：**4G**（主）+ **LoRa**（本地备选）
- 传感器 ↔ 一体机：**RS485** 接口（距离 < 1000 米）

### 传感器兼容性

- 兼容市面上 **90% 以上**土壤传感器（RS485 接口）
- 主要品牌：国产 EC/pH 传感器
- 手动配置：用户提供通信手册 → 可手动配置接入
- 寿命：国产 1-2 年，进口 2-3 年
- 更换成本：约 800 元/年

### 物理参数

| 参数 | 值 |
|------|-----|
| 整机尺寸 | ~60cm × 50cm × 30cm |
| 防护等级 | **IP65**（防尘 + 防喷水，不可浸水） |
| 工作温度 | **-30℃ ~ +70℃** |
| 电源 | AC220V / 太阳能+蓄电池（选配） |
| 本地存储 | 32GB（可扩展至 128GB） |

### 设计亮点

1. **分层决策**：高层/中层在 Jetson，底层在 STM32——互不干扰
2. **安全保障**：Jetson 死机或重启时，STM32 仍按最近一次指令执行
3. **模块化**：两块板独立安装，STM32 损坏换新仅 30 元
4. **国产供应链**：核心部件国产化，降低断供风险

### 低温方案

- Jetson Nano 核心板最低工作温度为 -25℃
- -25℃以下时，用**加热片预热**（功耗约 5-10W）
- 预热时间：取决于环境温度，通常 5-15 分钟
- 加热片由 STM32 控制，不与 Jetson 的启动依赖

## 关键概念

- **UART**：通用异步收发器——最简单的串口通信（3 根线）
- **PWM**：脉冲宽度调制——用"通电占比"控制电机转速
- **RS485**：工业级差分串行通信，抗干扰强，距离 < 1000 米
- **IP65**：防尘（6 级，完全防尘）+ 防喷水（5 级，各方向喷水无影响）
- **LoRa**：低功耗广域网通信，适合无 4G 的偏远地区本地通信
