# 水肥一体机文献综述

## 概述

基于 18 篇学术文献的系统精读，覆盖**硬件与装置研发、物联网与远程监控、需水需肥预测与 LSTM 算法、智能控制算法与决策模型**四大领域。每篇文献提炼核心技术点，末尾以智灌云联项目为参照进行横向对比，明确技术代际差异。

## 核心要点

### 一、硬件与装置研发类（3 篇）

#### 1. 王德哲（2024）——温室水肥气一体化灌溉装置

| 技术点 | 核心内容 |
|--------|----------|
| **水肥气一体化** | 灌溉+施肥+加气三合一，改善根区缺氧 |
| **控制系统** | 西门子 S7-1200 PLC + KTP700 触摸屏 + PID 恒压（精度 ±0.01MPa） |
| **精准度** | 灌溉 >95%，施肥补偿后达 98.69% |
| **vs 智灌云联** | 无 AI 预测（仅 PID），依赖传感器闭环，PLC 方案成本高 |

#### 2. 赵常（2020）——水肥一体式卷盘喷灌机

| 技术点 | 核心内容 |
|--------|----------|
| **卷盘喷灌+水肥** | 比例施肥泵旁路接入卷盘喷灌机主管道 |
| **桁架式** | 灌水均匀度 98%（喷枪式仅 80%） |
| **vs 智灌云联** | 固定比例施肥 vs 动态按需施肥（1:100~1:1000），单套数万元 vs ≤6500 元 |

#### 3. 古亮亮（2023）——声固耦合管路防堵技术

| 技术点 | 核心内容 |
|--------|----------|
| **超声抗堵塞** | 20-40kHz 超声空化效应排除堵塞物 |
| **最优参数** | 25kHz + 100W/L 功率密度 |
| **vs 智灌云联** | 事后疏通 vs 事前预测+预防 |

### 二、物联网与远程监控类（5 篇）

#### 4. 谢文胜（2019）——ZigBee 组网水肥一体化

ZigBee 无线组网（CC2530，空旷 300m）+ STM32F103RCT6 + 三菱 PLC + 比例施肥泵。有遮挡时通信成功率降至 54-75%。

#### 5. 张昆（2018）——WSN 智能灌溉系统

GPRS 无线传输（WG-8010-485）+ 耐特 PLC + 比例施肥泵。田间对比：小麦增产 8.41%、节水 46.1%；玉米增产 0.99%、节水 14.1%。

#### 6. 余锐（2020）——基于 STM32 的农业物联网网关

**亮点**：多协议兼容（RS485、I²C、SPI、ADC、4-20mA、电力载波、433MHz）、4G/NB-IoT 模块化可更换

**核心角色**：物联网网关——向下接传感器，向上接云平台，控制中心+信息枢纽

#### 7. 李小燕等（2024）——水肥药一体机智能控制系统

灌溉+施肥+喷药三合一 + 云平台机器学习（时间序列分析、聚类分析）+ 图像识别病虫害

#### 8. 李凤芝（2018）——基于农业物联网的水肥一体化

ZigBee + 云平台 + Web/APP 双终端 + 四种控制模式 + PLC。田间对比：番茄增产 13.7%，水分生产率提高 77%。

### 三、需水需肥预测与 LSTM 算法类（5 篇）

#### 9. 黄勇（2018）——枸杞需水需肥规律

传统回归建模（二次多项式，R²=0.992），Penman-Monteith 计算 ET₀，无水肥配比推荐。

#### 10. 李学军和程红（2022）——基于 LSTM 的节水灌溉预测

| 维度 | 内容 |
|------|------|
| **模型** | 双层 LSTM，步长 15，学习率 0.03，Dropout 防过拟合 |
| **对比** | LSTM（RMSE=0.0417）优于 RNN（0.1279）和 BP |
| **vs 智灌云联** | 无生育期切换，无边缘部署 |

#### 11. 吴建龙（2022）——LSTM 土壤墒情预测

| 维度 | 内容 |
|------|------|
| **方法** | 灰色关联度分析（GRA）做特征降维 + 克里金插值填补缺失值 + PSO 优化 LSTM 超参数 |
| **结果** | IPSO-LSTM：R²=0.9865，RMSE=1.6373 |

#### 12. 刘天凤（2018）——基于蒸腾量预测的优化灌溉

PSO-SWELM（改进极限学习机）+ 增量式学习机制 + 概念漂移处理。小数据场景下 ELM 的极致优化。

#### 13. 谢佳睿（2024）——LSTM CO₂加富番茄灌溉

| 维度 | 内容 |
|------|------|
| **模型** | 双层 LSTM（隐含层 64,32），步长 7/23，R²=0.9183 |
| **硬件** | 树莓派 4b + STM32 + 重量传感器，模型嵌入边缘设备 |
| **结果** | 产量 +2.3%，可溶性固形物 +11.7%，**节水 30%** |

### 四、智能控制算法与决策模型类（5 篇）

#### 14. 李嘉乐（2019）——自适应水肥一体化智能模型

两级专家系统（一级传统知识 + 二级 LSTM 自适应）+ 利用计量级与农用传感器"起始差"标定（精度提升最高 89.13%）

#### 15. 赵景波等（2020）——智能混肥浓度控制

变论域模糊 PID（论域随误差"伸缩"）+ 正态云模型推理机（云滴替代传统隶属函数）

#### 16. 李嵩（2019）——苹果园水肥灌溉决策控制

| 维度 | 内容 |
|------|------|
| **算法** | PSO 优化模糊 PID（ITAE 性能指标），上升时间 1.10s，超调 7.67% |
| **硬件** | STM32F103RCT6 + 组态串口屏 + SIM900 短信远程控制 |
| **验证** | 新疆塔城苹果园实地验证 |

#### 17. 张仁春（2019）——芝麻水肥配给专家系统

模糊专家系统（FES）：4 输入→3 输出，三角形隶属度函数 7 级划分，Mamdani Min-Max 推理，有效决策率 92.3%

#### 18. 马胜利（2013）——灰色理论与模糊控制灌溉

灰色预测 GM(1,1) + 模糊 PID + BP 神经网络 ET₀ 预测。SIMULINK 仿真：灰色预测模糊 PID 全面优于传统 PID

### 智灌云联核心优势

1. **开环可用**：竞品均依赖传感器实时反馈；仅需气象数据+播种日期
2. **预测层级更高**：竞品预测执行层参数（灌溉量/浓度）；本项目预测作物未来需求
3. **生育期精细化**：数据驱动（LSTM 学习 4 个生育期非线性关系）vs 竞品规则驱动
4. **边缘部署**：Jetson Nano 田间完成推理，单次 <50ms，断网不宕机
5. **双目标预测**：唯一同时预测需水量 + 氮磷钾需肥量的方案
6. **模型可解释**：SHAP/LIME 可解释性分析
7. **成本最低**：国产化 + 无传感器开环，单套 ≤6500 元

## 关键概念

- **技术代际**：自动化(2.0) → 物联网(2.5) → AI+硬件(3.0) → AI+边缘+开环(3.5)
- **开环 vs 闭环**：有传感器反馈修正 vs 纯预测输出
- **留一法交叉验证**：用 N-1 年训练、预测第 N 年，轮换 N 次
