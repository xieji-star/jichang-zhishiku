# 技术 50 问详解

## 概述

本页整理了智灌云联项目技术答辩 50 问（含追问 3 连击），覆盖从数据获取→生育期推算→LSTM 预测→智能 Agent 决策→执行控制→硬件部署→系统集成的完整技术路线，附带回答策略总结。

## 核心要点

### 八大模块概览

| 模块 | 问题范围 | 核心主题 |
|------|----------|----------|
| **一、数据获取与输入层** | Q1-Q8 | 气象数据、播种日期、生育期、GDD、传感器兼容 |
| **二、LSTM 预测模型层** | Q9-Q16 | 预测原理、窗口长度、超参数、可解释性 |
| **三、智能 Agent 决策层** | Q17-Q24 | 配比切换、模糊 PID、开环/闭环、异常处理 |
| **四、执行控制层** | Q25-Q32 | PWM 控制、EC 响应、电磁阀、4G 通信、电源 |
| **五、硬件设计与成本控制层** | Q33-Q39 | 国产替代、BOM 成本、模块化设计、质量检测 |
| **六、系统集成与部署层** | Q40-Q44 | 模式切换、OTA 升级、多设备管理、数据隐私 |
| **七、专利与知识产权层** | Q45-Q47 | 专利内容、软件著作权、开源策略 |
| **八、竞品对比与技术壁垒层** | Q48-Q50 | 与耐特菲姆对比、壁垒分析、一句话定位 |

### 回答问题的"三明治法则"

| 层级 | 内容 | 示例 |
|------|------|------|
| **上层（结论先行）** | 直接回答问题，给出核心结论 | "我们的 LSTM 模型误差 <5%，基于 7 年试验田数据训练" |
| **中层（证据支撑）** | 用数据、来源、验证方式支撑结论 | "采用留一法交叉验证，用 6 年训练、预测第 7 年，轮换 7 次" |
| **下层（坦诚边界）** | 承认局限，展示改进计划 | "目前仅在黑龙江验证，2027 年计划扩展到吉林、内蒙古" |

### 常见追问应答模板

| 追问类型 | 模板 |
|----------|------|
| "数据来源可靠吗？" | 黑大试验田 + 东北农业大学合作 + 第三方验证中 |
| "推广到其他地区行吗？" | 框架通用 → 需替换参数 → 已规划多区域采集 |
| "和 XX 品牌比怎么样？" | 承认差距 → 强调"够用" → 性价比是核心优势 |
| "极端情况怎么办？" | 坦诚局限 → 展示兜底方案 → 说明持续优化机制 |
| "被模仿了怎么办？" | 专利保护 → 数据壁垒 → 供应链先发优势 + 持续迭代 |

### 各模块精选问答

#### 模块一：数据获取与输入层

| 问题 | 核心回答 |
|------|----------|
| Q1：不依赖传感器，仅靠气象数据和播种日期？ | LSTM 基于"作物生长模型+气象修正"双层逻辑：GDD 推生育期+基准曲线+LSTM 动态修正 |
| Q2：播种日期错误对精度影响？ | 偏差 5-10 天影响约 2-3%，系统有 GDD 动态校正机制 |
| Q3：生育期固定天数 vs 品种差异？ | 以 GDD 为主、日历为辅；不同品种有对应参数 |
| Q4：倒春寒如何处理？ | GDD 模型天然应对——低温年生长慢，决策自动推迟 |
| Q6：为什么只选温度/降雨/日照三项？ | 消融实验证明风速/湿度边际贡献仅 0.3-0.5%，不值得增加 |
| Q7：RS485 通信距离有限怎么办？ | 支持传感器扩展（ZigBee/LoRa 可选模块） |

#### 模块二：LSTM 预测模型层

| 问题 | 核心回答 |
|------|----------|
| Q9：7 年数据是否包含极端气候？ | 包含 2018 偏旱、2021 偏涝、2023 高温三种极端场景 |
| Q10：为什么输入窗口是 7 天？ | 实验对比 3/7/14/30 天，7 天综合最优（精度 vs 计算量平衡） |
| Q11：为什么预测 3 天？ | 滚动预测模式：每天预测未来 3 天，但只执行第 1 天的计划 |
| Q12：N/P/K 独立预测还是多输出？ | 三个独立 LSTM 模型，K 精度略低（移动性强，检测更困难） |
| Q13：5% 误差是怎么算的？ | 留一法交叉验证 7 年轮换取平均 |
| Q14：超参数如何确定？ | 网格搜索 9 种组合（层数 1-3 × 单元数 64/128/256） |
| Q15：试验田 vs 农户大田的分布偏移？ | 用管理水平因子校正，2026 年 200 亩示范田验证中 |
| Q16：如何让农户信任黑箱模型？ | SHAP 生成"温度贡献 60%"等可读解释 |

#### 模块三：智能 Agent 决策层

| 问题 | 核心回答 |
|------|----------|
| Q17：水肥配比如何切换？ | GDD 阈值自动切换，读取数据库目标 N:P:K 比例 |
| Q18：模糊 PID 参数如何整定？ | 各生育期不同参数组，试验优化（苗期小 Kp，抽雄大 Kp） |
| Q19：开环模式下如何评估准确性？ | 虚拟传感器方案：水量平衡方程推算土壤含水量作为"伪反馈" |
| Q20：多传感器数据冲突如何处理？ | 加权平均+中位数滤波+一致性检测 |
| Q21：列举 3-5 个典型异常处理？ | ①注肥泵卡死→停止/仅灌水 ②EC 漂移→定期校准提醒 ③下雨判断→阈值 10mm |
| Q22：是否包含经济优化目标？ | 提供"高产模式/节本模式/平衡模式"供用户选择 |
| Q24：每日灌溉量是单次还是多次总和？ | 总量，拆分为多次，有最大单次灌溉量限制防止径流 |

#### 模块四~八（关键数据速查）

| 关键指标 | 数据 |
|----------|------|
| EC 阶跃响应时间 | ≤12 秒（平均值 11.3 秒，超调量 4.2%） |
| PWM 频率 | 1kHz，最小有效占空比 8%（死区效应） |
| 工作温度 | -30℃～+70℃（IP65 防护，-30℃需加热片预热） |
| 太阳能续航 | 连续阴雨天 3-5 天（选配方案） |
| BOM 成本 | ≤6500 元 |
| 专利 | 2 项发明专利 + 1 项实用新型 |
| 传感器兼容 | 8 个品牌 30 余种型号 |

### 答辩前技术自检清单

- [ ] 能一句话说清"无传感器 AI 决策"的原理
- [ ] 能背出所有核心数据（误差 5%、响应时间 12 秒、成本 6500 元、回收期 2-3 年）
- [ ] 能说出 LSTM 模型训练数据的来源、年限、样本量
- [ ] 能说出 PID 参数如何整定、各生育期参数差异
- [ ] 能说出国产与进口传感器的具体差距（精度、寿命、价格）
- [ ] 能说出 Jetson Nano 在 -30℃ 下的启动方案
- [ ] 能说出开环模式与闭环模式的精度差异和适用场景
- [ ] 能说出与大疆/耐特菲姆/华维的本质区别
- [ ] 能展示至少 1 份第三方验证材料或检测报告
- [ ] 能坦然承认至少 2 个技术局限并说明改进计划

## 关键概念

- **三明治法则**：结论先行 + 证据支撑 + 坦诚边界
- **GDD（生长度日）**：衡量玉米生长发育阶段的温度累加指标
- **滚动预测**：每天预测未来 3 天，但只执行第 1 天的计划
- **虚拟传感器**：用水量平衡方程推算土壤含水量作为"伪反馈"
