# 数据与算法

## 概述

智灌云联的数据来自黑龙江大学试验田 2018-2024 年共 7 个生长季，覆盖气象、土壤、作物、需水需肥和产量五大类，累计约 2.5-3 万条实测数据。采用"自动检测 + 人工复核 + 日志留痕"的质量控制体系和"留一法交叉验证"的模型评估方法。

## 核心要点

### 数据来源

- **黑龙江大学试验田 + 双城玉米科技小院**
- **2018-2024 年，7 个生长季**
- **约 2.5-3 万条实测数据**

### 五大类数据字段

| 类别 | 具体字段 | 采集频率 | 采集方式 |
|------|----------|----------|----------|
| 气象 | 最高/最低/平均温、降雨量、日照时数 | 逐小时 | 自动气象站 |
| 土壤 | 全氮、速效磷、速效钾、有机质、pH | 关键生育期（~10-15天/次） | 人工采样 + 实验室化验 |
| 作物 | 株高、叶面积指数、地上部生物量 | 关键生育期 | 人工测量 |
| 需水需肥 | 灌溉量、植株氮磷钾含量 | 逐日（灌溉）/ 关键生育期（施肥） | 人工记录 + 实验室化验 |
| 产量 | 穗重、粒重、含水量 | 收获后 | 实测 + 折算标准水分 |

### 需水量测定：田间水量平衡法

```
需水量 = 灌溉量 + 降雨量 - 径流量 - 渗漏量 - 土壤储水变化量
```

- 灌溉量：水表精确记录
- 降雨量：气象站自动记录
- 径流 + 渗漏：通过隔水层排除控制
- 精度：约 **±5%** 以内

### 需肥量测定：植株全量分析法

- 关键生育期采集 5-10 株代表性植株
- 烘干 → 粉碎 → 消煮 → 实验室检测
- 全氮：凯氏定氮法
- 全磷：钒钼黄比色法
- 全钾：火焰光度法
- 公式：`需肥量 = 植株养分含量 × 生物量`

### 数据质量控制

#### 异常值处理

| 数据类型 | 检测方法 | 处理方式 |
|----------|----------|----------|
| 气象 | 阈值法（<-40℃ / >+40℃）+ 变化率检测（1小时变化>10℃） | 前后 2 小时均值替代 |
| 土壤/作物 | **3σ 原则**（超出均值 ±3 倍标准差） | 标记 + 人工复核 |

#### 缺失值处理

| 缺失程度 | 处理方式 |
|----------|----------|
| ≤ 2 小时 | 线性插值 |
| 2-24 小时 | 前向填充 |
| > 24 小时 | 标记"数据不可用"，不参与训练 |

#### 记录方式

- 双人复核制（一人记录、一人核对）
- 双备份（纸质记录本 + Excel）
- 清洗日志记录：异常值、处理方式、处理人、审核人

### 对照试验设计

| 处理组 | 内容 | 重复 |
|--------|------|------|
| 系统决策组 | 按 LSTM + Agent 推荐方案 | 3 次重复 |
| 传统灌溉组 | 按农户经验/定时定量 | 3 次重复 |
| 优化灌溉组 | 按农技站推荐方案 | 3 次重复 |

> 所有处理地块面积、土壤类型、玉米品种、种植密度保持一致。

### 算法缩写速查

| 缩写 | 全称 | 一句话解释 |
|------|------|------------|
| LSTM | 长短期记忆网络 | 处理时间序列的 AI 模型 |
| RNN | 循环神经网络 | 带记忆的神经网络总称 |
| BP | 反向传播 | 训练神经网络的数学方法 |
| RMSE | 均方根误差 | 评估预测误差的标准指标 |
| PID | 比例-积分-微分 | 工业最经典的控制算法 |

## 数据答辩"3+1"原则

1. **数据来源**：说明来自何处、多长时间、大约多少
2. **数据质量**：说明如何采集、清洗、验证
3. **数据局限**：坦诚承认一个主要局限
4. **改进计划**：给出具体的未来补足路径
