# 行业与公司调研方法论

## 概述

求职前的调研分为三个层次：**城市 → 行业 → 公司**。城市决定产业集群和就业机会密度，行业决定赛道宽度和职业天花板，公司决定具体工作环境和成长路径。用多维度的调研方法交叉验证，能有效避开"坑"公司，找到真正适合自己的机会。

## 核心要点

### 一、城市调研方法论

#### 产业集群分布

| 区域 | 核心城市 | 主导产业 |
|------|----------|----------|
| 京津冀 | 北京、天津 | 互联网、金融、央媒、教育 |
| 长三角 | 上海、杭州、苏州、南京 | 金融、外企、电商、AI、数字经济 |
| 珠三角 | 深圳、广州、东莞 | 通信、电子、智能硬件、跨境电商 |
| 成渝 | 成都、重庆 | 均衡型，覆盖各行业 |

> **原则**：尽量在同一产业集群内跳槽，跨集群迁移意味着积累的人脉和行业认知需要重新建立。

#### 城市选择策略

| 策略 | 适用人群 | 做法 |
|------|----------|------|
| **长期扎根** | 目标明确、愿意承担高竞争 | 选择一线城市，all in |
| **镀金后回乡** | 希望降低生活成本 | 先去发达城市学经验，再回二三线城市降维打击 |

#### 人才政策

- 各城市对本科/研究生有不同补贴标准（生活补贴、租房补贴、创业补贴）
- 例：杭州本科生每年补贴约 2 万（生活+租房），研究生约 5 万
- 关注国家"十五五"规划对各城市的定位，资源会向重点城市倾斜

#### 留学生选城市策略

不要扎堆留学生多的城市（如上海），在留学生少的城市（如成都）更能放大留学优势，竞争更小。

### 二、行业调研方法论

#### 产业链分析框架

从 **上游 → 中游 → 下游 → 配套** 逐层分析：

以宠物行业为例：
> 活体养殖 → 宠物用品品牌 → 短视频带货 → 宠物医疗 → 日常洗护 → 殡葬 → 免费领养模式

分析维度：
- 每个环节的**成本结构**和**利润空间**
- 每个环节的**周期**和**门槛**
- 行业**上下游的议价能力**
- 行业**增长驱动力**

#### 行业报告来源

| 类型 | 来源 |
|------|------|
| 免费官方渠道 | 艾瑞咨询、36氪 |
| 券商研报 | 萝卜投研、东方财富、同花顺 |
| 咨询公司 | 麦肯锡、波士顿咨询（BCG）、贝恩 |
| 四大会计师事务所 | 德勤、普华永道、安永、毕马威的行业报告 |
| 行业协会 | 各行业官方协会发布的数据 |

#### 商业模式分类

| 类型 | 特点 | 案例 |
|------|------|------|
| **产品型** | 卖产品，关注产品力和供应链 | 苹果、小米 |
| **服务型** | 卖服务，关注专业能力和口碑 | 律所、咨询公司 |
| **平台型** | 连接供需双方，关注网络效应 | 淘宝、美团 |
| **内容型** | 卖内容/注意力，关注内容质量和流量 | 抖音、小红书 |

不同类型公司内部部门结构和职业发展路径不同，求职前应先判断目标公司的商业模式类型。

#### 推荐关注赛道

- ✅ **AI/互联网科技** — 数字化转型窗口期（2026-2030）
- ✅ **新能源** — 国家战略方向
- ✅ **医疗健康（含养老）** — 人口老龄化刚需
- ❌ 避免走下坡路的行业：传统制造业、房地产、传统金融

### 三、公司调研方法论

#### 调研渠道矩阵

| 渠道 | 可获取信息 |
|------|------------|
| **企查查/天眼查** | 法人、股权结构、注册资本、注册时间、司法风险、劳动仲裁、社保缴纳人数 |
| **招聘平台多平台对比** | 同一公司在不同平台（Boss直聘、前程无忧等）的岗位类型和数量 |
| **公司官网/公众号** | 融资新闻、新建产线/工厂（→ 预示扩张和招聘需求） |
| **脉脉/领英** | 员工评价、面试经验、公司动态 |
| **办公地址** | CBD 写字楼（资金实力强）vs 共享办公（初创小团队） |

#### 招聘信息分析技巧

- **大量招研发** → 产品还未成型，处于研发阶段
- **大量招销售/市场** → 产品已出，急需商业化
- **岗位发布时长**：3-6 个月还没关 → 难度极高或有坑
- **近期准备关** → 企业着急，可能是捡漏机会

#### 公司类型特点

| 类型 | 优势 | 劣势 |
|------|------|------|
| **大厂** | 晋升路径清晰（如P序列）、品牌背书 | 竞争激烈、分工细、螺丝钉化 |
| **外企** | 福利好、WLB（工作生活平衡） | 国内天花板低，核心资源在总部 |
| **创业公司** | 成长快、六边形战士锻炼、独立负责业务 | 不稳定、资源有限 |
| **国企/央企** | 稳定、福利完善 | 晋升慢、论资排辈 |

#### 薪资与招聘方式解读

- **薪资跨度大**（如 30K-60K）→ 底薪大概率是最低值，最高值要靠业绩/绩效
- **猎头招聘** → 要么公司HR招不到人，要么岗位难度高、之前招的人走了
- **猎头渠道额外问题**：岗位发布多久了？之前有几个人到岗又走了？
- **多平台交叉验证**：同一岗位在不同平台的叫法和描述是否一致

## 关键概念

- **产业集群**：同一行业在地理上的聚集效应，跳槽尽量在集群内
- **商业模式分类**：产品/服务/平台/内容，决定公司的组织结构和岗位特点
- **交叉验证**：通过多个独立渠道获取同一信息，对比判断真伪
- **公司调研"体检"**：面试前对公司做尽职调查，规避风险
