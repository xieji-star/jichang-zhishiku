# 职业规划框架

## 概述

职业规划的核心是**拓宽就业面**——不是找到一份工作，而是让自己有更多选择权。本页整合简历进化方法论（1.0→4.0）、三要素模型深度拆解、基于业务核心的数据写作、各岗位核心数据指标大全、三圆交叉职业规划法、甲方vs乙方选择策略等知识体系，帮助你系统性地规划职业路径。

## 核心要点

### 一、简历版本进化论（1.0 → 4.0）

网上所有的求职博主最多只教STAR法则和数据量化，但在此基础上还应该增加"三要素"和"基于业务核心写数据"。

| 版本 | 名称 | 说明 | 分数 |
|:---:|:----|:----|:----:|
| 1.0 ❌ | **垃圾版（流水账）** | 只写了工作本身，谁干这个岗位都是这个活儿 | 30分 |
| 2.0 📋 | **STAR法则版** | 有背景、任务、行动、结果，但没有数据 | 50分 |
| 3.0 📊 | **STAR+数据量化版** | 有框架有数据（写了3篇推文、触达XXX人） | 70分 |
| 4.0 ⭐ | **STAR+数据+三要素版** | 明确自己在流量/产品/交付中的位置，写业务核心数据 | 80-90分 |

#### 完整进化路径

| 阶段 | 分数 | 说明 |
|:---:|:----:|:------|
| ✅ 四个板块框架完整 | **60分** | 基础框架清晰 |
| ✅ 以上 + STAR法则 + 数据量化 + 三要素 | **80分** | 框架+数据+定位 |
| ✅ 以上全部 + **基于对方业务需求优化数据** | **90分** | 写对方真正关注的数据 |

#### 各岗位四个版本示例

**学生会新媒体部门**：

```
❌ 1.0："担任学生会新媒体部门干事，负责学院公众号推文撰写与活动海报设计"
✅ 2.0：背景(公众号内容老旧)→任务(负责大赛推送宣传)→行动(写推文、做海报)→结果(提升覆盖面)
✅ 3.0：写了3篇推文，通过推广触达XXX个同学，活动参与量增加了XX%
✅ 4.0(流量岗)：重点关注触达人数、阅读量、参与人数——拉新数据
```

**班长/班委**：
```
❌ 1.0："负责班级日常事务管理，组织班级活动"
✅ 4.0：流量+产品双重属性 → 多次触达+活动闭环
```

**奶茶店兼职**：
```
❌ 1.0："负责饮品制作和收银工作"
✅ 4.0(交付岗)：出餐量优化/客诉率降低/出餐速度
```

### 二、三要素模型详解 — 流量·产品·交付

你做的任何工作，都可以被归类为流量、产品、交付三个部分之一。

| 要素 | 含义 | 核心指标 |
|:---:|------|:--------:|
| 📢 **流量** | 让人过来——宣传推广、招新、拉赞助、发推文 | 触达人数、阅读量、参与人数 |
| 🏗️ **产品** | 做出东西来——写推文、剪视频、做海报、策划活动 | 产品质量、功能完成度 |
| ✅ **交付** | 执行落地——现场运营、签到引导、发放证书、客服 | 好评率、完成率、交付质量 |

#### 校内岗位三要素分类

**流量型岗位**：学生会新媒体/宣传部、外联部、社团推广招新
**产品型岗位**：内容创作（写推文/剪视频/做海报）、活动策划、创新创业竞赛
**交付型岗位**：活动现场运营、发放证书、招聘会签到引导、行政文员

#### 核心技巧

用STAR法则和数据量化写好简历后，再加三要素——优先侧重你所属的部分：
- 流量岗位 → 侧重拉新数据
- 产品岗位 → 侧重产品数据
- 交付岗位 → 侧重交付效率和质量

**同时，投递岗位类型决定侧重方向**：
- 投**新媒体运营** → 流量型 → 写拉新、触达数据
- 投**AI产品经理** → 产品型 → 写产品设计数据
- 投**IP助理/行政文员** → 交付型 → 写执行效率数据

### 三、从80分到90分 — 基于业务核心写数据

**核心逻辑**：不同的业务阶段、不同的公司类型，关注的数据指标完全不同。80分是帮自己优化，90分是帮对方优化。

#### 案例：MCN电商公司招聘剪辑实习生

老板真正关心的是**GMV、销售量**，而不是播放量、点赞量。

> 一个视频只有100播放量但能卖5单 → 一个视频有1000播放量但一单也卖不出去 → 电商老板更喜欢那个能卖得出去的。

#### 不同公司阶段的不同关注点

| 公司阶段 | 核心关注 | 简历应写的数据 |
|:--------|:--------|:--------------|
| **从0-1起号** | 播放量、涨粉量 | 爆款率、涨粉速度、能否稳定输出 |
| **稳定变现** | GMV、转化率 | 视频GMV、商品点击率、点击成交率 |
| **引流私域** | 客资、转化率 | 引流人数、私信转化率、单条视频客资 |

#### 常见数据误区

| 误区 | 正确认知 |
|------|---------|
| "发布了15条视频" | 15条不重要，**涨粉多少**才重要 |
| "单条视频播放量10万+" | 峰值不重要，**能不能稳定复制**爆款才重要 |
| "粉丝增长2800个人" | **时间周期**很重要——是一周涨2800还是一年涨2800？ |
| "管理了3个微信群" | 群不重要，**群里有多少人、转化了多少**才重要 |
| "获得了180个微信" | 其中多少个是**高意向**、最终**转化了多少**才重要 |

### 四、各岗位核心数据指标大全

| 岗位类型 | 核心数据指标 |
|---------|------------|
| **新媒体运营（从0-1）** | 播放量、涨粉量、完播率、互动率、能否稳定产出 |
| **新媒体运营（成熟变现）** | GMV、商品点击率、点击成交率、ROI、退货率 |
| **私域运营** | 引流人数、转化率、客资成本、单用户LTV |
| **教培线上推广** | 线索量、线索成本、高意向比例、试听转化率 |
| **教培助教/班主任** | 作业提交率、家长满意度、续费率、转介绍率 |
| **线下地推/课程顾问** | 获客量、地推成本、听课率、听课转化率 |
| **数据标注** | 标注准确率、标注效率、数据通过率 |
| **电商运营助理** | 短视频GMV、商品点击率、点击成交率、ROI、退货率 |
| **内容运营/文案策划** | 搜索排名、收录量、自然搜索流量、内容转化率、留资率 |
| **用户运营/社群运营** | 社群活跃度、用户留存率、社群转化率、单用户LTV |
| **产品运营** | 优化成功条数、时效、用户留存 |

### 五、职业规划框架 — 三圆交叉法

#### 核心框架

**两个轴**：横轴 = 行业（互联网/食品/金融/新能源…）；纵轴 = 岗位（运营/产品/销售/财务…）

**三个圆交叉法**：专业圆 × 岗位圆 × 行业圆

找到两个圆的交叉点就OK，三个都交叉就特别好。

#### 拓宽路径：至少占一个

```
岗位和行业，你至少要占一个才能跳。

如果要跨行跨岗，分两步走：
第一步：要么先进这个行业，干其他岗位
第二步：再跳到这个行业的想去的岗位

或者：
第一步：先干这个岗位，但在其他行业
第二步：再跳到想去的行业
```

**案例：食品专业想去互联网公司做AI产品经理**

| 路径 | 第一步 | 第二步 |
|:----|:------|:------|
| **路径A** | 先去食品公司做新媒体运营（行业不变，岗位变） | 再跳到互联网公司（岗位不变，行业变） |
| **路径B** | 先去互联网公司干其他岗位（行业进去，岗位变） | 再转AI产品经理 |

#### 冷门专业拓宽方向

| 冷门专业 | 可拓宽方向 |
|---------|-----------|
| 地理科学 | → 高德/滴滴做产品运营 |
| 化学 | → 美妆/护肤品公司做产品研发 |
| 英语 | → 跨境电商/外贸，新东方做产品/新媒体 |
| 机械电子 | → 新能源汽车、机器人、具身智能 |
| 生物学 | → 大健康/医美公司 |
| 数学与应用数学 | → 任何需要数据分析的行业 |
| 汉语言文学/历史 | → 没有对口限制，啥都能干 |

#### Offer选择原则

**哪个没有就去哪个**：手上没有的行业→去；没有的岗位→去；没有的公司类型→去。

> 不要在同一件事情上反复做。宁可同时干两段不同的实习，也不要两个时间干两段相同的实习。

### 六、甲方 vs 乙方 — 广度与深度的选择

**追求广度去甲方，追求深度去乙方。**

| 维度 | 🏢 甲方 | 🏗️ 乙方 |
|:----|:--------|:--------|
| 定义 | 金主爸爸，发钱的 | 帮别人做活的 |
| 部门结构 | **多部门**（产品/推广/供应链/行政/财务…） | **单一部门** |
| 广度 | ✅ 能接触不同部门、不同岗位 | ❌ 只有单一方向 |
| 深度 | ❌ 广度优先 | ✅ 专业深度优先 |
| 职业路径 | 可跨部门跳、跨行业跳 | 只能同方向深耕 |

**选择建议**：
- 文科专业、天坑专业、想拓宽就业面的 → ✅ **尽量去甲方**
- 走专业路线的（医学、技术研发）→ 按专业方向深耕
- 财会金融法律专业 → **也建议去甲方**

### 八、常见问题答疑

**Q：数据可以是假数据吗？**
A：可以是假数据，但你要自己能解释清楚，能完成这个闭环。不要编得太夸张，问你你能答得出来就可以。

**Q：实习证明重要吗？**
A：**能力 > 工作记录 > 实习证明。** 最重要的是能力积累，过程中要多保存工作记录（后台数据截图、作品案例、聊天记录等）。

**Q：如何避免中年危机？**
A：只要你一直在上班，就会一直有危机。每个行业周期最多5-10年。避免中年危机最好的方式不是找一份安稳的工作，而是**提高自己的社会能力和灵活性**。

**Q：所有实习都是打杂，怎么办？**
A：你判断的标准是——**你有没有更好的选择？** 你有选择权的前提是你有很多个选择。如果拒绝了手上的，没有其他地方去了，那就先去干。

**Q：付费实习靠谱吗？**
A：付费实习是最后实在找不到的情况下才考虑的选项。尽量先自己投递，自己找。如果家里面有条件，花个几千到1万多可以买一份实习，但尽量别走到这一步。

## 关键概念

- **简历版本进化**：1.0流水账 → 2.0 STAR法则 → 3.0 STAR+数据 → 4.0 STAR+数据+三要素+业务核心
- **三要素模型**：流量/产品/交付——任何工作都可以归入这三个环节
- **三圆交叉法**：专业圆 × 岗位圆 × 行业圆，找到至少两个圆的交叉点
- **甲方优先策略**：文科/冷门专业优先去甲方拓宽就业面
- **业务核心数据**：不同公司阶段关注不同指标，写对方关心的数据
