# 学术裁缝方法论

## 概述

"学术裁缝"是水岛课程（学术裁缝 2.1-2.5）提出的一套**以最快速度"缝"出达到毕业要求的论文的方法论**。其本质是 **"仅论文论"**——一切都只为发论文。核心公式：**论文 = A + B′ + C′**（在一个基准模型 A 上拼接若干学术模块），学术裁缝要做的就是把别人的论文拆成模块、再排列组合缝成自己的论文，最后用"编故事"包装成"发现问题→设计方法→解决问题"的正规科研叙事。

> ⚠️ 本文档仅客观记录该课程方法论，**不构成对学术不端行为的认可**。课程自身也给出了"学术不端的自查边界"（见 2.5 节）。

## 核心要点

### 2.1 学术裁缝的本质：仅论文论

- **论文的本质** = **A+B′+C′**（基准模型 A + 学术模块 B/C 的变体拼接）
- 学术裁缝 vs 科研人：一个拼凑模块、一个探究原理
- **编故事**：把模块拼装包装成"发现问题→设计 B 解决"的正规科研叙事
- 学术圈现实：顶刊顶会轮不到普通人（挂名作者/双盲机制）、名校课题组普遍存在论文流水线
- 需要的能力：高中水平 + 电脑 + 搜论文 + AI 就够了

### 2.2 如何阅读论文（上）

- **搜索渠道**：谷歌学术 / 知网 / 百度学术 / 某宝代下载，WOS 适用场景
- **该读什么**：顶刊顶会、水刊水会、综述、毕业大论文各自的作用与时机
- **读论文的作用不是搞懂论文，而是"拆分论文"**——把任何论文格式化为 A+B+C
- **论文大纲框架**：标题/摘要/引言/相关工作/方法/实验/总结/参考文献
- **阅读策略**：**必读 = 引言 + 方法**；**选读 = 摘要 + 实验 + 总结**；**不读 = 相关工作 + 参考文献**

### 2.2（拓展）期刊与论文的分级

- **查询期刊**：知网 / letpub / 小木虫 / CCF / core
- **刊号区分**：CN（国内认）/ ISSN（警惕只有 ISSN 的野鸡期刊）；地域划分（国家级/省级）
- **国内核心**：北大核心 / 南大核心（CSSCI）/ 科技核心 / CSCD 等 7 大核心
- **国际核心**：SCI / SSCI / A&HCI / EI（SCI 分 Q1-Q4，国内认中科院划分）；国际会议 ISTP / EI（**EI 会议给钱就行**）
- **机构售卖价格参考**：普刊 4-5 千、核心 3-3.5 万、SCI 代写代发 4-5 万
- **学校内部 ABCD 类与顶刊评级**：顶刊 ≈ SCI 1 区 top；计算机 CCF 会议 ABC 类、CCF-A ≈ 顶会
- **水刊判定**：搜 100 篇近两年论文统计期刊名查排名

### 2.3 如何拆分论文

- **目标**：看到论文就格式化 A+B+C，把**基准模型 A** 和**学术模块 B/C/D** 拆出来
- **A vs B 判别标准**：去掉 A 性能变零、去掉 B 性能几乎不变
- **四个位置找 A/B**：摘要（"基于××"=基准模型）、引言（最后几段讲创新和模块）、方法（看框架图和大纲小标题）、实验（**消融实验**才证明模块，对比实验看不出）
- **模块 vs 创新**：模块是真实做的，创新是编出来的故事；A 是大东西（代码量大），B 是小东西

### 2.4 定基准模型

- **基准模型 A 的类别**：可以是论文 baseline、一整篇论文、部分论文，甚至自己拆出来的
- **两条原则**：① 缝出来的模型性能 > 基准模型性能，且 > 近两年部分顶刊顶会；② **论文代码必须开源、一周内可复现**
- **复现结果以复现为准**：别人写 90 你跑 60，超过 62 就行
- **找模型注意点**：找近两年顶刊顶会、性能一直在涨、A 尽量大
- **课题组继承**：师兄师姐直接丢模型——实操与做人道理
- **不开源代码的论文 ≈ 学术造假**（"学裁缝眼中只有老实人"的由来）
- **A 起决定性作用**，决定缝出来的性能上限；基准模型论文要通读精读

### 2.5 定学术模块

- **唯一原则**：模块加到基准模型上**性能有提升就可以用**（无论什么形式加）
- **模块从哪找**：顶刊顶会、水刊水会都可以——模块是小东西，不用开源也能"搞一个差不多的出来"
- **实验基础学到什么程度**：会复现开源模型 + 能设计小模块 + 能把模块缝上基准模型（**"缝合那一瞬间"最难**，AI 不一定能帮你搞定）
- **为什么做"差不多样子"的模块**：A+B+C 要变成 A+B′+C′——B 变 B′ 的合法路径
- **模块的种类**：通用 / 本领域 / 相似领域；非模型专业找"共同点"，固定思想换对象
- **模块的作用**：不决定性，用来美化与编故事
- **学术不端的自查边界**：什么能做什么不能做

## 关键概念/术语

| 术语 | 定义 |
|------|------|
| **仅论文论** | 学术裁缝的核心立场——一切都只为发论文，不关心真正的科研 |
| **A+B′+C′** | 论文公式：基准模型 A + 拼接的学术模块变体 B′/C′ |
| **基准模型 A** | 被缝合的底层模型（去 A 性能变零），决定性能上限 |
| **学术模块 B/C** | 缝到 A 上的小模块（去 B 性能几乎不变），用于美化和编故事 |
| **消融实验** | 证明模块真实作用的关键实验（对比实验看不出） |
| **水刊/水会** | 门槛低、给钱能发、毕业够用的期刊/会议 |
