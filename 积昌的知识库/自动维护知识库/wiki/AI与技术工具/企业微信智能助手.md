## 概述

企业微信智能助手是一个 Python FastAPI Web 服务，通过内网穿透工具（LocalTunnel/Cloudflare Tunnel）暴露本地端口到公网，接收企业微信推送的 HTTP 回调消息，将用户从微信/企业微信发送的消息和文件交由 Claude CLI（实际调用 DeepSeek API）处理，最终将处理结果写入 Obsidian Vault 并通过企业微信 API 回复用户。其核心特点是**被动推送模式**（企业微信通过 HTTP POST 回调推送消息）、**AES 加密通信**、**需要内网穿透**。

## 核心要点

### 系统架构

```
微信 (WeChat) → 企业微信 (WeCom) → LocalTunnel/Cloudflare → Python FastAPI 服务 → Claude CLI → Obsidian Vault
                                                                     ↓
                                                           企业微信 API (回复用户)
```

### 架构核心特点

| 特点 | 说明 |
|------|------|
| **被动推送** | 企业微信通过 HTTP POST 回调推送消息，服务无需主动轮询 |
| **AES 加密通信** | 所有回调消息使用 AES 加密，需 wechatpy 解密 |
| **内网穿透必需** | 回调 URL 必须公网可达，需要 LocalTunnel 或 Cloudflare Tunnel |
| **FastAPI 异步** | 基于 FastAPI + Uvicorn 的异步 Web 服务器 |
| **单实例并发控制** | processing_lock 确保 Claude CLI 单实例运行 |
| **Windows 服务管理** | 使用 nssm 注册为 Windows 服务，实现开机自启 |

### 核心技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 服务端语言 | **Python 3.13** | 主服务逻辑、回调处理 |
| Web 框架 | **FastAPI** | 异步 Web 服务，处理回调请求 |
| ASGI 服务器 | **Uvicorn** | 运行 FastAPI 应用 |
| 消息加解密 | **wechatpy** | 企业微信 AES 解密、消息发送 |
| HTTP 客户端 | **httpx** | 下载企业微信媒体文件 |
| 内网穿透（主力） | **LocalTunnel / Cloudflare Tunnel** | 暴露本地端口到公网 |
| AI 引擎 | **Claude CLI** | AI 任务执行引擎 |
| AI 模型后端 | **DeepSeek API** (deepseek-v4-flash) | 实际推理后端 |
| Windows 服务管理 | **nssm** | 注册为 Windows 服务 |
| 知识库 | **Obsidian** | 笔记存储与知识管理 |

### API 端点

| 端点 | 方法 | 用途 |
|------|------|------|
| `/wecom/callback` | GET | 企业微信 URL 验证 |
| `/wecom/callback` | POST | 接收消息回调 |
| `/health` | GET | 健康检查 |

> **重要**：POST 回调必须返回 `PlainTextResponse(content="success")`，否则企业微信会认为回调失败并反复重试推送。

### 内网穿透方案

| 方案 | 安装方式 | 特点 |
|------|---------|------|
| **LocalTunnel** (主力) | `npm install -g localtunnel` | 基于 Node.js，稳定可靠 |
| **Cloudflare Tunnel** (备选) | `winget install Cloudflare.cloudflared` | 无需固定域名，免费隧道 |

### 配置要点

| 配置项 | 说明 |
|--------|------|
| `corp_id` / `agent_id` / `secret` | 企业微信自建应用凭证 |
| `token` / `encoding_aes_key` | 回调消息加解密参数 |
| `timeout_seconds: 600` | 10 分钟超时，大文件可提升至 1800 |
| `server.port: 8800` | 本地服务监听端口 |

### Claude CLI + DeepSeek API 架构（与企业微信版一致）

```
Claude CLI → ANTHROPIC_BASE_URL 重定向 → DeepSeek API → deepseek-v4-flash
```

## 关键概念/术语

| 术语 | 定义 |
|------|------|
| **企业微信自建应用** | 在企业微信管理后台创建的应用，提供 CorpID、AgentID、Secret 等凭证 |
| **回调 URL** | 企业微信推送消息的目标地址，必须公网可达，通过内网穿透实现 |
| **AES 加密** | 企业微信回调消息使用 AES-256-CBC 加密，需 wechatpy 的 WeChatCrypto 解密 |
| **内网穿透** | 将本地服务端口暴露到公网的技术，企业微信方案必须依赖此技术 |
