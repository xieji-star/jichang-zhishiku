# AI绘制思维导图

## 概述

AI 生成思维导图与流程图的底层本质都是"代码"：**流程图用 mermaid 代码、思维导图用 markdown 代码**，把文档或概念交给 DeepSeek 等 AI 生成代码，再导入能渲染的图平台（draw.io / XMind）即成图并二次创作。核心公式：**AI 生成代码 → 导入渲染平台 → 成图 + 二创**。

## 核心要点

### 核心原理

- **流程图** → mermaid 代码（文本绘制流程图的标记语言，可被 draw.io 渲染）
- **思维导图** → markdown 代码（轻量级标记语言）
- 操作三步：① 提供文档/概念给 AI → ② AI 输出代码 → ③ 导入渲染平台成图并微调

### 两种提示词方式

| 方式 | 场景 | 特点 |
|------|------|------|
| 现成文本 → 整理生成代码 | 手里有文档/论文段落 | 流程与时间控制较准确 |
| 一句话生成（仅概念） | 只有想法如"光合作用流程图" | 直接渲染成图可下载 PNG，但**较丑且不能二创** |

### 流程图实操（draw.io）

1. 打开 draw.io 网站 → 新建文件选**空白框**
2. 点击"+"选择 **mermaid** → 删除模板内容
3. 粘贴 DeepSeek 生成的 mermaid 代码 → 插入
4. 报错时把报错信息复制回 DeepSeek 让其修改

> mermaid 除流程图外还支持：状态图、甘特图、数据库 ER 图、百分比饼图、UML 类图等。

### 思维导图实操（XMind）

1. 新建文本文档 → 粘贴 AI 生成的 markdown 代码 → 保存
2. 后缀名 `.txt` 改为 `.md`（markdown 格式）
3. 下载安装 **XMind** → 文件 → **导入 Markdown** → 选择该文件
4. 自动生成思维导图，可二创、微调

### 集成 AI 制图产品拓展

| 产品 | 入口 | 限制 |
|------|------|------|
| 讯飞智文 | "AI 思维导图" | 每天免费次数有限 |
| WPS 自带 / WPS 灵犀 | 稻壳 → AI 创作 → 思维导图 | 软件内产品效果好于网页版灵犀；目前"限免" |
| draw.io 自带 AI | 新建 → "生成" | 简单流程图清晰；**复杂流程图文不对题** |

### 选型建议

- **简单图**：用集成工具快速生成
- **需要二创/微调**：走"DeepSeek 代码 → draw.io / XMind"路线
- **复杂流程图**：自行校验时间与活动内容是否对应

## 关键概念/术语

- **mermaid**：一种用文本描述图表的标记语言，可渲染流程图、甘特图、ER 图、饼图、UML 类图等
- **markdown**：轻量级标记语言，用纯文本写结构化内容（本文中用于表示思维导图层级）
- **二创**：在 AI 生成结果基础上手动修改完善
- **draw.io**：在线图表绘制工具，支持导入 mermaid 代码渲染
- **XMind**：思维导图软件，支持"导入 Markdown"自动生成导图
