# 第三方数据工具

## 概述

蝉妈妈和考古家是独立于抖音平台的第三方数据分析工具。做抖音现在是"开卷考试"——大部分数据都能在第三方平台查到。掌握这些工具是做运营/剪辑实习前的必备技能。

## 核心要点

### 核心功能模块

| 模块 | 功能 |
|------|------|
| **达人板块** | 找达人（涨粉/带货/对标）、MCN 机构查询、星图达人榜 |
| **商品板块** | 销量榜、潜力榜、佣金榜、各品类商品榜 |
| **直播板块** | 带货榜、小时榜、人气榜、高光话术录制 |
| **视频板块** | 热门视频、图文视频、营销日历、实时热点 |
| **品牌/店铺板块** | 品牌详情、小店数据 |

### 达人等级划分

| 等级 | 近30天销量 |
|------|------------|
| 尾部达人 | < 3 万 |
| 小达人 | 3万 - 10万 |
| 中腰部达人 | 10万 - 100万 |
| 肩部达人 | 100万 - 1000万 |
| 头部达人 | > 1000万 |

### 流量结构（重点指标）

直播间流量来源 5 种：
1. **推荐 feed**：刷短视频时直接刷到直播间
2. **短视频引流**：刷到短视频后点头像进入 → 转化率最高
3. **关注**：已关注用户专门进入
4. **搜索**：主动搜索
5. **其他**：直播广场、分享链接

**健康标准**：推荐 feed 占比 50%-80% 是健康数据——意味着不需要每天发短视频也能有稳定流量（平台自然推流）。

### 其他核心指标

| 指标 | 含义 |
|------|------|
| **直播穿透率** | 看到直播间后点进去的比例 |
| **平均停留时长** | 用户在直播间的平均时长 |
| **UV 价值** | 每 1000 次观看带来的销售额 |
| **分钟带货产出** | 每分钟卖多少 |

### MCN 机构"亏钱逻辑"

某大 MCN 机构主播单场卖 2000 万，投流花 500 万，佣金 25%（500 万）→ 不赚不亏。为什么还做？

> 他们赚的不是佣金，而是**坑位费**（一个产品上直播间收 10 万）+ **资本游戏**（做大盘子、冲 GMV、方便融资/上市）。

## 关键概念

- **推荐 feed**：平台自然流量推荐，不需要短视频引流的直播入口
- **短视频引流转化率 > 推荐 feed 转化率**：预种草过的用户意向度更高
- **坑位费**：品牌方为产品上直播间支付的固定费用
- **GMV**：总交易额，不等于实际收入
