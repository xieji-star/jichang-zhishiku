# JD拆解方法论

## 概述

JD（Job Description）不只是岗位要求清单，而是一份可以深度挖掘的公司情报。本方法论提供 9 个维度的拆解框架，帮助从一份 JD 中提取远超表面信息的洞察——公司业务模式、岗位真实级别、跳槽路径、面试准备方向。

## 核心要点

### 9 维度拆解框架

| 维度 | 关键问题 |
|------|----------|
| **硬能力** | 要会什么平台/工具？做什么类型的活儿？ |
| **软能力** | 跨部门沟通？向上管理？抗压？ |
| **汇报对象** | 向谁汇报？职级多高？ |
| **下属配置** | 手下有没有人？管几个人？ |
| **权限** | 有人事权（招人/定绩效）吗？有预算权吗？ |
| **业务本身** | 具体做什么？工作闭环是什么？ |
| **公司业务** | 公司靠什么赚钱？营收结构是什么？ |
| **跳槽路径** | 这段经历能帮你跳到哪些行业/岗位？ |
| **薪资与招聘方式** | 薪资跨度大不大？猎头还是 HR 直招？发布多久了？ |

### 不靠谱 JD 的辨别方法

面试系列课总结了一套判断 JD 是否靠谱的通用方法：

| 特征 | 具体表现 |
|------|---------|
| **反复强调** | "室内办公不是地推""不需要打电话"——说明很多人问过同类问题 |
| **薪资虚高** | 实习正常 100~200元/天，4000~8000元/月离谱 |
| **工作内容模糊** | 只写推广引流，不写具体做什么 |
| **公司岗位单一** | 90%以上都在招运营推广岗，没有技术/产品/设计岗 |
| **画大饼** | "成为分公司负责人"——招实习生不可能 |
| **公司简介随意** | 注册时间短（如2023年成立），简介像微商/传销 |
| **头像不专业** | HR头像用美女自拍/娱乐性质头像 |
| **工商信息异常** | 核准日期频繁变动，注册资本低 |

> 典型案例：新媒网络（运营推广岗）——反复强调"不是地推"、薪资 4000~8000、公司 90% 岗位都是运营推广、2023 年成立。业务链条为：上游娱乐平台→中游用户增长集团→下游皮包公司招实习生批量推广。

### 公司工商信息核查

投递前用企查查/天眼查/BOSS直聘交叉验证：

| 核查项 | 判断标准 |
|--------|----------|
| **注册时间** | 成立太短（<1年）需警惕 |
| **企业规模** | 100人以上相对靠谱 |
| **社保人数** | 是否真实缴纳社保 |
| **法人及股东** | 查关联公司，判断是否为皮包公司 |
| **注册资本** | 空壳公司通常注册资本低 |
| **公司地址** | 是否在正规写字楼 |
| **公司简介** | 描述是否清晰专业 |
| **各平台招聘情况** | 综合判断，多平台交叉验证 |

### 利润中心 vs 成本中心——理解公司业务模型

面试时讲出对目标公司业务模型的理解，是高级面试逻辑的体现。

| 类型 | 含义 | 举例 |
|------|------|------|
| **利润中心（乙方）** | 你帮企业做服务，直接创造利润 | 市场调研公司（尼尔森、益普索）、4A广告公司 |
| **成本中心（甲方）** | 你做调研/分析帮公司省成本、做决策 | 互联网公司（字节、腾讯）、快消公司（宝洁、联合利华） |

**跳槽路径**：乙方经验可迁移到行业研究、数据分析、商业分析、用户分析、品牌管理等甲方岗位。

### 案例一：新媒体运营经理（30K-60K）

**拆解过程**：
1. 薪资 30K-60K + 猎头招聘 → 中高级管理岗，非执行岗
2. JD 中"新品上市"优先级高于日常流量 → 公司近期有新品发布
3. 需追问：手下管几人？有没有人事权和预算权？
4. 新品发布会完成闭环：上市前策略 → 发布会执行 → 上市后线索转化
5. 成功 = 晋升/奖金；失败 = 可能被开除（汽车行业竞争惨烈）

### 案例二：数据分析实习生（120-160元/天）

**拆解过程**：
1. 公司位于杭州九堡（直播电商聚集地）→ 大概率是 DP（抖音品牌服务商）
2. 查看公司其他在招岗位 → 验证业务方向
3. 你的工作闭环：接需求 → 拆需求 → 抓数据 → 输出分析 → 落地跟进
4. 硬技能偏市场向数据分析（Excel/PPT，非 SQL/Python）
5. 跳槽路径：服务商 → 品牌方（做过某行业数据分析 → 跳该行业品牌方）

### 工作闭环思维

任何一个岗位都可以画出一条完整链路：

```
接到需求 → 拆解需求 → 执行 → 输出成果 → 落地跟进
```

在面试时把这套逻辑讲出来，比单纯说"我会 XX 技能"高级得多。

## 关键概念

- **DP（Douyin Partner）**：抖音品牌服务商，帮品牌做抖音代运营
- **年框基础服务费 + 佣金**：DP 公司的常见营收模型
- **跳槽路径**：从服务商跳到品牌方是常见的职业发展路线
- **利润中心**：乙方公司，直接创造利润（市场调研、广告公司等）
- **成本中心**：甲方公司，帮企业节省成本（互联网、快消公司等）
