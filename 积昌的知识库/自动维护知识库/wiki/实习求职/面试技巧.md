# 面试技巧

## 概述

面试的核心逻辑是**双向沟通**——从"推销自己"转向"展示业务理解"。准备分三个层次：扒透自己 → 扒透对方公司 → 直接聊业务方案。本页整合三套方法论体系，覆盖从准备到复盘的完整流程。

**核心框架**：面试准备 = 乙方视角（自我剖析）+ 甲方视角（外部洞察）+ 个性化准备（偏爱建立）。底层业务逻辑：所有公司/岗位本质上分为**流量、产品、交付**三个环节，理解这个全链路是写出好简历和应对面试的基础。

## 核心要点

### 面试失败的三大根本原因

1. **紧张，大脑空白** — 准备了很多，一紧张全忘光
2. **说的都不是 HR 想听的** — "我想来学习""我没经验但想学"
3. **不知道 HR 要什么** — 不了解岗位需求，回答不到点子上

> 面试过程中没有任何设施可以帮助你，只有你的脑子和嘴巴。**一定要在脑子里面有大纲**。

### 面试准备三层

1. **扒透自己**：简历上每段经历都能讲出逻辑和细节
2. **扒透对方公司**：用 JD 拆解法深度分析公司和岗位
3. **直接聊业务**：不介绍自己多优秀，直接展示对业务的理解和方案

### 面试完全体三段论

从 100% offer 课程提炼的面试准备三段式：

| 阶段 | 视角 | 核心任务 | 对应准备 |
|:----:|:----:|---------|---------|
| **乙方视角** | 自我剖析 | 了解自己的价值，包装为"流量-产品-交付"语言 | 写简历、拆解校园经历 |
| **甲方视角** | 外部洞察 | 深挖公司业务、岗位真实需求、行业模式 | JD 拆解、公司调研 |
| **个性化准备** | 建立偏爱 | 找到与面试官/公司的共同点，超越标准化竞争 | 调研面试官背景、找小众共同兴趣 |

> **底层逻辑**：一份工作的获得 = 我懂自己（乙方）+ 我懂对方（甲方）+ 我们之间有缘分（个性化）。三者缺一不可。

### 业务全链路认知：流量 → 产品 → 交付

所有公司、所有业务、所有岗位，本质上都分为三个环节。理解这一底层逻辑是写好简历、应对面试的关键。

#### 三环节定义

| 环节 | 含义 | 校园经历对应 | 常见岗位 |
|:----:|------|-------------|---------|
| **流量** | 客户来源、渠道推广、品牌曝光 | 公众号运营、海报设计、社群推广、校园地推 | 新媒体运营、编导、私域运营、设计、广告投放 |
| **产品** | 服务/商品本身的设计与交付 | 活动策划、课程设计、竞赛方案 | 产品经理、项目经理、课程设计 |
| **交付** | 售后服务、执行维护、客户运营 | 现场执行、物资管理、签到最后维护 | 客户成功、运营支持、售后管理 |

#### 在简历中的应用

将校园经历拆解为这三个环节，可以有意识地知道：

1. **我干的活属于哪个环节** → 我可以在哪个环节找工作
2. **我干了某个环节的活** → 我可以延伸到同环节的所有岗位
3. **我虽然只做了其中一个环节** → 但我知道全链路，面试时可以从容回答上下游问题

> **核心技巧**：简历不必把流量/产品/交付分开写，但你需要有这条逻辑。面试官问任何问题你都知道自己在全链路中的位置，不会露馅。

#### STAR 法则 + 三要素

这是 100% offer 课程独创的简历优化公式：

```
好的简历 = STAR 法则（逻辑框架）+ 三要素（业务理解）
```

- **STAR 法则**：Situation → Task → Action → Result（保证逻辑清晰）
- **三要素**：流量/产品/交付（保证知道自己处于什么业务环节）

> 当你既会 STAR 写简历，又懂三要素理解业务，你的简历想怎么写怎么写，面试想怎么说怎么说。

### 面试前的三大准备材料

1. **问题清单** — 把 JD 发给 AI，或连简历一起喂给 AI，让 AI 帮你分析 HR 可能问什么问题
2. **逐字稿** — 针对问题清单逐一写出回答，不需要一字不差，但要有完整的书面思考
3. **大纲/框架** — 基于逐字稿提炼回答框架（如：1234 或 总分总结构）

> **练习方法**：写完后多讲几次，用手机**拍视频回看**，自然就能发现问题。AI 模拟面试效果一般，没有拍视频来得真实。

### 两种面试逻辑

| 低级 | 高级 |
|------|------|
| 介绍自己多优秀 | 直接聊业务本身 |
| 求对方选择 | 展示"不选我是你的损失" |
| 背诵自我介绍 | 给出方案：怎么做、有什么渠道 |

### 大厂看下限，小厂看上限

| 类型 | 关注点 | 表现 |
|------|--------|------|
| **大厂** | **看下限** | 要求 985/211 或经历特别对口，面试流程长（3-5 面 + 笔试 + 群面），要保证你不拖后腿 |
| **小厂/创业公司** | **看上限** | 老板直接面，看你能冲到什么程度，能承担多大压力，能不能奋斗在一线 |

### 自我介绍的三段框架

自我介绍是最重要的板块——**面试官可能在自我介绍完就已经做了决定**。

```
基本信息（10秒）→ 展示能力（70%以上）→ 感性输出（15-20秒）
```

#### 1️⃣ 基本信息
只有三个信息：**姓名 + 学校 + 一个跟岗位相关的点**

- 专业与岗位相关→说专业；不相关→找一个佐证（如学财务但面试 AI 岗，说考了 AI 证书）

#### 2️⃣ 展示能力（核心，占 70% 以上）
**讲两段经历即可**（不要讲三段以上），必须与面试岗位相关。

> 在大一阶段，你的个人能力对公司其实不重要。企业招你是因为你的**稳定性**、**可培养性**和**风险成本**。

#### 3️⃣ 感性输出（差异化）
当两个人条件差不多时，感性输出就是决胜点：
- 为什么面试这个岗位（你的渊源或缘分）
- 你对这个岗位的理解
- 你个人的独特性

### STAR+L 法则

面试回答时用 STAR+L 框架，不仅讲结果，还要讲**复盘迭代能力**。

| 要素 | 含义 | 说明 |
|------|------|------|
| **S** (Situation) | **背景** | 工作的背景或要求 |
| **T** (Task) | **任务** | 要完成什么目标 |
| **A** (Action) | **行动** | 做了什么行动 |
| **R** (Result) | **结果** | 达到什么数据/效果 |
| **L** (Learn) | **学习/收获** | 学会了什么，怎么优化的 |

> **关键技巧**：用讲故事的手法——设置困难条件（如预算只有 1000 块、时间紧急），描述困难后展示解决问题的流程，让对方有**画面感**。L 是差异化所在，展示你的成长性和思考深度。

### 回答问题的方法论

| 方法 | 说明 |
|------|------|
| **一个点 + 一个系统** | 先直击痛点，再用框架系统展开 |
| **具体案例佐证** | 不要讲空话，用具体例子建立画面感 |
| **给出信息量** | 让 HR 有继续追问的欲望，形成螺旋式深入沟通 |
| **真诚的套路** | 站在公司角度，但和个人经历连接起来 |
| **一半 + 一半** | 不要极端，找到中间平衡点（如娱乐+专业） |

### 常见面试问题拆解

| 问题 | 核心回答策略 |
|------|-------------|
| **你了解我们公司吗？** | 看过哪个账号、业务是什么 + 最近某条具体内容 + 感受/与岗位关联 |
| **最有成就感的一件事？** | STAR+L 框架，设置困难条件，展示解决问题的流程 |
| **为什么想来我们公司？** | "公司有某个东西 + 我有某个东西 → 刚好能连接"（真诚的套路） |
| **平时刷短视频吗？** | 一半娱乐（看什么类型）+ 一半专业（关注某个博主的选题思路） |
| **什么样的内容能火？** | 讲具体方法论（利他、共情、猎奇）+ 加一个案例佐证 |
| **直播时网断了怎么办？** | 一个点（先开热点稳住直播间）+ 一个系统（排查断网原因分类处理） |
| **你平时用 AI 工具吗？** | 讲具体项目/案例，展示使用深度，而不是堆砌工具名 |
| **你做账号具体怎么做的？** | 从目标→人群→对标→选题→拍摄→数据，STAR 流程讲完整 + L 复盘 |
| **一条笔记数据差怎么分析？** | 曝光率低→选题/标题；完播差→开头/文案；互动率低→讨论价值 |
| **入职第一件事做什么？** | 先了解公司业务方向和目标用户→看平台契合度→提出第一周计划 |

### 面试时提问的技巧

| 层级 | 类型 | 示例 |
|------|------|------|
| ❌ 低阶 | 套路化 | "我还有什么地方需要提升？" |
| ✅ 中阶 | 具体 | "有没有工作文档/SOP 让我提前了解？" |
| 🔥 **高阶** | **具体 + 利他 + 偏业务** | "到岗前线上有没有能先做的事，让我快速熟悉起来？" |

### 面试复盘：按图索骥法

面试后不仅要复盘今天表现，还要**延展出相关联的问题**：

> 示例：HR 问了"你觉得什么样的内容能火？"
> → 延展准备：各短视频平台的区别？各平台的打法和方法论有什么不同？
> → 类似问题：直播断网→会议投屏出问题怎么办？一条视频差→一场活动办砸了？

**把一个问题延展出 10 个相关联问题**，逐步补充完善，形成**网状思维**，基本不会有超纲的问题。

### 个性化准备：建立偏爱

当所有客观条件都满足时，为什么选你不选别人？此时需要的是**偏爱**。

#### 偏爱的底层逻辑

> 人做选择始终有主观成分。当 10 个面试者中 5 个满足硬性要求时，选择取决于**一念之间的偏爱**。

**案例**：发一条面试官以前发过的朋友圈（如圣经金句），让对方主动约咖啡 → 拿到 offer。核心公式：*大佬愿意帮你，是因为你像他——他帮助了曾经的自己。*

#### 如何建立偏爱

| 方法 | 说明 |
|------|------|
| **找小众共同点** | 不要大众爱好（看书、运动），要找小众垂直的（某类纪录片、某个冷门作者） |
| **调研面试官背景** | 如果有面试官的微信/领英，可以研究其朋友圈、背景 |
| **强化共同标签** | 同校、同专业、同地方、同职业转型路径 |
| **制造缘分感** | "我也喜欢/经历过……" 让对方觉得"你不是陌生人" |

#### 务实派 vs 务虚派

| 派系 | 特征 | 适合 |
|:----:|------|:----:|
| **务实派** | 扎扎实实做事，拿到结果就是最好证明 | 踏实型、技术型 |
| **务虚派** | 善于社交逢场作戏，左右圆滑维系关系 | 社交型、资源型 |

> 没有对错之分，只有派系之分。务实派可以少一点社交包装，务虚派可以多利用社交优势。根据自己的特点选择风格。

### 可迁移技能——AI 时代的护城河

当 AI（如 GPT 生成海报）取代了某个技能本身（如设计），谁能留下来？

#### 核心观点

- **技能本身**（设计/剪辑/写作）可以被 AI 替代
- **技能 + 行业理解**（懂设计 + 懂电商）很难被替代
- 留下的人 = 能用 AI 工具 + 懂业务逻辑的人

#### 可迁移场景

| 底层技能 | 可应用的场景 |
|---------|-------------|
| **设计** | 新媒体海报、电商头图、招商手册、政务宣传 |
| **剪辑** | 口播视频、Vlog、品牌宣传片、招商视频 |
| **文案** | 公众号、小红书、广告语、政务公文 |

> 同样一个技能，可以应用到完全不同的行业。理解行业的人将 AI 作为效率工具；只懂技能的人被 AI 替代。

#### 行动建议

- 多了解行业（电商、教育、政务等不同场景）
- 实习时不只看自己的岗位，要看整个业务链条
- 学 AI、学自媒体、学销售——**所有公司都需要流量、产品和交付**

### 信息储备量与全局思维

信息储备量决定了决策质量和效率。

#### 核心逻辑

> 信息量越多 → 决策越正确 → 效率越高

**案例**：去香港留学的同学，有人只留学，有人还办了香港手机卡和银行卡 → 香港手机卡可注册美区 Apple ID → 可以用 ChatGPT/Gemini → 多了一个信息量就多了一个优势。

#### 研究生做加法的重要性

```
研一：大量做加法（调研、实习、社交、看案例）
     ↓
研二：开始做减法（聚焦方向、深耕）
     ↓
研三：减法越精准（决策效率高、路径清晰）
```

**为什么一直强调全局思维**：你买的不是一辆车，你还得想用车成本、社交需求、二手残值。每一件事都能往后推很多步，取决于前期储备量有多少。

> 所有公司本质上都是流量→产品→交付。你干什么活都一样，只是去了不同的行业。**多做加法是为了更精准地做减法**。

### 面试主观性

- 面试高度主观——可能因为一句话或一个挑战就被录用
- 敢于接受挑战比讲得好更重要
- 大一大二可以投递的条件：只要不是系统自动过滤（学历下拉菜单），即使不满足 985/211 也可以投

### 非技术岗的"万能投"

> 除了算法/开发等纯技术岗，市面上所有文科/商科/运营/市场类岗位，大一大二都能投。你干的活是一样的，区别在于你怎么讲成你要投递的岗位。

### 专业度：稳定就是专业

> **专业** = 任何时候都能保持 80 分
> **不专业** = 发挥忽高忽低（今天准备好就 90 分，感冒了就 30 分）

哪怕今天不舒服、不熟悉岗位、临时面试，也能在**基准线之上**，这才叫专业。

## 避坑指南

### 哪些实习不能去

| 类型 | 特征 |
|------|------|
| 主动联系你的 | 电销、卖人头、要实名信息注册 |
| "接受小白"+高薪 | 一眼假 |
| 面试就过/不面试上岗 | 极不靠谱 |
| 先交钱的 | 骗面试费 |
| 骗方案/脚本/剪辑 | 以面试为由白嫖完整方案 |

> 正经公司只会让你简单分享思路或问行业理解，不会让你交完整方案。

### 面试前必须确认

- 工作具体内容
- 实习薪资及组成结构
- 每月发薪时间
- 是否签实习合同/劳动合同
- 入职安排

### 关于实习证明

- **可有可无**，HR 不太看重
- **更有价值的替代**：日常拍照记录 + 聊天记录 + 后台数据截图 + 账号截图

## 关键概念

- **STAR+L**：背景→任务→行动→结果→复盘学习（差异化所在）
- **业务思维**：从"我能做什么"变成"我对你的业务有什么理解和方案"
- **老板视角**：实习时主动思考工作目的、业务环节、行业全貌
- **真诚的套路**：站在公司角度，但和个人经历连接起来
- **按图索骥法**：面试后延展关联问题，形成网状准备
- **一个点 + 一个系统**：先直击痛点，再用框架展开
