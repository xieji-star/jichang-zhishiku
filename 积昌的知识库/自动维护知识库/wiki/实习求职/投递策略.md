# 投递策略

## 概述

投递不只是"发了简历等回复"。从平台选择、时机把握、沟通话术到水下渠道拓展，每个细节都影响回复率。核心原则：**简历适配度 > 投递数量**；每天精准投递 5 份胜过盲投 50 份。

## 核心要点

### 平台选择

| 平台 | 适合人群 | 特点 |
|------|----------|------|
| **实习僧** | 大学生 | 大厂实习多，有面试/笔试经验 |
| **牛客** | 应届生 | 技术岗多，社交属性 |
| **Boss直聘** | 应届生+初级 | 回复最快，新媒体岗多，岗位质量参差 |
| 前程无忧 | 有工作经验 | 社招为主 |
| 智联招聘 | 央国企/上市公司 | 反馈慢 |
| 猎聘 | 中高端 | 适合做长期职业规划导航 |

> 大一大二优先用实习僧、Boss直聘、牛客。前程无忧/智联/猎聘目前阶段竞争压力大。

### Boss直聘进阶技巧

1. **改定位**：把定位改成目标城市的 CBD 写字楼/产业园 → 推送附近岗位
2. **关闭个性化推荐**：避免信息茧房，可测试开/关效果对比
3. **主动搜索 > 被动刷推荐**：多换关键词组合搜索
4. **打招呼话术**：聊天框只显示前 15~20 字，核心优势放最前面
   - ✅ "985本科/立即到岗/能线下/会Python/可实习3个月"
   - ❌ "你好面试官我是XXX..."
5. **只投 3~5 天内发布的岗位**：超 1~2 周基本已招到人
6. **简历三件套**：①平台简历 ②PDF附件 ③简历截图（方便 HR 手机预览）
7. **多设备轮换**：手机端 vs 电脑端算法不同

### 投递时机

- **核心逻辑**：避开对方休息时间
- **不要在**：周一上午（周末堆积简历淹没）+ 周五下午（HR 想下班）
- **周一~周五**（双休公司）或**周一~周六**（单休公司）的工作时间内
- **避开校招高峰**：春招（3-4月）、秋招（9-10月），此时主要开放全职岗

### 投递数量

- **每天 5 份**是最优：足够精准，每份可以做差异化话术
- 10~20 份偏多，5 份以下偏少
- **绝不**连续 3~4 次投同一岗位（会被当垃圾）

### 沟通话术

- ❌ 打死不说："在吗""还招人吗"
- ✅ 规范表达：100 字以内，简单介绍 + 核心优势
- 根据 JD 调整：JD 强调"立即到岗"→ 把"立即到岗"放最前面
- 不要同一句话术发给多个人

### 水下渠道（非平台投递）

许多中小创业公司不在平台发布岗位（发布要花钱）。水下渠道包括：

| 渠道 | 说明 |
|------|------|
| 企业官网/公众号 | 不仅搜"校招"，搜各类招聘关键词 |
| 学校就业中心/年级群 | 辅导员、导师、校企合作资源 |
| 新媒体平台 | 抖音/小红书上的招聘账号 |
| 学长学姐内推 | 实习快结束时找继任的窗口期 |
| 校园大使 | 可接触到全国各校大使群的招聘信息 |
| 垂类社群 | AI群、摄影群、知识付费群里的HR |
| 行业沙龙/峰会 | 一线城市线下面基，可能直接拿offer |
| 商业分析大赛/训练营 | 欧莱雅、宝洁等消费品公司举办 |

### 实习城市选择

- **首选一线城市**：北京、上海、广州、深圳、杭州、成都
- **贴钱实习是正常的**：一般每月贴 1~2K
- **不要因为不包吃住放弃实习**：没得选时先干了再说

## 关键概念

- **校招 vs 实习**：校招是毕业后直接入职的全职岗位；实习是在校期间的工作经历
- **春招 vs 秋招**：秋招岗位最多（大四上学期末），春招是补充（下学期初）
- **水下渠道**：非平台发布的招聘渠道，竞争更小但需主动发掘
- **劳务派遣**：中介公司招人再派到其他公司干活，无该公司的福利待遇
