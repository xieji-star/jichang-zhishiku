# 机械工程材料——相图与组织

## 概述

本页汇总《机械工程材料》的**概念主干**：从四个层层递进的基础概念（**组元 → 相 → 组织组成物 → 组织**）出发，讲到合金中最重要的相——**固溶体**，再落到相图的读法（以 **Pb–Sn 共晶相图** 为范本）与一个最易记反的考点——**共晶反应的发生条件**，用 **Fe–Fe₃C 相图（课本图3-30）** 做跨合金系的对照；再往下是**材料名称与简称体系**（§6，相/组织组成物/非平衡组织"降温链"）、**Fe–Fe₃C 相图的 14 个关键点与 5 条线**（§7，期末综合题的答题依据），以及**比容与黏度**如何解释非晶态合金（金属玻璃）的诞生（§8）。整门课的主线是：**成分 + 工艺 → 组织 → 性能**，而相图正是"成分决定组织"的定量工具。**"工艺 → 组织"的那一半**（四把火、钢种牌号）见姊妹页 [[wiki/学校课程/机械工程材料-热处理与材料命名]]。

## 核心要点

### 1. 四个概念的链条：组元 → 相 → 组织组成物 → 组织

| 概念 | 回答的问题 | 站在哪一端 | 个数符号 | 例子 |
|------|------|------|:--:|------|
| **组元** | 用**哪几样料**配 | 原料端（配料表、自变量） | $C$ | Fe、C（或 Fe、Fe₃C） |
| **相** | 有几块**内部均匀一致**的部分 | 产物端（零件） | $P$ | 铁素体、渗碳体、液相 $L$ |
| **组织组成物** | 组织由**哪几块可辨认部件**拼成 | 观察端（积木组件） | — | 铁素体、珠光体、莱氏体 |
| **组织** | 这些部件**拼成了什么花样** | 观察端（整体花纹） | — | "铁素体 + 珠光体"的整体排布 |

- **组元**可以是纯元素，也可以是**稳定化合物**（如 Fe₃C）——它只是相图坐标轴上的自变量（1 个组元=单元系、2 个=二元系、3 个=三元系）。
- **相**的三条判据：成分一致、结构一致、对外有界面（跨界面性质突变）。判据是"成分 + 结构是否一致"，**不是**"有没有连成一片"（两块成分结构相同的纯铁仍算一个相）。
- **组织**用金相显微镜直接看，描述它要讲**四要素**：数量、大小、形状、分布。
- 🔥 最容易混的一对：**珠光体（P）= 1 个组织组成物，但 = 2 个相**（铁素体 + 渗碳体层片状交替）。数相时要**拆开**，数组织组成物时算**一个整体**。
- **同一物质可两用**：Fe₃C 画相图时是**组元**，出现在钢的组织里时是**相**——两个维度各占一格，并不矛盾。

**经典考点（共析钢 0.77%C 缓冷）**：组织组成物数 **1**（珠光体），相组成物数 **2**（铁素体 + 渗碳体）。

### 2. 固溶体与固溶强化

- **固溶体 = 固态的溶液**：溶质原子溶进溶剂晶格，**晶格类型与溶剂保持一致**，形成成分均匀的**单一固相**。含量多、出晶格框架的叫**溶剂**；溶进去、含量少的叫**溶质**。
- 与另两种物质划界：**固溶体 vs 化合物**（成分可变 vs 固定成分比 + 独立新晶格）；**固溶体 vs 混合物**（单一相 vs 多相）。
- 两大分类：
  - 按"溶质住哪"分 —— **置换式**（占结点，如 Cu–Ni、铁中铬/镍）/ **间隙式**（挤间隙，如碳溶于 α-Fe 的铁素体）。🔥 **间隙固溶体一定是有限固溶体**，只有置换固溶体才可能无限互溶。
  - 按"能溶多少"分 —— **无限固溶体**（任意比例互溶，如 Cu–Ni）/ **有限固溶体**（超过**固溶度**就析出第二相）。
- 🔥 **固溶强化** = 溶质与溶剂原子大小不同 → 晶格畸变 → 应力场**阻碍位错运动** → 强度和硬度升高（塑性韧性略降）。这是合金强化最基本的手段之一（≠ 第二相强化）。
- ⚠️ 溶质超过**固溶度**后，多出来的部分以**第二相**析出（如碳超过溶解度就析出渗碳体 Fe₃C）。

### 3. 相图的读法：以 Pb–Sn 共晶相图为例

**七个关键点、四条线、六个相区**：

| 关键点 | 坐标（Sn 含量 / 温度） | 含义 |
|------|------|------|
| A | 0% / 327℃ | 纯 Pb 熔点 |
| B | 100% / 232℃ | 纯 Sn 熔点 |
| **C** | 19.2% / 183℃ | 共晶线左端点（α 最大固溶度） |
| **D** | 61.9% / 183℃ | **共晶点**（共晶成分） |
| **E** | 97.5% / 183℃ | 共晶线右端点（β 最大固溶度） |
| F | 2% / 20℃ | 室温 α 固溶度 |
| G | 99% / 20℃ | 室温 β 固溶度 |

- 四条线：**液相线 A–D–B**、**固相线 A–C–D–E–B**（结晶终止线）、**共晶线 C–D–E**（183℃ 水平线）、**固溶线 C–F / E–G**（溶解度随温度下降而减小）。
- 六个相区：液相 $L$、α 固溶体（Sn 溶于 Pb）、β 固溶体（Pb 溶于 Sn），以及三个两相区。
- 相图上的每一块色块就是一个"**相**"，两个坐标轴就是"**组元**"。

### 4. ⭐ 共晶反应的发生条件（最易记反的考点）

**问题**："降温经过 183℃ 是否一定发生共晶反应？"——**不一定。**

🔥 **核心结论：判断锚点不是温度轴上的 183℃，而是"成分竖线是否与共晶线 C–D–E 相交"，即"183℃ 那一刻还剩不剩液体"。**

| 合金类型 | 含 Sn 量 | 183℃ 时还有液体吗 | 会共晶吗 | 室温组织组成物 |
|------|:--:|:--:|:--:|------|
| **α 固溶体合金** | ≤ 19.2% | ❌ 早已凝固完（约 275℃ 全凝） | ❌ **不共晶** | α（＋二次 β_Ⅱ） |
| **亚共晶合金** | 19.2% ~ 61.9% | ✅ 剩一部分液体 | ✅ 共晶（仅剩余液体） | 初生 α ＋ 共晶组织 ＋ 二次 β_Ⅱ |
| **共晶合金** | = 61.9% | ✅ 全部是液体 | ✅ 共晶（整块） | 全部共晶组织（α＋β 层片状） |
| **过共晶合金** | 61.9% ~ 97.5% | ✅ 剩一部分液体 | ✅ 共晶（仅剩余液体） | 初生 β ＋ 共晶组织 ＋ 二次 α_Ⅱ |
| **β 固溶体合金** | ≥ 97.5% | ❌ 早已凝固完 | ❌ **不共晶** | β（＋二次 α_Ⅱ） |

- **"开关区间"记牢**：只有含 Sn 落在 **19.2% ~ 97.5%** 之间的合金才共晶；两端是单相固溶体合金，不共晶。
- **三重锁定**：共晶反应 $L_{61.9\%} \xrightarrow{183℃} \alpha_{19.2\%} + \beta_{97.5\%}$ 被三个"同时固定"锁死——温度固定（183℃）、反应物成分固定（61.9%）、产物成分固定（19.2% / 97.5%）。相律验证：二元系三相共存 $f = 2 - 3 + 1 = 0$，温度被完全锁死。
- **三大误区**：① 温度到 183℃ 就共晶 ❌（要看成分）；② 一共晶就整块全变共晶组织 ❌（除 61.9% 外，共晶的只是剩余液体）；③ 不共晶 = 组织无二次相 ❌（越过固溶线照样析出 β_Ⅱ / α_Ⅱ）。
- **冷却曲线判别法**：183℃ 处**有水平平台** = 共晶；**无平台**（凝固终了在高于 183℃ 处） = 不共晶。

### 5. 跨合金系对照：Fe–Fe₃C 相图（课本图3-30）

课本 **图3-30**（教材第 65 页，7 种典型合金在铁–碳合金相图中的位置）用另一种方式演示了同一条规律：

| 合金系 | 共晶温度 | 共晶点成分 | 才共晶的成分区间 | 不共晶的那一端 |
|------|:--:|:--:|:--:|------|
| **Pb–Sn** | 183℃ | 61.9% Sn | 19.2% ~ 97.5% Sn | ≤19.2%（α）、≥97.5%（β） |
| **Fe–Fe₃C** | 1148℃ | 4.3% C | 2.11% ~ 6.69% C | ≤2.11%（钢） |

- 铁碳共晶：$L_{4.3\%} \xrightarrow{1148℃} \gamma_{2.11\%} + \mathrm{Fe_3C}$，产物 = **莱氏体 Ld**；**只有白口铁（2.11%~6.69%C）才共晶**，**钢（≤2.11%C）不共晶**（结晶终了在 ≥1148℃ 的固相线上）。
- 🔥 **共晶 vs 共析**：**共晶** = 从**液相**同时长出两个固相（$L \to \gamma + \mathrm{Fe_3C}$，1148℃，白口铁）；**共析** = 从**一个固相**同时析出两个固相（$\gamma \to \alpha + \mathrm{Fe_3C}$，727℃，钢，产物珠光体）。名字像、机制不同。
- **共通规律**：不管哪个合金系，"温度经过共晶线"都 ≠ "发生共晶"——真正决定的是**成分竖线是否与共晶线相交**。

### 6. 材料的名称与简称体系（相 → 组织组成物 → 非平衡组织）

教材里的"名字"分**两套**：一套是**组织的名字**（金相显微镜下的"零件与部件"），一套是**钢材牌号**（工业上的"身份证号"）。这里先收拢第一套。**记简称的心法：多取自英文首字母**——F=Ferrite、A=Austenite、P=Pearlite、M=Martensite、L=Liquid，记住英文就记住符号。

**① 相的名称**（一块单独的"积木"）：

| 名称 | 符号 | 说明 |
|------|:--:|------|
| 液相 | $L$ | 熔融金属液，高温存在 |
| 高温铁素体（δ） | $\delta$ | 碳溶于 δ-Fe（bcc），**1394℃ 以上**稳定 |
| 铁素体 | $F$ | 碳溶于 α-Fe（bcc）；**727℃ 时最多仅溶 0.0218%**，又软又韧 |
| 奥氏体 | $A$ | 碳溶于 γ-Fe（fcc）；**1148℃ 时最多溶 2.11%**，高温塑性好 |
| 渗碳体 | $\mathrm{Fe_3C}$（Cm） | 铁碳**化合物**，含碳 **6.69%**，硬而脆，钢的强化骨架 |
| 石墨 | — | 铸铁中碳的游离态，软、有润滑性 |

**② 组织组成物**（显微镜下可辨认的"积木部件"）：

| 名称 | 符号 | 说明 |
|------|:--:|------|
| 珠光体 | $P$ | 铁素体 + 渗碳体的**层片状机械混合物**，**727℃ 共析**产物，含碳 **0.77%** |
| 莱氏体（高温） | $Ld$ | **1148℃ 共晶**产物，由**奥氏体 + 渗碳体**组成 |
| 变态莱氏体（低温） | $Ld'$ | 莱氏体冷到室温：**珠光体 + 渗碳体** |
| 先共析铁素体 | $F_{先}$ | 亚共析钢中先于珠光体析出的大块铁素体 |
| 五种渗碳体 | $\mathrm{Fe_3C_{I/II/III}}$ 等 | 按"**从哪里生出来**"区分（见下） |

⭐ **五种渗碳体按"出生地"记**：**一次**从液、**二次**从奥氏体、**三次**从铁素体、**共晶**从共晶反应、**共析**从共析反应——记住出生地就不会混。
🔥 最常考：**珠光体、莱氏体是"组织组成物"但不是"相"**——数相时要拆成铁素体 + 渗碳体。

**③ 七类铁碳合金的室温组织（按含碳量从低到高串一遍）**：

| 分类 | 含碳量 | 室温组织 |
|------|:--:|------|
| 工业纯铁 | < 0.0218% | 铁素体 + 三次渗碳体 |
| 亚共析钢 | 0.0218% ~ 0.77% | 铁素体 + 珠光体 |
| 共析钢 | = 0.77% | 珠光体（只有它一个） |
| 过共析钢 | 0.77% ~ 2.11% | 珠光体 + 二次渗碳体（网状） |
| 亚共晶白口铁 | 2.11% ~ 4.3% | 珠光体 + 二次渗碳体 + 变态莱氏体 |
| 共晶白口铁 | = 4.3% | 变态莱氏体 |
| 过共晶白口铁 | > 4.3% | 变态莱氏体 + 一次渗碳体 |

**④ 非平衡组织——一条"降温链"**（把钢加热到临界点以上再按不同速度冷却，奥氏体转成不同组织）：

$$A_{过冷} \to P \to S \to T \to B_{上} \to B_{下} \to M$$

| 名称 | 符号 | 形成温区 | 形态要点 |
|------|:--:|------|------|
| 过冷奥氏体 | $A_{过冷}$ | $A_1$ 以下未转变 | "待命状态" |
| 珠光体 | $P$ | $A_1 \sim 650℃$ | 500 倍光镜可辨 |
| 索氏体 | $S$ | 650 ~ 600℃ | 800~1000 倍才能分辨 |
| 托氏体（屈氏体） | $T$ | 600 ~ 550℃ | 只有**电镜**看得清 |
| 上贝氏体 | $B_{上}$ | 550 ~ 350℃ | 羽毛状，几乎无实用价值 |
| 下贝氏体 | $B_{下}$ | 350℃ ~ $M_s$ | 针状，综合性能好（等温淬火就为它） |
| 马氏体 | $M$ | $M_s$ 以下（共析钢 ≈ 230℃） | 碳在 α-Fe 中的**过饱和固溶体** |
| 残余奥氏体 | $A'$ | 淬火后残留到室温 | 未能转变完的奥氏体 |

🔥 **一条链全串起来**：**温度越低、硬度越高、韧性越差**。
💡 **注意两组"同名不同姓"**：$S$/$T$（直接冷却得到）≠ $S_{回}$/$T_{回}$（淬火后再回火得到）——形态相似、来历完全不同，考试最爱在此设坑（详见 [[wiki/学校课程/机械工程材料-热处理与材料命名]]）。

### 7. Fe–Fe₃C 相图的关键点与关键线（14 点 / 5 线 / 3 水平线）

课本 **图3-30** 用的是"位置图"的讲法；下面这张是同一张相图的"**坐标 + 符号**"精确版（教材表 3-2），是期末综合题的直接答题依据。

**14 个关键点**：

| 点 | 温度/℃ | 含碳/% | 含义 | 点 | 温度/℃ | 含碳/% | 含义 |
|:--:|:--:|:--:|------|:--:|:--:|:--:|------|
| **A** | 1538 | 0 | 纯铁熔点 | **G** | 912 | 0 | α-Fe → γ-Fe 转变点 |
| **B** | 1495 | 0.53 | 包晶时液相成分 | **P** | 727 | 0.0218 | 碳在 α-Fe 中**最大**溶解度 |
| **H** | 1495 | 0.09 | 碳在 δ-Fe 中最大溶解度 | **S** | 727 | 0.77 | **共析点** |
| **J** | 1495 | 0.17 | 包晶点 | **K** | 727 | 6.69 | 共析温度下渗碳体成分 |
| **N** | 1394 | 0 | δ-Fe → γ-Fe 转变点 | **Q** | 室温 | 0.0008 | 室温下碳在 α-Fe 中溶解度 |
| **D** | 1227 | 6.69 | 渗碳体熔点 | **E** | 1148 | 2.11 | 碳在 γ-Fe 中**最大**溶解度（**钢/铁分界**） |
| **C** | 1148 | 4.3 | **共晶点** | **F** | 1148 | 6.69 | 共晶温度下渗碳体成分 |

**5 条临界温度线**：$A_1$（**PSK 线**，727℃，共析线）、$A_3$（**GS 线**，冷却时奥氏体开始析出铁素体）、$A_{cm}$（**ES 线**，碳在 γ-Fe 中的固溶线，冷却时析出二次渗碳体）、$A_2$（**MO 线**，770℃，铁素体磁性转变/居里点）、$A_0$（**M'D 线**，230℃，渗碳体磁性转变）。

**3 条水平线（三条"变天定则"）**：

1. **HJB 线，1495℃ —— 包晶反应**：$L + \delta \to A$
2. **ECF 线，1148℃ —— 共晶反应**：$L \to A + \mathrm{Fe_3C}$（生成莱氏体，共晶点含碳 4.3%）
3. **PSK 线，727℃ —— 共析反应**：$A \to F + \mathrm{Fe_3C}$（生成珠光体，共析点含碳 0.77%）

💡 **符号记忆法**：带下标 "c" 的是**加热时用**（$A_{c1}$/$A_{c3}$/$A_{ccm}$），不带的是**冷却时用**；**热处理温度公式里全用带 c 的**。
> 🔖 **温度从高到低顺一遍**：1538（纯铁熔）→ 1495（包晶）→ 1394（δ→γ）→ 1227（渗碳体熔）→ 1148（共晶）→ 912（α→γ）→ 770（铁素体磁性点）→ 727（共析）→ 230（渗碳体磁性点）→ 室温。

### 8. 比容与黏度：非晶态合金（金属玻璃）

这一节回答一个看似与相图无关、实则同源的问题：**同一炉金属液，为什么有时凝固成规整晶体，有时却冻成一团无序的"金属玻璃"？** 课本答案是——**看冷得多快**，并用"**比容–温度**"曲线（图5-56）把两条路径画了出来。

**两个物理量**：

- **比容（specific volume）**：单位**质量**物质占的体积，$v = V/m = 1/\rho$，单位 $\mathrm{m^3/kg}$ 或 $\mathrm{cm^3/g}$——**密度的倒数**。密度讲"一升多重"，比容讲"一克多大"。之所以用它当纵轴，是因为**冷却时质量不变，比容就直接读出"体积怎么胀缩"**。
- **黏度（viscosity）**：流体**抵抗流动（抵抗剪切变形）**的能力，$\eta$，单位 $\mathrm{Pa\cdot s}$——通俗说就是"有多稠、多难流"。牛顿黏性定律 $\tau = \eta \cdot \mathrm{d}u/\mathrm{d}y$。

**两条冷却路径（图5-56）**：

| | 路径 1：正常冷却 | 路径 2：快速冷却（> $10^5$ K/s） |
|------|------|------|
| 冷却速度 | 慢 | 极快 |
| 中间状态 | 直接晶化 | 先变**过冷液体** |
| 比容曲线 | 在 $T_c$ **突变（跳水）** | **连续**变化，$T_g$ 处斜率放缓 |
| 黏度曲线 | 结晶温度区间**突变** | **无明显转变温度**，逐渐变硬 |
| 最终产物 | **晶体** | **非晶（金属玻璃）** |
| 比容大小 | 较小（排得密实） | **较大**（未达最密堆排列） |

🔥 **课本结论**："**固化后非晶的比容也比晶体高，说明非晶合金没达到最密堆排列**"——它是一群原子被"冻"在半路上、来不及排整齐。
⭐ **通用方法**：**"比容随温度是连续线，还是有个台阶"——是判断相变类型的通用手法**。有突变 → 原子重排（一级相变性质的**结晶**）；只有斜率变化 → 原子位置基本没动（**玻璃转变/非晶化**）。**判据是"突变 vs 连续"，不是"变没变固体"**。
🔗 **另一处黏度的用法**（课本第 38 页 §2.4.2 玻璃相）：陶瓷烧结产生的**硅酸盐熔体黏度很大**（含复杂硅氧阴离子团），冷却时**不利于晶体形核长大**，于是变成**玻璃体**；由熔体转变为玻璃体的温度称**玻璃化温度 $T_g$**，玻璃体加热到**软化温度 $T_s$** 时显著软化（陶瓷成型加工通常在 $T_s$ 以上进行）。**两处因果方向相反、互为印证**：第 38 页从"黏"入手，第 111 页从"快"入手，指向同一个结果。

## 关键概念/术语

| 术语 | 定义 |
|------|------|
| **组元** | 构成合金最基本、彼此独立的物质（纯元素或稳定化合物），相图坐标轴的自变量 |
| **相** | 成分、结构一致且与其他部分有界面分开的均匀部分（固溶体、化合物、液相各算一个相） |
| **组织** | 各相按数量、大小、形状、分布组合成的整体形貌，用金相显微镜观察 |
| **组织组成物** | 显微镜下能单独辨认、拼起整个组织的"积木部件"（可以是一个相，也可以是多相混合物） |
| **固溶体** | 溶质溶入溶剂晶格、晶格类型随溶剂的单一均匀固相；铁素体、奥氏体都是固溶体 |
| **固溶度** | 溶质在溶剂中能溶入的最大量；超过则以第二相析出 |
| **固溶强化** | 晶格畸变→应力场阻碍位错运动→强度硬度升高 |
| **共晶反应** | 一定成分的液相在恒温下同时析出两个固相（$L \to \alpha + \beta$），恒温、三相共存、成分固定 |
| **共析反应** | 一个固相在恒温下同时析出两个固相（$\gamma \to \alpha + \mathrm{Fe_3C}$），产物珠光体 |
| **相律** | $f = C - P + 2$（凝聚系统简化为 $f = C - P + 1$），把组元数与相数定量联系起来 |
| **铁素体（F）/ 奥氏体（A）** | 碳溶于 α-Fe / γ-Fe 的固溶体；既是相也是组织 |
| **渗碳体（Fe₃C）** | 铁碳化合物，硬而脆；画相图时是组元、在组织里是相 |
| **珠光体（P）/ 莱氏体（Ld）** | 两相/多相**组织**（不是相）：P=F+Fe₃C；Ld 室温=P+Fe₃C |
| **非平衡组织** | 加热到临界点以上再按不同冷速冷却、奥氏体转成的组织：$P \to S \to T \to B \to M$（越冷越硬越脆） |
| **索氏体 / 托氏体** | $S$（650~600℃）/ $T$（600~550℃），与"回火索氏体/回火托氏体"同名不同源 |
| **马氏体（M）** | 碳在 α-Fe 中的**过饱和固溶体**，$M_s$ 以下形成，硬而脆 |
| **残余奥氏体（A'）** | 淬火后未能转变完、残留到室温的奥氏体 |
| **比容（v）** | 单位**质量**的体积，$v = V/m = 1/\rho$，密度的倒数；图5-56 的纵轴 |
| **黏度（η）** | 流体抵抗流动（抵抗剪切变形）的能力，单位 Pa·s；决定"能不能结晶" |
| **玻璃化温度（$T_g$）/ 软化温度（$T_s$）** | 熔体转变为玻璃体的温度 / 玻璃体显著软化的温度（陶瓷成型加工常在 $T_s$ 以上） |
| **非晶合金（金属玻璃）** | 金属液以 > $10^5$ K/s 极快冷却、原子来不及重排而冻结成无序固态；**比容比晶体大** |
