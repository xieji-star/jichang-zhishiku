# 机械工程材料——热处理与材料命名

## 概述

本页是《机械工程材料》的**"工艺 + 名字"篇**，与姊妹页 [[wiki/学校课程/机械工程材料-相图与组织]]（"成分 → 组织"篇）配对。它回答两个问题：**① 同样的钢，为什么加热后冷却的快慢不同、性能就天差地别？**——答案是**"四把火"**（退火 / 正火 / 淬火 / 回火）；**② 工业上那么多钢材名字（45、40Cr、T10、Q235、W18Cr4V、HT200）到底怎么读？**——答案是**牌号编码规律**。两套"名字"要分开记：一套是**组织的名字**（相、组织组成物、非平衡组织、铸铁组织），一套是**钢材的牌号**。文末附**期末模拟试卷**的自测入口。

## 核心要点

### 1. "四把火"总表（先看这张）

四种热处理工艺都遵循"**加热 → 保温 → 冷却**"三步，**区别全在后两步**。

| 工艺 | 加热温度 | 冷却方式 | 室温组织 | 主要目的 |
|------|------|------|------|------|
| **退火** | 视种类而定（见下） | **随炉缓冷**（最慢） | $F+P$ / $P$ / $P_{球}$ | **软化**、去内应力、细化晶粒、为后续热处理备组织 |
| **正火** | $A_{c3}$ 或 $A_{ccm} + (30\sim50)℃$ | **空冷**（比退火快） | 细的 $F+P$，或 $P$ | 细化晶粒、**调整硬度改善切削性**、为球化退火备组织 |
| **淬火** | 亚共析钢 $A_{c3}+(30\sim50)℃$；共析/过共析钢 $A_{c1}+(30\sim50)℃$ | **水 / 盐水 / 油急冷**（> $V_k$） | **马氏体 $M$**（+ 残余奥氏体 $A'$） | **获得高硬度**、高耐磨性 |
| **回火** | $A_1$ **以下**（低 150~250℃ / 中 350~500℃ / 高 500~650℃） | 保温后**空冷** | $M_{回}$ / $T_{回}$ / $S_{回}$ | 消除淬火脆性、稳定组织、**调整强韧性配合** |

💡 **一句话抓区别**：退火与正火**只差冷却快慢**（炉冷 vs 空冷）；淬火是"**快冷到马氏体**"；回火是"**淬火后必经的补救与调优**"——淬火后不回火，基本不能用。

### 2. 退火：不是一种，而是六种

**退火** = 加热到适当温度、保温、**缓慢冷却**。按目的与温度分六种：

| 退火种类 | 加热温度 | 目的 / 适用 |
|------|------|------|
| **完全退火** | $A_{c3} + (30\sim50)℃$ | 主要用于**亚共析钢**：细化晶粒、降低硬度、消除内应力 |
| **等温退火** | 加热到 $A_{c1}$ 或 $A_{c3}$ 以上，再**快速冷到珠光体区等温** | 目的同完全退火，但**大大缩短冷却时间** |
| **球化退火** | $A_{c1} + (20\sim30)℃$ | 用于**共析钢、过共析钢**：渗碳体球化成 $P_{球}$，改善切削性能 |
| **均匀化退火**（扩散退火） | $A_{c3} + (150\sim200)℃$ | 用于合金钢锭：**消除枝晶偏析**，温度高、时间长 |
| **去应力退火** | $A_{c1} - (100\sim200)℃$ | **不发生相变**，只消除铸件 / 焊件的残余内应力 |
| **再结晶退火** | $A_{c1} - (50\sim150)℃$ | 用于**冷变形**金属：消除加工硬化、恢复塑性 |

🔥 **温度口诀**：完全退火在 $A_{c3}$ 之上；球化退火只在 $A_{c1}$ **之上一点点**（故意不完全奥氏体化）；**去应力退火与再结晶退火都在 $A_{c1}$ 之下**——所以后两种"**根本没发生相变**"。

⭐ **球化退火前要先正火**：过共析钢若直接球化退火，晶界上会留着"**网状二次渗碳体**"；先用正火把网打碎，再球化效果才好。

### 3. 正火：退火的"快进版"

- **定义**：加热到 $A_{c3}$（亚共析钢）或 $A_{ccm}$（过共析钢）以上 $30\sim50℃$，保温后**空冷**；
- **与退火的唯一区别**：**冷却速度更快**（空冷 > 炉冷）→ 组织**更细**、强度硬度**更高**；
- **室温组织**：含碳量 < 0.6% 时是 $F+P$；> 0.6% 时是 $P$；
- **低碳钢爱用正火**：退火后太软、切削时"粘刀"；正火后硬度刚好，**切削性能反而更好**；
- **过共析钢用正火的特殊目的**：不是为了切削，而是**消除网状二次渗碳体**，为球化退火备组织。

### 4. 淬火：要的就是"快"

- **定义**：加热到临界点以上、保温后以**大于临界冷却速度 $V_k$** 的速度冷却，使奥氏体转变为**马氏体**；
- **淬火温度（关键考点）**：
  - **亚共析钢**：$A_{c3} + (30\sim50)℃$（必须**完全**奥氏体化）；
  - **共析钢 / 过共析钢**：$A_{c1} + (30\sim50)℃$（只做**不完全**奥氏体化，故意留下颗粒状渗碳体以提高耐磨性）；
- **淬火介质**：水、盐水、油、碱浴 / 硝盐浴（冷却能力由强到弱）；
- **淬火方法**：单液淬火、双液淬火、分级淬火、**等温淬火**（等温淬火的目的不是马氏体，而是**下贝氏体 $B_{下}$**）。

🔥 **淬火最常见的两个坑**：① 以为"温度越高越好"——过共析钢必须用 $A_{c1}+(30\sim50)℃$，加热过高反而晶粒粗大、开裂；② 以为"淬火完就完工"——**淬火后必须回火**，否则又硬又脆。

### 5. 回火：淬火之后的必修课

**回火** = 把淬火后的钢加热到 $A_1$ **以下**、保温、再冷却（通常空冷）。**淬火 + 高温回火 = 调质处理（调质）**。

| 回火类别 | 温度 | 得到的组织 | 性能特点与典型用途 |
|------|------|:----:|------|
| **低温回火** | 150~250℃ | **回火马氏体 $M_{回}$**（$M$ + 极细 ε 碳化物 $\mathrm{Fe_{2.4}C}$） | 保持**高硬度、高耐磨**；**刃具、量具、轴承**、渗碳件、表面淬火件 |
| **中温回火** | 350~500℃ | **回火托氏体 $T_{回}$** | **弹性极限高**；**弹簧、锻模** |
| **高温回火** | 500~650℃ | **回火索氏体 $S_{回}$**（多边形 $F$ + 粒状 $\mathrm{Fe_3C}$） | **综合力学性能好**；即**调质**，用于轴类、连杆、齿轮等 |

### 6. 三组最易混的点

1. ⚠️ **退火 vs 正火**：温度、保温几乎一样，**唯一区别是冷却方式**（炉冷 vs 空冷）；正火组织更细、强度硬度更高。
2. ⚠️ **索氏体 $S$ ≠ 回火索氏体 $S_{回}$**、**托氏体 $T$ ≠ 回火托氏体 $T_{回}$**：前者是奥氏体**直接冷却**的产物，后者是**淬火钢回火**的产物，**形态像但出身不同**。
3. ⚠️ **淬火 ≠ 调质**：淬火只是"淬硬"；**调质 = 淬火 + 高温回火**，得到综合性能优良的回火索氏体。
4. 📌 **回火 vs 退火**：退火加热到临界点附近、**炉冷**；回火加热到 $A_1$ **以下**、**空冷**，且回火**必然是淬火的后续工序**。

### 7. 钢种牌号速查（"钢材的名字"）

上面是"组织的名字"，这里是工业上给具体钢种起的**身份证号**。

| 类别 | 牌号示例 | 牌号怎么读 |
|------|------|------|
| **普通碳素结构钢** | Q235AF、Q345R | **Q** = 屈服强度，数字 = 屈服强度 MPa；尾巴 F/b/Z/TZ = 脱氧方式 |
| **低合金高强度结构钢** | Q295GNH、Q345DTZ、L415 | Q + 屈服强度；**GNH = 高耐候**、R = 压力容器、DTZ = 特殊镇静 |
| **优质碳素结构钢** | 10F、20R、45、50MnE | **两位数字 = 平均含碳量的万分数**（45 → 0.45% C）；Mn = 含锰量较高 |
| **碳素工具钢** | T7、T8MnA、T10 | **T** = 碳素工具钢，数字 = 含碳量的**千分数**（T10 → 1.0% C）；A = 高级优质 |
| **合金结构钢** | 40Cr、40CrNiMo、38CrMoAl、60Si2Mn、GCr15、20MnVB | 数字 = 含碳量万分数，后跟合金元素符号；**GCr15 = 滚珠轴承钢** |
| **合金工具钢 / 高速钢** | 9SiCr、CrWMn、Cr12MoV、W18Cr4V、W6Mo5Cr4V2 | 含碳量 ≥1% 时**数字省略**；**W18Cr4V** 是最经典的高速钢 |
| **不锈钢与耐热钢** | 30Cr13、022Cr19Ni10、42Cr9Si2、20Cr25Ni20、102Cr17Mo | 前面数字仍是含碳量万分数 |
| **塑料模具钢** | SM3Cr2Mo | 前缀 SM = 塑料模具用钢 |

**脱氧方式代号（牌号尾巴）**：**F** 沸腾钢（脱氧不完全）、**b** 半镇静钢（居中）、**Z** 镇静钢（脱氧完全，通常省略）、**TZ** 特殊镇静钢（最彻底）。

🔥 **最容易记混的一点**：**结构钢**的数字指"含碳量**万分**数"（45 = 0.45%C），**工具钢 T** 后面的数字指"含碳量**千分**数"（T10 = 1.0%C）——一个分母是一万，一个分母是一千。

### 8. 铸铁：石墨形态与代号

**铸铁**是含碳量 $w_C > 2.11\%$、并含较多 Si、Mn、S、P 的**多元铁基合金**；组织 = **金属基体**（$F$ / $F+P$ / $P$）+ **石墨**。

| 名称 | 代号 | 石墨形态 | 牌号格式示例 | 数字含义 |
|------|:----:|------|------|------|
| **灰铸铁** | **HT** | **片状** | HT200 | **最低抗拉强度**（MPa），仅一组数字 |
| **可锻铸铁** | **KTH / KTB / KTZ** | **团絮状** | KTH300-06、KTB350-04 | 第一组 = 最低抗拉强度（MPa）；第二组 = **最小断后伸长率**（%） |
| **球墨铸铁** | **QT** | **球状** | QT400-18 | 同上，两组数字 |
| **蠕墨铸铁** | **RuT** | **蠕虫状** | RuT420 | **最低抗拉强度**（MPa） |
| **白口铸铁** | — | **无石墨** | — | 碳全以 $\mathrm{Fe_3C}$ 存在，硬脆，难切削 |

⭐ **可锻铸铁三个字母尾巴**：KTH = 黑心（T=团/黑）、KTB = 白心、KTZ = 珠光体基体。
🔧 **形态记忆钩子**：片状像"灰口"、团絮像"棉花"、球状像"弹珠"、蠕虫像"蚯蚓"。

### 9. 期末模拟试卷（自测入口）

📄 源文件：[[总结好的大纲以及笔记/学校/课程/大二上/机械工程材料/试卷/机械工程材料-期末考试模拟试卷.md|机械工程材料-期末考试模拟试卷]]（含[[总结好的大纲以及笔记/学校/课程/大二上/机械工程材料/试卷/机械工程材料-期末考试模拟试卷-参考答案与解析.md|参考答案与解析]]）

- **题型与分值**：选择题 10 题 × 2 分 = **20 分**；填空题 10 题（20 空）× 1 分 = **20 分**；**Fe–Fe₃C 相图综合分析题 1 题 = 60 分**；合计 **100 分**，时长 120 分钟，闭卷。
- **命题范围**（依课件，凡课件与教材不一致处**以课件为准**）：绪论、第一章材料性能及表征、第二章材料结构、第三章平衡凝固与相变、第四章塑性变形及再结晶、第五章热处理方式、第七章工业用钢、第八–九章铸铁和有色金属。
- **五大高频考点**（选择题 + 填空题密集覆盖）：
  1. **性能分类**：使用性能（力学/物理/化学）决定功能高低 vs 工艺性能（铸造/锻压/焊接/切削）决定制造成本；
  2. **硬度符号**：硬质合金球压头 = **HBW（650 以下）**，淬火钢球 = HBS（450 以下）；
  3. **晶体缺陷**：点（空位、间隙/置换原子）、线（位错）、面（**晶界、亚晶界**）；
  4. **同素异构转变**：1394℃ **bcc→fcc**、912℃ **fcc→bcc**（纯铁冷却时 δ→γ→α）；
  5. **Fe–Fe₃C 特征点**：**E 点 1148℃ / 2.11%C**（奥氏体最大溶碳量、钢与铁分界）、**C 点 1148℃ / 4.3%C**（共晶点）、**S 点 727℃ / 0.77%C**（共析点）、**P 点 727℃ / 0.0218%C**（铁素体最大溶碳量）。
- **综合题**：以 $w_C = 1.0\%$ 的过共析钢（预备热处理为退火）为载体，串起"特征点 → ECF/PSK 线反应式 → 缓冷过程相与组织 → 室温组织组成物 vs 组成相 → 杠杆定律算 P 与 Fe₃C_Ⅱ 相对量 → 淬火温度与组织"。**这道题把相图、组织、热处理三块全串起来了，是检验掌握程度的最好一题。**
- 🔥 **一条覆盖全卷的记忆主线**：能**同时**提高强度、硬度、塑性和韧性的强化方法是**细晶强化**（固溶/弥散/加工硬化都牺牲塑性）——这类"唯一区别"型考点最容易被设成选择题。

## 关键概念/术语

| 术语 | 定义 |
|------|------|
| **退火** | 加热到适当温度、保温、缓慢冷（炉冷）；软化为目的；六种细分 |
| **正火** | 加热到 $A_{c3}$/$A_{ccm}$ 以上 30~50℃、空冷；组织更细 |
| **淬火** | 加热到临界点以上、以 > $V_k$ 的速度急冷，得马氏体 |
| **回火** | 淬火后加热到 $A_1$ 以下、保温、空冷；消除脆性、调强韧性 |
| **调质** | 淬火 + 高温回火，得回火索氏体 $S_{回}$，综合力学性能好 |
| **$V_k$（临界冷却速度）** | 过冷奥氏体全部转变为马氏体所需的最小冷却速度 |
| **$A_{c1}/A_{c3}/A_{ccm}$** | 加热时的临界温度线（带 c 表示"加热用"）；热处理公式里都用带 c 的 |
| **淬透层深度** | 淬火后工件表层获得马氏体的厚度（深度）；$V_k$ 越小，淬透性越好、淬硬层越深 |
| **回火马氏体 / 托氏体 / 索氏体** | $M_{回}$ / $T_{回}$ / $S_{回}$，分别对应低 / 中 / 高温回火产物 |
| **牌号** | 工业上给具体钢种起的"身份证号"，按"数字 + 元素符号"编码 |
| **脱氧方式代号** | F 沸腾、b 半镇静、Z 镇静、TZ 特殊镇静 |
| **石墨形态** | 铸铁按石墨形状分类：片状（HT）/ 团絮（KTH等）/ 球状（QT）/ 蠕虫（RuT）/ 无石墨（白口） |
