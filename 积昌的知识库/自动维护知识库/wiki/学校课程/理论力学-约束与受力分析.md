# 理论力学——约束与受力分析

## 概述

本页汇总《理论力学》静力学部分"**从约束到受力图**"的一条完整主线：先建立**约束 / 约束力**的基本概念（§2.3），再认识工程中四类常见约束各自的约束力画法（§2.4），然后用**三步法**把约束画成受力图（§3.1），最后专门处理一类可以"一眼简化"的特殊构件——**二力构件/二力杆**（§3.2）。整条主线回答的是同一个问题：**一个机械零件被"绑"在某个位置上，是谁在托住它、方向朝哪、画图时该画几个力？**——这就是静力学一切计算的起点。

## 核心要点

### 1. 约束与约束力（§2.3 约束与约束反力）

- **自由体**：可以在空间任意运动的物体；**非自由体**：某些方向的运动受到限制的物体。
- **约束**：对非自由体运动**起限制作用**的周围物体（如地面、绳子、铰链、轴承）。
- **约束力（约束反力）**：约束施加在非自由体上、**阻碍其运动**的力。与之相对，主动力（如重力、推力）是**已知或已知方向、独立给定**的力，约束力是**被动**产生的。
- 🔥 **约束力三要素**：
  1. **大小**：一般**未知**，需要由平衡方程求解（这正是受力分析的意义所在）；
  2. **方向**：**与约束所阻碍（限制）的位移方向相反**——约束不让往哪走，力就朝反方向顶；
  3. **作用点**：作用在**约束与被约束物体的接触处**。
- **主动力 vs 约束力**：主动力（载荷）主动给定、一般已知；约束力被动跟随主动力产生，随主动力存在——**没有主动力就没有约束力**（绳子不受拉就没有拉力）。

### 2. 工程中常见的约束（§2.4）

| 约束类型 | 约束力画法 | 约束力特点 | 典型实例 |
|------|------|------|------|
| **光滑接触约束** | 一个力 $F_N$ | **沿接触面公法线、指向被约束物体**（只能是压力，不能拉） | 物体搁在光滑地面/斜面上 |
| **柔索类约束**（绳、带、链条） | 一个力 $F_T$ | **沿柔索方向、背离物体（只能受拉）** | 吊绳、皮带传动 |
| **光滑圆柱铰链约束** | 两个正交分力 | 方向**待定**（铰链不限制转动，只限制平动）→ 分解为 $F_x$、$F_y$ | 门窗合页、销钉连接 |
| ↳ **径向轴承（向心轴承）** | 两个正交分力 | 只限制径向移动，允许转动 | 转轴颈部的轴承 |
| ↳ **固定铰链支座** | 两个正交分力 | 底端固定在地/墙上、构件绕其转动 | 桥梁支座、支架 |
| **滚动支座（活动铰支座）** | 一个力 | **垂直于支承面**（可滚动，故沿面方向不约束） | 桥梁一端、管道支架 |
| **球铰链** | 三个正交分力 | 限制三个方向的平动，允许三向转动 | 球头拉杆、机械臂末端 |
| **止推轴承** | 三个正交分力 | 既限制径向又限制轴向移动 | 承受轴向载荷的轴 |

- 🔥 **核心规律**：**"限制几个方向的平动，就画几个力"**——光滑接触/柔索/滚动支座限制 1 个方向 → 1 个力；光滑圆柱铰链/固定铰链支座限制 2 个方向 → 2 个正交分力；球铰链/止推轴承限制 3 个方向 → 3 个分力。
- **"两个正交分力"的意义**：铰链处约束力的**真实方向事先不知道**，所以先用两个互相垂直的分力"占位"——这是**代数量**，最终由平衡方程解出正负号即可知道真实指向。
- **手臂关节应用**（课本练习）：肩、肘、腕可类比为不同自由度的铰链约束，用来理解"约束数 = 被限制的自由度"。
- **三步分辨法**：① 看接触方式（面接触/绳/铰/球窝）；② 数它限制了几个方向的平动；③ 按"限制几个画几个"写出对应的 1 / 2 / 3 个分力。

### 3. 受力分析与受力图（§3.1）

- **受力分析**：**定性**地确定研究对象受了哪些力、每个力来自谁、方向如何（只判性质与方向，不要求数值）。
- **分离体（自由体）**：把研究对象从周围环境中**单独取出**、解除所有约束后得到的孤立物体——**原约束的位置用对应的约束力"补上"**。
- **画受力图三步法**：
  1. **取研究对象**：明确要分析谁，把它单独画出来（解除约束）；
  2. **画主动力**：把已知的载荷（重力、外力）先画上；
  3. **依约束性质画约束力**：按 §2.4 那张表，逐个接触处补上该约束类型对应的力。
- 🔥 **核心原则：内力一律不画在受力图上**——研究对象是整体时，整体内部各部分之间互相作用的力（内力）不出现在图上；只有跨越"研究边界"的力才是外力。
- **例题（碾子）**：碾子受重力、地面法向约束力、推力等——按"面接触画 $F_N$、重力的作用点在质心"逐项落实。
- **例题（三角拱桥结构）**：两半拱之间是铰链，取整体时**铰链处两半之间的力是内力、不画**；取一半时它才变成外力。

### 4. 二力构件（§3.2 二力构件）

- **定义**：**只在两个力的作用下平衡**的构件（不多一个力、也不少一个力）。形状是直杆或弯杆时，习惯称**二力杆**。
- 💡 **一个构件是不是二力构件，只与它的受力有关，与形状无关**——弯杆、任意形状的构件，只要"只受两个力"就是二力构件。
- **受力特点（二力平衡公理）**：两个力必**等值、反向、共线**，且**沿着两个力作用点的连线**。
  - **直杆**形式：两作用点连线沿杆 → 两个力都沿杆方向，可能拉、可能压；
  - **弯杆 / 任意形状**：两力仍沿**两作用点的连线**（不是沿弯杆的弯折方向）。
- 🔥 **二力构件的最大简化价值**：**它其实只有一个未知力**——知道一个，另一个（等值反向）自然得到；方向也**从"不确定的两个正交分力"变成"沿连线的一个方向"**。识别出二力杆，受力图立刻简化。
- **识别方法（关键）**：逐一检查杆两端约束的**本质**——若每个约束本质上都相当于"**一个力**"（光滑接触、光滑圆柱铰链、固定铰链支座），且杆上**无其他主动力**，则该杆是二力杆。
- **例题（水平均质梁 AB + 轻直杆 CD）**：
  - **CD 杆**：C 端是固定铰链支座、D 端是光滑圆柱铰链，二者本质都是"一个力" → CD 是**二力杆**，受力应画成**沿 CD 方向的一对力**（不是两个正交分力）；
  - **AB 梁**：A 端固定铰链支座（两个正交分力 $F_{AX},F_{AY}$），D 端受 CD 杆的反作用力 $F_D'$——**方向已由 CD 杆的受力直接确定，无需再分解**；再加自身重力 $P_1$ 与电动机重力 $P_2$。
- **受力方向的假定**：画受力图时**不必先给真实方向**，可按直觉**先假定**（画成拉或压都可以）；由**定量计算**得出结果——**正值为假定方向，负值为反方向**。同一根二力杆先假定受压或先假定受拉皆可，**最终结果一致**（AB 梁在 D 点的力会相应反向）。
- **练习（四结构判断）**：结构一/二 → 两根杆中有二力杆；结构三 → **二力弯杆**，受力沿**两作用点连线**；结构四（三根杆）→ **三根杆都是二力杆**——关键在"销钉端受两段绳的拉力"是**两个共点力**，可合成为一个力，因此该端仍是"一个力"，不破坏二力杆条件。

## 关键概念/术语

| 术语 | 定义 |
|------|------|
| **自由体 / 非自由体** | 可在空间任意运动的物体 / 某些方向运动受限制的物体 |
| **约束** | 对非自由体运动起限制作用的周围物体 |
| **约束力（约束反力）** | 约束施加在非自由体上、阻碍其运动的力；被动产生，大小未知 |
| **主动力** | 独立给定、已知（或方向已知）的力，如重力、外力 |
| **约束力三要素** | 大小未知、方向与所阻碍位移相反、作用在接触处 |
| **光滑接触约束** | 约束力沿公法线、指向物体，只能是压力 |
| **柔索类约束** | 绳/带/链，约束力沿柔索、背离物体，只能受拉 |
| **光滑圆柱铰链** | 允许转动、限制两个方向平动 → 两个正交分力 |
| **固定铰链支座** | 底端固定的铰链 → 两个正交分力 |
| **滚动支座（活动铰支座）** | 可沿支承面滚动 → 一个垂直于支承面的力 |
| **球铰链 / 止推轴承** | 各限制三个方向平动 → 三个正交分力 |
| **分离体（自由体）** | 解除全部约束后单独取出的研究对象 |
| **受力图** | 在分离体上画出全部外力（主动力 + 约束力）的图 |
| **二力构件 / 二力杆** | 只在两个力作用下平衡的构件；两力等值、反向、沿作用点连线 |
| **二力平衡公理** | 二力构件平衡的充要条件：等值、反向、共线 |
