# 电工学——回路电流法与仿真图制作

## 概述

本页收拢《电工学》"电路分析方法"一章的**方法本体**与**配套画图工具链**两件事。方法本体是**回路电流法**（以"假想回路电流"为未知量、对每个独立回路列 KVL 方程联立求解，是节点电压法的姊妹方法），本体只有一个双回路的标准例题；工具链则是把这张双回路电路**用四种方式画出来**——CircuitJS 交互仿真、TikZJax 矢量渲染、Excalidraw 手绘、draw.io 矢量图，并沉淀出一条**Obsidian 仿真图尺寸规范**（≈780×540 px）。核心要记住两点：**回路电流法是"设假想电流 → 列 KVL → 解方程 → 回代求各支路电流"**，而**Obsidian 里的 CircuitJS 不会自动缩放，想让图变大只能放大 netlist 坐标**。

## 核心要点

### 1. 回路电流法（网孔电流法）

**出发点**：支路电流法要为每条支路列方程（b 条支路 = b 个未知量），方程多。回路电流法改以**每个独立回路里的假想回路电流**为未知量——独立回路数 = b − (n−1)，比支路数少，方程一下子就少了。

**解题四步**：

1. **设回路电流**：给每个独立回路假定一个环流方向（本例取两个回路电流 $I_{\mathrm{I}}$、$I_{\mathrm{II}}$，均设为顺时针）；
2. **对每个回路列 KVL**（沿回路一周电压降的代数和 = 0）；
3. **联立求解**回路电流；
4. **由回路电流回代求各支路电流**——**共有支路的电流 = 两个回路电流的代数和**。

**双回路标准例题的方程**（黑板原式）：

| 类型 | 方程 |
|------|------|
| **KVL**（回路 I / 回路 II） | $(R_1+R_3)I_{\mathrm{I}} - R_3 I_{\mathrm{II}} = E_1$ ； $-R_3 I_{\mathrm{I}} + (R_2+R_3)I_{\mathrm{II}} = -E_2$ |
| **KCL**（支路电流回代） | $I_1 = I_{\mathrm{I}}$ ； $I_2 = -I_{\mathrm{II}}$ ； $I_3 = I_{\mathrm{I}} - I_{\mathrm{II}}$ |

- **自阻（自阻抗）恒为正**：$R_1+R_3$、$R_2+R_3$——回路 I 经过 R1、R3，回路 II 经过 R2、R3，各是"本回路经过的电阻之和"。
- **互阻（互阻抗）取负**：$-R_3$——R3 是**两个回路共有**的电阻；**两回路电流同向**（都取顺时针）时互阻项前**统一用负号**。
- **等式右边**：$E_1$、$-E_2$——沿回路绕行方向，**电压源从"−"升到"+"（电位升高）取正**，从"+"到"−"取负。回路 II 得 $-E_2$ 正说明沿顺时针绕行时 $E_2$ 是从"+"到"−"。
- 🔥 **规律速记**：**自阻恒正、互阻恒负、两回路同向绕行**——这是回路电流法"看一眼就能把方程摆出来"的固定套路。

### 2. 例题电路（同一张图的四种画法）

电路结构：**上支路 R₁ 串联 R₂**，**左右各接一个电压源 E₁ / E₂**，**中间支路 R₃ 竖直连接上下两条水平线**——构成两个相邻的矩形回路。

| 呈现方式 | 插件 / 工具 | 特点 | 适用场景 |
|------|------|------|------|
| **CircuitJS** | `obsidian-circuitjs`（` ```circuitjs ` 代码块） | **可交互仿真**：拖动元件、改参数、实时看电流/电压变化；**需切到阅读视图** | 讲"电流往哪流""改变阻值会怎样"的动态演示 |
| **TikZJax** | `obsidian-tikzjax`（` ```tikz ` 代码块，需 `\usepackage{circuitikz}` + `\begin{document}…\end{document}`） | **矢量渲染、改代码即改图**，可由 AI 直接生成；适合放公式与电路同屏 | 静态、精确、可版本管理的电路图 |
| **Excalidraw** | Excalidraw 插件（`.excalidraw.md` 文件） | **手绘风**，可自由拖拽标注，最贴近"黑板讲题"的直观感 | 课堂记号、箭头标注、强调某个回路 |
| **draw.io** | draw.io / diagrams.net（`.drawio` + 导出 `.svg`） | **专业矢量图**，780×540 观感，是**尺寸参考基准** | 正式讲义、报告配图 |

- **CircuitJS netlist 元件对照**：`v` = 电压源（E₁/E₂）、`r` = 电阻（R₁/R₂/R₃）、`w` = 导线、`g` = 接地；`$ 1 …` 第 1 行是**总体设置行**（不参与绘图）。
- **netlist 手写易错**：推荐在 <https://www.falstad.com/circuit/> 画好后用「文件 → 导出为文本」，再粘进代码块。

### 3. ⭐ Obsidian 仿真图尺寸规范（CircuitJS 画布）

**问题**：CircuitJS 图默认"太小"，改容器 CSS 也没用。**根因**：Falstad CircuitJS **不自动缩放**——坐标多大图就多大；`obsidian-circuitjs` 把容器写死为 `width:100%; height:600px`，**容器不是瓶颈，netlist 的坐标数值才是**。

**唯一有效解法：放大 netlist 里坐标字段的数值，不动参数值。**

| 项 | 标准值 |
|------|--------|
| 目标观感尺寸 | **≈ 780 × 540 px**（与 draw.io 参考图 `回路电流法-双回路电路.drawio.svg` 一致） |
| 画布宽度 | netlist 坐标跨度 **≈ 768**（x 最大值 ≈ 768） |
| 画布高度 | netlist 坐标跨度 **≈ 384** |
| 坐标粒度 | **16 的整数倍**（Falstad 网格 = 16，避免元件错位） |
| 容器尺寸 | 由 CSS 片段 `circuitjs-size` 统一控制（`.obsidian/snippets/circuitjs-size.css`），须在 `.obsidian/appearance.json` 的 `enabledCssSnippets` 中启用 |

**操作步骤**：

1. 取得原始 netlist（Falstad 官网导出为文本）；
2. 把**每条元件行的前 4 个数字**（`x1 y1 x2 y2`）乘以放大倍数 **k**，使 **x 最大跨度 ≈ 768**——例：跨度 384 → k=2；256 → k=3；192 → k=4；
3. 乘积取 **16 的整数倍**；**切记不要乘后面的参数**（阻值、电压、频率、flags）；
4. 校验：x 跨度 ≈ 768（±32 可接受）、只放大了坐标、全为 16 的倍数、CSS 片段已启用。

- 各类元件行的坐标字段位置：`v x1 y1 x2 y2 flags …`（电压源）、`r x1 y1 x2 y2 flags 阻值`（电阻）、`w x1 y1 x2 y2 flags`（导线）、`g x1 y1 x2 y2 flags`（接地）。
- 本例范图已按 **×2** 放大（384×192 → 768×384），与参考图 780×540 观感一致。

## 关键概念/术语

| 术语 | 定义 |
|------|------|
| **支路电流法** | 以每条支路的真实电流为未知量列方程，$b$ 个未知量需 $b$ 个方程（KCL + KVL） |
| **回路电流法（网孔电流法）** | 以各独立回路中假想的**环流**为未知量列 KVL，方程数 = 独立回路数 $b-(n-1)$，比支路法少 |
| **独立回路数** | $b - (n - 1)$，$b$ 为支路数、$n$ 为节点数（平面电路即网孔数） |
| **自阻（自阻抗）** | 某回路电流所经过的全部电阻之和，**恒为正** |
| **互阻（互阻抗）** | 两个相邻回路共有的电阻；两回路绕行方向相同（同向）时，互阻项前**取负号** |
| **KVL** | 基尔霍夫电压定律：沿任一闭合回路绕行一周，各段电压降的代数和为零 |
| **KCL** | 基尔霍夫电流定律：流入任一节点的电流代数和为零（本例用于由回路电流回代支路电流） |
| **netlist** | CircuitJS 的电路描述文本，每行一个元件（首行为全局设置行） |
| **CircuitJS / TikZJax / Excalidraw / draw.io** | 四种电路图呈现方式：交互仿真 / 代码即矢量图 / 手绘 / 专业矢量图 |
