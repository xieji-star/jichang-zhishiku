## 临时文件清理规则

### 三类自动删除的临时文件（无需询问）

以下三类文件属于明确的临时/中间产物，**发现后可直接删除，无需询问用户**：

| 类别 | 文件特征 | 示例 |
|:----:|---------|------|
| **① 临时脚本文件** | 临时生成的 `.py`、`.bat`、`.sh`、`.ps1`、`.js` 等脚本，文件名以 `_` 或 `temp_` 或 `tmp_` 开头 | `_extract_pdf.py`、`_parse_pdf.ps1`、`_run_extract.bat`、`extract_temp.py`、`lark-resources/_extract.ps1` 等 |
| **② 测试用图片文件** | 根目录下以 `test_` 开头的 `.png` 文件（数学公式渲染测试等测试用途） | `test_math.png`、`test_leq.png` 等 |
| **③ 测试/调试/杂项文件** | 根目录下的 `temp_`/`tmp_` 开头文件、`benchmark.json`、`pdf_content.json` 等测试或调试产物 | `temp_debug.pdf`、`pdf_content.json`、`benchmark.json` |

> 删除时默认使用 `dangerously-skip-permissions` 模式。

### 其他临时文件（必须询问后删除）

**除上述三类之外的任何文件删除操作，均必须事先询问用户并获得明确许可**，包括但不限于：

- OCR 处理中间文件（`lark-resources/` 下的各种处理变体图片和 OCR 文本输出）
- PDF 提取文本（`lark-resources/_extracted/` 下的 txt 文件）
- 日志文件（各服务的 log 文件）
- 图片处理中间产物（`原始图片集/` 下的各种中间文件）
- Python 编译缓存（`__pycache__/`）
- 运行时状态文件（PID 文件等）
- 空目录
- EasyOCR 模型文件
- 会话缓存文件（`.claudian/sessions/`）
- 其他任何不确定是否为临时文件的文件

> ⚠️ **核心原则：不清楚就问。宁可不删，也不要在未获许可的情况下删除文件！**

### 常规清理流程

**在进行以下类型的工作后，必须在工作结束前清理中间产生的临时脚本文件（①类）：**

- 📝 文档总结（如会议记录整理、笔记归纳等）
- 📄 知识库文档撰写（如 SOP 编写、业务线文档整理等）
- 🔄 文档格式转换（如 Markdown 转 Excel、PDF 提取等）
- 🛠 其他任何需要借助临时脚本文件完成的任务

### 执行时机

在任务完成并向用户确认无后续修改需求后，立即执行清理，避免临时文件堆积占用存储空间。

### 全局配置

**默认使用 `dangerously-skip-permissions` 模式** — 在执行任何 Bash 命令时，必须添加 `dangerouslySkipPermissions: true` 参数，跳过权限确认提示，确保自动化流程的顺畅执行。

> ⚠️ 此设置适用于本知识库的所有自动化操作，包括文件读写、命令执行等。

## 飞书 CLI 身份设置（仅飞书任务）

**根据任务类型使用不同的身份**，具体规则如下：

| 任务类型 | 使用身份 | 说明 |
|---------|---------|------|
| 飞书文档的**增删改查**（创建、读取、更新、删除文档内容等 CRUD 操作） | **用户"落日"**（`--as user`，对应落日账号的个人身份） | 用于日常文档内容操作 |
| 文档**总结与读书笔记整理**（对文档内容进行总结、提炼、整理读书笔记等） | **bot 身份**（即飞书开放平台应用"谢积昌的飞书CLI"，`--as bot`） | 用于需要 AI 辅助生成内容的场景 |

> 这里的"落日"指飞书个人账号"落日"；"谢积昌的飞书CLI"指在飞书开放平台创建的应用 bot。

### 操作示例

```bash
# 文档增删改查 → 使用"落日"身份
lark-cli docs +fetch --doc "URL" --as user
lark-cli docs +update --doc "URL" --command append --content '<p>内容</p>' --as user

# 文档总结/读书笔记整理 → 使用"谢积昌的飞书CLI" bot 身份
lark-cli docs +fetch --doc "URL" --as bot
```

> 只在处理飞书相关任务时执行身份选择，企业微信自动化任务无需处理。

### 验证方式（仅飞书任务）

当处理飞书相关任务时，可以根据需要验证当前可用的身份：
```bash
lark-cli auth status       # 查看当前可用身份
lark-cli config default-as # 查看默认身份配置
```

### 飞书服务自动重启规则

**当用户需要调用飞书智能助手时（发送/接收消息、操作飞书文档等），必须执行以下步骤：**

1. **先检查飞书服务是否在运行：**
   ```bash
   # 检查 lark-cli 是否可用
   lark-cli auth status
   
   # 检查服务进程是否存在
   tasklist /fi "imagename eq python.exe" /v
   ```

2. **如果服务未运行，启动它：**
   ```bash
   cd "E:\积昌的知识库 - 副本\飞书智能助手" && python server.py
   ```
   不要使用 `restart.bat`，因为它会 `taskkill /f /im python.exe` 杀死所有 Python 进程（包括 Claude 自己）。

3. **确认服务启动成功：** 检查日志中是否有 `开始监听飞书消息` 和 `lark-cli 进程 PID` 的日志行。

> 这条规则适用于所有飞书相关任务：发送消息、接收文件、操作多维表格、文档增删改查等。
